# М11/3 — Агент и отчёты поколениями: инструкция для реализации

## Задача

Сторона консоли домена — `GET /domain/members`. Агент члена и сторона члена в приёме (`join`) — перенесено в [инструкцию урока P/09](../../Platform/09-agent/spec/09-agent.README.md), глава 9.1 (стадия B; урок 9). Сторона держателя
(приём отчётов поколениями, ответ держателя, приём члена у держателя) — перенесено в [инструкцию урока P/08](../../Platform/08-domain/spec/08-domain.README.md), глава 8.3 (стадия B; урок 8).

## Входы и их приоритет

Канон — [нормы](03-agent-and-reports.norms.md). [HTTP-контракт](03-agent-and-reports.api.openapi.yaml) выражает формы
дверей, тела, метки и ответа; приёмка (стадия B, урок 8: сценарии
держателя — [приёмка P/08.3](../../Platform/08-domain/acceptance/3/README.md), вида — [P/08.1](../../Platform/08-domain/acceptance/1/README.md);
сц. 10–13 сняты — векторы `agent-sig`, `domain-envelopes`, `accept`; каталог М11/03 снят) — стенд
нескольких кластеров и векторы; [лекция](../03-agent-and-reports.md) объясняет причины. При противоречии записать место и
контрпример и передать «Спецификации»; инструкция не вводит новый отказ. Внутренние типы и устройство — выбор реализации.

- Агент (роль `domainagent`) — перенесено в [инструкцию урока P/09](../../Platform/09-agent/spec/09-agent.README.md), глава 9.1 (стадия B; урок 9).

## При расхождении

Дефект реализации — вывод не совпадает с ожиданием на входе приёмки. Дефект приёмки — ожидание расходится с нормой. Пробел
нормы — вход, для которого норма не даёт однозначного исхода: вопрос «Спецификации» с входом и предложением. Закрытое
решение отражается в норме, а не в этой инструкции.
