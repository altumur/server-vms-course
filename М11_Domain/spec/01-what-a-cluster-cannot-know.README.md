# М11/1 — Чего кластер не может знать, теневой режим: инструкция для реализации

## Задача

Построить проход держателя, который сводит копии членов в вид домена и теневой отчёт, двери `GET /domain`,
`/domain/<sub>/<rows>`, `/domain/shadow` и команду `view` для приёмки. Домен ничего не пишет в члены.

## Входы и их приоритет

Канон — [нормы](01-what-a-cluster-cannot-know.norms.md). [OpenAPI](01-what-a-cluster-cannot-know.api.openapi.yaml)
выражает формы дверей и входа и вывода команды `view`, [приёмка](../../Source/tests/testdata/acceptance/М11_Domain/01/README.md) —
наблюдаемые примеры, [лекция](../01-what-a-cluster-cannot-know.md) объясняет причины. При противоречии записать место и
контрпример и передать «Спецификации»; инструкция не вводит новый отказ. Внутренние типы и устройство — выбор реализации.

## Что создать

- Проход держателя Н3: вид домена и теневой отчёт раз в 3 с, объекты `domain/view` и `domain/shadow`.
- Двери Н2 у консоли держателя.
- Команду `view` с той же функцией без хранилища; её вызов — дверь `view` словаря «Стенда» М11/01.

## Порядок работы

1. Свежесть Н1.3: смена метки и пульса — на монотонных часах держателя; первый взгляд на метку — не смена (член `unseen`), на пульс — смена; LOST_AFTER 45 с.
2. Вид Н1.4: единицы из пульсов, затем из шардов снимка без повторов id; порядок (cluster, id); `contested` до `complete`.
3. Теневой отчёт Н1.6: заявки из `status[]` с ref по шарду своего члена; память времени смены `observed_revision` по паре;
   `clean_streak` обнуляется любой находкой и `unknown`.
4. Команда `view`: вход `ViewInput`, вывод `ViewOutput` (OpenAPI); каждый проход входа — один проход держателя.
5. Двери Н2 и отказы Н4.

## Ловушки языка и библиотеки

| Норма | Возможная ошибка | Как сохранить поведение |
|---|---|---|
| Н1.3 | Возраст по стенным часам или по `sent_at` члена | Только монотонные часы держателя и смена на его глазах. |
| Н1.4 | Две заявки одного ref — взять первую по порядку | Обе в `contested`, ни одной в `units`, `complete: false`. |
| Н1.4 | Единица из шарда повторяет единицу из пульса | Id, уже взятый из пульса, шард не добавляет. |
| Н1.6 | Сравнение ревизий на равенство | Отставание — `revision > observed_revision`; застой — время без смены. |
| Н1.5 | Пустой список при молчащем члене | `complete: false` и член `silent`; список не короче «на всякий случай». |

## Готово, когда

- Сценарии приёмки 01–10 проходят командой `view`.
- Двери Н2 отвечают формами контракта; проверка на стенде нескольких кластеров — урок 3 Н5.
- Описание реализации называет команду `view` и где хранится память теневого отчёта.

## При расхождении

Дефект реализации — вывод не совпадает с ожиданием на входе приёмки. Дефект приёмки — ожидание расходится с нормой. Пробел
нормы — вход, для которого норма не даёт однозначного вида: вопрос «Спецификации» с входом и предложением. Закрытое решение
отражается в норме, а не в этой инструкции.
