# М11/5 — Книги из строк членов: инструкция для реализации

## Задача

Построить книги из строк членов: проверку объявления, вклад воркера под слотом, его путь в отчёте с секретом в конверте
`x25519:v1`, сборку у держателя, доставку члену и дверь книги.

## Входы и их приоритет

Канон — [нормы](05-books-from-member-rows.norms.md). [HTTP-контракт](05-books-from-member-rows.api.openapi.yaml) выражает
форму двери книги; [приёмка](../../Source/tests/testdata/acceptance/М11_Domain/05/README.md) — стенд с `testsub2` и векторы
`assemble`; [лекция](../05-books-from-member-rows.md) объясняет причины. При противоречии записать место и контрпример и
передать «Спецификации»; инструкция не вводит новый отказ.

## Что создать

- Загрузчик: форма `domain.books` и отказы Н1.1 (случаи `m51_books_*` урока 2).
- Воркер: запись вклада под слотом, чистка при захвате чужого слота; учебный писатель `testsub2` (Н5).
- Агент: вклады в отчёте объектами, живость слота с перечиткой, секреты — `x25519:v1`, тот же конверт для того же значения.
- Держатель: сборка Н3 в проходе вида, строки `domain/<sub>/<книга>/<член>`, `view.books`, доставка в `sealed.books`.
- Агент члена: строка `domain/<sub>/<книга>`; консоль: дверь книги Н2; команда `assemble`.

## Порядок работы

1. `assemble` (чистая функция Н3): кто вкладывает, `missing` с закрытыми словами, снятие вклада целиком, `unique`/`all`, порядок.
2. Вклад в отчёте и конверт секрета (урок 2 Н1.5): AAD — член, ключ строки, item, JSON Pointer.
3. Строки у держателя и члена, секреты — кольцом (М10/7), запись только при изменении.
4. Дверь книги и маска.

## Ловушки языка и библиотеки

| Норма | Возможная ошибка | Как сохранить поведение |
|---|---|---|
| Н1.2 | Новый конверт секрета каждым проходом | Тот же конверт для того же значения — иначе поколение каждые 5 с. |
| Н1.3 | Испорченный вход — снять только его | Снимается весь вклад члена в книге, член — в `missing`. |
| Н1.3 | Член `unseen` — не вкладывает | Вкладывает и стоит в `missing` (`why: unseen`). |
| Н1.3 | Получатель вне списка — доставить «на будущее» | Не получает ничего; только `view.books.undelivered`. |
| Н1.4 | Секрет книги в ответе двери или журнале | Только `show`-поля; секреты — конвертами кольца. |

## Готово, когда

- Сценарии приёмки 01–06 проходят; случаи `m51_books_*` урока 2 дают свои вердикты.
- Описание реализации называет `assemble`, учебного писателя и память конвертов.

## При расхождении

Дефект реализации — вывод не совпадает с ожиданием на входе приёмки. Дефект приёмки — ожидание расходится с нормой. Пробел
нормы — вход, для которого норма не даёт однозначного исхода: вопрос «Спецификации» с входом и предложением.
