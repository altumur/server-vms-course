# М11/9 — Люди, гранты, имена: инструкция для реализации

## Задача

Завести людей у держателя и вход, выдающий токен человека. Нести гранты каждому кластеру и решать право локально
функцией `may`. Дать аварийный вход у кластера и общий предел попыток. Вести индекс имён книг с `domain.names` и
дверь семей ключей.

## Входы и их приоритет

Канон — [нормы](09-people-grants-names.norms.md). [HTTP-контракт](09-people-grants-names.api.openapi.yaml) выражает
формы дверей урока; аварийный вход и `/session` — контракт P/06 (глава 6.3), форма токена и проверка — урок 2, пересылка — урок 8.
[Приёмка](../../Source/tests/testdata/acceptance/М11_Domain/09/README.md) — стенд урока 5 (сц. 07 снят: векторы
[`may`](../../Platform/common/vectors/may/README.md));
[лекция](../09-people-grants-names.md) объясняет причины. При противоречии записать место и контрпример и передать
«Спецификации»; инструкция не вводит новый отказ.

## Что создать

- Процесс `domain` — перенесено в [инструкцию урока P/08](../../Platform/08-domain/spec/08-domain.README.md), глава 8.4 ([P/08.4](../../Platform/08-domain/spec/08.4-domain.norms.md); индекс имён — глава 8.5,
  [P/08.5](../../Platform/08-domain/spec/08.5-domain.norms.md); стадия B; урок 8).
- Консоль домена:
  - `PUT`/`GET /domain/grants` по CAS с проверками имён;
  - передача дверей людей процессу `domain`;
  - сторожевая по `domain/grants/domain`.
- Агент: копия грантов с `as_of`, аварийная строка, снятие при отсутствии поля.
- Консоль кластера:
  - `may` в сторожевой, `/session` с грантами;
  - аварийный вход по порядку Н1.6 и предел Н1.10;
  - `GET /domain/keys`.
- Загрузчик: формы `domain.names` и `domain.keys`, слова `display.keys` (случаи `m59_*` корпуса P/02.1).
- Сборщик книг: доставка по рангу гранта, `person_names` в виде.
- Команда `may`.

## Порядок работы

Пп. 1–3 (`may` по векторам; строка человека, вход и предел; строки грантов, последний администратор, копия у члена)
перенесены в [инструкцию урока P/08](../../Platform/08-domain/spec/08-domain.README.md), глава 8.4 ([P/08.4](../../Platform/08-domain/spec/08.4-domain.norms.md); стадия B; урок 8).

4. Сторожевая консоли кластера и консоли домена; `/session` с грантами; «петля — operator» только в `open`.
5. Аварийный вход; индекс имён и его проверки; семьи ключей.

## Готово, когда

- Сценарии приёмки 03, 06 проходят (сц. 07 — векторы `may`), случаи `m59_*` корпуса P/02.1 дают свои вердикты; сц. 01, 02, 04, 08–10 —
  [приёмка P/08.4](../../Platform/08-domain/acceptance/4/README.md), сц. 05 — [приёмка P/08.5](../../Platform/08-domain/acceptance/5/README.md) (стадия B).
- Стенды уроков 3–8 проходят с личностью `root`, которую раннер ставит по словарю М11/01.
- Описание реализации называет команды `may` и `domain first-admin`.

## При расхождении

Дефект реализации — вывод не совпадает с ожиданием на входе приёмки. Дефект приёмки — ожидание расходится с нормой. Пробел
нормы — вход, для которого норма не даёт однозначного исхода: вопрос «Спецификации» с входом и предложением.
