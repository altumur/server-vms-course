Как устроено:

Правило долга (§1.7):
- Новая строка долга появляется, только если ADR вводит ключ сначала на одной стороне.
- В хвосте строки стоит `# ADR-NNNN «владелец второй стороны»`, и закрывает её коммит этого владельца.
- Голые строки, набранные до правила, «Паритет» размечает так же, после чего снимок моста удаляется (ADR-0003).

## 2. Решения, которые держат таблицы

**Словарь `fault`.** Слово для машины и теста; `detail` — для человека и не сверяется, `error` тоже.
- 400: `not_json`, `not_number`, `too_long`, `bad_url`.
- 409: `must_match`, `unique`, `garbled` — отказ зависит от уже стоящих строк (ADR-0031).
- Новое слово появляется сначала в `fault.tsv`, потом в коде обеих сторон.

**Значения в строке хранилища:**
- Скаляр — текст JSON. Строка пишется как есть. `null` на верхнем уровне любого поля значит, что поля нет. Целое значение пишется цифрами, без `-0`. Остальные числа — кратчайшей десятичной записью без экспоненты. Число за пределами float64 — `not_number`.
- Любой JSON, который платформа кладёт в строку, канонический: без пробелов, ключи отсортированы, UTF-8 как есть, без экранирования HTML.
- Поле `json` берёт значение как есть. Текстовое поле разбирает страница.
- Потолок поля `json` — 4000 байт канонического текста.

**Группа по хосту (ADR-0053).**
- Схемы объявляются картой у поля: `fields.<url>.schemes`.
- Схема поля называет только то, что пишет оператор и открывает актуатор. Адрес, который строится в памяти (`ingest://`), ключом спеки не является. `#` под схемой, читаемой по RFC, — отказ `bad_url`: правам он называет один хост, драйверу другой; одинаково их читает только `fragment: none`.
- Схема не из карты, нечитаемый хост, нечисловой порт или отсутствие хоста — отказ `bad_url` без группы.
- Если источнику отказано, но хост читается, источник остаётся в группе своего хоста.

**Итог просьбы в метке (ADR-0054).**
- `outcome`: `performed|refused|unknown|expired`.
- `error` — до 200 символов, `late: true` у позднего ответа.
- Запись жнеца несёт `ended_by: reaper` и `ended_at`.
- Закрывающий пишет по индексу (CAS), ответ держателя пишется безусловно.

**События команды.** Поля платформы `outcome`, `action`, `by`, `late`, `error` лежат на верхнем уровне. Ответ цели целиком идёт под ключом `reply`.
