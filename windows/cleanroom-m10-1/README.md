только по лекции, `spec/`, приёмке урока и `testsub` среза курса `6fe8ded5`, без кода, ADR и истории.
Репозиторий пилота — `/Users/murat/cleanroom/m10-1` (`5806494`), вне курса.

**Чистота.** Журнал сессии пилота (`~/.claude/projects/-Users-murat-cleanroom-m10-1/`) проверен: ни одного
пути вне каталога пилота в вызовах инструментов, подозрительных команд нет, субагентов нет.

**Приёмка.** Пилот: 23/23 сценария, 105/105 шагов через дверь и через API; реализация курса тем же раннером
(закрытые формы ответа, обязательный `error`): тоже 23/23, 105/105. Приёмка их не различает.

**Расхождения** (`diffprobe.txt`, 10 из 32; одно — только пробел в JSON ответа на запрос без версии HTTP):
