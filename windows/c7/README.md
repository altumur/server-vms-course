## Изменения

Живые части вынесены без алиасов в vms/: ingest, forwarder, gateway,
camera_cluster, cloud, camera_actions. Пакет vms/domainpart удалён;
подкоманда, юнит, неиспользуемый сокет токенов и группы сняты с поставки.
Стенд вызывает платформенного держателя, отчёты и издателей обычных воркеров.
Камера в сцене11 получает performed; шестичасовое отключение центра f04
проверяет токен, полученный камерой через её роль и сохранённый в RAM.

Книги у держателя показываются общим механизмом: объединение entries по
(member,item), строгие оболочки/маркеры, конфликт — отказ, только поля show,
права view на единицу и фильтр секретов. Добавлены применённые рекордером
retention_days/when/home в primaries; никакого domain.ref у rec.
В очередь доменной правки попадают только допустимые поля/типы/schema;
член проверяет повторно. По3cb47bdd у retention_days только schema.minimum:1,
обе устаревшие строки долга сняты, загрузчик не расширен.

У собираемой книги нет отдельного предметного писателя на держателе:
роль <sub>domain и её слот не создаются. Способность kept/testsub сохранена.

## Судьбы проверок

TESTS.tsv — исходные485 функций от C6b b9947a21, для каждой названы
конкретные файл/функция после переноса. Исходные AST-счётчики сверены
с git b9947a21; назначение каждой функции существует, у каждой утверждений
не меньше. Итого1999 →2011. Эта проверка числа не заменяет чтение смысла.
Четыре строки (d) явно называют снятые интерфейсы, не скрывают удаление:

- По1d92ecd8 глобальные unchecked, предварительное имя чужого триггера,
  GET /catalog сняты. Форма проверяется SharedDoor, возможности цели —
  настоящей camera_cluster.perform, серверная камера-триггер — autoworker
  через merged log. При событии отсутствие дороги называется словами
  продукта; произвольное содержимое исключения в пульс не попадает.
- По2c3c1fc3 сняты доменная дверь GET /metrics и stream_metrics(fed).
  Предметные утверждения переехали на rec/polled и upstream;
  401/403/200 человека/view — настоящая GET /domain/cam/cameras.
  Догон продуктовых rec_ingest_* у рекордера, если отсутствуют,
  отдельной задачей после C7, без новой формы.

## Сохранённое общее имя платформы

По0fecb291 слово domainpart сохраняется в трёх местах:
Source/w2cplatform/spec.py: SECRET_ROLES;
Source/w2cplatform/secrets.py: role_names;
Source/tests/testdata/platform_lists.tsv: secret_roles/domainpart.
Это форма имени читателя секретов → <sub>domain, не процесс VMS.
Имя и байты TSV не менялись. Приёмка grep по Source/vms/, Source/deploy/
и исполняемым процессам — пусто; не по историческим ADR и записям окна.

Сохранение способности проверяет
Source/tests/cluster/test_policies.py::test_the_domain_has_a_role_and_its_keys_are_read_by_that_role_alone:
kept/testsub может писать свой ledger, не ключи подписанта; у всех
собираемых VMS-книг отдельной роли нет. Неизвестное имя читателя
отвергается в Source/tests/test_spec_keys.py::test_who_reads_a_secret_row_is_what_the_specs_say_and_the_rights_are_held_to_it.
