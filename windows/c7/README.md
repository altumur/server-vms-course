По59738974 дверь книг требует человека (401 без него). View на *
отвечающего кластера открывает все ключи; иначе ключ сопоставляется с

членов и их отчёты для этого не читаются. Общий domain_may перед книгой снят.

По77d82f9d проход книг после записи нынешним получателям удаляет строки
ушедших из состава. GET ничего не пишет и не читает состав: объединяет
все строки, оставляет первую запись каждого (member,item), объединяет
missing, пропускает нечитаемые ключи. Конфликт не даёт503 у двери;
конфликты судит сборщик. Отображаются только поля show, секреты скрыты. Добавлены применённые рекордером
retention_days/when/home в primaries; никакого domain.ref у rec.
В очередь доменной правки попадают только допустимые поля/типы/schema;
член проверяет повторно. По3cb47bdd у retention_days только schema.minimum:1,
обе устаревшие строки долга сняты, загрузчик не расширен.

У собираемой книги нет отдельного предметного писателя на держателе:
роль <sub>domain и её слот не создаются. Способность kept/testsub сохранена.
