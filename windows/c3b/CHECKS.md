## Красные прогоны и исправления
- C3 baseline: `c3b-star-tests-baseline-red.log`, 0/3, exit1; новый unit
  `c3b-star-unit-baseline.log`, 2/5. В C3 ещё не было маршрута/поля C3b.
- `core-first.log`: 57/3, exit1 — избыточное требование топологии подавляло
  обычный primary ingress; это требование снято для обычной дороги.
- `domainvms-first.log`: 73/93, exit1 — обычная дорога без настроенного
  центра не получала stream token/ingress. Исправлено: отсутствие настройки
  не добавляет аудиторию; configured malformed topology по-прежнему 409.
- `core-second.log`: 74/1, exit1 — стала лишней строка load debt для
  star_centre. Сняты ровно одна строка паритета C3b и одна загрузки C3b.
- `ranges-token.log`: 21/0/0, exit0; `domainvms-second.log`: 166/0/0, exit0.
  Затем все четыре полных набора выше. Красное зелёным не считается.
