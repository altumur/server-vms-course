# Проверки окна C3b

Пока окно в работе, итогового зелёного прогона нет. Логи и SHA256
будут записаны сюда до запроса чтения; внешняя папка свидетельств не
заменяет запись окна.

| Проверка | Судьба |
|---|---|
| C2 star: без ложной доставки, кадры локально | Возвращается полная доставка camera→centre→relay; точные bytes/order и один camera transport. |
| C2 tree retry + star локально | Дерево остаётся; звезда повторяет потерянный pull-ответ без пропуска/дубликата. |
| Диапазон реальной карты | Camera→centre→relay recorder через текущий upstream token, именованная запись. |
| Сохранённое подтверждение v2 | Все восемь тестов и сквозное восстановление остаются. |

Чтение и слияние: ещё не состоялись. Хеши будут добавлены по факту.
Отложено: C4–C7, мутирование variables/storemachine после C3b. Новые
уроки и общую acceptance не меняем (ADR-0082).
