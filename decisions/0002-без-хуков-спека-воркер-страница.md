# Без хуков: смысл хука уходит в спеку, воркер или страницу

## Context and Problem Statement
Платформа курса и продукта открывала подсистеме двери «код под именем»: `register_constraint`, `admit`, `near_rank`, `refuse`, `Writes`, `extra`-маршруты, `MetricsExtra`, `ServersExtra`, `Visible`, хуки ресурса (`Pass`, `Freer`, `Kept`), регистрации секретных строк, скоупов, частей домена. Каждый хук это код подсистемы, который платформа вызывает, и он делает контракт платформы неполным для следующей подсистемы.

## Decision Drivers
* ADR-0001: платформа знает только спеки;
* хук скрывает знание в коде вместо YAML и не сверяется с продуктом.

## Considered Options
* оставить хуки как «правильный способ пересечь границу» (так учил курс);
* заменить каждый хук одним из трёх мест: спека (размещение, права, допустимость строки), воркер (байты и политика на данных), страница (показ).

## Decision Outcome
Выбраны три места. Таблица хук → замена: `../ГРАНИЦА-ПЛАТФОРМЫ-И-ПОДСИСТЕМЫ.md` §4. Вместе с этим решены четыре вопроса: байты идут мимо консоли (`/timeline`, `/segment`, `/export`, `/whep` уходят из платформенной консоли, страница идёт на дверь держателя по адресу из `/where`); уникальность источника только по RFC 3986, `ch/02` и `ch/2` ловит воркер; исполнимость сценария проверяется JSON Schema из YAML, глубже проверяет `autoworker`; хранение событий (`<sub>/retention`, `alarms_retention`) остаётся политикой платформы на её бакеты, уходит только слово «архив».

### Consequences
* Good, because словарь спеки это публичный контракт, описанный в уроке 09 М10A и проверяемый на `testsub2`.
* Good, because хуков больше нельзя добавить незаметно: новый `Register*` или опция-функция это находка ревью.
* Bad, because у спеки появляется маленький язык (`metrics:`, `requests:`), за краями которого надо следить (ADR-0012).

### Confirmation
В `w2cplatform/` нет реестров и опций-функций для подсистем; каждый ключ и оператор спеки используется двумя спеками или `testsub` (`Source/tests/test_spec_rule.py`); вызовы оболочки в библиотеку консоли (`addTab` и подобные) хуками не считаются (ADR-0005).
