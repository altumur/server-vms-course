# Нормы формы, семей данных и связей — стандартом JSON Schema 2020-12 и CEL; свой остаток — отдельными слоями (вариант В7); заменяет ADR-0087 п. 2, 4, 5, доп. (2) и ADR-0088 доп. (2)

## Context and Problem Statement
Класс системы: платформенная система — строгий загрузчик манифеста (урок P/02, глава 2.1), схемы семей данных (каталог
`Platform/common/data/`, ADR-0088), связи манифеста (`references.tsv`), канонический вид (ADR-0089).

Сейчас форма манифеста и схемы семей записаны на своём диалекте (`DIALECT.md`, ADR-0087), связи — своим языком § 6, текст
— своим подмножеством YAML (Н1.1), а каждая реализация обязана написать интерпретатор диалекта и свой разборщик YAML
(ADR-0087 п. 4). Правильность держится на корпусе и реализациях, сделанных нашим ИИ; внешнего оракула нет. Примерно
треть догадок стадии C (форма, YAML, связи, канонический вид) — об этом слое.

Записка 2026-10-26 (вариант В7) и независимая перепроверка своим стендом (Kimi): форма манифеста в чистой JSON Schema
2020-12 — 545 из 557 вердиктов, со слоем «целый знак» 557 из 557; связи — 112 из 121 строки в CEL, 0 различий на 270
случаях; 99 схем семей — 5 520 экземпляров без расхождений вердикта и исхода; текст — готовый парсер YAML 1.2 и тонкая
проверка, 630 из 630; Python, Go (и Rust у автора) совпали.

## Decision Drivers
* внешний оракул: библиотеки JSON Schema и CEL проверены наборами тестов сообщества (Bowtie, cel-spec), YAML — yaml-test-suite;
* меньше своего кода на каждом языке: нет интерпретатора диалекта (≈ 1 600 строк на Python) и своего разборщика YAML;
* слова значат то, что в стандарте: нет слов «с тем же именем, но другим смыслом» (`integer`, `pattern`, `default`);
* новые языки (C++, Rust) и продукт на Go — библиотеками, без переноса интерпретатора;
* поведение системы не меняется, кроме того, что решает владелец (пп. 3, 4, 8 ниже).

## Considered Options
* В1 — как сейчас: диалект, свой разборщик YAML, свой язык связей
* В6 — диалект нормой, стандарт — свидетелем в приёмке
* В7 — стандарт для того, что он поддерживает; свой остаток — отдельными слоями

## Decision Outcome
Выбран вариант **В7**, потому что он даёт те же вердикты, что диалект, на всём корпусе и экземплярах семей (подтверждено
двумя независимыми стендами), снимает свой интерпретатор и разборщик YAML с каждого языка и даёт внешний оракул.
Ответы на вопросы записки (раздел «Вопросы владельцу»):
1. **Вариант** — В7.
2. **Свой разборщик YAML** (ADR-0087 п. 4) — заменить готовым парсером YAML 1.2 закреплённой версии с тонкой проверкой
   (байты, один документ, корень — блочное отображение, отказ на якоре, псевдониме, `<<`, теге, повторе ключа, ключе-коллекции,
   глубине > 64; скаляры — по `scalars.tsv`); каждая реализация прогоняет yaml-test-suite своей версии парсера, отклонения — файлом.
3. **11 отклонений Н1.1 от YAML 1.2.2** — принять YAML 1.2.2 (меньше своих правил); ожидания случаев корпуса меняются.
4. **`{k:}` и TAB вне комментариев** — запретить нормой (снимает расхождения парсеров Python и Go).
5. **Пути и строки отказа загрузчика** — подсказка, не норма; строгим остаётся вердикт и код выхода.
6. **Класс отказа** — тип по слою: `text`, `form`, `relations`, `catalogue` (класс связи `value`/`reference` — из таблицы связей).
7. **Корпус одной причины** — да: каждый отказ — мутация принятого соседа; файлы без `worker:` дополняются.
8. **«`4.0` не целое» в манифесте** — отменить: стандартное `type: integer` (целое по значению) и `maximum: 9007199254740991`;
   целый знак у писателя строк семей (кодек `items`) — без изменений.
9. **Запрет чужого кода** — заменить критерием: стандарт, внешний набор тестов, закреплённая версия, наш корпус на каждом языке.
10. **Свидетель JSON Schema** — валидатор Go или Rust в приёмке сверяет форму.
11. **Случаи, утверждённые человеком** — да: ≈ 60 случаев формы и связей, коммит человека.
12. **Источник** — один раз сгенерировать схему и CEL из диалекта (генератор в навыке `lesson-spec`, опциональный синтаксис CEL),
    проверить на корпусе; дальше нормой становятся стандартные файлы, правятся руками.
13. **Корпус семей** — экземпляры с ожиданиями, утверждёнными человеком: по одному на строку `outcomes.tsv` и на слово вне стандарта.

Свой остаток (отдельные слои): тонкая проверка YAML; кодек строк `items`, `time`, `max_bytes`, имена сверх `max_items`,
целый знак писателя семей; таблица классов; обход путей связей и три функции CEL (`depth`, `template`, `text`); строки
связей с многозначным путём — `flatten` или обход хозяином.

Сроки и порядок перехода — ADR-0087, дополнение 2026-10-27 (после зелёных уроков 01–06, до домена и VMS).

### Consequences
* Good, because форму и связи исполняют библиотеки с внешними наборами тестов; оракул корпуса — люди (п. 11, 13).
* Good, because на каждом языке нет интерпретатора диалекта и своего YAML; новые языки и продукт — библиотеками.
* Good, because треть догадок стадии C (форма, YAML, связи, канонический вид) теряет предмет.
* Bad, because CEL длиннее строк § 6 (≈ вдвое–втрое) и требует трёх своих функций; 9 строк связей — своим слоем.
* Bad, because меняются ожидания корпуса (пп. 3, 4, 8) и урок 02 подтверждается заново; общая библиотека чтения форм
  перегенерируется в обеих реализациях.
* Bad, because дефекты библиотек входят в загрузчик — их держат тонкая проверка, закреплённые версии и корпус на каждом языке.

### Confirmation
Генератор «диалект → стандарт» на корпусе P/02.1: вердикт 630/630, класс по слою 206/206; связи 270 случаев — 0 различий;
семьи — 0 расхождений вердикта и исхода на экземплярах и на корпусе, утверждённом человеком; у каждой реализации —
корпус зелёный и yaml-test-suite по списку отклонений; Python и Go на корпусе — ноль расхождений. До подтверждения
статус — `proposed`; при опровержении второй перепроверкой или утверждёнными случаями — `rejected`, остаётся ADR-0087.

## Pros and Cons of the Options

### В1 — как сейчас
* Good, because ничего не меняется посреди стадии C.
* Bad, because свой интерпретатор и YAML на каждом языке; оракул — только наш ИИ.

### В6 — диалект нормой, стандарт свидетелем
* Good, because внешняя проверка без смены нормы.
* Bad, because два описания формы; интерпретатор диалекта остаётся на каждом языке.

### В7 — стандарт и отдельные слои
* Good, because см. Decision Outcome.
* Bad, because см. Consequences.
