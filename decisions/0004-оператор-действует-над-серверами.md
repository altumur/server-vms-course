# Оператор действует над серверами, воркеры и слоты это дело контроллера

## Context and Problem Statement
Одиннадцатое ревью предлагало кнопку «отправить воркер в отставку» в консоли. Оператор не может знать, жив ли процесс: зависший или отрезанный воркер был отправлен в отставку, продолжая писать, и камеры получили двух писателей.

## Decision Drivers
* оператор утверждает только то, что может знать;
* освобождение слота решается по свидетельствам (два молчания, список воркеров в строке ресурса), а не по кнопке.

## Considered Options
* действия оператора над воркерами и слотами;
* действия оператора только над серверами: вывод из эксплуатации (вернётся) и списание (навсегда), включая `gone: true` для сервера, которого физически нет (2026-10-04).

## Decision Outcome
Выбрано второе. Всё, что про воркер, в консоли только диагностика; освобождение слота это правило контроллера.

### Consequences
* Good, because один писатель на единицу не зависит от суждения человека.
* Bad, because зависший воркер освобождается с задержкой, пока контроллер не наберёт свидетельств.

### Confirmation
В консоли нет действий с объектом «воркер»; `gone: true` снимает только отказ «дверь пропала», отказы по свидетельству жизни остаются; удаление двери в журнале с `was`.
