# Решения (ADR)

Формат: `.cursor/rules/adr-format.mdc` (MADR). Решение владельца или архитектора, принятое в разговоре, записывает та сессия, которая его услышала, в тот же ход; индекс держит «Архитектор». Номера не переиспользуются. Номер берётся в момент коммита по `ls decisions/` (следующий свободный); если две сессии взяли один номер, перенумеровывает та, чей коммит позже, и говорит «Архитектору»: так 2026-10-05 три записи «Сборки» стали 0018–0020.
