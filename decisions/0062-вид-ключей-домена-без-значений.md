# Вид ключей домена `/domain/keys` — имена без значений; содержимое книг только через свой маршрут

## Context and Problem Statement
Класс системы: платформенная система.

`GET /domain/keys` показывает странице домена всё, что домен держит под `domain/` в хранилищах кластера. Секреты
закрывала маска: поле, чьё имя кончается на `_secret`, и запечатанная строка под любым именем. «Консоль» нашла на
стенде продукта книгу целиком с токеном потока `ingest.key`. Проба в курсе показала ту же дыру: маска смотрит только
верхний уровень строки. Вложенный `token_secret` книги (значение — словарь или JSON-текст) и первые 512 байт
неразобранного тела объекта выходят как есть. Книги несут токены потоков и токены просьб (ADR-0032), и любой, у кого
есть право смотреть домен, видел их.

## Decision Drivers
* токен из книги не выходит из процесса ни на одной двери
* маска по имени поля не доказывает отсутствия секрета: имя выбирает подсистема, вложенность любая
* странице нужен список ключей, а не их содержимое; содержимое, которое можно показать, объявляет спека

## Considered Options
* Усилить маску: обходить вложенные словари и JSON-текст, прятать больше имён.
* Не показывать значения вовсе: ключ, имена полей, индекс. Значения только у строк с публичными половинами ключей
  домена. Содержимое книг только через маршрут книг с объявленными полями.

## Decision Outcome
Выбран второй вариант. Форма общая для курса и продукта.
* **Переменные:** ключ, имена полей и индекс, без значений. Строку, которую роль процесса читать не может, вид называет
  (`withheld`) и ничего из неё не показывает, как прежде.
* **Значения** показываются только у строк с публичными половинами ключей домена. Закрытая половина, запечатанное
  значение и токен не показываются никогда.
* **Объекты:** ключ, размер и возраст (по `ts`), без тела.
* **Содержимое книг** — только через маршрут книг `GET /domain/<sub>/books/<book>` с полями, которые спека объявила к
  показу (`domain.books.<книга>.show`). Это отдельное решение, номер ему даёт «Платформа».
* **Проверка:** тест ищет строку токена во всём сериализованном ответе `/domain/keys`, а не в одном поле.
* Старая форма с замаскированными значениями не сохраняется (ADR-0003).

### Consequences
* Good, because секрет не выходит ни при каком имени поля и ни при какой вложенности: значений нет.
* Good, because у вида ключей одна задача — какие ключи есть; что в них, говорит спека через маршрут книг.
* Bad, because страница домена больше не видит содержимое строк, пока маршрут книг не появится: отладка смотрит в хранилище.

### Confirmation
* Курс: тест `/domain/keys` с вложенным `token_secret` (словарь и JSON-текст), полем вида `ingest.key`, запечатанным
  значением и телом объекта с токеном. Строки токена нет во всём ответе. Имена полей и публичные половины видны.
* Продукт: `keysview.go` в той же форме («Платформа продукта»), тот же тест на testsub.
