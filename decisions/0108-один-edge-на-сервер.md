# Один том `edge` на сервер

## Context and Problem Statement

Класс системы: подсистема `rec`, том `edge` кластера из одного сервера.

Сейчас том `edge` — на камеру (поле `cam`), норма знает кластер из одного только для одной камеры. Владелец: «Предлагаю заводить один edge на сервер»; «Тип edge тогда будет строкой оператора при настройке тома в консоли»; о бридже: «Вопросы про бридж неактуальны на данном этапе. Мы на этом примере разрабатываем архитектуру».

## Decision Drivers

* карта одна на коробку, а камер на ней может быть несколько;
* строку пишет оператор, а не код.

## Considered Options

* `edge` на камеру;
* `edge` на сервер.

## Decision Outcome

Выбрано: один `edge` на сервер.

1. Поле `cam` тома снимается, `server` обязателен; V/02.1, V/02.6 Н1.7: страж «камеры этой коробки», `quota_bytes` — бюджет всей карты.
2. **Вытеснение на общей карте:** старейшее из доставленного по всей карте, доли на камеру нет.
3. Строку `rec/volumes` пишет оператор в консоли. Как правка доходит до кластера из одного через агента домена, сверяет «Спецификация VMS»; не дошла — новая норма.
4. **Кольцо — потребитель потока** для ADR-0107 доп. (2) п. 1: иначе предзаписи нет.
5. Кластер из одного с несколькими камерами — новая норма V/01.6, V/02.6: держатель на камеру, том один.
6. Бридж вне этого решения.

### Consequences

* Good, because модель совпадает с железом и старым кодом.
* Bad, because вытеснение делит карту между камерами без гарантии доли.

### Confirmation

Приёмка V/02.6: две камеры на одной карте, вытеснение, бюджет, страж чужой камеры. Ревью Claude после норм.

## More Information

ADR-0107, ADR-0103.

## Дополнение (1), 2026-11-01 — `edge` со всеми камерами локального `camworker`

Владелец: «Предложи поменять схему, чтобы edge не требовал cam, а работал со всеми cam локального camworker». Вход: `cammeta-console/ПРЕДЛОЖЕНИЕ-EDGE-ВСЕ-КАМЕРЫ.md`, bc635ff. Работой не проверено.

1. Оператор пишет одну строку тома. Поле `when` переезжает на том, только у `edge`, умолчание `offline`. Запись на камеру заказывает держатель `cam` своего сервера через `worker.creates`: строка `rec/recordings/cam-<cam>`, `home` — том, `when` — из тома, `until` с продлением, как у `auto`. Заменяет п. 5 и уточняет п. 3 основного текста.
2. Камера снята или ушла — продления нет, строка кончается сама. Новый держатель заказывает свою, эпоха — обычным правилом.
3. **`until`** — сутки, продление раз в час: строка переживает кратковременное падение держателя.
4. **Невывезенное.** Конец строки не стирает карту: сегменты живут как долг и вытесняются последними, копия в основную идёт, пока они есть. Строка не снимается, пока долг есть.
5. Страж: запись, чей держатель не на сервере тома, — `waiting`, `reason`.
6. Выключить карту одной камере нельзя: «со всеми». `extraArchives` показывает такую запись только для чтения.
