# Сетевой том берётся только на `obsd` с патчем 07; парковки писателя нет

## Context and Problem Statement

Класс системы: подсистема VMS — регистратор пишет архив в движок `obsd`, сетевой том могут писать разные серверы.

Шестое ревью нашло, что «запаркованный» писатель — режим для движка без патча 07, когда регистратор оставлял писателя тома в демоне до выяснения, — делает сетевой том `busy` навсегда, умирает с сессией и стирает чужую блокировку (блокер 1 и major). Проверка возраста холда перед `put` на стороне регистратора не ограждает, а только сужает окно. Ограда есть у движка с патчем 07 (`WRITER_ABANDON`): он сам проверяет свою блокировку и останавливает писателя, чья блокировка потеряна.

## Decision Drivers

* один писатель на сетевой том держится только оградой у того, кто пишет байты;
* режим без ограды нельзя сделать безопасным со стороны клиента;
* локальные тома без патча работают и должны работать дальше.

## Considered Options

* держать оба режима: с патчем 07 — ограда движка, без него — парковка писателя;
* требовать `obsd` с патчами 01–07 для сетевых томов; на старом демоне сетевой том не брать и говорить оператору почему.

## Decision Outcome

Выбран второй вариант. Курс требует `obsd` с патчами 01–07. Регистратор один раз на демон пробует `Session.abandons()`; демон без операции `WRITER_ABANDON` получает сетевые тома в `unservable`, они не захватываются и не монтируются, а причина видна в `refused` пульса и на странице томов («obsd on srv-a is too old to write net safely … Update obsd»). Уже взятый том отпускается, если демон заменили старой сборкой. Писатель, чей холд потерян, бросается сразу; принятое, но не записанное — тревога `archive.footage.dropped` и метрика. Парковка удалена.

### Consequences

* Good, because единственный писатель сетевого тома держится движком, а не догадкой регистратора.
* Good, because поведения для движка без патча 07 нет, и проверять его не нужно.
* Bad, because сервер со старым `obsd` теряет сетевые тома, пока демон не обновят; локальные тома его не страдают.
* Bad, because курс и продукт привязаны к патченому движку: набор тестов не запускается на демоне без операции 36.

### Confirmation

Тест: `Source/tests/test_lock_lost.py::test_a_recorder_takes_no_network_volume_on_an_obsd_that_cannot_give_one_up`. Набор тестов отказывается запускаться на демоне без `WRITER_ABANDON`.

## Pros and Cons of the Options

### Два режима

* Good, because старые демоны продолжают писать сетевые тома.
* Bad, because парковка не безопасна: том `busy` навсегда, чужая блокировка стирается.

### Только патч 07

* Good, because ограда одна и у движка.
* Bad, because обязательное обновление движка для сетевых томов.
