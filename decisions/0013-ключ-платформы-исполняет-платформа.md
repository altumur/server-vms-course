# Ключ платформы исполняет платформа; спека обязательна у любого воркера; `of` ставит база

## Context and Problem Statement
Обход ключей спеки по исполнителям показал: `places.lease: strict` читал загрузчик, а исполнял только рекордер; `slot` копировал каждый класс VMS; спека у базового `Worker` была необязательной, и пять подсистем курса без неё молча не исполняли ни одного ключа; родителя события по `about` каждый воркер ставил сам, и рекордер его забыл.

## Considered Options
* оставить ключи платформы с исполнителями в подсистемах;
* ключ платформы исполняет платформа; у платформы нет пути, на котором спеки нет.

## Decision Outcome
Выбрано второе. Строгая аренда места и слот исполняются базовым `Worker`; конструктор без спеки отказывает, спека берётся по имени подсистемы из каталога спек; `of` (родитель по `about.field`, поле `fixed`) база запоминает при взятии эпохи и ставит в каждую строку события и отметку, переданный подсистемой `of` отказывается.

### Consequences
* Good, because подсистема не может «забыть» исполнить ключ.
* Bad, because все наследники `Worker` и их тесты правятся разом.

### Confirmation
На `testsub`/`testsub2` каждый ключ воркера (`lease`, `places`, `events.suppress`, `slot`) исполняется без строки кода в подсистеме; регресс-тест на событие без `of`.
