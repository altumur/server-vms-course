## Результат

356 отдельных R-id объединены в 242 смысловых абзаца. У абзаца остаётся первый по тексту внешне упомянутый id, иначе первый действующий id группы. Соседние условия объединены по одному предмету: выбору `opts.subsystems`, контексту профиля, логическому действию, обработке поля формы, раскладке папок и сборке доменных наблюдений. Границы разделов, роли, режимы и разные операции сохранены. В частности, форма версии, проверка версии оболочкой и фиксированная версия API остались раздельными; получение schema и построение формы страницей также не слиты.

114 снятых id зарезервированы в `req-id-map.tsv`; цель каждой строки — живой id той же главы. Для каждого снятого id в `history.tsv` добавлен дословный исходный пункт. Прежний файл истории сохранён байтовым префиксом. Карта не содержит цепочек и циклов, надгробия в M не добавлены. Урок не имеет нумерованных глав, поэтому карта и история находятся в общем журнале урока.

Внешне упомянуты 50 исходных id. Ссылки в инструкции, описании поверхности и переводах переадресованы только по карте. В действующих M/J на базисе нет входящих R-id P/07 из других уроков; менять их файлы не потребовалось. Диапазон со снятым id сначала развёрнут по исходным номерам, затем переадресован и очищен от повторов; незатронутый перечень сохранён. Самоссылки на слитые части сняты внутри своих абзацев.

Все 18 тем Index остаются многоместными: после карты у каждой не меньше двух живых адресов абзацев. Таблица сохраняет темы и адреса файлов, ссылки на id отсортированы и не повторяются. Строк «See also» нет.

Вне N5 сняты лишние ссылки на закрытые фикстуры и повторы проверяемых id. Вместо них стоят ссылки на видимые определения соответствующих строк N5. В начале инструкции один абзац объясняет недоступность сценариев, фикстур и эталонов модели. Необходимые имена фикстур и границы их свидетельств сохранены в N5: отсутствующее доказательство immutable-caller, complete-body timeout, pagination/unread, серверной проверки schema, активации выключенного раздела и прочих открытых предметов не объявлено полученным. Долги P/07-07, P/07-08 и `v1showsHidden` остаются открытыми.

Таблица «What this lesson takes from common» сохраняет 21 публичную зависимость других уроков. Из неё сняты чужая приёмка людей P/08.4 и строки человеческих заметок, fixture-исходников и контекста testsub. В §10 описания поверхности testsub назван как подсистема проверки, а его манифест не определяет правило библиотеки. Приёмка P/06.5 сохранена: она задаёт отдельные места доказательства публикации и HTTP Where. Узкий M рассчитан функцией `pair_m`; прямые ссылки проверены с P/07 в `M_NARROW` только в памяти процесса проверки, без правки навыка.

## Замечания к процедуре

- P/07 не имеет `forms/` и `stages.tsv`: их отсутствие не повод создавать новые носители.
- Каждому исходному пункту en соответствует один пункт ru; это позволяет воспроизводимо собрать оба текста одной картой групп.
- Форма поля и действие другого участника требуют разных абзацев, даже когда соседние предложения говорят об одном имени.
- N5 служит видимым определением имён из защищённого чеклиста. Снятие повторной ссылки вне N5 сохраняет это определение и его ограничения.
- Нельзя распространять редактуру Index на другие таблицы: строки N5 сохраняются отдельно и сверяются побайтно по карте.
- Ни число оставшихся id, ни число тем Index не являются целевым показателем сокращения.
