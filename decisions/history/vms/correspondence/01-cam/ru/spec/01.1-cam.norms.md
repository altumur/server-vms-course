## Соответствие прежним урокам

Из М10B/01 «Первая подсистема» — шаги 1–3, 5, 6 (заголовок, единица, поля оператора, значения размещения, снимок и
консоль); шаг 4 — общие сроки, платформа (P/05 Н1.3), срок видео — V/02; шаги 7, 8 — код свидетеля,
не переносятся. Из М10B/19 «Учётные данные камеры» — шаги 1, 2 (два поля, `schemes`, `credentials`, `secret_in`); шаги
3–5 — держатель, глава 2. Из М10B/15 шаг 1 — таблица `devices` (форма; писатель — глава 4). Из М10B/04 шаг 1 —
`group_by`. Из М10B/25 шаг 4а — строка `cam/devices/<хост>` как каталог возможностей; дети устройства — ADR-0102 и доп. (1), у свидетеля их нет (числа `rays`, `relays` в строке устройства сняты). Отличия от свидетеля: потолок снимка — L P/04 Н1.3а, а не 64 КиБ: папок в строке камеры нет (ADR-0096 §8); `offers` запасному → `grows`. Id ([id-map](../../../common/id-map.tsv)): М10B/01 ш.2–3 → V/01.1-01; М10B/01 ш.3
(`unique`) → V/01.1-02; М10B/19 ш.1–2 → V/01.1-03; М10B/15 ш.1 (таблица) → V/01.1-04; М10B/01 ш.5 → V/01.1-05;
М10B/01 ш.6 → V/01.1-06; М10B/01 ш.3 (`reach`) → V/01.1-07; М10B/01 ш.6 (`display`), М10B/04 ш.3 (подавление) →
V/01.1-08. Потоки камеры (Н1.1а, V/01.1-09) — решение владельца 2026-10-26, у свидетеля их нет: поток там — отдельная
камера без связи с другими.
