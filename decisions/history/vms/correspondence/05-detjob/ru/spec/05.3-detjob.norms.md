## Соответствие прежним урокам

Из М10B/20 — шаги 6 (прогресс), 7 (остаток по времени и записи); из М10B/21 — шаги 2 (бюджет прохода, `queued`, медийное
время событий, строка после событий, учебная модель), 6 (почему итог не в пульсе — механизм P/03.6 Н1.7), 7 (`earlier-run` —
P/06.4 Н1.2). Отличия от свидетеля: прогресс — курсор состояния единицы, а не файл на ресурсе (теряется при переезде; решение
плана 3); итог — `unit.state.result`; учебная модель — `tick` в медийном времени (решение плана 2); подавления нет; эпоха —
при взятии единицы, а не при первом декоде. Id ([id-map](../../../common/id-map.tsv)): М10B/21 ш.2 → V/05.3-01; М10B/20 ш.6–7 →
V/05.3-02; М10B/21 ш.2 → V/05.3-03; М10B/21 ш.2, 7 → V/05.3-04; М10B/21 ш.6 → V/05.3-05.
