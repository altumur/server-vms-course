## Соответствие прежним урокам

Из М10B/25 — шаг 3 (смысл: два поля — отказ вычислителя), шаг 4а (каталог — не устройство: кто что знает, тексты отказов,
«неизвестно» — не «не умеет», `unchecked`, `unfit`, проверка каждый проход, нечитаемое — беда одного). Отличия от свидетеля:
чтения чужих строк — `worker.reads` (у свидетеля — права процесса); нечитаемая строка сценария — фаза платформы `unreadable`
(у свидетеля — `failed`); слова — `reason`. Id ([id-map](../../../common/id-map.tsv)): М10B/25 ш.3 → V/07.3-01; М10B/25 ш.4а →
V/07.3-02, V/07.3-03; ADR-0105 → V/07.3-04.
