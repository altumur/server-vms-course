## Соответствие прежним урокам

Из М10B/13 — шаги 4 (отсрочка, удаление, камера без держателя — ожидание и удаление через `grace`), 5 (уборка сессий,
`CONNECT_SECONDS`), 8 (процесс без состояния, остановка, журнал в архив событий сервера), «Результат» (50 зрителей — одна
подписка, отсрочка); из М12A/03 — арифметика отказов. Отличия от свидетеля: строку удаляет шлюз по `worker.deletes` (у
свидетеля — `worker.writes: [streams]`, ADR-0067 доп. 2026-10-17); `waiting` — элемент `status[]` раздачи с
`reason`, а не отдельные словари пульса, эпоха не взята — элемента нет; журнал — двери процесса (договор журнала событий), не архив событий сервера; «шлюз
лежит — воспроизведение остановлено» (М12A/03) — неверно: воспроизведение — дверь регистратора. Id
([id-map](../../../common/id-map.tsv)): М10B/13 ш.4 → V/03.5-01; М10B/13 ш.5 → V/03.5-02; М10B/13 ш.2, 4 → V/03.5-03; М10B/13
ш.1 → V/03.5-04; М10B/13 ш.8, М12A/03 → V/03.5-05.
