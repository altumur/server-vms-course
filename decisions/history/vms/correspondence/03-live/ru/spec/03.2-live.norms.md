(ADR-0075 окно 2; решение плана 1); поиск держателя — чтение пульсов `cam/heartbeats/*` по `worker.reads`; свой проход

(глава 3); дополнительный поток камеры напрямую (М12A/03) — не переносится (одно соединение держателя, V/01.2 Н1.2). Id
