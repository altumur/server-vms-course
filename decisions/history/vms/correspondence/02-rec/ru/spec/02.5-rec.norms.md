## Соответствие прежним урокам

Из М10B/08 — видимость, срок, таймлайн, дверь архива; из М10B/20 — сторона `rec` (`/spans`, `held_since`, правило эпохи);
из М10B/24 — fMP4 и маршрут `/segment`; из М10B/15 шаги 7–9 — своё чтение, `source: device`, `.device.mp4`; из М10B/28 шаги
3–4 — где том и где дверь, таймлайн по двум томам; из М10B/18 шаги 3–4 — глубина. Отличия от свидетеля: допуск процессам —
сертификат роли (ADR-0075 окно 2), странице — токен двери платформы (403 `forbidden`, а не 401 со словом; claims договора);
`/samples` получает выбор потока (`stream`) — кусок одной эпохи и в томе с несколькими эпохами; копия удержания `e0`
проигрывается `/segment/<запись>/e0/…mp4` (у свидетеля — 404); `ARCHIVE_URL` с адресом снят — хост `SERVER_NAME`,
`0.0.0.0` — отказ старта; журнал — `audit/recworker`, `media` с эпохой и источником; `nan`/`inf` в `from`/`to` — отказ;
недоступные тома — только этой записи (в теле `/timeline`, поле `unavailable`); своей `/metrics` нет; пределы двери — P/03.4 Н1.7. Id
