## Соответствие прежним урокам

Из М10B/10 шаг 14 — приёмник и передатчик в регистраторе, поля пульса. Из М12B/02 «Поток из другого кластера» — данные
переходят, работа нет; книга источников, раз за проход; домен выключен; дозапись по заявке (карта решает); книга основных и
резерв. Из М12B/03 «Камера, до которой никто не дотягивается» — приёмник, долгий опрос, заявка кусками, время кадра,
тройник, обрыв продолжается (`have`), несколько приёмников, книга опроса, резерв на втором сервере, три канала; толкатель,
токены, шлюз, просьбы сценария — V/01.6, V/03, V/07. Из М12B/04 «Цепочка» — передатчик, звезда, `up_have`, архив
ретранслятора по заявке центра; топология и ретранслятор-представитель — P/08.3, P/09.2. Из М12A/13 — свидетель
`rec/polled`.

Отличия от свидетеля: решение «один кластер записи» и перенос — назначение платформы `domain/placement/rec/<ref>`
(P/08.6), а не `Crossings` воркера VMS (`domainpart` снят, ADR-0074); у записи — поле `ref` и `domain.ref` (у свидетеля
запись вне каталога домена); между кластерами — только толкание (RTSP — петля, ADR-0075 окно 2): решение «забирать или
толкать» и память дорог `domain/cam/roads` не переносятся; книги пишет регистратор вкладом (P/03.7 Н1.2), а не `domainpart`;
адреса приёмников — в книге `ingest` (пульс приёмника), а не в элементе `primaries` (ADR-0113 доп. (29), (30)); ключ потока — токен платформы (P/08.7), без
`token_secret` в книге и сокета подписывающего; книга `upstream` — по ретранслятору (`key: relay`), а не по камере: пишет первый регистратор центра (у свидетеля —
`domainpart`, с `token_secret`), ключ — токен `upstream`; потери приёмника (`dropped`, `clock_steps`) — в пульсе `ingest_streams`, а не в объекте
`rec/polled` и не на `/metrics` воркера у держателя; `rec/ingest`, `rec/forwarded/*` сняты (ADR-0003); `PEER_BUFFER`,
`CLOCK_STEP`, `period` — числа курса (у свидетеля не названы). Id ([id-map](../../../common/id-map.tsv)): М12B/02 ш.2, М12B/01
ш.2 → V/02.9-01; М12B/02 ш.1, 3, 4 → V/02.9-02; М12B/03 ш.1–3, М10B/10 ш.14 → V/02.9-03; М12B/03 ш.6, 6а → V/02.9-04;
М12B/03 ш.1, М10B/10 ш.14 → V/02.9-05; М12B/03 ш.5, М12B/02 ш.5 → V/02.9-06; М12B/03 ш.7 → V/02.9-07; М12B/02 ш.6, М12B/03
ш.9 → V/02.9-08; М12B/03 ш.8 → V/02.9-09; М12B/04 ш.2–5, 7 → V/02.9-10; М12A/13, М12B/03 ш.6а, М12B/04 ш.5 → V/02.9-11.
