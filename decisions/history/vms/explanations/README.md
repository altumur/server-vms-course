# Пояснения моделей к модулю «Серверные VMS»

Цельные рассказы об устройстве видеонаблюдения, написанные моделями по урокам курса. Это не спецификация: норм в них
нет, правила живут в нормах уроков `VMS/`. В выгрузку cammeta-specs каталог не идёт.

Имя файла — `<часть модуля>-<модель>.md`; пока часть одна: `vms` — весь модуль (V/01–V/09). Рассказ читается после
модуля «Платформа» — слова платформы (строка, единица, слот, эпоха, воркер, дверь, домен, книга) считаются известными.

| Файл | Автор | О чём | Написан по урокам |
|---|---|---|---|
| [`vms-kimi.md`](vms-kimi.md) | Kimi | все семь подсистем VMS, страница и развёртывание | V/01–V/09, срез назван в файле |
