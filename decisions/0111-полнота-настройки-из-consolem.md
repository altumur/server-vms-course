# Полнота настройки из consolem: решения по ревью

## Context and Problem Statement

Класс системы: перевод `backend`, стык с consolem, домен.

Ревью по просьбе владельца, `cammeta-console/РЕВЬЮ-CONSOLEM-ОТ-НАСТРОЕК-W2C.md`, `…-ОТ-РЕШЕНИЙ-К-ЗАПРОСАМ.md` (848993f), чтением: живую установку из consolem сегодня не настроить, полностью не проходит ни один из девяти шагов. Нужны решения до норм.

## Considered Options

* ждать ответов consolem;
* решить, что можно, у себя, остальное спросить.

## Decision Outcome

Выбрано второе. Всё ниже — до первой генерации, ADR-0103 доп. (2). Работой не проверено.

**Запуск и основа**

1. **Д1.** `GET /settings` отвечает наименьшим значением по схеме: шесть обязательных полей, `values: {}` схему не проходит; запись `out`. Шесть путей автоматизации — ADR-0105; вопрос consolem: звать их при `can()`.
2. **Д2.** `Server.disks` — из пульса `rec`, новое слово. `mode`, `dir`, `storage` формы принимаются и не хранятся, значение сервера показывается чтением. Сервер у бакета принимается и не хранится.
3. **Д3.** `backend` при создании пишет `ref` = `<кластер>-<id>`, основная и прочие записи камеры — тот же `ref`.
4. **Д4.** `recordMode: motion` — запись по детектору: `backend` держит на камеру строку `auto`, `recordDetectorIds` её цели, в списке правил не показывается; `sched` — то же с расписанием. Дополняет ADR-0105.

**Домен (ADR-0110)**

5. **А-1, Д5.** Вопрос 21 возвращается: приёмник назначается из consolem, `Device.recordingTarget` — черновик, вопрос consolem. Заменяет ADR-0109 доп. (1) п. 1 в этой части. Цена В-12 это учитывает.
6. **А-2.** Общее правило — ADR-0107 п. 7. Исключение: у камеры w2c `storage` — её карта `edge`, `when` и квота правятся через него. `edge` в consolem остаётся для коробок с несколькими камерами.
7. **А-3.** Член только с одной строкой `cfw://local` свёрнут. Член с другими строками показывается сервером, `storage` один на него.
8. **А-4.** Новая запись идёт в кластер `serverId`, без него — в кластер входа. `Rule.serverId` выбирает кластер правила.
9. **А-5.** Поиск и `probe` — на серверах кластера входа; другой кластер — вход через него. Заменяет ADR-0103 доп. (1) п. 6 в этой части.
10. **А-6.** Правило живёт в кластере своих целей. Цели из нескольких кластеров — документ V/07.5. `objectMode`, раскладки — на кластер.
11. **А-7.** Живое и пресеты камеры другого кластера — вход через её кластер: `backend` отвечает ссылкой. Камера w2c за NAT: живое из шлюза кластера приёмника, поток там есть. Пресет — хранимой правкой, с задержкой прохода. Движение арендой за NAT не идёт, предел.
12. **А-8.** `apply` — групповая операция по кластерам, ADR-0110 доп. (5) п. 2, заменяет ADR-0098 в этой части.
13. **А-9.** `POST /devices` с `folderId` без связи с доменом — `422` со словом.
14. **А-12.** `serverId` камеры без назначения — поля нет.
15. **А-14.** Чтение чужого сверх вида домена — пересылка к консоли кластера цели по билету; не слышен — нет данных со словом. Камера за NAT — только вид.
16. **А-15.** Д-2: дверь домена судит по гранту, член перепроверяет при применении. Д-4: источник — строка роли домена, правка на кластере судится как обычно, последнее слово по `at`. Д-10: кластер за ретранслятором домена не видит, предел. Д-12: `MEMBERS_MAX` 500 остаётся, до слова владельца. Секрет запечатывается ключом члена. Хранимая правка не отменяется, откат — новой правкой. Связка правок одного устройства — одна строка правки.
17. **А-17.** Исключение из домена — та же дверь `admin` домена, что приём.

**Откат и контракт**

18. **А-10.** `X-Operation-Id` снят: заголовок за закрытым перечнем до браузера не дойдёт. Id берётся из `GET /operations`, запрос 10 п. 15 правится. Заменяет п. 5 доп. (2) ADR-0106 в этой части.
19. **А-11.** `/devices/update`, `/objects/delete` входят в стопку, помощник пишет через них.
20. **А-13.** Перевод перепинается на контракт `785824c` сейчас: запертые объекты — `409 BUSY` на правку под операцией, страж `backend/opbusy/<корень>` с индексом `""` в пакете; заменяет ADR-0095 и P/06.9 Н1.3 в этой части; двери папок стража не берут, предел; устаревшая пауза снимается из перевода. Поля из запроса 10 ждут ответа.
21. **А-16.** Части прав, `MON_PROT`, `tel` остаются вне: нет предмета.
22. **А-18.** ADR-0094 «`remote` снят» заменён ADR-0109; `BUSY` ADR-0107 — запись здесь. В ADR-0110 «вариант В» значит доп. (2), (4).

Д6–Д10 (метка сервера, срок журнала, две линии, режим карты, общие тревожные виды) — вопросы следующего запроса.

### Consequences

* Good, because у каждого шага установки есть путь.
* Bad, because объём V/11 и P/ растёт, цена ADR-0110 — нижняя граница.

### Confirmation

Шаги 1–9 ревью проходят из consolem на приёмке V/11 после ответа consolem.
