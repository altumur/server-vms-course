# Формы ADR-0113 до норм, вторая версия

ADR-0113 с доп. (1)–(3); ревью `/private/tmp/ревью-adr-0113-формы-claude.md`, ссылки Б, С, М — его. Нормы идут за этим файлом.

## 1. Раздел и список

```yaml
раздел:      первые 12 бит SHA-256(UTF-8 имени члена), 4 цифры, 0000…4095; функция, списка разделов нет
domain/member-rows/<раздел>: {doc: {part, rev, term, members: {<член>: Entry}}, kid, sig}   # подпись держателя; part в подписанном (С7); читатель сверяет: хэш каждого имени = part
  предел:    ENTRY_MAX пересчитан: Entry с class, via 980 байт, url ≤ 256 — 1240; строка 524288: ≈ 420 Entry худшего размера; среднее при 250 000 — 61, хэш ровный, строка 18 КБ при 300 байт
             сверх — 409 «this name's row is full: pick another name» (С12): другое имя, а не «снять ушедших»
  имя:       уникально CAS этой строки; every_entry — по этой строке
  term:      claim новым держателем: переподписать все разделы, подъём rev, размазанно по REPORT_RATE; до переподписи строка прежнего срока верна по цепочке записей срока, как набор следования (С7)
domain/member-count: {servers, cameras}    # счёт; в голове копии; SERVERS_MAX 500 — отдельным счётом, приём сверх — 409 (С3)
Entry:       ещё class: server | camera; url?; via?; every? не в Entry, см. метку
domain/holder-entry: {term, name, ca?, key, kid, sig}   # маленькая подписанная запись держателя, идёт следованием с записью срока (доп. (3) п. 2, С1, Б2)
domain/relay-members/<ретранслятор>: {<член>: 1}       # индекс, тем же пакетом, что Entry.via (С9); via в Entry, но relay_for читает индекс
domain/member-list/<раздел>: {doc, kid, sig, fetched_at}  # у члена: свой раздел и запрошенные; срок запрошенной — 1 час, сброс при отказе TLS; домена нет — живёт дальше, это предел (С8)
publication.members_rev: {term, rev} своего раздела; carry.members: свой раздел, только если отстал; carry.holder_entry — только при смене
дверь:       GET /api/members/<член>/<раздел> с подписью агента; у ретранслятора та же дверь из памяти: строки подписаны (С8)
GET /domain/members?part=<раздел>; без part — {count, knocking}
```

`CLUSTERS` остаётся для держателя и первого контакта.

## 2. Классы, период, отказ «позже»

```yaml
class:       server — кластер с серверами, every 5 с; camera; партия всегда camera (доп. (3) п. 4); стук без партии объявляет class, человек видит и подтверждает; смена — уход и приём
every:       camera: max(5, cameras / REPORT_RATE), не больше 3600; смещение прохода — от хэша имени; выше 720 000 камер бюджет не держится: предел
метка:       пишет сказанный every (С5); silent_after = 3 × сказанный every; SHADOW_STALL, ROAD_QUIET — то же у камеры (М3); server — прежние
счёт:        нет domain/member-count — последний every из копии, не 5 (С4)
busy:        исход договора {retry_in} у POST /api/member и в refused пакета, retry_in в 404 стука (С6): единственный способ держать бюджет на старте агента и рывке rebase; разброс от хэша имени
unseen:      после перезапуска держателя камера выходит из unseen по received_at метки, а не по следующему отчёту (М4)
relayed:     держатель отвечает только членам с телом в этом пакете; остальным relay_for и keys; камера за ретранслятором видит ответ на проход позже (доп. (3), Б1)
```

## 3. Вид

```yaml
domain/view-head: {as_of, holder, url, term, complete, counts, knocking_count}   # объект, раз в 3 с; holds, view.url читают его
domain/view-rows/<раздел>: {as_of, members, units, contested}   # объекты (М2); VIEW_MEMBERS 2000 членов в с: круг = члены / бюджет, раздел — единица работы (С10)
complete:    закрыт круг после последнего старта и все разделы полны; после смены держателя ложь, пока круг не закрыт (С11)
contested:   domain/ref-claims/<sub>/<sha16 ref>: {<член>: {as_of}}; снимает проход раздела, чей член заявку больше не даёт; дверь правки судит ref свежим чтением заявки, а не видом; исполнители — назначение своей заявки (С11); ложный спор при переезде камеры длится до её отчёта: предел
GET /domain: голова; ?part=<раздел>: строка вида; фильтр P/10 — по строке
```

## 4. Снимки, папки, роли, сводка

- Снимки: `TABLES_MEMBER_MAX` server 8 МиБ, camera 64 КиБ, сверх — заглушка `refused`.
- Папки: `domain/folder-log` кольцо 1024; `carry.folders` — дельта от `rev`, дальше кольца — целиком; `domain/folder-counts/<id>/<раздел>`.
- Роли: проход только по изменённым; `role_spread` — по разделам.
- `anywhere`: в ответе `{as_of, sha256}`, тело — `GET /api/anywhere/<член>` при смене; камера строку не держит: вход по `anywhere` у неё нет.
- `domain/topology`: `centre`, `star`; `via` в `Entry`.

## 5. Копия и перенос

```yaml
копия:       голова {term, rev, parts: {<раздел>: {sha256, rev}}, counts, batches, …} и объекты domain/backups/rev-<rev>/<раздел>; неизменённый раздел ссылается на прежний
доставка:    хранитель тянет дверью GET /api/backup-part/<член>/<раздел> с подписью, не в carry (Б5); только class server; BACKUP_EVERY от размера
передача:    цель докачивает до начала; HANDOVER_WAIT — от остатка, передача стартует, когда цель почти догнала; server ждут 6 × REPORT_EVERY, камеры догоняют через busy
из ничего:   строки подписаны: новый держатель берёт с каждого отчёта строку раздела, наибольшую (term, rev) с верной подписью по цепочке; домен сходится за период (доп. (3) п. 3, Б3)
приём:       камера не принимается, пока хранителей меньше BACKUP_HOLDERS: 409 с объяснением
state:       + domain/batches с правилом объединения: отзыв не оживает, used — наибольший (С13); domain/issued; без folder-counts, member-count и вида
```

## 6. Массовый приём (доп. (2), (3))

```yaml
domain/batches/<имя>: {pub, record?, via?, n, used, until, revoked?, refused: {<отпечаток>: at}, by, at}
токен:       закрытый Ed25519 партии, показан один раз; в строке открытый; коробка подписывает (имя, key): секрет по сети не идёт, ретранслятор его не видит, к другому имени не подходит (С2)
via:         приём пишет его в Entry тем же пакетом с relay-members (Б4); поле record — кластер записи, слово не cluster
domain/knocks/<раздел>: {<имя>: {key, pinned, at, batch?, class}}  # всякий стук с подписью партии, годной или нет; неизвестная — память 64; порядок KNOCKS — старшинство, а не имя (С15)
приём:       подпись верна, used < n, не отозвана, отпечатка нет в refused → Entry, used + 1 одним пакетом; журнал; 
исключение:  DELETE принятого партией вносит отпечаток в refused: вернуться тем же токеном нельзя (С14)
сверх:       стук лежит, ждёт человека; отзыв закрывает новые, принятых не трогает
двери:       POST, GET /domain/batches, DELETE /domain/batches/<имя>; admin домена
```

## Читатели

`GET /domain`, `GET /domain/members` — постранично: V/11.3, V/11.8, страница держателя. `domain/members` исчезает из каталога: 144 строки семей, 8 сценариев. Записать в ADR: ключ `domain/member-rows/<раздел>` (М1).
