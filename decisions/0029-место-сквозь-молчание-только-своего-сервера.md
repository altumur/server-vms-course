# Место держится сквозь молчание хранилища, только если оно сервера этого воркера

## Context and Problem Statement
Платформенная система: базовый воркер платформы держит место (`<sub>/holds/<место>`) и пишет в него. Когда хранилище молчит, аренду места подтвердить нельзя. Писать дальше без подтверждённой аренды — значит ослабить единственность писателя.

По ADR-0013 где место, платформа читает из его строки по `placement.places.server_field`. Курс считал место нестрогим, если строка называет любой сервер. Тогда воркер, который по ошибке держит место чужого сервера, пишет туда сквозь молчание до `lease.unconfirmed_max`.

## Decision Drivers
* ADR-0012: умолчание, ослабляющее отсечение или единственность писателя, выключено, пока нет свидетельства, что оно безопасно.
* Одно значение ключа спеки на обеих сторонах: курс и продукт меняются в один день.

## Considered Options
* Место нестрогое, если строка называет любой сервер (как было в курсе).
* Место нестрогое, только если строка называет сервер этого воркера.

## Decision Outcome
Выбран второй вариант. Место держится сквозь молчание по `lease.unconfirmed_max`, только если строка места называет сервер этого воркера. Свидетельство «место своё» — равенство сервера строки и сервера воркера.

При `placement.places.lease: strict` всё остальное отпускается после окна аренды:
* место любой коробки (строка не называет сервер);
* место чужого сервера: это чужое место, а не место любой коробки;
* место, строка которого не прочиталась при взятии;
* любое место воркера, который не знает своего сервера. Это ошибка развёртывания: воркер теряет место в молчание через окно и сообщает об этом в пульсе.

Поле пульса пишет база воркера, только когда у воркера нет сервера, а спека называет `placement.places.server_field`:

```
server_unsaid: "this worker names no server of its own: every place it holds is let go when its hold goes unconfirmed"
```

Платформа по полю ничего не решает, в `/metrics` оно не идёт; консоль показывает его как предупреждение узла воркера.

Отказ на своё `of` (ADR-0013) действует в любом журнале подсистемы, а не только в журнале воркера. Исключение — платформенные деревья записей о единицах: отметки консоли и журнал аудита. Там `of` — предмет записи: что отметили или о чём событие.

### Consequences
* Good, because запись без подтверждённой аренды включается только там, где второго писателя быть не может: на своём сервере.
* Good, because подсистема не обходит правило `of`, открыв журнал напрямую.
* Bad, because воркер без сервера в опциях теряет и свой локальный диск через окно молчания, пока развёртывание не исправят.
* Bad, because курс и продукт правят базовый воркер и тесты в один день.

### Confirmation
* Продукт: `w2cplatform/baseworker_test.go`, `TestThroughASilenceAPlaceIsKeptOrLetGoByWhereItsRowSaysItIs` на `testsub2`, случаи «this server's», «another server's», «a server's, the worker says none».
* Продукт: `TestTheBaseWritesOfAndALineThatSaysItsOwnIsRefused` — строка журнала с `of` записана, строка подсистемы со своим `of` отказана, и мимо воркера тоже.
* Продукт: `TestWhereAPlaceIsIsReadAgainAtEveryRenewal` — признак «место этого сервера» по строке, прочитанной при продлении.
* Курс: те же случаи в тестах «Лекций» на `testsub2`.
* Продукт: `TestAWorkerWithoutItsServerSaysSoInItsHeartbeat` — `server_unsaid` есть только у воркера без сервера при `server_field` в спеке.

## More Information
Признак «место этого сервера» перечитывается при каждом успешном продлении удержания. Он ставится только по прочитанной строке с сервером этого воркера, неудачное чтение его не меняет, ослабления нет (решение «Архитектора» 2026-10-05).
