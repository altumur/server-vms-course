# Группа единиц (каналы одного устройства) размещается только целиком

## Context and Problem Statement
Устройство лицензирует две-четыре сессии; каналы одного устройства, разложенные по воркерам, открывают несколько сессий и отказывают словами устройства спустя часы. Продукт держал правило «нет места нигде: расщепить» и счётчик `groups_split`.

## Considered Options
* расщеплять группу, когда целиком она не помещается;
* размещать только целиком: одно устройство, один держатель, всегда.

## Decision Outcome
Выбрано второе, как в курсе. Группа без места целиком считается в недостаче и ждёт запасного; группа, удерживаемая ради достижимости, считается в недостаче целиком; пульс в общем слушании берётся под ключом хранилища, а не под именем из тела.

### Consequences
* Good, because отказ устройства по сессиям невозможен по построению.
* Bad, because одна большая группа может ждать запасного дольше, чем ждали бы её каналы по одному.

### Confirmation
Размещение по `placement.group_by`: тест, где группа не помещается ни к кому, даёт недостачу на всю группу и ни одного размещённого канала.
