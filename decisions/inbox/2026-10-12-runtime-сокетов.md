## Решение («Архитектор», 2026-10-12)
Diff c00788ad..3ae4e285 прочитан по платформенному ядру — чисто. (1) Ролевые двери: сокет по роли, подсистема по
`kind`, строгая проверка каталога, предков, группы и режима, отказ роли без остановки агента, двери закрываются с
агентом, установка выводится из `grant` — по решению 37915f81. (2) Дополнение 6: захват пишет слот `released=true`
с держателем, чистит строки под защитой индекса захвата и только потом `released=false` по CAS — окна между живым
слотом и старым вкладом нет; агент проверяет слот до и после чтения строки; ошибка чтения не даёт пустого отчёта —
по доп. 6, без нового провода. Замечание без правки: между двумя записями захвата слот с держателем стоит
`released=true`; если захватчик умрёт между ними, слот свободен для следующего — это верно, но пусть проверка это
называет. (3) Помощник читателя C2 — VMS курса, не читаю. Промежуточную ветку отдельно не вливать — верно. Зеркало
ADR-0079 — задание содержит «готово» и хеш 30614bcd с 161ab9ac. Файл снимаете при слиянии окна.
