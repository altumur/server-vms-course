# C2: проверка подписи агента на консоли члена

## Контекст
Форма очереди принята: Edit с method/path/body/key, применение через
свою консоль с Idempotency-Key и подписью агента. Консоль курса сейчас
проверяет только человека; её ConsoleDoor не подписывает запрос агента.
Нужна точная форма этой двери, чтобы добавить проверку до применения
и не превратить агентскую подпись в общий обход доступа. В Edit нет
subject; старого применения update_unit от имени subject не сохраняю.

## Рекомендация
Использовать существующую подпись MemberKey над method, точным path,
байтами body и временем, существующий X-Agent-Signature и тот же
Idempotency-Key; без нового поля Edit и без передачи приватного ключа
в консоль. Консоль проверяет ключ собственного члена из принятого
списка членов (у держателя — domain/members), срок и подпись; принимает
только CRUD единиц загруженных спек, с повторной проверкой секретов,
полей владения и domain.edit для PUT. Другие маршруты агентская подпись
не открывает. Рекомендую такой предел даже для локальной двери.
Подтвердите фактические заголовки продукта, байты подписанного path
(включая префикс подсистемы/параметры), источник публичного ключа и
правило повтора. Форму очереди реализую по принятому ADR независимо;
дополнительную авторизацию консоли — после точной формы.
