# З-10: нечитаемая сохранённая отметка времени таблицы

**Да, как предложено coord103-src:** подтверждённо прочитанная строка с присутствующим сохранённым `at` или `made_at` вне row-Time получает существующее представление `{name, garbled: true, index}`. Это привязка исхода по ADR-0129 (23), а не новое решение о совместимости, форме ответа или правах.

## Основание

Точная исходная база вопроса — `d034aa09e6dcad450cd4e0942457f430dda43ece`. В [P/06.1 N1](../../Platform/06-console/spec/06.1-console.norms.md) строка 38 относит сохранённые `at`/`made_at` таблицы к общему row-Time P/01.1 N0. Строки 262–266 различают текст отметки в хранилище и числовые поля экспортируемого `TableRow`. Строка 623 уже задаёт представление целой испорченной строки, но называет только ошибку объявленного поля. Уточнение охватывает также присутствующую испорченную отметку времени.

В [разборе З-10](2026-11-07-З10-P01-P02-разбор.md) принят предел дроби времени строк нынешнего писателя — не больше трёх цифр. Строка с более длинной дробью не получает округления, усечения или частичного положительного представления. Привязка использует уже существующий исход испорченной строки.

## Точная граница

- Подтверждённое чтение целой строки и присутствующий сохранённый `at`/`made_at`, который не читается как row-Time P/01.1 N0, дают `{name, garbled: true, index}`. Это относится и к дроби длиннее трёх цифр после согласования общего кодека по З-10.
- Неподтверждённое чтение или сбой listing остаются 503. Они не превращаются в пустой список или `garbled`.
- Отсутствие поля сохраняет прежнюю семантику. Новая обязательность отметок не вводится.
- Экспортируемые числовые `TableRow.at`/`made_at` сохраняют собственную форму по R012. Уточнение не ограничивает все JSON-числа и не меняет переносимые формы токена, private admission metadata или другие исключения З-10.
- Порты, HTTP-статусы, отказы, заголовки, права и условное удаление/замена по `index` остаются прежними. Текст исправляется в EN/RU с точными картами.

## Точная замена пояснения

До:

> Only an already read but spoiled row — the value of a declared field does not read by its type by values_by_type N1.2 — is represented as `{name, garbled: true, index}`

После:

> Only an already read but spoiled row — a declared field does not read by its type by values_by_type N1.2, or a present stored stamp at/made_at does not read as row Time by P/01.1 N0 — is represented as `{name, garbled: true, index}`

## Проверка и исполнение

Coord103-src включает эту привязку в точную Time-долю уже назначенного исправления З-10. До изменения фикстуры писатель отдельно объявляет существующий вход для сырой сохранённой строки, точные ячейки и положительного/отрицательного соседа. Если такого входа нет, исполнение этого места остаётся явно непокрытым. Новая дверь, шов или case этим уточнением не назначаются.

READONLY-вопрос `TABLE-STAMP-QUESTION.json`, SHA256 `0a2e9c467c4a98c0c7af90341db37fff52028b27ad1a0d51f88130afe6618e39`, и первичные нормы прочитаны. Программы автора, схемные проверки, Go/HTTP/SUT и полный GATE Архитектор не запускал. Узкие независимые FORMAT/floor не ждут исправления реализации локальной JSON Schema-рекурсии читателя P/08.
