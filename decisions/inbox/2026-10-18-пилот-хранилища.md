# Пилот микромодуля «хранилище»: задача «Спецификации»

## Контекст
ADR-0083 п. 7. Отчёт — `/Users/murat/w2c/cammeta-interop/REPORT.md`.

**По двери хранилище заменяемо.** Смешанная сборка (Go-хранилище под Python-процессами и обратная) прошла уроки 03–11
без единого расхождения с целиковой реализацией. Файл прав Python читается Go.

**Как модуль живой установки хранилище не заменяемо.** Не нормирован жизненный цикл:
- формат на диске и замок;
- копия и восстановление;
- флаги демона;
- раскладка сокетов;
- поставка.

Самое опасное: хранилище молча стартует пустым на чужом каталоге и обнуляет пол эпох.

## Решение — нормы М10/1, М10/6, М10/11 (урок 1 «Платформы» при переносе)
1. **А1.** В каталоге данных — метка формата `FORMAT` `{format, version, impl}`. Непустой каталог без своей метки —
   отказ старта, код 2, ничего не дописывать. Смена реализации — только через копию (п. 2) в свежий каталог. Шаг:
   старт на каталоге с чужим содержимым — код 2, каталог не изменён.
2. **А2.** Копия `backup` и вход `import/restore` — один нейтральный формат JSON Lines:
   - заголовок `{"format": "w2c-configstore-copy", "version": 1, "index": "<строка>"}`;
   - строки `{key, items, index[, unreadable]}`;
   - `platform/epoch_floor` — обычная строка.

   Иной формат — отказ целиком до первой записи. Векторы — в пакет векторов урока 1. Шаг: копия одной реализации
   восстанавливается другой (матрица).
3. **А3, А4, А8.** Таблица флагов демона: тип, умолчание, смысл.
   - `-dir` обязателен.
   - `-sockets DIR` — плоско: `DIR/admin.sock` и `DIR/<роль>.sock`, без подкаталогов. `-socket` снять.
   - «каталог setgid» снять: группу задаёт `SocketGroup=` юнита.
   - `-id` обязателен в группе; на коробке умолчание — `SERVER_NAME`.
4. **А5.** `--check` прав сравнивает по смыслу: `roles` как множества образцов по операциям, и `group`. `comment` и
   порядок списков не сравниваются. Уточни, что значит ключ `alarms_retention` в М10/6 Н1.4 (две реализации прочли
   по-разному).
5. **А6.** В словаре «Стенда» — отдельная команда `spec-put {socket} {file}` через дверь admin. Команда `store` спек
   не кладёт, раннер кладёт их до `@start`.
6. **А7.** `/v1/status`: `leader` — адрес API лидера (пусто без `-api`), `leader_id` — id. Описать в схеме.
7. **А9.** `PLATFORM_STORE`:
   - для микромодулей — дверь (`configstore:///…/<роль>.sock`);
   - `file://` — профиль «вся коробка — одна реализация», формат на диске не нормируется.

   Назвать это в М10/11 Н1.2 и в каталоге контрактов (ADR-0083).
8. **А10.** Демон принимает унаследованные сокеты по `FileDescriptorName=<роль>|admin`, без них создаёт по `-sockets`.
   Переменных, выключающих долговечность, в норме нет: стенд, которому нужна скорость, говорит это флагом стенда, а не
   окружением эксплуатации.

Правки — к следующей выгрузке. Дефекты реализаций (Б1–Б4) уходят генераторам.

## Исполнение
Пишет «Спецификация», 2026-10-18. Срез — 8899df40 и далее; находки — пилот (`cammeta-interop/REPORT.md`), «была раньше»:
жизненный цикл хранилища не нормировался с первого текста М10/11.

   - М10/11 Н1.3 `format`: `{format, version, impl}`, пишется первой в пустой каталог (tmp + rename). Непустой каталог без
     метки, чужие `format`/`version`, метка не по форме — отказ старта, код 2, без записи и удаления. Смена реализации —
     только копией.
   - Отказ — в `refuse_start` и в Н4.
   - Шаг: приёмка 11, сц. 10 `10-foreign-dir` — директива `@foreign store nolabel | otherlabel` словаря М10/01: второй

   - Писатель кладёт ключи по возрастанию байтов, читатель порядка не требует. `platform/epoch_floor` — обычная строка;
     память повторов `id` в копию не входит.

     - `/run/configstore` 0755 root;

   - «Решает реализация» п. 2 М10/11 и п. 4 М10/6 — нормированы.
   - М10/6:
     - `cluster`;
     - `установить`;

   - Лекция 11 — строка юнита.
4. **А5 — `--check` по смыслу.**

### Форма `generation_at` (решение «Архитектора» 2026-10-18)
- **М10/3 Н1.5:** `generation_at` — секунды стенных часов, десятичная запись: целая часть без знака и ведущих нулей,
  дробная — до 3 знаков, `^(0|[1-9][0-9]*)(\.[0-9]{1,3})?$`.
- **Копия.** В `copy-ok.jsonl` добавлена строка `platform/epoch_floor`
  `{floor: "4294967296", generation_at: "1760745600.5"}`, `index` `"6"`.
- **Сценарий.** Сц. 11 шаг 4 видит `floor` и `generation_at` после `import`.
- **README приёмки 11** поправлен.

**Класс (вопрос).** «До 3 знаков» сейчас не записано ни у одного времени строк:
- М10/3 «Решает реализация» п. 5 прямо отдаёт форму `until` реализации («с дробной частью или без»).
- Без формы стоят и другие времена:
  - урок 4: `at`, `since`, `asked_at`, `offered_at`, `last_success`;
  - урок 3: `taken_at`;
  - урок 5: `ts`, `started`;
  - урок 8: `t`, `usage_at`;
  - урок 10: `platform/schema.at`, `at`, `made_at`;
  - строки М11: `at`, `since`, `last`, `until` грантов и др.

Рекомендую одно правило в каноне Н0 М10/1 — «время в строке» с этой формой. Поля ссылаются на правило, п. 5 М10/3
снимается; при переносе правило уходит в Н0 урока 1 «Платформы». Это изменение поведения для писателей, которые пишут
больше 3 знаков: шаги приёмки — по полю, отдельной правкой.
