# Диалект формы и Н1.1 по журналам догадок шести агентов

Основание — ADR-0087 доп. (2): «описание диалекта и Н1.1 уточняются по журналам догадок всех шести агентов: каждое
неясное место — решение и, где данные его не различают, случай корпуса». Дополнено по разбору ревью доп. (2)
(`inbox/2026-10-19-ревью-ADR-0087-доп-2-разбор.md`, ADR-0087 доп. (3)): каждая догадка отнесена к одному из четырёх
видов (Р5), внесены Р1, Р2, Р4, Р6, Р7; ответы владельца на В1–В3 — ADR-0087 доп. (4) (§ 5). Исполнение — при переносе урока 2 (стадия B, ADR-0087 п. 6, доп. (1) Р9,
доп. (2) Р9: свод соединяется с решениями доп. (1)); нормы этой запиской не меняются.

Источники:
- отношения и диалект — `cleanroom-rel/work-py-own/GUESSES.md` (Py), `work-go-own/GUESSES.md` (Go; номера Г1–Г44);
  `work-py-cel`, `work-go-cel` — только общие места диалекта (форма, классы, числа, умолчания), не CEL;
- слой текста Н1.1 — `cleanroom-text/work-py/GUESSES.md` (Py-текст, Г1–Г18), `work-go/GUESSES.md` (Go-текст, 1–24);
- диалект — `cammeta-schema-pilot/source/DIALECT.md` (§), источник `spec.form.yaml` пилота; норма — М10/2 Н1.1–Н1.4,
  Н4 на срезе `ddc571347`.

**Виды** (разбор доп. (2) Р5). Норма и случай пишутся только для первого вида.
- **решение** — нормы нет или она противоречит себе, а ответ (вердикт, класс, множество путей, строка) от выбора
  зависит: норма и различающий случай. «Принято» — норма уже записана (коммит или дополнение ADR).
- **норма** — ответ уже задан: текстом Н1.1–Н4, описанием диалекта или смыслом YAML 1.2.2 у конструкции, которую
  подмножество Н1.1 принимает и не меняет (Н1.1: «читаемый как подмножество синтаксиса YAML 1.2»); нужны ссылка и
  тест. Тест — вариант пилота (имена `key_space_before_colon` и подобные — из `cammeta-schema-pilot/runs/parsers.tsv`),
  в корпус урока 2 он входит при переносе; ожидаемое — по норме, не по эталону и не по исполнителям (доп. (2) Р8).
- **ошибка исполнителя** — норма ответ задаёт, исполнитель прочёл иначе: исправить исполнителя, норму не трогать; тест.
- **свобода реализации** — ответ от выбора не зависит (пути — множество; форма отказывает раньше; источник такого
  сочетания не пишет): не норма, случая нет.

«Оба» — Python и Go выбрали одно. «Р7» — место, где исполнители своего языка уже написали противоположный код (разбор
доп. (2) Р7).

## 1. Слой текста (Н1.1)

`scalars.tsv`), `empties` (пути пустых значений) и карту строк ключей; при отказе текста — строку, путь (если он есть)
и причину. Без этого не пройти `diagnostics.tsv`: строки шагов 2–5, пути отказов `text` у повтора ключа и у ключа не
строкой. Исходной записи числа интерфейс не несёт (доп. (4), В3). Пишется в описание слоя (DIALECT § 5 п. 1) при переносе.

## 5. Ответы владельца (ADR-0087 доп. (4))

**В1 → (а). Источник формы читается слоем текста Н1.1.** `*.form.yaml`, `*.references.tsv`, `*.scalars.tsv` читаются
тем же слоем текста, что спеки: одна грамматика YAML в курсе, отдельного подмножества у построителя нет (Ф22).

**В2 → (а). Регулярное выражение в отношении — всегда строка в кавычках** (`t ~ "re"`); без кавычек — ошибка
построения. Слово синтаксиса диалекта, принятое владельцем (ADR-0087 п. 2) (О16).

**В3 → (б). `text()` — каноническая запись значения** по JCS (`1e0` → `"1"`), bool строчными; исходную запись слой
текста не отдаёт, его интерфейс (доп. (3), Р4) не меняется. Различающий случай — дробное значение `enum` под правилом
`display.options` (`1e0`, `1.50`) (О10).
