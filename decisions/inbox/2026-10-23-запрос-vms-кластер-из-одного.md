# Запрос: кластер из одного — дверь после первой публикации; запись копии `domain/grants` на флеш

**Какие нормы мешают.**
1. P/02.4 Н1.10, P/09.1 Н1.2 `ready`: отчёт агента не уходит до первого шарда снимка; о двери кластера из одного
   (консоль, дверь держателя) — когда она открывается относительно первой публикации — нормы нет. У свидетеля (М12A/10
   шаг 5): порядок загрузки камеры «эпоха → строка → публикация → дверь»: дверь до публикации отдала бы домену камеру,
   которой в его виде ещё нет.
2. P/09.1 Н1.4 `home_write` (`09.1-agent.norms.md:262–271`): `as_of` копии `domain/grants` освежается раз в
   `FRESH_EVERY` = 60 с — около 1 440 записей в сутки; P/02.4 Н1.11: принесённое агентом — долговечное (флеш камеры).
   Свидетель (М12A/10 шаг 4): «агент пишет только при отличии — 2 879 проходов без изменений ничего не стоят».

**Что нужно VMS.** Камера как кластер из одного (V/01.6 Н1.5): флеш камеры — ресурс; дверь камеры — тем же порядком у
обеих реализаций.

**Обход до решения.** (1) Порядок загрузки — правило реализации камеры (V/01.6 Н1.5). (2) Как есть.

**Рекомендация.** (1) P/02.4 Н1.10: у кластера из одного двери процессов слушают после первой публикации шарда (как
`ready` агента), до неё — 503 `not_ready`. (2) P/09.1 Н1.4 / P/02.4 Н1.11: у кластера из одного свежесть копии — в
памяти (горячее), на носитель — только при изменении содержимого; либо `FRESH_EVERY` кластера из одного — не чаще раза
в N минут.

## Решение
**Решён** (2026-10-23, «Архитектор»; текстовый запрос — «Спецификации» по слову, без ADR). (1) P/02.4 Н1.10: у кластера из одного двери процессов до первой публикации шарда снимка отвечают 503 `not_ready` (как `ready` агента); слушать порт раньше можно. (2) P/09.1 Н1.4, P/02.4 Н1.11 — для любого кластера, не только из одного: `as_of` копии `domain/grants` освежается в памяти раз в `FRESH_EVERY`; на носитель копия пишется при изменении содержимого, а одно освежение `as_of` — не чаще раза в час (после перезапуска копия выглядит старше не больше чем на час — строже, не опаснее). Приёмка — чтением и сценарием агента, где стенд позволяет.
