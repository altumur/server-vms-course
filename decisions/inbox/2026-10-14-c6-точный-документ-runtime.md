# C6: точного локального документа shared/auto пока нет

## Контекст
731121b7 разрешает чтение только `domain/shared/auto`. В курсе `SharedView.document()`
читает единственный указатель `domain/shared`, проверяет подпись целого документа
из объектов `domain/shared` (у держателя `shared/rev-N`), затем берёт
`settings.shared.auto.scenarios`. Агент точного документа не пишет. Поэтому одно
добавление права точному имени не исправит runtime; выдать общий указатель нельзя
по решению. Платформа пока не менялась.

## Рекомендация
Сохранить точное право `domain/shared/auto`, добавить общий платформенный механизм:
агент после проверки целого документа публикует для каждого объявленного spec.domain.shared
проверенную локальную проекцию `domain/shared/<sub>`; исполнитель читает её через общий
читатель. Запись доступна только агенту, чтение только объявившему путь воркеру;
при отзыве/смене поколения проекция отсекается вместе с проверенной копией.
Сначала согласовать форму и место хранения проекции: Variable содержит ссылку на
подписанный документ и имя sub; байты документа остаются в Objects. Общий указатель
воркеру не выдавать. Альтернатива — явное разрешение чтения существующего общего
указателя, но она противоречит точному ограничению 731121b7, потому не рекомендую её.

## Решение («Архитектор», 2026-10-15)

**Проекций не вводить; решение 731121b7 уточняется.** Общий документ домена — одно подписанное целое: указатель `domain/shared` (одна строка, точное имя) и байты поколений объектами `shared/rev-N` на двери объектов; так его читает и продукт (`HeldDoc`: указатель + объекты, затем `settings.shared.<sub>`). Строки `domain/shared/auto` не существует, и заводить её (или проекции `domain/shared/<sub>`) — второй носитель того же документа. Норма (урок 6 Н1.4, этим коммитом): воркер спеки, которая объявляет `domain.shared` или объём `scenario` у вида токена, читает **точное имя** `domain/shared` (указатель) и объекты документа через дверь объектов; `domain/shared/*` и `domain/shared-docs/*` ему не выдаются (это семья держателя). В `auto.worker.reads` — `domain/shared` (точное имя, без `/`), перегенерировать права; общие права воркеров не расширять. У продукта `auto` этого чтения в спеке нет — строка долга «курс первым», по снятии паузы.
