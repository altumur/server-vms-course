## Интерфейс и входы

`credential_fields` — список имён, которые фактически выбрала диагностика отказа `bad_url` по A15, без адреса и его частей;
порядок не судится. Непустая ячейка ожидания сравнивается как множество, `[]` требует пустого списка.
Пустая ячейка у прежних случаев оставляет поле без сравнения. Оно не заменяет основное `field`.

Колонка `manifest` выбирает входные байты `files["testsub2.subsystem.yaml"]` через существующую подстановку пути провода.
В ячейки алгоритма она не попадает. Ожидания, включая `credential_fields`, во вход не передаются.
Изолированная фикстура `vectors/row-check/fixtures/testsub2.subsystem.yaml` сохраняет имена testsub2/tallies;
общие `Platform/common/data/testsub/testsub{,2}.subsystem.yaml` побайтно сохранены.
Новая фикстура имеет `judge_only` в M и `include` в J; прочие записи обоих фильтров не менялись.
Публичный README описывает только интерфейс, конкретные случаи и покрытие остаются в judge-only README.cases.
