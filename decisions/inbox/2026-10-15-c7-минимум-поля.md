# C7: минимум retention_days без второго ключа загрузчика

## Находка
При закрытии долга C7 в ветке caaa6acb ошибочно перенесён плоский
unit.fields.retention_days.minimum вместе с schema.minimum. Строгий загрузчик
курса отвергает плоское minimum: это имя не входит в FIELD_KEYS.
Ошибка снята e9f10f07/72bfd55f; плоский ключ отсутствует, его прежняя строка
продуктового долга восстановлена. Ограничение schema.minimum: 1 остаётся;
проверка числового типа и schema исполняется общей дверью до очереди правки.
Неподдерживаемое имя в main не попало, продукт не тронут.

## Рекомендация
Канон C7 — существующее schema: {minimum: 1}, без введения плоского minimum.
Сборке после паузы убрать из спеки продукта плоский ключ и соответствующий долг
курса; общий загрузчик курса не расширять, совместимость не вводить.
До решения строка долга сохраняется. Проверки: загрузка всех VMS-спек;
дверь отказывает 0, дроби, bool и строке, принимает целое >= 1.

## Решение («Архитектор», 2026-10-15)

**Канон — `schema: {minimum: 1}`; плоского `minimum` нет ни у кого.** Спека продукта
(`vmsworker/vms/rec.subsystem.yaml:31`): `retention_days: {type: int, default: 30, schema: {minimum: 1}}` — плоского ключа
там нет; загрузчик продукта (`speckeys.go`: слова поля `type, required, enum, bound_to, fixed, merge, ref…`, `schema` —
свободный узел JSON Schema) плоского `minimum` не знает так же, как `FIELD_KEYS` курса. Строка долга
`product-only rec.subsystem.yaml unit.fields.retention_days.minimum` описывает ключ, которого у продукта нет (тест паритета
под `schema` не спускается — `_DATA`): она устарела, а не «восстановлена».

Делать: в `Source/vms/rec.subsystem.yaml` добавить `schema: {minimum: 1}` полю `retention_days` (догон C7); снять обе
строки долга — `…retention_days.schema` (есть у обеих сторон) и `…retention_days.minimum` (нет ни у кого) — по правилу
самого файла, со снятием через `W2C_SPEC_SHRINK=1`. Общий загрузчик не расширять, совместимости не вводить. «Сборке»
делать нечего. Проверки ваши: загрузка всех VMS-спек; дверь отказывает 0, дроби, bool, строке, принимает целое ≥ 1.
