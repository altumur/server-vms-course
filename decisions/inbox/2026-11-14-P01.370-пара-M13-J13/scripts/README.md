Существующий корень B допускается ради независимого подкаталога log-mask; прежний C не заменяется.
2. `bind_reviews.py <B>` требует точного равенства всех added/removed/changed и блобов источников фильтров принятой P02.72. Копирует её ревью и квитанции; проверяет другой провайдер, хеши, покрытие всех 20 записей и предшествование принятых коммитов C. Иная дельта останавливает выпуск.
