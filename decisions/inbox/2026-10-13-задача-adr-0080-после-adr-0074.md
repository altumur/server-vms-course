# ADR-0080: лекции как спецификации — после завершения ADR-0074

Решение владельца 2026-10-13, текст — `decisions/0080-…`. Не сейчас: начало после ухода `domainpart` (шаг C7
ADR-0074) и закрытия вашего окна книг. Тогда: первый урок М11_Cluster переводится в форму пяти разделов (Форма,
Двери, Проход, Отказы, Приёмка; приёмка — сценарии в `Source/tests/testdata/`, прогоняемые через двери) как образец,
кладётся в main и называется здесь разделом «Сделано» с хешем; «Архитектор» читает образец, формат закрепляется
поправкой к ADR-0080; дальше — по модулям в порядке зависимости. До того файл лежит без действия.

**Дополнение 2026-10-13:** нотации разделов закреплены дополнением к ADR-0080 — «Двери» и «Отказы» в OpenAPI с
закрытыми кодами, «Форма» хранилища в спеках, «Проход» псевдокодом (автомат там, где цикл жизни), приёмка и журнал
исправлений ИИ в общих данных; инструменты — на образце М11.

**Дополнение 2026-10-13 (2):** «Проход» — нормативный псевдокод только на словаре операций хранилища, который
определяется один раз в уроке о хранилище М11 (прочитать, записать, с `cas`, с `guard`, удалить, перечислить; форма и
коды — ADR-0074 доп. 1); подраздел «Гонки» обязателен у каждого прохода, пустой — словом «нет». Поэтому образец
начинается с урока о хранилище М11, а не с любого.

**Дополнение 2026-10-13 (3):** словарь ДОЛЖЕН/СЛЕДУЕТ/МОЖЕТ в уроке о хранилище М11, пометка «решает реализация»
с обязательной записью выбора у каждой реализации, подраздел «Цели и не-цели», чеклист готовности в конце урока со
ссылками на сценарии приёмки. Образец показывает все четыре.

**Дополнение 2026-10-13 (4), поправка задачи:** вместо М10A, М10B, М11_Cluster, М12A_Domain, М12B_DomainVMS —
четыре модуля по дополнению 4 к ADR-0080: М10 Платформа: хранилище и спека (11 уроков), М11 Домен (12), М12A
Подсистемы: камеры и запись (7), М12B Подсистемы: трансляция, автоматика, детекторы, сборка (6); таблица
соответствия старых уроков новым — там же. **Образец — урок 1 нового М10 «словарь операций хранилища»**, не урок
М11_Cluster. Порядок: записка `module-design` М10 → «Архитектору» на чтение, затем урок 1 как образец, «Сделано» с
хешем сюда; дальше М10 целиком, М11, М12A, М12B. М13 и М14 — после них по той же форме. Начало — по-прежнему после
C7 ADR-0074 и вашего окна книг.

## Поправка задачи («Архитектор», 2026-10-14, ADR-0082)
Перевод уроков вам не поручается: его ведёт с сегодняшнего дня отдельная сессия «Спецификация» (ADR-0082), не дожидаясь
вашего C7 — продукт закрыл ADR-0074 целиком. Ваша очередь без изменений: окна Python C2–C7 по ADR-0074, окно за шаг
(задача «окно за шаг»); затем Python догоняет переведённые уроки по их сценариям приёмки
(`Source/tests/testdata/acceptance/<модуль>/<урок>/`), урок за уроком, начиная с М10/1. Границы дерева: вам — `Source/`
кроме `tests/testdata/acceptance/`; новые каталоги модулей и прежние уроки не трогаете (прежние заморожены и уходят по
мере переноса). Расхождение Python с уроком — файл во входящие как сегодня: вопрос о тексте урока отвечает
«Спецификация», о решении — «Архитектор». Записки `module-design` новых модулей пишет «Спецификация». Файл остаётся
как задача «догнать уроки»; «Сделано» здесь — по каждому догнанному уроку с хешем.
