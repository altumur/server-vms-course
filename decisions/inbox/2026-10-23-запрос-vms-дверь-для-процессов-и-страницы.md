# Запрос: одна дверь процесса для процессов (сертификат роли) и для страницы (токен двери); единица токена двери места

**Какие нормы мешают.**
1. Класс `role` договора сертификата роли (P/10 Н1.4, `role-certificate.md`): сертификат клиента требуется при соединении;
   нет — 401 `no_role`. Токен двери консоли (договор `door-token.md`, P/03.4 Н3 «токен двери у держателя», P/06.5 Н3
   `/where`) — для страницы: браузеру сертификат клиента предъявить нечем. Норма не говорит, как одна дверь процесса
   служит обоим.
2. Договор токена двери: «`unit` и `holder` — свои» у держателя. Дверь места (`/where/<table>/<place>?unit=<id>`, P/06.5 Н3)
   выдаёт токен держателю **тома** для чтения записи, которую он не держит (запись другого регистратора на этом томе,
   отсечённая эпоха). «Своя единица» для двери места — какая?

**Что нужно VMS.** Дверь архива регистратора (V/02.5): процессам — `/spans`, `/samples` (копия резервной, копировщик
удержаний, скан `detjob`; роли `recworker`, `detjobworker`), странице — `/timeline`, `/segment`, `/keeps` (`door.routes`
манифеста `rec`). У свидетеля — одна дверь на одном порту (ADR-0075 окно 2 ещё не исполнено: процессные маршруты без
допуска).

**Обход до решения.** V/02.5 Н2: один слушатель; с комплектом — TLS сервера роли `recworker`, сертификат клиента
запрашивается **необязательно** и проверяется в рукопожатии (как слушатель `SIGNER_URL`, класс `signed`); процессные
маршруты требуют предъявленную роль `recworker` или `detjobworker` (иначе 403); страничные — токен двери (иначе 403
`forbidden`). Единица токена двери места — единица из пути (`/timeline/<запись>`, `/segment/<запись>/…`) или
`?recording=`; держатель проверяет, что запись лежит в держимом томе.

**Рекомендация.** (б) Договор сертификата роли — класс «смешанный»: один слушатель, сертификат клиента необязателен;
дверь объявляет, какие маршруты требуют роль (и какую), какие — токен двери. Альтернатива (а) — два слушателя (процессам —
класс `role`, странице — TLS сервера и токен) с двумя полями адреса в пульсе. Для двери места — норма: `unit` токена —
единица, данные которой лежат в месте держателя; держатель сверяет по своему месту.
