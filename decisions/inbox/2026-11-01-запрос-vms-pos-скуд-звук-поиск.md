## Решения сверх ADR: проверить ревью

POS, СКУД:
- `cam/unit_next` — счётчик единиц: поле в `cam/cameras` перезапускало бы соединение.
- Единицу в просьбе называет `n`: `unit` занят id строки: `{unit: <строка>, action: unit, n, operation}`.
- `template` ↔ `Device.model`; выбор по `unit-templates.tsv`, неоднозначно у 9 сочетаний — `model` обязателен. 13 шаблонов из 54 без `type`, дверь и забор отнесены к видам по смыслу.
- Вид `controller` в `device_units`: записи `Device` нет, заводит только дверь таблиц.
- `relay` в `deviceTypes` только как единица. `text` — строка на `EventData`, группу связывает поле `group`. Поле `phase` у `unit`.
- `serverId` не назван: строка без метки, `warning`. Метка `server:<имя>` обязательна на сервере, иначе 422.
- `device_state: lost`, `units_down` в пульсе.

Звук:
- Право `edit` проверяет просьба `talk`: токен двери выдаёт `view`; держатель занимает `spk` за `by`, срок `valid_for` 30 с.
- Звук на RTSP — отдельные точки `<live_url>/mic`, а не дорожка.
- Умолчание `audio` 0, значения «без звука» нет: выключить `mic`.
- Раздача `live/<ipsrv>` только ради разговора.
- SMPL звука `major = 3`, `AAC `, ADTS: требование к движку.

Поиск:
- Просьба не через `requests:`: у поиска нет единицы и идёт он на всех серверах: строка `cam/searches/<CLUSTER>`, вопрос о модели — `cam/probes`.
- Исполнитель — базовый воркер `w-<сервер>-1`; `h` — хеш MAC, без MAC — `ip:port`; заведённое скрывается по `ip`; `type` кандидата `camera`, `name` — `<vendor> <model>`; запись `searches`, `probes` — `admin`.
