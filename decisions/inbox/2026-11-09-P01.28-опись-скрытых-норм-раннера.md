# P01.28. Первая опись скрытых норм движков раннера

2026-11-09, представитель владельца (задача P01.28, ADR-0135; приём — Архитектор). Только чтение. Код — раннер `cammeta-acceptance` на пине `bcb22c07`; спека — `origin/main` `5fd8c2c0e` курса: `Platform/common/acceptance/{README,PROFILE}.md`, README приёмки `Platform/01-store/acceptance/{1,2,3}`, нормы P/01. Приоритет — P/01; общее — по тем модулям, что P/01 вызывает.

## Вывод

**Спека уже описывает стенд подробно:** подстановки, словарь директив и дверей, форму ожиданий, адаптер `door`, файл прав роли `acc`, раскладку `{data}`, кольцо, команды копии, пробы сырого HTTP P/01.1 — всё это в README и `PROFILE.md`, раннер им следует. Скрытого меньше, чем казалось по `c_store.py`. **Скрытое — в четырёх местах:**

1. **Реестр целей и проводка** (`c_targets.py`, `c_store.py`, `CHAPTER_ENGINES`) — целиком в коде: какая цель каким движком, с какими командами `stand.*`, ключами `keys`, каталогами и частями других уроков. В спеке этой таблицы нет (её ввод уже поручен — ADR-0083 доп. (156) п. 2).
2. **Сроки ожидания** раннера — почти все числа в коде (15/20/30/40/60/120/900 с); спека называет лишь часть (10 с выхода процесса, 20 с некоторых портов, 120 с заморозки) и в одном месте расходится с кодом.
3. **Источник манифестов стенда** — раннер берёт `testsub`/`testsub2` из `Source/tests/testdata/` (замороженный свидетель), а не из данных спеки; в выгрузке без `Source/` судья их не находит.
4. **Правила сравнения ответов**, которых нет в README: различение типов JSON (`1` ≠ `1.0`, `true` ≠ `1`), отказ на повторе имени и `NaN` в ответе, порядок ключей `/v1/list`, обработка заголовка `scenarios.tsv`.

**Счёт:** 59 пунктов. «Нет в спеке» — 27, «есть, но неоднозначно / расходится» — 16, «есть» — 12 (записаны, чтобы автор движка не искал их второй раз), наследие «решить» — 3, «проверить писателю» без оценки — 1. По разделам: 1 — 6, 2 — 6, 3 — 16, 4 — 6, 5 — 5, 6 — 5, 7 — 6, 8 — 9.

Ниже — по разделам 1–8; в конце — черновик реестра целей P/01 и форма реестра для остальных уроков. Где не уверен — «проверить писателю».
