# Типы полей sources и primaries для точного зеркала C2

## Контекст
Зеркало cam в main 7762fd77, продукт C2 готов 962852c0. Подключаю обычных
издателей/читателей в codex/course-primaries-sources. ADR-0074 задаёт имена
полей элементов C2, но не типы codec/polls/ingest/coverage и правила пустых
значений. Старый ingest — объект urls/token_secret/until; токен теперь
получается отдельно и не публикуется. Код продукта не читаю. Без точных типов
можно сделать другой провод при одинаковых ключах. Независимо готовлю строгую
поддержку терминального / в worker.reads и права на семейство.

## Рекомендация
Закрепить фактическую форму продукта в ADR либо Решением здесь; курс повторит
её. Предлагаю: sources.codec — строка (пустая = не определён); push/polls —
булевы; as_of — конечное число; live_url/server — строки. Primaries.coverage —
объект {from,to,fragments} либо null; peer_url — строка; ingest — объект
{urls:[строка,...]} либо null, без токена/срока; push/enabled/running — булевы;
recording/ref/role — строки, to — список имён членов без повторов. Отсутствие
наблюдения описывает пустой вклад, неполноту — missing, не starting.

Если продукт уже использует иной тип, принять именно его, без конверсионного
слоя и двойного чтения. Указать обязательность/умолчание пустых полей, формат
coverage, тип polls и ingest (строка, список либо объект), точный источник codec.
Сам токен stream получаем в памяти по ref через ролевую дверь агента; поля
старой дороги создаются только для внутреннего вызова текущего транспорта,
не записываются в книгу, журнал или хранилище.
