# C5: роль console у accounts без закрытия WHEP для браузера

## Контекст

Решение `2026-10-14-c5-комплект-tls.md` принимает штатный клиент роли
console и требует у шлюза проверить сертификат console отдельно от human
token. ADR-0075 исключает WHEP и публичные metrics из обязательного mTLS;
две двери с отдельным портом приняты только рекордеру (доп. 4).

В курсе `LiveWorker.serve` имеет одну HTTP-дверь: WHEP, metrics и служебные
маршруты. `GATEWAY_URL` уже задаёт её рекламируемый адрес; `LIVE_TLS` и
отдельного gateway peer-port в принятой форме не найдено. Обязательный
clientcert для всей двери нарушит браузерную модель. Общий role-client и
role-context можно реализовать без решения о bootstrap этой двери.

## Рекомендация

Оставить одну существующую дверь шлюза. Явный `GATEWAY_URL=https://…`
включает серверный TLS с комплектом `W2C_TLS_DIR/<W2C_ROLE>/server.*`,
ролью liveworker, общими ca.pem/revoked по ADR-0075 доп. 3. Включённый TLS
без корректного комплекта отказывает в старте; IP в TLS URL отказан.
Clientcert необязателен на handshake, а показанный проверяется CA/CRL.
Только `/live/accounts[/…]` в TLS-режиме требует строго роль console;
затем независимо проверяется исходный human token. WHEP сохраняет прежний
human token, metrics — публичность, браузерный сертификат не требуется.

Явный `http://` остаётся режимом коробки без TLS по доп. 3: без незаметного
https→http fallback. Новых env, портов, heartbeat-полей и второй двери нет.
Просим подтвердить переключатель по существующему GATEWAY_URL и такое
разделение route policy либо дать точную принятую форму. До Решения
server bootstrap шлюза не меняем.

## Решение («Архитектор», 2026-10-14)

**Одна дверь шлюза — да; переключатель — комплект, не `GATEWAY_URL`.** По уроку М10/11 Н1 (строка `<sub>worker`) и ADR-0075 доп. 3: есть `W2C_ROLE=liveworker` и комплект в `W2C_TLS_DIR` — дверь говорит TLS с `<роль>/server.{pem,key}`, общими `ca.pem`/`revoked`, и объявляет себя `https://`; нет комплекта — дверь только на петле и `http://`. Явный `GATEWAY_URL` должен согласоваться с режимом: `https://` без комплекта и `http://` с комплектом вне петли — отказ старта с причиной; IP в TLS-адресе — отказ. Клиентский сертификат на этой двери — по желанию (`VerifyClientCertIfGiven`, как у консоли домена, ADR-0075 доп. 7): показан — проверяется CA/CRL и роль; `/live/accounts[/…]` в TLS-режиме требует роль `console`, затем отдельно токен человека; WHEP — прежний токен человека, `/metrics` — как в ADR-0075. Второй двери, порта, env и полей пульса нет. Продукт сегодня: дверь шлюза `LIVE_URL` http без комплекта — долг окна 1 ADR-0075 у `liveworker`, «Сборке» сказано.
