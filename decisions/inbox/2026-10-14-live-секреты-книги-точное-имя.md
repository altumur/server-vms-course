# `live.subsystem.yaml`: читатели секретной книги `stream-accounts` при точном правиле ключа (М10/7 Н1.3)

## Контекст

Урок М10/7 Н1.3: ключ без `/` — точное имя, с `/` — префикс. У `live` курса объявлено
`domain/live/stream-accounts: [worker, domainagent, domain]` — это только унесённая агентом книга у члена; строки книги по
кластерам у держателя (`domain/live/stream-accounts/<кластер>`) при точном правиле остаются без читателя и открываются
всем (находка «Сборки» на окне М10/7). Платформенные строки той же природы (`domain/signer-pending`, семья `domain/backup*`)
добавлены в платформенный список урока 7 этим же коммитом.

## Решение

В `Source/vms/live.subsystem.yaml` под `secrets.readers` — две строки вместо одной:

```yaml
    domain/live/stream-accounts: [worker, domainagent, domain]     # книга у члена (точное имя) — читает шлюз
    domain/live/stream-accounts/: [domainagent, domain]            # строки книги по кластерам у держателя (префикс)
```

Сделать команде курса в текущем окне (C6) отдельным коммитом, хеш — во входящем; «Сборка» синкает `live` по нему и после этого
вливает точное правило в продукт. Это не задача по М10.
