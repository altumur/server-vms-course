# C5: штатный клиент к роли шлюза отсутствует в Python

## Контекст
C5 требует console→liveworker под комплектом роли. В Python ccfffb66
есть tls.Bundle(dir,name), contexts и require_role; общего клиента и
role layout ADR-0075 ещё нет. Generic door.pass/выбор воркера/auth уже
подготовлены с injectable client, но один injection и 503 не завершают C5.
Продукт руками не читаем. Новое расположение сертификатов не угадываем.

## Рекомендация
В той же ветке C5 сначала зеркалить минимальный общий комплект/HTTP-клиент
по принятой форме ADR-0075: источник W2C_TLS_DIR, CA и CRL только из
комплекта, сертификат клиента роли console; проверка server SAN и роли
<sub>worker; отсутствие комплекта закрывает соединение. Ответный сервер
шлюза подтверждает роль console и отдельно проверяет исходный human token.
Не открывать HTTP fallback и не довольствоваться тестовым injectable
клиентом. Просим точную форму путей комплекта и указание, входит ли это
в C5 или должно отдельным окном предварять C5. Общий клиент должен быть
платформенным, без знания live/VMS; код продукта не нужен.
