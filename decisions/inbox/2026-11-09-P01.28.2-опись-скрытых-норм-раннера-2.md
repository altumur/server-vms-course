# P01.28.2. Вторая опись скрытых норм движков раннера

2026-11-09, представитель владельца (задача P01.28.2, ADR-0135; приём — Архитектор). Только чтение. Продолжение
[первой описи](2026-11-09-P01.28-опись-скрытых-норм-раннера.md) (59 пунктов, нумерация продолжена по разделам). Код —
раннер `cammeta-acceptance` на пине `bcb22c07`: `runner/l02.py`, `l04.py`–`l09.py`, `l07_tables.py`, `m11stand.py`,
`pass_stand.py`, `c_installer.py`, `openapi.py`, `portable/*.py`, реестр `c_targets.py`. Спека — `origin/main` `1e07fa457`:
`Platform/common/acceptance/{README,PROFILE}.md`, `common/acceptance/{pass,ops,system,tls}`, README приёмки P/02–P/10.

## Вывод

**Спека описывает словарь директив почти полностью.** Каждая директива, которую разбирают эти движки (`@start` …
`@stream-wait`, `@pass-*`, `@tls-*`, `@domain`, `@kit-start`, `@clusters`), названа в README (сверка grep по en-файлам
спеки: не нашлось только голого префикса `@pass`); смысл и часть сроков домена и стенда передачи (40 с шага,
`PASS_TICKET_CHECK` + 30 с, 90 с `@domain`, 10/20 с `@kit-start`) — тоже. Протокол загрузчика P/02 и правила установки — в README P/02. Скрытого здесь меньше, чем в P/01-части.

**Скрытое — в пяти местах:**
1. **Сроки ожидания движков** — около десятка чисел только в коде: HTTP-запрос 30 с, команды стенда 60/120/150 с,
   старт домена и второго экземпляра 30 с, вход `root` 30 с, стенд передачи 30/30/45 с, сокет роли 10 с.
2. **Правило «команда не ответила»** — какой код выхода — ответ реализации, а какой — авария стенда
   (таймаут, фатальный сигнал `128+n`, 126, 127) — только в `l06.py`.
3. **Заголовок `scenarios.tsv`** — у P/01 закомментирован (`#`), у P/03–P/10 — строка `scenario<TAB>step…`, которую
   движки пропускают по буквальному началу; в спеке правила нет, движки различаются.
4. **Расхождение кода со спекой в сравнении чисел**: README (словарь, `<code> <JSON>`) — число сравнивается по значению
   (`50` = `50.0`); `run.py` P/01 — различает `1` и `1.0`. Это поправка к пункту 2.1 первой описи («нет» → «расходится»).
5. **Среда прогона** (`portable/driver.py`): без сети, одна цель за раз, ворота нагрузки, повтор лёгкой цели один раз
   при признаке нагрузки, отношение «самая долгая операция / таймаут раннера» ≤ 1/3 — только в ADR-0083 и коде, в
   спеке приёмки нет. Для боевых проверок (ADR-0130) это и есть «объявленная среда».

**Счёт:** 34 пункта. «Нет в спеке» — 17, «есть частично / неоднозначно / расходится» — 6, «есть» — 8 (записаны, чтобы
автор движка не искал второй раз), наследие «решить» — 2, «проверить писателю» без оценки — 1. По разделам: 1 — 3, 2 — 6,
3 — 9, 4 — 3, 5 — 3, 6 — 2, 7 — 4, 8 — 4. В конце — черновик реестра целей P/02–P/10.
