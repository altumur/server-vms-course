## Исполнение (курс)

2026-10-17, команда курса. Ветка `codex/course-m10-request-parse`, код `c104437c2db77e5e8462c2761bd6fb182a4feba6`.
Влиты решения и текущая приёмка main до `3eafbb8e` (Н2.1, включая `39e4f5dc`); форма курса исполнена без изменения норм и TSV командой курса.

Дверь и NativeAPI различают ошибку формы и неверный ключ, проверяют команду в порядке Н2.1, отказывают при повторе имени поля JSON на любой глубине. Query разбирается по байтам: повторы проверяются раньше UTF-8, `%zz` сохраняется, `?key` — пустой ключ, префикс может обрываться внутри символа. Путь сравнивается буквально. Неразбираемый HTTP возвращает `400` Fault; неизвестные методы и пути — `404` Fault.

Для команд введён отдельный разбор JSON; общий `canonical.parse_json` типизированных документов не менялся. Нечитаемые поля не получают правил значений: одиночный суррогат и большие числа в лишнем поле допустимы, но повторы имён и не-JSON константы отказаны. В дверь без голоса передан тот же разбор для распознавания `id` перед повтором. NativeAPI продолжает исполнять настоящие File/Mem, без вызова машины и HTTP.

Рамка HTTP проверена пробами сырых байтов: obs-fold и пробел перед двоеточием — отказ, `chunked` при наличии `Content-Length` определяет тело. Превышение декодированного chunked-тела — `413` без `size`. Тело GET не разбирается. Исправлено завершение транспорта: после ответа отправляющая половина закрывается, входящие байты отбрасываются не более секунды; иначе игнорируемое тело GET и ранний отказ могли обрывать TLS между заголовком и телом ответа. Регрессия — 96 TLS-запросов (GET, неизвестный метод, превышение тела), также повторён существующий тест отзыва демона.

Пределы реализации описаны в `Source/README.md`: строка запроса 65536 байт с CRLF, блок заголовков 65536 байт с завершающим CRLF, 99 полей, вложенность JSON 64 контейнера вместе с корнем. Предел тела по умолчанию прежний; стенд приёмки задаёт 1048576, потолок строки 524288. В двух существующих тестах исправлены четыре точных ожидания Fault: добавлено обязательное `error`; проверки исхода, повтора и отсутствия побочных записей сохранены.
