# Ревью ADR-0091 (пятая редакция) — разбор

| Ревьювер | Ветка, коммит | Вывод |

Срез `9c8358d1a`. `not_after`, `keep` для всех удалений, `made.gone`, состояние надгробия, исполнитель уборки
закрыты. Новые блокеры — в точности новых правил, не в выборе:
- **две нестрогие границы** (Codex R91.5-01, Claude мелкое 4). Приём при часах лидера ≤ `not_after` и удаление при часах
  удаляющего ≥ `keep` совпадают ровно на допуске 60 с: опоздавшая копия встаёт в журнал после удаления. Решение:
  удаление — только при часах **строго позже** `keep`. Предпосылка часов — кластерная, в P/01.1 «Время», а не ссылка на
  держателей домена;
- **цикл id** (Codex R91.5-02). Поле-источник named id, само `fixed`, требовалось в `key` — id определялся через себя.
  Решение: источник id из требования исключён, библиотека заполняет его готовым id, шаблон по нему — отказ загрузчика;
- **неоднозначный `key`** (Claude Д-1). `{cam}-{rec}` у (`7`, `1-x`) и (`7-1`, `x`) — один id. Решение (предложение
  Claude): однозначность построением — подстановка кодирует `%` и `-`, между подстановками литерал `-`, `:int` только к
  целым.

Шестая редакция этим коммитом.
