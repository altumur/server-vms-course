# P/10: точный план исправлений после двух ревью

Основание: ADR-0129 (22), разбор `2026-11-07-ревью-P10-ADR0129-разбор.md`. Писатель spec103, исходный поток coord103-src; код и судьи отдельно coord103-tools. Это первое поручение на только для чтения план, не разрешение менять ещё не перечисленные файлы.

1. Выбрать точный составной источник и составить список собственных/связанных путей, блоков и пересечений. Прежние P03–P09 компоненты и текущие S08/wire-формы сохранить. Не копировать ветку 192b поверх нового источника.
2. По А показать полный нынешний producer input и все носители silent_after: обе member-ветви,35 векторов, объявления native/швов и read/codec. Указать точные входные/ожидаемые изменения и новые отрицательные случаи отсутствия; прежние отрицательные причины сохраняются. Корневые поля и импортированные сроки без отдельной декларации не менять.
3. По Б/Д/Е/Ж дать точный список request/response refs, пяти HEAD,21 операции внешних параметров и применений отказов с владельцами. Наружные заголовки не смешивать с доверенными служебными.
4. По В/Г описать текущие обязательные поля и положительные/отрицательные соседи. Схема не подменяет алгоритм, неизвестный дополнительный subsystem payload не закрывается произвольно.
5. По З составить карту всех самостоятельных числовых копий и механических carrier-связей. Новой формы/генератора нет. По И/К только описательный счёт/редакторская чистка и зеркала.
6. До изменений таблиц и связанного корпуса — декларации raw-строк/ячеек, заголовка и сохранённого префикса; собственные новые строки одного существующего класса отдельно. Крупные чужие общие файлы не захватывать.
7. Проверки своей доли — по готовой области. Архивы старых прогонов не наследуются как новые исполнения; errors/panic/partial не смысловые отказы. Полная проверка общего source+tools одна на main у tools. Урок не объявляется готовым из одного Python/schema результата.

После плана src сама согласует точную исходную область внутри решения. Новое вне ADR — Архитектору; работу по уже разрешённой части не останавливать. Оценку начала/срока своей доли включить в З-13; чужой внешний вход не выдавать за полученный календарный срок.
