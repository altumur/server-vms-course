# Шаг 9

Работой не проверено ничего.

## Внесено

- **Свёрнутая камера:** признак `source`, равный `cfw://local`; V/01.1, V/01.4, V/01.6 Н1.1, Н1.5, V/02.9 Н1.1.
- **Карта автоматически:** `rec/volumes/card` в `boot-rows.json`, консоль создаёт при старте, строка есть — не трогает. Держатель не может: `worker.creates` заводит только единицы; регистратор не может: до тома его нет; агент только применяет правки. ADR-0108 п. 3 закрыт.
- **Токен `stream`:** `lifetime` 315360000, `keep: true`, файл `tokens/stream-<ref>`. Прочие камеры коробки — в памяти, предел.
- **`OLD_KEYS`:** плановая смена без разрыва. Камера не взяла набор за 3600 с — после `until` приёмник отвечает `unknown_key`, толчок стоит до возврата домена, пишет карта: единственный случай, где молчащий домен останавливает толчок. Смена после кражи и перенос с `stolen` останавливают все токены домена разом.
- **V/08.5 Н1.2:** член-камера судится по числу единиц.

## Не внесено

- `cam.shell.html`: группа «Без сервера» и признак `source`: дерево домена страницы идёт по членам, чтение `source` стоит вызова на члена, до форка не окупается. Страница снимается ADR-0112.
- Слова `display.tree` «Папки кластера» в домене неверны, но на странице не видны, правка тянет вектор `plan-check`: дело форка.
- Автоправка квоты при замене карты.

## Вопросы к платформе

Ответы (main 010ab4f95) внесены: `keep: true` вида `stream`, `DELETE /domain/issued/…`, предел живых отзывов, `boot-rows.json`. Сроки `upstream`, `poll`, `ask` остаются сутками, принято к сведению.

## Сверх ADR

Имя тома `card`; просьба заново по `kid` ≠ `current`; снятая строка тома возвращается при загрузке, выключение — `enabled: false`; после отзыва снимать назначение.

## Замечания к V/11

`serverId`: ADR говорит «из `domain/placed/rec/<ref>`», V/11.3 берёт первый `Unit` записи на другом члене, при резерве на кластере с меньшим именем выйдет сервер резерва. `storage` свёрнутого только чтением: снимается контрактом форка. Строка потока с `main: 1` разворачивает член в сервер.
