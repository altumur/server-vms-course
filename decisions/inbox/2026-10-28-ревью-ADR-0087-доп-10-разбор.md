# Разбор ревью ADR-0087 доп. (10)

Отчёты: Kimi `42e313b78` (Б1, С1–С4, М1–М2, «с правками») и его дополнение по правке п. 1 `ce344593c` (Б2, С5, С6, М3), Claude `56affa69b` (Б-1, Б-2, С-1…С-9, М-1…М-3). После ревью
владелец заменил подход: переход по GREEN Go, Python — с нуля после перехода. Решения — ADR-0087 доп. (11).

| № | Находки | Решение |
|---|---|---|
| 1 | Claude Б-1, Kimi С1 — «та же подробность» и «шаг» не определены (путь `mkdtemp`, шаг/вариант/проба) | снято: опора — GREEN, реестра и сверки подробностей нет (доп. (11) п. 1) |
| 2 | Claude Б-2 — переход меняет входы `P/02.1/*`, `P/02.2/vectors` | принято: сверка по `inputs[].sha256` плана (доп. (11) п. 4) |
| 3 | Kimi Б1, Claude М-1 — `P/01.1/inproc` не исполняется у обеих | принято: «без опоры ни у одной реализации» (п. 1) |
| 4 | Claude С-1 — первый провал прячет 43 пробы `v1-base` | снято: GREEN требует все пробы; `P/02.5/rights` лечится до GREEN |
| 5 | Claude С-2, С-3 — «неустойчива» без повтора; красный → GREEN без правки | снято реестром; повтор одной цели на опорном кандидате — разбор, не прогон (пп. 1, 4) |
| 6 | Claude С-4, Kimi С2 — правка п. 3 сдвигает пин, исход предсказан | снято: дефекты корпуса и нормы лечатся до GREEN, опора наблюдена |
| 7 | Claude С-5, Kimi С3 — классы реестра, полнота реестра | снято вместе с реестром |
| 8 | Claude С-6, Kimi С4 — пин раннера в опоре не назван; опоры на разных раннерах | принято: опора — четвёрка с раннером; смена раннера — по фикстурам (пп. 1, 4) |
| 9 | Claude С-7, С-8, С-9, М-2 — опора Python (нет прогона, 8 таблиц, 10 сценариев) | снято: Python на период перехода остановлен и генерируется с нуля на В7 (пп. 2, 3) |
| 10 | Claude М-3 — ACC-P03-STANDS-PY-01 противоречит; доп. (8) п. 1 не помечен | принято: журнал утратил силу (п. 2); доп. (8) п. 1 (б) помечен |
| 11 | Kimi М1–М2 | сняты вместе с доп. (10) |
| 12 | Kimi `ce344593c` Б2, С5, С6, М3 — опора Go не переносится на Python (красный «реализация» Go + GREEN Python), нет базиса «было-стало» у Python, запасная опора `3963ef1` вне пина, форма реестра Python | сняты: Python опорой не сверяется — генерируется с нуля на В7 (доп. (11) пп. 2, 3); запасной опоры нет, опора Go — одна четвёрка на `23d8e38` (п. 1) |
