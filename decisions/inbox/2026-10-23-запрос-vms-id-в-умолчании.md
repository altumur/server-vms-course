# Запрос: подстановка id единицы в умолчание поля

**Какая норма мешает.** P/06.1 Н1.2 «Строка единицы», шаг 3 (`06.1-console.norms.md:153`): «Поле не передано и имеет
`default` — взять значение `default` из загруженного манифеста». Подстановки id выданной единицы нет; P/02.1 не
различает умолчание-шаблон и умолчание-значение.

**Что нужно VMS.** Камера без имени у свидетеля называлась `cam<id>`: `name: {type: string, default: "cam{id}"}`
(`Source/vms/cam.subsystem.yaml`, М10B/01 шаг 3; `new_row` подставлял выданный id). По P/06.1 камера без имени получила
бы буквально `cam{id}` — у всех одно и то же. Имя по id нужно в списке камер, дереве папок, снимке, домене (`view:
[name, …]`).

**Пример из VMS.** `POST /cameras {"source": "driverpack://file/door.mp4"}` → id 7 → у свидетеля `name: "cam7"`.

**Обход до решения.** V/01.1 Н1.1: у `name` умолчания нет (`VMS/01-cam/cam.subsystem.yaml`, строка `name`); камера без
имени хранится с пустым `name`, страница показывает её по id (V/08). Долг «Сборке»: продукт подставляет id сам.

**Рекомендация.** P/02.1 Н1.3: у поля `string` с `unit.id: numeric` умолчание может содержать `{id}` — дверь (P/06.1
Н1.2 шаг 3) подставляет десятичную запись выданного id при создании; `{id}` у `id: name` или в поле иного типа — отказ
загрузчика; иные `{…}` в умолчании — знаки как есть (или отказ — как решит платформа, лишь бы закрыто). Приёмка P/06.1 на
`testsub2` (или новом `testsub` с `numeric`): создание без поля → значение с id; правка не пересчитывает. Альтернатива —
отказ с обходом: VMS остаётся без умолчания.

## Решение
**Решён** (2026-10-23, «Архитектор»; текстовый запрос — без ADR, ADR-0090 доп. (1) «Нагрузка»). P/02.1 Н1.3: у поля `string` таблицы с `unit.id: numeric` умолчание может содержать `{id}` — дверь (P/06.1 Н1.2 шаг 3) подставляет десятичную запись выданного id при создании; правка значение не пересчитывает. `{id}` при `id: name`, в поле иного типа и любые иные `{`/`}` в таком умолчании — отказ загрузчика (закрыто, без экранирования). Приёмка P/06.1 — таблица с `numeric`: создание без поля → значение с id; правка не пересчитывает; отказы загрузчика — корпус манифестов. Нормы — «Спецификации»; VMS снимает обход при переходе на выгрузку с нормой.
