## Source map and canonical inputs

`2026-11-06-adr0121-common-source-map.tsv` records exact before/after strings as ASCII JSON strings, source paths, physical line numbers or TSV field names, categories and preservation scope. It covers modified source and mirror cells, references and checker code; new files are explicit additions. Before strings are from the baseline, after strings from this author delivery. Existing English protocol and selector words are retained unless the map explicitly records a common change. `2026-11-06-adr0121-common-preservation.json` records checked counts and the bounded VMS edits.

- `Platform/common/data/key-placeholders.tsv`: direct typed canonical input, 50 rows. The old Russian translation dictionary moved to `Platform/common/ru/placeholders.tsv` for human mirrors and is not a new-generation input. `<сервер>` of the RFC 1123 host grammar becomes `<host>`; existing `SERVER_NAME` `<server>` remains. Object path `<ключ>` becomes `<object-key>`; existing one-segment `<key>` remains. Pattern bytes and the set of acceptable instance keys are unchanged. Active catalogue references and matching family tags follow the same exact map.
- `Platform/common/data/outcome-units.tsv`: the closed shared vocabulary is `row`, `field`, `element`. The translation is `строка` → `row`, `поле` → `field`, `элемент` → `element`. All 168 outcome tables are migrated, 404 Platform values and 85 VMS values. Other cells are unchanged. Source and mirror generated normative tables use these same identifiers.
- Record kinds `row`, `object`, `file`, mode `writer`/`reader`, verdict `ok`/`refused`, peer selector reasons `no_role`/`wrong_role`, ask/op/grant and `prepare`/`move`/`alarm`, and events participant `console`/`worker` are preserved. No old/new fallback, runtime alias or broader enum is introduced. Source manual directives preserve `@manual`, command spelling, arguments, codes, expected messages and number sequence; only the explanatory language and placeholder spelling change.
- Root source paths and their mirrors become `NORMATIVE-TERMS.md` and `CONSOLE-MODULE.md`. coord103 changes `export.sh` in the same joint; the Architect changes course `CLAUDE.md` after merge. The full source language pass of `CONSOLE-MODULE.md` and console UI localization belongs to the subsequent console lesson delivery. The strict completed-slice list currently covers common and `NORMATIVE-TERMS.md`.

## Payload preservation and source form

`Platform/common/contracts/source-cells.md` defines the exact `# cell-json: name[,name]*` grammar. `Platform/common/vectors/source-cells/cases.json` has 29 valid/invalid source-form fixtures, including first data row, headerless tables, duplicate names, malformed JSON, non-string values, ASCII, unpaired surrogates, valid surrogate pair, exactly-once decode, retained inner JSON quotes, and valid outer encoding around deliberately invalid inner JSON. The latter remains a negative input for the existing semantic parser/SUT; the source reader does not parse or repair it.

`Platform/common/data/cell-json-sha256.tsv` proves equality of original and once-decoded UTF-8 bytes for all 351 declared cells across six tables. Source line numbers and row rosters are unchanged. Raw JSON text/JCS, AAD contexts, signatures, encrypted envelopes, tokens and expected outputs are preserved. Existing semantic JSON payloads outside these raw columns retain decoded values through JSON Unicode escapes; they are distinguished from raw-text columns in the source map. Raw source SHA and decoded-byte SHA serve different purposes. The literal U+000B payload in the log-mask vectors is preserved.

`source_cells.py`, `test_source_cells.py` and the shared fixtures judge source form and complete proof coverage. `en_mirror`/`check_spec` enforce it under ADR-0120 addendum (5), item 6. The generator and runner common reader is delivered by their owners through coord103, with the same exactly-once rule before wire/CEL/native; this source commit alone is not a runtime or implementation GATE.
