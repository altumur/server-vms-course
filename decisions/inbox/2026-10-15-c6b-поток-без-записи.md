# C6b: поток камеры без записи по требованию центра

## Контекст
Форма C6b: камера без записи за ретранслятором видна и просится из центра,
форвардер передаёт поток вверх. В курсе PollPush.entry() жёстко возвращает
push: false для такой камеры; CameraPusher._channel_pass подавляет даже
полученное от ingest желание зрителя. Полный тест C4 прямо проверяет отсутствие
байтов при живом зрителе (test_recording_poll_push). Книга upstream и токен
ретранслятора сами этот барьер не снимают. Ingest уже принимает poll-токен для байтов.

## Рекомендация
В C6b убрать локальное подавление push: false только у маршрута камеры без
назначения: poll-токен разрешает ровно её ref у подтверждённого poll_home, а
байты передаются лишь по актуальному желанию ingest. Режим polls_only оставить
для диагностики отсутствия зрителя. Перенести проверку C4: без зрителя — ноль
байтов; зритель центра — байты через домашний ingest и forwarder; после ухода —
остановка по LINGER. Назначенная камера с pull не меняется. Новых имён/полей нет.
