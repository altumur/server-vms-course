# Публичный API File/Mem для той же приёмки М10/1

## Контекст
Окно от ccfffb66: File/Mem имеют put без id, delete возвращает None; TSV требует replay и версию удаления. Провод уже исправлен отдельно: 98/98 шагов. Норма требует помнить id две минуты/50000 записей, но явно не определяет перезапуск файлового backend. Новый disk replay без решения не пишем.

## Рекомендация
Расширить публичный API optional id и возвращаемой версией delete; второй исполнитель переводит HTTP-нотацию TSV в эти вызовы, без повторной реализации CAS/guard/id. Для File выбрать долговечный replay в одном атомарном record с изменением строки (предлагаем существующий row-envelope дополнить replay, удалённые строки хранить tombstone); Mem — та же семантика в памяти. Такая форма сохраняет повтор после сбоя между записью и ответом. Просим определить форму либо явно ограничить replay временем жизни процесса; до решения новый диск-контракт не реализуем.
