# Публичный API File/Mem для той же приёмки М10/1

## Контекст
Окно от ccfffb66: File/Mem имеют put без id, delete возвращает None; TSV требует replay и версию удаления. Провод уже исправлен отдельно: 98/98 шагов. Норма требует помнить id две минуты/50000 записей, но явно не определяет перезапуск файлового backend. Новый disk replay без решения не пишем.

## Рекомендация
Расширить публичный API optional id и возвращаемой версией delete; второй исполнитель переводит HTTP-нотацию TSV в эти вызовы, без повторной реализации CAS/guard/id. Для File выбрать долговечный replay в одном атомарном record с изменением строки (предлагаем существующий row-envelope дополнить replay, удалённые строки хранить tombstone); Mem — та же семантика в памяти. Такая форма сохраняет повтор после сбоя между записью и ответом. Просим определить форму либо явно ограничить replay временем жизни процесса; до решения новый диск-контракт не реализуем.

## Уточнение API до кода
Один возвращаемый Index не позволяет исполнителю увидеть нормативный again:true. Рекомендуем общий публичный write(cmd)→receipt с index и again, а put/delete — как интерфейс обычных платформенных клиентов. Receipt приходит от backend, не вычисляется и не кэшируется в тестовом исполнителе. Конкретную форму команды/receipt и атомарного disk-record нужно принять до реализации; новый метод пока не написан.

## Решение («Архитектор», 2026-10-14)

1. **Публичный API File/Mem**: `write(cmd) → receipt{index, again}` — receipt от backend, не от исполнителя; `put`/`delete` — обёртки над ним без своей памяти; `id` необязателен; `delete` возвращает версию (урок М10/1 Н1, Н3). Исполнитель TSV переводит HTTP-нотацию в эти вызовы, CAS/guard/id не повторяет.
2. **Память повторов — со сроком жизни процесса, не на диске.** Н3 требует минимум (две минуты / 50 000 записей) и говорит, что забытый повтор применяется как новая запись, — для того у значимой записи `cas`; «Решает реализация» п. 6 отдаёт срок и объём сверх минимума реализации. Долговечный replay-record и надгробия у File не вводить: это третий носитель истины рядом со строкой и её версией. В описании реализации File и Mem (п. 6) — слова «память повторов живёт с процессом». Продукт здесь иной (журнал raft переигрывает `done` после рестарта) — расхождение реализаций, не нормы; в ХОД не идёт.
