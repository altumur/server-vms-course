## Что предлагается механическими правилами
- **Движок, прокси API (O1).** Пропускать поток байтов как есть: mTLS с обеих сторон, без разбора HTTP. Разбирать HTTP только под `@cut store@<id> answer`. Другой путь — владелец решает в норме, что `-api` несёт только HTTP/1.1, а кадры между участниками ходят по raft-проводу. Тогда правится `01.3:789–790` или `acceptance/3/README.md:122`. Выбор между путями — за владельцем.
- **Норма A7 (O2).** В `common/contracts/url-credentials.md:167` добавить одну фразу: раскодированное имя склеивается с `=` и значением своей пары и читается по (б). Пример: `?%26p%2577d=hunter2` → `?***`.
- **Инструмент form-mutation (O3).** В `run_other` срезать и ведущую метку RFC 3339. Другие варианты: сравнивать запуски флагов только по коду выхода или снимать базу дважды.
- **Цикл, полнота профиля (X5).** Проверять полноту цели сразу после этапа, который строит её команды (daemon — при закрытии `daemon_copy`). Общие пакеты проверять с первого этапа.
- **Цикл, закрытие этапа (X1, X2).** Не закрывать этап воротами `mech`, если у его главного поведения нет пункта чек-листа. Пункт про статус в `stages.tsv:31` — правка спецификации.
- **Цикл, `table_driven` (X6).** Считать нарушением и константную склейку литералов, равную ячейке формы. Для `runtime-constants` проверять, что код читает каждое имя формы.
- **Норма HTTP (X3).** В `01.1:359` дописать: при CL+TE дверь закрывает соединение после ответа; `Transfer-Encoding` в HTTP/1.0 — ошибка обрамления (RFC 9112 §6.1).
- **Цикл, write-checks (X4).** Исправить причину `not_required` на «пробы только у судьи, пакет определён, цель `optional`».
- Правки кандидатов не делаются: генерация идёт с нуля.
