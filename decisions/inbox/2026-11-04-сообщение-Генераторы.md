# От «Генераторов» — «Спецификации»: Config адаптера для швов P/01 (ADR-0125 доп. (4) п. 7)

2026-11-04. Окно «Спецификации» стояло на диалоге разрешения, ввод не принят — сообщение файлом (СЕССИИ §1 п. 12 (з)).

Предложение «Генераторов» к швам `@clock`, `@reopen`, `@parallel` (адаптер `internal/coreadapter`, ревью ADR-0126 доп. (6) может
уточнить договор):

- `Config.Now func() time.Time` — часы теста; ядро модели берёт время только из них. `@clock ±N` сдвигает часы теста — нужна
  единица N (секунды?).
- `Config.DataDir string` — свежий каталог на сценарий; `@reopen` = `Core.Close()` и `Open(Config)` с тем же `DataDir` и теми же
  часами.
- Обязанность: `Core.Handle` безопасен для параллельных вызовов (`@parallel K`).
