## Что изменено

299 действующих R-id сведены к 191 абзацу. 59 групп соединяют смежные части одного предмета: 30 групп по два пункта, 12 по три, 14 по четыре, три по пять. Остальные 132 пункта самостоятельны. Из 66 внешне упомянутых id группа сохраняет первый в порядке текста, иначе — первый действующий id. Новых номеров нет. 108 снятых id направлены прямо на живые id в `decisions/journal/platform/05-resource/req-id-map.tsv`; каждому соответствует дословный прежний текст в `history.tsv`. Цепочек и надгробий в M для этих id нет. У двух прежних строк истории изменён только адрес переименованного раздела векторов `#shorttsv` → `#shortfall-vectors`; прочие клетки сохранены побайтно.

Сохранены границы новой записи, копии и нечитаемого надгробия; ресурса и merger; общих полей пульса и начального состояния. Шесть шагов query и фазы retain → usage → relieve → mirror не соединены. Ссылки на слитые id переведены в собственных инструкции и README форм и в четырёх ячейках `norm` формы `decision-order.tsv`. Снятые id искались по всему `Platform/`, включая другие уроки. Вне P/05 таких изменяемых ссылок не оказалось: соответствующие внешние id сохранены. Синтаксис CEL, порядок и исходы формы не менялись.

Сняты лишние ссылки на закрытые сценарные описания, seams, схему таблицы и человеческую опись, затем их пометки. Обязанности, формы входов векторов и наблюдаемая область приёмки сохранены. Указатель содержит прежние 29 многоместных тем: после применения карты id удалены повторы и восстановлен порядок, но темы форм, разных разделов и внешних договоров остаются.
