# Исходы двери ретранслятора над своей памятью — справка у свидетелей и решение

Свидетели на `d27f95d`: Python `fd7fe87` (`impl/m11domain/relay.py`, `member.py`), Go `018e4b8` (`domain_relay.go`,
`domain_accept.go`, `transport.go`). Читал «Архитектор» (через агента); генераторам стадии C эта справка не передаётся —
только норма.

## Что делают свидетели
| Исход | Python | Go |
|---|---|---|
| `same_sent_at` | 409 `refused`, reason `same_sent_at`; сравнивает с хешем последнего **поколения**, `heard` хеш не обновляет | 409, reason `same_sent_at`; хеш тела пишется на **каждой** записи метки (поколение и `heard`) |
| принять: `not_ready` (в целом нет `<sub>/snapshot/*`) | 409, reason `not_ready` | 409, reason `not_ready` |
| нет ответа держателя | 503 «the relay has nothing from the domain for <член> yet», без reason; незнакомцу — **после** записи стука | то же слово; 503 до проверки подписи и **без стука** (как норма Н3) |
| 413 транспорта | по `Content-Length` до чтения тела, 16 MiB, `{error: refused}` | то же условие; тело — общее слово двери консоли |
| принять: `whole_too_large` | 413? — нет: `refused`, reason `whole_too_large` | `{error: "whole too large"}` без reason |
| `rev_exhausted` | 503, reason `rev_exhausted` | 503, reason `rev_exhausted` |
| неверный метод | 404 (или 501 stdlib) | 405 |
| `Retry-After` | нет | нет |

`detail` у двух свидетелей различаются почти везде; `reason` совпадают.

## Решение (вносит «Спецификация», P/09.2 Н2, Н4 и OpenAPI 09)
1. Отказы двери ретранслятора — `{error: "refused", detail, reason?}`; **нормативны статус и `reason`**, `detail` —
   слова реализации (кроме двух уже названных нормой текстов 403 и 503).
2. Исходы «принять» над своей копией (общая функция с держателем, P/08.3 Н4) проходят через дверь с тем же `reason`:
   409 `same_sent_at`, 409 `rebase`, 409 `not_ready`, 413 `whole_too_large`, 503 `rev_exhausted`.
3. `same_sent_at`: тот же `sent_at`, иное тело, чем у **последней записи метки** — хеш тела пишется на каждой записи
   (поколение и `heard`); точный повтор — ответ копией (поведение Go; Python здесь отступал).
4. 413 транспорта — по `Content-Length` до чтения тела, предел `BODY_LIMIT` (16 MiB), `{error: refused}`, соединение
   закрывается; chunked — 400.
5. 503 «нет ответа держателя» — до проверки подписи, без стука, и незнакомцу (Н3 уже так; Python отступал).
6. Неверный метод — 405; `Retry-After` дверь не ставит.
7. Сценарий приёмки урока 09 — `same_sent_at` после `heard` (повтор байт в байт — 200, иное тело — 409).
