### Уточнение («Архитектор», 2026-10-15, по замечанию автора): слияние — после поправки 1; образец `asks` продукта

По просьбе команды слияние `7fb7c8ae` **откладывается до поправки 1** (форма `asks`); остальное решение в силе.
Образец объекта `asks` в пульсе `autoworker` продукта — байты `autoask/asker.go` (`consider`, `settle`, `note`, `Stats`):

```json
"asks": {
  "<имя сценария | #N>": {
    "why":     "no camera <триггер> in this cluster",
    "holding": {"<источник>": "<почему окно событий неполно>"},
    "last":    "<строка>",
    "asked":   1760540000.123
  },
  "refused": {"<имя | #N>": "<почему документ не подходит>"}
}
```
Правила: в `asks` — только сценарии документа, чей триггер — камера этого кластера (`book`, asker.go:122–125); сценарий,
ушедший из документа, уходит из объекта (`delete(a.status, id)`). Поля состояния: `why` — string, ставится, когда камеры
триггера в кластере нет; `holding` — объект `{источник: причина}` (`Incomplete` запроса к merged log, `map[string]string`),
**снимается**, когда окно стало целым; `last` — string, одна из: `"an event seen after its scenario's deadline: not asked"`,
`"over its ceiling of <N> a minute: not asked"`, `"the book of asks names no door for <цель>: not asked"`,
`"no token at <кластер>: <почему>"`, `"refused: <почему>"` (слово ingest), `"asked; the ingest's answer does not read, so its
outcome is not followed"`, `"no ingest answered"`; после `settle` — исход ingest как есть (`performed`, `refused: …`) или
`"lost: no ingest knows this ask — it restarted, or the ask never arrived"`, `"lost: the ingest's answer does not read"`,
`"lost: the ingest does not answer"` (после `deadline + AskGrace`); `asked` — number, unix-секунды последней отправленной
просьбы. `refused` — только при непустом; других полей нет. Ожидающие исходы — через `Asker.outcome`, как предлагаете.
