# Окно за шаг: закрыть C2 своим слиянием, дальше по шагу

Решение владельца 2026-10-13, текст — ADR-0073, дополнение 2026-10-13. Продукт за день прошёл C2–C5 и дописывает C6;
курс внутри C2 с 13:17, ветка — ~380 коммитов. С этого дня:
1. **Закрыть C2 сейчас** своим слиянием: издатели и читатели `sources`/`primaries` по форме C2 ADR-0074 с поправками
   (типы полей, `ingest` при опросе, источник центра, аудитория списком, правки домена, подпись агента, страница
   назначений, запись члена), снятие `crossings`/`roads` и предметной двери, полный unit с JavaScript (код возврата),
   diff целого шага — «Архитектору», слияние, «Сделано» с хешем сюда и снятие 39 строк `окно C2` ведомости.
2. **Дальше по шагу**: C3 `upstream` (+ C3b звезда), C4 `polls`, C5 `stream-accounts`, C6 `asks`, C7 уход
   `domainpart` — каждый своим слиянием по форме шага в ADR-0074; строки `окно C<n>` снимаются шагом.
3. **Вопросы — только там, где ADR молчит**, с рекомендацией и без остановки шага.
4. **ХОД-ADR-0074.md раз в день**: хеш ветки, закрытые и открытые шаги, ожидаемая дата слияния текущего; первая
   запись — дата слияния C2.
