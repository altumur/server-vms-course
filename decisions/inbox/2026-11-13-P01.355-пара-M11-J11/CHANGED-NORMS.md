# Изменения норм

## M10 → M11

Сравнены английские источники двух входов. Ниже перечислены все изменённые абзацы с R-id, пункты перечней и файлы M. Перенос договора и изменение обязательства обозначены отдельно.

| Абзац | Изменение |
|---|---|
| P/01.1-R148 | К обязанности инкрементальной записи добавлены цели BUDGET_WRITE_P99, BUDGET_WRITE_GROWTH и BUDGET_WRITE_BYTES на объявленной нагрузке и ресурсах. |
| P/01.1-R371 | Импорт обязан выдерживать BUDGET_IMPORT_ORDINARY, BUDGET_IMPORT_WORST и BUDGET_IMPORT_GROWTH; прежняя фраза об отсутствии числового потолка заменена ссылкой на цели. |
| P/01.2-R008 | Вместо локального блока pattern дана ссылка на общий договор образцов прав. |
| P/01.2-R010 | Алгоритм allowed перенесён в общий договор; запреты и исключения хранилища остаются в уроке. |
| P/01.2-R054 | Правило отсутствующего delete берётся из общего договора; результат остаётся пустым списком разрешений. |
| P/01.2-R055 | Сопоставление образцов и приоритет отрицания берутся из общего договора с прежним смыслом. |
| P/01.3-R420 | Новый боевой абзац: завершение и публикация backup в пределах BUDGET_BACKUP_ORDINARY/WORST; BUDGET_BACKUP_STALL для параллельных чтений и записей при остановившемся получателе. |
| P/01.3-R421 | Новый боевой абзац: штатная остановка и освобождение ресурсов в пределах BUDGET_STOP, ниже срока менеджера; принудительное убийство цель не закрывает. |
| P/01.3-R422 | Новый боевой абзац: после аварии обычное чтение и запись возобновляются в пределах BUDGET_REOPEN, с сохранением подтверждённого состояния; отдельное административное восстановление исключено. |
| P/01.3-R423 | Новый боевой абзац: перезапущенный член догоняет группу и возвращается здоровым за BUDGET_MEMBER_RETURN при восстановленной связи и жизнеспособном кворуме; id и membership сохраняются. |
| P/04-R164 | Реализация объявляет канал запроса rebalance, вызывающего и бюджет; боевая квалификация измеряет выполнение по этому бюджету. |
| P/04-R437 | Число сценариев и шагов приёмки контроллера изменено с 37/533 на 40/575. |
| P/04-R452 | Число CALL-швов приёмки контроллера изменено с 50 на 63. |

Маркер COURSE_COMMIT изменён как служебная идентичность источника; он не меняет норму. Сценарии, таблицы ожидаемых векторов и процедуры боевой квалификации остаются вне M. Цели производительности в M не означают, что соответствующие измерения уже выполнены.
