## Сохранность сведений и исходов

В каждой паре английского и русского пакета `README.cases.md` хранит семантическое тело прежнего README **целиком и дословно**, начиная с первого абзаца после шапки происхождения. Исходная шапка происхождения также сохранена в разделе Source metadata / «Метаданные источника». Новый README извлекает из этого текста общий интерфейс; смешанные блоки в J намеренно не разрезаны внутри предложения. Повторение общего контекста в J позволяет сохранить исходы и их условия без перефразирования.

Поэтому объединение двух файлов сохраняет все прежние сведения: ни один исход, предел, условие, оговорка о непокрытой проверке, история или комментарий к случаю не исчезает из J. Проверка дословного включения исходного тела сильнее выборочной сверки чисел и имён. Она не доказывает семантическую чистоту публичного извлечения; её проверяет чтение diff по таблице выше.
