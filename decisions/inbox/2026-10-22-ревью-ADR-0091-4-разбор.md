# Ревью ADR-0091 (четвёртая редакция) — разбор

| Ревьювер | Ветка, коммит | Вывод |
|---|---|---|
| Codex | `codex/review-adr-0091-4` `222140ef7` | с правками: 2 блокера, 1 существенная |
| Kimi | `kimi/review-adr-0091-4` `046a515a7` | годно: 1 мелкая |
| Claude | `claude/review-adr-0091-4` `beb75c563` | с правками: 2 блокера, 1 существенная, 4 мелких |

Срез `8c6b0b96f`. Порядок уборки, новая жизнь по `born`, видимость, чтения, маска, префиксы закрыты всеми тремя.
Блокеры — в удержании личности исполненного заказа и в физическом удалении:
- **удержание по сроку без предела доставки** (Codex R91.4-02). Запись, принятая в путь до конца окна, применяется
  после `keep` и создаёт исполненную задачу снова; никакой срок без барьера при применении этого не закрывает.
  Решение: **новое общее условие записи хранилища `not_after`** (P/01.1) — лидер принимает запись в журнал, только пока
  его часы не позже `not_after`; заказчик ставит `at` + `valid_for` + 60, `keep` = `at` + `valid_for` + 120. Принятая
  вовремя запись стоит в журнале раньше удаления и проваливается на CAS; опоздавшая — `expired`. Альтернатива —
  надгробия строк заказа навсегда — отвергнута: рост без предела, против ADR-0067;
- **удаление в обход `keep`** (Codex R91.4-01): `worker.deletes` адресата. Решение: `keep` — для любого физического
  удаления, проверка и в библиотеке;
- **физическое удаление против ADR-0067** (Claude Ч-2): у `detjob` (`fixed` `cam`, `rec`, `about` по `cam`)
  `delete_after` не грузится; у `rec`, `det` освобождённое `auto-7` оператор занимает другой камерой. Решение
  (рекомендация Claude, первый вариант): id — `<заказчик>-<key>`, шаблон `key` называет все `fixed` и поле `about` и
  однозначен; дверь отвергает id с префиксом заказчика; физически удаляются только строки с `made`. Поправка ADR-0067
  доп. 2026-10-10 названа в ADR-0091;
- **у надгробия строки единицы нет времени** (Claude Ч-1; Codex R91.4-03 — допуск часов). Решение: дверь ставит
  `made.gone` при удалении строки с `made`; запись над надгробием — только событием позже `made.gone` + 60, событие в
  этой минуте считается прежним (сознательное сужение).

Пятая редакция этим коммитом.

## Порядок
1. Этим коммитом — разбор, ADR-0091 (пятая редакция).
2. Повторное ревью трёх — только изменённое (п. 1: `not_after`, `keep` для всех удалений, `key` и отказ двери,
   физическое удаление только строк с `made`, `made.gone`; п. 3: надгробие, исполнитель уборки, снимок); если
   блокеров нет — ADR принимается, Т-правка «Спецификации» одной выгрузкой.
