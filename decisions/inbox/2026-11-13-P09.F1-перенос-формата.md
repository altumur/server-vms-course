## Результат

Нормы двух глав собраны в смысловые абзацы. В главе 9.1 осталось 426 якорей из 737, в главе 9.2 — 110 из 171: всего 536 из 908. Группы смежны, не пересекают заголовки, смену роли, режима, фазу процедуры или область production. Соседние правила разных ролей оставлены отдельно: например, отчёт агента, хранение у держателя и чтение книгой; формирование knocks ретранслятором и проверка держателем. Число снятых id не служило целью.

Абзац сохраняет первый внешне упомянутый id в порядке текста, иначе первый id группы. Внешние диапазоны сначала развёрнуты: за пределами двух норм и их переводов адресованы 819 различных id; подсчёт только буквальных концов диапазонов дал бы 429 и пропустил бы обращения из stages. Для 372 снятых id создан `decisions/journal/platform/09-agent/req-id-map.tsv`; каждый получил строку истории с дословным исходным текстом, прежние строки истории сохранены. Цель карты жива в той же главе; цепочек и новых надгробий в M нет.

Все обращения к слитым id в собранных M/J переведены по карте; диапазон разворачивается до проекции, повторы полученных id снимаются. В файлах других уроков нет обращений к id итоговой карты: поэтому эти файлы не правились. Пять машинных форм урока менялись только такой проекцией ссылок: flags, refusals, constants и две stages. Для обеих stages все прочие клетки, комментарий и заголовок сохранены. Для 96 защищённых пунктов чек-листов источника и перевода, включая инструкцию и закрытые описания, сохранены все байты вне проекции R-id; изменились ссылки у 86 пунктов.

## Отзыв о процедуре

Предыдущая крупная раскладка пригодилась как опора для соседства, но не как готовая карта: длинные исходные пункты пришлось разрезать по роли, режиму и фазе. Для P/09 необходимо разворачивать диапазоны stages до выбора якоря; подсчёт концов диапазонов занижает число внешних адресов. Переводы выровнялись с английскими блоками во всех разделах, поэтому слияние не потеряло русские определения. Защищать нужно каждый пункт чек-листа с продолжениями, а не весь хвост документа: между пунктами бывает обычная ссылка на закрытый N5. История перенесённого YAML помогает отдельно сверить каждое прежнее условие; зелёная структурная проверка такую смысловую сверку не заменяет.
