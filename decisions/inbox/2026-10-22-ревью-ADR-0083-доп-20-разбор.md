# Ревью ADR-0083 доп. (20) — разбор и решения

Срез `9ac51bc60`. Блокеров нет. Выбор — дверь с необязательным запросом проверяет предъявленный лист — не оспорил никто:
это общее подмножество стеков, у двери роли P/10 так уже. Codex пробами подтвердил исполнимость (Go 1.22, 64 сочетания;
Python 3.13/OpenSSL 3.5, 32 сочетания). Пробелы — довод (nginx), вход пробы (клиент может не предъявить лист),
Confirmation (двух строк мало), закрытость набора проверок, отзыв и `sig`, слушатель целиком, клиенты из других
кластеров, P/03.7. Claude поставил вопрос «оба исхода допустимы» (С-5); владелец выбрал вариант «2 уточнённый».
Решения — ADR-0083 доп. (21) этим коммитом.
