# Свой диалект норм или JSON Schema 2020-12 и CEL (вариант В7) — после стадии C

## Решение владельца 2026-10-27
- Стадия C доводится на нынешнем диалекте (ADR-0087, 0088, 0089) — архитектура норм посреди генерации не меняется.
- Вариант В7 (формы — JSON Schema 2020-12, связи — CEL, остальное — отдельными слоями) решается **после стадии C**, до
  старта VMS и сборки целевого продукта; вопросы 1–13 записки — тогда же.
- До решения — **независимая перепроверка записки своими стендами** (README каталога, пп. 1–5): Claude и Kimi;
  ответы — файлами `review-<кто>-<дата>.md` рядом с запиской.

## Почему не сейчас (совет «Архитектора»)
- Предмет В7 — около трети догадок стадии C (форма, YAML, связи, канонический вид); они пришлись в основном на уроки
  01–02, где уже GREEN. На уроках 03–10 две трети догадок — поведение договоров, его В7 не касается.
- Переход посреди стадии C — пересборка загрузчика 02 и чтения семей данных во всех уроках, повтор GREEN.
- Полный выигрыш В7 — на новых уроках VMS, продукте на Go и третьем языке.
