# Задача «Спецификации»: спецификации М10 без ссылок на код реализаций

## Контекст
Владелец (2026-10-17) поручил проверить, что спецификации курса не ссылаются на код Python, Go и каталог
`vmssubsystem`. Правило уже есть: `М10_Platform/module-design.md:16` — «Кода реализации нет… Python или Go — нет,
даже цитатой». Проверка «Архитектора» на main нашла нарушения; владелец принял исправление пунктов 1 и 3.
Ссылки на `Source/tests/testdata/acceptance/` и `testsub.subsystem.yaml` (пункт 2) не трогать: о размещении
реализации Python решает владелец отдельно.

## Что исправить

**1. Код и пути реализаций.** Заменить дверью, CLI или контрактом модуля консоли:
- `М10_Platform/spec/06-rights.norms.md:154` — `python -m w2cplatform.cluster rights`: оставить только команду
  установщика, которую норма задаёт (`w2cctl rights …`), без способа её реализации.
- `М10_Platform/spec/09-the-console.norms.md:342` (М10/9-06) — доказательство через `Source/tests/console/`:
  назвать предмет чтения (вызовы модуля и их порядок по `КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md`), без пути к тестам курса.
- `М10_Platform/module-design.md:23` — `Source/w2cplatform/console.js`: источник путей дверей консоли —
  контракт `КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md` (ADR-0005).
- `Source/tests/testdata/acceptance/М10_Platform/07/secret_in.tsv:1–7` и `log_mask.tsv:1–4` — шапки называют
  `Source/`, Python, `vmsworker/vms/secret_in_test.go`, `tests/test_credentials.py`, Go-имена (`Rule.MaskLog`,
  `w2cplatform.MaskText`, `ipint/uri.Redact`), `ipintd`. Шапка описывает таблицу (что в столбцах, кто её читает:
  «любая реализация»), без имён файлов и функций. Данные строк не менять; продукт заберёт байты `sync-course.sh`.

**2. Названные реализации в нормах.** Переписать в форме «любая реализация»; где различие реализаций нужно для
понимания (лекция), — без языка и имени дерева:
- `02-the-spec-and-the-strict-loader.md:19` («Python курса и Go продукта»);
- `Source/tests/testdata/acceptance/М10_Platform/01/README.md:12` («у курса — unix-сокет…, у продукта — дверь
  `configstore`»): дверь урока 1 Н2, способ подключения — параметр стенда;
- `spec/01-storage.norms.md:17` («ARCHITECTURE продукта, записка курса») → «описание реализации»;
- `spec/06-rights.norms.md:98` («у продукта отметки нет»), `spec/07-secrets-and-sealing.norms.md:332`
  («конверт v2… по продукту»), `08-events-resource-requests.api.openapi.yaml:7`, `spec/08-…norms.md:658`,
  лекции 6 (`:58`) и 7 (`:45`), README приёмки 3 (`:28`) и 7 (`:104`), `М10_Platform/README.md:3`.
  Состояние внедрения в конкретной реализации — не норма: ему место в `ХОД-Спецификация.md` или записи окна.

`module-design.md:12` («Go-продукт как дошедшая реализация» в старшинстве источников) — правило написания, не
норма; оставить.
