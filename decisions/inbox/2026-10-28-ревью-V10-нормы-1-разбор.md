# Разбор ревью норм V/10 (круг 1)

Отчёты (архив — `decisions/inbox/ревью/`): Claude `ca1140c56` (0 блокеров; С-1…С-7), Codex `b40b16f77` (RV10N-01, 02 —
блокеры; 03–06 — существенные). Предмет — ветка `vms/10-assist-plan` `598d44bcd`. Правит «Спецификация VMS».

| № | Находки | Решение |
|---|---|---|
| 1 | Codex RV10N-01 (блокер), Claude С-5 — неизвестный исход: чтение маски и `revision` не доказывает `applied`/`unwritten` | после неизвестного исхода: правка содержит поле `*_secret` — исход `unknown` (секрет чтением не подтверждается), если нет иного свидетельства; `revision` = план + 1 и все несекретные поля = `to` и секретных полей нет — `applied`; `revision` = плану — «результат ещё не наблюдался», разрешён только явный повтор с прежним CAS; окончательного `unwritten` нет |
| 2 | Codex RV10N-02 (блокер), Claude С-6 — приёмка опирается на скорость переходов | заглушка держит фазу управляемым барьером (директива файла ответов или шаг сценария снимает барьер); перед `ahead: 0` — наблюдать `running` у первого шага; механизм окружения заглушки на сценарий (`/etc/assist/assist.env`), подстановки `{model_stub}`, `{spec}` — в словарь приёмки; `load 15` против `@until 30` — согласовать; `03-owner` шаг 17 — ожидание `/session` `ann` |
| 3 | Claude С-1 — долгий опрос на keep-alive и PACE_FLOOR P/03.4 Н1.7 | ответы ожидания и 202 — `Connection: close` (константа урока) |
| 4 | Claude С-2 — `/health` llama.cpp 503 при занятом слоте | норма: пока модель считает шаг, проверка здоровья держателя не считает это отказом (200 или 503 с занятым слотом — живой); три отказа — только вне шага |
| 5 | Claude С-3 — `rights.routes {view: [chat]}` ничего не делает | снять; ADR-0093 доп. (2) п. 4 уточнён: доступ — токен двери по `view` на строку модели, `rights.routes` не нужен |
| 6 | Claude С-4 — ёмкость 1 против `CAPACITY` роли | `CAPACITY` ≠ 1 у роли модели — отказ старта, код 2 |
| 7 | Claude С-7 — чистота общего префикса | норма главы V/10.3 (после пакета харнеса): в общий префикс — только системный текст и описания инструментов, обзор с правами — нет |
| 8 | Codex RV10N-03…06 — OpenAPI: `StepId` и точка в имени, сервер HTTPS комплекта роли, `StepState` по ветвям, `Message.content` в запросе | принято по рекомендациям Codex |
