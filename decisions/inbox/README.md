# Входящие к ADR (ADR-0073)

Сюда команда лекций кладёт вопросы, предложения и возражения по решениям из `decisions/`. Один файл — один вопрос,
один коммит — один файл. Имя файла: `ГГГГ-ММ-ДД-<одно-два-слова>.md`. Папка `decisions/` выше для команды только на чтение.

Ответ «Архитектора» приходит коммитом: раздел «Решение» в этом же файле. Принятое уходит в ADR или дополнение к нему,
отклонённое получает причину; после этого файл удаляется, история остаётся в git. Молчание не значит согласие:
пока раздела «Решение» нет, решения нет.

## Форма

```markdown
---
kind: вопрос | предложение | возражение
adr: 0019, 0070
date: 2026-10-12
author: имя или команда
---

# Одна строка: о чём

## Контекст
До ста слов: что делали, где упёрлись, что видели (хеши, файлы, строки).

## Рекомендация
Обязательна: что предлагаете сделать и почему. Вопрос без рекомендации возвращается.

## Решение
(пишет «Архитектор»)
```
