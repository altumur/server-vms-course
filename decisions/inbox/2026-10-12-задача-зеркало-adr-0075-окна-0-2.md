# Задача команде: зеркало окон 0–2 ADR-0075 в курсе (продукт — main 1ace733)

Форма — ADR-0075 и его дополнения 1–4 (читать целиком; код продукта не читать — правило 15). Продукт прошёл окна 0, 1, 2;
курс зеркалит там, где у него есть провод.

## Окно 0 (без TLS)
Условные умолчания закрываются (ADR-0012): ворота консоли без `domain/keys` пускают только с петли — по адресу соединения
(пустой адрес — сокет или вызов в процессе — петля), не по заголовку; door-токены без `door/keys` — отказ вне петли
(WHEP, `/timeline`, `/segment`); playback вне домена — отказ вне петли; `AUTH=0` у консоли домена и `domainpart` убирается;
заголовки `X-User`/`X-Operator` снимаются всегда. Умолчание адреса 127.0.0.1 у подписанта, консоли домена, ретранслятора,
`domainpart`; вне петли — только по явному адресу с громкой строкой в журнале. `SIGNER_UNIX` и прочие сокеты — 0660 под
маской 0177. Правка держателя в свою консоль — его агенту, 202, подпись агента.

## Окно 1 (комплект роли, ресурс)
`tls.py`: комплект роли `W2C_TLS_DIR/<роль>/server.{pem,key}` с общими `ca.pem` и `revoked`; одна роль на сертификат, SAN URI
`urn:w2c:role:<роль>` ровно один, CN `<роль>.<сервер>`, SAN DNS `<сервер>`; `W2C_ROLE` у каждого процесса курса; без комплекта —
сервер только на петле, клиент только `http://`, `https://` без комплекта или по IP — отказ с причиной; хранилище читает
свой комплект из `tls/configstore/` (старая раскладка — отказ со словами). Ресурс: `-tls` (`RESOURCE_TLS=1`) — любой адрес и
обязательный сертификат клиента с таблицей ролей (`/events*`, `/buckets/`, `/mirrored/` — `console`, `resource`, `domain`,
`domainconsole`, `autoworker`, воркеры по спекам; `PUT /mirror/` — `resource`; `/v1/objects` и `/metrics` — любая роль);
без `-tls` — только петля, иной адрес — отказ старта; клиент сверяет роль `resource` и имя сервера; `/events/wait`
вытесняет по CN + `client=`; биение ресурса `door {addr, mode: loopback|mtls, cert_until}`.

## Окно 2 (рекордер, воркер)
Две двери рекордера: публичная (токены двери и камер, `/healthz`, `/metrics`) и между процессами (`/spans/`, `/samples/`,
пиры ingest там, где у курса есть провод) — mTLS роль `recworker`, без TLS только петля; биение рекордера — `peer_url` (слово
спеки `rec`: `heartbeat.strings[peer_url]`, строка ведомости `product-only … # ADR-0075 «продукт»` уже стоит — курс кладёт
слово и снимает строку) и `door {…}`; ключ члена у рекордера не читается. Playback воркера (`/playback`, `/devices`,
`/recordings`) — для `recworker`/`detjob` по сертификату; HMAC-способность `playback_key` уходит вместе с тремя строками
`course-only vms.subsystem.yaml heartbeat*` ADR-0034 в ведомости (снять). Вызов к двери чужого кластера под TLS — отказ
«чужая CA — окно 4» и счётчик. Карты и RTSP устройства — только петля.

## Приёмка
Тесты: гейт без ключей отказывает не-петле; дверь с комплектом отказывает без сертификата и чужой роли; `https://` по IP —
отказ; биения с `door`/`peer_url`; четыре набора зелёные; ведомость без строк ADR-0034. Код платформы — веткой; раздел
«Сделано» здесь с веткой и хешами; после «чисто» — в main, файл снять.
