# D0: один выбранный Python-запуск после замороженной подготовки T0

T0 прочитан первично: три внешних файла целиком, 51 файл пакета и 37 исходных runtime payloads сверены. Подготовка не исполняла caller, receiver или renderer. Отдельный допуск в `APPROVAL.json` разрешает существующей review103 через coord103-tools один exact caller и одну проверку его actual ответа frozen receiver.

Проверяется только представление четырьмя группами: шесть полных текстовых/metadata сравнений и два точных отказа конструктора. Это не приёмка всего источника или профиля. Старый P1 уже использован; его результаты сюда не прибавляются.

## Проверка

Исходный author root, FREEZE7f298, argv/cwd/env, subject4803 и ручные ожидания фиксированы. Родитель сохраняет raw stdout/stderr/exit/signal/time/timeout, а receiver требует все десять кадров и строгий терминал до сравнения. При расхождении полного нормального текста остаётся DISPLAY_MISMATCH; при неполноте, неправильном interface или эффекте — CheckingError. Повтора и исправления входов этим решением нет.

Результатов запуска на момент решения нет. Цена ограничения: при изменившейся зависимости исполнение останавливается, а следующая попытка требует отдельного решения; это сохраняет связь результата с прочитанными байтами.
