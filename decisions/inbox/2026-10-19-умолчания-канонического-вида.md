# Умолчания канонического вида: перечень для источника формы

Основание — ADR-0089 доп. (1) Р10, ADR-0088/0089 доп. (1) Р14 (`ordered`); разбор
`inbox/2026-10-19-ревью-ADR-0088-0089-разбор.md`. Канонический вид — принятая спека с подставленными умолчаниями
(ADR-0089 п. 1). Здесь — перечень для источника урока 2 при его переносе: какие умолчания сейчас записаны только словами
и какое машинное значение им дать; какой сахар приводится; какие умолчания вычисляются и по какому правилу; что не
подставляется. Нормы запиской не меняются.

Источник ответов — М10/2 Н1.2а (колонка «Обязательность / умолчание»), Н1.3, Н2 `SpecView` и нормы уроков-владельцев на
срезе `9a5a8172e`. Источник пилота C (`cammeta-schema-pilot/source/spec.form.yaml`: 26 мест `default_text`) — подсказка.

## 0. Правило подстановки (Р10)

Умолчание подставляется, только если его родитель есть в принятом дереве или у самого родителя есть умолчание
(подставленное по тому же правилу). Отсутствующий раздел без своего умолчания остаётся отсутствующим вместе со всеми
умолчаниями внутри него. Главный случай — `requests`: раздела нет — просьб нет, `settle`, `outcome`, `free` не
появляются, и правило `valid_for`/`most_valid` не ломается.

Отсюда: где норма даёт умолчание ключу внутри необязательного раздела и раздел без него ведёт себя так же, как с ним
пустым, — самому разделу нужен машинный `default: {}`. Иначе вложенное умолчание у отсутствующего раздела не
появится. Такие разделы — в таблице 1 с пометкой «родитель».

## 2. Сахар: приведение к одной форме

| Ключ | Сахар | Каноническая форма | Норма |
|---|---|---|---|
| `tables` | список имён `[a, b]` | `{a: {}, b: {}}`, дальше — умолчания таблицы (`fields: {}`, `journal` — раздел 3) | Н1.2а `tables` |
| `unit.fields.<f>.bound_to`, `tables.<т>.fields.<f>.bound_to` | одно имя `"x"` | `["x"]` | Н1.2а; М10/7 Н1.1 («одно имя — список из одного, /spec отдаёт списком») |
| `secret_in[]` вида `regex`: `in` | одно слово `query` | `["query"]` | М10/7 Н1.1 (`in: path \| query \| authority \| fragment \| [список]`) |

Перечень закрыт: других мест «значение или список» в нормах урока 2 и в описаниях полей М10/7 нет (поиск по нормам М10
и М11). Не сахар: `metrics[].equals` — «строка, bool или список строк», у них разный смысл (М13); `to` входа книги
(М11/5) — данные, а не спека.

## 3. Вычисляемые умолчания: закрытый перечень шагов проекции

| № | Ключ | Правило (норма) | Значение |
|---|---|---|---|
| П1 | `snapshot` | М10/10 Н1.3: нет ключа — все поля, кроме `*_secret` и blob; авторское поле `server` тоже исключено; `[]` — ни одного поля | имена `unit.fields` в порядке автора (`ordered`, Р14), без имён `*_secret`, без полей `type: blob`, без поля `server`; явный `[]` остаётся `[]` |
| П2 | `tables.<т>.journal` | Н1.2а, М10/10 Н1.6: нет — `<т>.written`, `<т>.deleted`; `{written?, deleted?}` | `{written: "<т>.written", deleted: "<т>.deleted"}`; если дан только один ключ, второй вычисляется так же |
| П3 | `display.form` | Н1.2а, М10/9 Н1.2: без `form` — один блок со всеми полями | `[{fields: [<имена unit.fields в порядке автора>]}]`, без `title` (необязателен) |
| П4 | `unit.fields.<f>.default`, `tables.<т>.fields.<f>.default` | Н2 `SpecView`: в описателе всегда есть `default`; отсутствующий — `null`; при заданном `inherit` — `null` | `null`, если не сказан или сказан `inherit`; иначе — сказанное значение (Р10: ключ `default` поля — данные, не слово диалекта) |

Векторы шагов П1–П4 — в `vectors/canonical` урока 2 (ADR-0089 доп. (1) Р13).

`events.suppress.<вид>.by` в перечень **не входит**, хотя назван в Р10 (вопрос В1). Его умолчание «все поля строки,
кроме `t`, `id`, `repeats`, `since`, `until`» (М10/8 Н1.2) зависит от полей каждой строки события, а не от спеки.
Вычислить его при установке нельзя. Оно остаётся правилом подавления урока 8, а в каноническом виде `by` отсутствует.

## 4. Не подставляется: отсутствие — само значение

Канонический вид не пишет этих ключей; читатель понимает их отсутствие по норме урока-владельца.
- Нет значения, равного умолчанию: `placement.capacity.unit_mb` (бюджет памяти не проверяется), `placement.unplaced`
  (не удалять), `placement.weight.field` (вес — `weight.default`), `requests.per_person` (предела нет), `requests.key`
  (id просьбы `r-<sha16(Idempotency-Key)>` вычисляется при подаче, а не из спеки), `slot.name_env` (имя не из
  окружения), `console.running` (в `SpecView` — `running_gauge: null`), `schemes.<s>.fragment` (`#` начинает фрагмент),
  `unit.fields.<f>.inherit`.
- Раздел без умолчания, наличие которого и есть включение: `requests`, `events.suppress`, `holds`, `about`, `near`,
  `places`, `affinity`, `group_by`, `retire_when`, `objects`, `domain` и прочие ключи Н1.2а с пометкой «необязателен»
  без слов умолчания.

## 5. Векторы (Р10, Р13)

Минимальный набор `vectors/canonical` урока 2 по этой записке:
- отсутствующий раздел без умолчания: без `requests` → в каноническом виде `requests` нет;
- отсутствующий раздел с умолчанием: без `display` → `display: {unit: "единица", units: "единица", units_count:
  "единица", events: true}`; без `lease` → `lease: {unconfirmed_max: off}`;
- отсутствующий вложенный ключ: `placement` без `headroom`, `weight`, `rebalance` → `headroom: {from: headroom}`,
  `weight: {default: 1}`, `rebalance: {dead_band: 0.1}`;
- сахар: `tables: [a]` → `{a: {fields: {}, journal: {written: "a.written", deleted: "a.deleted"}}}`; `bound_to: x` →
  `[x]`; `in: query` → `[query]`;
- вычисляемые: `snapshot` без `*_secret`, blob и `server`; явный `snapshot: []` остаётся; `display.form` из полей по
  порядку; `default: null` у поля без `default` и у поля с `inherit`.

## 6. Вопросы «Архитектору»

- **В1. `events.suppress.<вид>.by`** не вычисляется из спеки (раздел 3). Рекомендую снять его из перечня Р10: `by` не
  подставляется, правило остаётся у урока 8.
- **В2. `default` у поля `blob`.** Р10 говорит: ключ `default` поля — `null` у не-`blob`, у `blob` его нет, «как
  `SpecView`». Но Н2 `SpecView` даёт `blob` всегда `default: null`. Рекомендую как `SpecView`: `null` у всех полей,
  включая `blob` (П4). Одна форма описателя, и читатель не ветвится по типу.
- **В3. `display.section`, `display.general`.** Н1.2а даёт «единица» всем пяти ключам строки. У М10/9 Н1.2 «нет —
  «единица»» стоит только у `unit`, `units`, `units_count`; у `section` и `general` умолчания нет. Рекомендую
  по М10/9: `section` и `general` не подставлять (раздел 4), строку Н1.2а поправить при переносе урока 2.
