## Признаки и причина

Для K1–K4 норма доступна в показанном модели тексте и на рассмотренных
местах не двусмысленна. Метка — **модель (без обратной связи)** по
ADR-0133 (44) п. 3; вторая причина — обвязка/задание без проверки класса.
Это не метка «при обратной связи» и не доказанный предел модели по
ADR-0133 (41). В сравнении пригодности отдельно сохраняется отсутствие
проверки поведения, а для K1/K3 — отсутствие трассы фактических ответов.

У K2 есть дополнительный признак знания: Kfinal NOTES:63–67 верно
описывает отказ другого содержимого с тем же id, тогда как код возвращает
один отпечаток для всех batch. У K4 комментарий перед maxFloor верен,
арифметика неверна. Находки не объявляются намеренным обходом:
тесты содержат полезные проверки, но пропускают эти ветви.

K5 не получает этой метки: обязательное условие оставшегося бюджета
равного сравнения не выполнено. Готовность профиля при ином бюджете —
другой срез, а не исправление после обратной связи.
