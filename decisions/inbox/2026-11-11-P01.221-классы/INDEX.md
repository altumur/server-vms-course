# P01.221 — собственные красные Kimi Code

Разобраны **19 дополнительных red Kfinal**: door 8, rights 3, daemon 8.
В обоих сравниваемых кандидатах каждый из этих шагов GREEN.
Отдельно разобрано отсутствие профиля у K150. Новых запусков кандидата,
суда, проб, генераций или выбора пина не было.

В коде Kfinal найдены ошибки кандидата: обслуживание раннего запроса,
пустой отпечаток batch и floor, передача отказа floor и его верхняя граница.
Для K1 и ранней последовательности K3 сохранённые данные доказывают
механизмы ошибок, но не точную ветвь каждого фактического ответа:
P01.163 не сохранил HTTP-ответы. Это ограничение не заменено догадкой
о наблюдённом статусе.

## Проверка и оставшееся открытым

Результат задачи — только записка, таблица и сборщик доказательств
в этом каталоге. По карте связанных изменений lesson-spec норма,
контракт, формы, данные приёмки, зеркала и журнал правок не меняются:
здесь нет изменения поведения курса. VMS и продукт не исследовались.

Прямой причинный вывод по отдельному раннему запросу K1/K3 требует
сохранённой трассы либо нового диагностического суда по решению
владельца/представителя. Не утверждается, что после исправления найденных
ошибок кандидат пройдёт всё остальное. Пригодность модели и сравнение
разных бюджетов этой задачей не решаются.

Механическая проверка и сверка задания перед сдачей — [validation.md](validation.md).
