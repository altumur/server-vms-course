# C6: автоворкеру нужен указатель проверенного общего документа

## Контекст

На реальном configstore стенда новый autoworker отказывает при чтении
`domain/shared`: SharedView проверяет подписанную локальную копию по этому
указателю. У роли уже есть ключи доверия, членство, книги и топология;
право чтения указателя не выводится из формы scenario у вида ask в чужой спеке.
DomainVMS на полных локальных Variables этот отказ не показывает.
Лог вне репозитория: `/Users/murat/w2c/course-book-merge-evidence/c6-stand-asks-sealed-console.log`.

## Рекомендация

Добавить существующий точный путь `domain/shared` в `auto.worker.reads`.
Общие права всех воркеров не расширять; без подписанного документа
SharedView по-прежнему возвращает отсутствие настроек. Перегенерировать
installer JSON, добавить проверку чтения через роль autoworker и отказа записи.
Если сверка спек покажет отличие, строку `# ADR-0074 «курс»` добавить
со спекой одним коммитом; продукт на паузе не трогать.
Нового поля или пути на проводе/диске нет: существующее имя получает читателя.
