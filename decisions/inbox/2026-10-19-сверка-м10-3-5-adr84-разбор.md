## Пробелы нормы — решения (ADR-0084 доп. (2), Р13–Р24)

- **Р13. «В пути» без базового** (V4, S4; S6 — следствие). Базовый процесс не заказывается и в пути не бывает:
  `в пути(s) = max(0, (want(s) − 1) − живые заказанные n ≥ 2 (s))`. Одно определение для «нужно», кандидата и условия
  сокращения. Сервер с мёртвым базовым — `no_base` (тревога), его в пути не держит сокращение роли на других серверах.
- **Р14. `room` на момент счёта** (S3). Дверь `platform/doors/<сервер>` рядом с `room.<sub>` несёт `live.<sub>` — число
  замков присутствия, по которым `room` посчитан. Кандидат: `room(s) − max(0, want(s) − live_door(s)) > 0` — обе части на
  один момент; живые по пульсам в этой проверке не участвуют. Стенд: `@grow` поднимает не больше
  `floor(HOST_MEMORY_MB / WORKER_MEMORY_MB)` процессов, как скрипт (М10/11 Н1.5 rules 4) — README словаря стенда.
- **Р15. Пустое место** (S1). `place_by` из пульса со значением `""` — места нет (как у `spread_by`): воркер без места не
  хранитель, общего места `""` не бывает; единицы `distinct` получает только хранитель непустого места.
- **Р16. Нехватка мест** (S5). При `distinct` «свободно у подходящих живых» включает живых без места: новый процесс получает
  место так же, как они, поэтому заказ при нехватке мест не помогает. Единицы, которым не хватило места, — в
  `/unplaceable` с причиной о месте (`no free <place_by>`), заказ — по общей формуле.
- **Р17. Чтение объектов кластера** (S2). Процесс читает объекты кластера через ресурс своего сервера; без ресурса на своём
  сервере — только свой каталог. Стенд, где контроллер живёт на сервере без ресурса, вне нормы: README стенда — ресурс на
  сервере контроллера, если сценарию нужны пульсы других серверов.
- **Р18. `in_flight` вектора** (V5) — «сколько в пути набор взял»: `min(Σ в пути, processes)` для одиночного и для наборов.
- **Р19. Ёмкость смеси** (V6). Ёмкость воркера без названной — `default` (Н1.3); `per` — наименьшая по всем подходящим живым,
  названная или `default`.
- **Р20. Набор без вычислимого `per`** (V7) — элемент тех же полей, что вычисленный: `per: null`, `processes`, `in_flight`,
  `need`, `withheld` — нули, плюс `why`.
- **Р21. Набор меток — множество** (V8): каноническая запись — уникальные метки по возрастанию; повтор схлопывается.
- **Р22. «Вход не по форме»** (V9) — перечень в README каждого пакета векторов (типы, пределы, грамматика имён, уникальность
  канонических наборов, имена заказанных); код 2 обязателен ровно для перечня, остальное — вне вектора.
- **Р23. Формы** (F1–F3): `short[]` — `groups` всегда, свои счётчики МОЖНО, приёмка сравнивает названные поля; ряд
  `<sub>_workers_withheld{labels}` — у каждого набора отчёта прохода, ноль тоже; `why` пустого набора — `any labels`.
- **Р24. Строки векторов** для Р13, Р18–Р22 и V1–V3 — в пакеты `order`, `shrink-victim`, `workers-script`.
