Компонент теста45c9 принят только по точным байтам. Primary сверил один test-файл5469, неизменный модуль155b и восемь доказательств. Node ELF3517 прочитан без вызова; actual версия ещё неизвестна.

Отдельный допуск разрешает существующей spec103 через coord103-src ровно три команды: один `node --version` и по одному `node --check` для теста и модуля на exact45c9. Цена этой границы — отдельная будущая подготовка runtime и новый допуск после actual syntax evidence.
