## Разбор

1. **`{rights}` в команде векторов (отказ профиля).** Таблица подстановок `PROFILE.md` даёт векторам только `{input}`: ошибка модели. Повод в M: README пакета пишет `rights.json as {rights}`, а `wire.tsv`, куда README отсылает, в M нет; модель записала это догадкой № 2. Один неверный ключ снял весь суд.
2. **Группа, два независимых слоя.**
   - **Стенд и M.** Раннер дописывает к `stand.store` флаги `-dir`, `-sockets`, `-rights` (`runner/store_group.py:174`). `lifecycle.md` велит держать `-dir {data}/configstore` в команде, а норма P/01.3 требует отказывать на повторный флаг. Кандидат поступил по норме. Это скрытая норма стенда, класс «стенд, пробел M», а не реализация.
   - **Реализация.** Даже без этого группа не работает: `runRaftDaemon` нигде не вызывается, `daemon.Run` всегда поднимает одиночный режим, отказа `box_no_raft` нет, `recover` не реализован (`P01.16.2`, проверено Архитектором). Этап `group` закрылся по сборке и собственным тестам пакета.
3. **`daemon`, три шага.** `08-floor-replay`: кандидат отверг значение floor как неверное по форме (400 вместо 200). `15-service-doors`: 405 вместо 413. Класс раннера — реализация; с нормами отдельно не сверялись.
4. **Сборка.** Раннер собирает без `GOMODCACHE`, кандидат с зависимостями на суде не собирается. Дефект пути суда.

## Сравнение с попыткой 2

Закрыты: библиотека Raft настоящая, тип `index`, отказ на чужой подкаталог, команды общих пакетов векторов. Главы 1.1 и 1.2 полностью зелёные. Нового: не подключённая группа и неверная подстановка.

## Пределы

Стенд не изолирован. В копии суда вручную заменены две строки M на J. Вердикт как эталон ADR-0135 шага 8 годится только для целей диагностики и с её правками.
