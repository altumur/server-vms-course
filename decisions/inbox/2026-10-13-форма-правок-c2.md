# C2: форма создания/удаления в очереди правок домена

## Контекст
Маршрут через domain.edit согласован в «запись-члена-c2», GET where
не расширяю. Курс пока хранит лишь обновления: domain/pending/<member>,
элемент {rev,subject,since,fields:{поле:{old,new}}}, исходы domain/applied.
Агент вызывает update_unit; создания/удаления в форме нет. create_unit
ConsoleAPI только непосредственно вызывает консоль, в очередь не кладёт;
HTTP двери домена POST строк не реализует, rec.domain.ref отсутствует.
«kept» в нынешнем ответе — pending:true, а у принятой формы продукт пишет
kept. Прежде нового имени на проводе/диске нужна точная форма продукта,
включая исходы и отказ гранта при применении на члене.

## Рекомендация
Прислать фактические JSON строки/элемента/исхода и ответа POST/DELETE
продукта для create/update/delete, пути и идентичность записи (sub+id,
ref камеры), условия idempotency и авторизации. Курс повторит форму целиком,
старый формат очереди не читает. Рекомендую явную операцию с закрытым
набором значений, не превращать отсутствие строки в неявное создание
посредством update; создание проверяет полную спеку строки, изменение —
domain.edit, удаление — заявленные права. Предметной ветки rec в платформе
нет; решения исполняет агент своим контроллером по каталогу. «Уже есть»
при повторе и недоступный член должны соответствовать согласованным
409/kept без повторной записи. До формы новое поле очереди не добавляю;
проверки обычных издателей/читателей и страницы продолжаю независимо.

## Решение («Архитектор», 2026-10-13)
Фактическая форма продукта закреплена поправкой к форме C2 в ADR-0074 («правки домена для члена»): двери
`POST/PUT/DELETE /domain/<sub>/<rows>[/<единица>]` с обязательным `Idempotency-Key`, отказ секретов и чужих полей до
сохранения; ответ 202 `{kept: <id>, cluster, what, note}`; `domain/pending/<член>` = `{id: Edit{id, what, method, path,
body, key, at}}`, операция явная по `method` (POST создание, PUT изменение по `domain.edit`, DELETE удаление);
`id = "e-" + hex(sha256(член‖0x00‖key))[:12]`, тот же ключ с иным содержимым — 422; исходы `domain/outcomes/<член>` =
`{id: Outcome{id, status, result, error, at, what}}`; «уже есть» — исход 409; держатель — тоже член (правка хранится).
Курс повторяет форму целиком, старый формат очереди не читает. Файл снимаете слиянием окна.
