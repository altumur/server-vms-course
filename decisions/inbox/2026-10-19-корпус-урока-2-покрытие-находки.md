# Корпус урока 2: строгое покрытие ссылок и случаи свода — находки

Основание — ADR-0087 доп. (1) Р10 (строгое покрытие `references.tsv`) и доп. (3) (случаи свода журналов), очередь
«Архитектора» п. (2). Внесено в корпус `Source/tests/testdata/acceptance/М10_Platform/02/`: 59 случаев `c8_ref*` и 8
случаев `c8_*` свода. В корпусе 546 файлов, 97 ok и 449 refused. Ожидаемое записано по норме; пилот C и проверка курса
совпали с ней по вердикту и классу во всех 67 случаях.

Покрытие строк `references.tsv` источника пилота C (мерка — `tools/rows_coverage.py` пилота на новом корпусе) — **108 из
111**. Нормы этой запиской не меняются.

## Ф1. Три строки по норме одни не отказывают
- **58** `rights.unit_of.{}` и **61** `servers.show[$i].table`. У необъявленной таблицы нет полей, поэтому срабатывают и
  59 (`rights.unit_of.<т>` — поле таблицы), и 62 (`servers.show[$i].by` — поле таблицы). Предлагаю дать строкам 59, 62,
  63 (а также 39, 40, 43, 44, 49–52, 54, 56) условие `when <таблица> in keys(tables)`. Ссылка на поле неизвестной таблицы
  тогда — следствие, а не вторая причина; так же построено у `holds` (50–52).
- **84** `worker.writes[] != unit.rows` её поглощают две строки. Таблицы с таким именем нет — срабатывает 83. Такая
  таблица объявлена — раньше отказывает 14 (`tables.{} != unit.rows`, value). Предлагаю снять 84 при переносе урока 2.
- **47** (`about.field = unit.id` при `delete_after`) единственна только через порядок шагов «значения раньше ссылок»:
  строка следует из 46 и 79. Н3 нормативным называет порядок шагов 1–3, порядок 4 → 5 не закреплён. Предлагаю
  закрепить в Н3 «шаг 4 раньше шага 5»; тогда случай `c8_ref47_unplaced_about_not_id` получит класс. Сейчас он записан
  только вердиктом.

## Ф2. Проверка курса (ADR-0085) против нормы — пути (вердикт и класс совпадают, check_spec их не сверяет)
- Индекс списка в пути — строка `"0"`, а по Н4 — число. Так у `c8_ref15`, `c8_ref7`, `c8_ref21`, у прежних
  `status_worker` и `requests_stamp_group_without_group_by`.
- `domain.tokens`: путь `domain.tokens.<вид>` вместо ключа `…<область>.<x>_claim` (строки 93, 95–102, 104).
- `c8_rules_below_form_failure` (Р1): у проверки курса путь второго вида `secret_in` — сам элемент, по Н4 («ключ, который
  правило запрещает рядом с другим») — `…secret_in.0.regex`. Пилот даёт путь по норме.
- `c8_ref58`: путь повторён дважды; `worker.writes.0` назван в отказе шага значений.
- Пилот у строки 110 даёт `domain.shared` без индекса.

## Ф3. Р6 не внесены — проверка курса их не различает (слой текста `check_spec`, «Архитектору»)
- целое из 4301 цифры (`unit.fields.start.default`) — прогонщик падает (`ValueError`, предел `int()` Python), и пилот
  тоже. По Н1.1 int ожидается `refused:value` на пути значения;
- `display.unit: counter# c` проверка курса принимает, а по Н1.1 comment («`слово# c` — строка, не отнесённая ни к какому
  ключу») ожидается `refused:text`.

Файлы обоих случаев готовы: `c8_int_4301_digits`, `c8_word_hash_space` (scratchpad «Спецификации», `corpus2/gj/`).
Внесу их, когда проверка курса будет давать вердикт по норме.

## Ф4. Неясности норм, найденные при записи случаев (норм не правила)
1. Путь отказа правила над набором — `prefix_free` (88, 90), глубина схемы (12, 25, 26, 77, 113), `unique` в
   `domain.shared` (110), `claims_bind` (102, 104). «До самого глубокого ключа» допускает два ответа. Рекомендую
   дописать в Н4: у правила над набором путь — сам набор; у повтора — второе вхождение, как у повтора ключа.
2. Путь у строки 60 (`rights.reach.group` без `placement.group_by`). По букве Н4 «A требует B» путь — недостающий B, а
   пилот и курс дают сам A. Так же у строк 74, 75. Рекомендую дописать в Н4: у ссылки Н1.4 «A запрещён без B» путь — сам
   ссылающийся ключ.
3. Класс ссылки на поле не того вида: `bound_to` на секрет, `credentials.login` на поле url, `credentials.secret` на
   несекретное поле. Н1.4 для этих ключей говорит только «поля той же строки»; пилот и курс дают `reference`. Рекомендую
   дописать это в ячейку Н1.4.
4. `placement.home: near` без `near`. Н1.2а говорит «тогда `near` обязателен» — это звучит как value с путём `near`;
   Н1.4 относит `home` к ссылкам. Рекомендую в Н1.2а: «`refused:reference` с путём `placement.home` (Н1.4)», как у
   `requests.stamp` и `group_by`.
5. М11/11 Н1.1 обещает путь `domain.shared[<i>]`, а отказ глубины даёт путь глубже — `domain.shared[<i>].schema`.

## Ф5. Чего корпус не держит по причине источника
О3 (`@путь` в узел под `variants`) — случая нет: источник такой строки не пишет. Шаблон с вложенной `{`
(`c8_requests_key_nested_brace`) записан только вердиктом: класс — после решения О14 свода журналов.
