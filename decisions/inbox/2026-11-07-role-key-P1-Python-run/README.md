# Role-key: один запуск P1 по замороженному caller6a99

Основание — отдельная поставка P0, а не часовое напоминание З-13. Архитектор прочитал три Python-файла, контракт процесса, ожидания и окружение. Сверены 163 файла пакета и двадцать исходных файлов author followup1. Это чтение байтов: runtime-поведение ещё не проверено.

Разрешён один процесс по точным argv/cwd из APPROVAL.json и одно чтение его фактического ответа замороженным receiver. coord103-tools передаёт исполнение существующему review103. Источник285 читается отдельно с common437; основной источник, main и инструменты не перепиниваются. Внешний launcher лишь сохраняет stdout/stderr, реальный код выхода, время, идентичности и результат receiver в перечисленные файлы.

Все проверки terminal shape/types теперь идут до oracle. Набор остаётся прежним: двадцать групп, двадцать пять наблюдений, двадцать одно смысловое сравнение и четыре ожидаемых ошибки предусловий. Эти числа пока план. Полный штатный ответ с несовпадением — смысловое несовпадение, отдельное от служебной ошибки. Неполный ответ, неверный класс исключения, побочный эффект, таймаут или необъяснённый код выхода дают CheckingError без частичного успеха.

При отклонении от замороженных предусловий исполнитель останавливается и сохраняет факты. Автоматического повтора, ремонта, установки зависимостей и переноса запуска в другое дерево нет. Все шесть предметных ремонтов и Go/render/генерация/Source adoption/общий GATE остаются закрытыми для исполнения. После поставки результата Архитектор читает фактический полный ответ отдельно; допуск не объявляет его успешным заранее.

Длительность P1 и срок общей приёмки неизвестны. Начальная авторская оценка P0 сохранена историей, выполненная подготовка не начисляется повторно.
