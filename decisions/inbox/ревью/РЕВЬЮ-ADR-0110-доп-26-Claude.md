# Ревью текста: ADR-0110 доп. (26) (Claude)

**Счёт: Б 0, С 0, М 1.** С1 (25) исполнено: старт без памяти и с нечитаемой строкой — ждать ответа, слить, заменить только при `413`. Quint `cBad` с перезапуском заказан.

**М1. «Переполнение бывает лишь после очистки кражей» — сильнее, чем есть.** Так я написал в первой редакции отчёта (25), и в 9b227e546 сам сузил: есть и второй случай. Строка держателя у потолка, а у члена сверху свои отзывы, которых держатель лишился переносом без `stolen`. Слияние выходит за `ceiling`, замена теряет эти отзывы — тот же RV-случай, только при полной строке. Назвать пределом рядом с `domain.revoked.dropped`: «слияние при старте за потолком — замена строкой ответа; отзывы члена сверх неё теряются, предел». Только М — в нормы без дополнения.
