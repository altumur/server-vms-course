# Ревью текста: ADR-0103 доп. (8) (Claude)

**Счёт: Б 0, С 0, М 1.** С1 и М1 исполнены: поиск — строка `cam/searches/<CLUSTER>`, её читает базовый воркер `cam` каждого сервера, как V/01.8 Н1.1; пробуждение — одно решение на всех потребителей.

**М1. В доп. (7) п. 3 осталось «как зритель».** Первый вариант (7) п. 3: «читатели потока создают спрос, **как зритель**». По V/01.1 `:62` зритель камеры `live: on-demand` спроса тоже не создаёт: «будить её некому: зритель получает `camera <поток> is not running`». После (8) п. 2 сравнение ложно. Варианты для «Спецификации VMS»:
- **(а)** все потребители, зритель тоже, создают спрос;
- **(б)** `on-demand` — только устройство для всех; детектор и запись на такой камере отказываются словом при сохранении, зритель получает `not running`, как сейчас.

Только М — в нормы и в слово «решила» без дополнения.
