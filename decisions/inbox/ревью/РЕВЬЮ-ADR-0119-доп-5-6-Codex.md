**По дополнению (6): Б 0, С 0, М 0. Новых замечаний нет.**

Проверены уточнения:

- Заголовок `X-W2C-Supervision` относится к автору и доходит через `door.pass` независимо от наличия `supervisor`. Его формирует консоль, входящий извне снимается. Это дополнение к закрытому перечню передаваемых заголовков договора сторожевой/передачи; backend может выдать `SUPERVISOR_REQUIRED`, не вызывая проверку пароля.
- Роли с политикой передаются члену независимо от местных грантов; нечитаемые роли и группы передаются отметкой вместо исключения. Правило (5) о сохранении требования надзора теперь имеет источник данных у держателя и путь доставки через P/09.1. Прежнее замечание Codex о снятии надзора исключением нечитаемой роли закрыто.
- Целиком заменён прежний пункт с именами `exp`/`cam` в платформенной двери. Поля двери — `{cap, sub, units}`, значения VMS задаёт вызывающий backend.
- При недоступности хотя бы одной единицы ответ — 503 целиком. Частичный успех не служит подтверждением экспорта; отсутствие гранта остаётся `deny`, как определено (5).
- `VERIFY_UNITS_MAX = 256` — самостоятельный предел платформы, достаточный для `EXPORT_CAMERAS_MAX = 16`. Ключ проверки `(автор, имя)` 5/900 с сохраняется вместе с общим потолком процесса домена.

Проверен текст решения; соответствие будущих изменений схем, доставки и API этому решению требует отдельной проверки реализации.
