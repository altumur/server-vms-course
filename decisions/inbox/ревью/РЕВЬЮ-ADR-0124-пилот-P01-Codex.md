# Ревью пилота перераскладки P/01 — Codex

Вход: `arch/relayout-p01` **93b273561**, семь коммитов после **fa11822ea**. Итог: **Б 1, С 1, М 1**. Перенос самого P/01 проверен; пилот целиком пока не соответствует условию приёмки выгрузки.

## Б1. Выгрузка после переноса получает 160 битых ссылок в ещё не перенесённых уроках

**Место:** `tools/layout/migrate.py:197–211`, правила перевода ссылок; результат выгрузки пилота.

**Цитата нормы:** ADR-0124 доп. (1) п. 7: «Пилот считается сданным, когда выгрузка из ветки переноса собрана во временном клоне и проверена: нет `ru/` и `journal/`, все ссылки внутри выгрузки ведут на существующие файлы и якоря». П. 6 требует понимать обе раскладки на время перехода.

Ссылки русских производных других уроков правильно переведены в `Platform/01-store/ru/...` для чтения курса. Но экспортёр продолжает включать эти производные, исключая их новые цели `ru/`. Поэтому исправный курс превращается в неисправную выгрузку. Это не только ранее известный долг ссылок: появились новые отказы вследствие пилота.

Подтверждено чтением временных выгрузок из `scratchpad` сессии `2d7ea881-e3dd-42ee-ac34-002756a9f21d`:

| Дерево | COURSE_COMMIT | Ссылок | Битых вхождений |
|---|---|---:|---:|
| `base` | fa11822ea | 12005 | 407 |
| `exp2` | fb1948608 | 11841 | 559 |

В `exp2` ровно **160 битых вхождений** ведут в `P/01/ru`; после сведения одинаковых `(файл, цель, причина)` — 146 новых записей относительно базы. Из прежних ошибок часть исчезла, поэтому разница итоговых чисел не равна 160. Внутри экспортированного P/01 битых ссылок 0; `ru/` и `journal/` в выгрузке отсутствуют. Все 59 файлов экспортированного P/01 совпадают байт в байт с проверяемым 93b273561.

Примеры новых ошибок: `Platform/02-installer/02-installer.md` → `../01-store/ru/01-store.md`; `Platform/02-installer/acceptance/5/README.md` → `../../../01-store/ru/acceptance/2/README.md`.

**Предложение:** до зачёта пилота определить переходную политику экспорта производных прежней раскладки и реализовать её вместе с разрешением их ссылок. Возможен экспорт только источников с согласованным переписыванием ссылок прежней раскладки; альтернативный переходный вариант должен сохранять все включённые ссылки. Нельзя просто исключить `ru/`, сохранив ссылающиеся на него документы. После правки проверить всё экспортируемое дерево; прежние ошибки учитывать явно, но новые 160 не объявлять допустимыми без изменения условия приёмки владельцем. Закрепить SHA экспортёра и итоговой выгрузки.

## С1. Разборщик ссылок молча пропускает допустимый Markdown, поэтому не обеспечивает перенос следующих уроков целиком

**Место:** `tools/layout/links.py:16`, `links()`; использование в `migrate.py:222` и в проверке выгрузки.

**Цитата нормы:** ADR-0124 п. 6 — перенос «с правкой ссылок по всему курсу»; доп. (1) п. 7 — «все ссылки внутри выгрузки» должны разрешаться.

Одна регулярная строка разбирает только ссылки вида `[текст](цель)` без заголовка ссылки. Ссылки по определению не учитываются ни переносом, ни его судьёй. Стандартная библиотечная проба во временном каталоге:

```markdown
[missing][n]

[n]: absent.md
```

`links.check_tree` возвращает **`([], 0)`**: отсутствующая цель не даёт ошибки и даже не попадает в счётчик. При переносе ссылка такого вида на прежний `en/X.en.md`, форму или журнал останется на старом месте, а проверка тем же разборщиком всё равно даст зелёный результат. Аналогично пропускается `[текст](цель "заголовок")`.

В проверенном P/01 и выборке следующих P/02, P/03, V/01 пропущенных целей при сопоставлении с CommonMark не найдено; это дефект общего инструмента для дальнейшего переноса, а не утверждение о дополнительной найденной битой ссылке P/01.

**Предложение:** проверку выполнять по полному дереву Markdown, например уже используемому навыком `markdown-it-py`. Для миграции отдельно обрабатывать определения ссылок с сохранением координат исходного текста. Либо явно ограничить входной синтаксис и останавливать перенос при иных локальных ссылках. Добавить отрицательные пробы на reference-ссылку и ссылку с заголовком; независимая проверка не должна терять те же ссылки, что мигратор.

## М1. Несопоставленный якорь не делает фазу ссылок неуспешной

**Место:** `tools/layout/migrate.py:174–185`, `:370–372`.

**Цитата нормы:** ADR-0124 доп. (1) п. 3: «Якоря русских заголовков ... в ссылках на источник заменяются английскими — по парам заголовков».

При отсутствии пары `anchor_en` оставляет прежний якорь и записывает `unmapped`; затем фаза уже записывает и индексирует изменения, печатает `UNMAPPED anchor ...` и возвращает **0**. Пробой `Rewriter` подтверждено сохранение несопоставленного якоря. Автоматическая последовательность команд, судящая фазу по коду выхода, не узнает, что обязательная часть переноса не выполнена. В P/01 такого случая не найдено.

**Предложение:** при непустом `unmapped` завершать фазу ненулевым кодом, лучше выявлять проблему до записи/индексации. Различать исходно битый якорь и якорь, для которого нарушено соответствие заголовков. Диагностику сохранить.

## Что проверено и что осталось пределом

- Два коммита обмена имён содержат **12 + 16 переносов со сходством 100 %**; `git log --follow` для источника проходит через `afa2d10ce` в историю английского файла, для перевода — через `01066b708` в историю русского. Обмен не смешан в одном коммите.
- `moves.tsv` содержит все 28 переносов. В `decisions/` изменена только живая `adr-norms.tsv`; тексты ADR и архив ревью не правились. Сохранение их исторических русских якорей следует исключению доп. (1) п. 5, а не является обещанием работоспособности каждого старого якоря в новом английском тексте.
- Внутри P/01 — **251 локальная ссылка, 0 битых**, включая якоря. Обычные ссылки переводов ведут в переводы; переходы из `ru/` в английские `.md` внутри урока найдены только в 11 шапках пар. Машинные входы приёмки, схемы и OpenAPI не изменены; два файла таблицы перенесены без изменения байтов.
- Повторён полный `check_spec`: **PASS with 61 exceptions**. Тесты `test_check_spec`, `test_en_mirror`, `test_check_tables`, `test_check_machines`: **210 тестов, OK, один skipped**. Поддержка обеих раскладок проверена исходниками и этими тестами. План переноса P/02 строится; сам следующий урок не переносился.
- normgen: `GenChecks.test_out_up_to_date` и `OutOfSubset` — **3 теста OK**. Пакет Б: `Kit.test_build`, `Kit.test_limits_match_table` — **2 теста OK**, включая сборку и сверку манифеста. - Временный экспорт проверен чтением файлов, без запуска кода из клона. Это найденный `exp2` на fb1948608, а не заново выпущенная выгрузка 93b273561. Реализация переноса и экспортёр в рамках ревью не правились. Общая пауза ADR-0120 не снималась.
