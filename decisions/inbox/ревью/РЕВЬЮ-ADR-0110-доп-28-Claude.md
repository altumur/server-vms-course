# Ревью текста: ADR-0110 доп. (28) (Claude)

**Счёт: Б 0, С 0, М 1.** Вариант (а) исполнен. Без памяти набор ответа судится `keys` с `held = null` от `pinned` и записывается; строка отзывов — путём (26), (27). Согласно с (25): без памяти `thefts` прежнего не с чем сравнить, и очистка по краже не срабатывает, а работает слияние с заменой при `413`. Quint `cBadRSkip` заказан.

**М1. Назвать худший откат: набор до кражи.** «Вредить он не может дальше, чем позволяет закреплённый корень» верно, но корень подписывал и набор **до кражи**: в нём украденный ключ. Принявший такой откат член до следующего ответа или следования пропускает токены вора. Для этого нужен повтор старого ответа держателя, то есть чужой в канале. Узко, но это ровно тот ущерб, ради которого смена после кражи. Дописать в предел: «в том числе набор до кражи — до следующего ответа токены украденного ключа у этого члена проходят». Только М — в нормы без дополнения.
