# Ревью текста: ADR-0093 доп. (25), разбор ревью (24) (Claude)

Доп. (25) на origin/main 146a7c207. Сверено с V/11.13 Н1.6 (`tokens`, `hit`), `harness/rules/words.json` курса (обход всех значений скриптом: `\b`, `\w`, `\d`, `\s`, заглавные) и выражением Пилота для «switch … off» (доп. (20) п. 4).

**Счёт: Б 0, С 0, М 1.** С1 отчёта (24) исполнено. Граница по `tokens`, нижний регистр, `\b` не пишется, векторы с русскими основами.

**М1. Та же беда у `\w`: правило называет только `\b`.** В RE2 и ECMAScript `\w` — только `[0-9A-Za-z_]`, в Python 3 — любые буквы Юникода.
- Выражение «выключения камеры» у Пилота — `\b(?:switch|turn|shut|take)\w*\s+(?:[\w-]+\s+){0,3}off\b`. Доп. (20) п. 4 назвало его словами: «до трёх слов между». В Go и JS «switch Лобби Cam off» не совпадёт, потому что «Лобби» — не `[\w-]+`. В Python совпадёт.
- В словаре курса `default_yes` несёт `не ответ\w*`. Там исход тот же, его поглощает `.{0,40}`, но это случайность.

Дописать к правилу: «буква слова — `[0-9a-zа-яё]`, классы `\b`, `\w`, `\W` в словарях не пишутся». «Слово между» — `[0-9a-zа-яё-]+` или `\S+`. `\s` и `\S` держат одинаково: пробелы и не пробелы движки видят одинаково на этом тексте.

## Сверено и держит

- Нижний регистр текста и выражения без `(?i)`: в значениях `words.json` курса заглавных нет, проверено обходом. Исход в Go `strings.ToLower` и Python `str.lower` для латиницы и кириллицы, `ё` включительно, один.
- «`\b` не пишется» задевает и латинские `\bon\b`, `\bpulse\b`, `\barm\b`, `\benable\b`, `\bsees?\b`, `\bend`… — это 11 ключей словаря. Правило одно для всех, и это верно: два вида границы в одном словаре разошлись бы на `_` и цифрах.
- `(?:^|[^0-9a-zа-яё])…(?:$|[^0-9a-zа-яё])` поглощает соседний знак. Для `hit`, где ищется хотя бы одно совпадение, это безвредно. Lookbehind не нужен, и RE2 его не умеет.
- Набор `[0-9a-zа-яё]` совпадает с `tokens` V/11.13. `й` лежит внутри `а-я`, `ё` названа отдельно.
