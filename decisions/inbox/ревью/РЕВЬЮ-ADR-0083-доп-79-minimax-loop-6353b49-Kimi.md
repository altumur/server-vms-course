## Находки

- **С1. Раунд без зова — в счёт остановок.** `judge_round` не различает зов модели и авто-зов: авто-раунд
  двигает `stall`/`gate_fails` и может поставить `stalled`, `build_stalled` или `judges_exhausted` (6353b49,
  `loop.py:756-772`, вызов — `loop.py:984`). Модель, которая пишет код и не зовёт `done` (ровно случай четвёртой
  попытки), после трёх авто-раундов без роста меры получит остановку `stalled` к ~ходу 90+ от первого кода — цикл
  остановится по раундам, которых модель не просила. Совпадает с С1 ревью review-claude; закрыто решением (80)
  п. 1 (раунд без зова — сигнал и запись `auto`, в счёт остановок — только раунды по `done`), по коду be540dd
  не проверял — вне объёма этого поручения.
- **М1. Оглавление вне бюджета сжатия.** В `compact` остаток бюджета рабочей части считается
  `WORK_AFTER − STUBS_CHARS − NOTES_MAX − PLAN_MAX − REPORT_MAX` (`loop.py:573`) — без `OUTLINE_MAX`: сводка
  с оглавлением может превысить `WORK_AFTER` на величину до 8000 знаков. Совпадает с М1 review-claude; закрыто
  решением (80) п. 2.
- **М2. Оглавление не видит одиночные var/const.** `DECL_RX` (`loop.py:54`) ловит только блоки `var (` / `const (`;
  одиночные объявления вида `var x = …` / `const Name = …` наверху файла в оглавление не попадают (func и type
  видны всегда). Для цели «не перечитывать свой код» потеря мала, но оглавление неполное. Моя, открыта.
