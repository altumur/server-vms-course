## Код 4f59661 — Б 0, С 0, М 3

Исполнено:
- **сжатие:** оставляет последние ходы, пока вместе ≤ 30 тыс. знаков, не больше 6, хотя бы последний; заглушки — с конца, ≤ 8 тыс. знаков; ответы Архитектора — в сводке;
- **мера:** `targets` — словарь «цель → N» из задания, в паспорт; не напечатанная цель — 0 из N; проверки цели — суммой `steps`, `cases`, `probes` строки итога;
- **догадки:** запись `## N`, ключ — номер; пауза — строка `Блокирует: да` при первом появлении у номера; «не блокирует» паузы не даёт;
- **`wait_exhausted`:** проверяется при `--resume`.

Изоляция и чистка не тронуты.

**М1. N цели переписывается каждым раундом, а текст говорит «уточняет первая строка».** В `acceptance_measure` у напечатанной цели `good, cnt = run_checks(line)` берётся на **каждом** раунде. Знаменатель из задания (154, 42, …) замещается тем, что напечатал раннер этого раунда. Если прогон кандидата оборвал цель или раннер напечатал только `scenarios a/b` (стенд не поднялся), у цели в этом раунде окажется 12 вместо 154. Итог (`total`) снова скачет, а лучшее (`best`) сравнивает проверки разных единиц: шаги одного раунда со сценариями другого. Сделать по тексту: N из задания неизменен; первая напечатанная строка с `steps`, `cases` или `probes` может уточнить его один раз (в паспорт — было и стало); `good` = min(напечатанное, N); строка без этих единиц — `good` 0.

**М2. Догадки не в форме `## N` теряются для паспорта.** Модель, написавшая `### Догадка 1` или `1. …`, не даст ни одной догадки в паспорт, а это одна из мер ((61) п. 2). Назвать: `GUESSES.md` без записей `## N` при ненулевом размере — напоминание о форме (как напоминание о плане), а при остановке весь файл кладётся в паспорт как есть.

**М3. `wait_exhausted` при `--resume` не пишет `result.json`.** `sys.exit` выходит после паспорта и `state.json`, но без `result.json`. По `result.json` смотрят исход этапа — назвать его с `status: wait_exhausted`.
