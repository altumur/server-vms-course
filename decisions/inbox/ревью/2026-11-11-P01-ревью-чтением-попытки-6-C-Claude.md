## Находки: кандидат C

### C-01 · Б · Любая простая escape-последовательность JSON (`\"`, `\\`, `\/`, `\n`, `\t`, `\b`, `\f`, `\r`) — 400
- **Где:** `internal/jsonval/jsonval.go:319-343` (`escape`); вызовы `internal/door/write.go:51`, `internal/rights/rights.go:302`, `internal/copy/copy.go:104,151`.
- **Норма:** P/01.1-23; P/01.1-R048 (RFC 8259); P/01.1 N2.1.
- **Что не так.** Ветки простых escape-последовательностей пишут символ и выходят из `switch` на безусловный `return false, fail("the text is not JSON")`. Успешно разбирается только `\u`. Запись `{"op":"put","key":"acc/a","items":{"v":"a\"b"}}` получает 400 `badrequest`. Тот же разборщик читает файл прав и копию, поэтому строка с `\"` в копии или в файле прав тоже даёт отказ. Уроки, которые хранят JSON или JCS в строках, работать не смогут.
  ```go
  case 't':
  	b.WriteByte('\t')
  case 'u':
  	return p.unicode(b)
  }
  return false, fail("the text is not JSON")
  ```
- **Тест:** у `jsonval` тестов нет; тесты двери escape-последовательностей не подают.

### C-02 · Б · Размер чанка ≥ 2^63 (или сумма с прочитанным) — паника `makeslice`, демон падает
- **Где:** `internal/httpwire/httpwire.go:474-478` (`int(size)` и `make([]byte, size)`), `:507-538` (`chunkSize` возвращает `uint64` до `ffffffffffffffff`); `recover()` в коде нет.

- **Что не так.** `uint64` больше `MaxInt64` даёт отрицательный `int(size)`, проверка `len(body)+int(size) > cfg.MaxBody` проходит, и `make` паникует. При `7fffffffffffffff` после первого непустого чанка сумма переполняется так же. Свой HTTP-сервер без `recover` роняет весь процесс. Один запрос с любого сокета роли или с `-api` останавливает демон.
  ```go

  	return nil, 0, FailTooLarge
  ```

- **Тест:** нет.

### C-03 · Б · Ключ длиннее 125 байт не ложится на диск: 503 `ambiguous`, потеря строки, отказ старта
- **Где:** `internal/filestore/filestore.go:439-442` (имя файла `hex(key)+".ver"/".body"`), `:296-306` (`Commit`: кадр в WAL, затем запись строк), `:115-120` (`Open` → `replay`); `IMPLEMENTATION.md:132-137`.
