**Стадия 7 `growth_shrink` (вес 4, зависит 6).** Ядро `growth_core` (C26–C30) + property tests `order_plan`, `shrink_victim`, `shrink_allowed`. Нехватка по набору меток: per (наименьшая положительная ёмкость suitable live-воркеров, named или default; named 0 не заменяется), processes = ceil(max(0, Σвеса waiting − free)/per) + 1 за группу без места, in_flight по номерам 2…want без live, needed = max(0, processes − Σ in_flight); set order (каноническая запись UTF-8, пустой набор первым), free(s) = room − |{2…want} ∖ live.door| раз в проход минус shares; кандидаты (база жива, room>0, want<WANT_NUM_MAX=99, метки, requires, не drain/decommission, не «failed to raise» в окне RAISE_QUIET, distinct по place_by), порядок (live+in_flight, имя UTF-8), share ≤ min(free(s), WANT_NUM_MAX−want); непустой `door.pass.calls` → потолок want(s)=1. Проба (distinct + heartbeat place_by): ≤1 проба в проход, ≤1 незавершённая на сервер, in_flight=0, withheld «no free <place_by>». Векторы: order, shrink-victim, shrink-allowed.
