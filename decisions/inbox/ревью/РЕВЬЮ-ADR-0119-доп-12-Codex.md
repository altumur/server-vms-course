# Короткое ревью дополнения (12) к ADR-0119, Codex

Проверено на `origin/main` **f8aafb1a3**, вместе с (10)–(11), исходным ревью Claude к (11) и V/08.8 Н1.1, Н1.3–Н1.4.

**Счёт: Б 0, С 0, М 0. Новых замечаний нет.**

Автор (`by`) получает исполнимый путь удаления своей части без держателя; чужую часть по-прежнему удаляет только администратор с правом на `exp` по камере. Роль backend как единственного писателя по билету сохраняется: прямой сеансовой записи не появляется. При наличии держателя остаётся прежняя просьба.

Признак потери держателя и защита от его возвращения явно отнесены в нормы. Прежние М о размещении и файлах не начисляются повторно; их следует закрыть при переносе в нормы, без нового дополнения. Код клонов и тесты реализации не запускались.

Агент Quint проверил вход: `plat_to 0119 = 8`, выгрузка `cammeta-specs` **b7d4b651** ещё без `writes_via`. До нормативной выгрузки (12) и `plat_to >= 12` модель и CT не запускались; конкурентный алгоритм этим ревью текста не проверен.
