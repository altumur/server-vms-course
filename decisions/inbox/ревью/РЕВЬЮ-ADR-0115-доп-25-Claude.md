# Ревью ADR-0115 доп. (25) (Claude)

main 22b3371cb. **Счёт: Б 0, С 0, М 1.**

Принято:
- сервер с дверью — свой шаг: права ≡ файлу и чтение через дверь, без `applied`; кворум считается по голосующим;
- консоль — `sha256` равен хешу обхода и `served` = `rev` (обе сверки вместе ловят и чужой `put` посреди обхода);
- переключение плагина без перезапуска членов: `rollout` сам решает по `/v1/rights`, — это С1 ревью (23), (24);
- ожидание `served` работающих в (23) п. 3 (а), а новой — в (в);
- `404`/`401` `backend` — предел;
- `-last` — подтверждение оператора, а голос и `applied` прочих команда проверяет по статусу лидера.

**М1. Файлы — на всех серверах и без перезапуска.** П. 3 говорит, когда член не перезапускается, но не говорит, что `manifest get --sha256` нового манифеста `backend` на каждом сервере идёт всё равно. Это важно: `install` берёт байты только из файла `MANIFEST_DIR` ((21) п. 1). Сервер со старым файлом `backend` при следующем `install` положил бы прежние `calls` обратно. Дописать: шаг сервера — всегда `get` всех манифестов обхода и сверка консоли; перезапуск члена — только при разнице прав.
