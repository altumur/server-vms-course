`return any(parts[i] == "acceptance" and parts[i + 1].isdigit() and parts[i + 2] == "inputs"`.
Сценарий: путь `Platform/x/acceptance/١/inputs/y.js` в J — `"١".isdigit()` истинно, класс code не
применяется, файл проходит guard как «фикстура». Источник: ответ Архитектора 2026-11-11T09:28:46Z
(note к P02.45; ADR-0133 доп. (4) п. 8) — исключение отведено каталогам глав `acceptance/<n>/inputs/`,
а главы урока — ASCII-цифры (раскладка ADR-0124: `acceptance/K`). Последствие сегодня: нет — таких
путей нет ни в одном уроке, J строится из дерева курса, решение о include остаётся за фильтром, а
`FORBIDDEN_TEXT` действует. Рекомендация: `parts[i + 1].isascii() and parts[i + 1].isdigit()`.

## Наблюдения вне находок (не против P02.26)

- Guard verdict теперь держится на точных именах: корпус будущего урока с иным именем (например
  `verdict_corpus/`) или скрытый каталог `.spec_verdicts/` (у него `split(".", 1)[0] == ""`) пройдут
  guard молча, тогда как прежнее правило по подстроке «verdict» их ловило. Это следствие самого
  определения Архитектора (сегменты `spec_verdicts`/`legacy_spec_verdicts`), а не дефект реализации;
  стоит помнить, что переименование корпуса теперь тихо ослабляет guard.
- `range(len(parts) - 3)` не проверяет тройку в последней позиции (файл с именем `inputs` прямо в
  `acceptance/<n>/`): без наблюдаемого эффекта — у такого имени нет кодового суффикса, класс code его
  не касается.
