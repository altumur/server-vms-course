## (д) Оценка решения доп. (9): отпечаток повтора и время приёма — генерировать; условия и пакет — прозой

Согласен с разрезом. Проверка по нормам:

- **Выразимость формой.** Проекция/нормализация put/delete/batch (закрытый набор полей на операцию), `admitted = max(часы, последнее)`, `A > not_after` → expired, `A ≤ not_before` → early, эффекты на метаданные приёма (R088/R132) — всё это замкнутые правила без ветвления по семантике данных; форма 24–38 строк / выход 90–170 из разбора выглядит правдоподобно.
- **Устойчивость (Т2 доп. (8)).** Независимо пересчитал по журналу: последние смысловые правки места — K37-05 (2026-10-16: лишние поля верхнего уровня вне отпечатка), прогон 36 (2026-10-16: delete-повтор без items), s2/s3/s5 (2026-11-05: равенство границ, доля при откате часов), clarify (2026-11-06: отказы продвигают приём), extended (2026-11-06: повтор продвигает приём сохранно). Для выбранного среза (отпечаток + время) все пишутся строкой/значением формы — 5–6 из 5–6, против порога 1/5; для ядра целиком (floor, batch) 2/8 не проходит — вывод доп. (9) подтверждается моим чтением.
- **Граница среза — что проверить при написании формы** (не находка, условие): (1) проекция должна быть закрытой — тогда исключение лишних полей (K37-05) получается по построению, иначе оно останется скрытой прозаической зависимостью генерируемого кода; свидетель сц. 23 уже есть, шов на повтор с лишним полем не помешает; (2) отпечаток границ времени — binary64 по R090, включая написания (s11); (3) порядок «память id → время → guard → CAS» остаётся прозой и чеклистом -25 — форма не должна молча навязывать свой порядок, точка сшива (генерируемая функция получает уже принятое решение об условиях) должна быть названа в норме явно.
- **Судья 380–640 против выхода 90–170** — судья крупнее выхода в 2,5–7 раза; это отклонение от меры доп. (2) п. 2 разбор вынес на решение «Архитектора», и доп. (9) это решение и есть — процедура соблюдена.
- Расхождение с доп. (6) п. 4 доп. (9) оговаривает явно; швы s7–s15 уже лежат в приёмке и закрывают уточнения чтением до появления формы — риск окна «норма уточнена, формы ещё нет» прикрыт.
