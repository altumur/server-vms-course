**ADR-0083 (65): Б 0, С 0, М 0. Новых замечаний нет.**

- Неустановленный автор ноутбучного запуска назван неизвестным, а не заменён предположением. Уточнены запрет `darwin`, обязательная обёртка судей и серверный ключ; новый зачётный этап по (63) всё равно начинается с нуля. Вывод об отсутствии признаков выноса отнесён к указанному разбору журнала, не выдаётся за аудит этого ревьювера.
- Строковая команда исполняется обёрткой внутри отдельной песочницы с другим пользователем и чистым окружением. Следовательно, граница (61) остаётся на уровне исполняемого кода; отказ CR/LF и разделение сборки/ветеринга не подменяют изоляцию. Разрешение оболочки внутри этой границы уточняет прежнюю форму запуска судей, не открывая ей права клиента API.
- Очистка охватывает корни файловой системы сервера, но сохраняет пути API, необходимые для диагностики сценариев. Страж перед отправкой отдельно проверяет пути текущего хоста и ключ. Атомарная запись состояния и серверный маршрут запуска остаются в силе.

Проба функций с поддельной обёрткой без API не заменяет обязательных серверных канареек перед настоящим ключом по (61). Текст (65) этого условия не снимает. Проверка фактической изоляции и ревью свойств будущего кандидата P/01 остаются следующими отдельными работами.

**Итого: Б 0, С 0, М 0.** Дополнительного решения по результатам ревью не требуется.
