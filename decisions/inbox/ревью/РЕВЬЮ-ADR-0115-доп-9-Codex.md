# Ревью ADR-0115, дополнение (9), Codex

Проверен текст на `origin/main` **f54c19208**, вместе с доп. (2) п. 1, (3) п. 2, (8) п. 1 и прежней находкой С1 Codex. Сверено с уже прочитанными `plugin.schema.json` и P/03.6 Н1.7. Код клонов не запускался.

**Счёт: Б 0, С 0, М 0 — чисто.** С1 по дополнению (8) закрыта: `readonly` исключены из установочного ввода; их отсутствие не требует значения от оператора, они остаются состоянием, которое публикует держатель. Установка получает только записываемые оператором параметры без `default`. Новых противоречий в уточнении нет.
