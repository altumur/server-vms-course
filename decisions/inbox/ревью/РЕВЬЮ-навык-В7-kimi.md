**Место.** `check_spec.py:2370-2373`: список уроков по умолчанию — только строки, чей `NN-<каталог>/NN-<каталог>.md`
существует; прямой проверки «у строки lessons.tsv есть файл урока» нет (у модуля VMS она есть — `vms_module`,
«no directory VMS/…»).

**Факт.** Проба на копии: снял `Platform/07-console-module/07-console-module.md` — новых ошибок о пропавшем уроке
нет; сегодня удаление ловится косвенно: +4 «missing link target» (урок 06 ссылается), у уроков 05 и 10 — красное
`outcome_readers` (пропал читатель `*` ролей resource/domainconsole). Единственный след в общем случае —
`lessons=9` в COUNTS. Урок без входящих ссылок и без чтений `*` выпал бы молча; заодно молча перестали бы
расходоваться его строки реестра исключений (`stale()` зовётся только по обработанным урокам).

**Рекомендация.** Красное на строку lessons.tsv, чей файл урока отсутствует (как у VMS). Сегодня содержимое курса
дыру прикрывает — поэтому мелкая.

### М-2 (мелкая). `test_sections_keep_dialect_meaning` на дереве без git падает сырым CalledProcessError

**Место.** `v7/test_spec.py:352-355`: `subprocess.run(["git", "-C", ROOT, ...], check=True)` без обработки отказа.

**Факт.** На копиях `git archive` (дерево без `.git`/метки) тест — ERROR с трейсбеком `CalledProcessError`, а не
сообщением «нужна метка dialect-reference-dc94d0fd1». Красное, не молчание — по Н-1 это допустимо; но причина не
названа, а копии без `.git` — штатный способ прогона перехода (PLAN-TRANSITION п. 1.4 говорит о дереве после
пакета). На дереве с меткой тест зелёный (проверено на worktree).

**Рекомендация.** Поймать `CalledProcessError`/`FileNotFoundError` и падать с именем метки и команды.

### М-3 (мелкая). `Places.child` сверяет имена `patternProperties` через Python `re` — `$` совпадает перед `\n`

**Место.** `v7/spec.py:127-130`: `re.search(pat.replace("\\Z", "$"), seg)`.

**Факт.** Это тот же дефект D1, который стек ловит у значений (`test_trailing_newline_full_match`): ключ `"a\n"`
совпадёт с шаблоном `^(?:a)$`, и путь исходов `/a\n/…` сойдёт за место схемы, хотя стек В7 такой ключ не примет.
Затрагивает только проверку авторских `outcomes.tsv` (место — да/нет), не судьбу данных.

**Рекомендация.** Сверять `re.fullmatch` по телу шаблона без якорей (или заменять `$` на `\Z`, а не наоборот).
