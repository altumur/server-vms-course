# Ревью ADR-0119 доп. (8) (Claude)

main 11c450442. Сверено с ADR-0098 §4 (потолок таблицы ролей), §5 (удаление).

**Счёт: Б 0, С 0, М 2.** Только М — в нормы без дополнения. П. 1 снимает М1, М2 (7), п. 3 закрывает доставку заголовка.

**М1. Ссылка роли на саму себя не должна держать её удаление.** Своя роль супервизоров теперь разрешена (п. 1), поэтому у роли R может быть `supervision: {exp: R}`. По правилу «удаление роли под ссылкой — `409`, пока ссылка стоит» R не удалить, пока не снимешь её собственное поле. Норма P/08.4: ссылки из самой удаляемой роли не считаются.

**М2. Потолок — не только при записи роли или гранта.** ADR-0098 §4 уже проверяет `ROLES_TABLE_MAX` до приёма правки ролей, групп, людей и `domain/grants/<член>` (`409 roles table too large`). П. 2 перечисляет только роль и грант — норма не должна сузить перечень. Роль с `supervision` и её роль супервизоров теперь в таблице **каждого** члена (доп. (6) п. 2). Поэтому проверка их записи и записи групп в их `assigned` идёт по таблицам всех членов, а не только тех, где у роли есть строки. Назвать это в P/08.4.
