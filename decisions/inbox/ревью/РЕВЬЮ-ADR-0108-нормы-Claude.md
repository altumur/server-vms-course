## С

**С1. Выключить карту одной камере: ADR — «нельзя», норма — «можно `enabled: false`»; строка РАСХОДИТСЯ стоит без решения.** ADR доп. (1) п. 6: «Выключить карту одной камере нельзя: „со всеми“. `extraArchives` показывает такую запись только для чтения». Норма V/01.6 `:211`: «**Выключить карту одной камере** можно только `enabled: false` в строке: дверь строку заказа не закрывает (P/06.1 Н1.1), заказ её не повторяет. Снятую оператором строку держатель заказывает снова». V/11.3 `:197` к тому же выводит `recordMode` из `enabled: false` («`none` при `enabled: false`»). Норма дала оператору ход, который ADR запретил. Дверь таблиц его пропускает, а форма consolem — нет (`readOnly: true`).

Итог: две реализации разойдутся. Одна отказывает `enabled: false` у строки `cam-*` — по ADR, другая принимает — по норме. А `adr-norms.tsv` оставляет РАСХОДИТСЯ.

**Предложение.** Решить одно из двух.
- **(а)** Дополнением к ADR-0108 принять ход нормы: «выключить карту камере — `enabled: false` строки `cam-<cam>-<том>` дверью таблиц, не формой». Он честен: «со всеми» про заказ, а не про запрет.
- **(б)** Убрать ход из нормы: дверь отказывает `enabled: false` у строки заказа.

Мой выбор — (а). Ход уже есть, вреда не видно, и V/11.3 его показывает.
