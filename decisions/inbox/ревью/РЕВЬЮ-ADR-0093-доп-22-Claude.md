# Ревью текста: ADR-0093 доп. (22), разбор ревью (21) (Claude)

Доп. (22) на origin/main 1c5b2f37e. Сверено чтением с доп. (19)–(21) того же ADR, V/11.13 Н1.6 (строка «реле шага: у камеры таких больше одного — `has` имени; у реле ещё „relay N“») и `assist-pilot` `rules/ground.py:201` (`\b(relay|реле)\s*N\b`).

**Счёт: Б 0, С 0, М 2.** Чисто по существу: С1 и М1 отчёта (21) исполнены. Два уточнения слов.

**М1. «Вопрос всегда» не привязан к слову «open».** П. 1: «Реле, названное в просьбе номером…, — вопрос всегда». Вся цепочка (19) п. 2 → (21) п. 2 говорит о слове «open», а в п. 1 его нет. Текст нормы, переписанный отдельно, велит спрашивать и при «turn on relay 2», и при «включи реле 2», где вопроса нет: по V/11.13 строка `state` судит `closed` словом `state_on`. Дописать: «„open“ у реле, названного номером, — вопрос всегда».

**М2. Какие формы — «номером».** Примеры п. 1: `relay N`, `output N`, «реле 2 у Gate Barrier». Русского «выход N» нет, хотя `output N` есть. Строка V/11.13 знает только «relay N», у Пилота — `\b(relay|реле)\s*N\b`. Назвать одно выражение для обоих мест, например `\b(relay|output|реле|выход)\s*N\b`. Иначе «открой выход 2» пойдёт по имени устройства, а «open output 2» — в вопрос.

## Сверено и держит

- П. 1: три ветки не пересекаются:
  - реле названо номером — вопрос;
  - реле названо самим устройством («open Gate Barrier») — имя устройства;
  - иначе — последнее слово `title` реле по доп. (21) п. 2.

  Случай «open relay 2 of Gate Barrier» из (21) С1 решён: это вопрос.
- П. 1: если на устройстве несколько реле, а названо оно самим устройством, работает прежняя строка V/11.13 «у камеры таких больше одного — `ask_admin` which one». Вид прохода её не обходит.
- П. 2: обе замены названы, предел (21) п. 1 стоит один. Для внесения цепочка (19)–(22) читается без противоречий.
