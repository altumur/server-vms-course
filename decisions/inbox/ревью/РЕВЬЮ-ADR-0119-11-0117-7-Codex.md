# Ревью ADR-0119 (11) и ADR-0117 (7), Codex

Проверено на `origin/main` **4e8d96aa6**, вместе с прежними дополнениями. Прочитаны отчёты к ADR-0119 (10); сверены P/06.1, договор сторожевой/передачи (билет), V/08.6–V/08.8, манифест `exp`, требования «Консоли» (`ExportCreate`, область кадра и последнее уточнение владельца). Код клонов и тесты реализации не запускались.

**ADR-0119 (11): Б 0, С 0, М 0. Новых замечаний нет.**

- Прежнее С1 Codex к (10) закрыто: назван путь административной уборки части без держателя через backend; просьба отсутствующему держателю больше не является единственным путём.
- Область `writes_via` ограничена сеансами и билетами. Собственные записи состояния, удаление держателем и каскады консоли остаются исполнимыми.
- Право человека билета сохраняется. Временный `NOT_SUPPORTED` ограничен изменением надзора, а не любой правкой роли с уже сохранённой политикой.

**Quint:** агент проверил готовность входа для модели гонки уборки и появления держателя. `plat_to 0119 = 8`; доступная выгрузка `cammeta-specs` **b7d4b651** (курс **557e0d31f**) не содержит `writes_via`. По `cammeta-quint/RESUME.md` модель и CT не запускались: нужны выгрузка норм дополнения (11), согласованная V/08.8 и `plat_to >= 11`. Результат здесь — ревью текста, не проверка конкурентного алгоритма будущей реализации. `quint_to` не изменялся.

adr: 0117 (7)

**ADR-0117 (7): Б 0, С 0, М 0. Новых замечаний нет.**

- Область привязана к `cameras[i]`, как в `ExportCreate` требований; в каждую часть попадает область только её камеры. Прежнее общее поле настроек не служит источником рамки всех камер заказа.
- Обрезка явно распространяется на архивный и живой кадр JPG/PDF, заменяя прежнее «jpg как есть» при заданной области. Представление долями исходного кадра и границы координат 0…1 сохраняются; новые проверки положительных размеров и суммы координаты с размером не дают рамке выйти за изображение.
- Неверная рамка имеет 422 и указатель на область конкретной камеры; контракт форка меняется вместе с `/exports`. Преждевременная правка действующей консоли не требуется.

При переносе в нормы согласованно обновляются описание части/схема, обработка кадра и перевод `cameras[i].area` в V/11. Дополнительного ADR по результатам этого ревью не требуется.
