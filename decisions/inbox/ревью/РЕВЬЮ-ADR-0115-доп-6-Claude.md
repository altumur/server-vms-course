# Ревью текста: ADR-0115 доп. (6) (Claude)

**Счёт: Б 0, С 0, М 1.**

Закрыто:
- **С1 (5).** Сборщик — генератор урока `VMS/12-psim`. Канон ∪ фрагменты всех установленных плагинов по имени подсистемы, любое изменение — пересборка с нуля. Приёмка на двух плагинах со снятием и обновлением VMS.
- **М1 (5).** `ref_label` — имя поля, подпись читается при ответе.
- **М «Спецификации».**
  - `<т>_seen` снимается, когда нет `<т>` с тем же ключом.
  - Столкновение `status` с `<т>.<поле>` — отказ.
  - Поле единицы-плагина не совпадает с параметрами psim.
  - `severity: alarm` — не класс `alarm`.

**М1. Подпись «при каждом ответе» — цена перечня.** П. 2: `backend` читает подпись из строки источника при каждом ответе. У перечня объектов (`GET /units` вида с `source`, мультивыбор `cameras`) это чтение на каждый id каждой строки страницы: при 200 строках по 5 камер — до 1000 чтений на страницу. Назвать цену и способ: одно чтение таблицы источника на страницу, по набору id, как перечни V/11.3 Н1.2б. Тот же порядок цены, что «2 + R × …» шкалы, — предел или правило. Только М — в нормы без дополнения.
