# Ревью текста: ADR-0093 доп. (29) (Claude)

Доп. (29) на origin/main 6e7596499. Сверено с V/11.11 Н1.2 (`norm`, `name_in`, «Числа текста» `11.11-backend.norms.md:68`–`:91`) и V/11.13 Н1.6 (`has`, `opens`, `passage`). Выражение п. 6 проверено в Python 3.12 `re` с границами доп. (25).

**Счёт: Б 0, С 0, М 3.** Обе С и все М отчёта (28) исполнены. Lookbehind снят, имена вырезаются до слов состояния, порядок «после» вернулся, камера — по последнему слову.

**М1. «Вырезаны» — каким правилом и чем заменены.** П. 3 отсылает к V/11.11 Н1.2, где вырезаются «все вхождения имён… (`name_in`)». Это вхождение подряд. А «назван» в V/11.13 — `has`: все слова имени есть где-то в тексте, порядок не важен. Пример: «lock the back door» `has` имени Back Door Lock. Подряд вхождения нет, и вырезать нечего, `lock` остаётся глаголом — так и нужно. Назвать: «вырезается каждое вхождение `name_in` (подряд), заменяется пробелом». Без пробела соседние слова склеятся, а граница доп. (25) по склейке судит иначе.

**М2. Какие слова судятся по вырезанному тексту.** П. 3: «`other_state` и прочие слова состояния». Назвать их списком: `open_word`, `other_state`, `state_on`, `state_off`. `passage` и `numbered` ищут имя и номер и судятся по полному тексту. Иначе реле «Open Gate» с «turn on the Open Gate» даст `opens` по имени.

**М3. После `#` и `№` пробела не пускает.**

| Текст | п. 6 | `(?:#\|№\|no\.?)?\s*N` |
|---|---|---|
| relay #2 | да | да |
| реле №2 | да | да |
| relay no. 2 | да | да |
| реле № 2 | **нет** | да |
| relay # 2 | **нет** | да |
| relay 21 при N = 2 | нет | нет |

«№ 2» с пробелом — обычный русский набор. Предложение: `(?:relay|output|реле|выход)\s*(?:#|№|no\.?)?\s*N`. «relay number 2» и «реле номер 2» не ловит ни одно выражение. Добавить `number|номер` или назвать пределом.

## Сверено и держит

- П. 1: строка V/11.11 Н1.2 о диалекте заменена, флаг `i` снят: `norm` уже даёт нижний регистр.
- П. 2: три выражения названы, буква V/11.11 — `[0-9a-zа-я]` после «ё → е», `name_in` не трогается.
- П. 4: порядок `closed` → `wait` → `open`. План `open`, `wait`, `closed` судится целиком. Решение «порядок не судится» снято явно.
- П. 5: «Front Door Cam» — не проход, «open Gate Barrier» с камерой Gate Barrier — проход. Согласно с (21) п. 2 и (22) п. 1.
- П. 7: `[0-9]` вместо `\d`, пробелы Юникода — в обычный пробел до сверки. После этого `\s` и `\S+` одинаковы в RE2, JS и Python.
