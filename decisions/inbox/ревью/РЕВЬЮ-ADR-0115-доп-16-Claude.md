# Ревью текста: ADR-0115 доп. (16) (Claude)

Доп. (16) на main e886ebc1e. Сверено с моим отчётом норм V/12 (`РЕВЬЮ-ADR-0115-нормы-VMS-Claude.md`), P/06.5 Н3 «`/where/<id>`» (`06.5-console.norms.md:433`, `:473`–`:476`) и договором сторожевой (`gate-and-pass.md:107`–`:132`, кука `w2c_token` `:170`).

**Счёт: Б 0, С 2, М 1.** Б1 по входящим заголовкам закрыт: `Cookie`, `Authorization` снимаются, кука — `psim_<plugin_id>`. П. 3 — правки норм названы верно.

## С

**С1. Обратное направление: ответ плагина с `Set-Cookie`.** П. 1 чистит запрос, а ответ плагина уходит браузеру как есть. Куки по порту не разделяются. Ответ плагина `Set-Cookie: w2c_token=<токен атакующего>; Path=/` на двери `https://SERVER_NAME:<порт>` браузер примет для всего хоста. Кука консоли того же имени будет заменена: человек дальше работает в консоли под чужой личностью. Это вход под чужим именем, обратный случай Б1. Так же плагин может поставить `psim_<другой id>`.

**Предложение.** Дверь снимает `Set-Cookie` из ответов плагина целиком: своих кук страницам psim не нужно, сеанс держит дверь. Приёмка: плагин отвечает `Set-Cookie` — браузер его не получает.

**С2. «Токен страницы — по праву `edit`» платформа не судит: `/where` выдаёт токен по `view`.** П. 2. P/06.5: «token выдаётся по view на единицу», `routes` — все маршруты `door.routes` с допуском `token`, по рангу они не отбираются. Тогда `edit` проверяет только `backend`, когда отдаёт ссылку. Человек с `view` зовёт дверь консоли `GET /psim-<id>/where/plugin` сам, получает тот же токен с маршрутом страницы и открывает её. ADR-0115 доп. (1) п. 1 именно этот обход и закрывал.

**Предложение.** Одно из трёх:
- Правка платформы: маршруты токена `/where` по `rights.routes` ранга (`rights.routes: {edit: [<маршрут страницы>]}`). Тогда смотрящему маршрут не выдаётся, дверь отвечает 401. Это ещё одна правка P/06.5 сверх загрузчика — назвать её в «Платформа после».
- Дверь адаптера судит ранг сама: по `user` токена читает гранты. Чтения грантов у воркера нет.
- Предел: «`edit` — только у ссылки `backend`; токен консоли по `view` открывает страницу, запись настроек правом просмотра — предел».

Выбрать и записать.

## М

**М1. WebSocket.** V/12.3 Н1.6: «WebSocket — насквозь». Снятие `Cookie` и `Authorization` — и у запроса рукопожатия `Upgrade`, а `Set-Cookie` (С1) — и у его ответа `101`. Сказать прямо, иначе «насквозь» прочтут как «заголовки как есть».
