## С1. Существенная: путь исходной таблицы не задаёт table конверта

**Место:** `Platform/common/vectors/probe-tables.tsv:3` и `:13`.

Шапка определяет: `table: the probe table, a repository-relative path`. Значение строки:

```text
Platform/01-store/forms/write-checks.probes.tsv
```

При этом `Platform/common/vectors/wire.md:143` утверждает, что судья читает конверт из строки формы, а `:147` по-прежнему задаёт в прозе другое значение поля конверта: `table is write-checks.probes.tsv`. `Platform/common/acceptance/PROFILE.md:135` требует имя таблицы внутри пакета. В форме нет отдельного имени для конверта и нет правила преобразования пути в это имя: остальные примечания задают case, variant, files, cells, skip и native.

**Контрпример:** взять первую исполняемую пробу, физическая строка 16 `Platform/01-store/forms/write-checks.probes.tsv`, case `line-16`. Перенос одноимённого поля из новой формы даёт:

```json
{"package":"01-store/write-checks","table":"Platform/01-store/forms/write-checks.probes.tsv","case":"line-16"}
```

По прежнему и сохранённому договору тот же фрагмент конверта должен быть:

```json
{"package":"01-store/write-checks","table":"write-checks.probes.tsv","case":"line-16"}
```

Остальные обязательные поля здесь опущены только для показа различия. Получить второй вариант из формы можно, лишь самостоятельно выбрать basename либо снова прочитать специальный абзац wire.md. Общий PROFILE не задаёт операцию basename над путём источника.

**Нарушенный источник и последствие:** п. 5 цели P01.259 требует машинную форму транспорта без нового поведения; ретро §4 отдельно называет пакет и таблицу, извлекаемые из прозы. Сейчас имя table всё ещё задано только прозой. Движок P01.255, который переносит одноимённое значение из формы в конверт, передаст иную строку. Реализация, принимающая опубликованное имя `write-checks.probes.tsv`, вправе отклонить такой запрос; возможен ложный отказ команды реализации. Это статический контрпример договора, кандидат не запускался.

**Происхождение:** наведено коммитом `4ae6c4271`, добавившим форму и утверждение о чтении конверта из её строки; сохранено в `fcdf8cd86`. На `4adac1a13` формы ещё нет, а `wire.md` явно задаёт basename, поэтому прежнего расхождения двух носителей нет. Прежняя зависимость транспорта от прозы была раньше и этой частью переноса не устранена.

**Что исправить:** однозначно определить в договоре формы отображение исходной таблицы в поле `table` конверта — отдельным значением формы либо общим правилом преобразования, сохранив прежнее имя. Согласовать схему, ссылки en/ru и квитанцию, если выбранное исправление их затронет. Проверить построение полного конверта хотя бы одной существующей пробы непосредственно по форме без специальной ветви для P/01.
