# Ревью текста: ADR-0093 доп. (24), разбор ревью (23) (Claude)

Доп. (24) на origin/main 7522d1cc6. Сверено чтением с доп. (21)–(23), V/11.13 Н1.6 (`tokens`, `hit`, `11.13-backend.norms.md:135`–`:137`). Проверено исполнением на ноутбуке: Go 1.22.10 `regexp`, Node `RegExp` с флагами `i` и `iu`, Python 3.12 `re`.

**Счёт: Б 0, С 1, М 0.** По смыслу чисто: «открой» к реле номером — вопрос, у реле прохода — включить. С1 — о записи выражений всей цепочки (21)–(24). Ошибка и моя: `\b` с русскими основами я сам предложил в (20) С2 и не проверил вне Python.

## С

**С1. `\b` перед русской основой в Go и JS не совпадает никогда.** Доп. (24) `\bоткр`; доп. (21) п. 2 `\b(…|двер|шлагбаум|ворот|замок|замк|турникет)`; доп. (23) `\b(relay|output|реле|выход)\s*N\b`.

В RE2 (Go) и ECMAScript `\b` — граница по ASCII-`\w`. Кириллица для них не буква слова, поэтому между пробелом и «о» границы нет. Проверено:

| Выражение, текст «ну открой реле 2» | Go `regexp` | Node `/…/i`, `/…/iu` | Python `re` |
|---|---|---|---|
| `(?i)\bоткр` | false | false, false | true |
| `(?i)\b(relay\|реле)\s*2\b` | false | — | true |

Реализация на Go или проверка в браузере молча теряет все русские ветки:
- «открой реле 2» не станет вопросом;
- «Шлагбаум» не станет проходом;
- «реле 2» не станет номером.

Векторы на Python при этом зелёные. V/11.13 Н1.6 диалект выражений не называет (`:137` — «регулярное выражение … без учёта регистра»), а `tokens` там же задаёт буквы явно: `[0-9a-zа-яё]+`.

**Предложение.** Одной строкой в V/11.13 Н1.6 рядом с `hit`: «`\b` в словаре — граница слова `tokens`: `(?<![0-9a-zа-яё])` перед, `(?![0-9a-zа-яё])` после». Lookbehind в RE2 нет, поэтому для Go — `(?:^|[^0-9a-zа-яё])` в начале выражения. Либо писать в `words.json` и ADR сразу `(?:^|[^0-9a-zа-яё])(двер|…)`. Векторы — по одному с русским словом в начале фразы и после пробела. Касается и `\bon\b`, `\bpulse\b` в `state_on`: там ASCII, они держат, их не трогать.

## Сверено и держит

- «открой», «открыть» к реле номером — вопрос, как «open». Довод назван: канон `open` у реле — разомкнуть (V/01.4 `:40`), речь — включить.
- У реле прохода «открой» — включить, как прежде: согласно с `state_on` (`открой`) и с доп. (21) п. 2, (22) п. 1.
- Порядок веток не меняется: номер → вопрос, само устройство → имя устройства, иначе последнее слово `title`.
