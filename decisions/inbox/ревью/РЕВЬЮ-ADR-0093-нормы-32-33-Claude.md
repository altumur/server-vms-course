# Ревью норм: vms/words-93c, ADR-0093 доп. (32)–(33) (Claude)

Слияние a14c8f36e на main: V/11.13 Н1.6, V/11.11 Н1.2 (`norm`), `harness/rules/words.json` (`default_yes`, `default_no`, `conditions.recording`), `rules-words` 131 случай (+12), `plan-check/text.json` (+1), `adr-norms.tsv` +8.

Проверено исполнением:
- **Паритет.** `default_yes`, `default_no` и `recording` прогнаны на 15 фразах в Go 1.22.10 `regexp` и в Python 3.12 `re`, совпадения одинаковы.
- **Векторы.** Все случаи из `adr-norms.tsv` (`ask-default-*`, `recording-ru*`) в `cases.json` есть.

**Счёт: Б 0, С 0, М 1.** Доп. (32) п. 2 и (33) внесены по словам. Мои М (33) и М1 норм (28)–(31) тоже: `’` и `‘` → `'` в V/11.11 `norm` и в тексте хода V/11.13, `dont`, `won't`, `shouldn't`, одно слово между.

| Текст | `default_yes` | `default_no` | итог |
|---|---|---|---|
| with no answer, do raise it | да | нет | yes |
| no answer counts as yes | да | нет | yes |
| нет ответа считается да | да | нет | yes |
| нет ответа — поднимай | да | нет | yes |
| нет ответа — не поднимай | да | да | не yes |
| no answer — don't raise it | нет | да | не yes |
| no answer - dont raise it | нет | да | не yes |
| нет ответа — дальше по сценарию | нет | нет | не yes |
| **нет ответа — подними тревогу** | **нет** | нет | **не yes** |
| **нет ответа — поднять тревогу** | **нет** | нет | **не yes** |
| если камера не пишет (`recording`) | — | — | да — предел (33) п. 3 |

**М1. «Подними», «поднять» не `default yes`.** Основа `поднима` ловит только несовершенный вид: «поднимай», «поднимать». А «нет ответа — подними тревогу» — самая обычная форма просьбы: совершенный вид, повелительное. Основа `подним` берёт «поднимай» и «подними», `подня` — «поднять». Предложение: `(?:подним|подня)` в обоих выражениях, `default_yes` и `default_no`, и векторы `ask-default-yes-ru-podnimi`, `-podnyat`. Цена: «не забудь поднять тревогу» тогда отсекает `default_no` (одно слово между), и вместо записи будет вопрос. Это та же цена, что предел «отрицание по всему тексту», и её стоит назвать рядом с ним.

## Сверено и держит

- `default_yes`:
  - «нет ответа» добавлено в первую часть;
  - вторая часть — «do raise» и `yes` с двумя границами, «да» с двумя границами, «поднима» с одной;
  - «дальше» не «да».
- `default_no`: `не`, `don'?t`, `do not`, `never`, `won'?t`, `shouldn'?t`, вплотную или через `\S+`, перед `поднима`, `raise`. «Don't forget to raise» — два слова между, не отрицание: верно.
- Строка таблицы: `default yes` = `hit` `default_yes` и нет `hit` `default_no`. Слово ошибки прежнее, оно ведёт к вопросу, а не к записи.
- Пределы названы: «не пишет» — `recording-ru-not-gap`; отрицание по всему тексту.
- `recording` — `пишет` с границей начала, «пишется» попадает. «Запишет» и «опишет» не попадают.
- `norm` V/11.11 и текст хода V/11.13 одинаково переводят `’`, `‘` в `'`. Вектор `said` для `rights` с «don’t» добавлен.
- `adr-norms.tsv`: (32) п. 1 и (33) п. 4 — НЕ НОРМА (эталоны и пересчёт Пилота), (33) п. 3 — ПРЕДЕЛ, у остальных пунктов есть вектор.
