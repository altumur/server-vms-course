## Покрытие и пределы

Работа выполнена двумя фоновыми агентами. Часть выводов опирается на автоматические поиски, а не на чтение.

**M, 753 файла.** Сквозные проверки по всем: токены-хэши против всех файлов J, 1820 таблиц и каталогов случаев J против токенов M, шаблон «sc. N»/«step». Содержимым прочитаны целиком 21 файл, ещё 8 целиком с обрезанием строк до 620–900 символов, `runner-targets.tsv` целиком, около 20 — строками. **Около 700 файлов M — только счётчиками,** включая основные тексты норм и 305 таблиц `data/` (только заголовки). Ожидаемое значение, записанное не литералом и не совпадающее с токеном J, эти проверки не находят.

**J, 2710 записей.** Целиком 8 файлов, частично около 24, автоматическим отбором 122 (`*.cases.*`, README приёмки, 3 README векторов), около 2560 только по пути и виду записи, включая данные `acceptance/` и `vectors/`. Разделённые файлы с прежними текстами по истории git поштучно не сравнивались. Поэтому «потерь нет» относится к перечисленному выше, а не ко всему J.

**Перепроверено основным окном по файлам среза:** sha фильтра; диспозиции всех файлов из Б1, Б2, С1, С3, М1; цитаты и номера строк Б1, Б2, С1, С2 (часть номеров строк исходных частей была неверна и исправлена); нули вхождений Б2 по всем M; отсутствие литералов P01.34 Б1 и С2 по всем M; столбцы `runner-targets.tsv`.
