# Ревью текста: ADR-0116 доп. (5) (Claude)

Доп. (5) на main 3a993badb, коротко. Сверено с P/06.5 Н2 «GET /manifest» (`default` секретных полей — null) и с моим отчётом к (4) (`РЕВЬЮ-ADR-0116-доп-4-Claude.md`, С1).

**Счёт: Б 0, С 0, М 1.** Граница Codex С1 сохранена: значения секретов не выдаются ни в полном манифесте, ни в `/kinds`.

**М1. Не названа форма признака «задано».** «Вместо значения — признак «задано»»: в `ManifestView` у `*_secret` — `default: null`. Признак — новый ключ (например, `default_set: true`) или иное значение `default`? Ключ нужно назвать: форма читает его, чтобы показать «умолчание задано». Форму полного ответа выбрал доп. (6) (`GET /manifest/<sub>/source`) — признак вписать в её схему.
