# Ревью текста: ADR-0093 доп. (26), разбор ревью (25) (Claude)

Доп. (26) на origin/main d86f40527. Выражение «switch … off» проверено исполнением: Go 1.22.10 `regexp`, текст через `strings.ToLower`, границы доп. (25) `(?:^|[^0-9a-zа-яё])` и `(?:$|[^0-9a-zа-яё])`.

**Счёт: Б 0, С 0, М 2.** М1 отчёта (25) исполнено. Пример п. «switch Лобби Cam off» в Go совпадает.

| Текст | Совпало |
|---|---|
| switch Лобби Cam off for 15 minutes | да |
| Switch the Lobby Cam off | да |
| switch Lobby-2 Cam off | да |
| switch Lobby Cam off. | да |
| switched it off | да |
| turn off the light | **да** |
| switch Lobby Cam (east) off | **нет** |

**М1. `{0,3}` пускает «turn off the light» в `cam disable`.** Ноль слов между глаголом и `off` даёт совпадение на всякое «turn off», «switch off»: свет, сирену, реле. Это было и у Пилота, доп. (26) его переписало как есть. Слой пропускает подмену «выключить реле» → «выключить камеру». Ловят её показ (V/11.13 Н1.8) и строка `minutes`: срок у `cam disable` обязателен. Назвать пределом рядом с `выключ` / `switched_off` доп. (20) п. 4. Есть и другой путь: `{1,3}` и отдельная ветка «switch off the camera|cam» — шире, чем нужно для ревью текста.

**М2. Знаки в имени между словами рвут совпадение.** `[0-9a-zа-яё-]+` не пропускает скобки, точку, `#`, апостроф: «switch Lobby Cam (east) off», «switch Cam #2 off», «switch O'Hare Gate off» — нет. Имена камер оператор пишет свободно. `\S+` держит одинаково во всех движках, пробел для них один. Для «слова между» он надёжнее, а границу слова по `tokens` оставить как есть.

## Сверено и держит

- `\w`, `\W` под тем же запретом, что `\b`. Буква слова `[0-9a-zа-яё]` совпадает с `tokens` V/11.13.
- `[0-9a-zа-яё]*` после глагола даёт `switched`, `turning`. Граница в конце после `off` не даёт совпасть «offline».
- «Остальные выражения с `\w` переписываются тем же правилом»: в словаре курса такое одно, `не ответ\w*` у `default_yes`. Обход — отчёт (25).
