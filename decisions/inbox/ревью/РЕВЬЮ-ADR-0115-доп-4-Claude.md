# Ревью текста: ADR-0115 доп. (4) (Claude)

**Счёт: Б 0, С 0, М 0 — чисто.** Сверено с P/02.1: `tableName` — `[a-z][a-z0-9_-]{0,31}` и перечень запрещённых имён (`:854`, `02.1-installer.schema.json:3725`).

- **П. 1.** Связи `display.fields`, `display.options` расширены на поля таблиц `<т>.<поле>`. Точка в имени поля единицы запрещена, а имя таблицы точки не несёт по грамматике, поэтому разбор по первой точке однозначен. «Платформа — только загрузчик» держится.
- **П. 2.**
  - `<т>` ≤ 27 знаков — верно: `<т>_seen` даёт 32, предел `tableName`;
  - совпадение `<т>_seen` с другим видом или запрещённым именем — отказ генератора. Мои М1, М2 (3) закрыты;
  - `readonly` вместе с `secret` — отказ: секрет не идёт в `worker.writes`;
  - строку `<т>_seen` снимает воркер вместе со строкой `<т>`;
  - поле единицы-плагина в каждой таблице — для `rights.unit_of`;
  - перечень `severity`;
  - предел `items.ref` мимо `backend` — «форма показывает его без подписи».
