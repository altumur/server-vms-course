# Ревью ADR-0115 доп. (35) (Claude)

Что читалось:
- main cd838182a: `decisions/0115-…` доп. (31)–(35);
- P/02.4-05 (`RestartSec=2`).

**Счёт: Б 0, С 1, М 1.**

С1 Codex к (33) закрыт:
- партии статусов идут по часам, раз в 1 с, чтение цели их не задерживает;
- две соседние партии видят одного голосующего с промежутком меньше 2 с;
- член, перезапущенный по `RestartSec=2`, лежит дольше 2 с, и запрос хотя бы одной партии приходит, пока он лежит.

Граница 2 с даже с запасом: запросы уходят раз в 1 с, поэтому лежащий дольше 1 с уже попадает под отказ какой-то партии.

Новое из-за развязки чтений: чтение цели теперь может закончиться позже следующей партии. Что делать с целью, которая пришла уже после разрыва, правило не говорит (С1).

## С

**С1. Чтение цели, начатое до разрыва и законченное после него, закрепляет старую цель.**

(35) п. 1:
- чтение цели идёт отдельно от партий, его срок — 1 с;
- живой в партии — тот, у кого `applied` ≥ цели, «закреплённой к этому ответу».

(31) п. 2 (в): разрыв снимает цель, следующий живой ответ закрепляет новую по (б).

Чего нет: что делать, если чтение цели началось после живого ответа, а разрыв этого голосующего опрос увидел раньше, чем чтение закончилось. В тот миг цели ещё нет, снимать нечего. Чтение кончается — и по (б) его итог становится целью.

Ход (s₀ — начало опроса):
1. Партия k: c ответил живым, цели нет — пошло чтение `commit` лидера. Лидер ответил сразу, commit = T, но ответ идёт к rollout медленно (до 1 с).
2. c падает через доли секунды. Записи после T кворум принимает, c их пропускает.
3. Партия k + 1: c не отвечает — разрыв. Цели у c ещё нет, снимать нечего.
4. Ответ на чтение из шага 1 приходит в срок — T становится целью c.
5. c поднимается (`RestartSec=2`) отстающим. Партия k + 3: ответ живой, applied ≥ T. Цель у c есть, поэтому новую по (б) не читают — c засчитан.
6. Перезапуск b ставит записи, пока c догоняет.

Так правило само нарушает гарантию (32) п. 4. По ней цель должна быть не ниже `commit`, прочитанного после первого живого ответа после последнего разрыва, то есть после партии k + 3. А T прочитан после партии k.

Окно узкое: падение посреди одного медленного чтения цели. Но та же гарантия, которую (32) п. 4 требует от иного порядка, нарушается в основном порядке.

Предложение — одной фразой к (35) п. 1:
- чтение цели принадлежит живому ответу, после которого оно начато;
- если до его конца какая-то партия дала разрыв этого голосующего, итог отбрасывается, цели нет;
- новую цель читает следующий живой ответ.

Это же — смысл слова «закреплённой к этому ответу»: цель закреплена, если её чтение кончилось до этого ответа и после последнего разрыва.

## М

**М1. Партия без живого ответа своего члена.** По (33) п. 3 лидер круга — `leader` ответа своего члена в этом круге. Если в партии свой член дал разрыв, лидера у партии нет. Тогда:
- цель читать не у кого;
- проход в этой партии невозможен;
- `-last` не может судить лидерство.

Это безопасно, так задумано и по смыслу. Но стоит сказать одной фразой: «партия без живого ответа своего члена не проходит и целей не читает». Тогда это не придётся выводить из трёх дополнений.

## Модель

Для вердикта не нужна: С1 — ход прямо по слову, тот же класс, что падение посреди опроса, которое (31) п. 3 внёс в «не проверено». Если перегонять, в `poll.qnt` нужны чтение цели с задержкой, обгоняемое партией, и судья гарантии (32) п. 4.
