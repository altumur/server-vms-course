# Ревью ADR-0119 доп. (14) (Claude)

main e66232f72. **Счёт: Б 0, С 0, М 2.**

П. 1 исполняет С1 (а) ревью (13): третий ключ по имени, общий для авторов, вход не задет. П. 2 — поле `limit` и `Retry-After`.

**М1. Цену ключа по имени назвать пределом.** Десять неудач за 900 с от любых авторов закрывают проверку этого супервизора на 15 минут во всех кластерах домена. Один автор с `EXPORT` может держать так супервизора постоянно: десять неверных паролей раз в 15 минут. Против этого стоит его же ключ «автор» 20/900 с, но цели он не мешает. Это цена, которую я предлагал. Записать её строкой «предел»: подтверждения этим супервизором стоят, вход его цел; виден виновник — `domain.verify.limited {limit: name}` с автором. Оператору нужен ответ: снять автору `EXPORT`.

**М2. Как неудача идёт в счёт.** Назвать:
- одна неудача идёт во все три ключа сразу;
- отказ `429` (любой ключ) в счёт не идёт, иначе ключ продлевает сам себя;
- успех счёт не сбрасывает — или сбрасывает только ключ (автор, имя);
- порядок проверки при нескольких сработавших — какой `limit` называет аудит (например, первый по порядку `pair`, `name`, `author`).
