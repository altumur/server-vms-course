# Ревью текста: ADR-0113 доп. (46), разбор ревью (45) (Claude)

Доп. (46) на origin/main 4032e30bd. Сверено чтением с P/01.1 «пакет» (`01.1-store.norms.md:141`, `:280`, `:425`–`:435`, `:476`) и P/04 Н3 «вывести_сервер» (`04-controller.norms.md:1064`–`:1088`).

**Счёт: Б 0, С 0, М 0.** Чисто: С1, М1, М2 отчёта (45) исполнены точно.

- **П. 1.** Слот в `writes` пакета отдачи защищён `cas` своей записи, стража на него нет. Это согласно с P/01.1 `:141`: «условие записываемой строки — её `cas`». Пакет атомарен, так что снятие вкладов под этим `cas` держит. Ветка «вне `writes`» перечислена полностью: слот, отданный судьбой до вывода, пакеты после отдачи, повтор доп. (44) п. 2.
- **П. 1 и п. 3 вместе.** В первом пакете может стоять страж на слот, отданный судьбой до вывода. Его 412 отказывает весь пакет отдачи, и по п. 3 пакет идёт целиком следующим проходом. Там захваченный слот уже несёт чужой `server` и в пакет не входит, поэтому круг сходится: каждый слот такой отказ даёт не больше одного раза.
- **П. 2.** Версия из ответа пакета — одна на пакет (`:431`). Для слота, отданного судьбой, и для повтора остаётся версия чтения прохода по доп. (45) п. 1, противоречия нет.
- **П. 3.** Отказ пакета отдачи повторяется целиком, поэтому отметка не пишется при неотданном слоте. Правило «убрать и не повторять» остаётся только пакетам после отдачи, где `409` нет и бывает только `412` стража.
