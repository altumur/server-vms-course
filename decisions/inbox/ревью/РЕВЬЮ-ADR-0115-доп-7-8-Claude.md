# Ревью текста: ADR-0115 доп. (8) (Claude)

Доп. (8) на main 49f6c575d. Сверено с P/02.1 (`unit.fields`, зарезервированные имена, `fixed`), P/06.3 Н1.9, ADR-0115 доп. (2) п. 1 и доп. (3) п. 2 (откуда `x-readonly`), psim-sdk c3d9ebb (`doc/adr/008-plugin-databases`, `schema/plugin.schema.json`).

**Счёт: Б 0, С 0, М 3.** П. 2 закрывает Codex С2 полностью. Вид экземпляра плагина и `<s>/<unit.rows>` остаются во фрагменте. Включение — шаг установки с пересборкой, `enabled` сборщик читает вместе с каталогом. Приёмка проходит весь круг. П. 1 исполним: строка создаётся сразу с проходящими значениями, а «черновика» нет. П. 3 чист.

## М

**М1. «В форме `enabled` — только для чтения»: ключа, который это выразит, нет, и отказ `PATCH` не назван.** П. 2. `x-readonly` в `/kinds` сейчас берётся только из `unit.state` (доп. (2) п. 1, доп. (3) п. 2). `enabled` же — поле `unit.fields`, его пишет шаг установки. По одному манифесту форма покажет его как обычное поле. `PATCH /units` вида экземпляра (доп. (5) п. 4: `GET` и `PATCH`) его запишет: `<s>/<unit.rows>` во фрагменте есть. Исход: в строке `enabled: true`, пересборки не было, фрагмента объектов в `calls` нет, виды объектов отвечают 401.
- **Предлагаю.** Правило перевода `backend`: у вида экземпляра psim поле `enabled` — `x-readonly`. `PATCH` с ним — 400 `VALIDATION_FAILED`, `field: /enabled`, `params.keyword: readOnly`.
- Запись дверью консоли мимо `backend` под `admin` пересборку не запускает. Это предел, его стоит назвать рядом с пределом `items.ref` доп. (4) п. 2.

**М2. Параметр без `default`, у которого пустая форма проходит схему, установке не нужен.** П. 1 требует начальное значение каждого параметра без `default`. В psim такой параметр бывает и необязательным. Пример — psim ADR-008: у `external_db_host` и `external_db_password` нет `default`. По смыслу это замена управляемой базы, обычно их не задают. Оператору пришлось бы выдумывать значение.
- **Предлагаю.** Начальное значение требовать, только если пустая форма типа (договор проверки строки, «Подготовка полей», шаг 4) не проходит `schema` или `enum` поля. Иначе строка создаётся с пустой формой.
- Предел назвать: `Configure` получает `""`, `0`, `false`, а не отсутствующий ключ. Незаданное от пустого плагин не отличит (Codex С1 (7), вторая половина).

**М3. Секрет в «файле установки».** П. 1: начальные значения — «файл установки или ввод оператора». У параметра `secret` psim поле — `x_secret` (доп. (2) п. 4). Его значение в файле лежало бы открытым на машине установки, вне кольца `SECRETS_KEY`. Предлагаю: значение `*_secret` — только ввод оператора, оно проходит один раз дверью консоли. Если оно есть в файле — отказ шага с именем поля.
