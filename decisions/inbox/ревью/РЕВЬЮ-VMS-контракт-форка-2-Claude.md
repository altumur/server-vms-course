# Ревью дельты vms/fork-52c-2: 6b61fbb40 (Claude)

Верхние четыре коммита, сверено с ADR-0112 доп. (1)–(3). Чтением. Пробное слияние с `origin/main` чисто, `check_spec` PASS (54 исключения, структура). Токен первого вида доп. (3) п. 1 не выгружен: учётки на стенде не судил.

**Счёт: Б 0, С 2, М 3.** Прежние по дельте закрыты: С1–С3, М1–М3 `efb92cb80`; Б1, С1, С2, М1, М2, М3 контракта форка, кроме `presetMax`, он за «Консолью». Числа: 88 / 16 / 2 = 106 сошлись с `profile.tsv`.

Обе С — про пресеты, и обе идут от слов доп. (2), поэтому решать их «Архитектору», а не только тексту.

## С

**С1. Подпись пресета в строке камеры перезапускает камеру.** `VMS/01-cam/cam.subsystem.yaml`, поле `preset_labels` в `cam/cameras`, запись «пакетом с `cas`» (V/11.4 Н1.16, ADR доп. (2) п. 2). Тот же манифест про соседей, `:350`: «A table and not a field of the row: a field would bump `revision` and restart the holder's connection», `:358` то же, потому `unit_next`, `rule_state`, `ptz_moves` и вынесены в таблицы.

Сценарий: оператор подписал пресет, `revision` строки вырос, держатель перезапускает соединение. Живое и запись на камере рвутся ради подписи, которая устройству не нужна. На PTZ-камере с десятью пресетами это десять обрывов. И ещё `version` камеры: чужая форма с открытой правкой получит 412.

Правка: таблица `cam/preset_labels`, ключ `{camera}`, как `ptz_moves`, `view_tables`, `edit_tables` вместо поля; в версию не входит.

**С2. Кнопка «Пресет» в форме ничего не делает.** Форма `52c1113`, `index.html:8238`: `presetAdd` шлёт `PUT` с `{name:""}`. По доп. (2) п. 1 это «только имя», по V/11.4 Н1.16 «пустое имя снимает подпись»: положения нет, подписи нет, `Device.presets` — только названные. Ответ 200, строки нет, номер не занят, «Запомнить здесь» (`:8228`) жать негде.

И вторая половина: `PUT {}` на `n` без имени сохраняет положение, а в `Device.presets` номера нет: сохранённый пресет невидим. Автоматизация его вызовет, оператор его не видит и удалить не может.

Правка, контракт не меняется: `preset_save` кладёт ключ `n` с пустым именем, если ключа нет; `{name:""}` на номере без ключа тоже кладёт ключ, на номере с ключом снимает имя, ключ остаётся; снимает ключ только `DELETE`. Тогда `presets` — это номера, которые прошли через нас, плюс имена драйвера.

## М

**М1.** V/11.4 Н1.16 «Перед записью»: нет связи — 409 `DEVICE_OFFLINE`, `ptz` ложь — 422 стоят на всех записях, в том числе на имени. Имя устройству не идёт: подпись камеры вне связи отказа не требует. Правку С1 это упростит. `can` не сказан: граница `n` судится только при сказанном.

**М2.** Н1.15 `POST /devices/{id}/live`: «двери шлюза нет (404, 503 двери) — 409». P/06.5: `/where` отвечает 200 без поля `door`, когда подписанта нет или `door/keys` не читается. Этот случай не назван: добавить к 409.

**М3.** Н1.15 «токен идёт через `backend` один раз», а `Cache-Control: no-store` в V/11.1 назван только для тела с паролем. `LiveResult.token` — то же.
