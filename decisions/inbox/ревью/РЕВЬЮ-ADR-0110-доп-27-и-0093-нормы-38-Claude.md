# Ревью: текст ADR-0110 доп. (27) и нормы vms/words-93j (e51ee3e56) (Claude)

## ADR-0110 доп. (27)

Сверено с `cammeta-quint/vrev/REPORT.md` (7fd77d0): Х3 — базы `cBadRFull`, `cBadRNoFFull`; Х4 — `cBadRSkip`, слова P/09.1 `:315`–`:317`.

**Счёт: Б 0, С 0, М 1.** П. 1 верен. Путь старта зависел от того, есть ли память в миг ответа, а следование возвращает её раньше. Правило «413 слияния — замена строкой ответа всегда» от этого не зависит. П. 2 снимает противоречие слов.

**М1. Предел теперь шире, назвать это.** Прежде потеря своих отзывов члена при замене была только на старте без памяти (доп. (26)). Теперь — при любом `413` слияния. Сюда входит и случай без кражи: строка держателя у потолка, а у члена свои отзывы после переноса без `stolen`. Это тот же предел, но уже не узкий. В слове предела P/09.1 писать «при любом `413` слияния», а не «после старта». Журнал `domain.revoked.replaced` — с числом потерянных своих. Только М — в нормы.

## Нормы vms/words-93j, ADR-0093 (38) и С1 ревью (37)–(38)

Выражения прогнаны в Python 3.12 `re` на `harness/rules/words.json` курса. Поручение «сверь, что `det scan` по-русски только со словом архива во всех словарях» — ответ ниже, М2.

**Счёт: Б 0, С 0, М 2.**

| Текст | `asks_step` | `segment_lost_phrase` |
|---|---|---|
| просканируй архив Lobby Cam за час | `det scan` | — |
| сканирование архива камеры | `det scan` | — |
| проверь архив за ночь | `det scan` | — |
| сканирует номер машины | — | — |
| **отсканируй архив** | **—** | — |
| эскалируй на старшего | `escalate` | — |
| If the bag is lost, start recording | — | **нет**: моё С1 закрыто |
| the camera lost recording / if recording drops | — | да |

**М1. «Отсканируй».** `asks_step["det scan"]` — `(?:про)?сканир…архив`. «Отсканируй архив» не совпадает, а это обычная форма. Взять `(?:про|от)?сканир`.

**М2. Ответ на поручение: не во всех словарях.**
- `asks_step["det scan"]` (`words.json:74`) — по-русски и по-английски только со словом архива. Верно.
- Прямой словарь `actions["det scan"]` (`:82`) — `scan|сканир|check\s+\S+\s+archive|провер…архив`: голые `scan`, `сканир` без архива. Прямая проверка «план просит `det scan` — текст говорит» пропустит план `det scan` на «сканирует номер машины». Подмену `lpr` → скан архива слой не поймает.

Сужать ли прямой — решение. Узкий прямой отказал бы верный план на «просканируй Lobby Cam за последний час», где архив не назван. Мой выбор — прямой оставить широким и назвать пределом рядом с `running`, `start`. Если нужно ровно «во всех» — сузить и прямой, приняв лишний вопрос на такой просьбе.

`harness/words.json` (V/11.10, V/11.11): слова `скан` есть только в `units.detjob` — название вида единицы, а не шаг. Не задето.
