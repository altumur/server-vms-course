# P01.273: связь проверки с отказом и определение sock

Исходный срез — `1526d00b770cbfe5b555bbf4ee1889c9505f82f8`. Граница — F08/F09
сводки `spec-format-improvements-20261112.md` и F08 записки P01.266. Основание —
ADR-0133 доп. (90), (91) п. 2; доп. (92) не разрешает примеры, доп. (93)
предписывает довести эту правку до последующего отката формата.

Расхождения были раньше: на срезе попытки 7 `298e28fda` 27 из 31 уникального
имени `check` формы записи отсутствуют в каталоге отказов. На нём же четыре
шапки задают разные представления роли `sock`. Проверено чтением самих файлов
этого коммита и исходного среза задачи; причинность более ранних правок не установлена.

Изменения:

- В четырёх формах `check` называет существующий отказ из `refusals.tsv`.
  Ошибки формы записи выбирают `body_form`, ключи — `key_rules`, вес — `weight`,
  права записи — `write_forbidden`, чтение стража — `guard_read_forbidden`.
  `rc-rights_absent` выбирает `rights_not_loaded`, `rd-method` — `no_route`.
  `allowed` сохраняет полную проверку, включая `never`; имя общего отказа прав
  не добавляет разрешения или отдельного исхода для запрещённого ключа.
- `rd-query_form` сохранён для get (`body_form`), добавлена строка
  `rd-list_form` для list (`list_form`) под n=5. Проверка ключа сохраняет n=4; прежние id сохранены.
  Порядок наблюдаемых отказов прежний: две ошибки query относятся к разным маршрутам.
- В P/01.2-R017 одним абзацем определён `sock` в точке проверки: транспортная
  роль до проверки пересылки; действующая роль для put/delete/batch после неё;
  для floor сохраняется транспортная роль. Пересланный admin не становится
  локальным admin.sock. Четыре шапки ссылаются на этот абзац, английский источник
  и русский перевод согласованы.
- Service использует уже принятое `peer:<role>` для сертификата; формы прав
  снимают транспортный префикс при переходе к действующей роли без заголовка.
  Полное разрешение внутренней роли остаётся по P/01.2-R078/R079. Случаи проверяют
  собственный/чужой ключ configstore-door, две роли peer для floor и local admin.
- Схемы существующих ячеек и `headerRows` пакета форм согласованы с текстом.
  Столбцы, входы, виды форм и транспорт векторов не расширены; `local_admin`
  и столбец `refusal` не введены. Происхождение — в history.tsv/history-2.tsv,
  изменения случаев — в corrections-1.tsv/corrections-2.tsv.
