# Ответ «Спецификации VMS»: страницы и дерево, цена по виду большого домена

2026-11-02 · для «Консоли» · вход: `ПРЕДЛОЖЕНИЕ-СТРАНИЦЫ-И-ДЕРЕВО.md` cfbce9d, ADR-0113 доп. (8), (10). Всё по чтению норм на выгрузке 002c6bf5, числа размера — оценки, работой не проверено.

## Что есть у вида

Единица вида: `sub, id, ref, cluster, revision, labels, about, worker, server, phase, age, state`, у `cam` ещё `view: name, enabled, main` и `status: device_state, codec, units_down`. Дверь: `GET domain/cam/cameras[?cluster=<член>][&cursor=]`, разделы подряд до 1000 членов. Вид стареет на круг: при 250 000 членов около 20 минут.

## 1. Поля `DeviceRow`

| Поле | Камера-кластер, из вида | Член `class: server` |
|---|---|---|
| `id`, `domainId`, `name`, `enabled` | да | да |
| `online`, `licenseExceeded` | да, из `phase` | да |
| `fault` | да, из `device_state`, текста нет | да |
| `type` | **нет, добавлю в `domain.view` `cam`**, цена — одно слово на единицу | да |
| `subtype` | нет, значимо только у `ipsrv`, у камеры-кластера поля нет | да |
| `parentId` | `null`: дерево устройства лежит в таблицах | да |
| `serverId` | **`null`**: сервер записи живёт у другого члена, это чтение на строку | да |
| `silent` | **нет**: в контракте поля нет, в виде слова нет, это событие обрыва потока | только если будет слово пульса |
| `hasChildren` | **нет**: дети в таблицах. Могу дать `true` как «может быть», раскрытие читает таблицы одного члена и может вернуть пусто | да |
| `version` | **нет полной**: у `Device.version` склейка индексов нескольких таблиц, в виде только `revision` строки камеры | полная, снимок таблиц |

**`version`, решение к контракту.** В строке — `r<revision>`, это не `Device.version`. `/objects/delete` принимает обе формы; `r<revision>` сверяет только строку камеры. Предел: правка записи или детектора такое удаление не остановит. Иначе перед удалением шли бы до 10 вызовов на элемент, при `selectMax` 500 это 5000.

Рекомендую: `silent`, `hasChildren`, `serverId`, `parentId` у строки необязательные; `silent` убрать.

## 2. Порядок и курсор

Порядка по имени у двери нет. Порядок — разделы, внутри `(cluster, id, worker)` в байтах. Курсор — по месту, вставка страницы не сдвигает: п. 3 выполним, как только курсор доживёт до конца круга; протухший — `INVALID_CURSOR`.

п. 14 выполним только внутри одного члена: `?cluster=` читает одну строку раздела или снимок, `backend` сортирует сам. Под доменом, где лежат камеры-кластеры, и в папке — нет: нужен был бы весь набор. **Поменяй п. 14:** порядок — имя внутри члена; у верхнего уровня и папок — порядок сервера, неизменный между страницами, но не алфавитный. Индекса по имени у `backend` не будет: он читает билетом человека, индекс был бы на человека.

## 3. Фильтры `q`, `status`

Индекса нет, полный проход — все строки разделов, 72 МБ обычно, до 2 ГиБ в худшем случае: на запрос нельзя.

Можно ограниченным проходом: запрос просматривает не больше K разделов, K постоянное, и отдаёт найденное и `nextCursor`. `items` может быть пустым при живом `nextCursor`, форма пишет «ищем дальше» и спрашивает ещё. Цена на запрос постоянна, искать весь домен долго, порядка нет. **Поменяй п. 2:** пустая страница с `nextCursor` законна. `type`, `domainId` — так же. `serverId`, `parentId` — только в одном члене. `ids` — по записи, до `idsMax`.

**`folderId` дорог, п. 7, п. 13, п. 16.** `domain/memberof/<член>/…` ключевано членом: обратного указателя папка → единицы нет. `domain/folder-counts/<id>` называет члены с единицами папки, дальше вызов на члена: до 200 вызовов на страницу из 200. Перечень постоянной цены только при двери платформы «единицы папки», её нет; просьбу передам «Спецификации», если п. 7 остаётся. `/tree/paths` чужой камеры — один вызов `memberof`, годится.

## 4. `counts` и `total`

- `total` без фильтра: приближённо из `domain/member-count`, камеры и серверы, одно чтение. Оставить, форма пишет «≈».
- `total` с фильтром, `/devices/facets`, `byStatus`: только полным проходом. **Не будет.** `countFiltered` заменить нечем, кроме счёта по загруженному.
- `Folder.deviceCount`, `counts.total`, `childCount` папки: сумма `domain/folder-counts/<id>`, чтение на узел; 200 узлов страницы — 200 чтений, строка растёт с членами папки. Брать только для раскрытых, поле необязательное.
- `counts.nosignal`, `counts.off`: полный проход. **Не будет.**
