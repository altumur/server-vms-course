# Ревью стадии A (часть М10): разбор и задача «Спецификации»

Отчёты лежат в корне курса:
- `РЕВЬЮ-СТАДИЯ-A-1-codex.md` — 0 блокеров, 16 существенных;
- `РЕВЬЮ-СТАДИЯ-A-1-kimi.md` — 3 вопроса-блокера по векторам, остальное существенные и мелкие;
- `РЕВЬЮ-СТАДИЯ-A-1-gemini.md`.

Вывод у всех «с правками». Где решения ниже нет — по рекомендации отчётов, пересечения сведи сама.

## Решения «Архитектора»
1. **Права и каталог** — ADR-0083 доп. (6). Источник прав остаётся спекой. Каталог — контракт операций. Новая
   проверка «каталог ⊆ права»: каждую операцию каждого участника разрешает файл прав, выведенный из спеки.
   - Проверку пишу в `check_spec` я, по выведенным правам `testsub`, `testsub2` и вариантов урока 6.
   - Твоя часть — привести строки, которые ревью называют неверными:
     - `cas` записан как `put`;
     - потерян страж `placement_turn`;
     - ресурс не указан среди удаляющих;
     - условия `mark`/`no_begun`;
     - блокировка журнала.
   - Читатели — **не шире** прав. Где каталог шире прав — либо ошибка строки, либо пробел прав (решай по норме).
2. **Участник файла без роли** — `proc:NN-<процесс>`. `check_spec` уже понимает. Файл запасного — `proc:02-installer`.
3. **Точное имя против семьи в `<spec:…>`** (RA1-04). `<spec:objects.rows>` без `/*` — точный ключ, с `/*` — семья.
   Грамматика ключа не меняется.
4. **Вектор против нормы** (Kimi, три вопроса):
   - **SA1-17.** Дверь просьб: `fault` только `too_long`. Строки `requests_body.tsv` для маршрута просьб — по норме
     урока 8, долг продукта.
   - **SA1-18.** `Proxy-Authorization` — добавить в закрытый перечень маски журнала М10/7 Н1.4. Маскировать больше
     безопаснее; долг продукта.
   - **SA1-20.** Канон — ADR-0053: отказ источника группу по читаемому хосту не отменяет. М10/4 :93 привести к ADR,
     вектор `group_of.tsv` верен.
5. **Вектор оценщика прав** (RA1-16). Через HTTP:
   - `allow` — только подтверждённый успех: для чтения ответ формы Row, для записи успех;
   - 5xx и ошибка транспорта — неопределённый исход, а не `allow`;
   - действие `delete` добавить в векторы (SA1-22).

   Раннер дополнит генератор раннеров после выгрузки.
6. **Жизненный цикл:**
   - **кольцо консоли** — один путь, по раскладке `{data}/etc/secrets`;
   - **`BOX_ID`** — по норме М10/11, без «короткого имени хоста»;
   - **код выхода «бюджет памяти»** — без нормы не вводить;
   - **воркер** — `Type=notify`;
   - **окружение демона, по которому передаются сокеты**, — назвать;
   - **запасной** — без вымышленного кода.
7. **Карта id, абзацы «Данные», словарь** (ссылка в М10/2 Н0) — по рекомендациям, это механика.

Пишет «Спецификация».
