# D0: один блок представления и отдельная исходная декларация

Карта4d7197 показывает разрыв между двумя условными таблицами renderer и общим пояснением в исходнике. Архитектор сверил25файлов пакета и21литеральную привязку. Предлагаемый файл проверен только синтаксическим разбором в памяти; рендеринг и проектные функции не выполнялись.

coord103-tools получает одну CODE-долю: review103 может заменить только `_contextual_writer_body` в section.py на полный текст из APPROVAL.json. Это точная делегация владельца skills, а не передача владения. Меняются подписи person/role и русский текст корневой клетки. Выбор профиля, схема, Reader, kind, writer_body, генераторы и тесты защищены. Разрешены только проверки байтов и AST без импорта проекта, нормальная отдельная ветка и замороженная поставка.

Исходный поток получает после текущей задачи P07 только подготовку точной декларации двух P08 EN/RU файлов. Общий предел остаётся в writer-блоке, условные таблицы явно называют профиль человека и профиль роли; прежнее пояснение переносится рядом с исходным key-context за пределы generated marker. Роль{} и человек{at,done?} остаются выбранной нормой. Эта записка не активирует Source-запись.

Следующий внешний D0 caller ещё не разрешён к созданию или исполнению. Его будущие четыре группы/восемь записей остаются планом. После поставки CODE и точной исходной декларации нужны отдельные freeze/read/execution границы. Успех P1 не переносится на renderer; его единственный допуск использован.
