# Вопросы М11/11 «Общие настройки и тревоги членов»

Свидетели — курс (заморожен, `Source/w2cplatform/domain/shared.py`, `alarms.py`, `signer_service.py`) и продукт
(`vmsworker/w2cplatform/domain/shared.go`, `alarms.go`, `units.go`). Расходятся в 26 местах.

**Без вопроса:**
- ADR-0010: домен не знает полей подсистем, общее объявляет спека `domain.shared`.
- ADR-0032: подписывает процесс `domain`, консоль домена пересылает правку.
- C6 «точный документ»: указатель `domain/shared` (точное имя), поколения — объектами `shared/rev-N`, проекций и
  `domain/shared/<sub>` нет. Воркер читает указатель и объекты.
- Значение домена разрешается при чтении — цепочка «единица → домен → `inherit` спеки», `merge: union` объединяет. Писать
  значения в строки нельзя.
- Заморозка и смещение урока 10 охраняют правку.
- Урок 7: область `scenario` берёт **проверенный** документ, `items` — одно имя.

Ниже — развилки.

## 1. Документ и его подпись

**Курс:** `{rev, term, at, by, settings: {shared}, kid, sig}`, подпись ключом токенов.
**Продукт:** подпись ключом держателя с цепочкой `cred`, без корня принимает и неподписанное.

**Рекомендация.** Документ `{domain, term, rev, at, by, shared: {<sub>: {<поле>: значение}}, issuer, kid, sig}`.
- Обёртку `settings` снять: в ней только `shared`.
- Подпись — выпускающим ключом, как запись срока урока 10 (одна функция `record`).
- Неподписанный документ не принимается никогда.

**Указатель у держателя** — `domain/shared {doc: JCS {term, rev, sha256, object}}`. Объекты `shared/rev-<n>`, последние 5
(продукт).

**После переноса** выпускающий другой, поэтому новый держатель переподписывает то же содержимое как `rev + 1`, `by:
"domain"` (продукт). У курса прежний `rev` с новым `term`.

## 2. Доставка члену

**Рекомендация.**
- **Ответ агенту** несёт `shared: {pointer, doc?}`; `doc` — только когда отчётная копия члена ≠ указателю (продукт, без
  лишних мегабайт).
- **Агент проверяет:**
  1. `(term, rev)` ≤ своего — «up to date» / «holding newer», ничего не брать: назад никогда;
  2. sha256 текста = `pointer.sha256`;
  3. `record` по своему набору;
  4. `(term, rev)` документа = указателю.
- **Запись у члена:** объект `domain/shared`, затем строка `domain/shared {doc: {term, rev, sha256}}`.
- **Отказ** — строка `domain/shared-refused {doc: {term, rev, reason, at}}`; тексты курса.
- **В отчёте** обе строки — объектами `domain/shared` и `domain/shared-refused` (урок 3 `member_objects`).

## 3. `domain.shared` в загрузчике (М10/2 Н1.2а: сейчас opaque)

**Рекомендация:**
- элемент — имя поля единицы или `{name, type: json, schema}` ровно с этими ключами;
- поле — не секрет, наследует (`inherit`) или это `display.tree.group_by`;
- документ — не имя поля единицы;
- без повторов;
- `merge` (М10/2 «М11») — `override | union`, только у поля с `inherit`, `union` только у `list`.

Тексты отказов у свидетелей совпадают — беру их. Случаи `m61_shared_*` — в корпусе урока 2.

## 4. Двери правки и чтения

**`GET /domain/shared`** у консоли домена (`view`) → `{doc, delivery, declared}`. `declared: {<sub>: [{name, type,
schema?}]}`: схему документа отдаём (курс), иначе страница не построит форму. Контракт модуля §10a дополняется полем
`schema`.

**`PUT /domain/shared {base_rev, shared}`** (`admin`) → процесс `domain`. Свидетели расходятся:
- отказы: курс — все через «; », продукт — первый;
- типы полей: проверяет только продукт;
- тело: курс 16 KiB, продукт 4 MiB с обрезкой.

**Рекомендация:**
- тело ≤ 1 МиБ, иначе 413 — 500 сценариев весят около 80 КБ;
- `base_rev` — 409 «the shared settings are at rev N; the edit was made against rev M — look again»;
- все отказы содержания одним 400 через «; »: подсистема, поле не из `domain.shared`, тип поля по спеке (М10/3 формы),
  схема документа;
- `null` снимает значение;
- CAS указателя — 409;
- ответ `{term, rev, by}`, журнал `domain.shared.edited {term, rev, by}`.

**`GET /domain/shared/<sub>[?unit=<id>]`** у консоли кластера (`view`) → `{sub, term, rev, fields}`:
- поле `{value, from, inherit, merge?}`, у `group_by` — `{groups, from}`, у документа — `{value, from}`;
- только поля `domain.shared`;
- `from`: `unit`, `domain term T rev R`, `unit + domain …`, `spec`;
- единица чужой подсистемы — 400 (курс);
- подсистема без общего — 404.

## 5. Доставлено скольким

**Рекомендация.** `delivery: {term, rev, holding, behind, refused, silent, sentence}` по отчётным строкам членов, держатель
включён.
- `silent` — член не `ok` по виду урока 1.
- Фраза по-английски, как остальные слова курса: «rev R on H of T members; not taken yet: …; not answering: …; refused
  by: …».
- `sha256` не сверяем ни там, ни там: подпись уже проверил агент.

## 6. Страница тревог члена

**Курс:** поле `pages.alarms` `{from, to, events, truncated}`. **Продукт:** объект `domain/alarms/self` `{window, events,
truncated, state}`.

**Рекомендация.** Объект отчёта `domain/alarms` (урок 3 `member_objects`): `{from, to, events, truncated}`.
- `events` — строки тревог (класс `alarm`, М10/8) всех спек каталога за последние `ALARM_WINDOW` 86400 с, новые первыми,
  не больше `ALARM_PAGE` 100.
- Строка — событие М10/8 плюс `sub`; `t` — часы члена.
- Срочный отчёт — новая тревога, не чаще `URGENT_GAP` 1 с. Агент раз в секунду смотрит, есть ли тревога новее последней
  страницы: процессы раздельные, будить нечем.

## 7. Список у держателя

**Рекомендация.** `GET /domain/alarms?since=&until=` у консоли домена (`view`; умолчание — сутки; не числа — 400) →
`{since, until, events, members, complete, sentence}`.
- **Члены:** страница из последнего отчёта каждого, держатель включён (продукт), слияние по времени. Обрезанная —
  `truncated`.
- **Состояние члена:** `ok | silent | not_reporting | never | unreadable` (продукт; курс говорит `last_report`).
- **Молчание — строка тревоги:** `{t: silent_since, kind: silent | not_reporting, class: alarm, member, sub: "domain",
  last_report, ongoing: true, alive_at?, alive_via?}`.
  - Порог — `LOST_AFTER` вида урока 1 (45 с, курс), не 3 × `REPORT_EVERY` (продукт): одно правило молчания на домен.
- **Свидетель** `domain.witness {report, member_field}`: объект `<sub>/<report>/<имя>` = `{ts, cluster, units: {<член>:
  секунды}}`. Слышал после последнего отчёта — `not_reporting` с `alive_at`, `alive_via`. Поле `member_field` — `fixed`
  поле единицы (загрузчик).
- **История:** объект держателя `domain/alarm-history/<член>` `{events, cut_before}` — 7 суток, не больше 2000 строк.
  - Пишет только проход держателя (курс; ADR-0032 — один писатель), список читает.
  - Строка опознаётся по `(t_src, kind, sub, unit)`; часы домена — поправкой каждого отчёта.
  - История едет с копией урока 10.
- **Фразы** — английские, как у курса.
- **Событий** «тревога домена» в журнале М10/8 нет ни у кого и не вводим: тревога — строка этого списка.

## Приёмка (предложение)

**Стенд урока 3** (каталог `testsub`, поля `step`, `marks`, документ `rounds`):
1. `PUT /domain/shared` — 200; `base_rev` старый — 409; поле не общее, тип, схема — один 400 с причинами.
2. `m1` берёт документ; `GET /domain/shared/testsub?unit=` с `from`; `union` у `marks`.
3. Доставка по членам; выключенный агент — в `silent`, затем взял.
4. Агент `m1` выключен дольше `LOST_AFTER` — строка тревоги `silent` в `/domain/alarms`.

**Векторы:**
- `resolve` — поле спеки, строка единицы, документ → значение и `from`;
- `alarms` — страницы и отчёты членов, их состояния, история, свидетели, окно → список: шторм, `truncated`,
  `last_report`, `not_reporting`, предел истории.

Подделку документа агент проверяет функцией `record` урока 10.

Строки реестра:
- `inputs/resolve-*`, `inputs/alarms-*`;
- случаи `m61_shared_*` корпуса урока 2.
