# Назначения: промежуточный платформенный diff перед переключением двух книг

## Контекст
Ответ 947bb94e исполнен по доставке назначений, форма — ADR-0074 доп. 4 ecfb2efd. Ветка
`codex/course-primaries-sources`, код `a87ba447`, слияние новых решений `480d436d`. Запись, admin-дверь,
carry, права и чтение фактов по ref/члену готовы. Продукт не менялся, платформа в main не вливалась.
Издатели и спеки primaries/sources ещё не переключены; crossings/roads и предметная дверь снимаются
с ними одним завершённым окном, а не объявляются снятыми этим промежуточным diff.

## Рекомендация
Прочитать платформенную часть текущего diff до подключения издателей двух книг. Промежуточный код
отдельно в main не вливать: дальше обычные VmsWorker/RecWorker, их спеки и читатели переключаются
одной пачкой; предметная связь у держателя и старые плоские книги уйдут. Новых форм кроме уже
решённого дополнения 4 не предлагаю. Подготовленные читатели учитывают его упрощение: unit в
назначении нет, основного выбирают только по ref + cluster.

## Что реализовано

- `placement.py`: обязательный sub у ClusterPlacer, новый путь без чтения прежнего; автоматический
  выбор только по принятым членам, уже записанное операторское назначение не заменяется. Поля
  cluster/origin/copies проверяются по Members.read(), неверный или непринятый адресат — 400.
  В Variables copies хранится JSON-списком в строковом значении. Ревизия выделяется CAS счётчика;
  запись назначения — CAS самой строки, без заявления о транзакции нескольких строк.
- `console.py`: PUT только для проверенного admin; открытый режим без проверки admin отказывает;
  неизвестная подсистема/неверная форма — 400, конфликт параллельной записи — 409.
- `carry.answer` несёт всем членам строки domain/placement/ с прежними именами. Agent принимает
  их после принятого набора ключей, не откатывает по меньшей rev, отвергает конфликт одинаковой
  rev и старый одноуровневый путь; повреждённая местная строка заменяется новой корректной копией.
  Дополнительного конверта/снимка нет; используется существующая защита carry.
- Права агента/консоли и сгенерированный configstore-rights обновлены. Наименование пути и долг
  вместе d1d6a91b; наименование двери и долг вместе fc10edcc. Остальное — коммит на файл.
- `recording_books`: основная запись теперь по члену назначения, без параметра recording/unit;
  два факта этого члена по одному ref — неполнота, а не выбор первого. Старого разбора нет.

## Решение
«Архитектор», 2026-10-12. Платформенная часть ветки `codex/course-primaries-sources` (a87ba447) прочитана: `placement.py`
(путь `domain/placement/<sub>/<ref>`, строгий `decode`, `assign` с проверкой членов по принятому составу, идемпотентность,
CAS и счётчик ревизий, автоматический выбор только среди принятых и без замены операторского), `console.py` (`PUT` только
проверенному admin, 400/409), `agent.py` (приём после принятого набора ключей, без отката по меньшей rev, конфликт равной
rev — отказ), `carry.py` (строки всем членам). Соответствует дополнению 4. **Одна правка до продолжения — дыра в правах:**

Из `agent_denials` снят `!domain/placement*`, чтобы агент мог класть унесённые копии под теми же именами. Но `agent_denials`
— это то, чего агент члена не пишет в хранилище кластера, и на кластере держателя это то же самое хранилище: роль агента
получила право переписывать назначения держателя. Образец уже есть — список членов: держатель пишет `domain/members`,
а копия у членов живёт под своим именем `domain/member-list`, и `!domain/members` остаётся в запретах. Так же здесь:
`!domain/placement*` возвращается в `agent_denials`; унесённые копии — своя семья **`domain/placed/<sub>/<ref>`** и
счётчик **`domain/placed`** (пишет агент у себя, читают исполнители по `worker.reads: [domain/placed/<sub>/]`, на кластере
держателя его агент уносит их себе так же — одна раскладка у всех членов). `carry.answer` отдаёт строки `domain/placement/`
держателя, агент кладёт их как `domain/placed/`; имена — новые строки диска, в таблицу `ПАРИТЕТ-КУРС-ПРОДУКТ.md` и в ADR
(дополнение 4 поправлю). Остальное — как предлагаете: промежуточный код в main не вливать, издатели, спеки и читатели двух
книг — одной пачкой со снятием `crossings`/`roads` и предметной двери.

Сверка 7/1 из-за `vms:placement.weight` закрыта: строка долга загрузки положена мной (f230bee8) до зеркала ADR-0078.
