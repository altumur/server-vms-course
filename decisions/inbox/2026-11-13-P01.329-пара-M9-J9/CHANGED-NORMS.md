# Изменения M8′ → M9

Исходный вход M8′: `bfa66fa76ecfb2c1d9b59c7ac7e2641722493942`, исходный C: `30310352523e30aa7e7879d901e44d80e01b118d`. Новый вход M9: `67e3abaec8f0468495e05c3ec7d5a9521fd47efd`, C: `dc0645fa329eaf7d52203dac5d4e69eb63cbd989`. Правила ниже читаются вместе с полным M9. Пути начинаются от `Platform/`; R-id называют абзацы английского источника.

| P/01.3-R419 | 1.3, `01-store/spec/01.3-store.norms.md`, N2 | Отдельного абзаца с проверкой собственного членства не было. | Демон группы по mTLS роли `configstore` меняет только собственное членство. Собственный id берётся из проверенного сертификата пира: CN `configstore.<server>` / SAN DNS. Непустой чужой `id` тела даёт 403 `ForbiddenFault`, имя `membership_foreign`, без изменения состава. Проверка идёт после формы тела, до проверки лидера, фазы и членства. Чужое членство меняется через `admin.sock` лидера. Внутренняя операция передачи последователем собственного join/leave пира к лидеру по R119 не является запросом к этой двери: проверка выполняется там, куда пришёл запрос пира. |
