# Нечитаемая строка у сторожевой: сверка семей

Семьи, которые читает сторожевая (договор сторожевой и передачи «Форма», «Сторожевая», «Сторожевая с грантами»,
«Аварийный вход»; читатели `console`, `domainconsole` в `Platform/common/data/catalog.tsv`), и исход «не читается» для
сторожевой в их `*.outcomes.tsv`.

## Совпадают с правилом

| Семья | Где проверка | Исход для сторожевой |
|---|---|---|
| `keys` (08) | личность: токен | 503 `{error: "unavailable"}` |
| `member` (09) | подпись агента; аварийный вход шаг 4 | 503 `{error: "unavailable"}`, не в счёт предела |
| `disabled` (08) | вход `may` | 503 `{error: "unavailable"}`; исключение — отладочный вход, «как без входа» (названо в правиле) |
| `break-glass` (08) | аварийный вход шаг 4 | строка есть, но не по форме или не открывается — 503 `unavailable` |
| `root` (08), `member`, `revoked` как следы | `shut`, раздел «Следы домена» | нужен только факт наличия; нечитаемая — след есть; правило не задевает |

Вне правила: пульс воркера (`heartbeats`, `door.pass`) — не проверка доступа.

## Не совпадают

1. **`revoked` (08) — личность, токен.** Исход семьи: «сторожевая — 503» без слова. Договор токена домена (абзац о
   `no_revocations`): «503 у сторожевой» без слова. Договор сторожевой «Сторожевая с грантами» `cluster`: любой отказ
   функции `token` — 401 `token refused: <слово>`, `no_revocations` не исключён; так же P/10 Н1.5 у консоли домена.
   **Рекомендация:** по правилу — `no_revocations` у сторожевой → 503 `{error: "unavailable"}`; назвать слово в
   `revoked.outcomes.tsv` и договоре токена; в `cluster` (и P/10 Н1.5) — «кроме `no_revocations`: правило «Нечитаемая
   строка»».
2. **`grants` копия члена (09-agent, `domain/grants`) — грант у консоли кластера.** Исход: «строка целиком нечитаема —
   прав не даёт», то есть `may` → deny → 403 (так же отладочный вход: гранты из этой строки). **Рекомендация:** по
   правилу → 503 `{error: "unavailable"}`; править исход семьи и P/06.7 Н1.9; у отладочного входа — тоже 503 (не
   исключение), если не решите иначе.
3. **`grants` домена (08-domain, `domain/grants/domain`) — грант у консоли домена.** Исход: «may — как без строки» → 403.
   **Рекомендация:** по правилу → 503 `{error: "unavailable"}`; править исход и P/10 Н1.5.

## Исключения-кандидаты (не строка целиком)

4. **Строка гранта в `lines` не по форме** (обе семьи `grants`, путь `/doc/lines/*`): пропуск с диагностикой, остальные
   строки действуют (P/08.4 Н1.3 `unreadable`). Это элемент строки, строка читается. **Рекомендация:** назвать в
   правиле исключением: «нечитаемый элемент `lines` — пропуск, решают остальные».
5. **Строка единицы для гранта `labels:…` или `unit:` about-единицы** (раздел «Сторожевая» `scope`): нечитаема — грант не
   покрывает, при отсутствии другого — 403 (C06-EVENTS-QUERY-UNKNOWN-138-10). Строка подсистемы, не домена, — правило по
   букве не задевает. **Рекомендация:** назвать в правиле: «строки единиц — не строки домена: раздел `scope`».
