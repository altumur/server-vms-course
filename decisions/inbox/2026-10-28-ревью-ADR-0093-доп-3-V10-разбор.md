# Разбор ревью ADR-0093 доп. (3) и норм V/10.3–V/10.5

Отчёты — `decisions/inbox/ревью/РЕВЬЮ-ADR-0093-доп-3-V10-{codex,claude,kimi}.md`. Все три подтверждают главное доп. (3):
модель не может подделать ответ админа — тексты хода пишет страница из ввода человека. Решения, меняющие ADR, —
ADR-0093 доп. (4); остальное — правки норм «Спецификации VMS» на той же ветке до панели, векторов и сценариев.

## Блокеры

| № | Находка | Решение |
|---|---|---|
| Codex RV10H-01 | секрет живёт «до конца хода», ход кончается показом плана — к «Применить» значения нет | **принято, доп. (4) п. 1:** значения секретов живут с показанной версией плана до её применения или сброса (отмена, новая просьба, перестройка, выход, смена человека, закрытие страницы), не до конца разговора с моделью; конец хода их не стирает |
| Kimi Б1 | ответы админа — «тексты хода, не сокращаются», но в истории они результаты `ask_admin`, которые окно элидирует | **принято:** результаты `ask_admin` — тексты хода, окно их не элидирует (V/10.3 Н1.2, одна строка в правиле окна) |

## Существенные

| № | Находка | Решение |
|---|---|---|
| Codex RV10H-05, Claude Н-1 | `selection.named` не сверяется с текстами хода | **принято, доп. (4) п. 5:** каждое имя `named` — «имя в тексте» (V/10.5 Н1.2) текстов хода, иначе `selection.named: <имя> is not named in the admin's request`; векторы «названо / не названо» |
| Codex RV10H-06, Claude Н-5 | предел 25: ADR — на ход, норма — после каждого текста админа; перезапуски 410/404 без предела | **норма верна, ADR правится, доп. (4) п. 2:** 25 вызовов модели между текстами админа (каждый текст человека — новая точка контроля); перезапусков по 410/404 — не больше 2 за ход, затем «ход не завершён»; ответы админа в перезапущенном ходе — одним `user`, как у перестройки; вектор «вопрос на вызове № 25» |
| Codex RV10H-04 | исключение `bool` и `to = null` из «значение названо» ослабляет пол | **исключение снимается, доп. (4) п. 3:** `bool` и снятие значения называются словами полярности из `words.json` (`true`, `false`, `clear` — данные локали: «включи / выключи / убери…», границы как у «имени в тексте»); слова нет или есть обе полярности — ошибка «ask the admin»; моделью не судится |
| Codex RV10H-03, Claude М-5 | `can_edit` по `may("edit")`, а PUT/DELETE единицы требует `admin` (кроме `rights.routes`) | **принято, доп. (4) п. 4:** `can_edit` — `may` с возможностью, которую требует дверь записи этой строки (`need` договора сторожевой и передачи: `admin`, если `rights.routes` не понижает); одно правило в обзоре, проверке плана, полноте и проверке `refuse`; ADR доп. (1) п. 9 «право применения — admin» читать так |
| Codex RV10H-02 | инструменты читают `unit.rows`, `unit.id`, `unit.fields`, а `GET /manifest` отдаёт плоский `ManifestView` | **принято:** V/10.4 описывает вид инструментов как проекцию `ManifestView` (`rows`, `id`, `fields` верхнего уровня); внутреннее представление панели — её дело |
| Claude Н-2 | сверка по началу слова: трёхбуквенное слово совпадает с любым, что с него начинается («все» ~ «всегда», «при» ~ «приоритет») | **принято (а)+(в), доп. (4) п. 5:** слово текста короче 4 букв совпадает только целиком; служебные слова — список `stop` в `words.json` (данные локали), они ничего не называют; оставшиеся классы — в векторы V/10.5 Н5 «нарушено, но проходит» и в пробелы замера. Вариант (б) (однозначность поля) не берём — меняет алгоритм без замера |
| Kimi С1, Claude М-4 | строковые значения сверяются подстрокой («z2» ⊂ «z21») | **принято, доп. (4) п. 5:** строковые значения и элементы списков — по «имени в тексте» (границы Н1.2), одной отсылкой |
| Claude Н-3 | `rights` — подстрока «прав»/`allowed`: верный отказ по `fixed` («правка невозможна») отвергается | **принято:** выражение с границами и формами (`\bправ(?:а|ами|о|ом)?\b`, `нет\s+прав`, `недостаточно\s+прав`, `\bдоступ`, `(?:no|without)\s+(?:the\s+)?(?:right|permission|access)`, `not\s+permitted`); векторы «отказ по fixed со словом "правка" / "not allowed" — принят» |
| Claude Н-4 | `ask_admin` среди нескольких вызовов одного ответа | **принято:** принятый `ask_admin` тоже останавливает исполнение вызовов ответа; каждому неисполненному вызову — результат `not executed: <причина>` (пары `tool_call`/`tool` целы); сценарий «два вызова в одном ответе» |
| Claude Н-6 | ответ «да» ничего не называет — подтверждение недостижимо | **принято, сверка не ослабляется:** слова ошибок правил 4 и 6 — «ask the admin so that the answer itself names the field and the value (a yes/no answer names nothing)»; подсказка у поля ответа панели; вектор «вопрос со значением, ответ "да"» → `valid: false` |
| Kimi С2 | `label` у не-`list` поля без подписи не определён | **принято:** ключа нет (правило «ключ без значения не пишется»); `null` — только у `list` |
| Kimi С3, Claude М-7 | проверка `refuse` «не найдено» при нечитаемой подсистеме или `LIST_MAX` | **принято:** такая подсистема пропускается (опровергнуть нечем), подсказка `find_units` называет её словами; принять отказ безопасно — записи нет |
