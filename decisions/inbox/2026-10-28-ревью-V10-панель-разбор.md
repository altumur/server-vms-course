# Разбор ревью панели V/10

Отчёт — `decisions/inbox/ревью/РЕВЬЮ-V10-панель-codex.md`. Все находки — дефекты кода ядра и панели или пробелы векторов;
нормы V/10.3–V/10.6 и ADR-0093 не меняются. Исправляет «Спецификация VMS» на ветке от main, векторы — к каждой находке.

| № | Находка | Решение |
|---|---|---|
| RVP-01 блокер | отменённый ход и применение продолжают писать в состояние нового хода: старый цикл `apply` шлёт оставшиеся строки с секретом нового хода; старый `propose_plan` публикует план после отмены | **принято:** у запуска и применения — поколение (владелец хода); после каждого ожидания и перед каждой неотправленной строкой — проверка поколения; секреты привязаны к подтверждённой версии плана, не к общей памяти; сброс (отмена, новый ход, выход, смена человека, `pagehide`) прекращает отправку, исход уже отправленной строки — «неизвестен»; «Новый ход» во время применения — сначала сброс. Векторы `apply` и `turn`: вмешательства между строками и во время проверки плана (новый ход, отмена, выход, `pagehide`) |
| RVP-02 | полнота по единице, а не по паре «единица, поле» | **принято:** пропущенные — по каждому полю правок (V/10.5 Н1.4 п. 10); векторы — контрпример и положительный контроль |
| RVP-03 | граница имени читает половину суррогатной пары | **принято:** соседи — кодовые точки целиком; `text.json` — пара BMP/не-BMP и план с таким именем |
| RVP-04 | неверный тип списка — исключение JS вместо `valid: false` | **принято:** до операций над значением — проверка формы; ошибка формы — результат проверки; вектор `plan-form` с неитерируемым `list.to` |
| RVP-05 | обратный `about` — в блоке над diff «не задано» вместо значения связанной строки | **принято:** хранить свидетелей обратного отбора и показывать их значения (несколько — все); вектор и DOM-приёмка обратной связи |
| RVP-06 | имя из прототипа (`constructor`) — инструмент | **принято:** закрытый реестр (`Map`/собственные ключи); векторы `turn-bad-args` с `constructor`, `toString`, `__proto__` |
| RVP-07 | `gte`, `lt` в векторах не вызываются | **принято:** оба оператора на меньшем, равном, большем с точными count; матрица операторов сверяется с аргументами корпуса |

Статус урока V/10 «переведён» — после исправлений, зелёного прогона jsdom у раннера на новом пине и дописанного раздела
Kimi (если придёт до того; иначе — после, отдельной правкой).

## Kimi (7661137fc, `ревью/РЕВЬЮ-V10-панель-kimi.md`) — 0 блокеров, 2 существенные, 4 мелкие

| № | Решение |
|---|---|
| С1 — «Отменить» / «Новый ход» не останавливают старый цикл (общий `A.cancelled`, `A.step`) | то же, что RVP-01: поколение хода закрывает обе |
| С2 — нет вида «план не прошёл проверку: <правило>»: при пределе с непустой последней причиной страница пишет «модель не довела план» | **принято:** при пределе хода после отвергнутых версий плана — «план не прошёл проверку: <правило>» словами страницы по виду ошибки (V/10.3 Н1.5); вектор |
| М1 — «Ход не завершён: cancelled» сырым кодом; нет вектора `cancelled` двери | принято: слова для `cancelled` и общий вид для неизвестных `why`; вектор `turn` |
| М2 — комментарий маршрутов страницы называет `/mounts`, `/manifest`, `/session` | принято: убрать, `/<sub>/manifest` — «только проверка охвата» |
| М3 — норма `<user> has no right to edit`, код `the admin` | принято: норма V/10.5 Н1.3 — «the admin has no right to edit <unit>» (имени страница не знает) |
| М4 — `LIST_MAX` без вектора | принято: вектор на границе 5000 (5000 — читается, 5001 — ошибка) |
