## До переноса — правки (пишет «Спецификация», если не сказано иное)

**П1. Файлы, которыми говорят процессы, — в каталог** (Codex RA2-02, Kimi SA2-02, Gemini 2; хвост RA1-08 стадии A 1).
Строки `kind=file`: `/etc/w2c/configstore-rights.json` (форма — М10/6 Н1.2, пишет `proc:02-installer`, читает
`proc:01-store`), `/etc/w2c/roles/<роль>.env` (пишет установщик, читают ресурс и `w2c-workers.sh`), файл восстановления
домена (М11/2), sidecar имён `%h<sha256>.name` (М10/8 Н1.1); `schema` — `-` (ADR-0088 доп. (1) Р2). Абзац «Данные» у
М10/1 — единственного урока без него.

**П2. Владелец `platform/epoch_floor`** (Gemini 1): пишет и проверяет хранилище (`op: floor`, `import`, М10/11 Н1.3) —
владелец М10/11 (→ P/01.3), а не М10/3; читатели обеих строк дверей и пола — только по нормам.

**П3. OpenAPI урока 1: `Cmd` закрыт против нормы** (Codex RA2-01): Н2 принимает и не читает лишние поля верхнего уровня
команды, а `unevaluatedProperties: false` у `Cmd` отказывает 5 из 40 положительных запросов приёмки. Открыть лишние поля
у `Cmd` (закрытым остаётся `guard`), сверить сценарий 23.

**П4. Записка: канонический вид не пишется в коммите переноса** (Codex RA2-05, Kimi SA2-01, Gemini 7) —
`Platform/module-design.md` строка урока 2, глава 2.2 — по ADR-0089 доп. (1) Р11.

**П5. Приёмка урока 2: устаревшее** (Codex RA2-03, RA2-04; Gemini 6.4): README приёмки 02 — класс нестрокового ключа
`text` по Н1.1 (не `value`); счёты README урока и `classes.tsv` — по корпусу.

**П6. Версия Unicode** (Kimi SA2-04, Gemini 4): Unicode **15.0.0** — в норме named id (М10/3 Н1.3, категория Nd) и NFKC
(М10/7). Обе реализации сейчас на таблицах 15.0.0 (Python 3.12, Go ≥ 1.21) — поведение не меняется, норма называет его.

**П7. Самодостаточность хранилища: проверка TLS-пира** (Gemini 3): демон хранилища сам проверяет сертификат, роль
`configstore`/`configstore-door`, алгоритмы подписи и отзыв. В `id-map.tsv` у М10/6-12 и М10/11-11 — деление `1.3 —
проверка пира демоном хранилища`.

**П8. Самодостаточность установщика** (Gemini 10, 12; Kimi SA2-03):
- `w2c-workers.sh` правило 4: `unit_mb`/`base_mb` в `roles/<роль>.env` нет (это вход SDK воркера, М10/5 Н1.2) — сверить
  норму М10/11 Н1.5 с Н1.2 окружения и убрать из проверки скрипта то, чего он не читает; `lifecycle.md` так же;
- векторы `workers-script`: случаи «сбора не было / ряд старше минуты», возраст сверки (правило 2) и потолок памяти
  (правило 4); правило 5 (сериализация) — в README пакета «приёмкой стенда и чтением»;
- доменная часть вывода прав (М10/6-13, варианты v4, v5) — поздний слой 2.5 «вводит урок 8» в `id-map.tsv`;
- `w2cctl secrets` — один владелец в `id-map.tsv`, `lifecycle.md` установщика и `catalog.tsv`; участник
  `admin(w2cctl secrets seal)` у всех секретных семей;
- прочие пометки деления `id-map.tsv` (Gemini 12: М10/2-25, М10/2-20, М10/11-07, М10/6-07, М11/1-04, М11/3-04, М11/5-09);
- абзацы «Данные» М11/12 и М10/11 (Gemini 12.3); три умолчания М10/2 Н1.5 из описи (строчный hex `sha256`, закрытый
  набор полей строки и метки, исход `spec put` при нечитаемой строке) — записать нынешнее поведение.

**П9. Две копии векторных таблиц разошлись** (Gemini 11): `secret_in.tsv` и `log_mask.tsv` в `Source/tests/testdata/` и

**П10. `GET /spec` и `ConsoleRefusal` при переносе урока 2** (Gemini 9): `GET /spec` уходит в 6.5; при переносе урока 2
норма `GET /spec` (М10/2-15), `SpecView` и `ConsoleRefusal` переезжают **временно в М10/9** до переноса урока 6, чтобы

HTTP-дверей). В условия переноса урока 2.

**П11. ХОД** (Kimi SA2-05): В1–В3 решены (ADR-0087 доп. (4)).

## Решения «Архитектора» (ADR-0087 доп. (6))

**Р1. Чтение источника — TSV тоже** (Codex RA2-06). В1 (доп. (4)) относится к `*.form.yaml`: он читается слоем текста
Н1.1. `*.references.tsv` и `*.scalars.tsv` — таблицы TSV: UTF-8 без BOM, LF, TAB — разделитель колонок, строка `#` —
комментарий, закрытый набор колонок; ячейка отношения разбирается грамматикой языка отношений (§ 6), ячейка значения
скаляра — по своей колонке; YAML к ним не применяется. Одна грамматика YAML в курсе сохраняется — у YAML-файлов.

**Р2. Открытые решения свода журналов (17)** — по рекомендациям свода: Т15, Т16, Т28, Ф1, Ф2, Ф12, Ф15, Ф18, Ф23, О6, О7,
О9, О12, О15 (О3, О14 — уже). Случаи — как в своде, при переносе урока 2.

**Р3. Ф9 и В3 — случай должен достигать свойства** (Codex RA2-07). `enum` разрешён только у string и bool, поэтому
числовое равенство `1 = 1.0` в `enum` и `text()` дробного числа под `display.options` в форме манифеста недостижимы:
такие входы отказывают раньше по запрету `enum`. Правила диалекта остаются (Ф9 — равенство чисел по значению; В3 —
каноническая запись), их держат **векторы построителя диалекта** с явным источником, а не корпус манифеста; корпус не
расширяет форму ради пробы. Случаи `c8_options_enum_*` корпуса — с честной причиной отказа или снимаются при переносе.
