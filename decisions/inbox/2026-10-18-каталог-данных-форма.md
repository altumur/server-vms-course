# Каталог данных и абзац «Данные»: форма на чтение «Архитектору»

Стадия A (ADR-0083 доп. (2) п. 8, доп. (3)): каталог поверх нынешних М10 и М11, уроки не переносятся. Ниже — формат
`Platform/common/data/catalog.tsv` и абзац «Данные» в Н1 урока. Массовую выписку начну после ответа. Правку
`check_spec` делает «Архитектор» по этой форме.

## 1. `Platform/common/data/catalog.tsv`

UTF-8, LF, поля через TAB. Строки с `#` и пустые пропускаются. Первая непропущенная строка — заголовок, ровно девять
полей:

```text
key	kind	owner	ops	readers	when	version	schema	norm
```

| Поле | Значение | Форма |
|---|---|---|
| `key` | образец ключа строки или объекта, путь файла или каталога | как в норме: `<sub>/slots/<имя>`, `platform/epoch_floor`; переменная части — `<слово>`; семья под префиксом — `/*` в конце; файл — путь от корня, названного в норме (`<корень событий>/<дерево>/<unit>/e<эпоха>/<start>Z.events.jsonl`). Ключ уникален в таблице |
| `kind` | вид | `row` (строка хранилища урока 1) \| `object` (объект урока 8 Н1.1) \| `file` \| `dir` |
| `owner` | урок-владелец контракта формы | адрес нормы на стадии A: `М10/3`, `М11/6`; при переносе `id-map.tsv` переводит его в `P/NN` |
| `ops` | операции и участники с условиями | через `; `: `<операция>=<участник>[,<участник>…][(<условие>)]`. Операции — закрытый набор: `create` (создание-однажды, `cas ""`), `put` (запись без условия), `cas` (запись по прочитанной версии), `guard` (запись под стражем), `mark` (объект-метка создание-однажды), `delete`, `append` (дописать строку файла). Условие — слова нормы, коротко: `(cas "", пока имени нет)`, `(страж — слот)`, `(delete_after)` |
| `readers` | кто читает | участники через запятую; `*` — все роли кластера |
| `when` | при каком объявлении спеки семья есть | `-` — всегда; иначе ключ спеки: `requests`, `requests.free`, `domain.kept`, `objects.rows` |
| `version` | версия формы | целое ≥ 1; на стадии A у всех `1`. Несовместимая смена — новая строка той же семьи с `v` формы (ADR-0083 п. 3) |
| `schema` | схема или формат | `NN-<процесс>/data/<семья>.form.yaml` — источник в диалекте ADR-0087 (ADR-0088), когда он написан; до того `-` (форма — по `norm`). У `file` и бинарного объекта (блоб `<sub>/blobs/sha256-<hex>`) — всегда `-`: их контракт — нормы, векторы и `lifecycle.md` (ADR-0088 доп. (1) Р2) |
| `norm` | где норма формы | `<урок> <раздел>`: `М10/3 Н1.4`, `М10/8 Н1.2` |

**Участники** — имена ролей файла прав М10/6 Н1.1: `console`, `<s>controller`, `<s>worker`, `resource`, `domain`,
`domainagent`, `domainconsole`, `<s>domain`, `admin`. Так столбцы `ops` и `readers` сводятся с выводом прав: файл прав из
каталога по смыслу равен выведенному из спеки (решение п. 12). Для файлов, которых права хранилища не касаются, участник —
та же роль процесса: `resource` пишет бакеты.

**Пример** — по нормам на срезе `19c4392b`:

| key | kind | owner | ops | readers | when | version | schema | norm |
|---|---|---|---|---|---|---|---|---|
| `<sub>/slots/<имя>` | row | М10/3 | `create=<s>worker,<s>controller(cas "", имя свободно; контроллер — только предложение gen 0); cas=<s>worker(своё имя, продление и отдача)` | `<s>controller, console, resource, <s>worker` | - | 1 | - | М10/3 Н1.4 |
| `<sub>/epoch/<id>` | row | М10/3 | `cas=<s>worker(взять_эпоху, max(текущая, floor) + 1)` | `<s>worker, console` | - | 1 | - | М10/3 Н1.5 |
| `platform/epoch_floor` | row | М10/11 | `put=admin(op: floor, только вверх)` | `<s>worker` | - | 1 | - | М10/3 Н1.5, М10/11 Н1.3 |
| `<sub>/requests/<rid>` | row | М10/8 | `create=console,<s>worker(worker.requests);delete=console(жнец)` | `<s>worker, console` | requests | 1 | - | М10/8 Н1.5 |
| `<sub>/requests/free-<server>-<volume>` | row | М10/8 | `create=resource(cas "");cas=resource(своя форма и версия);delete=resource` | `<s>worker, console` | requests.free | 1 | - | М10/8 Н1.4 |
| `objects/<sub>/commands/<rid>` | object | М10/8 | `mark=<s>worker(begun до вызова; answer — начавший);mark=console(no_begun, жнец);delete=<s>worker` | `console` | requests | 1 | - | М10/8 Н1.5 |
| `<sub>/heartbeats/<имя>` | object | М10/5 | `put=<s>worker(своё имя)` | `<s>controller, console, resource` | - | 1 | - | М10/5 Н1.1 |
| `<корень событий>/<дерево>/<unit>/e<эпоха>/<start>Z.events.jsonl` | file | М10/8 | `append=<s>worker(observe), console(журнал и метки)` | `resource` | - | 1 | - | М10/8 Н1.2, Н1.3 |

Строки примера войдут в каталог только после сверки с нормами при выписке. Здесь они показывают форму.

**Чего в каталоге нет:**
- двери (OpenAPI);
- договор библиотеки (`spec/NN-<имя>.library.md`);
- жизненный цикл — флаги, окружение, коды выхода, юниты (`NN-<процесс>/lifecycle.md`, отдельный формат — следующей
  порцией);
- векторы (`NN-<процесс>/vectors/`, указатель `common/vectors/`).

## 2. Абзац «Данные» в Н1 урока

Сразу после абзаца «Время» (если его нет — первым в Н1). Три строки, каждая необязательна. Ключи — точно как `key`
каталога:

```markdown
**Данные** ([каталог](../../Platform/common/data/catalog.tsv)):
- владеет: `<sub>/slots/<имя>`, `<sub>/epoch/<id>`;
- пишет: `platform/schema` (put), `<sub>/placement/<id>` (cas);
- читает: `platform/spec/<sub>`, `<sub>/heartbeats/<имя>`.
```

- **владеет** — строки каталога, у которых `owner` — этот урок.
- **пишет** — чужие семьи, в которые урок вводит операцию; операция в скобках — из `ops` каталога.
- **читает** — чужие семьи, которые урок читает.

**Что сверяет `check_spec`** (предложение «Архитектору»):
1. Каждый ключ абзаца есть в `key` каталога.
2. Каждая строка каталога с `owner` = урок стоит в его «владеет», и наоборот.
3. «Пишет» с операцией — операция есть в `ops` строки.
4. Строка каталога без урока, который ею владеет, — ошибка.
5. Права: файл прав, выведенный из `ops` и `readers`, по смыслу равен выведенному из спеки — пока проверка чтением (п. 12
   решения), позже — шагом.

На стадии A уроки тематические: «пишет» и «читает» — то, что описывают нормы урока, а не процесс. При переносе (стадия B)
урок = процесс, и абзац становится контрактом процесса.

## Вопросы с рекомендацией
1. **Участник — роль файла прав**, а не урок. Рекомендую роль: тогда каталог прямо даёт права (направление доп. (2) п. 6).
2. **`owner` на стадии A — адрес урока М10/М11**, перевод — через `id-map.tsv` при переносе. Рекомендую.
3. **Жизненный цикл — отдельный формат** `NN-<процесс>/lifecycle.md`, следующей порцией после каталога. Рекомендую.

## Решение
2026-10-18, «Архитектор». Форма принята, три вопроса — как рекомендовано: участник — роль файла прав; `owner` — адрес
урока М10/М11 с переводом через `id-map.tsv`; жизненный цикл — отдельный формат следующей порцией. Уточнения грамматики
`ops` (без них разбор неоднозначен — в примере `;` стоит внутри условия, а у разных участников одной операции разные
условия):
- операции разделяются ровно `; `; внутри условия `;` запрещена;
- условие — у участника, а не у операции: `<операция>=<роль>[(<условие>)][,<роль>[(<условие>)]…]`; внутри скобок запятые
  допустимы, скобки не вкладываются. Пример: `create=<s>worker(cas "", имя свободно),<s>controller(только предложение
  gen 0); cas=<s>worker(своё имя), <s>controller(release)`;
- одна операция — один раз в строке.

**Пересечение образцов** (`<sub>/requests/<rid>` и `<sub>/requests/free-<server>-<volume>`): ключ относится к самому
узкому образцу (длиннее литеральная часть). Два образца, которые совпадают на одном ключе при равной узости, — ошибка
`check_spec`. Если узкий образец исключает ключи из широкого, грамматика широкого это говорит (`rid` не начинается с
`free-`) — проверь при выписке.

**Что сверяет `check_spec`** — твои п. 1–4 и ещё:
- поля и их формы (`kind`, операции, `when`, `version` ≥ 1, ключ уникален);
- участники и читатели — роли из перечня М10/6 Н1.1 (с `<s>`) или `*`;
- `norm` указывает на существующий урок;
- `schema` — существующий файл или `-`.

П. 5 (права по смыслу) — проверка чтением до решения п. 12. Пишу правку `check_spec` по этой форме сейчас, ты
начинаешь выписку.
