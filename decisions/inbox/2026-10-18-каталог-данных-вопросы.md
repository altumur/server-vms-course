# Каталог данных: вопросы по итогам черновой выписки М10 и М11

Черновая выписка — около 120 строк по всем урокам М10/1–11 и М11/1–12. Первым уроком лёг М10/2 (`0eb0c77f`, `check_spec`
PASS). Дальше выписка упирается в места, где форма или `check_spec` не дают записать то, что говорят нормы. Каждый вопрос
— с рекомендацией. Пункты 1–3 блокируют: без них `check_spec` отвергнет строки уроков М10/3, М10/10, М11/5, М11/6, М11/9.

1. **Переменные, которые называет спека.** Образцы `<sub>/<rows>/<id>` (единицы, М10/3) и `<sub>/<таблица>/<имя>`
   (таблицы, М10/10) равны по узости. Так же равны `domain/<sub>/<книга>` и `domain/<sub>/<kept>` (М11/5), а
   `<sub>/<from книги>` — с единицами. Различает их только спека: загрузчик держит имена порознь (М10/2: имя таблицы ≠
   `unit.rows` ≠ зарезервированные семьи, книга ≠ строка `kept`).

   **Рекомендую** переменную, привязанную к ключу спеки, писать `<spec:ключ>`:
   - `<sub>/<spec:unit.rows>/<id>`;
   - `<sub>/<spec:tables>/<имя>`;
   - `domain/<sub>/<spec:domain.books>`;
   - `domain/<sub>/<spec:domain.kept>`.

   Правило: два образца, которые различаются только переменными `<spec:…>` разных ключей, не пересекаются. `check_spec`
   их не сравнивает, а ключ после `spec:` проверяет по Н1.2а М10/2.
2. **Условные читатели.** Например:
   - `<s>worker` читает `domain/grants` только при `door.routes`;
   - `domain/member-topology` — только при ключе `unit` у вида токена;
   - `domain/holder` — при чтении под `domain/`.

   **Рекомендую** в `readers` ту же форму, что у участника `ops`: `роль(условие)`, условия через запятую внутри скобок,
   без `;`.
3. **Ширина читателей.** Таблица прав М10/6 Н1.4 разрешает больше, чем называют нормы чтения: `<s>worker` и
   `<s>controller` читают весь `<s>/*`, роли домена — `<s>/*` всех спек. Если писать только читателей из норм, права из
   каталога выйдут уже нынешних (п. 12 решения).

   **Рекомендую** `readers` = разрешённые таблицей прав ∪ названные нормами. Сужение прав — отдельной правкой поведения.
4. **`guard` и `cas` в одной записи.** Почти все записи процесса `domain` у держателя идут под стражем `domain/signer-turn`
   и при этом с `cas`. Так же записи контроллера идут под `placement_turn`.

   **Рекомендую:** `guard` — запись под стражем, с `cas` или без. Какое сравнение версии, говорит условие участника.
   Операция по-прежнему одна на строку.
5. **Строка и объект под одним ключом.** У держателя `domain/shared` — строка-указатель, а у члена объект `domain/shared` —
   копия документа (М11/11 Н1.2, Н1.5). Хранилища строк и объектов разные.

   **Рекомендую** уникальность по паре (`key`, `kind`).
6. **Роль `configstore-door`.** Строку `platform/configstore-doors/<id>` пишет дверь без голоса (М10/11 Н1.3). Её роль в
   перечне М10/6 Н1.1 есть (`store_internal`), а в `check_spec` — нет.

   **Рекомендую** добавить `configstore-door`. Собственные файлы демона — каталог данных, `FORMAT`, `member.json`,
   сокеты — не данные между процессами, а жизненный цикл: они уйдут в `contracts/lifecycle/`, роль `configstore`
   каталогу не нужна.
7. **`rid` не исключает `free-`.** Шаблон `requests.key` или случайный `rid` может начаться с `free-`. Тогда строка просьбы
   по правилу «самый узкий образец» попадёт в семью `<sub>/requests/free-<server>-<volume>` ресурса.

   **Рекомендую** норму М10/8: `rid` не начинается с `free-`. У двери консоли это 400, воркер такой не создаёт. Это
   изменение поведения, отдельной правкой с шагом.
8. **Писатель строки спеки у кластера из одного процесса.** Процесс со встроенной спекой сам пишет `platform/spec/<sub>`
   и метку (М10/2 Н1.5, М11/12 Н1.1). Роли «установщик» в перечне нет: установщик и `spec put` у меня — `admin`.

   **Рекомендую** записать, что встроенная спека пишется тем же правом `admin` (процесс коробки ставит её как
   установщик). Иначе нужна роль установщика.

**Решаю сам, сообщаю:**
- **Ключ меток просьб.** М10/3 Н1.1 называет `<sub>/commands/<id>`, а М10/6 и М10/8 — `objects/<s>/commands/<rid>`. Это
  дефект данных: поправлю М10/3 по М10/8.
- **`when` со значением** (`unit.id: numeric` у `<sub>/next_id`) — в `when` только ключ `unit.id`, значение — в условии
  участника.
- **Без строки, пока нет нормы формы:**
  - замок присутствия воркера (М10/11 «Решает реализация» п. 5);
  - `domain/<sub>/heartbeat` воркера на домене (М11/5 Н1.6 формы не даёт);
  - объекты свидетелей `<sub>/<report>/<имя>` — отдельным вопросом при выписке М11/5.

**Дальше, пока жду ответа:** уроки без этих мест — М10/4, М10/5, М10/7, М10/9 (ширина читателей пока по рекомендации 3).
