### Подсистемная принадлежность воркера

N1.5 требует worker:<sub>/<w>. Ключи heartbeats принадлежат подсистеме, совпадение короткого имени между ними допустимо. Однако закрытый WorkerRow P/06.5 в проверенном источнике не содержит sub. Поэтому простая замена root на угаданную подсистему, запрет одинаковых имён или выбор первого/последнего воркера не приняты.

spec103 через coord103 сначала показывает цепь «нынешний источник → проекция P/06 → ссылка/выбор/карточка P/07», реальные поля и минимальный набор файлов. Если имеющихся публичных данных недостаточно, показывает ровно недостающую часть договора. Архитектор согласует эту часть до правки API и байтов. Новых дверей, локального справочника соответствий и поддержки старого формата заранее не назначено. Остальные исправления и P/08 этого плана не ждут.

### Продолжение доменного вида

Курсор возвращается неизменным значением параметра, с обычным URL-кодированием. Применяется действующая проекция P/10-R004: members и остальные поля по членам, units по подсистемам, полные claimant-списки contested; глобальные поля остаются глобальными. Курсор не разбирается по собственной грамматике. Не обещается снимок через конкурентные изменения. Сбой следующей страницы не превращает неполный вид в полный успех; сохраняются существующие правила неизвестности и отказов. Точный способ сборки, дубли конфликтного контекста и отображение неполноты перечислить в плане потребителя до кода.

Из них 43 исполняют неизменённый нынешний JS, module-return меняет location.replace в памяти для jsdom, shell-short использует подставной модуль. Положительный список не доказывает все 45 на неизменённом JS. Собственные изолированные пробы review103 не являются HTTP-дверью P/06 или реализацией домена. Фразу Д4 Kimi о нынешнем JS в обоих прогонах не наследуем: одна серия использует свидетель 9e035645, другая нынешние байты 05d167f5; доказательство нынешнего JS даёт только вторая серия. Остальные тесты вне N5 прочитаны по заголовкам/фикстурам/спискам проверок; это ограничение сохранено, не полное чтение всех 45 тел. Отказ shell-short относится к старому ожиданию русского текста VMS-оболочки. Он не новый дефект P/07 и не основание объявить весь набор успешным.
