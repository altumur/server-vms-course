   - Использовано 11 раундов из лимита этапов в 480 ходов и 25,38 млн входа из 250 млн.

## 2. Почему ворота были зелёными без cmd/judge и без исполнителя

### 2.1 Что проверяли ворота

**Задание** (`R/task/p01-engine-5f3c384afa46.json`, `stages.mech`):
- cwd `engine`;
- `go build ./...`, `go vet ./...`, `go test -race -count=1 ./...`;
- `require_own_tests: true`;
- `norm_trace`, `stage_tests`, `profile_probe` — false. В строках этапов (`R/task/stages-rows.json`) у всех шести `gate: "build"`.

**Цикл приводит любые ворота строки к одному `mech`:**
- loop.py:2636 — `plan.append(dict(r, …, form_gate=r["gate"], gate="mech", checks=[{"gate": "mech", …}]…))`;
- loop.py:1682 — `TASK_GATE_KINDS = ("build", "code")`: судейских ворот задание назвать не может.
- Значит, этапы tables…report различались только текстом цели. Проверка была одна и та же: собирается, vet чистый, тесты прошли.

**`./...` и пустой каталог.**
- `engine/cmd/judge` создан командой `round-001.json messages[80]` (`mkdir -p engine/cmd/judge engine/internal/model …`); mtime каталога 23:26:42. Файла в нём нет до конца.
- Каталог без `.go` для `go` не пакет: шаблон `./...` его не находит, ни build, ни vet, ни test о нём не говорят.
- В паспорте у всех 11 раундов `mech.test.packages` содержит только `internal/*`. P01.303 подтверждает: `go list` даёт 10 пакетов, `package main` нет, `go build ./cmd/judge` → «no Go files» (`P01.303-pass1-20261113T0838Z/engine-minimax/build-engine-mm.log`, `list-engine-mm.txt`).

**Что требовал `require_own_tests`.**
- `variant_b.own_tests` (variant_b.py:262–275) считает функции Test/Example/Fuzz по каталогам с `.go`; каталог без `.go` пропускается (`if not gos: continue`).
- `mech_summary` (variant_b.py:360–432):
  - `ran = any(x == "ok" for x in pk.values())` (405);
  - `own_ok = (n_own > 0 and ran) or not require_own` (423);
  - пакеты без тестов дают только строку «packages without tests of yours» (428) и не блокируют;
  - `ok = b_ok and v_ok and t_ok and own_ok` (429).
- Хватало одного прошедшего теста в любом пакете. Так `internal/model`, `internal/spec` (с раунда 1) и `internal/report` (раунд 11) прошли без тестов (`passport.rounds[10].mech.own_tests.packages_without_tests`).

**Пятая проверка раунда 11 (5/5) — пустая.**
- `profile_gate` на последнем этапе добавляет «profile completeness … final check» (loop.py:3086–3121, `final` — 3095).
- Модуль урока — `acceptance`, строк реестра с `owner == acceptance` нет. Профиля нет (`profile: null`), но `ok: true` (`passport.profile_completeness[-1]`; variant_b.py:688–).
- Проверка засчиталась зелёной, не проверив ничего.

**В самом снимке** (`S/work/engine`): 65 своих тестов в 7 пакетах. Один из них — `internal/qualification/tmp_print_test.go` `TestTmpPrint`: временная печать без проверки, засчитана как свой тест. 11 853 строки Go.

### 2.2 Откуда «0/0»

- В `S/log.jsonl` у каждого раунда `"judge": {…, "passed": 0, "total": 0}`, в `S/result.json` `"best": 0`. Это **мера приёмки** `acceptance_measure` (loop.py:680–): число прошедших проверок по списку целей задания.
- В generation_only целей нет (`passport.targets = {}`, «targets» в GEN_FORBID_TASK), поэтому мера всегда 0/0 и best 0. Это не счёт `go test`. `go test -race` в раунде 11 прошёл, `ok` у 7 пакетов (`passport.rounds[10].mech.test.packages`).
- Строка уведомления (loop.py:5476–5486) выводит `best 0`. «0 (0/0)» — не признак того, что тесты не шли, а признак того, что мера приёмки в этом режиме пуста.

### 2.3 Как цикл решил generation_done

1. Любой конец раунда mini-SWE — Submitted, LimitsExceeded, window_in_round, RepeatedFormatError — отдаётся циклу как вызов `done` (agent_miniswe.py:1405, `{"name": "done"}`). В `S/log.jsonl` у всех 11 ходов `"tools": ["done"]`.
2. После `done` идёт `stage_round` (loop.py:4449–):
   - `go = variant_b.generation_only(task)` (4473);
   - без проверки регресса прежних этапов: `regress = [] if go …` (4474);
   - зелёные ворота текущего → `closed.append` (4499), `S["cur"] += 1`;
   - `if go: break` (4506) — один этап за раунд.
3. Когда `S["cur"] == len(plan)`, `cur = None` (4512) и `status = "generation_done" if go else "stages_done"` (4518–4519); затем `freeze_candidate` — фиксация кандидата для суда (4563–4565).
4. То есть **условие — «последний этап закрыт зелёным mech»**. Ничего сверх ворот этапа: ни проверки цели, ни артефакта.
5. Раунд 11 закрыт так:
   - `round-011.json messages[42]` — «Created report package»;
   - `[43]` — ответ без командного блока, `extra.model_response`: «The initial implementation is in place. Before running it, I will add table-driven tests for every N1.5 secret spelling/encoding…»;
   - `[44]`, `[45]` — ещё два таких ответа;
   - `[46]` — `exit_status: RepeatedFormatError`;
   - ворота 5/5 → `passport.stops = [{"status": "generation_done", "turn": 11}]`.

Модель не сдавала этап: раунд оборвался, и цикл засчитал обрыв как сдачу.
