# Разбор ревью правок проб 08

Срез `e7c93809a..62704201a`, ревью Claude (Б 0, С 4, М 6) и Kimi (М 2). Главный вопрос снят: украденный ключ не примется ни стуком, ни после вытеснения пределом 4, потому что `revoked_members` не усекается. Исполнение — коммит этого файла. Реализацией правки не прогнаны.

| Находка | Решение | Что сделано |
|---|---|---|
| С-1 Claude | принято | договор приёма `forget`: запись без key с `revoked_keys` не принятый, её стук держится |
| С-2 Claude | принято | P/08.2 шаг 3: без `Entry.key` берётся последний из `revoked_keys`, шаг 3а — повтор |
| С-3 Claude | принято | P/08.3 пакет ретранслятора: исключение; машина с `via` получает 403 и возвращается после снятия `via`, названо |
| С-4 Claude | принято | `alarm-history` `cut`: третий случай, вектор верен |
| М-1 Claude, М-1 Kimi | принято | P/08.3 шаг 5а: только при отсутствии записи этого имени |
| М-2 Claude | принято | P/08.10 `revoked_keys`: фраза об отчёте верна для обоих случаев |
| М-3 Claude | не вносится | `Entry` держателя без `revoked_keys`: вреда нет, ключи держит `revoked_members`; правка вне поручения |
| М-4 Claude | не вносится | запись без key и без `revoked_keys` возвращается через `DELETE`, текст это допускает |
| М-5 Claude | принято | сц. 18 шаги 4, 10 судят `set_at`, не `index`: норма не запрещает перезапись той же копии |
| М-6 Claude, М-2 Kimi | запись в журнал | порядок старший первым остаётся, сортировка свидетеля неверна для вытеснения |

Сценарий стука вернувшейся машины из С-1 внесён по решению «Архитектора»: сц. 28 приёмки 8.3, `stolen` на стенде не вызывается, запись засевается через `admin.sock`. Реализацией не прогнан. Сам вызов `stolen` остаётся чтением.

Находка «Архитектора» при закрытии `a474fada9`: после кражи на том же держателе и до нового ключа `stolen`-перенос отвечал 409, хотя шаг 3 P/08.2 уже брал ключ из `revoked_keys`. P/08.8 Н1.8 выровнен с шагом 3. Правка идёт следующим пакетом: `d104c441` остаётся пином V/11 и конечной для c-go.
