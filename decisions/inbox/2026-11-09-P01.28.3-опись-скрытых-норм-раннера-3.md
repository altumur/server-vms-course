## Вывод

**Словарь стенда домена и стенда передачи в спеке подробный**: директивы, подстановки, имена кластеров, подготовка
(`c1-<кластер>`, `sh1`, `srv-<кластер>` — README P/09.1), пароль `root`, копия восстановления 0600, `{cport}`, 40 с шага,
`PASS_TICKET_CHECK` + 30 с. Скрытого меньше, чем в P/01-части, и оно другого рода: не «что делает директива», а **как
раннер её исполняет** — формы проводов, сроки, порядок, исключения.

**Скрытое — в шести местах:**
1. **Провод подставного воркера и клиента консоли** (`pass_stand.py`): путь пробы `/<sub>/api/x`, ответ 204 на пробы
   замены (и они считаются в `@pass-seen`), форма ответа воркера (`200 Stream`, `text/event-stream`, кадр `текст\n\n`),
   случайный `Idempotency-Key` вместо правила `@key`, разбор SSE, поглощение сообщений `@stream-none`.
2. **Готовность и жизнь процессов домена**: «агент жив» = жив через 0,3 с; местная дверь — до 10 с по `mtime` сокета;
   остановка — 30 с без SIGKILL (у общего стенда — 60 с); копии ретранслятора — строго до членов за ним; `@domain`
   требует **точный** список `members` по имени, без лишних.
3. **Расхождения кода со спекой**: ключ по умолчанию без `<run>-` (README: `<run>-<scenario>-<step>`); `W2C_WALL_OFFSET`
   задаётся всегда (`+0`), README — только с `@clock`; `CLUSTERS` через посредников дорог, README — «without proxies»;
   `{args}` команды `move` — сырой текст строки, `PROFILE.md` — «prepared sequence of quoted arguments»; `@file`
   сравнивает пересериализованный JSON, README — «byte for byte»; `--only` даёт GREEN по подмножеству.
4. **Карта «дверь → договор полной формы»** (`full_form`) — только в коде; часть путей консоли не судится вовсе.
5. **Итог главы**: проваленная директива обрывает сценарий («not run»), а класс главы видит только `runner` и `data` —
   провал стенда на уровне главы неотличим от провала реализации.
6. **Среда засчитываемого прогона** (`portable/*`): предел файлов, локаль, ядра, каталоги спеки только для чтения, аудит
   процессов между целями, допуск архива (выпуск раннера, квалификация, печать кандидата), числа ворот — в ADR-0083, в
   спеке приёмки их нет (продолжение 8.12 второй описи).
