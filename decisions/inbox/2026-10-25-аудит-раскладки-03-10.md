# Аудит раскладки уроков 03–10

Поручение «Архитектора» по решению владельца ADR-0083 доп. (34) п. 4 (2026-10-25). Исполнитель — «Спецификация». Нормы
не правились: здесь только находки и предложения, решение — за «Архитектором».

**Охват.** Нормы `Platform/03-worker` … `Platform/10-domain-console` (`spec/*.norms.md`), все общие договоры
`Platform/common/contracts/*.md`, исходы `*/data/*.outcomes.tsv` уроков 03–10, каталог `Platform/common/data/catalog.tsv`,
указатель пакетов `Platform/common/vectors/README.md`. Срез — `origin/main` на 2026-10-25.

**Способ.** Категории «а»–«в» — чтение и поиск по договорам и нормам: категории выполнены параллельными проходами чтения,
каждая строка сверена с местом. Категория «г» построена скриптом: каждая строка `outcomes.tsv` уроков 03–10, где стоит
«норма исхода не называет», сопоставлена с семьёй каталога (колонка `form`) и её читателями (колонка `readers`). Строки
категорий могут сходиться (одно место — две находки): перекрёстные ссылки даны в колонке «Предложение».

**Ограничения.** Проверка — по тексту, не по реализациям. Категория «а» оценивает «читает другой процесс» по ссылкам норм
(«как P/0X», значение, повторённое литералом); чтения без ссылки могли не попасть. Нумерация строк файлов — на срез выше.
