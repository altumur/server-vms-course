# М10 Платформа: хранилище и спека

Все одиннадцать уроков в main (2026-10-14, «Архитектор» за «Спецификацию»). Во всех уроках 1–11 лекция отделена от норм: она лежит в каталоге модуля, нормы, OpenAPI и инструкция реализации — в общем `spec/` с префиксом лекции (ADR-0080, решение владельца 2026-10-15). У урока 7 (и у урока P/03, прежде урока 5) нет собственной HTTP-двери: в spec/ только нормы и инструкция (ADR-0082 доп. 13/14). Долг полных форм Н2 закрыт у всех собственных HTTP-дверей М10; проверка документов не подтверждает внедрение в реализациях. Любая реализация проверяется приёмкой из `Source/tests/testdata/acceptance/М10_Platform/`. Нарезка, форма урока и правила — [`module-design.md`](module-design.md); соответствие прежним урокам М10A и М11_Cluster — ADR-0080 доп. 4 и раздел «Соответствие прежним урокам» в нормах каждого урока; прежние уроки удалены 2026-10-14 по слову владельца, две записи о решениях прежнего М11 — в `_notes-ru/`.
