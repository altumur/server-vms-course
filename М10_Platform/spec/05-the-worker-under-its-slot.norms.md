# М10/5 — Воркер под слотом: нормы

Канон урока. [Лекция](../05-the-worker-under-its-slot.md); [инструкция](05-the-worker-under-its-slot.README.md).

## Н0 Словарь слов

ДОЛЖЕН, СЛЕДУЕТ, МОЖЕТ — по [общему словарю](01-storage.norms.md#н0-словарь-слов).

## Н1 Форма

### Н1.1 Пульс

Объект `<sub>/heartbeats/<имя>` (объект, не строка; двери объектов — урок 8). Платформа читает `worker`, `ts`, `status[].id`, `status[].phase`, `status[].epoch`, `status[].revision`, `status[].observed_revision`, `server`, `instance`, `labels`, ёмкость и запас; остальное — слова подсистемы, которые платформа не читает (`heartbeat.strings` спеки называет, какие из них — строки).

```yaml
heartbeat:
  worker:    <имя слота>                 # ДОЛЖЕН; равен имени в ключе
  ts:        <стенные секунды писателя>  # ДОЛЖЕН; для показа и расхождения часов, не для свежести (ADR-0049)
  status:    # ДОЛЖЕН; по элементу на единицу, которую воркер ведёт
    - {id, phase, epoch, revision, observed_revision, …слова подсистемы}
  server:    <сервер> | ""               # ДОЛЖЕН; "" ровно когда сервер неизвестен (ADR-0029)
  instance:  <экземпляр>                 # ДОЛЖЕН
  labels:    <метки узла через запятую>
  <capacity.from>:  <ёмкость>            # имя поля — из spec.placement.capacity.from (умолчание capacity); когда известна
  <headroom.from>:  <запас = ёмкость − Σ весов назначения>                       # умолчание headroom
  conflicts: <Σ конфликтов аренд + перенесённых>   # метрика <sub>_epoch_conflicts
  started:   <момент старта>
  previous_hb, previous_instance, previous_server:  # что воркер застал под своим именем при старте, если было
  fenced:    true                        # только пока отсечён
  schema, build, pending_writes:         # уроки 10, 11
  server_unsaid:  <текст ADR-0029>       # только когда сервер не назван, а спека требует places.server_field
  stood_in:  {step, for, as_of}          # только в пульсе подмены (Н3)
  stand_in_renewals: <число>             # только когда > 0
phase:
  rule: слова подсистемы; платформа знает одно — running (счётчик running, соседство near)
cadence:
  HEARTBEAT_EVERY: 10            # с; первый пульс — до первого прохода, последний — при остановке
  fresh_for: 45                  # с; читатель судит по смене на своих часах (урок 4)
nobody: пульс не пишется, пока воркер — никто
platform_strings: [worker, server, url, instance, labels, fetched, events]   # heartbeat.strings их не называет
```

Неизвестный сервер не препятствует работе под своим слотом. `server: ""` не разрешает считать
место своим; если задан places.server_field, пульс обязательно содержит server_unsaid; при places.lease: strict все
места считаются строгими по ADR-0029. При известном сервере server непустой, server_unsaid отсутствует.
BOX_ID и instance не подставляются вместо неизвестного сервера: это другие имена.

### Н1.2 Сроки цикла

```yaml
loop:
  LEASE_TTL: 30; LEASE_MARGIN: 5                    # окно 25 с (урок 3)
  LEASE_EVERY:  (TTL − MARGIN) / 3 ≈ 8.3            # шаг аренды, от НАЧАЛА предыдущего шага
  again:        после неотвеченного продления или при неподтверждённой аренде — следующий шаг сразу
  HEARTBEAT_EVERY: 10
  POLL:         ~2                                  # пауза между проходами без событий; долгий опрос — решает реализация
  WAKE_GAP:     0.25; WAKE_GAP_MAX: 2; PASS_SHARE: 2   # ранний проход не раньше 0.25 с от начала прошлого и не чаще
                                                    # двух длин прохода — для реализаций с долгим опросом
stand_in:
  STALL:        (TTL − MARGIN) / 2 = 12.5           # с; шаг застрял, если идёт дольше
  WAKE:         ≤ (TTL − MARGIN) / 4 = 6.25         # с; как часто подмена смотрит
  FOR:          300                                 # с; дольше не подменяет: единицы уходят
  BEAT_EVERY:   10                                  # с; повтор пульса подменой
watchdog:
  notify:       из цикла, не из подмены; WatchdogSec юнита — между FOR и HUNG_MOVE_AFTER (урок 11: 360)
contend:
  CONTEND_EVERY: 10; CONTENDER_FRESH: 300           # с; метка соперника
places:
  HOLD_SKEW: 5                                      # с; чужое место свободно, простояв без изменений 45 + 5
  WRITE_WINDOW: 45 − 5 = 40                         # с; строгое место пишется, пока подтверждено не дольше
  CLOSE_BY:     45 + 5 = 50                         # с; к этому моменту писатель места закрыт
memory:
  rule: CAPACITY × unit_mb + base_mb ≤ WORKER_MEMORY_MB, иначе процесс не стартует (ADR-0070); без unit_mb — не проверяется
```

### Н1.3 Строка удержания места

```yaml
<sub>/holds/<место>:                      # форма слота (урок 3 Н1.4) без server, плюс by
  holder, until, released, gen:  как у слота
  by:        <имя слота держателя>        # чьё место
rules:
  own_place: сервер воркера известен и непуст; строка места в таблице мест называет его (places.server_field) — место своё (ADR-0029);
             иначе место чужое или любой коробки — при places.lease: strict держится только в окне
```

### Н1.4 Метка соперника

Объект `<sub>/contenders/<имя>/<коробка>`: `{name, state: refused | nameless | waiting, box, hostname, server, instance, holder, holder_box, since, at}`; `refused` — имя держит живой на другой коробке; `nameless` — имя отняли, воркер ждёт его; `waiting` — держатель завис или о нём неизвестно, имя не берётся. Переписывается каждые `CONTEND_EVERY`; старше `CONTENDER_FRESH` не читается; `since` сохраняется в пределах одного состояния.

## Н2 Двери

У воркера нет собственной двери в этом уроке: он пишет и читает хранилище (урок 1) и объекты (урок 8). Что о нём видно снаружи — пульс, слот, метка соперника, `/servers` консоли (урок 9). HTTP-контрактов своего урока нет (ADR-0082 доп. 13). Формы ответов чтения/записи — [урок 1](01-storage.api.openapi.yaml), единиц — [урок 3](03-units-slots-epochs-lease.api.openapi.yaml), объектов — [урок 8](../08-events-resource-requests.md#н2-двери). Пульс — форма Н1.1, не HTTP-ответ воркера. Подсистеме воркер даёт четыре вызова, форма которых — дело языка (решает реализация):

```
start_unit(id, row, epoch)   — запустить единицу под эпохой
stop_unit(id)                — остановить
status() → [status-элемент]  — доложить для пульса
reconcile_once()             — шаг сверки желаемого с текущим (урок 8)
```

## Н3 Проход

### старт()

```
1. спека из каталога — обязательна (NoSpec иначе); бюджет памяти (Н1.2) → иначе не стартовать
2. экземпляр = <коробка>:<pid>:<6 hex>; коробка — BOX_ID | machine-id | hostname (урок 11)
3. сервер выведен (строка platform/decommission/<мой сервер> или <sub>/decommissioned/<мой сервер>, урок 4) → никто, журнал
   «server <s> is decommissioned», имя не берётся; иначе захватить(имя из окружения | без имени) (урок 3);
   роль обычного/запасного и набор SPARE_FOR сохраняются на весь срок экземпляра; каждый захват,
   включая поиск после потери, применяет фильтр участника таблицы М10/3 Н3;
   право забрать имя у своей коробки — только этот первый вызов при старте, не последующий поиск;
   отказ NameOnAnotherBox → никто, метка refused
4. запомнить, что застал под именем (previous_*)
5. имя получено → writing_allowed = true, пульс сразу; имя не получено → writing_allowed = false, пульса нет;
   запустить подмену и цикл (подмена никого не продлевает, пока воркер — никто)
```

**Гонки.** Две копии на одной коробке с одним именем: захват — `cas`, проигравший — никто (Н3); старт против живого слота на другой коробке — `refused` (Н1.4).

### цикл() — один оборот

```
1. если никто или не writing_allowed: воссоединиться() (ниже);
   имя не получено → только поиск/метка соперника и ожидание; шаги 2–5 не выполнять
2. проход сверки: прочитать назначение; для каждой назначенной единицы, которой нет: взять_эпоху →
   снова проверить ворота и may_act непосредственно перед start_unit; отказ → не запускать;
   ведомой нет в назначении → отменить её незавершённые запуски, stop_unit;
   revision вырос → при открытых воротах и may_act принять попытку перезапуска: stop_unit и start
   под той же эпохой/арендой через локальный переход ниже, без новой выдачи и без сброса last;
   иначе изменение revision ждёт, прежняя единица идёт лишь пока разрешает may_write;
   потерянную аренду останавливает шаг_аренды; каждая единица — в своей попытке
3. насос: события, просьбы, команды (урок 8)
4. если clock − начало_прошлого_шага_аренды ≥ LEASE_EVERY или again: шаг_аренды()
5. если clock − прошлый_пульс ≥ HEARTBEAT_EVERY: пульс
6. watchdog notify; пауза до POLL или до события (долгий опрос)
каждый шаг — в своей попытке и под маркером guarded(имя шага) для подмены
```

**Гонки.** Один поток цикла, но подмена может потерять имя/отсечь воркера, пока выдача эпохи или
start_unit не вернулись. Запуск и отсечение согласуются локальным переходом ниже; CAS хранилища
не защищает состояние процесса. Подмена пишет пульс, слот, аренды и место под теми же `cas`.

### шаг_аренды()

```
1. продлить слот (урок 3):
     хранилище не ответило            → всё ещё я; again = true
     holder ≠ я или released          → отдать_имя(); отсечь("slot <имя> is held by another instance now");
                                        вернуть все ведомые (они будут остановлены отсечением)
2. прочитать platform/epoch_floor (раз за шаг); подтвердить каждую аренду (урок 3): потеряны = те, у кого не may_write
   или эпоха единицы < пола (восстановление хранилища подняло пол — урок 11; процессы оно не перезапускает)
3. прочитать назначение; не ответило → прежний ответ, пометка «не отвечено»
4. для каждой потерянной: stop_unit; отпустить эпоху; запомнить «отпущена до следующего чтения»;
   журнал: «<единица> stopped: a newer epoch was issued for it | unconfirmed for longer than its ceiling (N s)
   | the store did not confirm the lease in time | its epoch is below the floor»
   единица не отсечена, в назначении и may_write под потолком → не останавливать: «данные идут, команды ждут»
5. подтверждённые снова после молчания — одна строка журнала, ничего не остановлено
6. строгие места (ниже)
```

**Гонки.** Переезд и отсечение экземпляра различаются только назначением: потерянная аренда при живом слоте — одна единица; потерянный слот — все. Молчание хранилища на шаге 1 и 2 одновременно — ничего не теряется до потолка.

### взять_эпоху(единица) — ворота перед запуском

```
по порядку:
  я никто (слот потерян / ищу имя)                              → отказ NoSlot
  отсечён                                                        → отказ
  шаг длится дольше FOR (пережил подмену)                        → отказ NoSlot «until the loop has looked again»
  единица отпущена после последнего чтения назначения            → отказ NotReadThisPass
  назначение не отвечено                                         → отказ NotReadThisPass
  единицы нет в последнем отвеченном назначении                  → отказ NotReadThisPass
перед обращением за эпохой: зарегистрировать незавершённую попытку запуска для этой единицы
  и текущего владения именем; потеря имени, отсечение или отмена единицы необратимо отменяют попытку
→ эпоха и новая аренда = выдать по уроку 3; last — время отправки подтверждённой записи,
  не время возврата; поздний ответ или истечение окна до start_unit → lost, не запускать,
  пометить «отпущена до следующего успешного чтения назначения»
после выдачи и непосредственно перед start_unit вновь проверить все ворота выше, may_act,
  что попытка не отменена и относится к тому же владению именем;
неответ выдачи новой аренды не создаёт; unconfirmed_max не разрешает этот первый запуск
любой отказ завершает/отменяет эту попытку; позднее завершение запроса не может её оживить
воркер, ни разу не читавший назначения, не держится ни за какой список
```

**Гонки.** Урок 3, «взять_эпоху»: `cas` по строке эпохи, пол читается до записи; второй воркер той же единицы берёт следующую эпоху, старший отсекается на подтверждении.

Успешный ответ записи, отправленной в 0, получен в 30: номер уже мог вырасти, но start_unit
не вызывается и номер не откатывается. То же при ответе в 24 и паузе до запуска в 26 без нового
подтверждения. Если за время выдачи потерян слот или поменялись ворота, их повторная проверка
запрещает запуск даже при оставшемся времени аренды.

Последняя проверка и принятие запуска — один локальный переход, согласованный с отсечением,
отдачей имени и отменой единицы. Отсечение раньше этого перехода запрещает start_unit; позже —
видит также уже принятый, но ещё не завершённый запуск и отменяет/останавливает его. Позднее
завершение отменённого start_unit не публикует ведомую единицу заново. Возврат имени и новое
чтение назначения не оживляют старую попытку: нужен новый вызов ворот. Запросы хранилища и
длительный start_unit не удерживают блокировку, которая запрещала бы подмене закрыть допуск.
Внутренний механизм синхронизации — выбор реализации; наблюдаемый порядок обязателен.
Это относится ко всем вызовам start_unit, включая перезапуск по revision. У такого перезапуска
проверяются те же ворота и may_act, но выдачи эпохи нет и состояние прежней аренды не заменяется
новым. Молчание при ещё разрешённых данных откладывает изменение revision до подтверждения;
само ожидание перезапуска не переводит действующую silent-аренду в lost.

### никто и возврат имени

```
отдать_имя(): отменить незавершённые попытки запуска; seeking = имя; slot = nil; назначение забыто
пока никто: продление → нет; подмена → нет; назначение → пусто, хранилище не спрашивать; взять_эпоху → NoSlot;
            пульс → не писать; отдать слот → ничего; удержание места → ждёт как все
искать_имя(): сервер выведен (как на старте, шаг 3) → остаться никем; given задано → только его, без отъёма у живого (steal = false): держит живой или не отдано
              → _NameTaken: раз за эпизод журнал worker.name_taken (тревога), метка nameless каждые CONTEND_EVERY
              given нет → любое свободное/отданное или новое <prefix>-<max+1>
воссоединиться(): перенести конфликты (conflicts_carried += Σ), отпустить все эпохи, забыть единицы, отдать_имя,
              искать_имя; имя получено → writing_allowed = true, журнал «rejoined as <имя>», worker.name_back
```

**Гонки.** Имя вернулось двум ждущим: захват с `cas`, второй остаётся никем и ждёт дальше; возврат имени против его отдачи контроллером — `gen` и `released` решают (урок 3).

### отсечь(почему)

```
флаг первым: writing_allowed = false (идемпотентно); все имеющиеся аренды — fenced;
отменить все незавершённые попытки запуска;
журнал «FENCED (почему). Stopping every unit.»;
остановить все единицы, включая принятые незавершённые запуски; эпохи отпускаются при воссоединении
```

**Гонки.** Отсечение и возврат выдачи эпохи/start_unit упорядочены локальным переходом ворот;
поздний ответ не сбрасывает флаг и не восстанавливает отменённую попытку. Пульс с причиной пишется,
только пока имя ещё моё (отсечение единиц при живом слоте); после `отдать_имя` пульса нет
(никто — Н3), причина — в журнале и в метке соперника Н1.4.

### подмена() — отдельный поток, каждые WAKE

```
шаг цикла идёт дольше STALL и меньше FOR, воркер не никто и writing_allowed:
  продлить слот первым записью с cas — только пока строка называет меня и не released (хранилище не ответило — всё ещё я;
  чужой holder или released → отсечь всё, как в шаге аренды, подмену прекратить); затем продлить каждую аренду;
  продлить удержание места так же;
  пульс: повторить последний пульс цикла с новым ts, stood_in: {step, for, as_of}, stand_in_renewals —
  не чаще BEAT_EVERY и только если цикл сам не написал
шаг идёт дольше FOR: done; журнал «no longer standing in for it (FOR 300 s): its units go»;
  аренды, которые больше не могут действовать, — остановить их единицы по одной
подмена никогда не оживляет отсечённого и не зовёт watchdog
```

**Гонки.** Подмена и цикл продлевают одну строку слота: замок слота неблокирующий, кто не взял — пропускает; `cas` страхует от записи поверх чужого захвата. Цикл вернулся из застрявшего шага: `взять_эпоху` в нём отказано (шаг пережил подмену), пока цикл не прочтёт назначение заново.

### писать_под_слотом(key, items | удалить)

Условия и запись — урок 3 Н3; здесь: кто зовёт — публикации вкладов, книг и служебных строк подсистемы; **удаления** таких строк — тоже под стражем. Ни аренда, ни потолок молчания не разрешают публиковать состояние управления: только живой свой слот.

**Гонки.** Урок 3: 412 `guard` требует перечитки владения. Собственное продление (в том числе подменой)
сохраняет holder/gen и имя; смена держателя или поколения — потеря. Подмена под слотом не пишет — только продлевает.

### место: взять, держать, отпустить

```
взять_место([кандидаты в порядке подсистемы]):
  порванные — пропустить; сначала места, чьё by = моё имя (если слот мой); место, которое «следует за именем»
  (строка места называет мой сервер; или не называет сервера и прежний держатель с этой коробки) — брать сразу;
  иное — только когда свободно (released, holder "", мой) или простояло без изменений 45 + HOLD_SKEW по моим часам;
  записать форму Н1.3 с cas; conflict → следующий; все заняты → "" (я запасной)
держать: продление на каждом шаге аренды с cas; другой holder → потеряно; хранилище молчит → держится
  в окне: строгое место (lease: strict и не своё) — пока подтверждено < WRITE_WINDOW, закрыть к CLOSE_BY;
  своё место — пока < WRITE_WINDOW + unconfirmed_max (forever — без предела)
  окно вышло → спросить ещё раз; не «моё» → leave_place: журнал «the hold on <p> has not been confirmed for N s,
  and its lease is strict | past the units' ceiling — letting go of it»; подсистема закрывает писателя
отпустить: released: "true", until: now (только упорядоченная остановка)
```

**Гонки.** Два воркера за одно место: `cas` строки удержания; строгое окно — проигравший отпускает место и единицы на нём (Н3); удержание против подмены — одна запись в момент, подмена перечитывает `holder`.

### остановка по SIGTERM

```
1. подмена — стоп; опрос — стоп
2. before_stop_all (подсистема); остановить все единицы; after — закрыть писателей мест
3. пульс последний раз
4. отдать слот (урок 3); отпустить место
5. after_stop
крах молчит: ни отдачи слота, ни последнего пульса — судит контроллер (урок 4)
```

---

**Гонки.** Остановка против подмены: подмена останавливается первой, затем отдача слота; остановка против шага аренды — шаг доводится до записи или прерывается до неё, отдача одна; SIGKILL — не пишется ничего (сц. 05).

## Н4 Отказы

| Причина | Исход | Запись | Что делает воркер |
|---|---|---|---|
| спеки нет в каталоге | не стартовать | `NoSpec` | ошибка развёртывания |
| бюджет памяти превышен | не стартовать | `MemoryBudgetRefused` | ошибка развёртывания (ADR-0070) |
| имя держит живой на другой коробке | никто | метка `refused`, тревога | ждать имени; оператор исправляет имя или BOX_ID/идентификацию коробки |
| имя отняли на этой коробке | никто | `worker.name_taken`, метка `nameless` | остановить всё, ждать своего имени |
| держатель имени завис / неизвестен | никто | метка `waiting` | ждать слова контроллера |
| продление слота: чужой `holder` / `released` | отсечён | «FENCED (slot … held by another instance now)» | отдать имя, остановить всё, воссоединиться |
| продление слота: хранилище не ответило | ещё мой | `store_errors + 1`, `again` | следующий шаг сразу |
| аренда: чужая эпоха | единица остановлена | «a newer epoch was issued for it» | эпоха отпущена; если в назначении — запустить снова под новой |
| аренда: молчание дольше потолка | единица остановлена | «unconfirmed for longer than its ceiling (N s)» | то же |
| аренда: не подтверждена вовремя (проспана) | единица остановлена | «did not confirm the lease in time» | то же |
| взять эпоху: никто / отсечён / шаг пережил подмену / не в назначении | отказ | `NoSlot` / `NotReadThisPass` | не запускать до следующего чтения |
| выдача эпохи подтверждена после истечения начального окна или оно истекло до start_unit | отказ запуска, lost | номер не удаляется и не откатывается; это не silent | ждать нового успешного чтения назначения, затем новая попытка через все ворота; forever не обходит отказ |
| запись под слотом: `412 guard` | запись не сделана | — | перечитать владение по уроку 3; своё продление сохраняет имя, чужой holder/gen или отданный/нечитаемый слот — отдать имя и воссоединиться |
| подмена: шаг дольше FOR | единицы уходят | «no longer standing in …» | остановить потерянные |
| место: другой `holder`; строгое окно вышло | место потеряно | «letting go of it» | закрыть писателя места |
| сервер не назван, а спека требует `server_field` | своих мест нет; при `places.lease: strict` все места строгие | `server_unsaid` в пульсе | ошибка развёртывания (ADR-0029) |

### Свидетельства вне TSV

Строка epoch доказывает выданный номер, но не сам вызов stop_unit или прекращение внешней записи.
Пульсы и метки — объекты, которые текущий TSV не читает. Для них нужен отдельный наблюдатель/стенд
или чтение реализации её владельцем; авторский обзор документов этим свидетельством не является.

| Нормы | Предмет и вмешательство | Наблюдаемый результат |
|---|---|---|
| 5-01, 02 | объект пульса до первого прохода, через 10 с, при SIGTERM и после потери имени | поля Н1.1, ритм, никто не пишет под прежним именем |
| 5-03…05 | журнал start/stop, неответ назначения, чужая эпоха, пол, проспанное окно; задержка ответа выдачи до 24/25/30 с, пауза до старта, смена ворот за время запроса (README приёмки) | первое окно от отправки; поздний успех и смена ворот не запускают единицу; остановка нужных единиц, запрет нового старта без свежего чтения |
| 5-06, 12, 14 | первый старт/повторный поиск, другая BOX_ID, выведенный сервер | отказ/метка по ветви, нет чередующегося отъёма имени; TSV проверяет только случай одной коробки |
| 5-07 | задержка шага через STALL и FOR, гонка подмены и цикла, возврат после FOR | ограниченная подмена, общий страж, нет watchdog из подмены, ворота до нового чтения |
| 5-08, 13 | собственное продление, чужое поколение, ambiguous до/после истечения памяти id | своё продление не лишает имени; поздний ответ не восстанавливает владение |
| 5-09 | своё/чужое strict-место, отказ хранилища, границы WRITE_WINDOW/CLOSE_BY | прекращение внешних записей и закрытие писателя; строка holds сама по себе этого не доказывает |
| 5-10, 11 | SIGTERM против подмены, SIGKILL, недостаточный/достаточный бюджет памяти | порядок остановки и отсутствие уборки при крахе; отказ до старта по бюджету |

## Решает реализация

Реализация обязана назвать в своём описании:

1. **форму четырёх вызовов подсистемы**, синхронизацию принятия/отмены запуска с отсечением
   и помощник сверки (ADR-0033);
2. **долгий опрос или пауза** между проходами, насос команд и его период;
3. **как присутствие процесса видно ресурсу сервера** (замок-файл `<root>/.workers/<экземпляр>.lock`, pid-файл, проверка pid) — норма присутствия в уроке 11;
4. **период подмены** в пределах Н1.2 и число повторов `cas` при продлении;
5. **дополнительные поля пульса** подсистемы и что из них строки (`heartbeat.strings`);
6. **`TimeoutStopSec`** юнита — не меньше времени остановки единиц плюс отдачи слота (урок 11);
7. **как воркер узнаёт `names_given` и предел зависания** — из отчёта прохода (урок 4).
