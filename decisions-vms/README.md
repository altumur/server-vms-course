# Решения VMS (ADR-VMS-NNNN)

VMS — отдельный продукт поверх платформы w2c (ADR-VMS-0001). Решения о VMS с 2026-11-08 — здесь, серия ADR-VMS-NNNN,
формат как у решений курса (`.cursor/rules/adr-format.mdc`). Решения курса — `decisions/` (ADR-NNNN); их шаги с долей VMS
ведутся в плане VMS со ссылкой на ADR курса.

| ADR | Решение | Статус |

| [ADR-VMS-0001](0001-vms-отдельный-продукт-поверх-платформы-w2c.md) | VMS — отдельный продукт поверх платформы w2c, работа на маке | proposed |
| [ADR-VMS-0002](0002-api-платформы-w2c-для-vms.md) | Что VMS берёт из платформы: вся выгрузка на закреплённом пине, VMS судится только по нему | proposed |
