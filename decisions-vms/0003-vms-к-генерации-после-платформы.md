# ADR-VMS-0003. VMS к генерации — после того, как путь докажет платформа; пакеты — генераторами на маке, правки инструментов — точечно на CT 103

## Context and Problem Statement

Класс системы: платформенная система.

Опись spec-vms-claude (2026-11-08) по урокам V/01–V/07, V/10, V/12: ни один урок VMS не готов к генерации нашим циклом MiniMax. Нет форм (`stages.tsv`, флаги, отказы), `lifecycle.md`, швов и входов приёмки, пакета генераторов; у 27 глав норм нет `acceptance/K/`. Первая предложенная проба — V/10, затем V/04–V/06.

Генераторы пакетов (`tools/normgen`) и раннер приёмки (`cammeta-acceptance`) — инструменты платформы у coord103-tools и coord103-src на CT 103; CT 103 работает только по платформе (ADR-0083 доп. (146)).

Два вопроса: когда открывать работу «VMS к генерации» и кто собирает пакеты и ведёт раннер для VMS.

## Decision Drivers

* Путь «спецификация → генерация → боевая приёмка» на платформе ещё не доказан: P/01 и P/02 с боевыми свойствами не зелёные (ADR-0130).
* Обвес урока (формы, приёмка, пакет) дорог; переделывать его после уроков платформы — двойная работа.
* Один код инструментов — без копий генераторов и раннера для VMS.
* CT 103 — только платформа.

## Considered Options

Вопрос 1 — когда:
* А. Открыть сейчас: обвес V/10 целиком.
* Б. Сейчас только формы и `lifecycle.md`, приёмка — позже.
* В. Подождать, пока путь докажет платформа.

Вопрос 2 — инструменты:
* а. Генераторы платформы запускать на маке для форм VMS, код не меняя.
* б. Правки кода генераторов и драйверы раннера для VMS — точечным исключением у coord103-tools и coord103-src.
* в. Свои копии генераторов и раннера для VMS.

## Decision Outcome

Слово владельца 2026-11-08: «1 - В, 2 - а+б».

1. **Работа «VMS к генерации» (формы, `lifecycle.md`, приёмка, пакеты уроков VMS) не открывается,** пока платформа не докажет путь: P/01 и P/02 сгенерированы и зелёные с приёмкой боевых свойств (ADR-0130). Тогда представитель владельца приносит владельцу предложение открыть работу, первой — V/10, затем V/04–V/06 (опись spec-vms-claude).
2. **Пакеты VMS — генераторами платформы на маке,** без правки их кода, пока его хватает. Если для VMS нужна правка кода генераторов или драйвер раннера — точечное исключение: представитель владельца просит coord103-tools (генераторы) или coord103-src (раннер) одной задачей; остальная работа VMS на CT 103 не попадает. Копий инструментов для VMS нет.

### Consequences

* Good, because VMS не тратит силы на обвес, который может поменяться по итогам платформы.
* Good, because один код инструментов для обоих продуктов.
* Bad, because генерация VMS откладывается на срок, который задаёт платформа; дата неизвестна.
* Bad, because точечные исключения на CT 103 размывают правило «только платформа»; каждое — отдельной задачей, видимой в учёте Диспетчера.

### Confirmation

* В плане VMS шаги обвеса уроков стоят «ждёт: путь доказан на платформе» до этого события.
* Каждая правка инструментов ради VMS — отдельная задача у coord103-tools или coord103-src со ссылкой на этот ADR.

## Pros and Cons of the Options

### В (выбран)

* Good, because без двойной работы.
* Bad, because ожидание.

### а + б (выбран)

* Good, because без копий и без переноса VMS на CT 103 целиком.
* Bad, because исключения на CT 103.

### в

* Bad, because две версии одного кода расходятся.
