## 1. Принцип

**Платформа ничего не делает того, что касается подсистем, и ничего о них не знает. Всё, что она знает, это спеки (`<sub>.subsystem.yaml`), по которым работают её элементы.** Подсистема это воркер плюс описание. Контроллер, консоль, ресурс, хранилища, эпохи, слоты, права поставляет платформа и работает от спеки.

Записка архитектуры (§1.11, §1.12, шаг 15) это обещает. Урок 1 М10A обещает «нет даже слова camera». Ни одно обещание сейчас не выполнено.

### 1.1 Без хуков: правило трёх мест

Хук это код подсистемы, который платформа вызывает. Каждый существующий хук уходит в одно из трёх мест:

| Про что хук | Куда уходит | Форма |
|---|---|---|
| размещение, права, допустимость строки | **в спеку** | декларация: `affinity`, `fit`, `near.prefer`, `ref`/`must_match`, `unique`, JSON Schema поля, `rights`, `metrics`, `servers.show`, `holds`, `about` |
| байты и политика на данных | **в воркер** | платформа пишет строку-запрос, воркер решает и отвечает heartbeat'ом; страница ходит на дверь держателя сама, адрес берёт из `/where` |
| показ | **в страницу** | страница продукта это контент; она пользуется только маршрутами, объявленными спекой |

Перечень хуков и их замена: §4.

## 2. Прямые утечки: платформа знает о VMS

Семь корней. Всё остальное (около 400 комментариев в продукте, около 250 в курсе) следует из них.

### 2.2 Страницы платформы это страницы VMS

| Где | Что |
|---|---|
| курс `w2cplatform/console.html:196-284, 399-402, 418-448, 595-910, 933-957, 1039` | формы «Declare an archive», «Recording» с `retention_days=30`, «Detectors» `motion|linecross|lpr`, «Automation» с реле/PTZ/пресетами, плеер, WHEP, `/timeline`, `/rec/*`, `/det/*`, `/auto/*`, опрос каждые 10 с |
| продукт `w2cplatform/console.html:53-57, 181-217, 332-362, 486-618` | то же |
| продукт `w2cplatform/domain/page.html` | «Домен VMS»: камеры, сценарии между камерами, пересечения, `/api/cameras`; хука замены нет |
| продукт `vms/console.html` (4398 строк) + `page.go` | обратное: вся платформенная часть UI (вход, break-glass, домен, серверы, drain, decommission, `/schema`) живёт в странице VMS и подменяет платформенную |

**Исправление.** Страница платформы строится из `/spec` и не содержит ни одной подсистемы по имени: список единиц, формы полей, индикатор, серверы, домен, вход. Всё, что про видео (плеер, таймлайн, WHEP, формы записи/детекторов/сценариев), уходит в страницу продукта (`Page`, это контент) или в панели, которые страница продукта монтирует под `/rec/…`, `/det/…`. Платформенная часть UI уезжает из `vms/console.html` обратно в платформу. `domain/page.html` получает тот же режим `Page`.

Тесты платформы идут на фиктивной подсистеме `testsub.subsystem.yaml`.

### 2.5 Поведение платформы определено через запись

| Где | Что |
|---|---|
| курс урок 17, `drain_state` | `safe = units == 0` верно только потому, что футаж VMS в ObjectStorage; подсистема с буфером на диске получит ложное `safe` |
| курс `contract.py:2101`, урок 7 L364 | корень ресурса называется `ARCHIVE`/`archive_root`, lock-файл воркера лежит «в архиве» |
| курс `contract.py:2452`, `epoch.py:85-172`; продукт `contract.go:1921` | `may_record`/`MayRecord` на платформенной аренде |
| курс/продукт консоль `_servers()` | читает `hb.extra["archive"]` рекордера (`console.py:1463-1499`, `console.go:795, 929`) |

**Исправление.** `safe` считается по платформенному полю heartbeat `pending_writes: 0` (воркер обязан его отдавать; спека может переименовать источник). `archive_root` → `resource_root`, `may_record` → `may_write`. `archive` в `/servers` становится `servers.show` из спеки. `media` исчезает вместе с байтовыми маршрутами (§4).

### 2.6 Лекции обосновывают платформу видео

Уроки 1 и 14: ресурс определён как «архив… сколько дней хранить». Урок 6: эпоха вводится через `rec/7/e3/…mp4` и «потерянная минута необратима». **Исправление.** Платформенный урок мотивирует механизм платформенной задачей (любой писатель с двумя экземплярами, любой шард с состоянием снаружи), а VMS приводит как пример «а в М10B это…». Таблица читателей урока 8 правится по коду. Обещания уроков 1, 13, 16 станут верными после §2.1 и §2.2.

### 2.7 Тест чистоты не охраняет границу

Курс `tests/test_lesson1_platform.py:78` и продукт `lesson1_platform_test.go:156-178` ищут только импорт и английское слово `camera` вне комментариев, только в верхнем уровне `w2cplatform/`, пропуская `domain/`, `trust/`, `configstore/`, HTML, тесты и русский текст.

**Исправление.** Тест границы: (1) импорт-граф: ни один пакет платформы, включая `cmd/resource`, `cmd/configstore`, `cmd/w2cctl`, `cmd/domain`, и ни один тест платформы не импортирует подсистему; (2) словарь запрещённых слов во всём дереве платформы, включая HTML, тесты и строки логов: `vms`, `cam`, `camera`, `камер`, `rec`, `det`, `auto`, `live`, `archive`, `footage`, `video`, `rtsp`, `device`, `recorder`, `volume`, `whep`, `timeline`; (3) бинарь платформы собирается с единственной спекой `testsub.subsystem.yaml` и проходит свои тесты.

## 6. Решения владельца (утверждены 2026-10-04)

Принцип §1.1 «три места вместо хука» утверждён. По вопросам ниже владелец принял предложения.

1. **Байты мимо консоли.** Страница сама ходит на дверь рекордера и шлюза (адрес из `/where`, тот же токен). Консоль платформы становится чисто спековой. Цена: дверь воркера принимает браузер (токен, CORS), слияние таймлайнов двух рекордеров делает страница. Предложение: да.
2. **Уникальность источника.** Платформа канонизирует URL по RFC 3986 и не знает, что `ch/02` и `ch/2` один канал. Предложение: строгое правило «одно написание», дубликат по устройству ловит воркер и пишет в heartbeat «устройство занято».
3. **Сценарии.** Исполнимость проверяется JSON Schema из YAML; остальное делает `autoworker` и отказ приходит через heartbeat. Предложение: да.
4. **Хранение событий.** `<sub>/retention`, `alarms_retention`, `ALARM_DAYS` считать политикой платформы на её собственные бакеты и оставить, убрав слово «архив». Предложение: да.
5. **Обратная совместимость не нужна** (добавлено владельцем 2026-10-04). Система работает только на этой машине: при переделке старые ключи, пути, имена переменных окружения, форматы строк и объектов, старые версии модуля не сохраняются; миграций, алиасов и двойного чтения нет. Когда это изменится, владелец скажет отдельно.
