## Блокеры

**И-1 (блокер).** Окно 3600 с выбрасывает пару, действовавшую в момент события.
- ADR:93–95: «курсор хранит смены `valid_for` — пары `(since, valid_for)`…; хранятся пары за последние 3600 с (`valid_for` ≤ 3600, старшие не влияют ни на одно исполнимое событие)».
- ADR:92: «наименьший из объявленных за время от события до сейчас».
- Значение в момент события задаёт последняя пара с `since` ≤ события, и её `since` может быть старше окна.
- Контрпример (секунды, T — сейчас):
  - Курсор: `(T−5000, 60)`. В T−200 событие E; единица исполняет его в T−190 при `valid_for` 60: `keep` = `at` + 180, `not_before` = `at` + 120.
  - В T−100 единица стартует под манифестом с `valid_for` 600 и пишет пару `(T−100, 600)`. Пара `(T−5000, 60)` старше 3600 с и отброшена.
  - Строка удалена при часах > `at` + 180 (около T−20), время приёма удаления > `at` + 120.
  - В T повтор E после переезда. В курсоре только `(T−100, 600)`. Минимум «от события до сейчас» по хранимым парам — 600; возраст 200 ≤ 600 — исполняется, `not_after` = `at` + 660 > `not_before` — принята, CAS `""` проходит. Удалённая жизнь вернулась.
- Последствие: ADR:97–98 «ни подъём, ни цепочка подъёмов её не возвращают» ложно при первом же подъёме после долгой стабильности. Двойное исполнение заказа.
- Предложение: «хранятся пары за последние 3600 с **и последняя пара до этого окна**»; без пар — объявленное значение манифеста, под которым единица стартовала, а не текущее.

**И-2 (блокер).** `keep` при продлении может уменьшиться: две единицы заказчика с разными курсорами пишут одну строку.
- ADR:78: «`keep` = `at` + `valid_for` + 120», `at` — «при продлении — наибольшее».
- ADR:96: «`keep` считается по действующему значению».
- ADR:80–81: «строку своего `made` продлевать вправе любая единица заказчика (два сценария продлевают одну запись)».
- Действующее значение — по курсору единицы (ADR:93), а у двух единиц курсоры и старты разные.
- Контрпример (`valid_for` объявлен 60 до T0 и 600 после):
  - Единица A стартовала под новым манифестом в T0. Её событие E2 (`at2` = T0+10) исполнено в T0+15 при действующем 600: `made.at` = `at2`, `keep` = `at2` + 720.
  - Единица B ещё не перезапущена: её курсор — только 60. В T0+20 B исполняет своё событие E1 (`at1` = T0−30, возраст 50 ≤ 60) и продлевает ту же запись (`until` больше). Запись: `made.at` = max = `at2`, `keep` по действующему значению пишущей B = `at2` + 60 + 120 = `at2` + 180.
  - Удаление после `at2` + 180, `not_before` = `at2` + 120.
  - В `at2` + 300 повтор E2 у A (после её переезда): действующее по курсору A — 600, возраст 300 — исполняется, `not_after` = `at2` + 660 > `not_before` — принята после удаления. Жизнь вернулась.
  - Тот же исход без двух единиц, если реализация берёт `valid_for` текущего пишущего события, а не события `made.at`. Текст не говорит, чьё значение.
- Последствие: защита повтора держит одну единицу, но не строку, которую разрешено продлевать нескольким.
- Предложение: **`keep` не убывает**: при продлении `keep` = max(прежний `keep`, `at` нового события + его действующий `valid_for` + 120). `not_before` = `keep` − 60 тогда не меньше `not_after` любого исполненного события любой единицы. При создании — как сейчас.

## Мелкие

1. **Пара смены — прочно до первой записи под ней.** Курсор пишется «не чаще `STATE_EVERY`» (ADR:153). Если пара снижения (`(S, 60)` после 600) не записана до первой записи под 60, а держатель упал, следующий старт под манифестом с 600 (откат) пары не увидит. Повтор события, исполненного под 60, пойдёт по 600 — исход И-1. Писать пару в курсор подтверждённо до первой записи `worker.creates` под новым значением — исключение из `STATE_EVERY`.
2. **«Лидер принимает в журнал, только пока…» осталось.** ADR:61–63 и :74–75 по-прежнему говорят о приёме: «лидер хранилища принимает запись в журнал, только пока время приёма не позже `not_after`», «лидер принимает запись, только если… строго позже `not_before`». ADR:65–67 переносит проверки в применение. Если лидер ещё и отказывает при приёме, возвращается окно мелкого 2 ред. 9. Переписать: «запись **применяется**, только если её время приёма…; лидер отказ при приёме не выдаёт».

Прежние отложенные мелкие (Г-7, Г-8, Г-9, С-4, С-5, мелкие 2, 3 разбора восьмой редакции) — при Т-правке, не повторяю.
