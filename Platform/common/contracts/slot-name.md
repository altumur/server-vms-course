# Договор имени слота: грамматика, «по имени», слотовый порядок, следующий номер, процесс роли

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13), доп. (30); догадка стадии C POOL-ORDER-51-01, решение
«Архитектора» 2026-10-25). Владелец — глава [P/03.2](../../03-worker/spec/03.2-worker.norms.md) Н1.4 (слот и его имя). Участники —
захват слота (P/03.2 Н3), контроллер ([P/04](../../04-controller/spec/04-controller.norms.md): хранитель места, «номер выше
want», жертва сокращения), [договор пула](pool.md), скрипт воркеров ([P/02.4](../../02-installer/spec/02.4-installer.norms.md) Н1.5),
консоль. Перенесено из P/03.2 Н1.4 («Порядок имён и следующий номер») без изменения поведения; имя процесса роли и номер
N — ответы «Архитектора» 2026-10-25 (P/04 о форме молчал).

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Форма

Имена слотов — ключи `<sub>/slots/<имя>` (занятые и отданные — по строкам слота); сервер процесса роли — поле `server`
пульса `<sub>/heartbeats/<имя>`. Формы и исходы: `Platform/03-worker/data/slots.form.yaml`,
`Platform/03-worker/data/slots.outcomes.tsv`, `Platform/03-worker/data/heartbeats.form.yaml`,
`Platform/03-worker/data/heartbeats.outcomes.tsv` (аудит раскладки, В-58; решение «Архитектора» 2026-10-25).

## Грамматика и «по имени»

```yaml
name:      <prefix>-<суффикс>; prefix — slot.prefix манифеста (1–8 строчных латинских, умолчание w); суффикс
           ^[a-z0-9]+(-[a-z0-9]+)*$; имя проверяется по грамматике и prefix своего манифеста
by_name:   лексикографическое сравнение полного имени по байтам ASCII; собственный префикс строки раньше её продолжения
           (w-a < w-a-b < w-ab); локаль и порядок обхода хранилища не влияют
```

## Слотовый порядок

Для выбора свободного слота и хранителя места:

1. Сначала имена, у которых весь суффикс после `<prefix>-` — цифры 0–9: по числовому значению суффикса (неотрицательное
   десятичное целое без машинного переполнения; длина суффикса не ограничена), при равенстве — по имени. `w-01` и `w-1` —
   разные имена с равным номером.
2. Затем остальные допустимые имена — по имени. Последние цифры `w-srv-a-2` не выделяются в номер: это имя второй группы.

Пример: `w-0`, `w-01`, `w-1`, `w-2`, `w-10`, `w-a`, `w-b`, `w-srv-a-1`.

## Следующий номер

Новое имя — `<prefix>-<max + 1>`: max — наибольший номер среди цифровых суффиксов этой подсистемы и prefix, включая занятые
и отданные имена; нет таких — max = 0; новый суффикс без ведущих нулей; прочие имена в max не участвуют; без переполнения.

## Имя процесса роли и его номер

```yaml
role_name: <prefix>-<s>-<N> — имя экземпляра от юнита (P/02.4 Н1.1, %i), s — SERVER_NAME (договор файла окружения «Переменные окружения»; может содержать «-»)
parse:     prefix — свой манифеста; N — последний сегмент после «-»: десятичное целое без ведущих нулей, ≥ 1, без
           переполнения; s — всё между «<prefix>-» и «-N», по грамматике SERVER_NAME ^[a-z0-9]+(-[a-z0-9]+)*$ (договор файла окружения «Переменные окружения»; аудит раскладки Б-24)
server:    s равно полю server пульса воркера — процесс роли сервера s с номером N; s ≠ server, пульса нет или server в нём не
           читается — не процесс роли (ни этого, ни какого сервера): «номер выше want» к нему не применяется, в живые(s) не
           входит
not_role:  не по форме — не процесс роли: w-5 (нет сервера в имени), w-srv-a-02 (ведущий ноль), w-srv-a-0 (N < 1), чужой
           prefix, последний сегмент не число
use:       номер выше want (P/04 Н3) и жертва сокращения сравнивают N целым, не слотовым порядком; 1 — базовый процесс роли,
           2…99 — заказанные контроллером (P/04 Н3 «заказать()», ADR-0084)
```

## Векторы

Пакет [`slot-name`](../vectors/slot-name/README.md): слотовый порядок (пример P/03.2, суффикс длиннее 64 бит, «по имени»),
следующий номер, номер процесса роли и «не процесс роли» (сервер с «-», s ≠ server, нет пульса, не по форме). Участник:
пакет [`pool`](../vectors/pool/README.md) — пакет общего договора pool, исполняет common; этот договор там — участник
(порядок пула, хранитель, «номер выше want»; В-59; CM-RECORD-VECTORS-128, решение «Архитектора» 2026-10-25).
