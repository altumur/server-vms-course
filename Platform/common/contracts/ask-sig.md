# Договор подписи просьбы: заголовки `X-W2C-Member`, `X-W2C-Time`, `X-W2C-Signature`, функция `ask-sig`, слова отказа

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (11) и доп. (13): общий алгоритм нескольких процессов — договор, а
не копии в главах; разбор ревью стадии A 8–10, № 13 / решение 2). Владелец — урок P/08, глава [8.8](../../08-domain/spec/08.8-domain.norms.md) (перенесено из
М11/10 Н3 «ask-sig»): подпись просьб без члена в пути.

| Просьба | Подписывает | Проверяет |
|---|---|---|
| `backup` — `GET /api/backup` (P/06.7 Н1.13) | процесс `domain` кластера-цели при аварийном переносе ключом члена `domain/member-key` (P/08.8 Н1.8 `order` шаг 5) | консоль кластера, которая держит резервную копию ([P/06.7](../../06-console/spec/06.7-console.norms.md) Н1.13) |
| `prepare` — `POST /api/prepare` (P/08.8 Н1.7 шаг 4) | процесс `domain` держателя ключом токенов `current` набора (8.8) | процесс `domain` цели (8.8); консоль цели передаёт просьбу без проверки (P/06.7 Н1.8) |

Перенесено из М11/10 Н3 «ask-sig — подпись просьбы» (блок `message`, `time`, `signature`, `check`) и Н4 (слова `ask-sig`)
без изменения поведения. Что дверь отвечает на отказ (401 у `/api/backup` с `detail` — слово; 400 и 403 у `/api/prepare`),
кто член и чей ключ — нормы дверей (P/08.8 Н1.7, Н2; P/06.7 Н1.13). Подпись агента `X-Agent-Signature` — другой договор
([договор подписи агента](agent-signature.md)). Ссылки в перенесённом тексте — урока М11/10 (Н1.7, Н1.8 — те же номера главы P/08.8; Н1.9 — P/06.7 Н1.13).

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Подпись и проверка

Из М11/10 Н3 «ask-sig — подпись просьбы»:

```
message:  backup|<кластер>|<член>|<время>   (просьба резервной копии; ключ члена)
          prepare|<цель>|<время>            (подготовка передачи; ключ токенов current набора)
time:     X-W2C-Time — десятичная запись стенных секунд с тремя знаками после точки: (0|[1-9][0-9]*)\.[0-9]{3}
signature: X-W2C-Signature — base64url без «=» подписи Ed25519 над UTF-8(message)
check:    по порядку: заголовка нет или он пуст — missing (prepare — X-W2C-Time, X-W2C-Signature; backup — ещё
          X-W2C-Member; пустой — добавлено сверкой М11, H13);
          время не по форме — bad_time; |now − время| > 300 — skew; подпись не base64url без «=», не 64 байта или не
          сходится — bad_signature; иначе ok
```

`<член>` просьбы `backup` — значение `X-W2C-Member`; `<кластер>` — кластер, у консоли которого просят копию; `<цель>`
просьбы `prepare` — член, которому передают домен (P/08.8 Н1.7 `to`); `<время>` — значение `X-W2C-Time` как пришло.
Форма функции — вход команды `ask-sig` [P/08.8](../../08-domain/spec/08.8-domain.norms.md) Н5:
`{ask: backup | prepare, cluster, pub, header: {member?, time?, signature?}, now}` → `{result: ok}` |
`{result: refused, reason}`. Поля входа (прочтение М11/10 Н5 и README приёмки М11/10 «Входы»; разбор ревью стадии B
8–10, № 4, Claude С-7):

```yaml
cluster:   <кластер> сообщения backup и <цель> сообщения prepare — кластер проверяющего: консоль, у которой просят копию,
           или цель передачи; подпись над другим именем — bad_signature (строка пакета ask-sig-08)
pub:       открытый ключ подписавшего, которому верит проверяющий: ключ члена (backup) или ключ токенов current набора (prepare)
header:    заголовки X-W2C-Member, X-W2C-Time, X-W2C-Signature без префикса (member, time, signature) как пришли;
           <член> сообщения backup — header.member
member:    поля member на верхнем уровне входа нет: член сообщения — только header.member; вход с полем member —
           лишнее поле, вход не по форме, код 2 (P/08.8 Н5 exit; решение «Архитектора» 2026-10-20 по открытым вопросам разбора ревью стадии B 8–10, вопрос 2; прежде поле допускалось и не читалось)
now:       стенные секунды проверяющего
```

## Слова отказа

Из М11/10 Н4: слова `ask-sig`: `missing`, `bad_time`, `skew`, `bad_signature`.

## Векторы

Пакет [`ask-sig`](../vectors/ask-sig/README.md) (разбор ревью стадии A 8–10, № 13): 13 строк — 12 входов команды `ask-sig`
приёмки М11/10 (сц. 07) без изменения байтов; одна из них — вход не по форме (`@exit 2`; разбор ревью стадии B 8–10, № 22); строка 13 — поле `member` на верхнем уровне, `@exit 2` (вопрос 2 того же разбора). Сценарий и входы сняты
переносом урока 8 — таблица единственный источник этих случаев.
