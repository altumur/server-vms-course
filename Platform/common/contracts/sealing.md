# Договор запечатывания: кольцо, конверт `enc:v2`, AAD

Общий договор модуля «Платформа» (ADR-0083 доп. (5): контракт, который читают несколько процессов, лежит в
`Platform/common/`; решение «Архитектора» по ревью стадии B 1–2, п. 4). Читают: установщик — команды `w2cctl secrets`
([P/02.4 Н1.9](../../02-installer/spec/02.4-installer.norms.md)), воркер — открытие (глава P/03.5), консоль —
запечатывание и перезапечатывание ([глава P/06.2](../../06-console/spec/06.2-console.norms.md)),
процессы домена (М11). Перенесено из М10/7 Н1.2 без изменения поведения: что запечатывать, кто держит ключ, ротация, режим
без ключа и отпечаток идемпотентности остаются в нормах читающих уроков. Векторы — [`../vectors/sealing/`](../vectors/sealing/README.md).

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Конверт

```yaml
envelope:  enc:v2:<kid>:<nonce>:<ct>
  kid:     непустая строка без `:` и без пробельных, не начинается с `#`; пробельные — ровно U+0020, U+0009, U+000D,
           U+000A (не `\s` библиотеки; NBSP U+00A0 и прочие пробелы Unicode — обычные знаки kid); new → k1; rotate → k<max+1>
           (разбор ревью стадии A 6–7, Б7)
  nonce:   12 случайных байт, base64url без =
  ct:      AES-256-GCM(key, nonce, plaintext, aad) с тегом (16 байт), base64url без =
  aad:     UTF-8(<ключ строки>) + байт 0x00 + UTF-8(<полный JSON Pointer к секрету от корня строки>)
  plain:   байты UTF-8 значения как дано, без нормализации; пустое и уже запечатанное не запечатываются
  looks:   всё, что начинается с enc: — считается конвертом (на входе — отказ)
  strict:  при открытии конверт не по грамматике — не enc:v2, не пять частей через `:`, kid не по грамматике, nonce не
           12 байт или ct не base64url без `=` (в том числе с `=`), ct короче тега — Sealed без криптографической
           операции; умолчания, ослабляющего отсечение, нет (решение «Архитектора», разбор ревью стадии A 6–7, Б6)
```

## Путь AAD

Путь AAD однозначен: каждый ключ/индекс — отдельный сегмент JSON Pointer, `~` заменяется на `~0`, `/` — на `~1`, сегменты разделяются `/` с начальным `/`; индекс массива — десятичный без ведущих нулей. Пример верхнего поля: `/password_secret`; вложенного — `/settings/a~1b/0/password_secret`. Используется весь путь, не только имя последнего ключа; никакой нормализации или склейки через `#`. В профиле запечатывания ключ строки не содержит NUL: с NUL seal/open отвергаются до криптографической операции. Это дополнительное условие договора, а не общий запрет P/01.1. Поэтому первый 0x00 однозначно отделяет его от пути, даже если JSON-ключ внутри пути содержит NUL.

Это исправляет байты AAD прежнего профиля, форма конверта `enc:v2` сохранена. Подбор прежних способов AAD при открытии запрещён: конверт, не открывающийся с этим единственным контекстом, даёт Sealed. Миграция уже запечатанных старым способом строк вне договора; внедрение требует согласованного перехода держателей кольца и повторного запечатывания из доверенного исходника.

## Файл кольца

```yaml
ring_file:                                   # SECRETS_KEY=<путь>; умолчание — раскладка установщика: юниту задаётся
                                             # <PLATFORM_DIR>/etc/secrets/platform.key (P/02.4 Н1.1); не задан у процесса —
                                             # режим разработки (P/06.2 Н1.2 unset; разбор ревью стадии A 6–7, № 19)
  line:    <kid> <64 hex>                    # 32 байта ключа; первая запись ключа — текущая; пустые строки и отдельные строки комментариев пропускаются;
                                             # BOM U+FEFF в начале файла пропускается и в kid не входит (сверка python и go М10/6–11, совпало)
  mode:    0640 root:w2c-secrets; каталог не доступен прочим; файл НЕ внутри каталога хранилища, объектов или их копий
```

Пробельные знаки файла — ровно пробел U+0020 и табуляция U+0009; строки разделяются LF, CR перед LF — часть конца
строки (CRLF допустим); NBSP U+00A0 и прочие пробелы Unicode — обычные знаки kid; hex-цифры — `0-9`, `a-f`, `A-F`
(разбор ревью стадии A 6–7, Б7). Строка, первый непробельный знак которой `#`, целиком является комментарием. kid не начинается
с `#`; `#` внутри kid допустим. Запись содержит ровно два поля, разделённых пробелом
или табуляцией; второе — ровно 64 hex-цифры. Встроенные комментарии после записи ключа
не допускаются. Пробелы/табуляции по краям строки игнорируются.
Кольцо содержит хотя бы один ключ, все `kid` различны; пустой или неверный файл считается
нечитаемым, а не незаданным. `new` и `rotate` создают имена `kN`, где N — положительное
десятичное целое без ведущих нулей. Для `rotate` допускается только кольцо с такими именами:
другое имя — отказ команды без изменения файла. Чтение конверта и `seal` сохраняют общую
грамматику `kid` выше. `max+1` вычисляется по числам N, без машинного переполнения; если
реализация не может представить результат, команда отказывает до изменения файла.
