# Договор журнала событий: строка, id, бакет, имена файлов, писатели

Общий договор модуля «Платформа» (ADR-0083 доп. (5): контракт, который читают и пишут несколько процессов, лежит в
`Platform/common/`; разбор ревью стадии A 3–5, № 9). Владелец — ресурс [P/05](../../05-resource/spec/05-resource.norms.md):
он читает бакеты (индекс P/05 Н1.3), копирует закрытые (P/05 Н1.4 `mirror`), убирает по сроку и тянет назад
(P/05 Н3 «проход ресурса», Н1.4 «Восстановление бакетов»); порядок записи строки — P/05 Н3 «записать событие». Дописывают строки
(`append`): воркер — события подсистемы по `observe` (глава [P/03.6](../../03-worker/spec/03.6-worker.norms.md)),
консоль — журнал и отметки оператора (глава P/06.4; до переноса — [М10/8](../../../М10_Platform/spec/08-events-resource-requests.norms.md)),
каждый процесс платформы — журнал `audit` своей роли; кодирование имён файлов исполняет каждый процесс, кладущий файл в
корень событий или объектов. Перенесено из М10/8 Н1.1 (абзац «Имена файлов в общих деревьях») и Н1.2 (блоки `line`,
`bucket`, `class`, `journal`, `writer`, абзац об id) без изменения поведения: подавление повторов (`suppress`) — глава
P/03.6 Н1.2; `older_epochs` и отметки оператора (`marks`) — М10/8 Н1.2 (урок 6). Векторов нет — норма формы.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Строка и бакет

```yaml
line:                                        # одна строка JSON в файле бакета
  t:        <секунды стенных часов писателя, когда записали>      # ДОЛЖЕН; выбирает бакет
  kind:     <вид>                                                  # ДОЛЖЕН
  id:       e1-<hexUTF8(дерево)>-<hexUTF8(единица)>-<эпоха>-<hexUTF8(экземпляр)>-<номер>                   # ДОЛЖЕН; уникален; по нему убирают дубли копий
  of:       <sub>/<id>                                             # единица, про которую; ставит платформа из about;
                                                                   # своё of — только деревья console и audit
  class:    alarm                                                  # только у тревоги; observation не пишется
  occurred: <секунды>                                              # когда произошло; необязателен; число
  <поля>:   слова подсистемы                                       # v не пишется: отсутствие = версия 1
bucket:
  path:     <root>/<sub>/<unit>/e<epoch>/<YYYYMMDDTHHMMSSZ>.events.jsonl       # root: RESOURCE_ROOT | <PLATFORM_DIR>/events
  alarms:   <root>/<дерево>.alarms/<unit>/e<epoch>/…                              # своё дерево у каждого дерева
  span:     600 с; начало = floor(t / 600) × 600 по UTC; закрыт, когда end ≤ now; катится только по часам
  durable:  тревога и журнал — fsync строки и каталогов до корня; наблюдение — нет
  torn:     порванная последняя строка пропускается и считается
class:      [alarm, observation]             # закрыто; класс строки — её поле class: alarm — тревога, поля нет —
                                             # observation; индекс берёт класс из поля, дерево его не переопределяет;
                                             # раскладка .alarms — у писателя: тревогу он кладёт в <дерево>.alarms любого
                                             # дерева, в том числе audit.alarms и console.alarms (срок alarms_retention)
                                             # (решение «Архитектора», второй пилот, Н-2; меняет выбор сверки М10/6–11 E18)
```

## Журнал и писатели файла

```yaml
journal:    дерево audit/<роль>/e1/…: строки платформы о себе (unit.created|changed|deleted, door.issued, schema.raised,
            events.removed, policy.changed, drain.*, server.*, worker.name_taken (alarm), worker.name_back (observation; глава P/03.2 Н3 «воссоединиться»), worker.hung, clock.skew, free_ask.key_taken, …);
            поля: о чём строка — sub и target (единица; не subsystem/unit), адрес клиента у строк о двери — addr;
            второго имени у этих полей нет (ADR-0069)
writer:     консоль — отдельный процесс; журнал и отметки она пишет в корень событий своего сервера (тот же, что
            у ресурса этого сервера), ресурс индексирует их как свои бакеты; у файла один писатель, кроме журнала:
            в audit/<роль>/e1 пишут все процессы этой роли на сервере (путь экземпляра не несёт, единица журнала — роль);
            строка дописывается целиком под исключительной блокировкой файла, строки разных процессов не перемешиваются,
            их различает id (экземпляр в нём); бакет — тот же по t у всех писателей (журнал cammeta-go, урок 8 № 5)
```

## Id события и экземпляр писателя

`hexUTF8` — строчные hex-пары байтов UTF-8 без префикса, разделителей и нормализации.
Дерево и единица — непустые компоненты пути бакета (для журнала audit/роль, для отметок
console/экземпляр). Эпоха — каноническое десятичное целое ≥0, номер — ≥1, без ведущих нулей.
Номер атомарно выделяется общим счётчиком экземпляра на каждую новую публикуемую строку,
включая итог подавления; не переиспользуется при смене единицы, дерева, эпохи или бакета.
Итог подавления получает новый id, а не id первой строки окна. Зеркало/повторная выдача
сохраняют id исходной строки. При исчерпании счётчика новые строки не публикуются до нового
уникального экземпляра; оборачивание счётчика запрещено.
Экземпляр писателя — непустая строка, уникальная с учётом коробок и перезапусков (`INSTANCE_ID`, `BOX_ID` — [P/02.4 Н1.2](../../02-installer/spec/02.4-installer.norms.md)); локального PID
недостаточно, повтор прежнего INSTANCE_ID новым процессом вне профиля. Экземпляр — один
компонент пути: не `.`/`..`, без `/`, `\`, `|`, `"`, запятой, Cc/Zl/Zp. Это условие
профиля действует и на INSTANCE_ID из окружения, и на вычисленное значение; проверяется
до старта/первой публикации вместе с файловой представимостью («Имена файлов в общих деревьях» ниже). Нарушение — отказ
старта с диагностикой имени экземпляра, без усечения/нормализации. Hex-компоненты
не содержат разделитель `-`, поэтому разные допустимые кортежи не склеиваются в один id.
Поля платформы
в строке/ответе не перезаписываются произвольными полями подсистемы. Числа JSON конечны.
`of` платформенной строки без единицы-адресата — пустая строка; у строки подсистемы
адресат определяется спекой.

## Имена файлов в общих деревьях

**Имена файлов в общих деревьях** — одно кодирование для всех реализаций: объекты и деревья событий (P/05 Н1.1, Н1.2,
Н1.4) пишут процессы разных реализаций на одной коробке (решение «Архитектора», второй пилот, Н-3; исполняет сверку python и go
М10/3–5 п. 14 и U20). Любой логический ключ, который разрешают грамматика [P/01.1](../../01-store/spec/01.1-store.norms.md), грамматики id и слота М10/3 ([P/03.2](../../03-worker/spec/03.2-worker.norms.md) Н1.4 — слот) и предел
полного ключа, представим на диске. Раскладка каталогов — по логическому ключу, компонент за компонентом (между `/`):

- байт компонента из `[a-z0-9._-]` пишется как есть, любой другой байт UTF-8 — `%` и две строчные hex-цифры (`A` —
  `%41`, `:` — `%3a`, `%` — `%25`, `я` — `%d1%8f`); компонент `.` — `%2e`, `..` — `%2e%2e`;
- закодированный компонент длиннее 255 байт — имя `%h<sha256 hex байтов исходного компонента>`, рядом файл
  `%h<sha256>.name` с исходным компонентом (байты UTF-8, без перевода строки);
- раскодирование — обратное; усечение и нормализация ключа запрещены, разные ключи — разные пути, файлового профиля уже
  грамматики нет;
- кодируются компоненты, взятые из имён и ключей: `<sub>`, дерево, `<unit>`, роль, экземпляр, `<server>`, сегменты ключа
  объекта; компоненты, форму которых задаёт сама норма, пишутся как есть — имя бакета `<YYYYMMDDTHHMMSSZ>.events.jsonl`,
  `e<эпоха>`, суффикс `.alarms`, каталоги `.workers`, `.mirror`, `.gone`, окончания `.lock`, `.name` (`T` и `Z` имени
  бакета — не `%54`, `%5a`); составной компонент — закодированное имя плюс суффикс нормы: `testsub.alarms`,
  `<экземпляр>.lock` (журнал cammeta-go, урок 8 № 10; решение «Архитектора»). Шаг — сц. 08 шаги 12–16 [приёмки P/05](../../05-resource/acceptance/README.md): бакет, который
  раннер пишет мимо писателя под именем нормы, ресурс читает.

## Соответствие прежним урокам

деревьях». Части норм М10/8-01 (кодирование имён; P/05-01), М10/8-03 (поля строки; P/05-03) и М10/8-04 (бакет, `fsync`,
порванная строка; P/05-04) — по `note` [id-map](../id-map.tsv). Подавление (`suppress` и его абзац) — глава P/03.6 Н1.2;
`older_epochs`, `marks` — М10/8 Н1.2.
