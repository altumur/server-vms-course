# Договор имени человека: форма имени и пробельные знаки

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): форму имени человека проверяют процесс `domain`, сторожевые
консолей, получатель токена, функция `may`, а множество пробельных знаков читают ещё маска журнала и маска секрета — договор,
а не копии в главах; аудит раскладки А-20, решение «Архитектора» 2026-10-25). Владелец — глава
[P/08.4](../../08-domain/spec/08.4-domain.norms.md) Н1.1 (`name` строки человека). Участники: процесс `domain` (P/08.4 Н1.1–Н1.2:
правка людей, вход), проверяющий токен человека — сторожевые консоли кластера и консоли домена ([договор токена
домена](domain-token.md) `person`), функция права ([договор права](may.md), `subject`), маска журнала ([договор маски
журнала](log-mask.md) `space`, `mask_in`).

Перенесено из P/08.4 Н1.1 `name` без изменения поведения; у P/08.4 и у договоров-участников — ссылки сюда.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Форма

Строка человека `domain/users/<имя>` — семья `users`: форма `Platform/08-domain/data/users.form.yaml`, исходы
`Platform/08-domain/data/users.outcomes.tsv` ([форма](../../08-domain/data/users.form.yaml),
[исходы](../../08-domain/data/users.outcomes.tsv)).

## Пробельные

```yaml
white_space:   пробельные знаки — свойство White_Space Unicode 15.0.0: U+0009–U+000D, U+0020, U+0085, U+00A0, U+1680,
               U+2000–U+200A, U+2028, U+2029, U+202F, U+205F, U+3000 (решение «Архитектора» 2026-10-20 по вопросам сборки
               урока 8, п. 3); одно множество модуля: имя человека, маска журнала (`space`), маска секрета (`mask_in`)
```

## Имя

```yaml
name:          имя человека — 1–64 символа без пробельных (white_space выше), управляющих (U+0000–U+001F, U+007F) и
               : | ( ) " /; не ровно break-glass (имя аварийной сессии — break-glass(<who>), скобки и так запрещены);
               не субъект индекса имён (глава P/08.5 Н1.7)
refusal:       что делает читатель с именем не по форме — у читателя: процесс domain — 400 bad name (P/08.4 Н1.1);
               сторожевая — 401 (договор токена домена person); функция may — вход не по форме, код 2 (договор права)
```

## Векторы

Своего пакета нет; участник — пакет [`may`](../vectors/may/README.md) — пакет урока-владельца P/08.4, исполняет он; договор имени
человека там — потребитель (`subject` по этой форме; CM-RECORD-VECTORS-128, решение «Архитектора» 2026-10-25), и приёмка
[главы 8.4](../../08-domain/acceptance/4/README.md) (сц. 01, граница пробельных U+0085 и U+FEFF).

## Соответствие прежним урокам

Из P/08.4 Н1.1 `name` (норма P/08.4 — по `note` [id-map](../id-map.tsv)); у P/08.4, договора токена домена `person`, договора
права `subject`, договора маски журнала `space` и `mask_in` — ссылки сюда (аудит раскладки А-20).
