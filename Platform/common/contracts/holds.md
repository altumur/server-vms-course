# Договор удержаний: раздел `holds` манифеста, строки удержаний, что они держат

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): общий алгоритм нескольких процессов — договор, а не копии в
главах; догадка стадии C R05-G06, решение «Архитектора» 2026-10-23). Владелец — урок P/06, [глава 6.4](../../06-console/spec/06.4-console.norms.md)
Н1.5 `holds`. Строки таблицы удержаний пишет дверь таблиц консоли ([P/06.1](../../06-console/spec/06.1-console.norms.md) Н1.6); удержания
читает ресурс в проходе срока ([P/05](../../05-resource/spec/05-resource.norms.md) Н3 «проход ресурса» `retain`; права —
[P/02.5](../../02-installer/spec/02.5-installer.norms.md) Н1.4, строка `resource`: «таблица `holds`, строки манифестов с
`about`»). Форма раздела в манифесте и проверки ссылок загрузчиком — [P/02.1](../../02-installer/spec/02.1-installer.norms.md)
Н1.2 `holds`, ссылки 50–54. Решения: [ADR-0057](../../../decisions/0057-консоль-из-каталога-спек-хуки-консоли-уходят.md)
(дополнение 2026-10-10 — `released`), [ADR-0091](../../../decisions/0091-механизмы-платформы-по-запросам-vms.md) п. 8 (удержание «про»).

Перенесено из P/06.4 Н1.5 `holds` и `about` без изменения поведения; добавлены правила чтения окна и адресата при неполном
объявлении и нечитаемых строках — в них действует правило «неизвестное чтение не равно отсутствию» (P/05 Н1.3 `retention`
`rule`): что не прочитано достоверно, держится.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Форма

Причины прохода срока и счёт нечитаемых строк удержаний (`garbled_rows.<table>`, `retention_withheld`) ресурс пишет в свой
пульс — семья `resource-heartbeat`: `Platform/05-resource/data/resource-heartbeat.form.yaml`,
`Platform/05-resource/data/resource-heartbeat.outcomes.tsv` (аудит раскладки, В-30; решение «Архитектора» 2026-10-25).

## Объявление

```yaml
holds:      раздел манифеста <M>: {table, unit, since, until, longest?, released?} — имена: table — таблица манифеста
            (tables.<table>), unit, since, until, released — поля этой таблицы; longest — секунды, число > 0
  complete: объявление полное, когда названы table, unit, since и until; longest и released необязательны
            (ADR-0057: longest?, released?); загрузчик принимает раздел и без них (P/02.1 Н1.2: все ключи необязательны)
  partial:  объявление неполное — удержания манифеста не читаются: ресурс не убирает по сроку ничего в деревьях адресата
            (ниже); манифест без раздела holds удержаний не имеет
addressee:  A — подсистема адресата: about.sub манифеста <M>, если <M> объявляет about, иначе сам <M>
            (ADR-0091 п. 8); деревья адресата — <A>, <A>.alarms и <X>, <X>.alarms каждого манифеста X каталога, чей
            about.sub = A (в том числе сам <M>)
```

## Строка удержания

Строка — `<M>/<table>/<id>`; элементы — тексты по `values_by_type` ([договор проверки строки](row-check.md) «Строка
единицы»; векторы [`values-by-type`](../vectors/values-by-type/README.md); Б-23).

```yaml
released:   объявлен released и элемент этого поля в строке есть и непуст (текст длиннее нуля) — строка ничего не держит,
            какими бы ни были прочие поля (ADR-0057, дополнение 2026-10-10); тип поля не важен: число, записанное 0, —
            непустой текст
unit:       элемент поля unit — id единицы подсистемы A как есть, байт в байт; элемента нет или он пуст — адресат не
            прочитан
since, until: элементы полей since и until, прочитанные своим типом, — конечные числа, стенные секунды (кодек `Platform/common/data/codec.tsv`, строка `time`; Б-27);
            запись читается и читателем `time`: ^(0|[1-9][0-9]*)(\.[0-9]+)?$, значение конечно — «-1», «+5», «1e3» не по форме,
            хотя тип int или float их прочёл бы (решение «Архитектора» 2026-10-27, как OBS154-RAW-TIME-EXACT-01);
            элемента нет, он не читается своим типом или читателем `time`, поле не числового типа или число не конечно — окно не прочитано
window:     окно [since, end], end = until, при longest — min(until, since + longest); until ≤ since — строка ничего не
            держит (пустое окно)
bucket:     бакет держит окно, когда его отрезок [начало, начало + 600 с] (договор журнала событий `bucket` `span`)
            пересекается с окном, концы включительно
```

Строка, которая не раскодировалась как строка таблицы, — ни `released`, ни адресат, ни окно не прочитаны.

## Что держит строка

Строка не отпущена (`released` выше):

| Прочитано | Держит |
|---|---|
| адресат и окно | бакеты единицы `<A>/<id>` в окне — в деревьях `<A>`, `<A>.alarms`; бакеты в окне единиц `<X>/<u>` деревьев `<X>`, `<X>.alarms`, чьё поле `about.field` называет `<id>`, — в том числе удалённых: значение `about.field` читается и из надгробия строки единицы; бакеты в окне единиц `<X>`, о которых неизвестно, называют ли они `<id>` (строки нет и надгробия нет, или строка не читается), — пока это неизвестно: «не знаю» — не «ничья» (ADR-0091 п. 8) |
| адресат, окно — нет | то же без окна: все бакеты этих единиц |
| адресат — нет | все бакеты деревьев адресата |

Держит — бакет не убирается по сроку (`retain`); прочие правила срока (дни, пол отметок консоли, час копий зеркала —
P/05 Н1.3 `retention`, Н3 `retain`) действуют для бакетов, которые никакая строка не держит. Строка, у которой не прочитан
адресат или окно и которая не отпущена, считается в `garbled_rows.<table>` пульса ресурса (P/05 Н1.4).

## Чтение таблицы

Ресурс читает строки `<M>/<table>/` перечнем хранилища в каждом проходе срока. Перечень не получен целиком (ошибка
хранилища, обрыв, отказ прав) — удержания не прочитаны: ничего не убирать в деревьях адресата в этом проходе, причина в
пульсе (P/05 Н4, строка «retention: … holds не удалось прочитать»). Пустой полный перечень — удержаний нет.

## Векторы

Пакет [`holds`](../vectors/holds/README.md) — функция «держит ли строка бакет» (вход — объявление, строка, отрезок бакета;
вывод — `held` | `not_held` | `unknown`): разделы «Объявление», «Строка удержания», «Что держит строка» без выбора деревьев
адресата (ADR-0083 доп. (37) п. 5). Чтение элементов строки своим типом — пакет
[`values-by-type`](../vectors/values-by-type/README.md). Перечень таблицы, деревья адресата и удержание «про» проверяются
чтением; уборка по сроку — тоже: стенд не выдерживает срок бакетов (P/06.4-08, P/05-06).

## Соответствие прежним урокам

Из P/06.4 Н1.5 (`holds`, `about`): объявление, `released`, окно, `longest`, удержание «про» (норма P/06.4-08 — по `note`
[id-map](../id-map.tsv)). У P/06.4 Н1.5 и P/05 Н3 `retain` — ссылки сюда.
