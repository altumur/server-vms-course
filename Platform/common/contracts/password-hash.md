# Договор хэша пароля: `pbkdf2-sha256`

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): общий алгоритм нескольких процессов — договор, а не копии
в главах; догадка стадии C GP-G06, решение «Архитектора» 2026-10-23). Владелец — глава
[P/08.4](../../08-domain/spec/08.4-domain.norms.md) (Н1.1 `pwhash_secret` строки человека, Н1.6 — аварийной учётки).
Участники: процесс `domain` — пишет хэш (люди, аварийная учётка) и проверяет вход людей (P/08.4 Н1.2); консоль кластера —
проверяет пароль аварийного входа ([договор сторожевой и передачи](gate-and-pass.md) «Аварийный вход»). Перенесено из P/08.4
Н1.1 без изменения поведения.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

```yaml
form:     pbkdf2-sha256$600000$<соль: 32 строчных hex>$<ключ: 64 строчных hex>
hash:     ключ = PBKDF2-HMAC-SHA256(пароль — байты UTF-8, соль — 16 случайных байт, 600000 итераций, длина 32 байта);
          писатель пишет hex строчными
verify:   строка по form — вычислить ключ от пароля и соли строки и сравнить с ключом строки за постоянное время: равны —
          пароль подходит; строка не по form (иной алгоритм или число итераций, hex заглавными, иная длина, лишняя часть,
          пустая строка) — пароль не подходит, не ошибка
secret:   в строке хранилища поле *_secret запечатано кольцом держателя (договор запечатывания); хэш — у открытого значения
```
