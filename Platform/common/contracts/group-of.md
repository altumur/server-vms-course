# Договор группы по хосту: `group_by` с `cut_at: host`

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): общий алгоритм нескольких процессов — договор, а не копии
в главах; догадка стадии C W03-GROUP-01, решение «Архитектора» 2026-10-23). Владелец — урок
[P/04](../../04-controller/spec/04-controller.norms.md) (Н1.3 `group_by`; ADR-0011, ADR-0053). Участники: контроллер —
размещение группы целиком на одном воркере (P/04 Н1.3, Н3); воркер — штамп `group` просьбы, поданной воркером, и один
незавершённый вызов действия на группу ([P/03.6](../../03-worker/spec/03.6-worker.norms.md) Н1.5, Н3); дверь единиц — отказ
источника шагом url [проверки строки](row-check.md). Правила перенесены из P/04 Н1.3 `group_by` и шапки векторов
[`group-of`](../vectors/group-of/README.md) без изменения поведения.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Группа

```yaml
group:      одно значение поля placement.group_by.field; у поля type: url с cut_at: host — хост адреса в одном написании:
            нижний регистр, без конечной точки корня; IP-литерал — как его пишет netip: IPv6 без скобок, нули свёрнуты,
            зона снята, IPv4-mapped — как IPv4; схема и порт в группу не входят (rtsp:// и ipint:// к одному хосту, :554 и
            без порта — одна группа)
host:       место хоста — по schemes поля ([договор адреса](url-credentials.md) «Схемы»): host: authority — хост authority
            после последнего «@» (у схемы с fragment: none «#» — обычный знак); host: path — первый сегмент пути, узел
            authority — хаб и в группу не входит; путь пуст — места хоста нет
none:       узел authority из none своей схемы — единица не в группе; none действует только в своей схеме (rtsp://file/x —
            группа file); узел сравнивается как записан, с userinfo и портом, хост в нём — в одном написании (договор адреса «Схемы» node);
            перевод IPv4-mapped в IPv4 — только для ключа группы, не для узла none (GROUP-NODE-01)
readable:   хост — метки RFC 1123 (метка 1–63 знака, имя ≤ 253 знаков без точки корня; длиннее — хост не читается;
            догадка стадии C GO-DNS-01, решение «Архитектора» 2026-10-23) или IP-литерал; иное — %-кодирование, «_», знаки вне ASCII, числовая последняя метка, не
            записанная десятичным IPv4 целиком (010.0.0.50, 10.1, 0x0a.0.0.1; числовая — в том числе восьмеричная с ведущим 0
            и шестнадцатеричная 0x…: cam.0x50 — догадка стадии C GROUP-NUMERIC-01, решение «Архитектора» 2026-10-23), нечисловой порт
            после хоста — хост не читается
alone:      значения нет, оно пусто, хост не читается или места хоста нет — единица не в группе и размещается одна;
            общей «группы без значения» нет; нет значения или пусто — без группы и без отказа, обязательность поля — П4
            [проверки строки](row-check.md) (догадка стадии C GO-EMPTY-01, решение «Архитектора» 2026-10-23)
refusal:    отказ источника — шаг url проверки строки (bad_url: договор адреса А15 и «Схемы»): у cut_at: host нечитаемый
            хост — отказ, а не «принят без группы»; отказ по правилу url не отменяет группу читаемого хоста — старая строка
            остаётся с соседями (вектор называет и группу, и отказ)
```

Векторы — [`../vectors/group-of/`](../vectors/group-of/README.md): адрес → группа (`<none>` — не в группе) и отказ.
