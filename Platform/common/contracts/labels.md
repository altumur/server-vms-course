# Договор азбуки меток

Общий договор модуля «Платформа» (ADR-0083 доп. (5); решение «Архитектора» по разбору ревью стадии A 6–7, № 11: азбука
меток — в `common/`). Читают: контроллер — ограничение `labels-subset` и метки воркера ([P/04](../../04-controller/spec/04-controller.norms.md)
Н1.3), консоль — поле меток единицы ([P/06.1](../../06-console/spec/06.1-console.norms.md) Н1.2 `list`), двери меток
сервера и прогнозы ([P/06.6](../../06-console/spec/06.6-console.norms.md) Н2.1), гранты по меткам (урок 8, М11/9 Н1.2
`scope`). Перенесено из главы 6.6 Н2.1 (прежде М10/4 Н2) без изменения поведения. Форма строки меток сервера — семья
`server-labels` ([P/06.6](../../06-console/data/server-labels.form.yaml)); что метки значат для размещения — у читающих уроков.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Метка

```yaml
label:   1–64 ASCII-знака: первая — буква или цифра, далее буква, цифра, `_`, `.`, `:`, `-`;
         целиком `[A-Za-z0-9][A-Za-z0-9_.:-]{0,63}`; перевод строки и иной знак — не метка
compare: байтами; регистр различается
set:     набор меток — без повторов, порядок не значим
```

## Список меток

```yaml
text:    метки через запятую (правило списка P/06.1 Н1.2 `list`: иначе — массив JSON); "" — ни одной метки
query:   список query разбирается по запятым, без пустых элементов, кроме целиком пустой строки (P/06.6 Н2.1)
empty:   пустой элемент у поля меток размещения недопустим, у обычного `list` — допустим (P/06.1 Н1.2)
refuse:  элемент не по азбуке — отказ того, кто читает вход: 400 у дверей консоли (P/06.1 Н4, P/06.6 Н4)
```
