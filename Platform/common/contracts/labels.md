# Договор азбуки меток

Общий договор модуля «Платформа» (ADR-0083 доп. (5); решение «Архитектора» по разбору ревью стадии A 6–7, № 11: азбука
меток — в `common/`). Владелец — урок [P/06](../../06-console/spec/06.6-console.norms.md) (глава 6.6: двери меток
сервера; перенесено оттуда; разбор ревью стадии B 6–7, № 35). Читают: контроллер — ограничение `labels-subset` и метки воркера ([P/04](../../04-controller/spec/04-controller.norms.md)
Н1.3), консоль — поле меток единицы ([P/06.1](../../06-console/spec/06.1-console.norms.md) Н1.2 `list`), двери меток
сервера и прогнозы ([P/06.6](../../06-console/spec/06.6-console.norms.md) Н2.1), гранты по меткам ([P/08.4](../../08-domain/spec/08.4-domain.norms.md) Н1.3
`scope`). Перенесено из главы 6.6 Н2.1 (прежде М10/4 Н2) без изменения поведения. Форма строки меток сервера — семья
`server-labels` ([P/06.6](../../06-console/data/server-labels.schema.json)); что метки значат для размещения — у читающих уроков.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Форма

Файлы, по которым работает договор (аудит раскладки, В-33, В-34; решение «Архитектора» 2026-10-25): строка меток
сервера `platform/servers/<s>` — семья `server-labels`: `Platform/06-console/data/server-labels.schema.json`,
`Platform/06-console/data/server-labels.outcomes.tsv`; двери меток сервера (`PUT /servers/{server}/labels`, проба `labels`,
отказ 400) — `Platform/06-console/spec/06-console.api.openapi.yaml`.

## Метка

```yaml
label:   1–64 ASCII-знака: первая — буква или цифра, далее буква, цифра, `_`, `.`, `:`, `-`;
         целиком `[A-Za-z0-9][A-Za-z0-9_.:-]{0,63}`; перевод строки и иной знак — не метка
compare: байтами; регистр различается   # решение «Архитектора» (разбор ревью стадии B 6–7, № 40): уроки-источники способа
                                         # сравнения не называли
set:     набор меток — без повторов, порядок не значим; повтор метки (байтовое равенство) во входе записи меток сервера и
         в query `labels` пробы — отказ 400, не сжатие (P/06.6 Н2.1, Н4; разбор ревью стадии B 6–7, № 40; проба — (решение «Архитектора» 2026-10-20, разбор ревью стадии B 6–7))
output:  набор, который платформа пишет или выдаёт (строка меток сервера, ответы дверей меток и прогнозы, метки воркера), —
         по возрастанию байтов UTF-8 (`Vlan:a` < `gpu` < `vlan:b`, `a10` < `a9`); порядок входа не сохраняется; значение
         поля меток единицы — значение поля списка (договор проверки строки «Строка единицы»), набором не переупорядочивается
         (догадки стадии C L01–L03, решение «Архитектора» 2026-10-23)
```

## Список меток

```yaml
text:    метки через запятую (правило списка, [договор проверки строки](row-check.md) `values_by_type` `list`: иначе —
         массив JSON); "" — ни одной метки; массив JSON писатель пишет компактно, без пробелов (`["a","b"]`); у меток по
         азбуке он не нужен — запятой, ведущего `[` и пустого элемента у метки нет (догадки стадии C L01–L03, решение «Архитектора» 2026-10-23)
read:    ведущий `[` значим только первым знаком текста: такой текст читается массивом JSON (пробелы между лексемами
         допустимы, как у `list`), его элементы — метки по азбуке; `[` дальше в тексте — знак метки, то есть отказ азбуки
query:   список query разбирается по запятым, без пустых элементов, кроме целиком пустой строки (P/06.6 Н2.1)
empty:   пустой элемент у поля меток размещения недопустим, у обычного `list` — допустим (договор проверки строки)
env:     LABELS окружения воркера (договор файла окружения «Переменные окружения») — текст списка, каждая метка по азбуке
         (иначе отказ старта, код 2); повтор — не отказ: метки узла — набор, повтор сжимается, пульс пишет их по output
         (ENV54-01/02, решение «Архитектора» 2026-10-25)
refuse:  элемент не по азбуке — отказ того, кто читает вход: 400 у дверей консоли (P/06.1 Н4, P/06.6 Н4); повтор метки в
         `PUT /servers/{server}/labels` и в query `labels` пробы `GET` — тоже 400 (P/06.6 Н4; № 40; проба — (решение «Архитектора» 2026-10-20, разбор ревью стадии B 6–7))
```
