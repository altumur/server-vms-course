# Договор ключа резервной копии домена: вывод из корня

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): общий алгоритм нескольких процессов — договор, а не копии
в главах; догадка стадии C I02-BACKUP-HMAC, решение «Архитектора» 2026-10-23). Владелец — урок P/08, глава
[8.8](../../08-domain/spec/08.8-domain.norms.md) Н1.5 (резервная копия держателя: конверты секретов, `kid`, чтение).
Участники: установщик — команда «установка домена» ([P/02.4](../../02-installer/spec/02.4-installer.norms.md) Н3 шаг 8)
выводит ключ при `backup_key_rev` 1 и пишет его в `domain/signer`; процесс `domain` держателя — запечатывает резервную
копию и выводит ключ при чтении копии по её `backup_key_rev`. Перенесено из P/08.8 Н1.5 (строка `backup_key`) без
изменения поведения.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

```yaml
backup_key:      HMAC-SHA256(ключ: root_key файла восстановления — 32 байта, записанные hex (P/08.2 Н1.1 recovery_file),
                 данные: байты ASCII "w2c domain backup secrets", байт 0x00, байты ASCII десятичной записи backup_key_rev)
                 — 32 байта
backup_key_rev:  целое ≥ 1 без ведущих нулей; при установке 1; иное — ключа нет (отказ того, кто выводит)
```

Где ключ хранится у держателя (`domain/signer.backup_key_secret`), конверт `enc:v2` этим ключом, `kid` `b<backup_key_rev>` и
чтение копии — P/08.8 Н1.5. Векторы — [`../vectors/domain-backup-key/`](../vectors/domain-backup-key/README.md).
