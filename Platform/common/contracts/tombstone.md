# Договор надгробий: надгробие удалённого тела, соседи, подтверждения, снятие

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): надгробие пишут и читают несколько процессов — договор, а
не копии в главах; догадка стадии C C06-BLOB-GC-33-01 / IF-OBJECT-TOMBSTONE63-PEERS-01, решение «Архитектора» 2026-10-25).
Владелец — урок [P/05](../../05-resource/spec/05-resource.norms.md) (Н1.1 «Надгробия»; семья `.gone/<ключ>` —
[каталог](../data/catalog.tsv), форма — [`gone.form.yaml`](../../05-resource/data/gone.form.yaml), исходы —
[`gone.outcomes.tsv`](../../05-resource/data/gone.outcomes.tsv)). Участники — консоль: пишет надгробие на завершении окна
уборки тел ([P/06.1](../../06-console/spec/06.1-console.norms.md) Н3 «уборка тел»); ресурс: роняет копии по надгробиям
соседа, дописывает подтверждения и снимает надгробие (P/05 Н1.1 «Тела у ресурса», «Надгробия»).

Перенесено из P/05 Н1.1 «Надгробия» (прежде М10/10 Н1.5 `delete`) без изменения поведения; новое — правило `peers`
(раздел «Соседи»): прежде источник и полнота списка не были названы.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Форма

```yaml
tombstone: .gone/<ключ> у удалившего — объект {written, peers, acked}: written — стенные секунды удаления, peers —
           соседи кольца, у которых могла быть копия (раздел «Соседи»), acked — подтвердившие, acked ⊆ peers (журнал
           cammeta-go, урок 10 № 2); у двери объектов DELETE нет; записи и удаления .gone/ дверь не принимает
listing:   обычный листинг .gone/ не показывает; /v1/objects?prefix=.gone/ — листинг надгробий только для чтения
garbled:   нечитаемое надгробие (gone.outcomes.tsv, объект целиком) — неизвестный исход: сосед копию не роняет,
           удаливший подтверждений не дописывает и надгробие не снимает
```

## Соседи (`peers`)

Соседи меняются со временем (копии кладутся следующим `copies` живым по имени — P/05 Н1.1 «Тела у ресурса»), поэтому
`peers` — надмножество тех, у кого могла быть копия (C06-BLOB-GC-33-01, решение «Архитектора» 2026-10-25):

```yaml
peers:     все серверы <s>, чья строка двери platform/doors/<s> есть в подтверждённом листинге удаляющего, кроме своего
           сервера и выведенных — тех, чья строка platform/decommission/<s> есть в подтверждённом листинге вывода
           (P/06.6 Н1.1, P/04 Н3 «вывести_сервер»); сервер — по ключу листинга, читаемость строки не важна; сервер без
           копии подтвердит быстро (404)
unknown:   листинг дверей или листинг вывода не подтверждён (не получен целиком, неответ, нечитаем) — надгробие не
           пишется и удаления нет: уборка ждёт (неизвестный исход — не основание; P/06.1 Н2 «Команда окна уборки», код 2)
silent:    молчащий, но не выведенный сервер — в peers: надгробие ждёт его подтверждения (раздел «Снятие»)
order:     порядок элементов peers и acked не нормирован; повторов нет
```

## Чтение соседом

```yaml
drop:      сосед раз в 10 мин (проход ресурса, P/05 Н3) читает надгробия удалившего листингом prefix=.gone/ и роняет свою
           копию старше written; копия, которую надгробие удалившего новее, не принимается (P/05 Н4, «удалено позже» — 409)
```

## Подтверждение

```yaml
ack:       удаливший раз в 10 мин спрашивает каждого из peers, кого нет в acked, GET копии: 404 — подтверждение (сосед
           дописывается в acked, cas); копия есть, иной ответ или неответ — нет (неизвестный исход не подтверждение)
retired:   сосед из peers, выведенный после записи надгробия (строка platform/decommission/<s> есть в подтверждённом
           листинге вывода), — подтвердивший: дописывается в acked без GET копии; листинг вывода не подтверждён — не
           подтверждение (C06-BLOB-GC-33-01, ответ «Архитектора» 2026-10-25 (2))
```

## Снятие

```yaml
rewrite:   объект с тем же ключом записан у удалившего снова после written — надгробие снимается сразу: без
           подтверждений и без срока 7 дней (ключ снова живой; копии старше written сменит новая запись; C06-BLOB-GC-33-01, ответ «Архитектора» 2026-10-25 (1))
remove:    иначе надгробие хранится не меньше 7 дней и снимается только когда все peers подтвердили удаление (peers ⊆ acked);
           неизвестный исход не подтверждение
```

## Векторы

Пакет [`tombstone`](../vectors/tombstone/README.md): `peers` — листинг дверей, листинг вывода, свой сервер → peers или
«удаления нет»; `ack` — peers, acked, ответы GET копии и листинг вывода → acked; `remove` — peers, acked, written, now, запись снова →
снять или держать. Роняние копии соседом и 409 «удалено позже» — P/05 и чтение; стенд с двумя ресурсами — системная
приёмка (P/05-11 — чтением).
