# Договор истории тревог: история члена у держателя, равенство строк, `cut_before`

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): историю пишет держатель, читает консоль домена — договор,
а не копии в главах; догадка стадии C C10-ALARM-SAME-LINE83, решение «Архитектора» 2026-10-25). Владелец — глава
[P/08.9](../../08-domain/spec/08.9-domain.norms.md) Н1.9. Участники: писатель — проход держателя, процесс `domain`
(ADR-0032); читатель — список тревог консоли домена ([P/10](../../10-domain-console/spec/10-domain-console.norms.md) Н1.8, Н3
`alarms`: слияние страницы и истории); резервная копия держателя (P/08.8 Н1.5 `objects`).

Перенесено из P/08.9 Н1.9 без изменения поведения, вместе с правилом повтора строки в одной странице (P/10 Н3 `alarms`
шаг 2; сверка М11, A16); P/08.9 и P/10 — ссылкой сюда.

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md).

## Форма

Объект `domain/alarm-history/<член>` — семья `alarm-history`: форма `Platform/08-domain/data/alarm-history.schema.json`,
исходы `Platform/08-domain/data/alarm-history.outcomes.tsv` ([форма](../../08-domain/data/alarm-history.schema.json),
[исходы](../../08-domain/data/alarm-history.outcomes.tsv)). Строка истории — строка страницы тревог члена, как принята:
`t` — на часах домена (раздел «Часы домена»), `t_src` — `t` строки, как пришло, по часам члена. Времена — канон P/01.1 Н0
«Время в строке» (`Platform/common/data/codec.tsv`, строка `time`): писатель — не больше трёх знаков дроби.

## Часы домена

Перенесено из [P/10](../../10-domain-console/spec/10-domain-console.norms.md) Н1.8 `clock` без изменения поведения (аудит раскладки, решение «Архитектора» 2026-10-25, А-13):
часы строки читают проход держателя (пишет историю, `events[].t`) и список тревог консоли домена.

```yaml
clock:         время строки страницы на часах домена: t + (received_at − sent_at) последнего принятого отчёта, который
               несёт эту страницу (поля последнего запроса метки, P/08.3 Н1.3); не page.to: прежняя страница в новом отчёте
               старые тревоги вперёд не сдвигает (решение «Архитектора» по R41-16 прогона 41); t_src — t как пришло
```

## История

```yaml
history:       объект держателя domain/alarm-history/<член> {events, cut_before} — скользящая неделя, не больше
               HISTORY_LINES строк, самые новые; cut_before — с какого момента член держится целиком: число (часы домена),
               при создании истории — 0, не null (сверка М11, A13)
cut:           cut_before двигается только при фактическом снятии строк: сняты строки с t < now − HISTORY_DAYS × 86400 —
               cut_before = max(cut_before, now − HISTORY_DAYS × 86400); сняты самые старые сверх HISTORY_LINES —
               cut_before = max(cut_before, t самой новой снятой); сверх HISTORY_LINES остаются самые новые по t (часы домена),
               при равных t — устойчиво по порядку истории (раньше принятые снимаются первыми), оставшиеся — в прежнем
               порядке (AH-SAME52-01, AH-CUT52-01, решение «Архитектора» 2026-10-25); ничего не снято — объект истории и его байты прежние, записи нет, и тихий
               член не двигает rev резервной копии (P/08.8 Н1.5 rev); начальный 0; cut_before не убывает (сверка М11,
               A14; решение «Архитектора» по cammeta-go М11-03 № 11)
  events:      строки страницы, как приняты: t — на часах домена (раздел «Часы домена»), t_src — как пришло
HISTORY_DAYS:  7
HISTORY_LINES: 2000
writer:        только проход держателя (процесс domain, ADR-0032): после приёма отчёта дописать строки его страницы,
               которых нет (same_line ниже); список тревог (P/10 Н1.8) историю только читает
in_copy:       история едет с резервной копией держателя (P/08.8 Н1.5 objects)
```

## Равенство строк

```yaml
same_line:     строки a и b — одна строка, когда равны (t_src, kind, subsystem, unit): t_src — как пришло, по часам члена
               (поправка часов меняется от отчёта к отчёту, поэтому не t); id, t и прочие поля в равенство не входят;
               t_src сравнивается как число (канон времени P/01.1 Н0: 990 и 990.0 — одно значение), хранится как пришло, байты
               не меняются; kind, subsystem, unit: отсутствует = отсутствует, отсутствует ≠ null, присутствующие — равенство
               значений JSON, не текста (AH-SAME52-01, AH-CUT52-01, решение «Архитектора» 2026-10-25)
page_repeat:   повтор same_line внутри одной страницы — берётся первая строка по порядку страницы, прочие отбрасываются
               (сверка М11, A16)
```

Слияние страницы и истории в выдаче консоли домена (строка страницы прежде строки истории, окно `[since, until]`, строка
молчания) — P/10 Н3 `alarms`, по `same_line` отсюда.

## Векторы

Пакет [`alarm-history`](../vectors/alarm-history/README.md): равенство строк (`same`), повтор в странице (`page`), запись
держателя (`write`: создание с `cut_before` 0, без повторов по `same_line`, снятие по неделе и движение `cut_before`,
ничего не снято, равные `t` на границе `HISTORY_LINES`); `same` — и `t_src` 990/990.0, отсутствует/`null` (AH-SAME52-01, AH-CUT52-01).
Слияние страницы и истории — пакет `alarms` урока P/10.
