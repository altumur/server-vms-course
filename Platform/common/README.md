# Общее для всех микромодулей

```text
data/catalog.tsv           каталог данных: строки, объекты, файлы — владелец, участники, читатели (ADR-0083)
contracts/                 общие договоры нескольких процессов: запечатывание (кольцо, enc:v2, AAD), сертификат роли,
                           журнал событий, замок присутствия, наблюдение (resource_state, LOST_AFTER), азбука меток;
                           просьба и её метка, токен двери, токен домена (разбор ревью стадии B 3–5, В1);
                           местная дверь токенов агента (разбор ревью стадии A 8–10, решение 1); конверты домена
                           x25519:v1 и m1 (№ 12); подпись агента, набор ключей домена, запись срока, подпись
                           просьбы, приём отчёта (№ 13); сторожевая и передача door.pass (№ 14); пересылка (№ 23); право
                           по грантам may, клиент peer (решение «Архитектора» 2026-10-20, ADR-0083 доп. (14) пп. 1, 2)
vectors/README.md          указатель всех векторов по урокам-владельцам (сами векторы — в каталоге владельца)
vectors/sealing/           векторы договора запечатывания (общие, без урока-владельца)
vectors/domain-envelopes/  векторы договора конвертов домена (бывшие входы приёмки М11/2, М11/3)
vectors/domain-token/      векторы договора токена домена (бывшие входы приёмки М11/2 token-*)
testdata/                  testsub*.yaml — сквозной пример (переезжает из Source/tests/testdata на стадии B)
acceptance/system/         сквозные сценарии нескольких микромодулей
acceptance/matrix/         смешанные сборки
id-map.tsv                 старый id нормы, сценария, шага, вектора → новый
stage-a-after-m11.md       кандидаты стадии A по итогам М11 cammeta-go и матрицы домена (ADR-0083 доп. (4))
```

Словарь нормативных слов — канон всего курса, лежит вне модуля (файл курса).
