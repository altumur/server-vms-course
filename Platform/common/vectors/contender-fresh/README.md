# Векторы: свежесть метки соперника — возраст наблюдаемой версии → свежа

Владелец — [договор наблюдения](../../contracts/observation.md) «Свежесть метки соперника: `CONTENDER_FRESH`» (догадка
стадии C C06-CONTENDER-FRESH-33-01, решение «Архитектора» 2026-10-25). Писатель метки — воркер
([P/03.2](../../../03-worker/spec/03.2-worker.norms.md) Н1.4а, `CONTEND_EVERY`); читатель — консоль (`WorkerRow.name_conflict`
`/servers`, ряд `name_conflicts`, [глава 6.5](../../../06-console/spec/06.5-console.norms.md)). Байты пишет «Спецификация»;
строки — по тексту договора.

## Правило

- `CONTENDER_FRESH` = 300 с;
- **свежа** — возраст наблюдаемой версии метки ≤ `CONTENDER_FRESH`; старше — читатель метку не учитывает.

Функция чистая: вход — возраст в секундах (число, дробное допустимо), выход — свежа или нет. Как возраст получается
(монотонные часы читателя, первый взгляд — 0, поле `at` — показ) — договор, раздел «Наблюдение версии»; нечитаемая
метка — как старше: это чтение формы, не возраст, в таблице её нет — проверяется чтением.

## `fresh.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок. Поля `case`, `age`,
`fresh`, `note` — как в пакете [`fresh-age`](../fresh-age/README.md) (`age` — число JSON, `fresh` — `true` | `false`).

6 строк: 0 (первый взгляд), 299, 300, 300.0, 300.001, 301.

## Прогон

Без стенда: сторона подаёт `age` своему суждению о свежести метки и сверяет с `fresh`, над числом как есть, без
округления. Исполняет читатель — консоль (`06-console`); писатель метки (воркер) свежесть чужих меток не судит (ACC-VECTORS-CONNECT-02, решение «Архитектора» 2026-10-26).
При расхождении прав договор, вектор правит «Спецификация».
Кто исполняет — консоль (`06-console`: свежесть меток для `WorkerRow.name_conflict` и ряда `name_conflicts`, P/06.5 Н3 «/servers»). Воркер (`03-worker`) метку только пишет и свежесть чужих меток не судит (P/03.2 Н1.4а); поле `name_conflicts` отчёта контроллера (`04-controller`, P/04 Н1.2) по этому правилу не считается (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Нативный исход

Код 0 и значение колонки `fresh` — `true` или `false` (одна колонка ожидания — общее правило «Векторы» [общего README
приёмки](../../acceptance/README.md); как у [`fresh-age`](../fresh-age/README.md)); вход — ячейка `age`; решение «Архитектора» 2026-10-27.
