# Векторы: азбука меток

Владелец — урок P/06 через [договор азбуки меток](../../contracts/labels.md) (`label`, `set` `output`, `text`, `read`;
догадки стадии C L01–L03, решение «Архитектора» 2026-10-23). Участники — читающие метки по договору: консоль (поле меток
единицы, двери меток сервера), контроллер (`labels-subset`), гранты по меткам. Байты пишет «Спецификация». Поле меток
единицы как поле списка — векторы [`values-by-type`](../values-by-type/README.md) (`list:labels`) и
[`row-check`](../row-check/README.md).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая строка без `#` — заголовок. Пять полей:

| Поле | Значение |
|---|---|
| `case` | имя случая, уникально |
| `op` | `label` — одна метка по азбуке; `set_write` — набор меток (массив входа) → текст списка, который пишет платформа; `text_read` — текст списка → набор; `env_labels` — `LABELS` окружения воркера → метки узла набором (повтор сжимается; ENV54-02) |
| `input` | значение JSON: строка у `label`, `text_read` и `env_labels`, массив строк у `set_write` |
| `expect` | `ok` (метка допустима), `@refuse` (отказ), иначе значение JSON: у `set_write` — строка текста (байт в байт), у `text_read` и `env_labels` — набор массивом по возрастанию байтов (сравнение как набора) |
| `note` | правило договора или шаг приёмки P/06.6 |

32 случая: 15 `label`, 6 `set_write`, 8 `text_read`, 3 `env_labels`.

## Прогон

Сторона исполняет свой код азбуки меток: проверку метки, запись набора текстом списка и чтение текста списка в набор.
Значение поля меток единицы набором не переупорядочивается (договор `output`) — эти векторы его не проверяют: поле с
повтором `["a","a"]` хранится как есть (`values-by-type` `lb-repeat`, `row-check` `labels_repeat`); сравнение такого поля
как набора `{a}` (ограничение `labels-subset`) пакет не выражает — у него нет операции сравнения наборов: чтением
(C51-LABEL-LIST-01). `read_repeat` — повтор в тексте меток сервера и query пробы: отказ (P/06.6), не поле единицы.
Кто исполняет — по `op`: `env_labels` — воркер (`03-worker`, договор `env`); `label` — читающие метки по договору:
контроллер (`04-controller`), консоль (`06-console`), гранты по меткам (`08-domain`) и воркер (`03-worker`: каждая метка
`LABELS` — по азбуке); `set_write` — консоль (`06-console`: строка меток сервера, поле меток единицы; метки пульса
воркер пишет массивом, не текстом списка); `text_read` — контроллер (`04-controller`) и консоль (`06-console`) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-26).
