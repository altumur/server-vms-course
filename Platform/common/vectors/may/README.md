# Векторы права по грантам

Векторы [договора права](../../contracts/may.md): функция `may` — право человека по строкам грантов (ранг, область,
срок строки, давность копии, выключенный, аварийная сессия). Владелец — урок P/08, глава 8.4; исполняют сторожевые консоли
кластера ([P/06.3](../../../06-console/spec/06.3-console.norms.md) Н1.3, глава 6.7) и консоли домена (урок 10) и процесс
`domain` (8.4) (решение «Архитектора» 2026-10-20, ADR-0083 доп. (14) п. 1; разбор ревью стадии A 8–10). Байты пишет
«Спецификация» (ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из входов команды `may` приёмки [М11/9](../../../../Source/tests/testdata/acceptance/М11_Domain/09/README.md)
(`inputs/may-*.json`, сц. 07) без изменения значений: JSON входа — одной строкой, порядок ключей и лексемы чисел — как в
файле; `case` — имя файла входа. До переноса урока 8 приёмка М11/9 идёт по своим входам; таблица и входы — одни и те же
случаи.

## Прогон

Без стенда: функция реализации получает вход (колонка `input`) и даёт вывод; `expect` — подмножество полей вывода или
`exit 2` (вход не по форме М11/9 Н5 `exit`: строки `grants` — доверенный вход, строка не по форме — 2, не пропуск). Время —
входом `now`, не часами процесса.

## Единицы

`c1` `testsub` с метками `east`, `ground`; `c2` без меток; `t1` `testsub2` с меткой `west` и `about` — `c1`. `now` —
1760000000; давность копии — `GRANT_LIFETIME` (М11/9 Н1.3).

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок; `note` — сценарий и шаг
приёмки.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 24 строки: 11 `allow`, 12 `deny`, 1 `exit 2` | `input` — вход команды `may` текстом JSON → `expect`: `{"result":"allow"}` (аварийная сессия без грантов, копия ровно суточной давности, строка держателя без `as_of`, `view` без единицы — любая строка, `*`, `unit:` своя и через `about`, `labels:` все метки, метки `about`, ранг выше, срок строки впереди) или `{"result":"deny","reason":<слово>}`: `disabled` (выключенный при гранте), `stale` (копия старше суток), `no_grant` (строки нет, `edit` без единицы не по `*`, чужая единица, одной метки нет, метки самой единицы при `about`, ранг ниже, истёкшая строка, `"*"` не по `*`, строка другого субъекта, единица без меток); `exit 2` — область `unit:` с id не по грамматике [P/06.1](../../../06-console/spec/06.1-console.norms.md) Н1.3 |

Векторы проверены оракулом по тексту договора (шаги 1–8) и форме входа М11/9 Н1.3, Н5 `exit`, не по коду реализаций; при
расхождении прав договор, вектор правит «Спецификация».
