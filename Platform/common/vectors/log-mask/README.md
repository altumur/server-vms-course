# Векторы: маска лога

Владелец — [договор маски журнала](../../contracts/log-mask.md) (глава [P/06.2](../../../06-console/spec/06.2-console.norms.md) Н1.4 `never.log`; пары и адреса — [договор адреса](../../contracts/url-credentials.md)). Пакет перенесён из `Platform/06-console/vectors/log-mask/` байт в байт (C06-LOG-MASK-33-01); восемь строк в конце (конец учётных данных Basic/Bearer, пробельные White_Space — ответ «Архитектора» 2026-10-25) — только здесь: общая таблица `Source/tests/testdata/log_mask.tsv` прежняя.
Участники — все процессы платформы, которые пишут лог (id-map: М10/7-08 → P/06.2-05, «все процессы»). Байты пишет
«Спецификация»; соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16, ADR-0083). Перенесено из
`Source/tests/testdata/log_mask.tsv` байт в байт (стадия B, перенос урока 6, решение «Архитектора» по В8 плана урока 6);
шапка файла — английская, как была: `М10/7 Н1.4` в ней — прежний адрес главы P/06.2 Н1.4.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` — пояснения, пустые пропускаются. Заголовка нет. Ячейка читается байт в байт
между TAB, ничего не раскрывается: `\t`, `\n` в ячейке — два знака. Три поля:

| Поле | Значение |
|---|---|
| `raw` | текст как записан — строка лога, ошибка, документ JSON, строка подключения; не значение поля |
| `masked` | что показывает лог: учётные данные заголовков `Authorization` и `Proxy-Authorization`, значение каждой пары с секретным именем (и `имя=значение`, и пара JSON) и каждый адрес — с маской |
| `note` | зачем строка; пусто — пояснения нет |

## Прогон

Сторона маскирует `raw` лог-маской процесса, который знает манифесты стенда, и сравнивает с `masked` байт в байт. Правило
каталога — объединение правил полей `cam.source` и `rec.volumes.url` из [`fields.yaml`](../secret-in/fields.yaml) векторов `secret-in`
(во входе единой команды `vectors` — `files` с ключом `fields.yaml`; `cells: {raw}`; опись C04/C06-NEXT-167, решение «Архитектора» 2026-10-27)
с общим словарём Н1.1 `common_words` (имена, которые добавляет манифест, — `sig`, `psd` — включены).
Кто исполняет — каждый процесс платформы, который пишет лог (ACC-VECTORS-CONNECT-04, решение «Архитектора» 2026-10-26; принцип ACC-VECTORS-CONNECT-03): демон хранилища и его CLI (`01-store`),
установщик, `w2c-run.sh` и скрипт воркеров (`02-installer`), воркер (`03-worker`), контроллер (`04-controller`), ресурс
(`05-resource`), консоль кластера (`06-console`), процесс `domain` (`08-domain`), агент (`09-agent`), консоль домена
(`10-domain-console`); модуль консоли (`07`) лога не пишет.

Значение поля `type: url` — векторы [`../secret-in/`](../secret-in/README.md): в свободном тексте адрес кончается на пробеле,
кавычке, `\`, `<` или `>` (договор адреса А2), в значении поля — нет.

## `mask_in.tsv`

Маска на входе — договор маски журнала «Маска на входе» (`mask_in`); пробельные — договор имени человека `white_space`
(решение «Архитектора» 2026-10-27). UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая строка без `#` —
заголовок `case<TAB>value<TAB>expect<TAB>note`. `value` — значение секретного поля, присланное на запись, строкой JSON
(невидимые знаки — `\uXXXX`); `expect` — `{"mask": true}` (маска: отказ записи, P/06.2 Н4) или `{"mask": false}`
(значение). Знаки маски — те, которыми закрывают показ таблицы `cases.tsv` и векторы `secret-in` (`***`), и всё множество
договора. 33 строки: 21 маска, 12 значений (меньше трёх знаков, знак вне множества или внутри, не-White_Space по краю).
Вход единой команды `vectors` — `cells: {value}`; нативный исход — код 0 и объект `{mask}`, JSON по значению.

Кто исполняет — консоль (`06-console`: запись секретного поля распознаёт маску, P/06.2 Н1.1 `mask_in`, Н4); прочие писатели
лога `mask_in` не зовут — им `cases.tsv` (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Чего вектор не покрывает

Журнал, пульс, снимок, argv и текст отказа без значений (Н1.4 `never`) — чтением против мест записи реализации: эти
выходы таблица не читает (P/06.2-05).
