# Векторы: файл отзыва `revoked`

Владелец — общий [договор сертификата роли](../../contracts/role-certificate.md) `revoke` (`file`, `bad_file`; догадка
стадии C S01, решение «Архитектора» 2026-10-23). Участники — двери, которые проверяют TLS-пира: демон хранилища
([P/01.3](../../../01-store/spec/01.3-store.norms.md) Н1.6), дверь роли консоли домена ([P/10](../../../10-domain-console/spec/10-domain-console.norms.md)
Н1.4), дверь воркера на домене ([P/03.7](../../../03-worker/spec/03.7-worker.norms.md) Н1.6), слушатель `SIGNER_URL`. Байты пишет
«Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая непропущенная — заголовок `case<TAB>file<TAB>expect<TAB>note`.

| Поле | Значение |
|---|---|
| `case` | имя строки |
| `file` | содержимое файла `revoked` — строка JSON (`\n` — LF, `\r` — CR); `@absent` — файла `revoked` нет и `crl.pem` нет (договор `absent`); объект JSON `{revoked, crl}` — оба файла (договор `both`): `revoked` — содержимое строкой или `"@absent"`, `crl` — уже разобранный `crl.pem`: массив серийников (hex) CRL издателя проверяемого листа или `"@bad"` неверного (разбор CRL и область по издателю проверяет пакет [`crl`](../crl/README.md)) |
| `expect` | `@bad` — файл неверен целиком (`bad_file`); иначе JSON-массив серийников файла по значению — каноническая запись: строчные hex-цифры без ведущих нулей, ноль — `"0"`, по возрастанию значения, без повторов |
| `note` | правило |

## Прогон

Сторона читает `file` своим кодом чтения `revoked`, без TLS, и сравнивает: множество отозванных серийников (по целому
значению) равно `expect`, либо файл отвергнут как неверный при `@bad`. Байты не UTF-8 строкой JSON не выразить — этот
случай `bad_file` проверяется чтением.
Кто исполняет — те же роли, что у пакета [`crl`](../crl/README.md) (функция `revoke` договора сертификата роли): двери — хранилище (`01-store`), воркер (`03-worker`), ресурс (`05-resource`), процесс `domain` (`08-domain`, `SIGNER_URL`), консоль домена (`10-domain-console`); клиенты своего кластера (`own_client`: peer, затем отзыв) — установщик (`02-installer`), контроллер (`04-controller`), ресурс (`05-resource`), консоль (`06-console`), агент (`09-agent`), консоль домена (`10-domain-console`) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Нативный исход

Отдельного договора команды у пакета нет — общее правило «Векторы» [общего README приёмки](../../acceptance/README.md)
(ACC-VECTORS-CONNECT-04, решение «Архитектора» 2026-10-26): функция отвечает кодом 0 и одним значением JSON. Массив серийников или строка JSON `"@bad"` — файл неверен.
