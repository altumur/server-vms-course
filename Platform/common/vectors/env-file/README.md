# Векторы: строка файла окружения

Владелец — глава P/02.4 через [договор файла окружения](../../contracts/env-file.md) (грамматика `KEY=VALUE`, края B19;
догадка стадии C C04-ENV-01, решение «Архитектора» 2026-10-23). Участники — все процессы, которые читают файлы окружения
сами (раннер `w2c-run.sh` и процессы ролей): каждый проходит таблицу своей функцией разбора строки. Байты пишет
«Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая строка без `#` — заголовок. Четыре поля:

| Поле | Значение |
|---|---|
| `case` | имя случая, уникально |
| `line` | одна строка файла без завершающего LF — строка JSON (CR, BOM, табуляция записаны экранированием `\r`, `﻿`, `\t`) |
| `expect` | значение JSON: `["KEY","VALUE"]` — пара; `"skip"` — строка пропускается (пустая или комментарий); `"bad"` — не по грамматике (у процесса — отказ запуска кодом 2 со строкой лога, называющей файл и номер строки) |
| `note` | правило договора |

29 случаев: 12 пар, 3 `skip`, 14 `bad`. BOM относится к началу файла; строка `bom` — первая строка файла.

## Команда стенда `env-line`

Ключ `stand` профиля `02-installer` (раздел «Раскладка по процессам» [общего README приёмки](../../acceptance/README.md)),
по общему правилу команд векторов: шаблон с `{input}` — путь файла, в который раннер пишет ячейку `line` байт в байт (строку
JSON); stdout — значение JSON и LF, сравнивается с `expect` по значению; код 0 — вычислено, 2 — вход не по форме (не строка
JSON). Процессы других профилей, читающие файлы окружения, проходят ту же таблицу своей функцией без стенда.
