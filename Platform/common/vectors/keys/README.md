# Векторы набора ключей домена

Векторы [договора набора ключей домена](../../contracts/keys.md): функция `keys(pinned, held, offered)` — принять набор
`domain/keys`, подписанный корнем, только вперёд. Владелец — урок P/08, глава 8.2; функцию исполняют агент члена (9.1),
консоль кластера ([P/06.3](../../../06-console/spec/06.3-console.norms.md) «Ключи есть») и процесс `domain` при переносе и
следовании (разбор ревью стадии A 8–10, № 13 / решение 2; ADR-0083 доп. (13)). Байты пишет «Спецификация» (ADR-0083);
соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из входов команды `keys` приёмки М11/2
(`inputs/keys-*.json`, сц. 01–03) без изменения байтов; `case` — имя файла входа. Сценарии М11/02 сц. 01–03 и их входы
сняты переносом урока 8 (ADR-0083 доп. (14) п. 17; журнал — [README пакета `domain-token`](../domain-token/README.md#журнал-источника)): таблица — единственный источник
этих случаев.

## Прогон

Без стенда: функция реализации получает вход (колонка `input`) и даёт вывод; `expect` — подмножество полей вывода.
Кто исполняет: `cases.tsv` — агент члена (`09-agent`), консоль кластера (`06-console`) и процесс `domain` (`08-domain`);
`revoked.tsv` — агент члена (`09-agent`): строку `jtis` пишет он (ACC-VECTORS-CONNECT-02, решение «Архитектора» 2026-10-26).

## Ключи

Зёрна — `sha256("w2c test <слово>")`, слова — [README пакета `domain-token`](../domain-token/README.md#ключи) «Ключи» (`root 1` — корень домена `acme`, `root 2` —
чужой корень, `token key 1…3`, `book seal 1`, `book seal 2`); байты ключей — в самих входах (`pinned.pub`, `doc`).
Открытый корень `acme` — `34dc3424ca1fc497170b49eef38222db60fbcaa887852645d7c73bedcc9f7684`.

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок; `note` — сценарий и шаг
приёмки.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 21 строка: 4 `took`/`holding`, 17 отказов | `input` — вход команды `keys` текстом JSON (`pinned` — `{pub, domain}` или `null`, `held` — документ набора или `null`, `offered` — строка `domain/keys` как пришла) → `expect` — `{"result":"took"\|"holding","rev":…}` или `{"result":"refused","reason":<слово>[,"rev":…]}`: `older` (rev `held`), `no_pin`, `another_root` (корень, домен), `bad_signature` (подмена, `kid` не `root`, подпись 63 байта, не тот ключ), `not_a_set` (не JSON, лишнее поле, `current` не в `keys`, лишний элемент строки, повтор ключа JSON), `no_book_seal` (нет, точка малого порядка) |
| [`revoked.tsv`](revoked.tsv), 7 строк | `input` — `{own, answer, now}`: своя строка `jtis` члена, `jtis` ответа держателя или `null`, стенные секунды; `expect` — `jtis` строки, которую агент пишет (`merge`, `repeat`, `prune` договора; `TOKEN_SKEW` 60; KEYS-G01) |

Векторы проверены эталонными Ed25519 (RFC 8032), X25519 (RFC 7748) и JCS (RFC 8785) по тексту договора, не по коду
реализаций; при расхождении прав договор, вектор правит «Спецификация».
