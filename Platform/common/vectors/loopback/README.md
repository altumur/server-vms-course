# Векторы: порог петли клиента своего кластера

Владелец — [договор сертификата роли](../../contracts/role-certificate.md) «Клиент двери своего кластера» `loopback`
(ADR-0075 доп. 2026-10-26 (3) п. 1, (4) п. 1, (5) п. 1). Участники — клиенты двери своего кластера (`own_client` договора):
агент к своей консоли, скрипт воркеров, консоль кластера на переходе 2 и в пересылке подписанту, клиент двери ресурса.
Порог решает, подставить ли `SERVER_NAME` в `host` функции [`peer`](../peer/README.md) до шага 1; сама функция `peer` и
её пакет от этого не меняются. Байты пишет «Спецификация»; строки — по тексту договора.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — `{url}`: абсолютный URL со схемой и хостом (v6 — в скобках, зона — `%25<зона>`). **Выход** — строка JSON
`"loopback"` (литерал петли: v4 из четырёх десятичных частей 0–255 без ведущих нулей с первой `127`; v6 со значением `::1`
в любой записи без зоны), `"ip"` (иной IP-литерал по шагу 1 `peer`, в том числе v6 с зоной, `::ffff:127.0.0.1`,
`0.0.0.0`, `::`) или `"name"` (иначе: `localhost`, `127.1`, запись с ведущими нулями); или `@exit 2` — вход не по форме (не
объект, нет `url`, `url` не строка или не URL со схемой и непустым хостом). Код 2 — исход функции на вход не по форме;
у клиента такой URL — `bad_url` договора: из окружения — отказ старта, код 2; из строки хранилища — как поля нет
(ревью норм ADR-0075 Kimi 80ee2b775, Н6).

31 строка: v4-петля (в том числе граница и схема `http`), ведущие нули, три части, часть вне 0–255, шестнадцатеричная
запись — имя; IP вне петли, `0.0.0.0`; v6 `::1` в трёх записях — петля; с зоной, `::ffff:127.0.0.1`, `::`, иной v6 — `ip`;
имена (`localhost` в двух регистрах, имя сервера); точка в конце — имя; `[::0.0.0.1]` (хвост v4, значение `::1`) — петля;
`[::127.0.0.1]` — `ip`; `userinfo@` перед хостом не мешает; не URL, пустой хост, вход не объект, без `url`, `url` не строка — `@exit 2`. Запись хоста берётся как
записана, без нормализации разборщиком URL (договор `loopback`).

## Прогон

Без стенда: сторона подаёт `url` своей функции порога (та, что решает подстановку `host` клиента своего кластера) и
сравнивает слово с `expect`; DNS не спрашивается. Кто исполняет — каждый клиент двери своего кластера: агент
(`09-agent`), скрипт воркеров (`02-installer`), консоль кластера (`06-console`), консоль домена (`10-domain-console`:
`SIGNER_URL`, дверь воркера на домене), воркер и шлюз к своей консоли (`03-worker`), клиенты двери ресурса (процессы,
читающие объекты кластера по `RESOURCE_URL`: `03-worker`, `04-controller`, `06-console`, `08-domain`, `09-agent`)
(ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию).
