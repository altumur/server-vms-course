# Векторы: история тревог — равенство строк, повтор в странице, запись держателя

Владелец — [договор истории тревог](../../contracts/alarm-history.md) (глава P/08.9 Н1.9; догадка стадии C
C10-ALARM-SAME-LINE83, решение «Архитектора» 2026-10-25). Участники — проход держателя (процесс `domain`) и список тревог
консоли домена (P/10). Байты пишет «Спецификация»; строки — по тексту договора.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>op<TAB>input<TAB>expect<TAB>note`.
Строка тревоги во входе — `{id, class, kind, subsystem, unit, t, t_src}`.

| `op` | Вход → выход |
|---|---|
| `same` | `{a, b}` — две строки → `true` (одна строка по `same_line`) или `false` |
| `page` | `{events}` — строки одной страницы → `id` оставшихся строк по порядку (повтор — первая) |
| `write` | `{now, history, lines}`: `history` — `{events, cut_before}` или `null` (истории нет), `lines` — принятые строки страницы (`t` уже на часах домена) → `{ids, cut_before}` истории после записи: `id` строк по порядку и `cut_before` |

Сравнение — JSON по значению. 9 строк: 5 `same`, 1 `page`, 3 `write` (создание с `cut_before` 0, без повтора по
`same_line`, снятие по неделе и движение `cut_before`).

## Прогон

Без стенда: сторона подаёт вход своим функциям равенства, разбора страницы и записи истории (хранилище и часы подменены
входом). Слияние страницы и истории в выдаче консоли домена — пакет `alarms` урока P/10.
