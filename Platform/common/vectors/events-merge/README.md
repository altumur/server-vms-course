# Векторы: слияние журнала событий

Владелец — [договор слияния журнала событий](../../contracts/events-merge.md) (урок P/06, глава 6.4; ADR-0091 доп. (21) п. 3).
Участники — консоль кластера (`GET /events`, [P/06.4](../../../06-console/spec/06.4-console.norms.md)) и воркер подсистемы,
сливающий журнал сам. Байты пишет «Спецификация»; строки составлены по тексту договора и проверены его оракулом, не кодом
реализаций.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — объект JSON:

| Поле | Значение |
|---|---|
| `participant` | `"console"` или `{"worker": [<sub>…]}` — подсистемы, чьи строки эпох объявлены в `worker.reads` |
| `query` | `{limit?, keep?}` — как у запроса P/05 Н1.3 (умолчания 1000, `newest`); нет — умолчания |
| `policies` | `{<sub>: fenced | earlier-run}` — `older_epochs` манифеста; нет — `fenced` |
| `epochs` | `{<sub>: {<id единицы>: <эпоха>} | "did not answer"}` — что участник прочёл в `<sub>/epoch/*`; у воркера — только объявленные |
| `grant` | области `view` вызывающего консоли — `*`, `unit:<sub>/<id>`, `labels:<метка>[,…]` (договор `may` шаг 7); нет — `["*"]` |
| `units` | `{<sub>/<id>: [<метка>…] \| "@unreadable"}` — метки строк единиц, как прочитаны (поле `labels`, объявленное в `unit.fields`; `"@unreadable"` — строка нечитаема или чтение не подтверждено); единицы нет — меток нет (`[]`) |
| `resources` | `{<сервер>: <ответ ресурса> | "did not answer" | "silent" | {"said": <state>}}` — живые ресурсы и их исходы; ответ — `{events, state, truncated, partial?, lines_garbled?}` P/05 Н1.3 |

**Выход** — ответ договора `{events, state, truncated, partial?, lines_garbled?, complete, incomplete, withheld?}`. `expect` — подмножество:
`events` — массив строк в порядке выдачи, у каждой сравниваются перечисленные поля (`id`, `epoch_is`, `fenced`; `"@absent"` —
поля нет); прочие ключи — по значению JSON (`"@absent"` — ключа нет).

23 строки: 13 консоли (5 — фильтр видимости: грант по меткам и нечитаемая единица — строка скрыта, `withheld` с ней; грант на
единицу и на `*` — видна, `withheld` нет; метки по `of`; метки `[]` — скрыта без `withheld`; C06-EVENTS-LABEL-SOURCE-138-07), 4
воркера, 3 общих (`limit`/`keep`, равное время, `partial`/`lines_garbled`) у консоли и 3 их двойника у воркера (`*-worker`:
слияние воркера — шаги 1–6 договора без фильтра 5а; ACC-VECTORS-CONNECT-03).

## Прогон

Без стенда: сторона подаёт вход своей функции слияния (запросы к ресурсам и чтения эпох подменены входом) и сравнивает вывод
с `expect`. Порядок сегментов `state` при нескольких недоступных ресурсах строки не фиксируют (в строке не больше одного).
Кто исполняет строку — по полю `participant` входа: `"console"` — консоль кластера (профиль `06-console`),
`{"worker": […]}` — воркер, сливающий журнал сам (профиль `03-worker`); чужие строки сторона не исполняет
(ACC-VECTORS-CONNECT-02, решение «Архитектора» 2026-10-26).

## Чего вектор не покрывает

Фильтр видимости консоли (договор, шаг 5а) — строки с `grant` выше; без `grant` вызывающий — с `view` на `*`. Обрезка `limit`
после фильтра с пределом 10000 к ресурсам и чтение самих строк единиц — приёмка и чтение (C06-EVENTS-VIEW-33-01). Свежесть строки двери (пакет [`fresh-age`](../fresh-age/README.md)), `from mirror`, полосы и таймаут, поздний ответ, сверка
строки-доказательства со свежим чтением эпохи — чтением договора; права воркера на `<sub>/epoch/` — P/02.5 и сценарии.
