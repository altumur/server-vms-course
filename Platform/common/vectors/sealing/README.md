# Векторы запечатывания

Векторы [договора запечатывания](../../contracts/sealing.md): путь AAD, конверт `enc:v2`, открытие и файл кольца. Реализация
каждого процесса, который запечатывает или открывает (установщик — `w2cctl secrets`, воркер, консоль, процессы домена),
проходит их своей функцией, без стенда. Ключи и nonce детерминированы: ключ — 32 байта `sha256("w2c test <слово>")`,
nonce — первые 12 байт `sha256("w2c test <слово>")`; в работе nonce — 12 случайных байт, векторы его фиксируют. Слова
порождения таблицы не называют: ключи и nonce зафиксированы в таблицах байтами (`key_hex`, `nonce_b64url`), реализация
берёт их оттуда и заново не порождает (дополнение Kimi к разбору ревью стадии A 6–7, SA67-Б3).

| Файл | Вход → ожидание |
|---|---|
| [`aad.tsv`](aad.tsv) | ключ строки и сегменты пути (JSON-массив: строка — ключ, число — индекс) → JSON Pointer и байты AAD (hex) |
| [`envelope.tsv`](envelope.tsv) | ключ, kid, nonce, ключ строки, путь, значение → конверт `enc:v2`; открытие того же конверта на том же месте — значение |
| [`open.tsv`](open.tsv) | ключ, конверт, ключ строки, путь → значение или `sealed` (конверт не на своём месте, чужой ключ, путь без начального `/`, конверт не по грамматике, испорченный тег); пустой `key_hex` — у кольца нет ключа с kid конверта |
| [`ring.tsv`](ring.tsv) | текст файла кольца (JSON-строка) → `current <kid>; keys <kid>, …` в порядке файла или `unreadable`; у строк `rotate*` ещё `; rotate <kid>` — имя, которое даст `rotate` (`max+1` по числам N), или `; rotate refused` |

Значения в `plaintext`, `expect` (кроме `sealed`) и `file` — JSON-строки (`\n`, `\t`, `﻿` — экранированием JSON).
Векторы получены эталонным AES-256-GCM по договору; при расхождении прав договор, вектор правит «Спецификация».
