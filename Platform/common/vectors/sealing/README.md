# Векторы запечатывания

Векторы [договора запечатывания](../../contracts/sealing.md): путь AAD, конверт `enc:v2`, открытие и файл кольца. Реализация
каждого процесса, который запечатывает или открывает (установщик — `w2cctl secrets`, воркер, консоль, процессы домена),
проходит их своей функцией, без стенда. Ключи и nonce детерминированы: ключ — 32 байта `sha256("w2c test <слово>")`,
nonce — первые 12 байт `sha256("w2c test <слово>")`; в работе nonce — 12 случайных байт, векторы его фиксируют. Слова
порождения таблицы не называют: ключи и nonce зафиксированы в таблицах байтами (`key_hex`, `nonce_b64url`), реализация
берёт их оттуда и заново не порождает (дополнение Kimi к разбору ревью стадии A 6–7, SA67-Б3).

| Файл | Вход → ожидание |
|---|---|
| [`aad.tsv`](aad.tsv) | ключ строки и сегменты пути (JSON-массив: строка — ключ, число — индекс) → JSON Pointer и байты AAD (hex) |
| [`envelope.tsv`](envelope.tsv) | ключ, kid, nonce, ключ строки, путь, значение → конверт `enc:v2`; открытие того же конверта на том же месте — значение |
| [`open.tsv`](open.tsv) | ключ, конверт, ключ строки, путь → значение или `sealed` (конверт не на своём месте, чужой ключ, путь без начального `/`, конверт не по грамматике, неканонический base64url, испорченный тег); пустой `key_hex` — у кольца нет ключа с kid конверта |
| [`reseal.tsv`](reseal.tsv) | кольцо (`k2` текущий, `k1` прежний; ключи — те же байты, что в `ring.tsv`), ключ строки, строка (элементы текстом), json-поля → `row`: `changed` \| `same` \| `skip` и по пути каждого секрета: `{kid, plaintext}` — открыть новый конверт ключом `kid` тем же AAD даёт этот текст (nonce случайный, байты не сравниваются), `@same` — байты те же, `@untouched` — значение байт в байт не тронуто; 11 строк: k1→k2, уже k2, вложенный в json-поле, открытое, пустое, без секретов, enc:v1, не по грамматике, kid нет в кольце, тег не открывается, json-поле не JSON ([договор](../../contracts/sealing.md) «Перезапечатать значение», C06-RESEAL-33-01) |
| [`ring.tsv`](ring.tsv) | текст файла кольца (JSON-строка) → `current <kid>; keys <kid>, …` в порядке файла или `unreadable`; у строк `rotate*` ещё `; rotate <kid>` — имя, которое даст `rotate` (`max+1` по числам N), или `; rotate refused` |

Неверный UTF-8 файла кольца (договор: кольцо нечитаемо) и символьные ссылки (`link`) строкой JSON не выразить — их
проверяет чтение файла. Значения в `plaintext`, `expect` (кроме `sealed`) и `file` — JSON-строки (`\n`, `\t`, `﻿` — экранированием JSON).
Векторы получены эталонным AES-256-GCM по договору; при расхождении прав договор, вектор правит «Спецификация».

Кто исполняет (держатели кольца — P/06.2 Н1.2 `holders`, установщик — P/02.4 Н1.9): `aad.tsv`, `open.tsv` и строки
`ring.tsv`, кроме `rotate*`, — все, кто открывает: установщик (`02-installer`), воркер (`03-worker`), консоль
(`06-console`), процесс `domain` (`08-domain`), агент (`09-agent`); `envelope.tsv` — запечатывающие: установщик,
консоль, процесс `domain` (книга у держателя), агент (ключ члена, строки книг); воркер только открывает (P/03.5);
`reseal.tsv` — консоль (перезапечатывание при старте) и установщик (`w2cctl secrets seal`); строки `rotate*` —
установщик (`w2cctl secrets rotate`) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-26).

## Нативный исход

По общему правилу «Векторы» [общего README приёмки](../../acceptance/README.md) (решение «Архитектора» 2026-10-27); колонки ожидания:
`aad.tsv` — `pointer`, `aad_hex`: объект `{"pointer": …, "aad_hex": …}` (вход — `row_key`, `path`); `envelope.tsv` —
`envelope`: строка JSON конверта (вход — `key_hex`, `kid`, `nonce_b64url`, `row_key`, `pointer`, `plaintext`; открытие того же
конверта — `open.tsv` своей функцией); `open.tsv`, `reseal.tsv`, `ring.tsv` — `expect`: значение JSON, слово (`sealed`,
`unreadable`, строка `current …`) — строкой JSON. `ring.tsv`: вход единой команды `vectors` — `cells` «имя → строка»: у строк
`rotate*` (по имени строки) `{"file": <ячейка>, "rotate": "true"}` (`"true"` — строка, не булево JSON), у прочих
ровно `{"file": <ячейка>}`; исход — код 0 и строка JSON как `expect`; строки `rotate*` исполняет
только установщик (`02-installer`) (ACC-SEALING-RING-ROTATE-01, решение «Архитектора» 2026-10-27).
