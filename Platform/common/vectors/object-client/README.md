# Векторы: клиент хранилища объектов — адрес и исход чтения

Владелец — [договор клиента хранилища объектов](../../contracts/object-client.md) (урок P/05; C10-OBJECT-ADDRESS-32, решение
«Архитектора» 2026-10-25). Участники — процессы платформы, которые пишут и читают объекты. Байты пишет «Спецификация».

## `address.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.
**Вход** — `{OBJECTS, PLATFORM_DIR, SERVER_NAME?, door?}`; `door` — строка двери `platform/doors/<SERVER_NAME>`, как
прочитана при обращении к объектам кластера: объект строки, `null` — строки нет, `"@unreadable"` — не читается по форме,
`"@none"` — хранилище не ответило. **Выход** — `{kind: file | cluster, dir, door?, resource?}`: каталог записи; у
`cluster` — дверь чтения кластера `resource` (явный адрес или `url` строки двери; `"@unknown"` — чтение объектов кластера
«не известно») и `door` — ключ прочитанной строки двери, когда адрес по ней; или `@exit 2` — отказ старта. 15 строк: голый
`file://`, абсолютный и неабсолютный путь, `cluster://` с `resource` (пусто и имя до «?»), иная схема; `resource` пустой,
повторённый, с percent-кодированием (OBJECT135-URL-01); голый `cluster://` и `cluster://<имя>` — дверь по строке двери своего
сервера; строки нет, не читается, хранилище не ответило — `"@unknown"`, не отказ старта; явный `resource` перекрывает строку
двери (P03-OBJECTS-DEFAULT-1FD, решение «Архитектора» 2026-10-26). Векторы проверяют разбор адреса, не соединение: IP в
`resource` (`https://10.0.0.1:8446`) остаётся — клиент своего кластера к такой двери откажет `ip_address` (договор `tls`;
ADR-0075 доп. 2026-10-26 (4) п. 6).

## `read.tsv`

Те же правила файла. **Вход** — `{reply}`: `{status, X-Missing}` ответа `GET /v1/objects/{key}` (`X-Missing` — строка или
`null`) или `"@none"` — дверь не ответила. **Выход** — `"object"`, `"absent"`, `"unknown"` или `"refused"` (договор «Исходы и что
делает клиент»). 8 строк.

## Прогон

Без стенда: сторона подаёт вход своему разбору адреса и разбору ответа (окружение и провод подменены входом). Провод
двери — приёмка урока P/05.
