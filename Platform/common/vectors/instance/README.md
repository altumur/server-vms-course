# Векторы: экземпляр процесса — заданный `INSTANCE_ID`

Владелец — [договор экземпляра процесса](../../contracts/instance.md) (глава P/03.2; INSTANCE54-02, решение «Архитектора»
2026-10-25). Участники — процессы, которые пишут экземпляр (воркер, ресурс, процесс `domain`, писатели журнала событий).
Байты пишет «Спецификация»; строки — по тексту договора.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — `{INSTANCE_ID}`: значение переменной окружения. **Выход** — `{instance}`: экземпляр, как процесс его пишет, или
`@refuse` — отказ старта, код 2. Сравнение — JSON по значению, `instance` — байт в байт.

`cases.tsv`, 5 строк: принят; ведущие нули pid и заглавные hex — как задан; pid из нулей, 5 hex, pid со знаком — отказ.

## `box.tsv` (INSTANCE130-SOURCES-01)

Те же правила файла. **Вход** — `{INSTANCE_ID?, BOX_ID?, machine_id, hostname}`: переменные окружения (нет ключа — не
задана), содержимое `/etc/machine-id` строкой JSON или `"@missing"` (файла нет), `"@error"` (ошибка чтения), hostname
системы строкой. **Выход** — `{box, source}`: коробка и взятый источник (`BOX_ID`, `machine-id`, `hostname`), или `@refuse`
— отказ старта, код 2. 12 строк: BOX_ID; пустые INSTANCE_ID и BOX_ID; BOX_ID не по грамматике — отказ; machine-id — обрезка,
первая строка, нет, ошибка, пусто, не по грамматике → hostname; hostname не годится — отказ «no box name».

## Прогон

Без стенда: сторона подаёт значение своей функции экземпляра (окружение подменено входом). Вычисленная форма (без
`INSTANCE_ID`) зависит от машины — чтением.
Кто исполняет — каждый процесс, чья норма пишет свой экземпляр — обе таблицы: воркер (`03-worker`, P/03.2 Н3 «старт()» шаг 2 — слот, пульс, метка соперника), контроллер (`04-controller`, писатель `audit/<роль>`, `by` строк P/04 Н1.1), ресурс (`05-resource`, писатель `audit/resource`, P/05 Н1.2 `writer`), консоль (`06-console`, P/06.4 Н1.2: `console/<экземпляр>`, `audit/console`), процесс `domain` (`08-domain`, P/08.10 Н1.7 `holder` очереди, P/08.9 `audit/domain`), агент (`09-agent`, P/09.1 Н1.13 `holder` очереди) и консоль домена (`10-domain-console`, журнал событий). Экземпляр воркера в замке присутствия ресурс читает готовым (P/05 Н1.4) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Нативный исход

Отдельного договора команды у пакета нет — общее правило «Векторы» [общего README приёмки](../../acceptance/README.md)
(ACC-VECTORS-CONNECT-04, решение «Архитектора» 2026-10-26): функция отвечает кодом 0 и одним значением JSON. Объект выхода таблицы или строка JSON `"@refuse"`; «отказ старта, код 2» — исход процесса, у функции пакета — `"@refuse"`
с кодом 0.
