# Векторы: экземпляр процесса — заданный `INSTANCE_ID`

Владелец — [договор экземпляра процесса](../../contracts/instance.md) (глава P/03.2; INSTANCE54-02, решение «Архитектора»
2026-10-25). Участники — процессы, которые пишут экземпляр (воркер, ресурс, процесс `domain`, писатели журнала событий).
Байты пишет «Спецификация»; строки — по тексту договора.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — `{INSTANCE_ID}`: значение переменной окружения. **Выход** — `{instance}`: экземпляр, как процесс его пишет, или
`@refuse` — отказ старта, код 2. Сравнение — JSON по значению, `instance` — байт в байт.

5 строк: принят; ведущие нули pid и заглавные hex — как задан; pid из нулей, 5 hex, pid со знаком — отказ.

## Прогон

Без стенда: сторона подаёт значение своей функции экземпляра (окружение подменено входом). Вычисленная форма (без
`INSTANCE_ID`) зависит от машины — чтением.
