# Векторы: состояние ресурса по истории наблюдения

Владелец — [договор наблюдения](../../contracts/observation.md) («Наблюдение версии» с `lapse`, «Свежесть», «Состояние
ресурса»; догадка стадии C OBS-001 (Go), решение «Архитектора» 2026-10-23). Участники — наблюдатели `resource_state`:
контроллер ([P/04](../../../04-controller/spec/04-controller.norms.md) Н3) и консоль (`ServerRow.resource`
[главы 6.5](../../../06-console/spec/06.5-console.norms.md), вывод сервера главы 6.6). Байты пишет «Спецификация».
Граница свежести одна — векторы [`fresh-age`](../fresh-age/README.md); здесь — как возраст и состояние следуют из
истории наблюдения: первый взгляд, повтор той же версии, новая версия, нечитаемое, неответ и подтверждённое отсутствие.

`LOST_AFTER` = 45 с (P/04 Н1.4).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая строка без `#` — заголовок. Пять полей:

| Поле | Значение |
|---|---|
| `case` | имя случая, уникально |
| `history` | массив JSON наблюдений по порядку `[t, источник, исход]`: `t` — секунды монотонных часов наблюдателя от начала его памяти; источник — `pulse` (пульс `platform/resources/<s>/heartbeat`) или `door` (строка `platform/doors/<s>`); исход — метка версии (`v1`, `v2` — одинаковые метки — одна версия), `garbled` (прочитано, не по форме писателя), `noanswer` (хранилище не ответило), `absent` (подтверждённое отсутствие) |
| `at` | момент суждения — секунды тех же часов, не раньше последнего наблюдения |
| `state` | `live`, `unreachable`, `unknown` или `silent` |
| `note` | правило договора |

24 случая: 5 `live`, 7 `unreachable`, 4 `unknown`, 8 `silent`.

## Прогон

Сторона подаёт историю своему наблюдателю (память наблюдения и монотонные часы — подменяемые) и сравнивает состояние в
момент `at`. Что состояние значит для судьбы слота, пула и выдач — у читающих уроков, векторы этого не проверяют.
