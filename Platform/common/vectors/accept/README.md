# Векторы приёма отчёта

Векторы [договора приёма отчёта](../../contracts/accept.md): функция «принять» (`accept`) — поколение, метка, `same`,
`heard`, `ignored`, отказы, дороги. Владелец — урок P/08, глава 8.3 (держатель); участник — ретранслятор (9.2), который
принимает члена той же функцией над своей памятью (разбор ревью стадии A 8–10, № 13 / решение 2; ADR-0083 доп. (13)). Байты
пишет «Спецификация» (ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из входов команды `accept` приёмки
М11/3 (`inputs/accept-*.json`, сц. 13) и
М11/4 (`inputs/accept-*.json`, сц. 06 — дороги) без
изменения байтов; `case` — имя файла входа (номера урока 4 начинаются заново, имена различны), `note` — урок, сценарий и
шаг. Сценарии М11/03 сц. 13 и М11/04 сц. 06 и их входы сняты переносом урока 8 (ADR-0083 доп. (14) п. 17; журнал —
[приёмка главы P/08.3](../../../08-domain/acceptance/3/corrections.tsv)): таблица — единственный источник этих случаев.

## Прогон

Без стенда: функция реализации получает вход (колонка `input`) и даёт вывод; `expect` — подмножество полей вывода по
словарю «Стенда» ([общий README приёмки](../../acceptance/README.md)): `"@absent"` — поля нет, `"@any"` — поле есть с любым
значением. Метка `mark` — по форме [P/08.3](../../../08-domain/spec/08.3-domain.norms.md) Н1.3, её `sha256` — от JCS `stored` (в `accept-05` — нет).

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 35 строк (26 урока 3, 9 урока 4) | `input` — вход команды `accept` текстом JSON (`catalog`, `mark`, `stored`, `body`, `refreshed_ago`; у урока 4 — `via`, `heard_ago`) → `expect`: `generation` (`rev`, `base`, части `whole`), `heard` (`refresh`), `same`, `ignored` или `refused` (`status`, `reason`: `rebase`, `same_sent_at`, `not_ready`, `not_a_publication`, `rev_exhausted`) |

Векторы — входы приёмки, прошедшей у двух реализаций-свидетелей; эталонной пересборкой не проверялись (поколение и метка
опираются на формы [P/09.1](../../../09-agent/spec/09.1-agent.norms.md) Н1.2, P/08.3 Н1.3). При расхождении прав договор, вектор правит «Спецификация».
