# Векторы записи срока и подписи выпускающего

Векторы [договора записи срока](../../contracts/record.md): функция `record(keys, row, виды)` — проверка документа,
подписанного выпускающим ключом держателя (запись срока, документ резервной копии, грант). Владелец — урок P/08, глава 8.8;
функцию исполняют агент члена (9.1), процесс `domain` (8.8) и консоль кластера (6.7, общий документ урока М11/11) (разбор
ревью стадии A 8–10, № 13 / решение 2; ADR-0083 доп. (13)). Байты пишет «Спецификация» (ADR-0083); соответствие продукта —
его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из входов команды `record` приёмки [М11/10](../../../../Source/tests/testdata/acceptance/М11_Domain/10/README.md)
(`inputs/record-*.json`, сц. 05) без изменения байтов; `case` — имя файла входа. До переноса урока 8 приёмка М11/10 идёт по
своим входам; таблица и входы — одни и те же случаи.

## Прогон

Без стенда: функция реализации с тремя видами урока М11/10 получает вход (колонка `input`) и даёт вывод; `expect` —
подмножество полей вывода или `@exit 2` (вход не по форме М11/10 Н5 `exit`: доверенный набор `keys` не по форме). Подпись
самого набора функция не проверяет: набор доверенный (М11/10 Н5).

## Ключи

Ключи выпускающего и набор — байтами во входах (`keys.issuing`, `doc.issuer`); зёрна — README приёмки М11/10.

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок; `note` — сценарий и шаг
приёмки.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 17 строк: 3 `ok`, 13 отказов, 1 `@exit 2` | `input` — вход команды `record` текстом JSON (`keys` — документ набора, `row` — `{doc}` как прочитана) → `expect`: `{"result":"ok","term":…,"holder":…}` (запись срока, восстановленный срок, документ резервной копии) или `{"result":"refused","reason":<слово>}`: `another_domain`, `revoked_issuer`, `unknown_issuer`, `bad_signature` (`kid` ≠ `issuer`, подмена записи, документа резервной копии, гранта), `not_a_record` (не строка, лишнее поле, общий документ урока 11, `holder` документа резервной копии, повтор в `members` и `ca`); `@exit 2` — `keys` не набор |

Векторы проверены эталонными Ed25519 (RFC 8032) и JCS (RFC 8785) по тексту договора (подписи и шаги 2–5), не по коду
реализаций; при расхождении прав договор, вектор правит «Спецификация».
