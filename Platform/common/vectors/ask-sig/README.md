# Векторы подписи просьбы

Векторы [договора подписи просьбы](../../contracts/ask-sig.md): функция `ask-sig` — проверка заголовков `X-W2C-Member`,
`X-W2C-Time`, `X-W2C-Signature` у просьб `backup` и `prepare`. Владелец — урок P/08, глава 8.8; проверяют консоль кластера
(6.7, `GET /api/backup`) и процесс `domain` цели (8.8, `POST /api/prepare`) (разбор ревью стадии A 8–10, № 13 / решение 2;
ADR-0083 доп. (13)). Байты пишет «Спецификация» (ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080
доп. 16).

Строки переложены из входов команды `ask-sig` приёмки [М11/10](../../../../Source/tests/testdata/acceptance/М11_Domain/10/README.md)
(`inputs/ask-sig-*.json`, сц. 07) без изменения байтов; `case` — имя файла входа. До переноса урока 8 приёмка М11/10 идёт по
своим входам; таблица и входы — одни и те же случаи.

## Прогон

Без стенда: функция реализации получает вход (колонка `input`) и даёт исход (колонка `expect`) или `@exit 2` (вход не по
форме М11/10 Н5 `exit`); сравнение — подмножество полей вывода, как у прочих доменных пакетов (чтение коммитов «cammeta-acceptance» 2026-10-20). Время — входом `now`, не часами процесса.

## Ключи

Ключ члена `m1` — `b7b1b2708888b80495bdee35906cdbf0143b649eb92b6cf1f95d8108a3533b62` (зерно `sha256("w2c test member m1")`);
ключ токенов `t1` — `dc8561d3f7f3a8f7fd68636f4762ed842dfbceb256c56f0707ed3b1ee41b9d8f`; чужой ключ — члена `m2`
`88cae557b9e5d4285769289b5af9d27cfdee0092823f38993912feae4b0c92c7`.

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок; `note` — сценарий и шаг
приёмки.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 12 строк: 3 `ok`, 8 отказов, 1 `@exit 2` | `input` — вход команды `ask-sig` текстом JSON → `expect`: `{"result":"ok"}` (`backup`, `prepare`, граница окна 300 с) или `{"result":"refused","reason":<слово>}`: `missing` (нет подписи), `bad_time` (без дроби, одна цифра дроби), `skew` (301 с в прошлое и в будущее), `bad_signature` (чужой ключ, другой кластер в сообщении, `prepare` чужим ключом); `@exit 2` — `pub` не hex |

Векторы проверены эталонным Ed25519 (RFC 8032) по тексту договора, не по коду реализаций; при расхождении прав договор,
вектор правит «Спецификация».
