# Векторы: группа единицы по хосту адреса (`cut_at: host`)

Владелец — урок P/04 через [договор группы по хосту](../../contracts/group-of.md) ([нормы](../../../04-controller/spec/04-controller.norms.md) Н1.3 `group_by`, `cut_at: host`; ADR-0053; разбор адреса —
`schemes` P/02.1 Н1.2а). Участники — `<s>controller` (группа единицы при размещении) и `<s>worker` (штамп `group` просьбы и вызов на группу, P/03.6); перенесено из `04-controller/vectors/group-of` байт в байт (W03-GROUP-01). Байты пишет «Спецификация»; перенесено
из `Source/tests/testdata/group_of.tsv` (стадия B, перенос урока 6, решение «Архитектора» по В8 плана урока 6). Шапка
`cases.tsv` перенесена байт в байт и называет прежние адреса: М10/3 Н4 — ныне P/06.1 Н4, М10/7 Н1.1а — P/06.2 Н1.1а,
`fault.tsv` — пакет [`fault`](../fault/README.md).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` — пояснения (объявление поля `source` со схемами и правила разбора — в шапке файла,
они часть пакета), пустые пропускаются. Заголовка нет; три поля: адрес (как в строке единицы), группа (хост в одной записи)
и отказ (`bad_url` или пусто). Пустая группа без отказа — единица не в группе. Сравнение — по байтам. Строка с пустой первой ячейкой (начинается с TAB) —
пустое значение поля: `<none>`, отказа нет (GO-EMPTY-01).

## Команда стенда `group-of`

Ключ `stand` профилей `03-worker` и `04-controller` (раздел «Раскладка по процессам» [общего README
приёмки](../../acceptance/README.md)), по общему правилу команд векторов: шаблон с `{input}` — путь файла, в который раннер
пишет байты ячейки адреса (первое поле строки) как есть; stdout — `{"group": <ключ группы или "">, "fault": <"bad_url" или
"">}` и LF, `<none>` таблицы — `""`; сравнение — JSON по значению; код 0 — вычислено, 2 — вход не по форме, stdout пуст.
Пустой адрес — по форме; нечитаемый адрес — код 0 с `fault: "bad_url"`; не по форме — только неверный UTF-8 (код 2,
stdout пуст; догадка стадии C W03-G06, решение «Архитектора» 2026-10-23) (догадка стадии C C04-VECTOR-01, решение «Архитектора» 2026-10-23).
