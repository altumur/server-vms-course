# Векторы: ключ резервной копии домена

Владелец — [договор ключа резервной копии домена](../../contracts/domain-backup-key.md) (догадка стадии C I02-BACKUP-HMAC,
решение «Архитектора» 2026-10-23). Участники — установщик (P/02.4 Н3 «установка домена» шаг 8) и процесс `domain`
держателя (P/08.8 Н1.5). Байты пишет «Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая непропущенная — заголовок
`case<TAB>root_key<TAB>backup_key_rev<TAB>expect<TAB>note`.

| Поле | Значение |
|---|---|
| `case` | имя строки |
| `root_key` | hex 32 байт — `root_key` файла восстановления |
| `backup_key_rev` | запись `backup_key_rev` как пришла (текст) |
| `expect` | ключ — hex 32 байт строчными; `@refuse` — `backup_key_rev` не целое ≥ 1 без ведущих нулей: ключа нет |
| `note` | правило |

## Прогон

Сторона выводит ключ своим кодом из `root_key` и `backup_key_rev` и сравнивает с `expect`, либо отказ при `@refuse`.
