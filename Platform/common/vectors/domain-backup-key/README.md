# Векторы: ключ резервной копии домена

Владелец — [договор ключа резервной копии домена](../../contracts/domain-backup-key.md) (догадки стадии C I02-BACKUP-HMAC,
DBK-G01/G02, решение «Архитектора» 2026-10-23). Участники — установщик (P/02.4 Н3 «установка домена» шаг 8) и процесс `domain`
держателя (P/08.8 Н1.5). Байты пишет «Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая непропущенная — заголовок
`case<TAB>root_key<TAB>backup_key_rev<TAB>expect<TAB>note`.

| Поле | Значение |
|---|---|
| `case` | имя строки |
| `root_key` | запись `root_key` как пришла (текст): 64 знака hex, регистр A–F при чтении допустим |
| `backup_key_rev` | запись `backup_key_rev` как пришла (текст) |
| `expect` | ключ — hex 32 байт строчными; `@refuse` — вход вне области функции (`backup_key_rev` не pos53 `[1-9][0-9]*` ≤ 2^53 − 1, `root_key` не 64 знака hex): отказ вывода |
| `note` | правило |

## Прогон

Сторона выводит ключ своим кодом из `root_key` и `backup_key_rev` и сравнивает с `expect`, либо отказ при `@refuse`.
Кто исполняет — установщик (`02-installer`, команда «установка домена» P/02.4 Н3: ключ при `backup_key_rev` 1, шаг 4 договора основания домена) и процесс `domain` держателя (`08-domain`, P/08.8 Н1.5 `backup_key`: запечатывание и чтение копии по её `backup_key_rev`) — все строки. Только читают готовое, ключа не выводят: агент хранителя (`09-agent`, P/09.1 Н3 «проверить резервную копию») и консоль кластера (`06-console`, `GET /api/backup` как прочитано, P/06.7) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Нативный исход

Отдельного договора команды у пакета нет — общее правило «Векторы» [общего README приёмки](../../acceptance/README.md)
(ACC-VECTORS-CONNECT-04, решение «Архитектора» 2026-10-26): функция отвечает кодом 0 и одним значением JSON. Ключ — строка JSON с hex (`"<64 hex>"`), отказ вывода — строка JSON `"@refuse"`.
