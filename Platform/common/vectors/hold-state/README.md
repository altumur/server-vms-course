# Векторы: действующее удержание места

Владелец — [договор наблюдения](../../contracts/observation.md) «Удержание места» (догадка стадии C C06-WHERE-PLACE-HOLD-33-01,
решение «Архитектора» 2026-10-25). Участники — консоль (`/where/<table>/<place>`, [P/06.5](../../../06-console/spec/06.5-console.norms.md)
Н3) и берущий место воркер ([P/03.2](../../../03-worker/spec/03.2-worker.norms.md) Н3 «взять_место»: то же отношение к
`LOST_AFTER + HOLD_SKEW`). Байты пишет «Спецификация»; строки — по тексту договора.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

| Поле входа | Значение |
|---|---|
| `hold` | строка `<sub>/holds/<place>` по форме (P/03.2 Н1.3): `{by, holder, released, gen}`, или `null` — строки нет |
| `hold_age` | возраст наблюдаемой версии строки удержания на монотонных часах наблюдателя, секунды |
| `heartbeat` | пульс воркера `by` (`{worker, instance}`) или `null` — пульса нет |
| `heartbeat_age` | возраст наблюдаемой версии пульса, секунды |

**Выход** — `{"active": true | false}`. 10 строк: возраст 0, 49.999, 50; пульс 45 и 45.001; иной экземпляр; `released`; пустой
`holder`; нет пульса; нет строки.

## Прогон

Без стенда: сторона подаёт вход своему суждению «удержание действует» (память наблюдения и часы подменены входом).
Свежесть пульса как граница — пакет [`fresh-age`](../fresh-age/README.md).
