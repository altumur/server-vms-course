# Векторы: счёт `room` и `live`

Владелец — [договор замка присутствия](../../contracts/presence-lock.md) «Счёт `room`» (догадка стадии C PL-EXT-01, решение
«Архитектора» 2026-10-23). Участники — ресурс (пишет `room.<sub>`, `live.<sub>` отметкой двери, P/05 Н1.4) и контроллер
(читает, P/04 Н3 «заказать()», «свободно(s)»). Байты пишет «Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.
`input` — `{prefix, server, HOST_MEMORY_MB, WORKER_MEMORY_MB, locks}`: `slot.prefix` манифеста и `SERVER_NAME` (по ним номер
`n` имени `<prefix>-<сервер>-<n>`; во всех строках `w` и `srv-a`, C61-PREFIX-01), значения файла роли и поле `worker`
каждого живого замка роли (flock занят); `expect` — `{room, live}` строками, как в строке двери.

## Прогон

Сторона считает `room` и `live` своим кодом ресурса по входу, без файлов, и сравнивает с `expect` (JSON по значению).
