## Стенд

Сц. 05 идёт на стенде раннера: [«Стенд кластера из трёх серверов»](../README.md#стенд-кластера-из-трёх-серверов) общего README,
манифесты `testsub` и `testsub2`, зеркало событий включает шаг 6. Прежде оно было учением `@manual` на настоящем кластере; план
этапа 2 — `automatic group scenarios plan (2026-10-30, for people)` (ПРАВИЛА-РАБОТЫ.md § 4).

Сц. 07 и 08 проверяют коробку с systemd, не группу: настоящий тестовый сервер с юнитами платформы
([P/02.4](../../../../02-installer/ru/spec/02.4-installer.norms.md) N1.1). Учения оператор прогоняет по журналу учений, раннер шаги
`@manual` только печатает ([словарь директив](../README.md#словарь-директив-и-дверей)): в итог они не входят, не зелёные и не
красные, PASS от печати не получают. Журнал оператора обязан назвать предусловия N3 норм, исходы и ограничения.

## Сценарии

Для `recover` (теперь сц. 18 приёмки P/01.3) обязательны изоляция прежней группы, сохранённые исходники и
достоверный upper; отсутствие любого условия означает отказ до изменений, в том числе с `force`. Одна доступная копия не
доказывает полный restore событий.

## Сц. 05 — выдернуть питание

Сц. 05 выдёргивает питание одного сервера, смотрит переезд и копии, затем возвращает сервер. Нормы-владельцы — P/01.3 N1.3 `join`, P/03.2 N1.5 и N3 «захватить», P/04 N1.3 `home`, N1.4a и N3, P/05 N1.4 и N1.6, договор наблюдения `resource_state` и договор слияния.

Стенд задаёт имя каждому процессу (`@start worker <имя>`); выбор свободного имени безымянным процессом — приёмка главы P/03.2.

Объявленный home допускает автоматический возврат в HOME_BUDGET; без home возврат сервера сам по себе не вызывает
перебалансировки (проверка класса ошибок R37, Codex).

### Сроки

Сроки 45/90 с нормы — профиль учения исправного стенда с заранее наблюдёнными пульсами, доступным хранилищем и ёмкостью, не
общий deadline (P/04 N1.4a `moves`); сценарий судит только верхнюю границу. Нижней границы переезда шаги не утверждают.
`t = 0` — `ok` директивы `@power-pull`.

`silent` ресурса сам ничего не двигает. N3 «уходит» срабатывает на нём только при `requires: resource` и живом воркере
(решение «Архитектора» 2026-10-31). `move` у молчащего ресурса не зависит от единиц, слот не отдан.

### Исполнимость

Сц. 05 **пока не исполним**: директивы и двери раздела у раннера есть (цель `system/05-power-pull`, только по имени), но сухого прогона реализацией не было. Правило плана
«Сухой прогон до выпуска»: в выпуск раннера сценарий идёт только после прогона против реализации, каждый красный шаг разбирается
вопросом «норма или данные» до выпуска. Новые сценарии входят в пин линий только выпуском раннера. Сборка хранилища `box`
сценарий не исполняет (общий README).

## Границы сценариев

Сц. 05 — граница общего README: каждый запуск получает новые каталоги и порты всех трёх серверов. Учения 07, 08 исполняются на настоящей коробке и границ раннера не имеют: каждое — на своей тестовой коробке, исходные каталоги сохранены до начала.
