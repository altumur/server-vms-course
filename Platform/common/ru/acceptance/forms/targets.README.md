# Реестр целей приёмки

Этот русский текст — производный от `acceptance/forms/targets.README.md`, руками не правится (ADR-0121).

[`targets.tsv`](../../../acceptance/forms/targets.tsv) — реестр целей приёмки. Форма едина для всех уроков. Сначала заполнены строки P/01, с теми же ячейками, что у их строк в [`runner-targets.tsv`](../../../acceptance/runner-targets.tsv); цели остальных уроков пока есть только в той таблице. Строка `P/01/production` есть только здесь: в той таблице её нет.

## Форма таблицы

UTF-8, строки по физическим LF, ячейки разделены TAB. Первая строка — заголовок:

```text
id\towner\tstand_commands\tstand_addresses\tkeys\trequirements\tnorm_anchors\tflags
```

`id` и `owner` — строки; все остальные ячейки — компактные значения JSON. `id` уникален.

| Столбец | Смысл |
|---|---|
| `id` | Имя цели: область договора, а не выбор реализации или входов. |
| `owner` | Модуль, отвечающий за цель. |
| `stand_commands`, `stand_addresses`, `keys`, `requirements`, `norm_anchors` | Те же формы и смысл ячеек, что у одноимённых столбцов в [требованиях к целям](../runner-targets.README.md). |
| `flags` | JSON-массив слов-флагов из закрытого списка ниже; пустой, если флагов нет. |

| Флаг | Смысл |
|---|---|
| `optional` | Профиль, не объявивший интерфейс цели, оставляет цель неисполненной. Без этого флага отсутствующий интерфейс блокирует цель. У `P/01/production` флаг относится только к функциональному вердикту (N6.1 норм судьи). |

Эти столбцы не добавляют поля профиля, команды, подстановки, адреса или параметра.
