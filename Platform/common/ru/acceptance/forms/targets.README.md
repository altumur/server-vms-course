# Реестр целей приёмки

Этот русский текст — производный от `acceptance/forms/targets.README.md`, руками не правится (ADR-0121).

[`targets.tsv`](../../../acceptance/forms/targets.tsv) — реестр целей приёмки. Форма едина для всех уроков. Заполнены строки P/01 и P/02, с теми же ячейками, что у их строк в [`runner-targets.tsv`](../../../acceptance/runner-targets.tsv); цели остальных уроков пока есть только в той таблице. Строки `P/01/production`, `P/02.1/seams`, `P/02.4/seams` и `P/02.5/variants` есть только здесь: в той таблице их нет. В строке маршрута одно слово движка, поэтому швы P/02.1 и P/02.4 и варианты прав P/02.5 — отдельные цели рядом с вердиктами P/02.1 и сценариями P/02.5. У P/02 `P/02/vectors-canonical` и `P/02/vectors-workers-script` — это строки `P/02.2/vectors` и `P/02.4/vectors` той таблицы, названные по своим пакетам, как остальные `P/02/vectors-*`; условие `rights_check` строки `P/02.5/rights` той таблицы здесь стоит у `P/02.5/variants`: её `check.tsv` вызывает `stand.rights-check`. Строка `P/02.1/put` той таблицы — не цель: у P/02.1 нет выборки через установку ([приёмка P/02.1](../../../../02-installer/ru/acceptance/1/README.md#выборки-установки-нет)).

## Форма таблицы

UTF-8, строки по физическим LF, ячейки разделены TAB. Первая строка — заголовок, столбцы читаются по его именам ([шапка таблицы и столбцы по имени](../README.md#шапка-таблицы-и-столбцы-по-имени)):

```text
id\towner\tstand_commands\tstand_addresses\tkeys\trequirements\tnorm_anchors\tflags
```

`id` и `owner` — строки; все остальные ячейки — компактные значения JSON. `id` уникален.

| Столбец | Смысл |
|---|---|
| `id` | Имя цели: область договора, а не выбор реализации или входов. |
| `owner` | Модуль, отвечающий за цель. |
| `stand_commands`, `stand_addresses`, `keys`, `requirements`, `norm_anchors` | Те же формы и смысл ячеек, что у одноимённых столбцов в [требованиях к целям](../runner-targets.README.md). |
| `flags` | JSON-массив слов-флагов из закрытого списка ниже; пустой, если флагов нет. |

| Флаг | Смысл |
|---|---|
| `optional` | Профиль, не объявивший интерфейс цели, оставляет цель неисполненной. Без этого флага отсутствующий интерфейс блокирует цель. У `P/01/production` флаг относится только к функциональному вердикту (N6.1 норм судьи). |

Эти столбцы не добавляют поля профиля, команды, подстановки, адреса или параметра.
