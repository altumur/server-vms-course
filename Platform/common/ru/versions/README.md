Модуль закреплённого [`go.mod`](../../versions/go.mod), который использует главный модуль реализации на Go, берётся только директивой `require` с закреплённой версией и контрольными суммами [`go.sum`](../../versions/go.sum) из кэша модулей, который даёт стенд ([сборка](../acceptance/PROFILE.md#владение-командами-и-результаты-сборки)). В дереве реализации нет копии исходников этих модулей, в её `go.mod` нет директивы `replace` на них, а в корне главного модуля нет каталога `vendor` и файла `go.work`.


## Пины общих модулей кода

Модули [общего перечня кода](../modules.md) используют прямые зависимости того же `go.mod` и хеши `go.sum`. Их пины добавляются после генерации и квалификации модулей. До этого урок-потребитель не готов к генерации; перечень не выдумывает версию и не выбирает коммит.

## Библиотека Raft и граница реализации

Реализация группы Raft P/01 на Go использует прямую зависимость `github.com/hashicorp/raft v1.7.3` из [`go.mod`](../../versions/go.mod), её контрольные суммы — в [`go.sum`](../../versions/go.sum). Модель реализует FSM, ввод-вывод и адаптеры вокруг библиотеки, а не новое ядро консенсуса. Выбор библиотеки не добавляет внешнего протокола платформы.

Адаптеры отвечают за долговечные `LogStore` и `StableStore`, mTLS-идентичность соседей, атомарное применение FSM, время допуска и память повторов, снимки и восстановление, исходы ошибок, отмену и штатную остановку по нормам P/01. Сохранение снимка учитывает договор библиотеки о параллельной работе FSM. Наличие Raft само по себе не доказывает долговечность или боевую готовность; стоимость, замки и поведение при сбоях остаются ответственностью реализации.

[Модуль закреплённой версии](https://raw.githubusercontent.com/hashicorp/raft/v1.7.3/go.mod) объявляет Go 1.20. Нынешние `go 1.22.0` и `toolchain go1.22.10` не меняются. [Выпуск](https://github.com/hashicorp/raft/releases/tag/v1.7.3) и [API FSM](https://raw.githubusercontent.com/hashicorp/raft/v1.7.3/fsm.go) определяют зависимость, а не заменяют нормы платформы. Поставка включает полное замыкание зависимостей времени исполнения, версии модулей, контрольные суммы, лицензии и происхождение; изолированная сборка из кэша модулей стенда проверяется без сети. Эта исходная фиксация не означает выполнение проверки без сети.
