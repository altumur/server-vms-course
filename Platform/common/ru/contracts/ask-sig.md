## Подпись и проверка

Из М11/10 Н3 «ask-sig — подпись просьбы»:

```
message:  backup|<кластер>|<член>|<время>   (просьба резервной копии; ключ члена)
          prepare|<цель>|<время>            (подготовка передачи; ключ токенов current набора)
          move|<кластер>|<время>|<sha256 тела>   (перенос по файлу восстановления; root_key; <sha256 тела> — 64 строчных hex; P/08.8 Н1.8 by_file; C08-MOVE-BY-FILE-01)
time:     X-W2C-Time — десятичная запись стенных секунд с тремя знаками после точки: (0|[1-9][0-9]*)\.[0-9]{3}
signature: X-W2C-Signature — base64url без «=» подписи Ed25519 над UTF-8(message)
check:    по порядку: заголовка нет или он пуст — missing (prepare и move — X-W2C-Time, X-W2C-Signature; backup — ещё
          X-W2C-Member; пустой — добавлено сверкой М11, H13);
          время не по форме — bad_time; |now − время| > 300 — skew; подпись не base64url без «=», не 64 байта или не
          сходится — bad_signature; иначе ok
```

`<член>` просьбы `backup` — значение `X-W2C-Member`; `<кластер>` — кластер, у консоли которого просят копию; `<цель>`
просьбы `prepare` — член, которому передают домен (P/08.8 Н1.7 `to`); `<время>` — значение `X-W2C-Time` как пришло.
Форма функции — вход команды `ask-sig` [P/08.8](../../../08-domain/ru/spec/08.8-domain.norms.md) Н5:
`{ask: backup | prepare | move, cluster, pub, header: {member?, time?, signature?}, now, body_sha256?}` → `{result: ok}` |
`{result: refused, reason}`. Поля входа (прочтение М11/10 Н5 и README приёмки М11/10 «Входы»; разбор ревью стадии B
8–10, № 4, Claude S-7):

```yaml
cluster:   <кластер> сообщений backup и move и <цель> сообщения prepare — кластер проверяющего: консоль, у которой просят копию,
           или цель передачи; подпись над другим именем — bad_signature (строка пакета ask-sig-08)
pub:       открытый ключ подписавшего, которому верит проверяющий: ключ члена (backup), ключ токенов current набора (prepare) или root_pub своей domain/root (move)
body_sha256: только у move и обязателен: <sha256 тела> сообщения, 64 строчных hex, считает проверяющий
header:    заголовки X-W2C-Member, X-W2C-Time, X-W2C-Signature без префикса (member, time, signature) как пришли;
           <член> сообщения backup — header.member
member:    поля member на верхнем уровне входа нет: член сообщения — только header.member; вход с полем member —
           лишнее поле, вход не по форме, код 2 (P/08.8 Н5 exit; решение «Архитектора» 2026-10-20 по открытым вопросам разбора ревью стадии B 8–10, вопрос 2; прежде поле допускалось и не читалось)
now:       стенные секунды проверяющего
exit:      0 — вычислено; 2 — вход не по форме; коды выхода — по принципу словаря «Стенда домена» («Коды выхода команд-векторов»: 2 — форма
           доверенного входа, 0 со словом — документ другого кластера; решение «Архитектора» по сверке М11, H14) (копия P/08.8 Н5 exit; аудит раскладки, решение «Архитектора» 2026-10-25, B-14):
           у ask-sig pub не hex 32 байт, cluster не имя кластера, ask не backup | prepare | move, body_sha256 не по форме, нет его у move или есть у другого ask, now не число или нет, нет header,
           header не объект, header.time не строка, лишнее поле в header или во входе — 2
```
