## Грамматика

Файлы окружения (`w2c.env`, `roles/*.env`, файл подсистемы, `configstore.env`) читаются разбором, не
`source`: строка `KEY=VALUE`, `KEY` — `[A-Za-z_][A-Za-z0-9_]*`; необязательный префикс `export `; значение в парных `"…"`
или `'…'` — без кавычек, подстановок нет; пустая строка и строка, чей первый непробельный знак `#`, пропускаются. Иная
строка — отказ запуска с кодом 2 и строкой лога, которая называет файл и номер строки.

На краях (сверка python и go M10/6–11, B19): строки разделяет LF; знак CR в строке, BOM в начале файла, пробел или табуляция до или после
`=` и в имени — строка не по грамматике; `export` — ровно одно слово и один пробел перед `KEY`, `export` без `KEY=` — не по
грамматике; значение без кавычек — всё после `=` до конца строки как есть, без обрезки пробелов, `#` внутри значения —
часть значения, не комментарий; пустое значение (`KEY=`) — пустая строка; непарная кавычка — не по грамматике.

Ещё на краях (догадка стадии C ENV-G01, решение «Архитектора» 2026-10-23): «пробельный» перед `#` комментария — только пробел и табуляция (U+00A0 и прочие — нет);
строка только из пробелов — не по грамматике; знак NUL в строке — не по грамматике; последняя строка без LF принимается;
повтор имени в одном файле — побеждает первое вхождение. Файл — строго UTF-8: строка с неверной последовательностью UTF-8 —
не по грамматике (код 2, строка лога называет файл и номер строки; догадка стадии C ENV-F01, решение «Архитектора»
2026-10-23).

## Файла нет

Для всех файлов окружения (файл роли, `w2c.env`, файл подсистемы, `configstore.env`; путь явный или по умолчанию): файла нет —

(права, ошибка ввода-вывода) — отказ запуска с кодом 2 и строкой лога, которая называет файл (догадка стадии C W03-G07, решение «Архитектора» 2026-10-23).

## Файлы и порядок чтения

Перенесено из [P/02.4](../../../02-installer/ru/spec/02.4-installer.norms.md) N1.2 без изменения (аудит раскладки, решение «Архитектора» 2026-10-25, B-26).

Порядок чтения раннера: значения юнита → файл роли `roles/<W2C_ROLE>.env` → `w2c.env` → файл подсистемы; раньше прочитанное побеждает. Юнит части (`w2c-run.sh part`, P/02.4 N1.9) читает только значения юнита и файл подсистемы `W2C_SUB_ENV` (ADR-0091 доп. (3) п. 2). Каталог `roles/` лежит рядом с `w2c.env` (каталог файла `W2C_ENV`, по умолчанию `/etc/w2c/roles/`); другого места нет. `W2C_ROLE` юнита, который не совпадает с ролью команды раннера (`w2c-run.sh <команда>`, P/02.4 N1.9), — отказ запуска с кодом 2 (сверка python и go M10/6–11, B20); у `w2c-run.sh worker <sub>` роль команды — `<sub>worker`, у `domainworker <sub>` — `<sub>domain`: одна программа в обеих ролях видит окружение одним правилом (ADR-0091 доп. (4), (5); решения «Архитектора» по повторному ревью 2026-10-23).

`W2C_ENV` и `W2C_SUB_ENV` берутся из окружения юнита один раз на проход чтения: тот же ключ в загружаемом файле не
применяется (перенаправления нет), строка журнала без значения, не отказ. `W2C_ROLE` юнита обязательна и равна роли
команды: нет или не равна — отказ старта, код 2 (ENV54-01/02, решение «Архитектора» 2026-10-25). Правило `W2C_ROLE` — у
маршрутов процессов платформенной роли (раннер с файлом роли), не у маршрута части: у части роли нет — `W2C_ROLE` не
требуется и не читается, файл роли и `w2c.env` не читаются; читаются значения юнита и файл `W2C_SUB_ENV` (C02-ENV-PART-99, решение «Архитектора» 2026-10-26).

| `W2C_WALL_OFFSET` | только стенд: сдвиг стенных часов агента, с ([P/09.1](../../../09-agent/ru/spec/09.1-agent.norms.md) «Решает реализация» п. 3; при заданной — громкая строка журнала при старте; решение «Архитектора» по планам переноса 8–10, ADR-0083 доп. (14) п. 13) | не задан (0) | раннер стенда; вне стенда не задаётся |
| `CONFIGSTORE_ID/RAFT/API/GROUP_SIZE/JOIN/FLAGS/TUNING` | демон хранилища | tuning `lan` | `configstore.env` |
| `NOTIFY_SOCKET` | сторож systemd | — | systemd |

**Два имени одной настройки** (`OBJECTS` / `PLATFORM_OBJECTS`, `RESOURCE_ROOT` / `EVENTS`): задано одно — оно; заданы оба
с равными значениями (байт в байт) — оно же; заданы оба с разными — отказ старта, код 2, строка лога называет оба имени, как
прочие неверные значения окружения (молчаливый выбор скрыл бы ошибку раскладки); не задано ни одно — умолчание таблицы
(C10-ENV-PAIR-01, решение Спецификации).

Имя слота — аргумент `%i` или переменная `slot.name_env` ([P/03.2](../../../03-worker/ru/spec/03.2-worker.norms.md) N3 «старт()» шаг 3).

### `CLUSTERS`

Из [P/06.7](../../../06-console/ru/spec/06.7-console.norms.md) N1.4 без изменения (аудит раскладки, решение «Архитектора» 2026-10-25, A-09); читают консоль кластера, процесс `domain`
([P/08.8](../../../08-domain/ru/spec/08.8-domain.norms.md) N1.6–N1.8) и агент ([P/09.1](../../../09-agent/ru/spec/09.1-agent.norms.md) N3 «следовать»). Строка окружения для держателя и первого контакта: адрес прочего члена — `Entry.url` его строки раздела, на десятки тысяч окружения не написать (P/06.7 N1.6; ADR-0113 доп. (1) п. 4).

```yaml
CLUSTERS:     <имя>=<url>[,<имя>=<url>…]; имя — имя члена (P/08.3 N1.1), url — http:// или https:// с хостом, без
              userinfo (`user@`), пути и завершающего «/» (userinfo — добавлено сверкой M11, D6); повтор имени, элемент без
              «=», иной url — значение не читается (503 у консоли, не падение процесса); переменной нет или пусто — пустой список
```

## Константы и юниты

Одно место значений, которые читают юнит установщика и процессы (аудит раскладки, решение «Архитектора» 2026-10-25, A-16, A-17); роль каждой — в уроке.

```yaml
FOR:              300   # с; подмена воркера дольше не подменяет: единицы уходят (роль — P/03.4 N1.2)
HUNG_MOVE_AFTER:  900   # с; возраст наблюдаемой версии слота до предела hung/unsure/wait; переменная HUNG_MOVE_AFTER
                        # окружения контроллера, умолчание 900 (роль — P/04 N1.4)
REACH_BUDGET:     10    # единиц за проход на переезды по достижимости; переменная REACH_BUDGET, умолчание 10 (P/04 N1.4)
SHRINK_AFTER:     300   # с; без нехватки — сокращение (P/04 N3 «нехватка(), заказать(), снять заказ, сократить() — при grows: true»); только у стенда — W2C_SHRINK_AFTER (таблица выше)
watchdog:         WatchdogSec юнита воркера — между FOR и HUNG_MOVE_AFTER: 360 (СЛЕДУЕТ; P/02.4 N1.1); notify — из цикла,
                  не из подмены (P/03.3 N1.2 watchdog)
```
