# Договор хэша пароля: `pbkdf2-sha256`

Текст производный от `contracts/password-hash.md`, руками не правится: источник — английский [`contracts/password-hash.md`](../../contracts/password-hash.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124 доп. (1) п. 4).

Общий договор модуля «Платформа» (ADR-0083 доп. (5), доп. (13): общий алгоритм нескольких процессов — договор, а не копии
в главах; догадка стадии C GP-G06, решение «Архитектора» 2026-10-23). Владелец — глава
[P/08.4](../../../08-domain/ru/spec/08.4-domain.norms.md) (N1.1 `pwhash_secret` строки человека, N1.6 — аварийной учётки).
Участники: процесс `domain` — пишет хэш (люди, аварийная учётка) и проверяет вход людей (P/08.4 N1.2); консоль кластера —
проверяет пароль аварийного входа ([договор сторожевой и передачи](gate-and-pass.md) «Аварийный вход»). Перенесено из P/08.4
N1.1 без изменения поведения.

Нормативные слова — по [канону курса](../../../../ru/NORMATIVE-TERMS.md).

`PBKDF2_ITERATIONS` имеет ровно одну привязку: одноимённая строка [формы P/08](../../../08-domain/forms/runtime-constants.tsv). В `form` метапеременная `<PBKDF2_ITERATIONS>` разворачивается только в значение этой строки десятичными ASCII-цифрами без ведущих нулей; операнд `hash` использует то же значение. Скобки и имя не передаются по проводу; другого числа итераций, alias, настройки или дополнительного принимаемого формата нет.

```yaml
form:     pbkdf2-sha256$<PBKDF2_ITERATIONS>$<соль: 32 строчных hex>$<ключ: 64 строчных hex>
hash:     ключ = PBKDF2-HMAC-SHA256(пароль — байты UTF-8, соль — 16 случайных байт, PBKDF2_ITERATIONS итераций, длина 32 байта);
          писатель пишет hex строчными
verify:   строка по form — вычислить ключ от пароля и соли строки и сравнить с ключом строки за постоянное время: равны —
          пароль подходит; строка не по form (иной алгоритм или число итераций, hex заглавными, иная длина, лишняя часть,
          пустая строка) — пароль не подходит, не ошибка
secret:   в строке хранилища поле *_secret запечатано кольцом держателя (договор запечатывания); хэш — у открытого значения
```

## Форма

`pwhash_secret` — поле строк человека и аварийной учётки: `Platform/08-domain/data/users.schema.json`, `Platform/08-domain/data/users.outcomes.tsv`; `Platform/08-domain/data/break-glass.schema.json`, `Platform/08-domain/data/break-glass.outcomes.tsv` (аудит раскладки, V-41; решение «Архитектора» 2026-10-25).
