# Оценщик прав

Текст производный от `contracts/rights-evaluator.md`, руками не правится: источник — английский [`contracts/rights-evaluator.md`](../../contracts/rights-evaluator.md), правка идёт в него, русский пересобирается переводом.

Оценщик вычисляет право роли выполнить одно действие над одним ключом по загруженному файлу прав. Действия — `read`, `write` и `delete`; у каждого действия свой список образцов. Отсутствующий `delete` — пустой список: удалять нельзя. Оценщик не выводит `delete` из `write`.

## Образцы

Точный образец совпадает с равным ему ключом. `*` последним знаком делает образец префиксом; `*` не последним — буквальный знак. `!` только первым знаком делает образец отрицанием; `!` не первым — буквальный знак. Образец после начального `!` использует то же правило точного совпадения или префикса. Отрицание побеждает независимо от места в списке.

Строки `""`, `"!"`, `"!*"`, `"p/!x"` и `"a*b"` — допустимые образцы. `""` совпадает только с пустым ключом; `"!"` отрицает пустой ключ; `"!*"` отрицает всё. Конечная звёздочка после буквальной остаётся префиксом: `a**` совпадает с ключами, начинающимися с `a*`.

## Вычисление

Для `allowed(role, action, key)`, где `action` — одно из `read`, `write`, `delete`:

1. Роль отсутствует в файле: deny.
2. Любой отрицательный образец роли для действия совпал: deny.
3. Любой положительный образец роли для действия совпал: allow.
4. Иначе: deny.

Результат — `allow` или `deny`. Хранилище применяет проверки личности, правила `never` и исключения для admin и внутренних ролей по [P/01.2](../../../01-store/ru/spec/01.2-store.norms.md#n13-оценщик); они вне оценщика образцов.
