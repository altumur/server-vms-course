# Общие модули кода

Русский текст — производный от `modules.md`, руками не правится; перевод английского источника для человека, вне выгрузки.

Урок использует общий модуль кода для функции, которую вызывает его договор. Общий модуль генерируется один раз по договорам и приёмочным входам ниже. Остальные общие договоры задают общее поведение через векторы; они не требуют ещё одного общего модуля кода.

Имя пакета в приёмочных входах выбирает его существующие таблицы и протокол через [consumers.tsv](../vectors/consumers.tsv) и [wire.tsv](../vectors/wire.tsv). Ресурс и контроллер не потребляют векторы JCS. Библиотека байтов JS `07-console-module` вызывает публичные двери консоли; она не потребитель этих модулей Go и не имеет назначенных общих векторов.

## Пины и использование

Место пина каждого модуля Go из перечня — прямой `require` в [versions/go.mod](../versions/go.mod); хеши содержимого — в [versions/go.sum](../versions/go.sum). Версия указывает точный коммит сгенерированного модуля, хеши указывают его байты. Модуль без сгенерированного и прошедшего квалификацию пина не готов к генерации урока-потребителя. Версии-заглушки и подмены локальной копией нет.

У урока-потребителя Go есть строка `requires_module` с точным путём модуля из перечня и `from`, равным `Platform/common/versions/go.mod`. Имя строки в профиле указывает пакет урока, вызывающий общий модуль. Реализация импортирует и использует его по существующему [правилу зависимостей](versions/README.md); пустой импорт, скопированные исходники, `replace`, `vendor` и `go.work` правило не выполняют. Поведение, выбор отказа и пределы остаются по договору вызывающего.

Строка `forbid_imports` урока исключает прямые импорты `encoding/json` в его главном модуле, поэтому разбор и кодирование JSON проходят через общий модуль `json`. Проверка охватывает каждый нетестовый пакет, включая команды и пакеты вне пакета, указанного строкой. Зависимости общего модуля находятся вне главного модуля урока. Остальные библиотеки доступны для функций вне этих общих договоров; исключение для запрещённого импорта явно указывается в `allow` и обосновывается нормой в той же строке. Определения проверок кода — [общий словарь](../acceptance/forms/code-rules.tsv).

## Договоры во входе урока

Вход модели урока N включает каждый договор предыдущего урока, на который опирается: двери и OpenAPI, формы, схемы и интерфейсы клиентских векторов. Эти файлы целиком выбираются таблицей зависимостей README урока и собранными списками выгрузки как публичные файлы. Зависимости этих файлов тоже входят. `forms/export.json` урока классифицирует только собственные файлы; файлы другого урока ему не принадлежат. Общие модули кода дают реализации своих договоров; код реализации предыдущих уроков во вход не входит. Входы сценариев и ожидаемые векторы остаются вне входа модели.
