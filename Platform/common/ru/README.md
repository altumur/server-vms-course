## Код реализации

Пиши код реализации без пояснительных комментариев. Короткая метка требования необязательна и допустима только в месте реализации указанного правила; используй точный ID существующего якоря требования. Не придумывай ID меток или отдельную нумерацию. Приёмка и судьи комментариев не требуют.
