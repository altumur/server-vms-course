# Векторы: файл `crl.pem`

Текст производный от `vectors/crl/README.md`, руками не правится: источник — английский [`vectors/crl/README.md`](../../../vectors/crl/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124 доп. (1) п. 4).

Владелец — общий [договор сертификата роли](../../contracts/role-certificate.md) `revoke` (`crl`, `both`, `absent`;
догадки стадии C RC-02, S03, RC-05 и RC-06, решение «Архитектора» 2026-10-23). Участники — те же двери, что у пакета
[`revoked`](../revoked/README.md). Байты пишет «Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

| Поле | Значение |
|---|---|
| `case` | имя строки |
| `input` | JSON-объект: `ca` — содержимое `ca.pem` (PEM), `ca_next` — `ca.next.pem` или `null`, `crl` — содержимое `crl.pem`, `now` — секунды Unix |
| `expect` | `@bad` — файл неверен (договор `crl`): отказ закрыт; иначе JSON-объект: `ca`, `ca_next` — серийники, отозванные у листов этого центра (каноническая запись пакета `revoked`: строчные hex без ведущих нулей, по возрастанию значения; `[]` — блока этого центра нет; `ca_next` — `null`, когда нет `ca.next.pem`), `stale` — центры, чей блок без `nextUpdate`, с `nextUpdate` раньше `now` или с `thisUpdate` позже `now` более чем на 60 с: по каждому строка лога и счёт, список действует; центры в списке идут в порядке `ca`, `ca_next` |
| `note` | правило |

## Прогон

Сторона читает `crl` своим кодом при центрах `ca`, `ca_next` и времени `now`, без TLS, и сравнивает по каждому центру
множество отозванных серийников листов этого центра и множество центров со строкой лога о сроке с `expect` либо отказ
файла с `@bad`. Серийник сверяется только с CRL издателя листа: лист другого центра с тем же серийником
не отозван.
Кто исполняет — каждая роль, чья дверь или клиент проверяет отзыв (`revoke` договора сертификата роли): двери — хранилище (`01-store`, P/01.3 N1.6), воркер (`03-worker`, дверь процесса P/03.4 N1.7 и дверь на домене P/03.7 N1.6), ресурс (`05-resource`, допуск к дверям P/05), процесс `domain` (`08-domain`, слушатель `SIGNER_URL`, P/08.0 N1.6), консоль домена (`10-domain-console`, дверь роли P/10 N1.4); клиенты своего кластера (`own_client`: peer, затем отзыв) — установщик (`02-installer`, скрипт воркеров P/02.4 N1.6), контроллер (`04-controller`, клиент двери ресурса — договор клиента объектов, как у пакета `loopback`), ресурс (`05-resource`, двери соседей), консоль (`06-console`, P/06.7 N1.4, N1.8; клиент двери ресурса), агент (`09-agent`, P/09.1), консоль домена (`10-domain-console`, P/10 N1.3) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Провод векторов

Провод таблиц `cases.tsv` задают строки `common/crl` в [единой форме](../../../vectors/wire.tsv); [грамматика](../wire.md). Форма — источник шапки, выбранных входов, фикстур, нативного исхода и сравнения. Смысл алгоритма и обязанность потребителя остаются здесь.
