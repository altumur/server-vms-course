# Векторы права по грантам

Текст производный от `vectors/may/README.md`, руками не правится: источник — английский [`vectors/may/README.md`](../../../vectors/may/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124 доп. (1) п. 4).

Векторы [договора права](../../contracts/may.md): функция `may` — право человека по строкам грантов (ранг, область,
срок строки, давность копии, выключенный, аварийная сессия). Владелец — урок P/08, глава 8.4; исполняют сторожевые консоли
кластера ([P/06.3](../../../../06-console/ru/spec/06.3-console.norms.md) N1.3, глава 6.7) и консоли домена (урок 10) и процесс
`domain` (8.4) (решение «Архитектора» 2026-10-20, ADR-0083 доп. (14) п. 1; разбор ревью стадии A 8–10). Байты пишет
«Спецификация» (ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из входов команды `may` приёмки M11/9 (`inputs/may-*.json`, сц. 07) без изменения значений: JSON
входа — одной строкой, порядок ключей и лексемы чисел — как в файле; `case` — имя файла входа. Одно исключение —
`may-24-unit-id-not-grammar`: у единицы входа добавлено `"labels": []` (решение «Архитектора» 2026-10-20): единица
`{sub, id}` без `labels` — сама вход не по форме (`unit` — `{sub, id, labels, about?}`), и `@exit 2` не отличал бы id
области `unit:` не по грамматике от единицы без меток. Сц. 07 приёмки M11/9 и её входы сняты переносом урока 8 (решение
«Архитектора» 2026-10-20, ADR-0083 доп. (14) п. 17): таблица — единственный источник этих случаев; журнал — приёмка главы 8.4 (`corrections-4.tsv` (historical correction record), журнал, в выгрузку не входит).

## Форма входа команды `may`

Нормативная форма входа и смысл кодов выхода определены в [общей форме входа функции](../../contracts/may-input.md#may). Входы случаев и привязки ответов ниже остаются только для судьи.

## `covers`

Нормативные вход, выход и правило покрытия определены в [общей форме covers](../../contracts/may-input.md#covers).

19 строк. Ярусы 1–4 и выбор первого непустого судит группа роли, а не одна область, поэтому они — в [`cases.tsv`](../../../vectors/may/cases.tsv) (may-62…may-92), а не здесь. Первые 9: `unit:` по имени при нечитаемой строке — `true`; `labels:` и грант на about-единицу при нечитаемой — `false`; `*` при
нечитаемой — `true`; при читаемой — метки у самой строки, метки у about, грант на about-единицу — `true`, `unit:` чужой
единицы без about — `false`; область не по грамматике — `@exit 2`. Ещё 10 — `folder:`: у единицы, у about, у подпапки, у папки как объекта, над мёртвой цепочкой, при неизвестном членстве.

## Прогон

Без стенда: функция реализации получает вход (колонка `input`) и даёт вывод; `expect` — подмножество полей вывода (`{"result":"unavailable"}` — третий исход, дверь отвечает 503) или
`@exit 2` (вход не по форме [P/08.4](../../../../08-domain/ru/spec/08.4-domain.norms.md) N5 `exit`: строки `grants` — доверенный вход, строка не по форме — 2, не пропуск). Время —
входом `now`, не часами процесса. Кто исполняет: `cases.tsv` — сторожевые консоли кластера (`06-console`) и домена
(`10-domain-console`) и процесс `domain` (`08-domain`); `covers.tsv` — только `06-console` и `10-domain-console` (запись `vectors` `common/may` или прежняя команда
`covers` общего README приёмки; хватает одной — ACC-VECTORS-COVERS-STAND-01) (ACC-VECTORS-CONNECT-02, решение «Архитектора» 2026-10-26).

## Единицы

`c1` `testsub` с метками `east`, `ground`; `c2` без меток; `t1` `testsub2` с меткой `west` и `about` — `c1`. Папки — id из 32 hex-цифр: `0f…`, `0b…` — корневые, `0a…` — корневая с подпапкой `0c…`. `now` —
1760000000; давность копии — `GRANT_LIFETIME` ([P/08.4](../../../../08-domain/ru/spec/08.4-domain.norms.md) N1.3).

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок; `note` — сценарий и шаг
приёмки.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](../../../vectors/may/cases.tsv), 127 строк: 52 `allow`, 44 `deny`, 7 `unavailable`, 24 `@exit 2` (may-26 — `until` не помещается в binary64, MAY-UNTIL-D8-01; may-27…may-106 — ADR-0097–ADR-0100, сухого прогона реализацией нет) | `input` — вход команды `may` текстом JSON → `expect`: `{"result":"allow"}` (аварийная сессия без грантов, копия ровно суточной давности, строка держателя без `as_of`, `view` без единицы — любая строка, `*`, `unit:` своя и через `about`, `labels:` все метки, метки `about`, ранг выше, срок строки впереди) или `{"result":"deny","reason":<слово>}`: `disabled` (выключенный при гранте), `stale` (копия старше суток), `no_grant` (строки нет, `edit` без единицы не по `*`, чужая единица, одной метки нет, метки самой единицы при `about`, ранг ниже, истёкшая строка, `"*"` не по `*`, строка другого субъекта, единица без меток); `@exit 2` — область `unit:` с id не по грамматике [P/06.1](../../../../06-console/ru/spec/06.1-console.norms.md) N1.3; `subject` "" строки гранта (`may-25`, MAY-G03) |

Векторы проверены оракулом по тексту договора (шаги 1–8) и форме входа [P/08.4](../../../../08-domain/ru/spec/08.4-domain.norms.md) N1.3, N5 `exit`, не по коду реализаций; при
расхождении прав договор, вектор правит «Спецификация».

## Провод векторов

Провод `cases.tsv`, `covers.tsv` задают строки `common/may` [единой формы](../../../vectors/wire.tsv); [грамматика](../wire.md). Форма — источник шапки, выбранных входов, фикстур, кадра нативного ответа и сравнения. Смысл входов и выходов, обязанности потребителей, проверка нативной формы и проверки вне функции остаются здесь. Layout — исключение из вызовов функции, а не доказательство отдельной приёмки.
