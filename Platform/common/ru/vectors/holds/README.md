# Векторы: удерживает ли строка удержания бакет

Текст производный от `vectors/holds/README.md`, руками не правится: источник — английский [`vectors/holds/README.md`](../../../vectors/holds/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124 доп. (1) п. 4).

Владелец — [договор удержаний](../../contracts/holds.md) (владелец договора — урок P/06, [глава 6.4](../../../../06-console/ru/spec/06.4-console.norms.md)
N1.5 `holds`): разделы «Объявление», «Строка удержания», «Что держит строка». Функция пакета — «держит ли строка бакет»
раздела «Векторы» договора (ADR-0083 доп. (37) п. 5). Байты пишет «Спецификация»; строки — по тексту договора.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок
`case<TAB>holds<TAB>types<TAB>row<TAB>bucket<TAB>expect<TAB>note`.

| Поле | Значение |
|---|---|
| `holds` | раздел `holds` манифеста — объект JSON с ключами из `{table, unit, since, until, released, longest}` (P/02.1 N1.2); `null` — раздела нет |
| `types` | типы полей таблицы удержаний `tables.<table>.fields` — объект JSON `{field: type}`, слова типов — как в [`values-by-type`](../values-by-type/README.md) |
| `row` | строка `<M>/<table>/<id>` — объект JSON `{field: element text}` (элемента нет — ключа нет); `@garbled` — строка не раскодировалась как строка таблицы |
| `bucket` | начало бакета, стенные секунды (кратно 600: договор журнала событий `bucket` `span`); отрезок — `[start, start + 600]` |
| `expect` | `{"hold": "held"}` — держит; `{"hold": "not_held"}` — не держит (отпущена, пустое окно, бакет вне окна, раздела нет); `{"hold": "unknown"}` — адресат или окно не прочитаны, объявление неполное или строка не раскодировалась: держит по правилу «не прочитано — держится» («Что держит строка» строки 2–3, «Объявление» `partial`), строка — в `garbled_rows.<table>` пульса ресурса |
| `note` | правило договора |

## Прогон

Без стенда: сторона подаёт объявление, типы полей, строку и отрезок бакета своей функции «держит ли строка бакет» и
сравнивает `hold`. Принадлежность бакета адресату (деревья `<A>`, `<A>.alarms`, удержание «про» по `about.field` и
надгробию) — вне функции: вход — бакет, уже отнесённый к единице, которую называет строка. Кто исполняет — ресурс
(`05-resource`: проход срока, [P/05](../../../../05-resource/ru/spec/05-resource.norms.md) N3 «проход ресурса» `retain`). Консоль
(`06-console`) строки удержаний пишет дверью таблиц (P/06.1 N1.6) и функцию не исполняет; загрузчик (`02-installer`) проверяет
только ссылки раздела (P/02.1 N1.2, ссылки 50–54) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию).

Во входе единой команды `vectors` ([общий README приёмки](../../acceptance/README.md)) `cells` — `holds`, `types`, `row`,
`bucket` (текст ячеек как записан); `files` пуст. Результат — один JSON-объект `{"hold": …}`.

## Чего вектор не покрывает

Перечень строк таблицы и его обрыв (договор «Чтение таблицы»: удержания не прочитаны — `holds_unread`), выбор деревьев
адресата и удержание «про» по `about` (раздел «Объявление» `addressee`, «Что держит строка» строка 1), счёт `garbled_rows`
и причины пульса (P/05 N1.4, N4), сама уборка по сроку (стенд не выдерживает срок бакетов: P/05-06, P/06.4-08 — чтением).
