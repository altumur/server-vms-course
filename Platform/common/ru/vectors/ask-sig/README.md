# Векторы подписи просьбы

Текст производный от en, руками не правится: источник — английский [`en/README.en.md`](en/README.en.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124 доп. (1) п. 4).

Векторы [договора подписи просьбы](../../contracts/ask-sig.md): функция `ask-sig` — проверка заголовков `X-W2C-Member`,
`X-W2C-Time`, `X-W2C-Signature` у просьб `backup`, `prepare` и `move`. Владелец — урок P/08, глава 8.8; проверяют консоль кластера
(6.7, `GET /api/backup`) и процесс `domain` цели (8.8, `POST /api/prepare`) (разбор ревью стадии A 8–10, № 13 / решение 2;
ADR-0083 доп. (13)). Байты пишет «Спецификация» (ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080
доп. 16).

Строки переложены из входов команды `ask-sig` приёмки М11/10
(`inputs/ask-sig-*.json`, сц. 07) без изменения байтов; `case` — имя файла входа. Сценарий 07 приёмки М11/10 и его входы
сняты переносом урока 8 (ADR-0083 доп. (14) п. 17; журнал — приёмка главы P/08.8 (`Platform/08-domain/journal/corrections-8.tsv`, журнал, в выгрузку не входит)):
таблица — единственный источник этих случаев.

## Прогон

Без стенда: функция реализации получает вход (колонка `input`) и даёт исход (колонка `expect`) или `@exit 2` (вход не по
форме [P/08.8](../../../08-domain/ru/spec/08.8-domain.norms.md) Н5 `exit`); сравнение — подмножество полей вывода, как у прочих доменных пакетов (чтение коммитов «cammeta-acceptance» 2026-10-20). Время — входом `now`, не часами процесса.
Кто исполняет — по `ask` входа: `backup` — консоль кластера (`06-console`, `GET /api/backup`); `prepare` — процесс
`domain` цели (`08-domain`, `POST /api/prepare`); `move` — консоль кластера цели и процесс `domain` (ACC-VECTORS-CONNECT-02, решение «Архитектора» 2026-10-26).

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок; `note` — сценарий и шаг
приёмки.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 27 строк: 5 `ok`, 16 отказов, 6 `@exit 2` (строка 13 — поле `member` на верхнем уровне входа, разбор ревью стадии B 8–10, вопрос 2; строки 14–26 — `move`, строка 27 — `backup` с лишним `body_sha256`, C08-MOVE-BY-FILE-01) | `input` — вход команды `ask-sig` текстом JSON → `expect`: `{"result":"ok"}` (`backup`, `prepare`, граница окна 300 с) или `{"result":"refused","reason":<слово>}`: `missing` (нет подписи), `bad_time` (без дроби, одна цифра дроби), `skew` (301 с в прошлое и в будущее), `bad_signature` (чужой ключ, другой кластер в сообщении, `prepare` чужим ключом); `@exit 2` — `pub` не hex |

Векторы проверены эталонным Ed25519 (RFC 8032) по тексту договора, не по коду реализаций; при расхождении прав договор,
вектор правит «Спецификация».
