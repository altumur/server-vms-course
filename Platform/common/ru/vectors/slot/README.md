# Векторы: суждение о строке слота

Текст производный от `vectors/slot/README.md`, руками не правится: источник — английский [`vectors/slot/README.md`](../../../vectors/slot/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124 доп. (1) п. 4).

Владелец — [договор слота](../../contracts/slot.md) (глава P/03.2 N1.4; C140-SLOT-TIME-01, решение «Архитектора» 2026-10-26).
Участники — воркер (захват, продление), контроллер (судья слота), консоль, агент, договор пула. Байты пишет «Спецификация»;
строки — по тексту договора, нормы не меняются.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — `{row, age}`: `row` — элементы строки `<sub>/slots/<name>` текстом (`holder`, `until`, `released`, `gen`), `age` —
возраст наблюдаемой версии на часах судьи, с (договор наблюдения «Наблюдение версии»). **Выход** — `{state}`: `held`, `lapsed`,
`released`, `taking`, `torn`; у `torn` ещё `takeable` — можно ли захватывать по этой версии (gen читается и версия
наблюдается не меньше `TORN_STILL`; P/03.2 исходы `/until`, `/gen`). Сравнение — JSON по значению.

## Прогон

Без стенда: сторона подаёт вход своему суждению о слоте (чтение и часы подменены входом). Переходы (захват, продление,
уход единиц) — сценарии приёмки P/03.2, P/04 и чтение.
Кто исполняет — захват и продление воркера (`03-worker`, P/03.2 N1.4, N3 «захватить») — все строки; контроллер (`04-controller`, P/04 N3 «судьба», «уходит») — поле `state` всех строк, `takeable` нужен только захвату воркера. Не исполняют: консоль (`06-console`) показывает поля строки (`slot_garbled`, `released`, `slot_taking`, P/06.5 N2) без сроков `SLOT_TERM` и `TORN_STILL`; агент (`09-agent`) судит живость слота на члене своим правилом по `until` (P/09.1 N1.2 `liveness`) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

Читаемость gen включает область нынешнего писателя семейства slots. TORN_STILL = SLOT_TERM + TORN_MARGIN по договору slot; самостоятельный запас не подменяется HOLD_SKEW. takeable — условие наблюдаемой версии для порванной строки; полный захват также проверяет исчерпание поколения и все допуски P/03.2.
