# Векторы: проверка схемы при старте

Текст производный от `vectors/schema/README.md`, руками не правится: источник — английский [`vectors/schema/README.md`](../../../vectors/schema/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124 доп. (1) п. 4).

Владелец — [договор схемы](../../contracts/schema.md) (глава P/06.6; C06-SCHEMA-WIDE-32-01, решение «Архитектора»
2026-10-25). Участники — процессы, которые проверяют схему при старте: контроллер, воркер, ресурс, консоль, процессы домена.
Байты пишет «Спецификация»; строки — по тексту договора.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — `{SCHEMA, row}`: `SCHEMA` — нынешний номер сборки, в текущей спецификации и этих векторах 1; `row` — элементы `platform/schema` как текст (`{version, at}`) или `null`, строки нет. Синтетическая положительная поддержка прежнего layout при SCHEMA=3 не требуется.
**Выход** — `{start: true, version}` (старт; версия десятичной строкой) или `{refuse: "too_new", n}` (схема новее; `n` —
точное N десятичной строкой) или `{refuse: "not_a_form"}`. Сравнение — JSON по значению. «Отказ — код 2» — исход
процесса при старте; функция пакета в единой команде `vectors` отвечает кодом 0 и объектом выхода `{refuse…}`
(ACC-VECTORS-CONNECT-04; ACC-SCHEMA-REFUSE-EXIT-01, решение «Архитектора» 2026-10-27).

9 строк: нынешняя 1, ровно SCHEMA, SCHEMA+1, точное 2^63, 0, 1.5, отсутствие строки; конечное binary64 время и переполнение. Положительные запуски используют только нынешнюю схему.

## Прогон

Без стенда: сторона подаёт вход своей функции проверки схемы (чтение строки подменено входом). Ошибка чтения (ждать
доступности) и проверка воркером после продления слота — чтением и сценариями приёмки участников.
Кто исполняет — каждый процесс, чья норма проверяет схему при старте: воркер (`03-worker`, P/03.2 N3 «проверка схемы воркером»), контроллер (`04-controller`, P/04 N3 «старт контроллера — проверка схемы»), ресурс (`05-resource`, P/05 N3 «старт ресурса — проверка схемы»), консоль (`06-console`, P/06.6 N3 «старт консоли — проверка схемы»), процесс `domain` (`08-domain`) и агент (`09-agent`) — по P/02.4 N1.12, консоль домена (`10-domain-console`, P/10 N1.1). Модуль консоли (`07-console-module`) берёт `/schema` готовым (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Провод векторов

Провод `cases.tsv` задают строки `common/schema` [единой формы](../../../vectors/wire.tsv); [грамматика](../wire.md). Форма — источник шапки, выбранных входов, фикстур, кадра нативного ответа и сравнения. Смысл входов и выходов, обязанности потребителей, проверка нативной формы и проверки вне функции остаются здесь. Layout — исключение из вызовов функции, а не доказательство отдельной приёмки.
