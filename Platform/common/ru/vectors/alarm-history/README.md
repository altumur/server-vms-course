## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>op<TAB>input<TAB>expect<TAB>note`.
Строка тревоги во входе — `{id, class, kind, subsystem, unit, t, t_src}`.

| `op` | Вход → выход |
|---|---|
| `same` | `{a, b}` — две строки → `true` (одна строка по `same_line`) или `false` |
| `page` | `{events}` — строки одной страницы → `id` оставшихся строк по порядку (повтор — первая) |
| `write` | `{now, history, lines}`: `history` — `{events, cut_before}` или `null` (истории нет), `lines` — принятые строки страницы (`t` уже на часах домена) → `{ids, cut_before, written}` истории после записи: `id` строк по порядку, `cut_before` и `written` — была ли запись (ничего нового и ничего не снято — `false`, объект прежний) |

## Прогон

Без стенда: сторона подаёт вход своим функциям равенства, разбора страницы и записи истории (хранилище и часы подменены
входом). Слияние страницы и истории в выдаче консоли домена — пакет `alarms` урока P/10.
Кто исполняет — по `op`: `same` — проход держателя (`08-domain`, запись без повторов) и список тревог консоли домена
(`10-domain-console`); `page` — консоль домена (P/10 N3 `alarms` шаг 2); `write` — только проход держателя (договор,
`writer`) (ACC-VECTORS-CONNECT-02, решение «Архитектора» 2026-10-26).
