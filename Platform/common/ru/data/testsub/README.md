# Тестовые подсистемы курса

Текст производный от `data/testsub/README.md`, руками не правится: источник — английский [`data/testsub/README.md`](../../../data/testsub/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124).

Курс владеет каноническими манифестами [`testsub.subsystem.yaml`](../../../data/testsub/testsub.subsystem.yaml) и [`testsub2.subsystem.yaml`](../../../data/testsub/testsub2.subsystem.yaml) здесь (ADR-0083 доп. (115)). Первый — подсистема именованных счётчиков; второй проверяет объявленные ключи платформы. Первоначальные байты точно скопированы из принятого общего среза.

Файлы, оставленные в `Source/tests/testdata/`, — неизменяемые свидетели. Импортированные комментарии описывают происхождение; упоминания копии продукта не создают нынешнего требования синхронизации. Курс меняет эти канонические манифесты независимо и не запускает `sync-course.sh` продукта.

Файлы консоли для стенда установщика остаются существующими данными приёмки P/06.5; этот каталог их не дублирует. Читатели и генераторы используют два точных канонических пути, без запасного чтения свидетелей Source.
