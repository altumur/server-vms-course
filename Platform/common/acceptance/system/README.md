# Системная приёмка модуля «Платформа» — стенд всех процессов

Сквозные сценарии, которые проверяют нормы нескольких микромодулей сразу и требуют стенда из всех процессов платформы
на настоящем кластере ([записка модуля](../../../module-design.md): «сквозные сценарии … со стендом из всех
микромодулей»). Перенесены из приёмки М10/11
(сц. 05, 06; стадия B, ADR-0083 доп. (1): без изменения поведения) по решению «Архитектора» о В2 плана переноса урока 6:
сценарий принадлежит уроку, чью норму проверяет (замок присутствия, сц. 16 М10/11, — приёмка
[P/05](../../../05-resource/acceptance/README.md)), учения многих процессов — сюда. Номера и шаги — прежние.
Три сценария / 9 шагов, все `@manual`; сц. 06 `recover` перенесено сценарием 18 [приёмки P/01.3](../../../01-store/acceptance/3/README.md) на стенд группы хранилища (ПРАВИЛА-РАБОТЫ.md § 4, 2026-10-30); сц. 07 — холодный запуск части и воркера (ADR-0091 доп. (2), (3)), сц. 08 — программа воркера из строки манифеста (ADR-0091 доп. (4)–(6)).

## Стенд

Настоящий тестовый кластер, не стенд раннера: три сервера и больше, на каждом — один набор юнитов платформы
([P/02.4](../../../02-installer/spec/02.4-installer.norms.md) Н1.1: хранилище, ресурс, консоль, контроллеры и воркеры
манифестов), группа хранилища из трёх голосов ([P/01.3](../../../01-store/spec/01.3-store.norms.md) Н1.3), манифесты `testsub` и
`testsub2`, зеркало событий включено. Учения оператор прогоняет по журналу учений (`failover-drill.sh`, `recover`),
раннер шаги `@manual` только печатает ([словарь директив](../README.md#словарь-директив-и-дверей)): в итог они не
входят, не зелёные и не красные, PASS от печати не получают. Журнал оператора обязан назвать предусловия Н3 норм,
исходы и ограничения.

Сроки 45/90 с — профиль учения исправного стенда с заранее наблюдёнными пульсами, доступным хранилищем и ёмкостью, не
общий deadline (P/04 Н1.4а `moves`). Для `recover` (теперь сц. 18 приёмки P/01.3) обязательны изоляция прежней группы, сохранённые исходники и
достоверный upper; отсутствие любого условия означает отказ до изменений, в том числе с `force`. Одна доступная копия не
доказывает полный restore событий.

Объявленный home допускает автоматический возврат в HOME_BUDGET; без home возврат сервера сам по себе не вызывает
перебалансировки (проверка класса ошибок R37, Codex). Это предмет проверки норм/данных и будущего стенда, не выполненное
испытание реализации.

## scenarios.tsv

Формат — [словарь директив и дверей «Стенда» общего README приёмки](../README.md#словарь-директив-и-дверей): только

## Границы сценариев

Учения исполняются на настоящем кластере и границ раннера не имеют: каждое — на своём тестовом кластере, исходные каталоги сохранены до начала.

приёмки М10/11 (сняты переносом урока 6, `e11928b21`), в начале этого журнала по сценариям главы, с прежними путями и номерами (их
разрешает `Platform/common/id-map.tsv`); строки без сценария — во всех главах-наследниках (разбор ревью стадии B 6–7, № 18).
