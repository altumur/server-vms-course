## Стенд

Подготовка — как README приёмки [главы 8.3](../../08-domain/acceptance/3/README.md) («Подготовка каждого сценария», из
М11/03: кластеры `hold`, `m1`, `m2`, каталог `testsub`); у сц. 02 — с объявлением общего в `testsub`, как README приёмки
[главы 8.9](../../08-domain/acceptance/9/README.md):
- `domain.shared: [step, marks, {rounds}]`;
- `step` — `int` с `inherit: 1`;
- `marks` — `list` с `inherit: []`, `merge: union`.

Раннер ходит человеком `root` (первый администратор — глава 8.4, директива `@person`).

- **Сценарий 02.** Агент `m2` выключен дольше `LOST_AFTER`: в доставке он `silent`, в списке тревог — член `silent` и
  строка молчания (шаг 05); окно не по грамматике и `since > until` — 400 (шаги 06, 07). Включённый, он берёт документ,
  и список снова полон (шаги 09, 10).
- **Сценарий 05** — двери страницы держателя (нормы Н1.7). Вызовы модуля в режиме `domain` проверяет тест модуля у его
  владельца ([P/07](../../07-console-module/spec/07-console-module.norms.md) Н1.6), не эта приёмка.
- **Сценарий 06** — вида нет (нормы Н1.2а, Н1.2б, Н1.2в, Н1.2е, Н4 `no domain here`): `@start domain` без `@install domain` —
  процесс `domain` без строки подписанта прохода держателя не ведёт и вида не пишет ([P/08.10](../../08-domain/spec/08.10-domain.norms.md)
  Н1.7 `no_signer`), следов домена в хранилище `hold` нет — сторожевая `open`: раннер звонит с петли без токена, личность —
  `operator` (`@person`: «до домена заголовка нет»; шаг 2 это подтверждает). Каждая дверь вида — 404 `no domain here`;
  у двери строк подсистемы — после проверок манифеста (у `testsub` есть `domain.ref`, `counters` — его строки).
- **Сценарий 07** — вид и тень есть, но не читаются (Н1.2а, Н1.2б, Н1.2е, Н4 `unavailable`): процесс `domain` остановлен
  (единственный писатель `domain/view` и `domain/shadow` — каталог данных), затем объект испорчен `@spoil object` — 503
  `unavailable`, не 404, у `GET /domain`, `/domain/members`, `/domain/testsub/counters`, `/domain/shared`; затем тень — 503
  у `/domain/shadow`. Топологию шаг не спрашивает: её дверь читает строку `domain/topology`, нечитаемого вида Н1.2в не называет.
- **Сценарий 08** — обрыв передачи (Н1.3 `pass`, Н4 «слова договора пересылки `answer`»): процесс `domain` остановлен,
  консоль домена жива; правка (`PUT /domain/topology`) и дверь людей (`GET /domain/users` — передаётся и `GET`, Н1.3а) — 502
  `did not answer` («сеть», [договор пересылки](../../common/contracts/forwarding.md) «Пересылка — одна функция» `answer`);
  своя дверь чтения (`GET /domain`) отвечает. После `@restart domain` и готовности процесса (вход `signer`, как сц. 04 приёмки
  [главы 8.10](../../08-domain/acceptance/10/README.md)) та же правка — 200 `rev: 1`: оборванная не применена.
- **Сценарий 09** — молчание (Н1.3 `pass`): процесс `domain` заморожен (`@on hold @freeze domain`, пауза ≈ срок «Ожидание»
  строки `PUT /domain/topology` — 5 с, предел заморозки 120 с) — 502 `did not answer` (нет ответа за `FORWARD_WAIT`). Правка под
  молчанием — та, что процесс отказал бы (`via: {m1: m1}` — 409 «through itself», P/08.3 Н1.2): прочти он её после `@thaw`,
  записи нет; контроль — правка `base_rev: 0` даёт `rev: 1`. Что 502 приходит не раньше срока — чтением (приёмка не меряет
  время ответа).

Отказ `not in the directory` (манифест без `domain.ref`, Н1.2а) — чтением: у манифестов стенда (`testsub`, `testsub2`)
`domain.ref` есть.

Соседи на стенде: правку общего документа (сц. 02 шаг 03) консоль домена передаёт процессу `domain` (нормы Н1.3;
исполнение — [глава 8.9](../../08-domain/spec/08.9-domain.norms.md) Н1.3); содержимое `delivery` (шаги 04, 09) —
`view.shared` главы 8.9 (Н1.6), дверь `GET /domain/shared` — этот урок (P/10-14); документ берёт агент члена
([глава 9.1](../../09-agent/spec/09.1-agent.norms.md)); шаг 11 — подпись агента у `/events` консоли кластера члена
([договор подписи агента](../../common/contracts/agent-signature.md), сторожевая P/06.3; план урока 10 В6: шаг не дробится).

Страницу тревог (фронт раз в секунду, срочный отчёт, `truncated`) стенд не вызывает: учебной подсистемы, которая
поднимает тревоги, у стенда нет. Это проверяется вектором `alarms` и чтением.
