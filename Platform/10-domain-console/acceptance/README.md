## Стенд

Подготовка — как README приёмки [главы 8.3](../../08-domain/acceptance/3/README.md) («Подготовка каждого сценария», из
М11/03: кластеры `hold`, `m1`, `m2`, каталог `testsub`); у сц. 02 — с объявлением общего в `testsub`, как README приёмки
[главы 8.9](../../08-domain/acceptance/9/README.md):
- `domain.shared: [step, marks, {rounds}]`;
- `step` — `int` с `inherit: 1`;
- `marks` — `list` с `inherit: []`, `merge: union`.

Раннер ходит человеком `root` (первый администратор — глава 8.4, директива `@person`).

- **Сценарий 02.** Агент `m2` выключен дольше `LOST_AFTER`: в доставке он `silent`, в списке тревог — член `silent` и
  строка молчания (шаг 05); окно не по грамматике и `since > until` — 400 (шаги 06, 07). Включённый, он берёт документ,
  и список снова полон (шаги 09, 10).
- **Сценарий 05** — двери страницы держателя (нормы Н1.7). Вызовы модуля в режиме `domain` проверяет тест модуля у его
  владельца ([P/07](../../07-console-module/spec/07-console-module.norms.md) Н1.6), не эта приёмка.

Соседи на стенде: правку общего документа (сц. 02 шаг 03) консоль домена передаёт процессу `domain` (нормы Н1.3;
исполнение — [глава 8.9](../../08-domain/spec/08.9-domain.norms.md) Н1.3); содержимое `delivery` (шаги 04, 09) —
`view.shared` главы 8.9 (Н1.6), дверь `GET /domain/shared` — этот урок (P/10-14); документ берёт агент члена
([глава 9.1](../../09-agent/spec/09.1-agent.norms.md)); шаг 11 — подпись агента у `/events` консоли кластера члена
([договор подписи агента](../../common/contracts/agent-signature.md), сторожевая P/06.3; план урока 10 В6: шаг не дробится).

Страницу тревог (фронт раз в секунду, срочный отчёт, `truncated`) стенд не вызывает: учебной подсистемы, которая
поднимает тревоги, у стенда нет. Это проверяется вектором `alarms` и чтением.

## scenarios.tsv

сценариях и входах урока — как есть (план переноса урока 10, § 3 «corrections.tsv»: из М11/08 — строка 2026-10-18 о

`04-alarms 6`; пути старых строк — `11/…`, `NN-<имя> <шаг>` — разрешает [id-map](../../common/id-map.tsv)); строки о
сц. 04 — и в «Журнале источника» вектора `alarms`; последняя строка — перенос.
