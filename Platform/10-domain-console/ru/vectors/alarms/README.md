# Векторы списка тревог

Текст производный от `vectors/alarms/README.md`, руками не правится: источник — английский [`vectors/alarms/README.md`](../../../vectors/alarms/README.md), правка идёт в него, русский пересобирается переводом.

Векторы функции `alarms(input)` консоли домена — список тревог членов у держателя: состояние каждого члена (`ok`,
`silent`, `not_reporting`, `never`, `unreadable`), строка молчания, свидетели, часы домена у строк страницы, история без
повторов, окно и фраза `sentence`. Владелец — урок P/10 ([нормы](../../spec/10-domain-console.norms.md) N1.8, N3 `alarms`,
N5 `alarms`).
Историю, которую функция читает, пишет процесс `domain` ([P/08.9](../../../../08-domain/ru/spec/08.9-domain.norms.md) N1.9);
страницу тревог члена — агент ([P/09.1](../../../../09-agent/ru/spec/09.1-agent.norms.md) N1.10). Байты пишет «Спецификация»; соответствие продукта — его приёмкой по этой таблице.

`case` — идентификатор случая вектора. В JSON-тексте `input` и `expect` нет пробелов вне строк; `@exit 2` — строка. Таблица — источник этих случаев.

## Прогон

Без стенда: функция реализации (команда `alarms`, нормы «Решает реализация» п. 1) получает вход (колонка `input`) и
даёт вывод; `expect` — подмножество полей вывода (`@absent` — поля нет) или `@exit 2` (вход не по форме: нормы N5
`exit`). Страница не по форме P/09.1 N1.10 — исход 0 `unreadable`, не код 2.
Кто исполняет — консоль домена (`10-domain-console`, P/10 N3 `alarms`, N1.8, N5 `alarms`). Процесс `domain` (`08-domain`) не исполняет: он пишет историю, которую функция читает (P/08.9 N1.9 `writer`; его запись без повторов — пакет `alarm-history`); агент (`09-agent`) пишет страницу тревог члена (P/09.1 N1.10).

## Вход

- `now` = 1760000000, окно — сутки (`since` = `now` − 86400, `until` = `now`; кроме строк 08, 27), `lost_after` 45 (кроме строки 15);
- члены: `last_report` и `received_at` — часы домена, `sent_at` — часы члена того же отчёта (у векторов — `page.to`; при
  `page` не объектом — число, как `received_at`: `null` у члена с отчётом — код 2, строка 19), `page` — страница P/09.1 N1.10 (`"garbled"` — не читается; `null` — нет), `history` —
  объект истории P/08.9 N1.9; `reported: "garbled"` вместо `last_report`, `received_at`, `sent_at` — метка прочитана, не по форме;
- `witnesses` — объекты свидетелей `{sub, name, ts, cluster, units}` (нормы N1.8 `witness`).

Имена подсистем и единиц во входе (`testsub`, `testsub/c1`) — данные входа: от байтов манифестов каталога вектор не зависит.

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок. Столбец `note` поясняет случай.

При расхождении права норма, «Спецификация» исправляет вектор.

## Соседние случаи P/10

В обеих формах члена обязателен `silent_after`, конечное положительное число; подстановки `lost_after` нет. Сборщик всегда передаёт предел server/camera из N1.8, функция не выводит класс. `ts` свидетеля во входе уже переведён на часы домена по исходному отчёту, а не метке наблюдаемого члена. Обе стороны сдвига настоящего сборщика проверяются CALL-швами.
