# Векторы сборки книги

Векторы функции `assemble` [главы P/08.5](../../spec/08.5-domain.norms.md): сборка одной книги у держателя без
хранилища, сети и стенда — вход — копии членов списка и их состояние вида, вывод — строки книги каждого члена до кольца
(секреты открыты) и отчёт вида `{conflicts, dropped, undelivered}` (Н1.3, Н1.5, Н3 «сборка книги»; Н5 «`assemble`»).
Владелец — урок P/08, глава 8.5; функцию исполняет процесс `domain` (проход держателя раз в `VIEW_EVERY`). Байты пишет
«Спецификация» (ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из шагов приёмки [М11/05](../../../../Source/tests/testdata/acceptance/М11_Domain/05/README.md)
(сц. 06, 17 шагов; команда `assemble` на `inputs/assemble-*.json`) при переносе урока 8 (план переноса урока 8, § 3 и В1;
решение «Архитектора» 2026-10-20, ADR-0083 доп. (14)). `case` — имя файла входа, `note` — сценарий и шаг приёмки М11/05.
Вход — JSON файла одной строкой: сняты только незначащие пробелы вне строк; порядок ключей, лексемы чисел и значения — как
в файле. Ожидание — подмножество шага приёмки как есть (после `ok `); шаг `@exit 2` — `@exit 2`. Сценарий М11/05 сц. 06 и
его входы сняты переносом урока 8 (строка `corrections.tsv` приёмки М11/05): таблица — единственный источник этих случаев.

## Прогон

Без стенда: команда `assemble` реализации получает вход (колонка `input`) и печатает JSON `{rows, report}`; `expect` —
подмножество полей вывода по словарю «Стенда» ([общий README приёмки](../../../common/acceptance/README.md), `<код>
<JSON>`: названные поля есть и равны, `"@absent"` — поля нет, массив — по длине, порядку и элементам) или `@exit 2` (вход
не по форме Н5: ключи `copies` — не в точности `members`; `grants` без `now`). Каждая строка — отдельный запуск.

## Входы, ключи и спеки

Вход — Н5 главы: `book` — `testsub2/notes` (`pick: unique`, индекс имён `notes/` с `grant: view`) или `testsub2/rolls`
(`pick: all`), `members` — список членов, `book_seal_seed` — `seed_secret` ключа приёма книг (`book seal 1`,
[README пакета `domain-token`](../../../common/vectors/domain-token/README.md#ключи) «Ключи»), `copies` — состояние и объекты копии
каждого члена (`null` — копии нет), `grants` и `now` — строки грантов получателей для правила Н1.3 `grant`. Секреты
входов — конверты `x25519:v1` к `book seal 1` (в случае 07 — к `book seal 2`: не открывается), `eph 1`, `nonce` 0…11
([договор конвертов домена](../../../common/contracts/domain-envelopes.md) «Конверт `x25519:v1`», AAD — `[член, ключ строки,
item]` и JSON Pointer секрета). Случай 12 — секрет конвертом кольца члена `enc:v2:`: член его не открыл, и агент нёс как
есть (глава 9.1, М11/5 Н1.2) — сборка даёт `secret_unopened`.

Ожидания зависят от байтов спек каталога (разбор ревью стадии A 8–10, № 37): `domain.books` (`from`, `key`, `pick`, `to`) и
`domain.names` спеки `testsub2` из данных спецификации:

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 17 строк: 16 вычислено, 1 `@exit 2` | `input` — вход `assemble` текстом JSON → `expect`: строки `rows` (доставка только членам из `to`, порядок `entries` по (member, item), `missing` с закрытыми словами, ключ конфликта `unique` и недоставленный по гранту — `"@absent"`, открытый секрет в `value`) и `report` (`conflicts`, `dropped` — `bad_contribution`, `secret_unopened`, `undelivered`); `@exit 2` — `grants` без `now` |

| Случаи | Что проверяет |
|---|---|
| 01, 09 | доставка по `to`, держатель — тоже получатель; получатель вне списка — `undelivered`, не получает ничего |
| 02, 03 | конфликт `unique` — ключа нет у всех; `all` — все вклады, порядок по (member, item) |
| 04, 05, 11, 13 | испорченный вход (нет `key`, пустой `key`, повтор `key` у одного члена, в том числе в двух слотах) — весь вклад снят; форма раньше секретов |
| 06, 07, 12 | секрет открыт (`value` с открытым значением); чужой `book_seal`, неоткрытый членом конверт кольца — `secret_unopened` |
| 08 | `unseen` вкладывает и в `missing`; `silent`, `never`, `no_copy` |
| 10 | объекты вне `from` книги не читаются |
| 14–16 | индекс имён `notes/` с `grant: view`: строка гранта получателя — ключ доставлен; строк нет — только `""`; `grants: null` — правило не применяется |
| 17 | `grants` без `now` — `@exit 2` |

Векторы проверены оракулом по тексту норм (Н1.3, Н3 «сборка книги», Н5; открытие секрета — эталонными X25519, HKDF-SHA256
и AES-256-GCM по договору конвертов домена; действующая строка гранта — [договор права](../../../common/contracts/may.md)
шаг 5), не по коду реализаций: вывод оракула содержит ожидание каждой строки. При расхождении прав текст нормы, вектор
правит «Спецификация».
