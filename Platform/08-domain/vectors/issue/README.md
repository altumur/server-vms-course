# Векторы выдачи токена воркера

Векторы функции `issue` [главы P/08.7](../../spec/08.7-domain.norms.md): выдача токена держателем без хранилища, сети и
стенда — вход — объявление вида, роль и член-заявитель, тело просьбы, назначения, топология, единицы членов, общий
документ и `now`; вывод — утверждения токена без `jti` или отказ `{status, reason}` (Н1.1 `computed`, Н1.3 `body`, Н1.4,
Н3 «выдать» шаги 2–7; Н5 «`issue`»). Шаги 0–1 (смещённый процесс, подпись агента) вход не несёт. Владелец — урок P/08,
глава 8.7; функцию исполняет процесс `domain` на двери `POST /api/tokens/<член>/<sub>/<вид>`. Байты пишет «Спецификация»
(ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из шагов приёмки М11/07
(сц. 03, 30 шагов; команда `issue` на `inputs/issue-*.json`) при переносе урока 8 (план переноса урока 8, § 3 и В1;
решение «Архитектора» 2026-10-20, ADR-0083 доп. (14)). `case` — имя файла входа, `note` — сценарий и шаг приёмки М11/07.
Вход — JSON файла одной строкой: сняты только незначащие пробелы вне строк; порядок ключей, лексемы чисел и значения — как
в файле. Ожидание — подмножество шага приёмки как есть (после `ok `). Сценарий М11/07 сц. 03 и его входы сняты переносом
урока 8 (каталог М11/07 снят; журнал — [приёмка главы P/08.7](../../acceptance/7/corrections.tsv)): таблица — единственный
источник этих случаев.

## Прогон

Без стенда: команда `issue` реализации получает вход (колонка `input`) и печатает JSON; `expect` — подмножество полей
вывода по словарю «Стенда» ([общий README приёмки](../../../common/acceptance/README.md), `<код> <JSON>`: названные поля
есть и равны, массив — по длине, порядку и элементам, число — по значению) или `@exit 2` (вход не по форме Н5, в том числе
`decl` не по форме загрузки [P/02.1 Н1.2б](../../../02-installer/spec/02.1-installer.norms.md)). Строк `@exit 2` в таблице
нет: все 30 входов — по форме. `iat`, `exp` — от `now` входа, не от часов процесса.

## Входы

Вход — Н5 главы: `decl` — объявление вида (`null` — вида нет), `role` — роль, которую удостоверил агент, `member` —
член-заявитель, `body` — тело `{request_id, ref, by?}`, `members`, `holder`, `placements` (`"garbled"` — запись нечитаема,
запись без `copies` — тоже нечитаема), `topology` (`centre?`, `star`, `via`), `units` — владельцы единиц по ref, `shared` —
общий документ, `now` — 1760000000. Домен — `acme`; члены — `hold`, `m1`, `m2`, `relay`. Объявления видов во входах — виды
`tally`, `probe` манифеста `testsub` и `feed`, `tally2` манифеста `testsub2` из данных спецификации
([`testsub`](../../../../Source/tests/testdata/testsub.subsystem.yaml),
[`testsub2`](../../../../Source/tests/testdata/testsub2.subsystem.yaml)) — входы несут их целиком и от байтов манифестов не
зависят.

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 30 строк: 9 `ok`, 21 `refused` | `input` — вход `issue` текстом JSON → `expect`: `{"result":"ok","claims":…}` (утверждения Н1.4: `iss`, `sub`, `kind`, `iat`, `exp`, утверждение ref и аудитории из области, давшей аудиторию, у `scenario` — `by`, `acts` по JCS, `up`) или `{"result":"refused","status":…,"reason":<слово>}`: `bad_request`, `by_misplaced` (400); `not_granted`, `outside_scope`, `no_assignment`, `assignment_unreadable`, `unit_not_unique`, `not_poll_home`, `trigger_not_reported`, `no_shared_doc`, `no_item`, `no_home`, `no_audience` (403); `no_centre` (409) |

| Случаи | Что проверяет |
|---|---|
| 01, 06–09, 30 | `placement`: аудитория `cluster` и `copies`; не `origin`, имя записи не член — `outside_scope`; записи нет — `no_assignment`; нечитаема, без `copies` — `assignment_unreadable` |
| 02–05, 22, 24 | порядок первых шагов: роль не в `grant`, вида нет — `not_granted`; тело не по форме — `bad_request`; `by` не у `scenario` и нет у `scenario` — `by_misplaced`; `not_granted` раньше `by_misplaced` |
| 10–12 | `unit` `self`: владелец — этот член; не владелец, два владельца — `unit_not_unique` |
| 13–15, 27 | `placement` без записи падает на `unit` (`poll_home`): ретранслятор — ближайшая дверь владельца; не она — `not_poll_home`; `centre` без центра — `no_centre`; `poll_home` через `centre`, не держатель |
| 16–21, 23, 25, 26, 28, 29 | `scenario`: прямо, за ретранслятором (`up`), подъём ретранслятора, дом по назначению; нет элемента, `by` чужой, нет документа, имя дважды — `no_item`; `acts` по JCS; дом нечитаем — `no_home`; дом не член — `no_audience` |

Векторы проверены оракулом по тексту норм (Н1.1 `computed`, Н1.3 `body`, Н1.4, Н3 «выдать»), не по коду реализаций: вывод
оракула содержит ожидание каждой строки. При расхождении прав текст нормы, вектор правит «Спецификация».
