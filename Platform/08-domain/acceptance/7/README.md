# Приёмка P/08.7 — выдача токенов (стенд)

Стенд, словарь директив и дверей — [общий README приёмки](../../../common/acceptance/README.md#словарь-директив-и-дверей),
раздел [«Стенд домена»](../../../common/acceptance/README.md#стенд-домена) (стенд нескольких кластеров; прежде — словарь М11 README приёмки
М11/01; план переноса урока 8, В5). Норма главы —
[`08.7-domain.norms.md`](../../spec/08.7-domain.norms.md) Н5. Сценарии 01, 02 перенесены из приёмки М11/07 (стадия B,
ADR-0083 доп. (1): без изменения поведения); номера и шаги — прежние. Всего 2 сценария / 19 шагов.

Выдачу на всех областях и словах отказа без стенда проверяет вектор [`issue`](../../vectors/issue/README.md) (30 строк,
бывший сц. 03 приёмки М11/07). Отказы объявления вида — случаи `m57_tokens_*` корпуса
[P/02.1](../../../02-installer/acceptance/1/README.md); проверка токена у получателя на векторах —
[договор токена домена](../../../common/contracts/domain-token.md), пакет `domain-token` (бывший сц. 12 приёмки М11/02).

Деление (план переноса урока 8, В12): оба сценария — глава 8.7, их исход — выдача держателя и утверждения токена. Местная
дверь агента ([договор местной двери токенов](../../../common/contracts/local-token-door.md), [глава 9.1](../../../09-agent/spec/09.1-agent.norms.md) Н1.6) и получатель
(`@verify`, [P/03.7](../../../03-worker/spec/03.7-worker.norms.md) Н1.5) — соседи на стенде: шаги 02/6, 02/8, 02/12 — отказы
местной двери (400 `request_id`, 413 `TOKEN_BODY`, 404 `<sub>` не из каталога), шаги 01/4–7 — проверка у получателя.

## Подготовка

Как подготовка стенда главы 8.3 ([приёмка главы 8.3](../3/README.md); до переноса — README приёмки
М11/03, «Подготовка каждого сценария 01–09») с одним
отличием: каталог каждого кластера — `testsub` и `testsub2`, как стенд главы 8.5 (порядок — «Стенд» общего README
приёмки); на каждом кластере работает и контроллер `testsub2` (без его шарда снимка агент не отчитывается — [глава 9.1](../../../09-agent/spec/09.1-agent.norms.md)
Н1.2 `ready`), воркер `testsub2` не нужен. Вид `tally` спеки `testsub` — область `placement`,
`caller: origin`, `target_fields: [cluster, copies]`. Роль `testsub2worker` у стенда — настоящая личность (сокет роли или комплект), а
`grant` вида `tally` её не называет: шаг 02/3 — чужая роль просит вид, которого ей не дали. Дверь `token <кластер> <роль>` и
директива `@verify` — словарь домена: `@verify` проверяет токен функцией `token`
([договор токена домена](../../../common/contracts/domain-token.md) «Проверка») по строкам `domain/keys` и `domain/revoked`
названного кластера и с его именем в `expect`.

## scenarios.tsv

Формат — словарь «Стенда» и словарь домена; ожидание — подмножество полей. `$tok` — токен из ответа местной двери.

- Сц. 02 шаги 7–8 — предел тела: 4096 байт у местной двери проходят к держателю (`no_assignment`), 4097 — 413 у местной
  двери; `TOKEN_HOLDER_BODY` 4608 у двери держателя стенд не шлёт мимо агента — чтением (Н1.3 `body`).
- Сц. 02 шаги 9–11 — часы члена вне окна подписи агента: 401 у держателя, затем часы назад
  ([договор подписи агента](../../../common/contracts/agent-signature.md)).
- Сц. 01 шаг 7 — подделанный токен (`@spoil`) у получателя — `bad_signature`.

## corrections.tsv

Журнал исправлений ИИ (ADR-0080 доп. 1): `date`, `sample`, `fix`, `languages`. Строки до переноса — из `corrections.tsv`
приёмки М11/07 целиком, в начале журнала, с прежними путями и номерами (их разрешает
[`id-map.tsv`](../../../common/id-map.tsv)); строки о сц. 03 — история источника (план переноса урока 8, § 3 «Журналы»).
Реализации и их раннеры проверяют свой результат; этот каталог сам их не запускает.

## Сны (`@sleep`, ADR-0080 доп. (17) п. 4)

Снов нет. Часы члена двигает `@clock` (сц. 02 шаги 9, 11).
