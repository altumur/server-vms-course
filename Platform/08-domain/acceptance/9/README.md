## Стенд

Подготовка — как README приёмки [главы 8.3](../3/README.md) («Подготовка каждого сценария», из М11/03: кластеры `hold`, `m1`,
`m2`, каталог `testsub`), с объявлением общего в `testsub`:
- `domain.shared: [step, marks, {rounds}]`;
- `step` — `int` с `inherit: 1`;
- `marks` — `list` с `inherit: []`, `merge: union`.

Раннер ходит человеком `root` (первый администратор — глава 8.4, директива `@person`).

- **Сценарий 01.**
  - Шаг 05 — правка с устаревшей `base_rev` и неизвестной подсистемой: 409 ревизии раньше 400 содержания (Н1.3 шаги 3, 4).
  - Шаги 06–08 — отказы содержания: подсистемы нет и имя не общее, тип поля, схема документа `rounds` (`every` ≥ 1). Шаг 06
    называет две причины одним отказом; ожидание проверяет обе подстроки.
  - `c5` — счётчик со своими `step` и `marks`, `c6` — без них.
  - Шаг 15 снимает значение домена (`null`), и `c6` снова берёт `inherit` спеки (шаг 16).

Соседи на стенде: правку передаёт процессу консоль домена (`holder PUT`, урок P/10, глава 8.0); `GET /domain/shared`
(шаги 02, 14) — дверь консоли домена (урок P/10, P/10-14), содержимое `delivery` — `view.shared` этой главы (Н1.6); документ
берёт агент члена ([глава 9.1](../../../09-agent/spec/09.1-agent.norms.md), P/09.1-12); значение при чтении `GET /domain/shared/testsub` (шаги 11–13, 16) — консоль кластера
(М11/11 Н1.5, глава P/06.7 позднего слоя); единицы `c5`, `c6` (шаги 09, 10) — дверь единиц P/06.1.
