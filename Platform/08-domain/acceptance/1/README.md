# Приёмка P/08.1 — вид домена и теневой отчёт (стенд)

Стенд, словарь директив и дверей — [общий README приёмки](../../../common/acceptance/README.md#словарь-директив-и-дверей),
раздел [«Стенд домена»](../../../common/acceptance/README.md#стенд-домена) (стенд нескольких кластеров; прежде — словарь М11 README приёмки
М11/01; план переноса урока 8, В5). Норма главы —
[`08.1-domain.norms.md`](../../spec/08.1-domain.norms.md) Н5. Сценарии перенесены из приёмки М11/03 (04, 06–09) и
М11/06 (06 → 15) (стадия B, ADR-0083 доп. (1): без изменения поведения); номера и шаги — прежние, кроме сценария М11/06:
номер 06 занят сценарием М11/03, он получил номер 15 — следующий после наибольшего номера источников главы (М11/03 сц. 14;
решение «Архитектора» 2026-10-20, ADR-0083 доп. (14) п. 14; строка `corrections.tsv`). Всего 6 сценариев / 39 шагов.

Те же виды без стенда — векторы [`view`](../../vectors/view/README.md) (28 строк, бывшие сц. 01–16 приёмки М11/01).
Двери `GET /domain`, `/domain/<sub>/<rows>`, `/domain/shadow`, через которые стенд читает вид и отчёт, — двери консоли
домена (урок P/10, [Н1.2а](../../../10-domain-console/spec/10-domain-console.norms.md)); глава нормирует их содержимое.

## Подготовка

Как README приёмки [главы 8.3](../3/README.md) («Стенд», «Подготовка каждого
сценария»; прежде — README приёмки М11/03): раннер поднимает на одной машине три кластера — `hold`, `m1`, `m2`; у каждого своё пустое хранилище,
свой `{data}`, свои сокеты ролей и порты консоли и ресурса, своё кольцо (P/06.2 Н1.2), каталог спек — только `testsub`
(`domain.ref: name`); консоль, контроллер и воркер `w-1` `testsub`, ресурс своего сервера (`srv-hold`, `srv-m1`, `srv-m2`).
Единиц нет. Домена нет: его ставит директива `@domain` первого шага каждого сценария. Имя домена — `acme`; файл
восстановления — `{recovery}` в каталоге экземпляра.

Часы не ускорять: LOST_AFTER 45 с, REPORT_EVERY 5 с, MARK_REFRESH 22,5 с, SHADOW_STALL 60 с; сроки `@until` взяты с
запасом. У двери `holder` раннер ставит `Idempotency-Key` и у `PUT` (сц. 15, назначения — глава 8.6).

## scenarios.tsv

Формат — словарь «Стенда» и словарь домена; ожидание — подмножество полей.

| № | Сценарий | Шагов | Что |
|---|---|---|---|
| 04 | `cut-and-mend` | 5 | `@cut m1` — через LOST_AFTER `silent`, `complete: false`; `@mend` — снова `ok` |
| 06 | `view-on-the-stand` | 8 | две единицы в двух членах, поиск по ref, `?cluster=`, `no such member`; `contested` пуст; теневой отчёт — `unmanaged` 2, `may_write: false` |
| 07 | `view-unseen-and-silent` | 7 | после перезапуска `domain` члены `unseen`, затем `ok`; молчащий — `silent` |
| 08 | `view-configured-and-stale` | 8 | единица без воркера — `configured`, `unobserved`; воркер убит — `stale` |
| 09 | `view-contested` | 5 | один ref в двух членах — `contested`, единицы нет в `units` |
| 15 | `shadow-and-executors` | 6 | назначение с `copies`: заявки исполнителей из `cluster` и `copies` — не `conflict`; назначение без единицы — `orphaned` после SHADOW_STALL |

Сценарии 06–09 повторяют на стенде сценарии 01–05 приёмки М11/01 (векторы `view`): настоящие отчёты агентов в
`domain/members/<член>/reports/<rev>` и вид держателя.

## corrections.tsv

Журнал исправлений ИИ (ADR-0080 доп. 1): `date`, `sample`, `fix`, `languages`. Строки до переноса — `corrections.tsv`
приёмок М11/03 и М11/06 целиком, в начале журнала, с прежними путями и номерами (их разрешает
[`id-map.tsv`](../../../common/id-map.tsv)); строки о сценариях других глав — история источника (план переноса урока 8,
§ 3 «Журналы»).
