# P/08.9 — Общий документ и история тревог: нормы

Канон главы 8.9 урока P/08 «Процесс domain» (ADR-0080; модуль «Платформа» — ADR-0083). [Лекция](../08-domain.md),
[контракт](08-domain.api.openapi.yaml), [инструкция](08-domain.README.md), [жизненный цикл](../lifecycle.md),
[приёмка](../acceptance/9/README.md). Здесь — общий документ домена у держателя: документ, подпись выпускающим и указатель,
правка по порядку, сторона держателя доставки (ответ агенту), доставлено скольким (`view.shared`), и история тревог членов
(один писатель, предел).

Глава перенесена (стадия B, ADR-0083 доп. (1): без изменения поведения) из
М11/11: Н1 «Время» (история) и вводный абзац Н1, Н1.2
целиком, Н1.3 целиком (сторона процесса), Н1.4 `carry` и `holder_self` (сторона держателя; `note` id-map М11/11-04), Н1.6
`domain/view.shared`, Н1.9 целиком, строка Н2 `PUT /domain/shared`, строки Н4 правки, предложения «Гонок» Н3 о правке и
переносе, сценарий 01 Н5. Номера подразделов — прежние номера источника. Чего здесь нет и где оно:
- объявление `domain.shared`, `merge`, `domain.witness` — [P/02.1 Н1.2б](../../02-installer/spec/02.1-installer.norms.md)
  (глава позднего слоя 2.1, вводит эта глава; М11/11-01 → P/02.1-29);
- значение при чтении (`resolve`, `GET /domain/shared/<sub>` консоли кластера) — OpenAPI урока 6 `GET /domain/shared/{sub}`,
  векторы `resolve` (глава P/06.7); ссылки главы на консоль кластера — на контракты (ADR-0083 доп. (14) п. 12);
- сторона агента доставки (`member`, `in_report`, Н3 «взять документ») и страница тревог члена (Н1.7) — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) урока
  P/09 (Н1.10, Н3 «взять документ»);
- двери консоли домена `GET /domain/shared` (`{doc, delivery, declared}`) и `GET /domain/alarms`, список тревог у держателя
  (Н1.8: состояния, строка молчания, свидетели, часы строки `clock`, функция `alarms` и её вектор) — урок P/10 ([нормы](../../10-domain-console/spec/10-domain-console.norms.md) Н1.2е, Н1.8, Н3
  `alarms`; P/10-14, P/10-06; вектор `alarms`; решение «Архитектора» по разбору ревью стадии A 8–10, № 8, и план урока 8
  В2). Номер P/08.9-04 свободен (как P/03.6-02).

Ссылка «глава 8.K» — глава этого урока; «глава 9.1» — глава урока P/09 (ссылкой);
«урок P/10» — урок «Консоль домена» ([нормы](../../10-domain-console/spec/10-domain-console.norms.md)); «P/0N[.K]» — урок или глава модуля; «М11/N»
— урок-источник М11 (снят переносами уроков 8–10; новые адреса — id-map). Id норм — `P/08.9-MM`; соответствие прежним id — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля — [P/01.1 Н0](../../01-store/spec/01.1-store.norms.md#н0-словарь-слов)
(порядок массивов вывода — P/01.1 Н0 «Порядок массивов вывода», область уроки 8–10).

## Н1 Форма

**Время.** Поля времени строк и объектов главы — время по [канону Н0](../../01-store/spec/01.1-store.norms.md#время-в-строке):
объект истории `domain/alarm-history/<член>` — `events[].t`, `cut_before` (писатель — не больше трёх знаков дроби;
добавлено сверкой М11, A22). Объект страницы `domain/alarms` (`from`, `to`) — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н1 «Время».
Документ `domain/shared-docs/rev-<rev>` (Н1.2 document) — `at`: число JSON ([договор записи
срока](../../common/contracts/record.md), шаг 1), не строка (решение «Архитектора» 2026-10-20).

**Данные** ([каталог](../../common/data/catalog.tsv)):
- владеет: `domain/shared`, `domain/shared-docs/rev-<rev>`, `domain/alarm-history/<член>`;
- пишет: `<корень событий>/audit/<роль>/e1/<YYYYMMDDTHHMMSSZ>.events.jsonl` (append);
- читает: `platform/manifest/<sub>`, `domain/holder`, `domain/members`, `domain/view`, `domain/signer`, `domain/signer-turn`, `domain/members/<член>/reports/<rev>`, `domain/members/<член>/reported`.

Строка `domain/shared` — указатель у держателя (Н1.2) и строка копии у члена: протокол строки задаёт держатель, агент —
участник `cas` ([глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н1.10); объект `domain/shared` у члена (копия документа) — семья агента. Объекты
`domain/shared-docs/rev-<rev>` и `domain/alarm-history/<член>` пишет только процесс `domain` (ADR-0032): документ — без стража,
раньше указателя; указатель — по CAS прочитанной версии со стражем `domain/signer-turn` ([P/08.10 Н1.7](08.10-domain.norms.md));
история — по CAS, `put_at` по индексу объекта ([P/08.10 Н1.7](08.10-domain.norms.md) `objects`). Манифесты каталога (`domain.shared`,
схема документа) процесс читает строками `platform/manifest/<sub>` (Н1.3 шаг 4); подпись — выпускающим ключом строки
`domain/signer` ([договор записи срока](../../common/contracts/record.md), `issuing_key_secret`); срок — запись
`domain/holder` (глава 8.8); членов — список `domain/members`, их состояние — вид `domain/view` (глава 8.1); копии членов
(`domain/shared`, `domain/shared-refused`) и страницу тревог — объекты отчёта `domain/members/<член>/reports/<rev>`,
`received_at` и `sent_at` отчёта — метка `…/reported` (глава 8.3). Журнал `domain.shared.edited` (Н1.3 `answer`) процесс
дописывает в `audit/domain` по [договору журнала событий](../../common/contracts/event-journal.md) (участник `append`,
владелец — P/05).

Общее Н1 урока P/08 ([P/08.2 Н1](08.2-domain.norms.md) «Общее для всех форм главы», [P/08.3 Н1](08.3-domain.norms.md)) действует. Домен не знает ни одного поля подсистемы
(ADR-0010): что общее, объявляет манифест, а значение домена разрешается **при чтении**, не записью в строки. Тревоги членов
домен собирает из их отчётов: к члену он соединений не открывает. Решение «Архитектора» по вопросам М11/11; C6 «точный
документ».

### Н1.2 Общий документ

```yaml
document:        объект держателя domain/shared-docs/rev-<rev> — JCS {domain, term, rev, at, by, shared, issuer, kid, sig}
  shared:        {<sub>: {<имя>: <значение>}} — только объявленное P/02.1 Н1.2б; подсистемы и имена по возрастанию (JCS)
  term, rev:     срок держателя (P/08.8) и номер правки; порядок — (term, rev), term старше
  by:            имя, доказанное сторожевой; после переноса — "domain"
  signature:     выпускающий ключ, как запись срока (договор записи срока, record.md; проверка — функция record); неподписанный
                 не принимается никогда
pointer:         domain/shared {doc: JCS {term, rev, sha256, object}} у держателя; sha256 — hex sha256 текста объекта;
                 object — ключ этого объекта, строка "domain/shared-docs/rev-<rev>" с rev указателя (разбор ревью стадии A 8–10, № 26)
write:           сначала объект, затем указатель по CAS (две правки одновременно — одна получает 409); держатель хранит
                 последние 5 объектов. Правки общего документа процесс исполняет по одной (шаги Н3 «правка» 3–6 — одна
                 правка за раз). Объект ревизии — порядком G6, как объекты без указателя (P/08.10 Н1.7 objects): снимок
                 указателя domain/shared (по нему объект признаётся ничьим) → get_at объекта ревизии → подтверждение своей
                 очереди domain/signer-turn → запись по индексу ЭТОГО get_at (договор клиента хранилища объектов «Операции» ops): объекта не было — put_new;
                 есть с теми же байтами — не писать; есть с другими байтами — указатель его не называет (rev объекта выше
                 rev указателя: прежняя правка оборвалась между объектом и указателем), объект ничей — put_at поверх
                 (решение «Архитектора» 2026-10-20 по вопросам сборки урока 8, п. 2; решение «Архитектора», разбор ревью стадии B 8–10, № 1, ADR-0083 доп. (15)); очередь потеряна между
                 чтением и подтверждением — правке 503 по P/08.10 Н1.7, объект не тронут; put_new или put_at получил
                 conflict — объект сменился после get_at, его пишет другая правка или другой процесс: правке 409 «the shared
                 settings changed while this edit was made — look again», объект не трогается — проигравшая правка не
                 перезаписывает объект выигравшей (добавлено сверкой М11, A1)
after_move:      новый держатель (P/08.8 Н1.8) переподписывает то же содержимое как rev + 1, by "domain" — у него другой
                 выпускающий; при плановой передаче выпускающий тот же, документ не меняется
readers:         процесс domain, консоль домена, воркер подсистемы на домене (роль <sub>domain) — указатель domain/shared
                 (точное имя) и объекты domain/shared-docs/rev-* (семья domain/* двери объектов P/05); консоль кластера — строка domain/shared (точное имя: у держателя
                 указатель, у члена строка копии, Н1.4; P/02.5 Н1.4 console, добавлено М11/11); проекций по подсистемам нет (C6)
```

### Н1.3 Правка

```yaml
door:            PUT /domain/shared {base_rev, shared: {<sub>: {<имя>: <значение> | null}}} у консоли домена (admin, P/08.4;
                 урок P/10 Н1.3) → процесс domain тем же путём (ADR-0032; глава 8.0); тело ≤ 1 МиБ (иначе 413 {error: "refused"})
order:           1. заморозка, смещение — P/08.8 (503 frozen, 409 deposed)
                 2. тело не {base_rev: целое ≥ 0, shared: объект, каждое shared.<sub> — объект} — 400 (shared.<sub> не
                    объект — тоже здесь, до base_rev; добавлено сверкой М11, A9) {error: "refused", detail: "the edit is {base_rev:
                    <the revision it was made against>, shared: {<sub>: {<field>: value or null}}}"}
                 3. base_rev ≠ rev указателя (0 — документа нет) — 409 {error: "refused", detail: "the shared settings are at
                    rev N; the edit was made against rev M — look again"}
                 4. содержание — все отказы одним 400 через «; »: «shared settings for '<sub>': no subsystem on the domain
                    shares a field by that name»; «'<имя>' is not in its domain.shared [<имена domain.shared манифеста через «, », по возрастанию>]»; тип поля — та же проверка
                    формы, что у двери единиц (P/06.1 Н3 «создать» шаг 4), на одном этом поле, слово отказа — её; значение документа
                    против его schema (слова схемы); значение, которое консоль запечатала бы (P/06.2 Н3) (имя *_secret на любой глубине,
                    находка пароля в адресе по P/06.2 Н1.1а), — «'<имя>': the shared document is signed, not sealed» (сверка М11, A6)
                 5. новый документ: прежний shared, поверх — значения правки; null — снять имя; пустая подсистема —
                    снять; rev + 1, term — свой, at, by; прежний документ (объект, который называет указатель) не читается
                    или не с его sha256 — 503 {error: "refused", detail: "the shared document at rev N does not read: nothing
                    is written"}, ничего не пишется: правка поверх пустого потеряла бы прежние значения (сверка М11, A7)
                 6. записать (Н1.2 write); CAS не прошёл — 409 «the shared settings changed while this edit was made — look again»
answer:          200 {term, rev, by}; журнал domain.shared.edited {term, rev, by}
```

### Н1.4 Доставка члену — сторона держателя

```yaml
carry:           ответ держателя агенту (P/08.3 Н1.5) несёт shared: {pointer: {term, rev, sha256}, doc?: <текст>} — doc,
                 только когда domain/shared из копии члена ≠ указателю (P/08.3 Н3 «прочитать копию»)
holder_self:     у кластера держателя строка domain/shared — указатель (Н1.2), а документ — объект domain/shared-docs/rev-<rev>: агент
                 держателя документа не берёт, консоль держателя читает указатель (дверь
                 GET /domain/shared/{sub} OpenAPI урока 6)
```

Сторона агента — `member` (взять документ по порядку, объект и строка `domain/shared`, отказ — строка
`domain/shared-refused`) и `in_report` (строки `domain/shared` и `domain/shared-refused` — объекты отчёта) — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md)
(Н1.10, Н3 «взять документ»).
Держатель читает эти объекты из отчёта члена для доставки (Н1.6).

### Н1.6 Доставлено скольким

```yaml
domain/view.shared:  {term, rev, holding, behind, refused, silent, sentence}       # P/08.1 Н1.4, добавлено М11/11
  holding:     [<член>…] — копия члена ≥ (term, rev) указателя; держатель включён
  behind:      {<член>: {term, rev}} — держит старее; член без копии — {term: 0, rev: 0}, не null (добавлено пилотом схем семей данных, Д2)
  refused:     {<член>: <reason>} — domain/shared-refused члена с (term, rev) указателя
  silent:      [<член>…] — член не ok по виду (глава 8.1); раньше прочих правил
  sentence:    «rev R on H of T members[; not taken yet: …][; not answering: …][; refused by: <член> (<reason>), …]»
  before:      до первого документа (указателя нет): term 0, rev 0, holding [], behind {}, refused {}, silent — по виду,
               sentence «rev 0 on 0 of T members» с теми же хвостами (решение «Архитектора» по сверке М11, A5)
```

Дверь `GET /domain/shared` у консоли домена (`view`) → `200 {doc, delivery, declared}`: `delivery` — `view.shared` выше;
`doc` (документ как подписан — объект Н1.2 | `null`) и `declared` (элементы `domain.shared` манифестов каталога со `schema` у
документа) — урок P/10 ([Н1.2е](../../10-domain-console/spec/10-domain-console.norms.md), P/10-14).

### Н1.8 Список тревог у держателя

Перенесён в урок P/10 (P/10-06; [нормы урока P/10](../../10-domain-console/spec/10-domain-console.norms.md) Н1.8 и Н3 `alarms`): дверь `GET /domain/alarms`,
состояния членов, строка молчания, свидетели, часы строки (`clock`), порядок, функция `alarms` и её вектор (решение
«Архитектора» по разбору ревью стадии A 8–10, № 8; план урока 8 В2). Номер P/08.9-04 свободен. Историю (Н1.9) пишет эта
глава; список её только читает.

### Н1.9 История тревог

История члена у держателя (`history`, `cut`, `HISTORY_DAYS`, `HISTORY_LINES`, `writer`, `in_copy`), равенство строк
`same_line` и повтор в странице — [договор истории тревог](../../common/contracts/alarm-history.md) (перенесено туда без
изменения поведения; C10-ALARM-SAME-LINE83, решение «Архитектора» 2026-10-25). Пишет история только проход держателя этой главы.

### Семьи данных (построены из стандартных файлов)

Форма строк и объектов, которыми глава владеет по [каталогу](../../common/data/catalog.tsv), — JSON Schema 2020-12 семьи (ADR-0092). Экземпляр строки — `{key, row}`, объекта — `{key, object}`; ключ — грамматика колонки `key` каталога. Поля `row` — значения `items` после [кодека](../../common/data/codec.tsv): писатель проверяет схему и её `$defs.writer`, читатель — схему (слой 3 — слова `x-*` схемы). Нечитаемо — строка не раскодировалась или не прошла схему в режиме читателя; исход — по таблице исходов семьи: путь — префикс пути отказа (пустой — строка целиком), при нескольких путях отказа действует исход с наименьшим приоритетом.

#### `domain/shared` — строка

Схема — [`shared.schema.json`](../data/shared.schema.json), исходы — [`shared.outcomes.tsv`](../data/shared.outcomes.tsv); версия формы 1; норма — P/08.9 Н1.2, Н1.4.

| Ключ | Тип и границы | Обязательность | Урок | Смысл |
|---|---|---|---|---|
| `doc` | отображение `{term, rev, sha256, object?}`; в `items` — текст JSON, у писателя — JCS (x-encoding: jcs) | обязателен |  | текст JCS указателя (у держателя) или строки копии (у члена) |
| `doc.term` | целое; ≥ 1; ≤ 9007199254740991 | обязателен |  | срок держателя документа (глава 8.8, из М11/10 Н1.1); порядок — (term, rev), term старше |
| `doc.rev` | целое; ≥ 1; ≤ 9007199254740991 | обязателен |  | номер правки документа |
| `doc.sha256` | строка; целиком `[0-9a-f]{64}` | обязателен |  | hex sha256 текста объекта документа |
| `doc.object` | строка; целиком `domain/shared-docs/rev-[1-9][0-9]*` | необязателен |  | ключ объекта документа — строка `domain/shared-docs/rev-<rev>` с rev указателя; только у указателя держателя, у строки копии члена поля нет (Н1.2 pointer; разбор ревью стадии A 8–10, № 26) |

## Н3 Проход

Своих проходов, кроме порядка правки (Н1.3 `order`) и писателя истории (Н1.9 `writer`), у главы нет. «Взять документ»
(агент члена) — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н3, `resolve(field, unit, domain)` — консоль кластера (векторы `resolve`, глава P/06.7), `alarms(input)` —
[урок P/10](../../10-domain-console/spec/10-domain-console.norms.md) Н3 `alarms`.

**Гонки.** Две правки общего документа — CAS указателя, вторая — 409. Держатель перенесён — новый переподписывает
документ (`rev + 1`), члены берут его как новый. Обрыв между объектом и указателем (Н1.2 write): объект выше указателя
ничей, указатель прежний; следующая правка пишет поверх (Н1.2 write: get_at → подтверждение очереди → put_at по индексу
этого get_at). Смена очереди между чтениями: активный A пишет объект N+1, смещённый S прочитал индекс до записи A — его
put_at получает conflict (409); S прочитал индекс после записи A — подтверждение очереди S не проходит (503), объект A цел
(решение «Архитектора», разбор ревью стадии B 8–10, № 1, ADR-0083 доп. (15); расписание Codex R-B810-01, Claude Р-1). Член без связи и шторм тревог — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н3 «Гонки» и урок P/10 (Н3
«Гонки»).
