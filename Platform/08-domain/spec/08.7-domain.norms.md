# P/08.7 — Выдача токенов воркеров: нормы

Канон главы 8.7 урока P/08 «Процесс domain» (ADR-0080; модуль «Платформа» — ADR-0083). [Лекция](../08-domain.md),
[контракт](08-domain.api.openapi.yaml), [инструкция](08-domain.README.md), [жизненный цикл](../lifecycle.md),
[приёмка](../acceptance/7/README.md). Здесь — сторона держателя токенов воркеров: дверь держателя
`POST /api/tokens/<член>/<sub>/<вид>` с пределом тела `TOKEN_HOLDER_BODY` и ответом в конверте `m1`, выдача по порядку
(первое правило даёт исход) по области вида — назначение, единица, сценарий — и утверждения токена.

Глава перенесена (стадия B, ADR-0083 доп. (1): без изменения поведения) из
М11/7: «Данные» и вводный абзац Н1 (без абзаца о токене у воркера),
вычисляемые значения Н1.1 (`computed`), Н1.3 без строки `agent`, Н1.4 целиком, строка Н2 двери держателя, Н3 «выдать»
целиком, Н4 (слова выдачи и 413), Н5 (сценарии 01, 02 и форма команды `issue`; сценарий 03 — вектор `issue`), п. 1
«Решает реализация»; из пункта М11/7-02 — `TOKEN_HOLDER_BODY` у держателя (разбор ревью стадии A 8–10, № 20: сторона
держателя — в 8.7). Номера подразделов — прежние номера М11/7. Чего здесь нет и где оно:
- объявление вида `domain.tokens` и его отказы загрузки (случаи `m57_tokens_*`) —
  [P/02.1 Н1.2б](../../02-installer/spec/02.1-installer.norms.md) (глава позднего слоя 2.1, вводит эта глава; М11/7-01 →
  P/02.1-28); вычисляемые значения `target_fields` остались за выдачей — Н1.1 ниже;
- местная дверь агента (сокет роли, тело, `TOKEN_BODY`, `TOKEN_WAIT`, отказы у агента) —
  [договор местной двери токенов](../../common/contracts/local-token-door.md) (владелец — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н1.6); проверка ответа
  держателя агентом (строка `agent` Н1.3: `request_id`, `exp`, 502 `invalid token reply`) — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н1.6
  (P/09.1-10; часть М11/7-03 по `note` id-map); токен через ретранслятор байт в байт — [глава 9.2](../../09-agent/spec/09.2-agent.norms.md) (P/09.2-05);

  форма токена, подпись и проверка `token` — [договор токена домена](../../common/contracts/domain-token.md).

## Н1 Форма

**Время.** Полей времени у строк и объектов главы нет: глава ничем не владеет. Утверждения `iat`, `exp` (Н1.4) — стенные
секунды держателя; форма — [договор токена домена](../../common/contracts/domain-token.md) «Токен».

**Данные** ([каталог](../../common/data/catalog.tsv)):
- читает: `domain/placement/<sub>/<ref>`, `domain/members`, `domain/topology`, `domain/shared`, `domain/shared-docs/rev-<rev>`, `domain/members/<член>/reports/<rev>`, `domain/signer`, `domain/keys`, `domain/revoked`.

Выдача ничего не пишет (Н3). Записи назначения — [P/08.6 Н1.1](08.6-domain.norms.md), список членов —
[P/08.3 Н1.1](08.3-domain.norms.md), топология — [P/08.3 Н1.2](08.3-domain.norms.md), единицы членов (`units` копии) — поколения отчётов `…/reports/<rev>` (глава 8.3),
общий документ — указатель `domain/shared` и объект `domain/shared-docs/rev-<rev>` ([P/08.9 Н1.2](08.9-domain.norms.md)), ключ токенов
держателя — `domain/signer` и набор `domain/keys` ([P/08.2 Н1.2, Н1.3](08.2-domain.norms.md); [договор набора ключей домена](../../common/contracts/keys.md)),
отзывы `domain/revoked` — [договор набора ключей домена](../../common/contracts/keys.md) «Отзывы».

Общее Н1 урока P/08 ([P/08.2 Н1](08.2-domain.norms.md) «Общее для всех форм главы», [P/08.3 Н1](08.3-domain.norms.md)) действует. Токен воркера — токен домена
([договор токена домена](../../common/contracts/domain-token.md) «Токен») с `kind` вида манифеста. Ключ подписи держателя
воркеру не выдаётся, ключ члена — тоже. Токен у воркера (просьба через агента, только в памяти) и проверка у получателя —
[P/03.7 Н1.5](../../03-worker/spec/03.7-worker.norms.md) (стадия B).

### Н1.1 Вычисляемые значения

Объявление вида — [P/02.1 Н1.2б](../../02-installer/spec/02.1-installer.norms.md) (стадия B; глава позднего слоя, вводит
урок 8). Вычисляемые значения `target_fields` (выдача, Н3):

```yaml
computed:   centre, star_centre, poll_home — не поля записи и не поля единиц: вычисляются по топологии (P/08.3 Н1.2)
            centre — topology.centre; star_centre — centre, если cluster записи в star, иначе ничего (в аудиторию не
            добавляет и не отказ); cluster в star, а centre нет — 409 no_centre;
            poll_home(член) — via[член], иначе centre, иначе держатель
```

Местная дверь агента (прежде Н1.2) — [договор местной двери токенов](../../common/contracts/local-token-door.md) «Дверь»
(владелец — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н1.6; участник P/03.7; разбор ревью стадии A 8–10, № 1 / решение 1).

### Н1.3 Дверь держателя

```yaml
door:       POST /api/tokens/<член>/<sub>/<вид> у процесса domain; подпись агента (договор подписи агента); через ретранслятор —
            байт в байт, той же подписью (глава 9.2 Н1.1 `not_author`, Н2)
body:       {request_id, role, ref, by?} — role — роль, которую агент удостоверил; формы как у местной двери (договор местной
            двери токенов «Дверь»); больше TOKEN_HOLDER_BODY — 413
TOKEN_HOLDER_BODY: договор местной двери токенов (значение и смысл там; перенесено без изменения; аудит раскладки, решение «Архитектора» 2026-10-25, А-19)
answer:     200 {sealed: <m1 P/08.3 Н1.5>} — внутри текст JSON {request_id, token, exp}
```

Конверт `m1` и его содержимое у двери токенов — [договор конвертов домена](../../common/contracts/domain-envelopes.md)
«Конверт `m1`», «Содержимое `sealed`»; `TOKEN_BODY` — [договор местной двери токенов](../../common/contracts/local-token-door.md).
Что агент делает с ответом (открыть `m1`; `request_id` ≠ запрошенного или `exp` ≤ now — 502 `invalid token reply`; иначе
отдать) — [глава 9.1](../../09-agent/spec/09.1-agent.norms.md) Н1.6 `agent`.

### Н1.4 Утверждения

```yaml
payload:    {iss: <домен>, sub: <член-заявитель>, kind: <вид>, iat: now, exp: now + lifetime, jti: 16 hex,
             <ref_claim>: ref, <audience_claim>: [<член>…] по возрастанию, без повторов,
             scenario: <trigger_claim>: by, <acts_claim>: [<act>…] без повторов по тексту JCS, по возрастанию байтов UTF-8
             этого текста, <up_claim>?: centre}
names:     ref_claim и audience_claim — из области, которая дала аудиторию (placement без записи упал на unit — из unit)
signed:     ключом токенов держателя (current набора, договор набора ключей домена; P/08.2 Н1.2), JCS header и payload (договор токена домена «Токен»)
```

## Н3 Проход

### выдать (процесс domain) — по порядку, первое правило даёт исход

```
0. процесс смещён (P/08.8 Н1.6) — ключей токенов у него нет               → 409 deposed (с holder)
1. член, ключ, подпись — P/08.3 Н2                                        → 404 / 403 / 401
2. тело не по форме Н1.3 — закрытое {request_id, role, ref, by?}          → 400 bad_request
3. вид не объявлен манифестом sub, или без области, или role ∉ grant          → 403 not_granted
4. by есть без scenario или нет у scenario                               → 400 by_misplaced
4а. область берёт значение топологии (centre, star_centre, poll_home, via — Н1.1 computed), а domain/topology есть, но
    не читается → 503 unavailable, ничего не выдаётся, журнал без значения (В7 п. 3, решение «Архитектора» 2026-10-28, П1; строка 51 списка)
5. область:
   placement — запись <placement.sub>/<ref>:
     нечитаема (в том числе без поля copies или поле не по форме главы 8.6 Н1.1; добавлено сверкой М11, T2)
                                                                         → 403 assignment_unreadable
     нет: есть unit — к unit; иначе                                      → 403 no_assignment
     имя записи (cluster, origin, copies) не член, или член ≠ поле caller → 403 outside_scope
       (origin "" — не имя: на членство не проверяется, в аудиторию не входит; caller origin при "" — outside_scope)
     аудитория: значения target_fields по Н1.1 computed: centre без centre → 409 no_centre; star_centre — только
       при cluster записи в star (вне star ничего не добавляет, отказа нет), cluster в star без centre → 409 no_centre
       (добавлено сверкой М11)
   unit — владельцы ref (члены, чьи копии заявляют единицу с этим ref в units подсистемы unit.sub, глава 8.1):
     caller self: владелец — ровно этот член; caller poll_home: владелец один  → иначе 403 unit_not_unique
     caller poll_home: poll_home(владелец) ≠ член                         → 403 not_poll_home
     аудитория: значения target_fields — poll_home → poll_home(владелец), centre → centre (без centre → 409 no_centre)
   scenario — by:
     владельцы by и ref — в units подсистемы вида (sub манифеста, объявившего вид)
     владелец by один: член или член за этим ретранслятором (via[владелец] = член)  → иначе 403 trigger_not_reported
     общий документ doc (глава 8.9 Н1.2, проверенный record — договор записи срока) → массив items; нет        → 403 no_shared_doc
     элементы: имя — строка, которая встречается в массиве один раз; enabled отсекает только false (нет поля —
       включён); target = ref, trigger = by; нет поля по пути act — элемент пропускается → acts; нет ни одного → 403 no_item
     дом: запись <placement>/<ref> — её cluster (в star — centre); записи нет — poll_home(единственного владельца ref)
       запись нечитаема, или cluster в star без centre — дома нет, к владельцу не переходить  → нет → 403 no_home
     аудитория (правила по порядку; дом посчитан раньше): подъём ретранслятора (заявитель — via владельца by) — [centre];
                заявитель за ретранслятором R: R = дом — [R], иначе [R] и up = centre;
                иначе — {дом} и centre, если он есть; у подъёма и за ретранслятором ≠ дом centre нужен → нет → 409 no_centre
6. аудитория пуста или с не членом                                       → 403 no_audience
7. утверждения Н1.4, подпись, m1 члену                                   → 200
```

Ничего не пишется: выдача — чтение записей, топологии, копий и документа. `detail` отказа называет причину словами, без
значений документа и токенов.

Отказы шага 1 — глава 8.3 Н2 и [договор подписи агента](../../common/contracts/agent-signature.md) «Проверка и слова
отказа»; единицы копий членов (шаг 5 `unit`) — [P/08.1](08.1-domain.norms.md); общий документ (шаг 5 `scenario`) —
[P/08.9 Н1.2](08.9-domain.norms.md); запись назначения — [P/08.6 Н1.1](08.6-domain.norms.md).

## Н4 Отказы

| Слово | Код | Когда |
|---|---|---|
| `bad_request` | 400 | тело не по форме |
| `by_misplaced` | 400 | `by` не у `scenario` или его нет у `scenario` |
| `not_granted` | 403 | вида нет, области нет, роль не в `grant` |
| `assignment_unreadable` | 403 | запись назначения нечитаема |
| `no_assignment` | 403 | записи нет, `unit` не объявлен |
| `outside_scope` | 403 | имя записи не член; член не в поле `caller` |
| `unit_not_unique` | 403 | у ref не ровно один владелец (или у `self` — не этот член) |
| `not_poll_home` | 403 | член — не ближайшая дверь владельца |
| `trigger_not_reported` | 403 | `by` заявляет не член (и не член за ним) |
| `no_shared_doc` | 403 | проверенного документа нет |
| `no_item` | 403 | подходящих включённых элементов нет |
| `no_home` | 403 | дом цели не определить |
| `no_audience` | 403 | аудитория пуста или с не членом |
| `no_centre` | 409 | нужен центр, его нет в топологии |
| `deposed` | 409 | процесс смещён ([P/08.8 Н1.6](08.8-domain.norms.md)), тело с `holder` |
| `standby` | 503 | процесс `domain` — ждущий ([P/08.10 Н1.7](08.10-domain.norms.md)) |
| `unavailable` | 503 | `domain/topology` не читается, а области нужна топология (Н3 «выдать» шаг 4а) |
| — | 413 `{error: "refused", detail}` | [договор местной двери токенов](../../common/contracts/local-token-door.md) `refusal_413` (тело больше TOKEN_BODY у местной двери агента, больше TOKEN_HOLDER_BODY у двери держателя — до подписи и разбора; Б-31); тело отказа — общая форма [P/08.3 Н4](08.3-domain.norms.md) (добавлено сверкой М11, D11) |

Отказы местной двери «у агента» (401/404/400, 502 `invalid token reply`, 503 `unavailable`) — [договор местной двери
токенов](../../common/contracts/local-token-door.md) «Отказы» (разбор ревью стадии A 8–10, № 1 / решение 1).
Отказ у получателя (`wrong_kind`, `wrong_audience`) — [P/03.7 Н4](../../03-worker/spec/03.7-worker.norms.md) (стадия B).

## Н5 Приёмка

Каталог [`acceptance/7/`](../acceptance/7/README.md): 3 сценария / 27 шагов — стенд нескольких кластеров главы 8.3 с
местной дверью агента (каталог `testsub` и `testsub2`, как глава 8.5); сценарии 01, 02 из М11/07 (номера и шаги
прежние), сц. 03 — framing местной двери (догадки стадии C LTD-E01, LTD-E02). Выдача на всех областях и словах — вектор [`issue`](../vectors/issue/README.md) (30 строк, бывший сц. 03 приёмки
М11/07). Отказы объявления — случаи `m57_tokens_*` корпуса главы P/02.1 ([P/02.1 Н1.2б](../../02-installer/spec/02.1-installer.norms.md)).

```yaml
issue:      вход {domain, sub, kind, decl: <объявление вида> | null, role, member, body, members: [<член>…], holder,
                  placements: {"<sub>/<ref>": {cluster, origin, copies} | "garbled"}, topology: {centre?, star, via},
                  units: {<sub>: {<ref>: [<член>…]}}, shared: {<doc>: {<items>: [...]}} | null, now}
            вывод {result: ok, claims: <payload Н1.4 без jti>} | {result: refused, status, reason}
exit:       0 — вычислено; 2 — вход не по форме, в том числе decl не по форме загрузки P/02.1 Н1.2б (lifetime ≤ 0 или не число,
            claims или grant пусты, область не по форме): такое объявление загрузчик отверг бы (добавлено сверкой М11, T4);
            запись placements без copies — не вход не по форме, а нечитаемая запись (Н3 шаг 5)
```

| № | Сценарий | Нормы |
|---|---|---|
| 01 | стенд: `tally` члену из `origin` назначения — токен; принят кластером из `aud`, отвергнут кластером вне `aud` (`wrong_audience`) и с чужим видом (`wrong_kind`) | Н1.3, Н1.4, Н3 (местная дверь — договор местной двери токенов, глава 9.1; проверка у получателя — P/03.7 Н1.5, договор токена домена: соседи на стенде) |
| 02 | стенд: роль не в `grant`, член не `origin`, назначения нет — 403 со словом; `<sub>` не из каталога — 404 у агента (сверка М11, T8) | Н1.3, Н3 (шаги 6, 8, 12 — отказы местной двери агента: сосед на стенде) |
| 03 | стенд: местная дверь агента — второй `Host`, второй `Content-Length`, `Transfer-Encoding`, заголовки больше 16 KiB — 400 `bad request`; тело больше `TOKEN_BODY` — 413 `refused`; ответ с `Connection: close`; срок ввода — чтением | договор местной двери токенов «Дверь» `framing`, «Отказы» (догадки стадии C LTD-E01, LTD-E02) |
| вектор `issue` | placement, unit (`self`, `poll_home`), переход placement → unit, scenario (прямо, за ретранслятором, подъём, дом по назначению), все слова отказов; запись без `copies` — `assignment_unreadable` (сверка М11, T2) | Н3 |

Проверяются чтением: `TOKEN_HOLDER_BODY` у держателя (стенд не шлёт держателю тело мимо агента; пределы 4608/4609 сверены
у обеих реализаций сверкой М11 01–04); `decl` не по форме загрузки — код 2
(сверка М11, T4).
