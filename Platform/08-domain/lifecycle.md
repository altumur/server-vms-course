# Процесс `domain` — жизненный цикл (урок P/08)

Контракт жизненного цикла процесса (ADR-0083 доп. (2) п. 1): как его запускают, чем настраивают, что он держит на диске,
чем выходит. Строки ссылаются на главы урока (`spec/08.K-domain.norms.md`), уроки модуля, договоры, главы урока P/09, главу 6.7 и урок P/10 (переносы
уроков 8–10, стадия B); нормы здесь не повторяются.

## Запуск

- Юнит `w2c-domain.service`, роль `domain`, раннер `w2c-run.sh domain`, `User=w2c`, группы `w2c-store w2c-events
  w2c-secrets` — [P/02.4 Н1.12](../02-installer/spec/02.4-installer.norms.md) «Порты и юниты домена» (P/02.4-13).
- Общее юнитов (`Restart`, `RestartPreventExitStatus=2`, раннер, `ProtectSystem`) — P/02.4 Н1.1 `common`.
- Только у кластера-держателя. Процессов может быть несколько (узлы кластера), активен один — очередь
  `domain/signer-turn` ([P/08.10 Н1.7](spec/08.10-domain.norms.md)).
- Домена процесс не основывает: установку делает команда оператора, один раз на домен
  ([P/02.4 Н3 «установка домена»](../02-installer/spec/02.4-installer.norms.md), P/02.4-10); без строки
  `domain/signer` процесс ждёт её раз в `VIEW_EVERY` и роль держателя не берёт ([P/08.2](spec/08.2-domain.norms.md) Н3
  «процесс `domain` домена не основывает», «холодный старт»).

## Окружение

Канал настройки — только окружение P/02.4 Н1.2 и раскладка `PLATFORM_DIR` (второй пилот, Н-4).

| Переменная | Смысл | Умолчание | Норма |
|---|---|---|---|

| `SECRETS_KEY` | кольцо (credential): ключи держателя, `book_seal` — конверты кольца | — | [P/08.2 Н1.3, Н1.4](spec/08.2-domain.norms.md); [P/06.2](../06-console/spec/06.2-console.norms.md) Н1.2 (`holders`); [договор запечатывания](../common/contracts/sealing.md) |

и [договор сертификата роли](../common/contracts/role-certificate.md).

## Флаги

Нет: канал настройки — только окружение (P/02.4 Н1.2).

## Каталоги и файлы

- Строки и объекты держателя — в хранилище и хранилище объектов своего кластера; семьи и их писатели — каталог данных
  [`common/data/catalog.tsv`](../common/data/catalog.tsv) (владельцы — главы P/08.K, P/09, P/06.7 и урок P/10).
- Кольцо `SECRETS_KEY` — по раскладке `<PLATFORM_DIR>/etc/secrets/platform.key` (`/etc/w2c/secrets` — ссылка), вне каталога
  хранилища, корня объектов и корня событий (P/02.4 Н1.1 `dirs`, Н1.2); на стенде — `{data}/etc/secrets/platform.key`.
- Файл восстановления — у оператора: создаёт установка, режим 0600, вне каталогов хранилища (P/02.4 Н3 «установка
  домена», шаг 3; форма — [P/08.2](spec/08.2-domain.norms.md) Н1.1); процесс его не читает. Нужен установке, плановой смене
  ключа токенов, смене ключа приёма книг и смене после кражи (P/08.2 Н1.1 `needed_for`; перенос — `w2cctl domain move`,
  [P/08.8](spec/08.8-domain.norms.md) Н1.8; разбор ревью стадии A 8–10, № 33).
- Журнал роли — `<корень событий>/audit/domain/e1/…` ([договор журнала событий](../common/contracts/event-journal.md) `journal`).

## Коды выхода

| Код | Когда | Норма |
|---|---|---|
| 2 | отказ старта по манифесту, правам, схеме — без перезапуска | P/02.4 Н1.1 `common` |
| ≠ 0 | иной сбой; юнит перезапускает | P/02.4 Н1.1 |

Без строки `domain/signer` процесс не выходит, а ждёт (P/08.2 Н3 «процесс `domain` домена не основывает»).

## Сигналы и готовность

- Очередь `domain/signer-turn`: захват и продление — алгоритм `placement_turn` (TURN_TERM 45, TURN_RENEW 10); каждая
  запись строки держателя — под стражем очереди ([P/08.10](spec/08.10-domain.norms.md) Н1.7 `turn`, `guard`).
- `SIGTERM` — отдать очередь (`holder ""` по CAS своей версии); `SIGKILL` — очередь берут по TURN_TERM (P/08.10 Н1.7
  `release`).
- Без очереди — ждущий: прохода нет, каждая дверь отвечает `503 standby` до чтения тела (P/08.10 Н1.7 `standby`).
- Проход держателя — раз в `VIEW_EVERY` (3 с; [P/08.1 Н3](spec/08.1-domain.norms.md)).

## Стенд

Стенд нескольких кластеров — раздел «Стенд домена» [общего README приёмки](../common/acceptance/README.md): `@install domain` — установка
с `{domain}` и `{recovery}`; `@start domain` — процессы `domain` и консоли домена на `hold`; `@start domain on
<кластер>` — без установки; `@start domain second` — вторая копия с тем же `{data}`; `@move` — перенос. Дверь `signer` —
через посредника раннера (`DOMAIN_URL` агентов). `{data}` — `PLATFORM_DIR` кластера ([общий README приёмки](../common/acceptance/README.md) «Стенд»; разбор ревью стадии B 3–5, № 33).
