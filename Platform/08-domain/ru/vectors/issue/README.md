# Векторы выдачи токена воркера

Текст производный от `vectors/issue/README.md`, руками не правится: источник — английский [`vectors/issue/README.md`](../../../vectors/issue/README.md), правка идёт в него, русский пересобирается переводом.

Векторы функции `issue` [главы P/08.7](../../spec/08.7-domain.norms.md): выдача токена держателем без хранилища, сети и
стенда — вход — объявление вида, роль и член-заявитель, тело просьбы, назначения, топология, единицы членов, общий
документ и `now`; вывод — утверждения токена без `jti` или отказ `{status, reason}` (N1.1 `computed`, N1.3 `body`, N1.4,
N3 «выдать» шаги 2–7; N5 «`issue`»). Шаги 0–1 (смещённый процесс, подпись агента) вход не несёт. Владелец — урок P/08,
глава 8.7; функцию исполняет процесс `domain` на двери `POST /api/tokens/<член>/<sub>/<вид>`. Байты пишет «Спецификация»;
соответствие продукта — его приёмкой по этой таблице.

`case` — имя случая, `note` — примечание к строке.
Вход — текст JSON одной строкой: сняты только незначащие пробелы вне строк; порядок ключей, лексемы чисел и значения
сохранены как есть. Ожидание записано, как в шаге стенда после `ok `. Таблица — единственный источник этих случаев.

## Прогон

Без стенда: команда `issue` реализации получает вход (колонка `input`) и печатает JSON; `expect` — подмножество полей
вывода по словарю «Стенда» ([общий README приёмки](../../../../common/ru/acceptance/README.md), `<код> <JSON>`: названные поля
есть и равны, массив — по длине, порядку и элементам, число — по значению) или `@exit 2` (вход не по форме N5, в том числе
`decl` не по форме загрузки [P/02.1 N1.2b](../../../../02-installer/ru/spec/02.1-installer.norms.md)).
`iat`, `exp` — от `now` входа, не от часов процесса.

## Входы

Вход — N5 главы: `decl` — объявление вида (`null` — вида нет), `role` — роль, которую удостоверил агент, `member` —
член-заявитель, `body` — тело `{request_id, ref, by?}`, `members`, `holder`, `placements` (`"garbled"` — запись нечитаема,
запись без `copies` — тоже нечитаема), `topology` (`centre?`, `star`, `via`), `units` — владельцы единиц по ref, `shared` —
общий документ, `now` — 1760000000. Домен — `acme`; члены — `hold`, `m1`, `m2`, `relay`. Объявления видов во входах — виды
`tally`, `probe` манифеста `testsub` и `feed`, `tally2` манифеста `testsub2` из данных спецификации
([`testsub`](../../../../common/data/testsub/testsub.subsystem.yaml),
[`testsub2`](../../../../common/data/testsub/testsub2.subsystem.yaml)) — входы несут их целиком и от байтов манифестов не
зависят. Строки `issue-31`…`issue-35` несут объявление `tally` с изменённой областью `placement` (`target_fields`
`[cluster, star_centre]` или `[cluster, origin]`, `caller: copies`) — по форме загрузки P/02.1 N1.2b,
не байты манифеста.

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок.

Векторы проверены оракулом по тексту норм (N1.1 `computed`, N1.3 `body`, N1.4, N3 «выдать»), не по коду реализаций: вывод
оракула содержит ожидание каждой строки. Строки `issue-31`…`issue-38` — входы `issue-01` и `issue-17` с правкой, названной в `note`.
Векторы не покрывают пропуск элемента `scenario` без поля по пути `act`: у
объявлений манифестов (`tally2`: `act` `then`, `target` `then.item`) элемент без `act` не имеет и `target` — он отсеян
раньше, правило пропуска так не отличить (чтением). При расхождении прав текст нормы, вектор правит «Спецификация».
