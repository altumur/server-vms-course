# Формы P/08 и швы процесса

Текст производный от `forms/README.md`, руками не правится: источник — английский [`forms/README.md`](../../forms/README.md), русский пересобирается переводом (ADR-0121). Формы выражают существующие нормы по ADR-0125 доп. (5).

## Входы и константы

[daemon-flags.tsv](../../forms/daemon-flags.tsv) объявляет 20 входов окружения и существующее позиционное имя first-admin с общей шапкой. `$NAME` остаётся окружением; commands=domain — роль процесса. Полные договоры запускателя, алиасов, каталога, экземпляра, кольца, TLS и адресов сохраняются. Неподтверждённые входы операции сохраняют свои исходы. Без строки signer процесс ждёт; форма не превращает ожидание в отказ старта. Логический вызов first-admin обозначает выбранную реализацией операторскую команду с обязательным именем человека, не задаёт имя исполняемого файла. Пароль по-прежнему приходит через stdin по P/08.4 N1.9 (весь UTF-8 с удалением не более одного конечного LF/CRLF), не через новый флаг или значение окружения.

[runtime-constants.tsv](../../forms/runtime-constants.tsv) объявляет 26 положительных целых литералов с общей шапкой `name value unit norm meaning`. Единицы — count, s, bytes. Count означает кодовые точки Unicode, когда meaning говорит о символах. KiB/MiB переведены в точные байты. Условные формулы камер, период агента и зависимые границы остаются в разделах-владельцах; MARK_REFRESH = LOST_AFTER/2 остаётся производной дробной длительностью без округления. Константы не являются настройками окружения.

## Каталог отказов

[refusals.tsv](../../forms/refusals.tsv) сохраняет все 154 исходные строки N4 и два явных операторских отказа first-admin из N1.9 как 178 проекций. Четыре ячейки сохраняются ровно в cause/outcome/diagnostic/caller; третья ячейка 8.1 называлась Body. Трёхколоночные таблицы 8.4, 8.7, 8.8, 8.9 сохраняются в word/outcome/cause, diagnostic/caller — `-`. Word — исходная нормативная ячейка: индексированные слова не являются свободным выбором error или reason. Проекция действует под исходным условием и операцией.

HTTP-схемы называют существующие компоненты урока. Fields перечисляет прямо объявленные обязательные свойства; унаследованные/составные и условные требования остаются в полном OpenAPI и исходных ячейках. Отказы нативной формы и выходы оператора сохраняют свои правила кода. Отказ одного члена в relay или поздний исход сохранённой правки не становится новой ошибкой HTTP. Успех старой дороги имеет оболочки Carry прямого вызова и RelayAnswer ретранслятора, выбираемые настоящей операцией. Динамический Retry-After и условные detail/reason/field остаются в полных нормах-владельцах, без вымышленных фиксированных значений заголовков. Прежний закрытый словарь error остаётся в data/refusal-words.tsv.

## Версионные двери

[versioned-doors.tsv](../../forms/versioned-doors.tsv) — источник прежней таблицы P/08.0 N1.9: 19 проекций операций из 16 строк. Закрытая шапка — `method path row revision etag if_match absent_revision norm`, разделитель — TAB. Пара method/path уникальна и существует в OpenAPI урока. Каждая операция OpenAPI с ETag или If-Match имеет строку. Batch остаётся в таблице, хотя не объявляет ни один из заголовков. Norm — непустой список существующих req-якорей урока через запятую.

У row три вида. Литерал или шаблон выбирает прежнюю строку версии по её семье; placeholder `<name>` — захват пути OpenAPI этой операции. Единственное исключение `<part>` — раздел списка членов, вычисляемый обычным ядром, не новый параметр двери. `-` означает отсутствие прежней версионной строки при создании. `writes[]` означает каждую отдельную строку batch, это не ключ хранилища. Revision закрыт значениями doc.rev, revision, rev: логическое поле версии раскодированной по норме семьи, не произвольный язык выражений. Разрешение строки, отсутствующие/нечитаемые поля и все guards ссылок остаются обычной процедурой семьи/ядра.

Etag — true или false. True означает ETag успеха как индекс результата в двойных кавычках, а не счётчик revision. Индекс даёт настоящая процедура записи/повтора; создание с row=- тоже выдаёт заголовок успеха. False означает отсутствие ETag. DELETE члена сохраняет ETag изменённой строки списка; DELETE человека/группы/роли/назначения и POST batch его не выдают. Наличие выбирается таблицей, не общим правилом по методу.

If_match — optional, ignored или base-rev. Optional проверяет и судит необязательный заголовок по P/08.0-R006. Ignored не читает его на POST создания и POST batch. Base-rev даёт приоритет If-Match и использует base_rev только без заголовка; несовместимые оба значения дают прежний отказ (400 refused, field /base_rev); индекс рядом с base_rev несовместим по норме. Такие строки обязаны назвать P/08.0-R006 в norm. Порядок личности, памяти повторов, существования строки и условия остаётся P/08.0-R006/R007, в том числе повтор не судит прежнее условие заново.

Absent_revision закрыт значениями 0 и `-`. Ноль даёт revision 0 только для подтверждённо отсутствующей выбранной строки, в том числе первой записи topology/shared и других создающих путей/счётчиков из их строк. `-` не даёт счётчик отсутствия: действует собственное правило создания или отсутствующей строки операции. Ошибка транспорта или неподтверждённое чтение не становится revision 0. Для writes[] политика применяется к каждой записи. Row=- и writes[] различны даже при игнорируемом If-Match.

Метаданные принадлежат core; нового значения KIT_PARTS нет. Исходные четыре английские ячейки однократно сверены при переносе без потерь и не дублируются отдельной нормативной колонкой.

## Швы и этапы

[stages.tsv](../../forms/stages.tsv) задаёт 13 этапов: основа, доверие, turn, люди, приём, вид, книги, правки, выдача, перенос, shared, проверка процесса и полная приёмка. Во всех kit=-: ни один этап целиком сгенерированным не объявлен. 35 CALL-швов в acceptance/0…10/seams.tsv — помощь для пакета, не зачёт урока. Нормы и обычные сценарии глав, все назначенные свои/общие векторы, дополнительные пробы и чтение остаются обязательными. Полный domainstand требует настоящие процессы 08–10; самостоятельные алгоритмы и процесс 08 можно строить раньше соседей, но P/08 GREEN до полной приёмки нет.

Грамматика CALL/JSON — [P/02](../../../02-installer/ru/forms/README.md): один вход JSON, один ответ JSON; объекты сравниваются рекурсивным подмножеством, массивы точно, пустой объект точно пустой. Порты адаптируют обычные функции, HTTP и команды реализации, не задают новую публичную API. Ожидание нельзя возвращать как готовый результат; паника, посторонняя ошибка и неисполненный вызов проваливают шов.

У каждого случая новый временный корень и валидный нейтральный фон: каталог, домен/члены/права, ключи и криптографические доказательства, подтверждённые строки и собственный turn, если вмешательство не меняет именно их. Нейтральный вход не означает unknown. Фикстуры задают реальные данные и управляемые I/O/часы/гонки; обычное решение ядра не подменяется. Счётчики — реальные эффекты с именованными целевыми ключами, без технических диагностик. Секреты — только тестовые, наружу выдаются результаты сравнения, не байты секретов.

| CALL-порт | Вмешательство и наблюдение |
|---|---|
| `domain-versioned-edit` | Обычная запись/повтор с допущенным человеком и своим turn. Потеря ответа — после настоящей атомарной target+claim записи. Повтор несёт прежние body/key и If-Match; сравниваются реальные байты ответа и ETag. Две несовместимые версии — существующая topology; unknown claim не отсутствие. |
| `domain-view-round` | Настоящий наблюдатель держателя над Entry и mark. Новый наблюдатель сервера не видел смены revision. У камеры Entry.class=camera и настоящий received_at метки; класс не выводится из silent_after, received_at не заменяется heartbeat.ts. Unknown часть не становится пустой. |
| `domain-key-state` | Обычные старт/turn/чтение ключей и prepare. У prepare настоящие валидные root/set/подпись и обычная генерация X25519; отсутствует только местная signer-строка. Процесс не основывает root или signer держателя из-за отсутствующей/нечитаемой строки. |
| `domain-report-admit` | Настоящий валидный подписанный агентом full/delta report, кроме случая испорченной подписи. Unknown old copy и unknown исход записи поколения вводятся на настоящих I/O границах. Наблюдаются принятые поколения и записи mark; unknown поколения не успех. |
| `domain-first-admin` | Настоящая выбранная реализацией команда/точка first-admin с позиционным именем и stdin. Неверный UTF-8 — байт ff; валидный пароль проходит обычную норму. Подтверждённо пустой список и перечисленный нечитаемый человек различаются. Считаются реальные user/grant записи. |
| `domain-role-version` | Чтение и правка настоящей roles/groups строки с валидным payload и нечитаемой строкой revision. Назначения/состав сохраняются, дверь версии даёт 0, следующая обычная запись 1. Это не подмена native verdict family-read. |
| `domain-book-assemble` | Обычные чтение вкладов и сборка объявленной книги. Один настоящий секретный конверт не открывается, либо два читаемых неравных значения совпали по unique ref. Наблюдаются реальные диагностика и ключи результата, не предсказанный флаг. |
| `domain-edit-accept` | Настоящие член, живой обычный исполнитель, объявление правки и ключ члена; ambiguous — два подходящих исполнителя. Настоящий m1 открывается ключом члена с проверкой edit+field+value. Проверяются pending/asked/журнал на plaintext. Другой секрет с тем же ключом идёт через обычную память; pending_appends считает новые правки обоих запросов. |
| `domain-token-issue` | Обычная HTTP-выдача объявленного вида с настоящими ключами и правом. Oversize на байт выше опубликованного предела этой операции. Unknown отзывы не пустое множество. Keep под freeze включает прежний сохранённый токен: заморожен весь запрос. |
| `domain-handover` | Настоящие freeze/backup/prepare/take/forget с обычными криптографией и записями term. Unknown forced backup/stranded вводится только на этой записи. Успешный take действительно проверяет и принимает term; поздний отказ stranded его не отменяет и не возвращает вымышленный stranded. |
| `domain-backup-restore` | Создать, подписать, запечатать, открыть и восстановить настоящую копию. Один объект читается семьёй, второй — неверные JSON-байты, третий — ноль байт. Читаемый JSON сравнивается значением JCS, raw — байтами, включая пустоту. |
| `domain-shared-edit` | Валидная подписанная правка shared с подходящим условием, кроме названного документа/секрета/гонки. При гонке настоящий pointer меняется до commit. Считаются эффективные pointer-записи, безвредный осиротевший объект не считается pointer. |
| `domain-turn-door` | Вызвать обычную дверь процесса при чужом turn, наблюдать настоящие чтения тела. Standby отвечает до тела. |
| `domain-turn-object` | Обычная запись mutable view с настоящими версиями объекта. Events — отфильтрованный I/O порядок get_at, свой turn CAS, put_at этой записи. После нашего подтверждения новый владелец реально пишет объект, наш old-index put_at конфликтует; наблюдаются перечитывание turn и потеря active. |
| `domain-turn-write` | Unknown исход настоящего turn-guarded row batch. Наблюдаются вход в барьер процесса и отсутствие слепой повторной записи; восстановление следует обычной процедуре чтения turn/store. |
| `domain-turn-release` | Настоящий SIGTERM release. До его CAS свой turn заменён реальным другим владельцем/версией. Новый владелец сохраняется, без unconditional clear. |
