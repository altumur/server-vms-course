## Стенд

Подготовка — как README приёмки [главы 8.3](../3/README.md) («Подготовка каждого сценария», из M11/03: кластеры `hold`, `m1`,
`m2`, каталог `testsub`), с объявлением общего в `testsub`:
- `domain.shared: [step, marks, {rounds}]`;
- `step` — `int` с `inherit: 1`;
- `marks` — `list` с `inherit: []`, `merge: union`.

Раннер ходит человеком `root` (первый администратор — глава 8.4, директива `@person`).

Соседи на стенде: правку передаёт процессу консоль домена (`holder PUT`, урок P/10, глава 8.0); `GET /domain/shared`
(шаги 02, 14) — дверь консоли домена (урок P/10, P/10-14), содержимое `delivery` — `view.shared` этой главы (N1.6); документ
берёт агент члена ([глава 9.1](../../../../09-agent/ru/spec/09.1-agent.norms.md), P/09.1-12); значение при чтении `GET /domain/shared/testsub` (шаги 11–13, 16) — консоль кластера
(OpenAPI урока 6 `GET /domain/shared/{sub}`); единицы `c5`, `c6` (шаги 09, 10) — дверь единиц P/06.1.
