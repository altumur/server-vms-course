## Подготовка

Как README приёмки [главы 8.3](../3/README.md) («Стенд», «Подготовка каждого
сценария»): раннер поднимает на одной машине три кластера — `hold`, `m1`, `m2`; у каждого своё пустое хранилище,
свой `{data}`, свои сокеты ролей и порты консоли и ресурса, своё кольцо (P/06.2 N1.2), каталог манифестов — только `testsub`
(`domain.ref: name`); консоль, контроллер и воркер `w-1` `testsub`, ресурс своего сервера (`srv-hold`, `srv-m1`, `srv-m2`).
Единиц нет. Домена нет: его ставит директива `@domain` первого шага каждого сценария. Имя домена — `acme`; файл
восстановления — `{recovery}` в каталоге экземпляра.

Часы не ускорять: LOST_AFTER 45 с, REPORT_EVERY 5 с, MARK_REFRESH 22,5 с, SHADOW_STALL 60 с; сроки `@until` взяты с
запасом. У двери `holder` раннер ставит `Idempotency-Key` и у `PUT` (назначения — глава 8.6).

## scenarios.tsv

Формат — словарь «Стенда» и словарь домена; ожидание — подмножество полей.

Часть сценариев использует настоящие отчёты агентов в `domain/members/<member>/reports/<rev>` и вид держателя (векторы `view`).
