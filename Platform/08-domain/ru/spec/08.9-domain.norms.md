## N1 Форма

**Время.** Поля времени строк и объектов главы — время по [канону N0](../../../01-store/ru/spec/01.1-store.norms.md#время-в-строке):
объект истории `domain/alarm-history/<member>` — `events[].t`, `cut_before` (писатель — не больше трёх знаков дроби;
добавлено сверкой M11, A22). Объект страницы `domain/alarms` (`from`, `to`) — [глава 9.1](../../../09-agent/ru/spec/09.1-agent.norms.md) N1 «Время».
Документ `domain/shared-docs/rev-<rev>` (N1.2 document) — `at`: число JSON ([договор записи
срока](../../../common/ru/contracts/record.md), шаг 1), не строка (решение «Архитектора» 2026-10-20).

**Данные** ([каталог](../../../common/data/catalog.tsv)):
- владеет: `domain/shared`, `domain/shared-docs/rev-<rev>`, `domain/alarm-history/<member>`;
- пишет: `<events root>/audit/<role>/e1/<YYYYMMDDTHHMMSSZ>.events.jsonl` (append);
- читает: `platform/manifest/<sub>`, `domain/holder`, `domain/member-rows/<part>`, `domain/view`, `domain/signer`, `domain/signer-turn`, `domain/members/<member>/reports/<rev>`, `domain/members/<member>/reported`.

Строка `domain/shared` — указатель у держателя (N1.2) и строка копии у члена: протокол строки задаёт держатель, агент —
участник `cas` ([глава 9.1](../../../09-agent/ru/spec/09.1-agent.norms.md) N1.10); объект `domain/shared` у члена (копия документа) — семья агента. Объекты
`domain/shared-docs/rev-<rev>` и `domain/alarm-history/<member>` пишет только процесс `domain` (ADR-0032): документ — без стража,
раньше указателя; указатель — по CAS прочитанной версии со стражем `domain/signer-turn` ([P/08.10 N1.7](08.10-domain.norms.md));
история — по CAS, `put_at` по индексу объекта ([P/08.10 N1.7](08.10-domain.norms.md) `objects`). Манифесты каталога (`domain.shared`,
схема документа) процесс читает строками `platform/manifest/<sub>` (N1.3 шаг 4); подпись — выпускающим ключом строки
`domain/signer` ([договор записи срока](../../../common/ru/contracts/record.md), `issuing_key_secret`); срок — запись
`domain/holder` (глава 8.8); членов — список `domain/member-rows/<part>`, их состояние — вид `domain/view` (глава 8.1); копии членов
(`domain/shared`, `domain/shared-refused`) и страницу тревог — объекты отчёта `domain/members/<member>/reports/<rev>`,
`received_at` и `sent_at` отчёта — метка `…/reported` (глава 8.3). Журнал `domain.shared.edited` (N1.3 `answer`) процесс
дописывает в `audit/domain` по [договору журнала событий](../../../common/ru/contracts/event-journal.md) (участник `append`,
владелец — P/05).

Общее N1 урока P/08 ([P/08.2 N1](08.2-domain.norms.md) «Общее для всех форм главы», [P/08.3 N1](08.3-domain.norms.md)) действует. Домен не знает ни одного поля подсистемы
(ADR-0010): что общее, объявляет манифест, а значение домена разрешается **при чтении**, не записью в строки. Тревоги членов
домен собирает из их отчётов: к члену он соединений не открывает. Решение «Архитектора» по вопросам M11/11; C6 «точный
документ».

### N1.2 Общий документ

```yaml
document:        объект держателя domain/shared-docs/rev-<rev> — JCS {domain, term, rev, at, by, shared, issuer, kid, sig}
  shared:        {<sub>: {<имя>: <значение>}} — только объявленное P/02.1 N1.2b; подсистемы и имена по возрастанию (JCS)
  term, rev:     срок держателя (P/08.8) и номер правки; порядок — (term, rev), term старше
  by:            имя, доказанное сторожевой; после переноса — "domain"
  signature:     выпускающий ключ, как запись срока (договор записи срока, record.md; проверка — функция record); неподписанный
                 не принимается никогда
pointer:         domain/shared {doc: JCS {term, rev, sha256, object}} у держателя; sha256 — hex sha256 текста объекта;
                 object — ключ этого объекта, строка "domain/shared-docs/rev-<rev>" с rev указателя (разбор ревью стадии A 8–10, № 26)
write:           сначала объект, затем указатель по CAS (две правки одновременно — одна получает 409); держатель хранит
                 последние 5 объектов. Правки общего документа процесс исполняет по одной (шаги N1.3 order 3–6 — одна
                 правка за раз). Объект ревизии — порядком G6, как объекты без указателя (P/08.10 N1.7 objects): снимок
                 указателя domain/shared (по нему объект признаётся ничьим) → get_at объекта ревизии → подтверждение своей
                 очереди domain/signer-turn → запись по индексу ЭТОГО get_at (договор клиента хранилища объектов «Операции» ops): объекта не было — put_new;
                 есть с теми же байтами — не писать; есть с другими байтами — указатель его не называет (rev объекта выше
                 rev указателя: прежняя правка оборвалась между объектом и указателем), объект ничей — put_at поверх
                 (решение «Архитектора» 2026-10-20 по вопросам сборки урока 8, п. 2; решение «Архитектора», разбор ревью стадии B 8–10, № 1, ADR-0083 доп. (15)); очередь потеряна между
                 чтением и подтверждением — правке 503 по P/08.10 N1.7, объект не тронут; put_new или put_at получил
                 conflict — объект сменился после get_at, его пишет другая правка или другой процесс: правке 409 «the shared
                 settings changed while this edit was made — look again», объект не трогается — проигравшая правка не
                 перезаписывает объект выигравшей (добавлено сверкой M11, A1)
after_move:      новый держатель (P/08.8 N1.8 шаг 8; сумма не совпала ни у одной копии — не переподписывает; на исключении шага 3 указатель идёт пакетом шага 8, C08-SHARED-SPLIT-BATCH-01) переподписывает то же содержимое как rev + 1, by "domain" — у него другой
                 выпускающий; при плановой передаче выпускающий тот же, документ не меняется
readers:         процесс domain, консоль домена, воркер подсистемы на домене (роль <sub>domain) — указатель domain/shared
                 (точное имя) и объекты domain/shared-docs/rev-* (семья domain/* двери объектов P/05); консоль кластера — строка domain/shared (точное имя: у держателя
                 указатель, у члена строка копии, N1.4; P/02.5 N1.4 console, добавлено M11/11); воркер подсистемы по worker.reads domain/shared — у члена строка копии и объект domain/shared,
                 у кластера держателя указатель и объект по его полю object; сумму и подпись сверяет сам, не сошлось — прежнее значение (C08-CATALOG-SHARED-WORKER-01); проекций по подсистемам нет (C6)
```

### N1.3 Правка

```yaml
door:            PUT /domain/shared {base_rev?, shared: {<sub>: {<имя>: <значение> | null}}} и If-Match у консоли домена (admin, P/08.4;
                 урок P/10 N1.3) → процесс domain тем же путём (ADR-0032; глава 8.0); тело ≤ 1 МиБ (иначе 413 {error: "refused"})
order:           1. заморозка, смещение — P/08.8 (503 frozen, 409 deposed)
                 1a. заголовки и память повторов (глава 8.0 N1.9)
                 2. тело не {base_rev?: целое ≥ 0, shared: объект, каждое shared.<sub> — объект}, нет ни If-Match, ни base_rev либо они
                    расходятся (глава 8.0 N1.9 «base_rev») — 400 (shared.<sub> не
                    объект — тоже здесь, до base_rev; добавлено сверкой M11, A9) {error: "refused", detail: "the edit is {base_rev:
                    <the revision it was made against>, shared: {<sub>: {<field>: value or null}}}"}
                 3. ревизия раньше содержания: If-Match не равен версии указателя — 412 revision moved; заголовка нет и
                    base_rev ≠ rev указателя (0 — документа нет) — 409 {error: "refused", detail: "the shared settings are at
                    rev N; the edit was made against rev M — look again"}
                 4. содержание — все отказы одним 400 через «; »: «shared settings for '<sub>': no subsystem on the domain
                    shares a field by that name»; «'<имя>' is not in its domain.shared [<имена domain.shared манифеста через «, », по возрастанию>]»; тип поля — та же проверка
                    формы, что у двери единиц (P/06.1 N3 «создать» шаг 4), на одном этом поле, слово отказа — её; значение документа
                    против его schema (слова схемы); значение, которое консоль запечатала бы (P/06.2 N3) (имя *_secret на любой глубине,
                    находка пароля в адресе по P/06.2 N1.1a), — «'<имя>': the shared document is signed, not sealed» (сверка M11, A6)
                 5. новый документ: прежний shared, поверх — значения правки; null — снять имя; пустая подсистема —
                    снять; rev + 1, term — свой, at, by; прежний документ (объект, который называет указатель) не читается
                    или не с его sha256 — 503 {error: "refused", detail: "the shared document at rev N does not read: nothing
                    is written"}, ничего не пишется: правка поверх пустого потеряла бы прежние значения (сверка M11, A7)
                 6. записать (N1.2 write); целевая запись — указатель, объект идёт раньше него и повторяется без вреда (глава 8.0 N1.9 write);
                    CAS не прошёл — 409 «the shared settings changed while this edit was made — look again»
answer:          200 {term, rev, by}, ETag — индекс указателя; журнал domain.shared.edited {term, rev, by}
```

### N1.6 Доставлено скольким

```yaml
domain/view.shared:  {term, rev, holding, behind, refused, silent, sentence}       # P/08.1 N1.4, добавлено M11/11
  holding:     [<член>…] — копия члена ≥ (term, rev) указателя; держатель включён
```

### Семьи данных (построены из стандартных файлов)

Форма строк и объектов, которыми глава владеет по [каталогу](../../../common/data/catalog.tsv), — JSON Schema 2020-12 семьи (ADR-0092). Экземпляр строки — `{key, row}`, объекта — `{key, object}`; ключ — грамматика колонки `key` каталога. Поля `row` — значения `items` после [кодека](../../../common/data/codec.tsv): писатель проверяет схему и её `$defs.writer`, читатель — схему (слой 3 — слова `x-*` схемы). Нечитаемо — строка не раскодировалась или не прошла схему в режиме читателя; исход — по таблице исходов семьи: путь — префикс пути отказа (пустой — строка целиком), при нескольких путях отказа действует исход с наименьшим приоритетом.

#### `domain/shared` — строка

Схема — [`shared.schema.json`](../../data/shared.schema.json), исходы — [`shared.outcomes.tsv`](../../data/shared.outcomes.tsv); версия формы 1; норма — P/08.9 N1.2, N1.4.

| Ключ | Тип и границы | Обязательность | Урок | Смысл |
|---|---|---|---|---|
| `doc` | отображение `{term, rev, sha256, object?}`; в `items` — текст JSON, у писателя — JCS (x-encoding: jcs) | обязателен |  | JCS text of the pointer (at the holder) or of the copy row (at the member) |
| `doc.term` | целое; ≥ 1; ≤ 9007199254740991 | обязателен |  | term of the holder of the document (chapter 8.8, from M11/10 N1.1); order — (term, rev), term is senior |

| `doc.object` | строка; целиком `domain/shared-docs/rev-[1-9][0-9]*` | необязателен |  | key of the document object — the string `domain/shared-docs/rev-<rev>` with the rev of the pointer; only at the holder's pointer, the member's copy row has no field (N1.2 pointer; review analysis of stage A 8–10, № 26) |

## N3 Проход

Своих проходов, кроме порядка правки (N1.3 `order`) и писателя истории (N1.9 `writer`), у главы нет. «Взять документ»

[урок P/10](../../../10-domain-console/ru/spec/10-domain-console.norms.md) N3 `alarms`.

**Гонки.** Две правки общего документа — CAS указателя, вторая — 409. Держатель перенесён — новый переподписывает
документ (`rev + 1`), члены берут его как новый. Обрыв между объектом и указателем (N1.2 write): объект выше указателя
ничей, указатель прежний; следующая правка пишет поверх (N1.2 write: get_at → подтверждение очереди → put_at по индексу
этого get_at). Смена очереди между чтениями: активный A пишет объект N+1, смещённый S прочитал индекс до записи A — его
put_at получает conflict (409); S прочитал индекс после записи A — подтверждение очереди S не проходит (503), объект A цел
(решение «Архитектора», разбор ревью стадии B 8–10, № 1, ADR-0083 доп. (15); расписание Codex R-B810-01, Claude R-1). Член без связи и шторм тревог — [глава 9.1](../../../09-agent/ru/spec/09.1-agent.norms.md) N3 «Гонки» и урок P/10 (N3
