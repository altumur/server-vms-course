## N1 Форма

**Время.** Полей времени у строк и объектов главы нет: глава ничем не владеет. Утверждения `iat`, `exp` (N1.4) — стенные
секунды держателя; форма — [договор токена домена](../../../common/ru/contracts/domain-token.md) «Токен».

**Данные** ([каталог](../../../common/data/catalog.tsv)):
- читает: `domain/placement/<sub>/<ref>`, `domain/member-rows/<part>`, `domain/topology`, `domain/shared`, `domain/shared-docs/rev-<rev>`, `domain/members/<member>/reports/<rev>`, `domain/signer`, `domain/keys`, `domain/revoked` — для самопроверки выданного токена: дверь просьбы токеном не принимает; проверка не прошла или строка не читается — 503 unavailable (C08-TOKEN-SELF-CHECK-01); `domain/revoked` — ещё шаг 6a; `domain/issued/<sub>/<kind>/<sha16>` — шаг 6a.
- пишет: `domain/issued/<sub>/<kind>/<sha16>` (cas) — только вид с keep: true (N3 «выдать» шаг 6a, [глава 8.2](08.2-domain.norms.md) N1.6a).

Выдача вида без `keep` ничего не пишет (N3). Записи назначения — [P/08.6 N1.1](08.6-domain.norms.md), список членов —
[P/08.3 N1.1](08.3-domain.norms.md), топология — [P/08.3 N1.2](08.3-domain.norms.md), единицы членов (`units` копии) — поколения отчётов `…/reports/<rev>` (глава 8.3),
общий документ — указатель `domain/shared` и объект `domain/shared-docs/rev-<rev>` ([P/08.9 N1.2](08.9-domain.norms.md)), ключ токенов
держателя — `domain/signer` и набор `domain/keys` ([P/08.2 N1.2, N1.3](08.2-domain.norms.md); [договор набора ключей домена](../../../common/ru/contracts/keys.md)),
отзывы `domain/revoked` — [договор набора ключей домена](../../../common/ru/contracts/keys.md) «Отзывы».

Общее N1 урока P/08 ([P/08.2 N1](08.2-domain.norms.md) «Общее для всех форм главы», [P/08.3 N1](08.3-domain.norms.md)) действует. Токен воркера — токен домена
([договор токена домена](../../../common/ru/contracts/domain-token.md) «Токен») с `kind` вида манифеста. Ключ подписи держателя
воркеру не выдаётся, ключ члена — тоже. Токен у воркера (просьба через агента, только в памяти) и проверка у получателя —
[P/03.7 N1.5](../../../03-worker/ru/spec/03.7-worker.norms.md) (стадия B).

### N1.1 Вычисляемые значения

Объявление вида — [P/02.1 N1.2b](../../../02-installer/ru/spec/02.1-installer.norms.md) (стадия B; глава позднего слоя, вводит
урок 8). Вычисляемые значения `target_fields` (выдача, N3):

```yaml
computed:   centre, star_centre, poll_home — не поля записи и не поля единиц: вычисляются по топологии (P/08.3 N1.2)
            centre — topology.centre; star_centre — centre, если cluster записи в star, иначе ничего (в аудиторию не
            добавляет и не отказ); cluster в star, а centre нет — 409 no_centre;
            poll_home(член) — via[член], иначе centre, иначе держатель
```

Местная дверь агента (прежде N1.2) — [договор местной двери токенов](../../../common/ru/contracts/local-token-door.md) «Дверь»
(владелец — [глава 9.1](../../../09-agent/ru/spec/09.1-agent.norms.md) N1.6; участник P/03.7; разбор ревью стадии A 8–10, № 1 / решение 1).

### N1.3 Дверь держателя

```yaml
door:       POST /api/tokens/<член>/<sub>/<вид> у процесса domain; подпись агента (договор подписи агента); через ретранслятор —
            байт в байт, той же подписью (глава 9.2 N1.1 `not_author`, N2)
body:       {request_id, role, ref, by?, revoked?} — revoked: <jti> — получатель отказал этому токену словом revoked (P/08.2 N1.6a jti); у вида без keep — отказ 400 bad_request; role — роль, которую агент удостоверил; формы как у местной двери (договор местной
            двери токенов «Дверь»); больше TOKEN_HOLDER_BODY — 413
TOKEN_HOLDER_BODY: договор местной двери токенов (значение и смысл там; перенесено без изменения; аудит раскладки, решение «Архитектора» 2026-10-25, A-19)
answer:     200 {sealed: <m1 P/08.3 N1.5>} — внутри текст JSON {request_id, token, exp}
```

Конверт `m1` и его содержимое у двери токенов — [договор конвертов домена](../../../common/ru/contracts/domain-envelopes.md)
«Конверт `m1`», «Содержимое `sealed`»; `TOKEN_BODY` — [договор местной двери токенов](../../../common/ru/contracts/local-token-door.md).
Что агент делает с ответом (открыть `m1`; `request_id` ≠ запрошенного или `exp` ≤ now — 502 `invalid token reply`; иначе
отдать) — [глава 9.1](../../../09-agent/ru/spec/09.1-agent.norms.md) N1.6 `agent`.

### N1.4 Утверждения

```yaml
payload:    {iss: <домен>, sub: <член-заявитель>, kind: <вид>, iat: now, exp: now + lifetime, jti: 16 hex,
             <ref_claim>: ref, <audience_claim>: [<член>…] по возрастанию, без повторов,
             scenario: <trigger_claim>: by, <acts_claim>: [<act>…] без повторов по тексту JCS, по возрастанию байтов UTF-8
             этого текста, <up_claim>?: centre}
names:     ref_claim и audience_claim — из области, которая дала аудиторию (placement без записи упал на unit — из unit)
signed:     ключом токенов держателя (current набора, договор набора ключей домена; P/08.2 N1.2), JCS header и payload (договор токена домена «Токен»)
```

## N3 Проход

### выдать (процесс domain) — по порядку, первое правило даёт исход

```
0. процесс смещён (P/08.8 N1.6) — ключей токенов у него нет               → 409 deposed (с holder)
1. член, ключ, подпись — P/08.3 N2                                        → 404 / 403 / 401
2. тело не по форме N1.3 — закрытое {request_id, role, ref, by?, revoked?}          → 400 bad_request
3. вид не объявлен манифестом sub, или без области, или role ∉ grant          → 403 not_granted
4. by есть без scenario или нет у scenario                               → 400 by_misplaced
4a. область берёт значение топологии (centre, star_centre, poll_home, via — N1.1 computed), а domain/topology есть, но
    не читается → 503 unavailable, ничего не выдаётся, журнал без значения (V7 п. 3, решение «Архитектора» 2026-10-28, P1; строка 51 списка)
5. область:
   placement — запись <placement.sub>/<ref>:
     нечитаема (в том числе без поля copies или поле не по форме главы 8.6 N1.1; добавлено сверкой М11, T2)
                                                                         → 403 assignment_unreadable
     нет: есть unit — к unit; иначе                                      → 403 no_assignment
       (ключ записи, который хранилище именем не примет — длиннее предела ключа P/01.1 N1, 400 badkey, — записи нет,
        не «нечитаема»: такой записи быть не может; C08-ASSIGNMENT-BADKEY-01)
     имя записи (cluster, origin, copies) не член, или член ≠ поле caller → 403 outside_scope
       (origin "" — не имя: на членство не проверяется, в аудиторию не входит; caller origin при "" — outside_scope)
     аудитория: значения target_fields по N1.1 computed: centre без centre → 409 no_centre; star_centre — только
       при cluster записи в star (вне star ничего не добавляет, отказа нет), cluster в star без centre → 409 no_centre
       (добавлено сверкой М11)
   unit — владельцы ref (члены, чьи копии заявляют единицу с этим ref в units подсистемы unit.sub, глава 8.1):
     caller self: владелец — ровно этот член; caller poll_home: владелец один  → иначе 403 unit_not_unique
     caller poll_home: poll_home(владелец) ≠ член                         → 403 not_poll_home
     аудитория: значения target_fields — poll_home → poll_home(владелец), centre → centre (без centre → 409 no_centre)
   scenario — by:
     владельцы by и ref — в units подсистемы вида (sub манифеста, объявившего вид)
     владелец by один: член или член за этим ретранслятором (via[владелец] = член)  → иначе 403 trigger_not_reported
     общий документ doc (глава 8.9 N1.2, проверенный record — договор записи срока) → массив items; нет        → 403 no_shared_doc
     элементы: имя — строка, которая встречается в массиве один раз; enabled отсекает только false (нет поля —
       включён); target = ref, trigger = by; объявлен путь member и значение по нему непусто и не равно владельцу by — элемент пропускается: ref уникален только в кластере (C08-SCENARIO-MEMBER-01, решение «Архитектора» 2026-11-01, разбор инвариантов VMS); нет поля по пути act — элемент пропускается → acts; нет ни одного → 403 no_item
     дом: запись <placement>/<ref> — её cluster (в star — centre); записи нет — poll_home(единственного владельца ref)
       запись нечитаема, или cluster в star без centre — дома нет, к владельцу не переходить  → нет → 403 no_home
     аудитория (правила по порядку; дом посчитан раньше): подъём ретранслятора (заявитель — via владельца by) — [centre];
                заявитель за ретранслятором R: R = дом — [R], иначе [R] и up = centre;
                иначе — {дом} и centre, если он есть; у подъёма и за ретранслятором ≠ дом centre нужен → нет → 409 no_centre
6. аудитория пуста или с не членом                                       → 403 no_audience
6a. вид с keep, под общей стороной замка (P/08.2 N1.6a порядок): заморозка → 503 frozen; domain/revoked не читается → 503 unavailable; e = now + lifetime; строка domain/issued цели: CAS создания или продления max(exp, e); слово revoked равно jti строки, в пределах REVOKED_WORDS и строка domain/revoked не заполнена на 80 % (P/08.2 N1.6a) — пакет с ним в domain/revoked, новый jti → jti строки; конфликт — перечитать, до 3 раз, затем 503 unavailable
7. утверждения N1.4, exp вида с keep — e шага 6a, подпись, m1 члену   → 200
```

Кроме шага 6a ничего не пишется: выдача — чтение записей, топологии, копий и документа. `detail` отказа называет причину словами, без
значений документа и токенов.

Отказы шага 1 — глава 8.3 N2 и [договор подписи агента](../../../common/ru/contracts/agent-signature.md) «Проверка и слова
отказа»; единицы копий членов (шаг 5 `unit`) — [P/08.1](08.1-domain.norms.md); общий документ (шаг 5 `scenario`) —
[P/08.9 N1.2](08.9-domain.norms.md); запись назначения — [P/08.6 N1.1](08.6-domain.norms.md).

## N5 Приёмка

Каталог [`acceptance/7/`](../acceptance/7/README.md): 7 сценариев / 55 шагов — стенд нескольких кластеров главы 8.3 с
местной дверью агента (каталог `testsub` и `testsub2`, как глава 8.5); сценарии 01, 02 из М11/07 (номера и шаги
прежние), сц. 03 — framing местной двери (догадки стадии C LTD-E01, LTD-E02), сц. 04 — `TOKEN_HOLDER_BODY` у двери держателя (аудит покрытия P/08), сц. 05, 06 — нечитаемые назначение и топология (аудит покрытия P/08, второй проход Gemini). Выдача на всех областях и словах — вектор [`issue`](../vectors/issue/README.md) (38 строк: 30 — бывший сц. 03 приёмки
М11/07, 8 — аудит покрытия P/08, второй проход Gemini). Отказы объявления — случаи `m57_tokens_*` корпуса главы P/02.1 ([P/02.1 N1.2b](../../../02-installer/ru/spec/02.1-installer.norms.md)).

```yaml
issue:      вход {domain, sub, kind, decl: <объявление вида> | null, role, member, body, members: [<член>…], holder,
                  placements: {"<sub>/<ref>": {cluster, origin, copies} | "garbled"}, topology: {centre?, star, via},
                  units: {<sub>: {<ref>: [<член>…]}}, shared: {<doc>: {<items>: [...]}} | null, now}
            вывод {result: ok, claims: <payload N1.4 без jti>} | {result: refused, status, reason}
exit:       0 — вычислено; 2 — вход не по форме, в том числе decl не по форме загрузки P/02.1 N1.2b (lifetime ≤ 0 или не число, keep и lifetime больше KEEP_OLD,
            claims или grant пусты, область не по форме): такое объявление загрузчик отверг бы (добавлено сверкой М11, T4);
            мерило — «загрузчик отверг бы»: форма и связи P/02.1 № 99–110 (02.1-installer.relations.json: поля *_claim
            входят в claims и различны) над обёрткой {domain: {tokens: {<kind>: decl}}} — нарушение тоже код 2; № 97–98
            (нужен domain.ref манифеста, во входе его нет) не судятся (C08-ISSUE-DECL-RELATIONS-01);
            запись placements без copies — не вход не по форме, а нечитаемая запись (N3 шаг 5)
```

| № | Сценарий | Нормы |
|---|---|---|
