Контракт жизненного цикла процесса `console` (ADR-0083 доп. (2) п. 1). Стадия A: строки ссылаются на нынешние нормы
М10 и их не пересказывают.

## Запуск

- **Юнит** — `w2c-console.service` на каждом сервере; `User=w2c`,
  `SupplementaryGroups=w2c-store w2c-events w2c-secrets`, `SECRETS_KEY` ([P/02.4] Н1.1).
- **Запуск** — через раннер `w2c-run.sh console` с `W2C_ROLE=console` ([P/02.4] Н1.1, Н1.9).
- **Порядок старта** — проверка схемы, спеки из строк, оболочка `CONSOLE_ROOT`, перезапечатывание секретов, жнец
  просьб и отметки тел; удаление тел — только в окне обслуживания ([P/02.4] Н3 «старт сервера», шаг 4).
- **Модуль консоли** поставляется вместе с консолью — те же байты, что в спецификации; из каталога выгрузки во время
  работы не читается ([М10/9] Н1.1 `module`).

## Окружение

Окружение собирает раннер `w2c-run.sh` в порядке P/02.4 Н1.2: значения юнита → `roles/<W2C_ROLE>.env` → `w2c.env` →
файл подсистемы, раньше прочитанное побеждает; файлы — разбором, не `source` ([02-installer/lifecycle.md](../02-installer/lifecycle.md)).

| Переменная | Смысл | Умолчание | Норма |
|---|---|---|---|
| `W2C_ROLE` | роль `console`; не та роль команды раннера — код 2 | задаёт юнит | [P/02.4] Н1.2 |
| `PLATFORM_STORE` | дверь хранилища — сокет роли `configstore:///run/configstore/console.sock` | `file://<PLATFORM_DIR>/config` (профиль коробки одной реализации) | [P/02.4] Н1.2 |
| `PLATFORM_DIR` | корень состояния | `/data/platform` | [P/02.4] Н1.2 |
| `RESOURCE_ROOT` / `EVENTS` | корень событий своего сервера: журнал `audit/console` и отметки `console/<экземпляр>` | `<PLATFORM_DIR>/events` | [P/02.4] Н1.2, [М10/8] Н1.2 `writer` |
| `OBJECTS` / `PLATFORM_OBJECTS` | объекты: тела `blob`, отметки уборки | `<PLATFORM_DIR>/objects`; `cluster://` при configstore | [P/02.4] Н1.2 |
| `CONSOLE_ROOT` | подсистема, чья оболочка отдаётся на `/`; пустой или не из каталога — код 2 | — | [М10/9] Н1.1 `root` |
| `CONSOLE_HOST`, `CONSOLE_PORT` | адрес консоли | `127.0.0.1`, `8080` | [P/02.4] Н1.1, Н1.2 |
| `CONSOLE_TLS` | консоль по TLS; вне петли без комплекта — отказ старта | — | [P/02.4] Н1.2, [P/02.4] Н1.6 |
| `SECRETS_KEY` | путь кольца; не задан — режим разработки с громкой строкой; задан пустым — нечитаем, 503 | — | [М10/7] Н1.2 |
| `SERVER_NAME` | сервер | короткий hostname (`%l`) | [P/02.4] Н1.2 |
| `BOX_ID` | коробка; экземпляр `<коробка>:<pid>:<6 hex>` | `BOX_ID`, иначе `/etc/machine-id`, иначе hostname | [P/02.4] Н1.2, [М10/5] Н3 «старт()» шаг 2 |
| `CLUSTER` | имя кластера | `local` | [P/02.4] Н1.2 |
| `BUILD` | слово сборки в `/schema` | `dev` | [P/02.4] Н1.2, [М10/10] |
| `W2C_TLS_DIR` | корень комплектов; свой — `<W2C_TLS_DIR>/console` | `/etc/w2c/tls` | [P/02.4] Н1.2, Н1.6 |
| `LOGIN_URL`, `SIGNER_URL`, `DOMAIN_*`, `CLUSTERS` | домен (поздние главы урока 6) | — | [P/02.4] Н1.2 |
| `W2C_ENV` | файл общих настроек | `/etc/w2c/w2c.env` | [P/02.4] Н1.2 |

## Флаги

Нет: канал настройки — только окружение ([P/02.4] Н1.2 «Канал настройки и раскладка `PLATFORM_DIR`»).

## Каталоги и файлы

- **Кольцо** — файл `SECRETS_KEY` (по умолчанию `/etc/w2c/secrets/platform.key` — по раскладке
  `<PLATFORM_DIR>/etc/secrets/platform.key`, [P/02.4] Н1.1 `dirs`), вне каталога хранилища, корня объектов и корня событий; консоль его читает, пишет только `w2cctl secrets` ([М10/7] Н1.2, [P/02.4] Н1.2, [каталог]).
- **Корень событий своего сервера** — журнал `audit/console/e1/…` под исключительной блокировкой файла и отметки
  оператора `console/<экземпляр>/e1/…`; имена — одно кодирование `%XX` ([М10/8] Н1.1, Н1.2 `writer`, `marks`).
- **Корень объектов** — тела `<sub>/blobs/sha256-<hex>`, надгробия `.gone/<ключ>` ([М10/10] Н1.5).
- **Строки хранилища** — двери единиц и таблиц, просьбы и их учёт, отметки уборки, дренаж, политика, метки серверов,
  вывод серверов, схема ([каталог]: строки, где участник — `console`).

## Коды выхода

| Код | Когда | Норма |
|---|---|---|
| 0 | смена спеки — стоп, супервизор запускает снова | [P/02.3] Н3 «Смена спеки» |
| 2 | схема хранилища выше своей или не число | [М10/10] Н3 «старт … — проверка схемы» |
| 2 | спека не читается или отказана | [P/02.3] Н3 «Старт процесса» |
| 2 | `CONSOLE_ROOT` пустой или не из каталога | [М10/9] Н1.1 `root`, Н4 |
| 2 | файл окружения не по грамматике; `SERVER_NAME` не по грамматике; `W2C_ROLE` не роль команды | [P/02.4] Н1.2, Н4 |
| ≠ 0 | вне петли без комплекта; иной отказ старта — строка лога называет источник | [P/02.4] Н1.6, [P/02.3] Н3 |

Нечитаемая строка семьи при перезапечатывании на старте — строка лога, старт не прерывается ([М10/7] Н3
«перезапечатать при старте»).

## Сигналы и готовность

- **Готовность** — порт `CONSOLE_PORT` ([Стенд]).
- **SIGTERM** — упорядоченный выход; заявки `<sub>/idem/*` и просьбы остаются в строках, жнец следующего процесса их
  доводит ([М10/8] Н3 «жнец»).
- **Перезапуск** — `Restart=always`, `RestartSec=2`, кроме кода 2 ([P/02.4] Н1.1). У стенда — директива
  `@restart console` ([Стенд]).

## Стенд

- Команда «Стенда» с подстановкой `{port}`; `{data}` — это `PLATFORM_DIR`: стенд ставит `PLATFORM_DIR={data}`,
  `CONSOLE_PORT={port}`, `PLATFORM_STORE` — сокет роли, `SECRETS_KEY={data}/etc/secrets/platform.key` — кольцо, которое раннер создаёт
  командой «Стенда» `ring {file}` до первого процесса, `BOX_ID`,
  `SERVER_NAME` ([Стенд] «Один каталог данных»).
- `CONSOLE_ROOT` называет README урока: урок 7 — `testsub2`, остальные — `testsub` ([Стенд]).

## Открыто

- Нет. Кольцо стенда — один путь `{data}/etc/secrets/platform.key` (выше, «Стенд»); `BOX_ID` — по [P/02.4] Н1.2;
  экземпляр с `:` в имени представим по кодированию имён ([М10/8] Н1.1).
