# Приёмка P/06.9 — групповые операции (стенд)

Норма главы — [`06.9-console.norms.md`](../../spec/06.9-console.norms.md) Н5. Стенд, словарь директив и дверей — [общий README приёмки](../../../common/acceptance/README.md#словарь-директив-и-дверей).
Всего 2 сценария / 8 шагов.

**Сухого прогона реализацией нет.** Глава входит в приращение прав и ждёт зачёта приращения B.

## Подготовка

Консоль с манифестом `testsub`, операций он не объявляет. Дверь без префикса — консоль; роль двери `store` — `console`. Снов нет.

## scenarios.tsv

Формат — [словарь директив и дверей](../../../common/acceptance/README.md#словарь-директив-и-дверей). Сценарии проверяют только то, что выполнимо без объявления: у подсистемы нет дверей операций, строки не появляются, отката как пути нет.

## План сценариев после ADR-0094 B1

Шаг операции требует манифеста с `door.pass.operations` и воркера с маршрутом вызова шага. Двери стенда не сочиняются: сценарии войдут в `scenarios.tsv`, когда в словарь попадёт тестовый воркер с дверью `door.pass` второго вида (запрос раннеру плана B, шаг 6) и маршрут вызова шага у `testsub2`. До этого эти случаи проверяются чтением.

## Что проверяется чтением

Всё из таблицы плана, сц. 03–13, — чтением: до тестового воркера стенда (воркер с `door.pass.operations`, заявка раннеру); форма ключа — случаи `a95_*` корпуса P/02.1. Алгоритмы без стенда проверяют векторы [`op-step`](../../vectors/op-step/README.md): `step_key` и ожидаемая версия по цепочке корня.
