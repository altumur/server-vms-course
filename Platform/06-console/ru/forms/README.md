## Входы и константы

[daemon-flags.tsv](../../forms/daemon-flags.tsv) использует шапку P/01 `flag type default default_text required commands bad norm`. `$NAME` — окружение, не CLI-флаг. Процесс — console. `cleanup-window` — только логическое имя выбранной реализацией команды окна; настоящее имя/исполняемый файл остаются решением реализации P/06.1. Единственный CLI-флаг здесь — её прежний `--writers-stopped`. Разбор не отменяет проверки каталога, комплекта, роли, server/box, алиасов, положения кольца, часового пояса и активного listener по договорам. Неактивный callback и нечитаемое заданное кольцо судятся в нормативной точке активации/операции, не становятся новыми отказами запуска. Неправильный CLUSTERS — нечитаемый вход операции, не пустой список и не новый отказ запуска.

`$INSTANCE_ID` — уже существующая общая настройка экземпляра: отсутствие или пустота выбирает обычное вычисление из коробки/pid/случайного суффикса; заданное непустое значение принимается либо отвергается по договору экземпляра и сохраняется байт в байт. Это окружение, нового флага CLI или правила настройки нет.

[runtime-constants.tsv](../../forms/runtime-constants.tsv) — числовой источник её 25 констант. Шапка `name value unit norm meaning`, literal TAB. Уникальный name `[A-Z][A-Z0-9_]*`; value — положительное целое JSON без кавычек; unit `count|s|bytes`; norm — существующий req-якорь главы-владельца; meaning — текст. Нового языка выражений и переменных окружения нет. Процедура владеет зависимыми формулами и условным применением: OPS_KEEP не меньше срока памяти приёмки подсистемы. Эти литералы можно выдавать с core; целиком сгенерированный этап этим не объявлен.

Вложенный путь W получает квалифицированный ключ подписи (`n.late`, `kinds.server.decommission_requested`); точки event-name внутри kinds остаются буквальными, не переименованием протокола. ## Отказы

[refusals.tsv](../../forms/refusals.tsv) использует `chapter row name surface code kind fields headers log norm word response_schema cause outcome diagnostic caller`. Сохранены все 204 исходные строки N4 урока и 14 импортированных строк сторожевой (6.3), как 279 проекций. В четырёхколоночных таблицах cause/outcome/diagnostic/caller сохраняют каждую ячейку точно; у 6.7 были три word/outcome/cause, diagnostic/caller равны `-`. Успешные строки и абстрактные исходы загрузки/процедур остаются в каталоге и не становятся новыми ошибками.

HTTP-тела ссылаются на компоненты урока; Fault.kind не вводится. `fields` — обязательные свойства, объявленные непосредственно компонентом; унаследованные/составные требования, условные поля, слова ошибок, динамические заголовки и журналирование остаются в полной OpenAPI и исходных ячейках. `response_schema=-` означает отсутствие собственного JSON-тела; peer сохраняет форму импортированного владельца. Закрытые слова также остаются в [data/refusal-words.tsv](../../data/refusal-words.tsv). Компонент схемы RevisionMoved точно равен прежней inline-схеме ответа components/responses/RevisionMoved; публичный ответ остаётся по прежнему адресу.

## Швы и этапы

Сохраняются все исходные сценарии и обязанности README глав. Добавленные швы используют CALL/JSON по [P/03](../../../03-worker/ru/forms/README.md) и [P/02](../../../02-installer/ru/forms/README.md). CALL принимает один JSON-вход и выдаёт одно нативное JSON-значение; рекурсивное подмножество объектов, точные массивы и пустые объекты. Порты нормализуют наблюдения настоящего кода консоли, не требуют от реализации частного API. Нельзя возвращать ожидаемый объект случая. Panic, посторонняя ошибка и неисполненный вызов — провал.

У каждого сценария новый временный корень, допустимые каталог, строки, личность, права и пределы до вмешательства. Неназванное значение — допустимый нейтральный фон, не неподтверждённое чтение. Слова фикстур выбирают подготовку и исход зависимости, не вычисленный заранее ответ функции. Версии/CAS настоящие и допустимые; читаемые ключи/билеты/cookie/конверты создаёт обычная криптография, охраны транзакций настоящие. Счётчики измеряют реальные вызовы, записи, байты и удаления. Управляемый store/транспорт вводит названный I/O-исход или гонку, решение принимает обычный код консоли. Фиктивный run или готовый успех его не заменяет.

Тела отличаются одним допустимым пользовательским полем. В случаях ADR-0127 продолжения POST первая настоящая запись выполняется над указанным надгробием или отсутствующей строкой, ответ теряется и исполнение останавливается до done; другая консоль наблюдает прежнюю версию pending 30 s и перехватывает CAS. ## Принятое ревью ADR-0127: вычисляемое TLS-умолчание

При отсутствии W2C_TLS_DIR исполнить общий определитель окружения в профилях Linux и macOS: /etc/w2c/tls против <W2C_BOX>/tls. Переданный путь используется как есть, Given остаётся true; отсутствие остаётся Given=false и после определения. default=- формы daemon-flags означает вычисляемое значение, а не строку "-" и не безусловный путь Linux. Это проверки определителя и старта, не новые флаги и не правка общего договора env-file. VerifyUnavailable — только собственная форма verify503; свойства остальных ConsoleRefusal прежние.
