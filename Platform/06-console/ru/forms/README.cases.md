# Данные случаев только для судьи

Этот русский текст — производный от `forms/README.cases.md`, руками не правится (ADR-0121).

Общие правила остаются в [README.md](README.md). Следующие исходные отрывки сохраняют прежние связи именованных случаев как происхождение только для судьи.

Добавления ADR-0129(17) используют только те же порты. Для s09 главы 1 построить настоящую named pending-заявку с тем же отпечатком без сохранённого намерения цели и подтверждённую чужую живую цель с revision 1; для s10 сохранить в pending настоящий numeric-резерв, но не намеченные revision/born, а по номеру разместить чужую живую строку. Для s11 сохранить настоящую пару намерения, но у цели совпадает только revision: допустимый born цели чужой. Наблюдать неизменный pending объявленный срок допуска и перехватить обычным CAS-путём. Прежние s06–s08 остаются положительными контролями сохранённого намерения/лёгшей цели и подтверждённой перечитки плана; вход не обходит обычный кодек заявки, гейт или владение.

Для s05–s08 главы 8 выполнить настоящий пакет удаления единицы с читаемым допустимым членством в одной папке и действительными правами/CAS/стражами. `writes[0]` удаляет U, `writes[1]` — явная папка, когда она задана, `writes[2]` — явное членство, когда оно задано. Папка либо сохраняет U, либо снимает; восстановление членства — допустимый непустой put прежней связи. Согласованные случаи удаляют его явно либо поручают это последствие обычному удалению. Счётчики наблюдают настоящие целевые мутации unit/folder/memberof после подготовки, исключая подготовку/claim/журнал только из этих названных счётчиков. unique_target_keys проверяет настоящий выданный целевой пакет. Нынешние служебные/gone эффекты, допуск, полный размер и атомарность сохраняются. Ожидания адаптеру не передаются.
