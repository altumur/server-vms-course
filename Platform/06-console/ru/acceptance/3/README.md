## Подготовка

Дверь сессии консоли `testsub` (root) с `testsub2` смонтированной, без воркеров, без домена (консоль открыта, раннер
звонит с петли). До сценария остановить процессы предыдущего, создать отдельные пустые строковое/объектное хранилища и
очистить переменные/память повторов. Загрузить неизменённые testsub и testsub2 по разделу «Стенд» общего README приёмки;
root — testsub, второй доступен под /testsub2. Домена нет, обращения с петли. Фоновые controller/resource/worker не
работают. Третий манифест стенда главы 6.5 (`probe-x`) этому сценарию не нужна.

## scenarios.tsv

Формат — [словарь директив и дверей «Стенда» общего README приёмки](../../../../common/ru/acceptance/README.md#словарь-директив-и-дверей):
дверь без префикса — консоль; подмножество полей, `@header` в ожидании. Всего 1 сценарий / 5 шагов.

Подмножество expect не заменяет проверку полной HTTP-формы OpenAPI урока: проверить обязательные поля, типы, Content-Type,
специальные заголовки. Успешный открытый `/session` содержит `login_url`, даже когда TSV проверяет только `open`.

## Свидетельства вне TSV

Доменный вход, закрытые `grants`, `via` доказанной личности, порядок `identity`, `need` до тела, Origin по куке, журнал
`access.denied`, аварийный вход и отладочная личность проверяются отдельным стендом (стенд домена: приёмка P/08.4 и главы 6.7) и тестом модуля, не этим TSV
(нормы главы N5, «Проверяются чтением»).

Дополнительная проверка класса ошибок прогона 36 (Kimi), чтением: без домена каждый путь, включая открытый и /session,
закрыт вне петли; после личности кука проверяет Origin до гранта. Проверить аварийный вход.

Это предмет ручной проверки спецификации и будущей проверки реализации. Подготовленные запросы, чтение и конечные модели
автора не являются выполненным стендовым испытанием.



ADR-0129(17): нынешний GET /session с via=ticket даёт until, равный exp подтверждённого билета, и grants его человека по gate-and-pass. Это не новый вход POST /session и не новые права. Контроль источника/схемы отделён от исполнения настоящего обмена билета/сессии.
