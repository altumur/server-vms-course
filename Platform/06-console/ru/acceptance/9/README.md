## План сценариев после ADR-0094 B1

Шаг операции требует манифеста с `door.pass.operations` и воркера с маршрутом вызова шага. Тестовый воркер есть в словаре, данные лежат в [`common/acceptance/ops`](../../../../common/ru/acceptance/ops/README.md): сц. 03 и 07 написаны там, прочие строки таблицы пока чтением.

| № | Сценарий | Нормы |
|---|---|---|
| 03 | приём: потерянный 202, повтор на другом экземпляре — та же операция, шаги не исполнены дважды; два одновременных исполнителя одного ключа; повтор ключа после завершения операции | N3 «принять» |

| 05 | версии: `fail → set`, `ok → fail → set` над одним корнем, те же случаи в `retry-failed`, чужая правка между шагами | N1.4 |

## Что проверяется чтением

Сц. 04–06, 08–13 таблицы плана — чтением, смена кольца сц. 11 — насовсем: директивы нет; форма ключа — случаи `a95_*` корпуса P/02.1. Алгоритмы без стенда проверяют векторы [`op-step`](../../vectors/op-step/README.md): `step_key` и ожидаемая версия по цепочке корня.
