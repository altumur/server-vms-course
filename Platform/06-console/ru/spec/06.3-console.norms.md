# P/06.3 — Сторожевая и люди: нормы

Текст производный от `spec/06.3-console.norms.md`, руками не правится: источник — английский [`spec/06.3-console.norms.md`](../../spec/06.3-console.norms.md), правка идёт в него, русский пересобирается переводом.

Канон главы 6.3 урока P/06 «Консоль кластера» (модуль «Платформа»). Лекция (`ru/06-console.md`, для человека, в выгрузку не входит),
[контракт](../../spec/06-console.api.openapi.yaml), [инструкция](06-console.README.md), [жизненный цикл](../lifecycle.md),
[приёмка](../acceptance/3/README.md). Здесь — кто звонит консоли и что ему можно: сторожевая (состояния `on`, `open`,
`shut`, личность, что требует каждая дверь, гранты, Origin, тело), двери сессии `/session`, ключи `rights:` манифеста как
граница прав людей; поздний слой — следы домена у сторожевой и «петля — operator» только в `open` (вводит урок P/08).

Порядок проверок на каждом запросе — [глава 6.5](06.5-console.norms.md)
N3 «запрос → ответ (консоль)» (шаги 3, 4, 6–8 исполняет сторожевая этой главы); разбор запроса и общие коды — глава 6.5
N2. Сессия с грантами домена, вход людей и аварийный вход по смыслу — урок P/08 ([P/08.4](../../../08-domain/ru/spec/08.4-domain.norms.md) N1.2, N1.4, N1.6, N1.10; сторожевая с
грантами и аварийный вход у консоли — [глава 6.7](06.7-console.norms.md) N1.9, N1.10). N1.3 `session` задаёт слово `via` ответа `/session` и его значения. Ссылка «P/0N[.K]»
— урок или глава модуля; «глава 6.K» — глава этого урока. Id норм — `P/06.3-MM`.

### N1.9 Обратный вызов по билету: закрытый перечень дверей

В нынешнем ответе GET /session при via=ticket until равен exp билета. В нынешнем ответе GET /session при via=ticket grants — строки его человека по общему договору gate-and-pass. Этот ответ — чтение билета, не новый способ POST /session.

Воркер с `door.pass` второго вида зовёт консоль обратно по билету запроса ([договор сторожевой и передачи](../../../common/ru/contracts/gate-and-pass.md) «Передача второго вида»). Обратный вызов по билету — отдельный путь личности: ни кука, ни токен, поэтому сторожевая судит его своим порядком `ticket`.

С комплектом обратный вызов идёт на отдельный слушатель консоли с обязательным листом роли (договор сертификата роли «Лист обратного вызова»).

Без комплекта обратный вызов идёт на сокет роли ([P/02.5](../../../02-installer/ru/spec/02.5-installer.norms.md) N1.5).

Двери перечня те же, что у основного слушателя: другая только личность.

Манифест называет двери в `calls`. Проверка двери обратного вызова — пересечение `calls` с закрытым перечнем ниже. Загрузчик отвергает `calls` вне перечня ([P/02.1](../../../02-installer/ru/spec/02.1-installer.norms.md) N1.4). Дверь вне `calls` на запросе — 401 (`ticket` шаг 4). Так захваченный воркер делает только то, что мог бы переводчик внутри консоли, и только за людей, чьи запросы идут через него сейчас.

Приставка `GET ` у записи `<s>/…` оставляет только `GET` и `HEAD`. Путь сравнивается без префикса монтирования: у `CONSOLE_ROOT=<s>` запись `<s>/<rows>` покрывает и `/<rows>`. `<s>/<rows>` у подсистемы, которой нет в каталоге, не судится: дверей нет, запрос — 404.

**Строки пакета.** Билет не расширяет перечень через пакетную дверь: каждая строка `writes` — запись без приставки `GET`. В пакете по билету страж `guards` — запись с приставкой или без. В пакете по билету страж `<s>/opbusy/<корень>` — запись `<s>/operations`.

В пакете по билету счётчик `<s>/next_id` покрывается записью `<s>/<rows>`, потому что счётчик идёт в пакете при создании строки. В пакете по билету строки `platform/folders/<id>` и `platform/memberof/…` покрываются записью `folders`. В пакете по билету итог и счётчики операции покрываются билетом шага (глава 6.9 N2 «Пакет шага»). В пакете по билету строка вне перечня — 401 всего пакета, ничего не записано.

**Маршрут двери.** Манифест `<s>` объявляет дверь держателя единицы, `door.routes`. Запрос `<метод> /<s>/<маршрут>/<id>[/…]` консоль передаёт живому держателю единицы `<s>/<id>`: держатель и адрес — как у `GET /where/<id>` ([глава 6.5](06.5-console.norms.md) N3). Право маршрута двери — `view` на единицу. Запись журнала маршрута двери — `door.issued`.

На маршруте двери воркеру уходят путь `/<маршрут>/<id>[/…]`, query, тело ≤ 1 МиБ, `Content-Type` и `Authorization: Bearer <токен двери>` на этого человека. Ответ маршрута двери — статус, `Content-Type` и тело ≤ 4 МиБ, как пришли от воркера. Предел маршрута двери — `PASS_WAIT`. У маршрута двери нет живого держателя — 503 `{detail: "no worker of <s> with a door is heard", error: denied}`.

Сама дверь `/where` в перечень не входит: адрес и токен остаются у консоли, а билет гаснет вместе с запросом.

Билет потока идёт на маршрут двери любым методом: только так потоковый маршрут зовёт модель, а записи в этом вызове нет.

**Двери домена**. Запись `calls` открывает ровно свою дверь.

Билет дальше консоли кластера не идёт: консоль пересылает запрос консоли домена по [договору пересылки](../../../common/ru/contracts/forwarding.md) с исходным токеном внешнего запроса. На двери домена по билету консоль кластера держит исходный токен внешнего запроса только в памяти, рядом с билетом. На двери домена по билету воркер исходный токен внешнего запроса не видит.

На двери домена по билету вид сессии — `person`.

`GET domain`, `GET domain/<s>/<rows>`, `GET domain/<s>/tables/<таблица>`, `GET domain/<s>/kept/<имя>`, `GET domain/relays`, `GET domain/topology` и `GET` записи `domain/shared` консоль домена отвечает сама. На дверях домена, на которые консоль домена отвечает сама, право — [P/10](../../../10-domain-console/ru/spec/10-domain-console.norms.md) N1.2a.

На двери домена по билету процесс `domain` судит право человека, как у страницы ([P/08.4](../../../08-domain/ru/spec/08.4-domain.norms.md) N1.5).

На двери домена по билету `by` — имя человека. На двери домена по билету журнал несёт `via: <sub>/<экземпляр>`. Консоль кластера ставит на пересылке двери домена по билету заголовок `X-W2C-Via-Worker: <sub>/<экземпляр>` ([договор пересылки](../../../common/ru/contracts/forwarding.md)).

**Не входят:** записи `/session`, `/session/break-glass`, гранты кластера и люди иными дверями, ключи, `/drain`, запись `/schema`, `/mounts`, семьи `<s>/idem/*`, `<s>/asked/*`, прочие `platform/*` и `domain/*`. Причина: двери сверх перевода строк дали бы захваченному воркеру следствия, которые переживают запрос; следствие записи прав принято владельцем с тревогой `domain.rights_via_backend`; учётки первого вида и метки серверов переживают запрос; отметка `marks` — только журнал.

## N3 Проход

Сторожевая исполняется на каждом запросе в порядке [главы 6.5](06.5-console.norms.md) N3 «запрос → ответ (консоль)»:

- доверие `gate` — чтением на каждом запросе, без кэша, до разбора пути и тела (шаг 3);
- `/session*` — процедура N1.3 после установления личности, с проверкой Origin до изменения сессии и кук (шаг 4);
- личность по N1.3 `identity` (шаг 6);
- Origin по куке, единицы из пути и требуемая возможность — грант или 403 с журналом (шаг 7);
- единицы тела по N1.5 (`unit_of`, `reach`, `names`) после ограниченного чтения тела, ни одного изменения до завершения всех проверок (шаг 8).

прохода, кроме этого порядка, у главы нет.
