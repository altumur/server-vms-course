## N1 Форма

**Время.** Строк и объектов со временем глава не пишет. Срок аварийной сессии `until` (N1.10) — время по
[канону N0 P/01.1](../../../01-store/ru/spec/01.1-store.norms.md#время-в-строке); строка журнала (`domain.forwarded`,
`access.break_glass.*`, `domain.shared.refused`) — `t` по [договору журнала событий](../../../common/ru/contracts/event-journal.md).
Документы, которые двери отдают как прочитаны (`/api/held`, `/api/backup`), несут время своих владельцев.

**Данные** ([каталог](../../../common/data/catalog.tsv)):
- пишет: `domain/member-want/<part>` (create), `<events root>/audit/<role>/e1/<YYYYMMDDTHHMMSSZ>.events.jsonl` (append);
- читает: `<sub>/heartbeats/<name>`, `domain/<sub>/<manifest:domain.books>/*`, `domain/<sub>/<manifest:domain.books>/*/<part>`, `domain/root`, `domain/anywhere`, `platform/manifest/<sub>`, `domain/view`, `domain/<sub>/<manifest:domain.books>/<member>`, `domain/<sub>/<manifest:domain.books>`, `domain/member-list/<part>`, `domain/member`, `domain/keys`, `domain/revoked`, `domain/grants`, `domain/roles`, `domain/disabled`, `domain/break-glass/<cluster>`, `domain/holder`, `domain/backup-taken`, `domain/backup`, `domain/shared`, `domain/shared-docs/rev-<rev>`.

Своих строк у главы нет. Дверь книги читает строку держателя `domain/<sub>/<книга>/<CLUSTER>` у кластера, который держит
домен (`holds` — объект `domain/view`), иначе копию члена `domain/<sub>/<книга>` (N1.1). Пересылка читает объект
`domain/view` (`holds`, `view.url`) и `domain/member-list/<part>` (запись держателя; `Entry.ca` назначения для `peer`) (N1.4,
N1.6, N1.7). Сторожевая с грантами — копию `domain/grants` и `domain/disabled`, условие чтения — договор права (N1.9; токен — `domain/keys`,
`domain/revoked`, глава 6.3). Аварийный вход — `domain/member` и `domain/break-glass/<этот кластер>` (N1.10). `/domain/keys` —
строки под `domain/` этого хранилища и `domain/keys` (N1.11). `/api/held` — `domain/holder`, `domain/keys`,
`domain/backup-taken` (N1.12); `/api/backup` — `domain/member-list/<part>`, указатель `domain/backup-taken`, объекты
`domain/backup` и копия общего документа `domain/shared` (N1.13). Значение при чтении — у члена объект `domain/shared`
(копия общего документа), у держателя — строка-указатель `domain/shared` и объект `domain/shared-docs/rev-<rev>`, который
она называет (N1.14). Объекты консоль читает дверью объектов
[P/05](../../../05-resource/ru/spec/05-resource.norms.md) (чтение `/v1/objects` — любая роль с комплектом, P/05 N2 «Допуск к
дверям ресурса»), не строками прав ([P/02.5](../../../02-installer/ru/spec/02.5-installer.norms.md) N1.4). Журнал консоль
дописывает в `audit/console` по договору журнала событий (участник `append`, владелец — P/05).

Строк вкладов `<sub>/<manifest:domain.books.from>` (владелец — [P/03.7](../../../03-worker/ru/spec/03.7-worker.norms.md)) нормы
главы не читают: дверь книги читает строки книги, а не вклады; сборка вкладов — у держателя (P/08.5) и агента (P/09.1).

### N1.1 Дверь книги этого члена

Дверь `GET /domain/<sub>/books/<книга>` — у консоли кластера, члена и держателя (N2). Дверь читает книгу этого члена:
кластер держит домен (N1.4 `holds`) — строку `domain/<sub>/<книга>/<CLUSTER>`, иначе — копию `domain/<sub>/<книга>`. Строки
книги у члена нет (домена нет, книга ещё не пришла) — 404 `{error: "no such book shown", detail: "not delivered
yet"}`: пустая книга — это `""` с пустым `missing`, а не отсутствие строки. Поля вне `show` и секреты в ответе не бывают.
Сегмент `<книга>` сравнивается с именем книги манифеста байт в байт: `%72olls` — не `rolls`, 404.

Раздел книги `to: "*"` дверь этого члена не отдаёт: копия приходит по просьбе, за обход. `GET /domain/<sub>/books/<книга>/*/<раздел>` — строка таблицы «Двери домена», консоль кластера пересылает держателю ([P/08.5](../../../08-domain/ru/spec/08.5-domain.norms.md) N2).

Объявление книги и `show` — [P/02.1 N1.2b](../../../02-installer/ru/spec/02.1-installer.norms.md); сборка у держателя и строка
`domain/<sub>/<книга>/<член>` — [P/08.5](../../../08-domain/ru/spec/08.5-domain.norms.md) N1.3; строка книги у члена —
[P/09.1](../../../09-agent/ru/spec/09.1-agent.norms.md) N1.4 `member_row`. Книга — наблюдение, не власть (P/08.5 N1).

### N1.2 Консоль кластера — дверь кластера к домену

Двери людей домена (`/domain/*`) живут у консоли домена — процесса `domainconsole` на коробке держателя (урок
[P/10](../../../10-domain-console/ru/spec/10-domain-console.norms.md); ключей у неё нет); двери процессов (`/api/*`) — у процесса
`domain` (урок P/08). Глава говорит, как до них доходят из любого кластера.

```yaml
door:      консоль кластера (P/06) — единственный адрес кластера для домена и единственная дверь людей и процессов
           кластера к /domain/* домена: шлюз, воркер, страница идут через консоль своего кластера; шлюз и
           воркер — клиенты своего кластера: URL — own_url, проверка сервера — own_client договора сертификата роли,
           роль console;
           второго адреса консоли домена в записях и прямого пути процесса к ней нет
process:   двери процессов /api/* (агент — P/09.1, ретранслятор — P/09.2, токены — P/08.7) идут своими адресами
           (DOMAIN_URL, RELAY_URL), не через консоль; кроме входа людей POST /api/login (P/08.4 N1.2) — строка таблицы N1.3:
           страница ходит к своей консоли
local:     консоль кластера отвечает сама только на: /domain/<sub>/books/<книга> (N1.1, книга этого члена; не GET —
           405, N4);
           /domain/at/… (N1.6); двери переноса (N1.8, N1.12, N1.13); GET /domain/keys (N1.11); GET /domain/shared/<sub> (N1.14)
forwarded: пары (метод, путь) таблицы N1.3 — в консоль домена (N1.4, N1.5); прочее под /domain/ — 404 not a domain route,
           держатель не зовётся
```

### N1.3 Таблица пересылки

Закрытый список дверей домена со столбцами «Ожидание» и «Личность», сопоставление по порядку, `HEAD` у строк с `GET` и
отказ сегментам `.`/`..` — [договор пересылки](../../../common/ru/contracts/forwarding.md) «Двери домена» (владелец — этот урок; участники — процесс `domain`, [P/08.0](../../../08-domain/ru/spec/08.0-domain.norms.md),
и консоль домена, урок P/10 N2).

### N1.4 Адрес и один переход

```yaml
holds:        этот кластер держит домен ⟺ объект domain/view его хранилища читается и view.holder = CLUSTER консоли
to:           holds → view.url (консоль домена своей коробки, N1.4 view.url; переход 2 — клиент своего кластера,
              договор сертификата роли own_client: host — SERVER_NAME, если хост view.url — литерал петли); иначе держатель — поле holder записи срока domain/holder этого хранилища (договор записи срока): копия domain/member-list
              здесь неполна, свой раздел и запрошенные (P/09.1 N1.1) → CLUSTERS[держатель] (консоль кластера держателя)
view.url:     поле domain/view (P/08.1 N1.4): DOMAIN_CONSOLE_URL окружения процесса domain — адрес двери
              его консоли домена; переменной нет — поля нет. Вид пишет держатель, поэтому адрес верен и после передачи
CLUSTERS:     окружение консоли кластера, для держателя и первого контакта: адрес прочего члена — Entry.url его строки раздела (N1.6); форма, «не читается» (503) и пустой список — договор файла окружения `CLUSTERS`

```

Строка `via` (`X-W2C-Via`, один переход) — [договор пересылки](../../../common/ru/contracts/forwarding.md) «Один переход»
(владелец — этот урок).

### N1.5 Пересылка — одна функция

Блок целиком (`request`, `pass`, `set`, `never`, `x_operator`, `answer`, `FORWARD_MAX`, `FORWARD_WAIT`, `gate`, `tls`,
`journal`) — [договор пересылки](../../../common/ru/contracts/forwarding.md) «Пересылка — одна функция». Отказы каждого перехода и какой OpenAPI их
несёт — там же, «Отказы по переходам»: коды переходов 1–2 (сторона пересылающей) несёт [контракт урока](../../spec/06-console.api.openapi.yaml).

### N1.6 Чтение у члена — `/domain/at/<кластер>/…`

```yaml
routes:    GET /domain/at/<кластер>/<sub>/where/<id>
           GET /domain/at/<кластер>/<sub>/where/<таблица>/<место>?unit=<id>
           GET /domain/at/<кластер>/<sub>/<имя>[/<id>]
           GET /domain/at/<кластер>/events с query двери журнала: subsystem, unit (журнал правила чужого кластера)
           GET /domain/at/<кластер>/<sub>/<маршрут>/<id>[/…][?place=<таблица>/<место>] (<маршрут> — элемент door.routes манифеста без role)
           GET /domain/at/<кластер>/<sub>/heartbeats, только у <sub> с heartbeat.door; имя heartbeats судится раньше <имя>: зарезервировано (P/02.1), unit.rows и таблицей не бывает
           <sub> — манифест каталога этой консоли; <таблица> — places.table этого манифеста (P/04 N1.3 `places`; дверь /where/<table>/<place> — P/06.5); <имя> — unit.rows или таблица манифеста, не service: true; query как пришёл
to:        <адрес>/<sub>/where/…, <адрес>/<sub>/<имя>[/<id>], <адрес>/<sub>/heartbeats, <адрес>/<sub>/<маршрут>/<id>[/…], <адрес>/events — тот же хвост; адрес — Entry.url строки раздела кластера, нет поля или строки — CLUSTERS[кластер]; корень или маунт решает принимающая:
           консоль, чья корневая подсистема — <sub>, отвечает на /<sub>/where/… как на /where/…
member:    кластер — не этот кластер и есть в строке domain/member-list/<раздел имени> этого кластера; копия неполна (P/09.1 N1.1): строки раздела нет — член не судится, запрос идёт по CLUSTERS, клиент peer кладёт просьбу (договор peer client)
answer:    как N1.5; дверь в ответе выдала консоль члена своим ключом, пересылающая её не переподписывает
only:      только GET (и HEAD — как GET без тела, N1.3) и только эти формы: правки идут через держателя
           (P/08.6); маршрут двери другим методом, POST сверки удержания тоже, этим путём не идёт:
           его судит и исполняет кластер записи у себя, читатель другого кластера получает предел
read:      чтение чужого сверх вида домена: право судит консоль цели своей сторожевой и своими грантами, токен человека идёт
           как у любой пересылки; не слышен — отказ пересылки 502 или 503 как есть, данных нет. Член за NAT: адреса нет —
           404 no console known, читатель берёт вид домена (P/08.1 N1.4, N1.4a)
route:     консоль цели отвечает на этот хвост «Маршрутом двери» (P/06.3 N1.9) по токену человека: своя сторожевая, view на единицу <sub>/<id>, живой держатель, журнал door.issued. Билет дальше консоли отправителя не идёт, токен человека дальше консоли цели не идёт: воркеру цели — токен двери на этого человека.
           ?place — держатель и токен места как /where/<таблица>/<место>?unit=<id> (P/06.5 N3), воркеру не уходит. Только GET и HEAD, ответ JSON. AT_ROUTE_WAIT вместо общего PASS_WAIT; FORWARD_WAIT этой пересылки — локальная строка forms/runtime-constants.tsv. Дверь спрашивает соседей с общим PASS_WAIT. Это нормативные бюджеты, не результаты замера.
           Предел: ответ больше FORWARD_MAX из N1.5 — 502 answer too large, читатель сужает окно; цена — на вызов одна пересылка и одна строка door.issued у цели; читатель без гранта у цели — 403 как есть. Байты этим путём не идут: кусок — адрес клиенту, байты мимо консоли; член записи за NAT адреса не даёт, этот путь ему — 404 no console known
pulse:     GET /<sub>/heartbeats у консоли (у корневой подсистемы и /heartbeats; view без единицы, договор сторожевой need) → 200 {rows: [{worker, server, ts, age, worker_state, fields}]}:
           по элементу на пульс <sub>/heartbeats/<слот>, по worker в байтах UTF-8. worker, server, age, worker_state, нечитаемый пульс, неответ и 503 unavailable — как rows в GET /{rows} (P/06.1 N2),
           ts — поле пульса, fields — только поля heartbeat.door манифеста (P/02.1 N1.2), какие в пульсе есть, как есть: прочие поля ключами называют единицы, а view здесь без единицы.
           <sub> без heartbeat.door — двери нет: 404 у самой двери, not a route handed to a member у /domain/at. domain.ref и domain.view_pulse дверь не читает:
           документ общий на домен, а его состояние лежит в пульсе подсистемы вне вида
```

### N1.7 TLS между кластерами — сторона консоли кластера

Комплект роли, сертификат, центр и отзыв — [P/02.4 N1.6](../../../02-installer/ru/spec/02.4-installer.norms.md), [договор
сертификата роли](../../../common/ru/contracts/role-certificate.md): один центр на кластер. Отпечаток центра, публикация
`tls_ca`/`tls_ca_certs`, `Entry.ca`, строка `ca-certs`, `on_accept`, `relayed`, `admin` — [P/08.3 N1.6](../../../08-domain/ru/spec/08.3-domain.norms.md).

```yaml
client:       клиент двери другого кластера по https:// — договор peer (Platform/common/contracts/peer.md) «Клиент и
              первый контакт»; консоль кластера — клиент роли console к консоли члена или
              держателя (договор пересылки tls)
first:        DOMAIN_CA, RELAY_CA при первом контакте, RELAY_MEMBER — там же (агент, P/09.1 N1.7)
roles:        роли комплектов процессов домена — P/10 N1.4 roles (одно место; договор сертификата роли); консоль кластера —
              console
revoke:       договор peer «Клиент и первый контакт» revoke (одно место)
server:       серверная сторона дверей между кластерами — два класса;
              сервер обоих классов предъявляет лист своей роли с EKU serverAuth (договор сертификата роли cert): класс role — дверь роли консоли домена (договор сертификата роли «Серверная сторона: класс `role`»,
              P/10-11); класс signed — договор сертификата роли «Серверная сторона: класс signed» (P/08.0-02, P/09.2-07)
              и консоль кластера — всё входящее из других кластеров на её слушателе (переход 1 — N1.4 и договор
              пересылки; /domain/at/… — N1.6; /api/prepare, /api/take — N1.8; /api/held — N1.12; /api/backup, /api/backup-part — N1.13):
              предъявляет лист роли console с EKU serverAuth, сертификата клиента не запрашивает, в рукопожатии по
              центру не отказывает; пропускает запрос или нет — норма двери (сторожевая по Authorization — P/06.3,
              P/08.4; подпись — N1.8, N1.13; открытая — N1.12); X-Operator: console — не признаёт; снимает всегда
              (договор пересылки x_operator, «Принять консолью» п. 2).
callback:     обратный вызов по билету — отдельный слушатель консоли с обязательным листом роли подсистемы (договор сертификата роли «Лист обратного вызова»); основной
              слушатель выше им не меняется
stand:        проверяется чтением: TLS между кластерами на одной машине стенд не поднимает (P/02.4 N1.10; TLS-стенд —
```

### N1.14 Значение при чтении

Объявление `domain.shared` и `merge` — [P/02.1 N1.2b](../../../02-installer/ru/spec/02.1-installer.norms.md); общий документ,

```yaml
                 называет указатель; документа нет — null, значения — без домена; у держателя указатель или объект документа,
```

## N3 Проход

### переслать (консоль кластера) — по порядку, первое правило даёт исход

```
1. (метод, путь) не в таблице N1.3 и не своё (books, at, keys, shared/<sub>, двери переноса), или в пути сегмент `.`/`..`
   (в том числе процент-формой, N1.3) → 404 not a domain route
   (шаги 1–2 — до личности: путь вне таблицы — 404 и без токена; сторожевая — шаг 3)
   (переходы — договор пересылки; X-Operator: console на обоих)
2. тело — предел консоли (P/06.3 N1.3 `body`)                                        → 413 / 400 / 408
3. сторожевая — кто звонит (N1.9), кроме открытых строк таблицы                → 401 / 403 N1.9
4. holds (N1.4):
     view.url нет                                                            → 503 domain console not known
     иначе — переслать на view.url (N1.5; переход 2: X-Operator: console, без X-W2C-Via)
5. пришёл X-W2C-Via                                                          → 400 one hop
6. domain/holder не читается, хранилище молчит                                → 503 the list of members does not read
7. записи domain/holder нет                                                  → 404 no domain here
7a. holder записи — этот кластер (holds ложно: вида нет)                       → 404 no domain here
8. CLUSTERS не читается                                                      → 503 CLUSTERS does not read
9. нет строки держателя                                                      → 404 no console known
10. переслать на CLUSTERS[держатель] (N1.5; переход 1: X-Operator: console, X-W2C-Via) → ответ как пришёл | 502
11. журнал domain.forwarded
```

### у члена (консоль кластера, /domain/at/…) — по порядку

```
1. пришёл X-W2C-Via                                                          → 400 one hop
2. не GET/HEAD, или путь не форма N1.6 манифеста каталога, или сегмент `.`/`..` (N1.3) → 404 not a route handed to a member
3. сторожевая — кто звонит                                                   → 401 / 403 N1.9
4. domain/member-list/<раздел имени> есть, но не читается, хранилище молчит            → 503 the list of members does not read
5. кластер = CLUSTER этой консоли                                            → 404 not another member
6. строка раздела есть, кластера в ней нет                                   → 404 no such member
7. нет Entry.url: CLUSTERS не читается / нет строки кластера                  → 503 CLUSTERS does not read / 404 no console known
8. переслать на адрес N1.6 to (N1.5) с X-W2C-Via                              → ответ как пришёл | 502
9. журнал domain.forwarded
```

### принять консолью (любая консоль, до сторожевой)

Шаги 1–2 (`X-User` — снять; `X-Operator: console` — только у доказанной роли `console`; консоль кластера — не признаёт; снимает всегда: всё входящее из других кластеров — класс `signed`, N1.7 `server`) — [договор пересылки](../../../common/ru/contracts/forwarding.md)
«Принять консолью».

### peer(chain, fingerprints, role, host, now) — клиент о сервере другого кластера, по порядку

Шаги 1–9 и абзац после них — [договор `peer`](../../../common/ru/contracts/peer.md) «Функция `peer`» (номера шагов прежние; владелец P/09; участники 6.7, 8.8, 10). Векторы —
[`common/vectors/peer`](../../../common/ru/vectors/peer/README.md) (judge-only: acceptance evidence).

### resolve(field, unit, domain)

```
вход:   field {name, type, inherit?, merge?, group_by?, document?}; unit — значение строки единицы | отсутствует;
        domain — {term, rev, value} значения в документе | null
pre:    поле — по форме общего раздела P/02.1 N1.2b: поле без inherit, не document и не group_by — не по форме (загрузчик
        такое поле отвергает; merge без inherit запрещён): вход не по форме, код 2 (N5 exit)
label:  "domain term T rev R"
1. document              → {value: domain ? domain.value : null, from: domain ? label : "none"}
2. group_by              → {groups: domain ? domain.value : [], from: domain ? label : "none"}   # groups — в порядке domain.value
3. unit есть, merge union, domain есть → {value: sorted(unit ∪ domain.value), from: "unit + " + label}
                         # списки строк (type list); объединение без повторов, порядок — байты UTF-8
4. unit есть             → {value: unit, from: "unit"}
5. domain есть           → {value: domain.value, from: label}
6.                       → {value: field.inherit, from: "manifest"}
```

Векторы — [`resolve`](../vectors/resolve/README.md), [`key-families`](../vectors/key-families/README.md) (N1.11).

**Гонки.** Список членов или `CLUSTERS` меняются между проверкой и звонком — пересылка идёт по прочитанному; следующий
запрос читает заново. Две пересылки одного запроса не склеиваются: ключ повтора (`Idempotency-Key`) несёт клиент, принимающая
дверь решает по нему (P/08.6). Приём `tls_ca` и правка администратора одной записи → [P/08.3 N3](../../../08-domain/ru/spec/08.3-domain.norms.md) «Гонки».
