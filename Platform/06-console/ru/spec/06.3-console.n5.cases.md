Описания случаев и их исходы — данные только для судьи. Каноническая нормативная глава — [`06.3-console.norms.md`](06.3-console.norms.md). Общие правила и явно сохранённые нормативные примеры остаются там.

### Блок случаев 1

- [ ] **P/06.3-02** сторожевая N1.3: открыта только с петли — раннер звонит с петли и получает `open: true` — сц. 03 шаг 1; порядок `identity`, `need` по пути до тела, `X-User` никогда, закрыта при потере доверия, `{detail, error: denied}`, журнал `access.denied` — проверяются чтением: стенд приёмки без домена и с петли, ветвей 401/403/503 не достигает (стенд домена — приёмка P/08.4) (разбор ревью стадии A 6–7, № 22)
