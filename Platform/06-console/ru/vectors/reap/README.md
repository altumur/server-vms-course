## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — объект JSON (решение одного прохода жнеца над одной строкой, чтения подменены входом):

| Поле | Значение |
|---|---|
| `profile` | `fetched` — дозапись (`requests.outcome: fetched`); `resource` — строка ресурса `requests/free-<server>-<volume>` |
| `resource_state` | у `resource`: `resource_state` сервера-хозяина из ключа (`live`, `unreachable`, `unknown`, `silent`) или `noanswer` — хранилище не ответило |
| `settle`, `ttl` | ключи `requests` манифеста, секунды; ключа `ttl` может не быть. `REAP_AFTER` — константа 60 (P/06.4 N1.5) |
| `row` | `{unit, digest}` строки просьбы, прочитанной подтверждённо |
| `row_age` | возраст строки (по правилу `ttl` договора), секунды |
| `unit` | чтение строки единицы-адресата: `present`, `absent` (строки нет или надгробие, подтверждено), `unknown` (не подтверждено) |
| `mark` | метка `objects/<sub>/commands/<rid>` как прочитана или `null` — нет |
| `mark_age` | возраст первого подтверждённого чтения метки, местные монотонные секунды, или `null` |
| `fetched_age` | возраст первого подтверждённого `fetched` держателя по этой строке или `null` — не было |

**Выход** — `{"write_mark": "gone" | "expired" | null, "remove_row": true | false}`: какую метку писать создание-однажды и снимать
ли строку (по CAS, с rid из `asked`) в этом проходе. Сравнение — JSON по значению.

## Прогон

Без стенда: сторона подаёт вход своему решению жнеца и сравнивает выход. Гонки CAS, повтор записи метки по `conflict` и
освобождение учёта — чтением договора; сценарий 07 приёмки главы 6.4 — `gone` на стенде, сценарий 11 — `expired` на стенде.
Кто исполняет — жнец консоли (`06-console`, оба профиля: P/06.4 N3 «жнец» и снятие строки ресурса без живого хозяина по `ttl`; договор просьбы и её метки, строки «жнец …»). Вход пишут другие роли и решения жнеца не исполняют: `fetched` пульса — воркер-держатель (`03-worker`, P/03.6 N3 «Дозапись»), строку `free-*` — ресурс (`05-resource`, P/05 N1.4 `free_ask`; её снятие под отметкой — `relieve`, не жнец) (строку исполняет роль, чья норма вызывает её функцию).
