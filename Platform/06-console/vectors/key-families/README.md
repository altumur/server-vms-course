# Векторы: семьи ключей домена `families`

Владелец — глава P/06.7 ([нормы](../../spec/06.7-console.norms.md) Н1.11 `families`; догадка стадии C
C06-DOMAIN-KEY-FAMILIES-168-21, решение «Архитектора» 2026-10-27). Участник — консоль кластера (дверь `GET /domain/keys`).
Объявление `domain.keys` и его отказы загрузки — [P/02.1 Н1.2б](../../../02-installer/spec/02.1-installer.norms.md)
(случаи `m59_keys_*`). Байты пишет «Спецификация»; строки — по тексту нормы, правило — там, не здесь.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок
`case<TAB>decls<TAB>present<TAB>expect<TAB>note`.

**Вход** — `decls`: объявления `domain.keys` манифестов каталога, объект JSON `{<sub>: [{id, keys?, prefix?}]}` (ключи и
семья — под `domain/<sub>/`, как требует загрузка); `present`: ключи строк под `domain/` этого хранилища, массив JSON, порядок
не значим.

**Выход** — `families`: `{<id>: [<ключ>…]}`; сравнение — JSON по значению, порядок в массиве значим.

12 строк: один манифест (ключей нет — пустой список, сц. 06 шаг 2; названный ключ и ключи под `prefix`); один `id` в двух
манифестах — объединение, тот же ответ при ином порядке манифестов, ключи только одной стороны (каждой), ни одной; общий
`id` рядом со своими; названный ключ под `prefix` — один раз; `prefix` — по байтам; порядок по возрастанию байтов UTF-8
(ASCII и не-BMP: 😀 после ｚ, хотя в UTF-16 шёл бы раньше).

## Прогон

Без стенда: сторона подаёт вход своему расчёту `families` двери `GET /domain/keys` (манифесты каталога и чтение строк под
`domain/` подменены входом). Нативный исход — код 0 и значение `families` (одна колонка ожидания — общее правило «Векторы»
[общего README приёмки](../../../common/acceptance/README.md)); вход — `cells` `decls`, `present`.
Кто исполняет — консоль кластера (`06-console`, P/06.7 Н1.11 `families`). Модуль консоли (`07-console-module`) берёт
`families` готовым: страница подсистемы отбирает свои ключи префиксом (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья
норма вызывает её функцию; решение «Архитектора» 2026-10-27).
