# Векторы: ряды манифеста `metrics[]`

Владелец — глава P/06.5 ([нормы](../../spec/06.5-console.norms.md) Н3 «Ряды манифеста metrics[]»; догадка стадии C
C06-METRICS-DSL-33-01, решение «Архитектора» 2026-10-25). Участник — консоль кластера (`GET /metrics`). Байты пишет
«Спецификация»; ожидания получены свидетелем курса над тем же входом (поведение перенесено без изменения).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

**Вход** — объект JSON:

| Поле | Значение |
|---|---|
| `sub` | префикс рядов (`metrics.prefix`) |
| `now` | стенные секунды консоли |
| `metrics` | элементы `metrics[]` манифеста (обычно один; повтор `name` — два) |
| `heartbeats` | `{<воркер>: <пульс без worker>}` — пульсы, прочитанные консолью (поля пульса и `status`) |
| `live` | воркеры, чья версия пульса менялась в последние `LOST_AFTER` (нет поля — пусто) |
| `tables` | `{<таблица>: {<имя строки>: {<элемент>: <текст>}}}` — читаемые строки таблиц манифеста |
| `held` | имена строк таблицы мест, которые держит живое удержание `<sub>/holds/<имя>` |

**Выход** — `{"lines": [<строка выдачи>…], "garbled": <n>}`: строки `/metrics` этих элементов по порядку (с `# TYPE`) и число
полей, счёт нечитаемого которых прибавился (`<sub>_console_rows_garbled{table="field"}`). Сравнение — массив строк байт в байт
и число.

28 строк: все ключи — `name` (и повтор), `type`, `labels`, `from` (`heartbeat`, `status`, сегмент `<имя>`), `agg` (`value`, `flag`,
`age`, `label`, `count`, `sum`, `max`, `histogram`), `equals`, `when`, `default`, `live`, `count`, `where` (слово и список), `unheld`,
`unless`, `buckets`, `label`, `values`; запись значения по значению, экранирование подписи; логическое значение в числовом поле
(`value`, `sum`: true — 1, false — 0); округление половины к чётному у `age` (0.25, 0.35, 0.45) и `_sum` (7.0625) — C06-METRICS-ROUND-91-01.

## Прогон

Без стенда: сторона подаёт вход своему построению рядов (чтения подменены входом) и сравнивает строки.
