# P/09.1 — The member agent: norms

This English text is the source; the Russian translation `ru/spec/09.1-agent.norms.md` (for people, not in the export) is derived from it by translation and is not edited by hand.

The canon of chapter 9.1 of lesson P/09 «The agent» (module «Platform»). Lecture (`ru/09-agent.md`, for people, not in the export),
[contract](09-agent.api.openapi.yaml) (tag `local-door`), [instructions](09-agent.README.md), [life
cycle](../lifecycle.md), [acceptance](../acceptance/1/README.md). Here — the process `domainagent` on every member, the holder
included: the member key and `join`; publishing the report whole or as a delta, book contributions and report objects; signing its own
requests; the holder's answer and the write at home only on a difference, freshness marks; copies of placements, applying edits and
outcomes; the local token door; roads, `domain/reached`, the HTTPS client; following the holder and the switch point; the keeper's agent;
the shared document and the alarm page; the agent in a process; the row `domain/agent`, `sign_failures` and the answer `standby`; one
active agent at a member — the turn `domain/agent-turn` (N1.13).

What is not here and where it is:
- the relay mode (`RELAY=1`: the door for the members behind it, the packet `relayed`, the memory, the relay pass) —
  [chapter 9.2](09.2-agent.norms.md);
- the holder's side: the reception of a report, the generation and the mark, the answer `carry`, the sealing of `m1`, `members` only to the
  one lagging behind, `tls_ca` → `Entry.ca` — [P/08.3](../../08-domain/spec/08.3-domain.norms.md); the key set and the changes —
  [P/08.2](../../08-domain/spec/08.2-domain.norms.md); grants and the break-glass account — [P/08.4](../../08-domain/spec/08.4-domain.norms.md);
  books — [P/08.5](../../08-domain/spec/08.5-domain.norms.md); placement and stored edits —
  [P/08.6](../../08-domain/spec/08.6-domain.norms.md); issuing a token — [P/08.7](../../08-domain/spec/08.7-domain.norms.md);
  the term, the backup copy, the switch point `switch` — [P/08.8](../../08-domain/spec/08.8-domain.norms.md); the shared document —
  [P/08.9](../../08-domain/spec/08.9-domain.norms.md); ceilings and `standby` — [P/08.10](../../08-domain/spec/08.10-domain.norms.md);
- the cluster console (`/api/held`, `/api/backup`, the book door, the value on read, the alarm list) — [chapter P/06.7](../../06-console/spec/06.7-console.norms.md)
  (N1.1, N1.12–N1.14) and [lesson P/10](../../10-domain-console/spec/10-domain-console.norms.md) (the alarm list);
- the contribution of a worker under a slot and the token at the worker — [P/03.7](../../03-worker/spec/03.7-worker.norms.md).

The common algorithms are the contracts of [the agent signature](../../common/contracts/agent-signature.md) (owner — this chapter),
[the local token door](../../common/contracts/local-token-door.md) (owner — this chapter), [`peer`](../../common/contracts/peer.md)
(owner — lesson P/09, this chapter), [the domain key set](../../common/contracts/keys.md) (participant: the function `keys`, merge and
prune of `domain/revoked`), [the domain envelopes](../../common/contracts/domain-envelopes.md) (the agent seals `x25519:v1` and
