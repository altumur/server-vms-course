# Judge-only case data

This English text is the source; the Russian translation `ru/forms/README.cases.md` is derived from it (ADR-0121).

Generic rules remain in [README.md](README.md). The following original passages preserve the existing named case associations as judge-only provenance.

<!-- original-mixed-case-paragraph -->

The seven review cases use the existing ports and ordinary implementation paths. Retry fixtures first obtain a real camera busy or knock-404 response with retry_in, make the snapshot not ready and observe every holder/relay request before/at the monotonic deadline; local reads, turn renewal and neighbouring-console held reads remain available. The backup fixture supplies genuinely signed documents and matching checksums: each attempt independently starts from the same own pair; only the last attempt revokes the own issuer. Compare actual object/taken bytes after the smaller same-term pair is refused.

<!-- original-mixed-case-paragraph -->

The key replacement fixture operates on real ring-protected seeds and the actual two store rows, loses the conditional-batch reply, and also presents a readable mismatched binding. Run the actual signing gate, operator-authorized maintenance execution by domainagent under its current turn guard, confirmation, normal holder re-admission and own-console signature check; no fabricated public-key decision or new operator command is introduced. Never return key/seed/signature bytes.

<!-- original-mixed-case-paragraph -->

The member-want fixture drives ordinary part requests through two passes of the same process with eight real persistent 503 responses and a valid ninth part. Count actual requests, observe unchanged stored at values, completion/withdrawal cleanup and a real restart from the state after the first pass; restart restores the original persisted at/name order. The relay-age fixture executes real empty/other-member batches, forwards the real cached carry into the ordinary member copier/may age path, then receives a new carry for that same member and restarts. Its old cached grants are truly expired, not refreshed by global heard. The missing-cache fixture uses a genuine first empty-batch response admitting the member, then actual signed GET handlers; valid GET is 503 only after signature checking, invalid signature remains 401, and neither a knock nor an invented cached response is produced.
