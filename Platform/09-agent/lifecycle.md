# Агент — жизненный цикл (урок P/09)

Контракт жизненного цикла процесса агента `domainagent` (ADR-0083 доп. (2) п. 1): запуск, настройка, диск, выход. Три режима одного
процесса: агент члена (глава 9.1), режим ретранслятора `RELAY=1` (глава 9.2) и агент в процессе платформы у кластера из
одного. Нормы — главы [9.1](spec/09.1-agent.norms.md) и [9.2](spec/09.2-agent.norms.md) (стадия B).

## Запуск

- Юнит `w2c-domainagent.service`, роль `domainagent`, раннер `w2c-run.sh domainagent`, `User=w2c`, группы `w2c-store
  w2c-events w2c-secrets`; своего порта у агента члена нет —
  [P/02.4 Н1.12](../02-installer/spec/02.4-installer.norms.md); общее юнитов — P/02.4 Н1.1 `common`
  ([P/02.4](../02-installer/spec/02.4-installer.norms.md)).
- На каждом члене, в том числе у держателя: держатель — тоже член
  ([P/09.1 Н1.1](spec/09.1-agent.norms.md) `agent`).
- Член закрепляет корень домена командой оператора `join` ([P/09.1 Н1.1](spec/09.1-agent.norms.md) `join`); порядок
  сторон приёма любой ([P/08.3 Н1.1](../08-domain/spec/08.3-domain.norms.md)).
- **Режим ретранслятора** — тот же процесс, роль и ключ члена: `RELAY=1` открывает дверь ретранслятора
  ([P/09.2 Н1.1](spec/09.2-agent.norms.md) `door`); память — в процессе, после перезапуска пуста (P/09.2 Н1.4,
  «Решает реализация» п. 1).
- **Агент в процессе** — кластер из одного МОЖЕТ держать агента в процессе платформы без комплекта роли `domainagent`;
  местная дверь токенов тогда — вызов, а не дверь ([P/09.1 Н1.11](spec/09.1-agent.norms.md); [договор местной двери
  токенов](../common/contracts/local-token-door.md) «Вызов в процессе»).

## Флаги

Нет: канал настройки — только окружение (P/02.4 Н1.2).

## Каталоги и файлы

- Строки и объекты агента у своего кластера — копии, исходы, строка `domain/agent` и пр.; `domain/reached` и
  `domain/reaches` — объекты (P/05 Н1.1), а не строки хранилища ([P/09.1 Н1.7](spec/09.1-agent.norms.md)); семьи и
  участники — каталог данных [`common/data/catalog.tsv`](../common/data/catalog.tsv) (владелец — P/09.1, участник
  `domainagent` в строках P/08.2, P/08.4, P/08.8, P/08.9).
- Кольцо `SECRETS_KEY` — по раскладке `<PLATFORM_DIR>/etc/secrets/platform.key` (`/etc/w2c/secrets` — ссылка), вне каталога
  хранилища, корня объектов и корня событий (P/02.4 Н1.1 `dirs`, Н1.2); на стенде — `{data}/etc/secrets/platform.key`.
  Процесс при чтении сверяет размещение кольца ([договор файлов секретов](../common/contracts/secret-files.md) `forbidden`)
  с корнями, известными ему самому из окружения: каталог хранилища при `PLATFORM_STORE=file://…`, корень объектов
  (`OBJECTS`), корень событий (`RESOURCE_ROOT` / `EVENTS`). При двери хранилища через сокет демона (`configstore://…`)
  `-dir` демона и каталоги его копий процессу не известны — их исключает установка (раскладка P/02.4 Н1.1, `w2cctl secrets
  new` с перечнем установщика); новых переменных нет (C08-RING-FORBIDDEN-ROOTS-01, решение Спецификации домена).
- Память ретранслятора (копии и `rev` членов, ответы держателя, стуки) — в памяти процесса, не в хранилище
  ([P/09.2 Н1.4](spec/09.2-agent.norms.md); где держит — «Решает реализация» п. 1 главы 9.2).
- Местная дверь токенов — Unix-сокеты `<AGENT_TOKEN_DIR>/<роль>.sock`, по одному на роль воркеров каталога; сокеты —
  от юнитов `w2c-domainagent-token-<роль>.socket`, не переданный юнитом агент создаёт сам ([договор местной двери
  токенов](../common/contracts/local-token-door.md) «Сокет роли»; разбор ревью стадии A 8–10, № 1 / решение 1); токены —
  только в памяти просящего.
- Журнал роли — `<корень событий>/audit/domainagent/e1/…` ([договор журнала событий](../common/contracts/event-journal.md) `journal`).

## Сигналы и готовность

- Проход — раз в `every`, умолчание `REPORT_EVERY` 5 с; ответ держателя может назначить `every` 1…3600
  ([P/08.3](../08-domain/spec/08.3-domain.norms.md) Н1.3, Н1.5; [P/09.1](spec/09.1-agent.norms.md) Н3 «проход агента»).
- `503 standby` держателя — «держатель недоступен» на этот проход, не повод искать другой срок; повтор следующим
  проходом ([P/09.1 Н1.12](spec/09.1-agent.norms.md) `agent`).
- Следование за держателем — раньше отчёта в каждом проходе ([P/09.1](spec/09.1-agent.norms.md) Н3 «следовать»).
- В режиме ретранслятора проход ретранслятора — в каждом проходе агента, после своего отчёта, и даже если свой отчёт не
  прошёл ([P/09.2 Н3](spec/09.2-agent.norms.md)).

## Стенд

Корни `{data}/config`, `objects`, `events` до старта процесса создаёт команда запуска роли профиля — [общий README
приёмки](../common/acceptance/README.md) «Стенд без root»; процесс корней не создаёт ([P/02.4](../02-installer/spec/02.4-installer.norms.md) Н1.1 `dirs`; STAND-ROOTS-CLEAR-01, решение «Архитектора» 2026-10-27).

Стенд нескольких кластеров ([общий README приёмки](../common/acceptance/README.md#стенд-домена), раздел «Стенд домена»): `@start agent <кластер>` — `CLUSTER`, `DOMAIN_URL` —
посредник раннера; `@start agent <кластер> via <ретранслятор>` — `RELAY_URL` вместо `DOMAIN_URL`; `@join <кластер>
[<файл>]` — команда `join` с файлом восстановления; `@clock` — `W2C_WALL_OFFSET`. `{data}` — `PLATFORM_DIR` кластера
([общий README приёмки](../common/acceptance/README.md) «Стенд»; разбор ревью стадии B 3–5, № 33). Четвёртый кластер
`relay` с `RELAY=1` и `{relay_port}` — приёмка [главы 9.2](acceptance/2/README.md).
