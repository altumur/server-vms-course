# Агент — жизненный цикл (урок P/09)

Контракт жизненного цикла процесса агента (ADR-0083 доп. (2) п. 1): запуск, настройка, диск, выход. Три режима одного
процесса: агент члена (глава 9.1), режим ретранслятора `RELAY=1` (глава 9.2) и агент в процессе платформы у кластера из
одного. Стадия A: строки собраны поверх нынешних норм М10 и М11 и ссылаются на них.

## Запуск

- Юнит `w2c-domainagent.service`, роль `domainagent`, раннер `w2c-run.sh domainagent`, `User=w2c`, группы `w2c-store
  w2c-events w2c-secrets`; своего порта у агента члена нет —
  [М11/12 Н1.8](../../М11_Domain/spec/12-small-members-and-one-node.norms.md); общее юнитов — P/02.4 Н1.1 `common`
  ([P/02.4](../02-installer/spec/02.4-installer.norms.md)).
- На каждом члене, в том числе у держателя: держатель — тоже член
  ([М11/3 Н1.1](../../М11_Domain/spec/03-agent-and-reports.norms.md)).
- Член закрепляет корень домена командой оператора `join` до приёма (М11/3 Н1.1 `join`).
- **Режим ретранслятора** — тот же процесс, роль и ключ члена: `RELAY=1` открывает дверь ретранслятора
  ([М11/4 Н1.1](../../М11_Domain/spec/04-relays-and-roads.norms.md) `door`).
- **Агент в процессе** — кластер из одного МОЖЕТ держать агента в процессе платформы без комплекта роли `domainagent`;
  местная дверь токенов тогда — вызов, а не дверь ([М11/12 Н1.3](../../М11_Domain/spec/12-small-members-and-one-node.norms.md)).

## Окружение

Канал настройки — только окружение P/02.4 Н1.2 и раскладка `PLATFORM_DIR` (второй пилот, Н-4).

| Переменная | Смысл | Умолчание | Норма |
|---|---|---|---|
| `W2C_ROLE` | роль `domainagent` | юнит | P/02.4 Н1.2 |
| `PLATFORM_DIR`, `PLATFORM_STORE`, `OBJECTS`, `RESOURCE_ROOT` / `EVENTS` | состояние, дверь хранилища, корни объектов и событий | P/02.4 Н1.2 | P/02.4 Н1.2 «Канал настройки и раскладка» |
| `SECRETS_KEY` | кольцо (credential): ключ члена, книги и аварийные строки — конверты кольца | — | М11/12 Н1.8; М10/7 Н1.2 |
| `CLUSTER` | имя своего члена | `local` | P/02.4 Н1.2; М11/3 Н1.1 |
| `DOMAIN_URL` | дверь процесса `domain` держателя — дорога отчёта | — | [М11/3 Н3](../../М11_Domain/spec/03-agent-and-reports.norms.md) «проход агента»; М11/4 Н1.3 |
| `RELAY_URL` | дверь ретранслятора — дорога вместо `DOMAIN_URL` у члена за ретранслятором | — | М11/4 Н1.1 `door`, Н1.3 |
| `DOMAIN_CA`, `RELAY_CA` | отпечаток центра держателя / ретранслятора при первом контакте, пока запись члена не называет `ca` | — | [М11/8 Н1.6](../../М11_Domain/spec/08-doors-between-clusters.norms.md) `first` |
| `RELAY_MEMBER` | имя члена-ретранслятора для проверки сервера по `https://`; `RELAY_URL` на `https://` без него — агент не стартует | — | М11/8 Н1.6 `client`, `first` |
| `RELAY`, `RELAY_HOST`, `RELAY_PORT` | режим ретранслятора: дверь для членов за ним | `RELAY` не задан; `0.0.0.0`; `8446` | М11/4 Н1.1 `door`; М11/12 Н1.8 |
| `W2C_WALL_OFFSET` | только стенд: сдвиг стенных часов агента; при заданной — громкая строка журнала | не задан | М11/3 «Решает реализация» п. 3 |
| `BOX_ID`, `SERVER_NAME` | коробка и сервер | P/02.4 Н1.2 | P/02.4 Н1.2 |

TLS: комплект роли `domainagent` по `W2C_ROLE`; дверь ретранслятора — тот же комплект (М11/8 Н1.6 `roles`). Агент в
процессе — без комплекта, клиент только `https://` с проверкой `peer` (М11/12 Н1.3 `client`).

## Флаги

Нет: канал настройки — только окружение (P/02.4 Н1.2).

## Каталоги и файлы

- Строки агента у своего кластера — копии, исходы, строка `domain/agent`, `domain/reached` и пр.; семьи и участники —
  каталог данных [`common/data/catalog.tsv`](../common/data/catalog.tsv) (владельцы М11/2–12, участник `domainagent`).
- Кольцо `SECRETS_KEY` — по раскладке `<PLATFORM_DIR>/etc/secrets/platform.key` (`/etc/w2c/secrets` — ссылка), вне каталога
  хранилища, корня объектов и корня событий (P/02.4 Н1.1 `dirs`, Н1.2); на стенде — `{data}/etc/secrets/platform.key`.
- Память ретранслятора (пакеты членов, стуки) — в памяти процесса, не в хранилище (М11/4 Н1.4; где держит —
  «Решает реализация» п. 1 [М11/4](../../М11_Domain/spec/04-relays-and-roads.norms.md)).
- Местная дверь токенов — выбор реализации; если TCP — порты 8444–8447 не занимать, умолчание `8448` (М11/12 Н1.8
  `local_door`; [М11/7 Н1.2](../../М11_Domain/spec/07-worker-tokens.norms.md)); токены — только в памяти просящего.
- Журнал роли — `<корень событий>/audit/domainagent/e1/…` (М10/8 Н1.2 `journal`).

## Коды выхода

| Код | Когда | Норма |
|---|---|---|
| 2 | отказ старта по спеке, правам, схеме — без перезапуска | P/02.4 Н1.1 `common` |
| ≠ 0 | `RELAY_URL` на `https://` без `RELAY_MEMBER` — агент не стартует | М11/8 Н1.6 `first` |

## Сигналы и готовность

- Проход — раз в `every`, умолчание `REPORT_EVERY` 5 с; ответ держателя может назначить `every` 1…3600 (М11/3 Н1.3,
  Н1.5).
- `503 standby` держателя — «держатель недоступен» на этот проход, не повод искать другой срок; повтор следующим
  проходом (М11/12 Н1.7 `agent`).
- Следование за держателем — раньше отчёта в каждом проходе ([М11/10 Н3](../../М11_Domain/spec/10-holder-transfer-and-keepers.norms.md) «следовать»).

## Стенд

Стенд нескольких кластеров М11 (README приёмки М11/01): `@start agent <кластер>` — `CLUSTER`, `DOMAIN_URL` —
посредник раннера; `@start agent <кластер> via <ретранслятор>` — `RELAY_URL` вместо `DOMAIN_URL`; `@join <кластер>
[<файл>]` — команда `join` с файлом восстановления; `@clock` — `W2C_WALL_OFFSET`. `{data}` — `PLATFORM_DIR` кластера
(README приёмки М10/01 «Стенд»).

## Открыто

- Имя и аргументы команды `join` и запуск агента — решает реализация: М11/3 «Решает реализация» п. 2.
- Сторона читателя спеки, проверка схемы при старте и готовность по порту — [М11/12 Н1.8](../../М11_Domain/spec/12-small-members-and-one-node.norms.md) (Решено «Архитектором» 2026-10-18 (второй пилот)).
