# Векторы следования за держателем

Векторы функции `follow(keys, held, answers)` агента члена — выбор, за чьей записью срока идти: своя строка
`domain/holder` и записи из ответов консолей (`/api/held`, 409 `deposed`) проверяются функцией `record`
[договора записи срока](../../../common/contracts/record.md) и сравниваются по сроку. Владелец — урок P/09, глава 9.1
([P/09.1](../../spec/09.1-agent.norms.md) Н3 «следовать», Н5 `follow`); исполняет только агент (разбор ревью стадии A 8–10,
№ 8). Байты пишет «Спецификация» (ADR-0083); соответствие продукта — его приёмкой по этой таблице (ADR-0080 доп. 16).

Строки переложены из входов команды `follow` приёмки М11/10 (`inputs/follow-*.json`, сц. 06) без изменения байтов: сняты
только пробелы и переводы строк вне строк JSON; `case` — имя файла входа; ожидание `ok <JSON>` — ячейка `expect` (план
переноса урока 9, § 3; решение «Архитектора» по планам 8–10, ADR-0083 доп. (14) п. 17). Сценарий 06 приёмки М11/10 и его
входы сняты переносом урока 9: таблица — единственный источник этих случаев.

## Прогон

Без стенда: функция реализации получает вход (колонка `input`) и даёт вывод; `expect` — подмножество полей вывода или
`@exit 2` (вход не по форме P/09.1 Н5 `exit`: у `follow` нет `held` или `answers`, `answers` не объект, лишнее поле, доверенный
набор `keys` не по форме). Подпись самого набора функция не проверяет: набор доверенный. Строк `@exit 2` в таблице нет.
Отсутствие поля (`term` у `stay` без своей записи, прошедшей `record`) подмножеством не сравнивается — Н5 `follow`, чтением.

## Ключи

Ключи выпускающего и набор — байтами во входах (`keys.issuing`, `doc.issuer`). Зёрна — `sha256("w2c test <слово>")`, как
у пакета [`record`](../../../common/vectors/record/README.md) «Ключи» (корень `root 1`, ключ токенов `token key 1`, выпускающие
`issuing key 1`, `issuing key 0` — в `revoked_issuing`, `issuing key 9` — чужой, члены `member m1`, `member m2`). Набор `keys`
у всех строк один: `domain: acme`, `rev: 2`, подпись корня.

## Файлы

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок; `note` — сценарий и шаг
приёмки М11.

| Файл | Вход → ожидание |
|---|---|
| [`cases.tsv`](cases.tsv), 12 строк: 5 `follow`, 7 `stay` | `input` — вход команды `follow` текстом JSON (`keys` — документ набора, `held` — `{doc}` своей строки `domain/holder` или `null`, `answers` — `{<кластер>: {doc} \| null}`) → `expect`: `{"result":"follow","term":…,"holder":…,"url":…}` (больший срок; тот же держатель с новым `url` и большим `at`; тот же срок у другого держателя; своя `held` — документ резервной копии или грант, своей записью не считается) или `{"result":"stay","reason":<слово>}` — `larger` (свой больше), `holding` (тот же; поддельный или испорченный больший ответ — в `refused`), `two_holders` (два держателя на одном сроке), `none` (ответов нет; только поддельный); `refused` — `{<кластер>: <слово record>}` |

Векторы проверены прогонами реализаций приёмки М11/10 (прогон 41, сверка М11 09–12) и по тексту норм; при расхождении
прав норма, вектор правит «Спецификация».
