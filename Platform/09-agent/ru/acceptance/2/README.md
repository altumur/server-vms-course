ретранслятором (глава 9.1: P/09.1-05, P/09.1-21, P/09.1-24), молчание члена в виде (глава 8.1).

## Стенд

Подготовка — как README приёмки [главы 8.3](../../../../08-domain/ru/acceptance/3/README.md) («Стенд», «Подготовка каждого
сценария»; прежде — README приёмки М11/03), кластеров четыре: `hold`, `m1`, `m2`, `relay`. Агент `relay` всегда открывает
дверь ретранслятора (`RELAY=1`, `{relay_port}`); двери и директивы — раздел «Стенд домена» общего README приёмки
(`@domain <кластеры>`, `@start agent <кластер> via relay`, `@stop agent`, `@cut relay`, `@mend relay`, `@clock`).
Топология пуста до шага, который её пишет.

## scenarios.tsv

Формат — словарь «Стенда» и раздел «Стенд домена» общего README приёмки; ожидание — подмножество полей. `$fp2` — отпечаток
незнакомца, которого держатель узнал из стука, пришедшего пакетом ретранслятора.

## Сны (`@sleep`, ADR-0080 доп. (17) п. 4)

| Сц./шаг | Сон | Причина |
|---|---|---|
| 02/17 + 02/19 | 70 + 15 с | отсутствие: под `@cut relay` `domain/reached` не растёт; новое значение было бы записано не позже `FRESH_EVERY` (глава 9.1, `fresh`) после ответа по другой дороге, а другая дорога открылась бы после `ROAD_QUIET` 15 с ([P/08.3](../../../../08-domain/ru/spec/08.3-domain.norms.md) N1.3a) и прохода агента 5 с — всего не меньше 80 с |
