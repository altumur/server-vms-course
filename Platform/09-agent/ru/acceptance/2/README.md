## Стенд

Подготовка — как [стенд главы 9.1](../1/README.md#стенд), кластеров четыре: `hold`, `m1`, `m2`, `relay`. Агент `relay` всегда открывает
дверь ретранслятора (`RELAY=1`, `{relay_port}`); двери и директивы — раздел «Стенд домена» общего README приёмки
(`@domain <кластеры>`, `@start agent <кластер> via relay`, `@stop agent`, `@cut relay`, `@mend relay`, `@clock`).
Топология пуста до шага, который её пишет.

## scenarios.tsv

Формат таблицы — словарь «Стенда» и раздел «Стенд домена» общего README приёмки; ожидание — подмножество полей. `$fp2` — отпечаток
незнакомца, которого держатель узнал из стука, пришедшего пакетом ретранслятора.

## Швы помощи пакету

CALL-швы задаёт 10 CALL-шагов обычных путей реализации. Договор фикстур/портов — [forms/README.md](../../forms/README.md); [stages.tsv](../../../forms/stages.tsv) их выбирает. Швы помогают пакету и не заменяют обычные сценарии процесса и обязательных соседей.
