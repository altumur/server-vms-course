# Воркер — жизненный цикл (урок P/03)

Контракт жизненного цикла процесса `<sub>worker` — SDK воркера на любом языке (ADR-0083 доп. (2) п. 1): запуск, имя,
окружение, замок присутствия, коды выхода, сигналы, режим запасного. Стадия A — поверх нынешних норм М10. Нормы здесь не
пересказываются: каждая строка ведёт к своей норме.

Нормы: [М10/5](../../М10_Platform/spec/05-the-worker-under-its-slot.norms.md) (Н3 «старт()», «цикл», «остановка по
SIGTERM», Н4), [М10/3](../../М10_Platform/spec/03-units-slots-epochs-lease.norms.md) (Н1.4 имя слота),
[М10/11](../../М10_Platform/spec/11-the-platform-on-a-box-and-a-cluster.norms.md) (Н1.1 юниты, Н1.2 окружение, Н1.5
запасные), [М10/2](../../М10_Platform/spec/02-the-spec-and-the-strict-loader.norms.md) (Н3 «Старт процесса», «Смена
спеки»), [М10/10](../../М10_Platform/spec/10-schema-drain-snapshot-limits.norms.md) (Н3 проверка схемы),
[М10/7](../../М10_Platform/spec/07-secrets-and-sealing.norms.md) (Н1.2 кольцо), [М10/8](../../М10_Platform/spec/08-events-resource-requests.norms.md)
(Н1.4 `presence_lock`).

## Запуск

| Что | Как | Норма |
|---|---|---|
| воркер | юнит `<dep>-<sub>worker@.service`: экземпляр `%i` — имя слота `<prefix>-%l-1`, аргументом команды; `W2C_ROLE=<sub>worker`; `Type=notify` (М10/11 Н1.1 `notify`: `Type=notify` — у контроллера и воркера; строка юнита Н1.1 ещё называет `Type=simple` — см. «Открыто»), `NotifyAccess=main`, `WatchdogSec=360` | М10/11 Н1.1 |
| имя слота | аргумент команды; нет — переменная `slot.name_env`, если спека её объявила; иначе без имени | М10/5 Н3 «старт()» шаг 3 |
| запасной | юнит `<dep>-<sub>worker-spare@.service`: без имени; `W2C_SPARE_FILE=/run/w2c-spares/%n.env`, `Requisite=configstore` | М10/11 Н1.1, Н1.5 |
| старт по шагам | схема → спека → бюджет памяти → экземпляр → замок присутствия → имя → захват | М10/5 Н3 «старт()» шаги 0–3, М10/10 Н3 |

## Окружение

Окружение собирает раннер `w2c-run.sh` в порядке М10/11 Н1.2: значения юнита → `roles/<W2C_ROLE>.env` → `w2c.env` →
файл подсистемы, раньше прочитанное побеждает ([02-installer/lifecycle.md](../02-installer/lifecycle.md)).

| Переменная | Смысл | Умолчание | Норма |
|---|---|---|---|
| переменная `slot.name_env` спеки | имя слота, только если спека её объявила (`testsub2` — `TALLY_NAME`) | — | М10/11 Н1.2 |
| `SLOT_INDEX` | номер слота вместо имени | — | М10/11 Н1.2 |
| `SPARE_FOR` | набор меток запасного из `W2C_SPARE_FILE`; пусто — пустой набор | — | М10/11 Н1.2, Н1.5 |
| `W2C_SPARE_FILE` | файл запасного | `/run/w2c-spares/%n.env` | М10/11 Н1.5 |
| `BOX_ID` | коробка | `/etc/machine-id`, иначе hostname | М10/11 Н1.2, М10/5 Н3 шаг 2 |
| `SERVER_NAME` | сервер по грамматике суффикса слота | короткий hostname | М10/11 Н1.2 |
| `LABELS` | метки узла | — | М10/11 Н1.2 |
| `INSTANCE_ID` | экземпляр вместо `<box>:<pid>:<6hex>` | — | М10/11 Н1.2 |
| `PLATFORM_DIR` | корень состояния | `/data/platform` | М10/11 Н1.2 «Канал настройки и раскладка» |
| `PLATFORM_STORE` | дверь хранилища `configstore:///run/configstore/<sub>worker.sock` | `file://<PLATFORM_DIR>/config` (коробка одной реализации) | М10/11 Н1.2 |
| `OBJECTS` / `PLATFORM_OBJECTS` | хранилище объектов | `file://`; `cluster://` при configstore | М10/11 Н1.2 |
| `RESOURCE_ROOT` / `EVENTS` | корень событий: бакеты и замок присутствия | `<PLATFORM_DIR>/events` | М10/11 Н1.2, М10/8 Н1.4 |
| `SECRETS_KEY` | кольцо — у держателей секретов | — | М10/7 Н1.2 |
| `W2C_ROLE`, `W2C_TLS_DIR` | роль и комплект | `<sub>worker`; `/etc/w2c/tls` | М10/11 Н1.2, Н1.6 |
| `CAPACITY`, `WORKER_MEMORY_MB` | ёмкость и бюджет памяти | — | М10/11 Н1.2, Н1.5 `memory` |
| `BUILD` | слово сборки в пульсе (урок 10) | `dev` | М10/11 Н1.2, М10/10 Н1.1 |
| `W2C_ENV`, `W2C_SUB_ENV` | файлы окружения | `/etc/w2c/w2c.env`; путь юнита | М10/11 Н1.2 |
| `NOTIFY_SOCKET` | сторож systemd | — | М10/11 Н1.2 |

## Флаги

Нет: канал настройки — только окружение и аргумент имени (М10/11 Н1.2 «Канал настройки»).

| Путь | Что | Норма |
|---|---|---|

| `<корень событий>/<sub>/<unit>/e<эпоха>/…`, `<sub>.alarms/…`, `audit/<sub>worker/e1/…` | бакеты событий, участник `append` | [каталог](../common/data/catalog.tsv), М10/8 Н1.2 |
| объекты `<sub>/heartbeats/<имя>`, `<sub>/contenders/<имя>/<коробка>` | пульс и метка соперника | [каталог](../common/data/catalog.tsv), М10/5 Н1.1, Н1.4 |

| имена компонентов в деревьях | одно кодирование `%XX`, `%h<sha256>` | М10/8 Н1.1 |

## Коды выхода

| Код | Когда | Норма |
|---|---|---|
| 0 | метка спеки сменилась — остановиться, супервизор запустит заново; упорядоченная остановка по SIGTERM | М10/2 Н3 «Смена спеки», М10/5 Н3 «остановка по SIGTERM» |
| 2 | отказ старта: схема выше сборки или не число; нет строки или метки спеки, sha256 не тот, спека отказана; имя не по грамматике или не с `prefix`; замок присутствия не взят; строка файла окружения не по грамматике; запасной без файла или файл не одна строка `SPARE_FOR=…` | М10/10 Н3, М10/2 Н3, М10/5 Н3 шаги 2а, 2б, М10/11 Н1.2, Н1.5 |
| ≠ 0 | бюджет памяти превышен — не стартовать (`MemoryBudgetRefused`); свой код норма не задаёт | М10/5 Н3 «старт()» шаг 1, Н4; М10/11 Н4 |
| 2 | после продления схема выше сборки — отсечь, отдать имя, выйти; слот не отдаётся | М10/10 Н3, М10/5 Н4 |

## Сигналы и готовность

| Что | Как | Норма |
|---|---|---|
| SIGTERM | подмена и опрос — стоп; `before_stop_all`, единицы, писатели мест; последний пульс; отдать слот и место; `after_stop`; `TimeoutStopSec` ≥ 20 | М10/5 Н3 «остановка по SIGTERM», М10/11 Н1.1 |
| SIGKILL | ничего не пишет: судит контроллер по молчанию и замку присутствия | М10/5 Н3, М10/8 Н1.4 |
| готовность | `READY=1` после захвата имени; `WATCHDOG=1` каждым оборотом цикла, не из подмены | М10/11 Н1.1 `notify`, `watchdog` |
| перезапуск | `Restart=always`, `RestartSec=2`, `RestartPreventExitStatus=2` | М10/11 Н1.1 `common` |
| запечатанная единица | не запускается, эпохи не берёт, в `status` — `why` | М10/7 Н3 «открыть», М10/5 Н1.1 |

## Стенд

«Стенд» — [README приёмки М10/01](../../Source/tests/testdata/acceptance/М10_Platform/01/README.md): `@start worker [<sub>]
<имя>` — имя подстановкой `{name}` (аргумент), `{sub}`; окружение от `{data}` (`PLATFORM_DIR`), `BOX_ID` стенда,
`SERVER_NAME`, `PLATFORM_STORE` сокета роли, переменная `slot.name_env`, если спека её объявила; `@sigterm`, `@sigkill`;
запасной — `@start worker` без имени.

## Открыто

- `SERVER_NAME` и `INSTANCE_ID` сверены с М10/11 Н1.2.
- Строка юнита воркера в М10/11 Н1.1 называет `Type=simple`, а Н1.1 `notify` и решение «Архитектора» второго пилота —
  `Type=notify` у воркера: строку юнита нужно привести к `Type=notify` в норме.
- Запасной воркер (`<dep>-<sub>worker-spare@.service`) до предложения имя не захватывает, а `READY=1` норма даёт после
  захвата имени: при `Type=notify` старт запасного ждёт `TimeoutStartSec`. Нужна норма: когда запасной шлёт `READY=1`.
