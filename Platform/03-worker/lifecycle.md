# Воркер — жизненный цикл (урок P/03)

Контракт жизненного цикла процесса `<sub>worker` — SDK воркера на любом языке (ADR-0083 доп. (2) п. 1): запуск, имя,
окружение, замок присутствия, коды выхода, сигналы. Нормы здесь не пересказываются: каждая строка ведёт к своей норме.

Нормы: главы урока [3.2](spec/03.2-worker.norms.md) (Н1.4 имя слота, Н3 «старт()», «проверка схемы воркером», Н4),
[3.3](spec/03.3-worker.norms.md) (Н3 «цикл()»), [3.4](spec/03.4-worker.norms.md) (Н1.1 пульс, Н3 «старт() — шаг бюджета»,
«остановка по SIGTERM», Н4), [3.5](spec/03.5-worker.norms.md) (Н1.2 кольцо, Н3 «открыть»), [3.6](spec/03.6-worker.norms.md)
(Н1.2 события);
[P/02.4](../02-installer/spec/02.4-installer.norms.md) (Н1.1 юниты, Н1.2 окружение, Н1.5
воркеры по заказу), [P/02.3](../02-installer/spec/02.3-installer.norms.md) (Н3 «Старт процесса», «Смена
спеки»), [М10/10](../../М10_Platform/spec/10-schema-drain-snapshot-limits.norms.md) (Н1.1 строка схемы),
[М10/8](../../М10_Platform/spec/08-events-resource-requests.norms.md) (Н1.4 `presence_lock`, Н1.2 бакеты).

## Запуск

| Что | Как | Норма |
|---|---|---|
| воркер | юнит `<dep>-<sub>worker@.service`: экземпляр `%i` — имя слота `<prefix>-<SERVER_NAME>-<n>` (1 — базовый, 2…99 — по заказу контроллера, ADR-0084), аргументом команды; сервер в `%i` ≠ `SERVER_NAME` — код 2; `W2C_ROLE=<sub>worker`; `Type=notify`, `NotifyAccess=main`, `WatchdogSec=360` | P/02.4 Н1.1 |
| имя слота | аргумент команды; нет — переменная `slot.name_env`, если спека её объявила; иначе без имени | P/03.2 Н3 «старт()» шаг 3 |
| воркер по заказу | тот же юнит, экземпляр `<prefix>-<SERVER_NAME>-<n>`, n 2…99; запускает и останавливает скрипт воркеров по ряду `<sub>_workers_wanted{server}`; захват слота обычный | P/02.4 Н1.1, Н1.5 |
| старт по шагам | схема → спека → бюджет памяти → экземпляр → замок присутствия → имя → захват | P/03.2 Н3 «старт()» шаги 0–3 (шаг 1 — P/03.4 Н3 «старт() — шаг бюджета»), P/03.2 Н3 «проверка схемы воркером» |

## Окружение

Окружение собирает раннер `w2c-run.sh` в порядке P/02.4 Н1.2: значения юнита → `roles/<W2C_ROLE>.env` → `w2c.env` →
файл подсистемы, раньше прочитанное побеждает ([02-installer/lifecycle.md](../02-installer/lifecycle.md)).

| Переменная | Смысл | Умолчание | Норма |
|---|---|---|---|
| переменная `slot.name_env` спеки | имя слота, только если спека её объявила (`testsub2` — `TALLY_NAME`) | — | P/02.4 Н1.2 |
| `SLOT_INDEX` | номер слота вместо имени | — | P/02.4 Н1.2 |
| `BOX_ID` | коробка | `/etc/machine-id`, иначе hostname | P/02.4 Н1.2, P/03.2 Н3 «старт()» шаг 2 |
| `SERVER_NAME` | сервер по грамматике суффикса слота | короткий hostname | P/02.4 Н1.2 |
| `LABELS` | метки узла | — | P/02.4 Н1.2 |
| `INSTANCE_ID` | экземпляр вместо `<box>:<pid>:<6hex>` | — | P/02.4 Н1.2 |
| `PLATFORM_DIR` | корень состояния | `/data/platform` | P/02.4 Н1.2 «Канал настройки и раскладка» |
| `PLATFORM_STORE` | дверь хранилища `configstore:///run/configstore/<sub>worker.sock` | `file://<PLATFORM_DIR>/config` (коробка одной реализации) | P/02.4 Н1.2 |
| `OBJECTS` / `PLATFORM_OBJECTS` | хранилище объектов | `file://`; `cluster://` при configstore | P/02.4 Н1.2 |
| `RESOURCE_ROOT` / `EVENTS` | корень событий: бакеты и замок присутствия | `<PLATFORM_DIR>/events` | P/02.4 Н1.2, М10/8 Н1.4 |
| `SECRETS_KEY` | кольцо — у держателей секретов | — | P/03.5 Н1.2 |
| `W2C_ROLE`, `W2C_TLS_DIR` | роль и комплект | `<sub>worker`; `/etc/w2c/tls` | P/02.4 Н1.2, Н1.6 |
| `CAPACITY`, `WORKER_MEMORY_MB` | ёмкость и бюджет памяти | — | P/02.4 Н1.2, Н1.5 `memory` |
| `BUILD` | слово сборки в пульсе (урок 10) | `dev` | P/02.4 Н1.2, М10/10 Н1.1 |
| `W2C_ENV`, `W2C_SUB_ENV` | файлы окружения | `/etc/w2c/w2c.env`; путь юнита | P/02.4 Н1.2 |
| `NOTIFY_SOCKET` | сторож systemd | — | P/02.4 Н1.2 |

## Флаги

Нет: канал настройки — только окружение и аргумент имени (P/02.4 Н1.2 «Канал настройки»).

## Каталоги и файлы

| Путь | Что | Норма |
|---|---|---|
| `<корень событий>/.workers/<sub>/<экземпляр>.lock` | замок присутствия: содержимое заново при старте, исключающий `flock` всё время жизни | [каталог](../common/data/catalog.tsv), М10/8 Н1.4, P/03.2 Н3 «старт()» шаг 2б |
| `<корень событий>/<sub>/<unit>/e<эпоха>/…`, `<sub>.alarms/…`, `audit/<sub>worker/e1/…` | бакеты событий, участник `append` | [каталог](../common/data/catalog.tsv), М10/8 Н1.2, P/03.6 Н1.2 |
| объекты `<sub>/heartbeats/<имя>`, `<sub>/contenders/<имя>/<коробка>` | пульс и метка соперника | [каталог](../common/data/catalog.tsv), P/03.4 Н1.1, P/03.2 Н1.4а |
| `/etc/w2c/secrets/platform.key` (`SECRETS_KEY`) | кольцо — только чтение | [каталог](../common/data/catalog.tsv), [договор запечатывания](../common/contracts/sealing.md) |
| имена компонентов в деревьях | одно кодирование `%XX`, `%h<sha256>` | М10/8 Н1.1 |

## Коды выхода

| Код | Когда | Норма |
|---|---|---|
| 0 | метка спеки сменилась — остановиться, супервизор запустит заново; упорядоченная остановка по SIGTERM | P/02.3 Н3 «Смена спеки», P/03.4 Н3 «остановка по SIGTERM» |
| 2 | отказ старта: схема выше сборки или не число; нет строки или метки спеки, sha256 не тот, спека отказана; имя не по грамматике или не с `prefix`; замок присутствия не взят; строка файла окружения не по грамматике; сервер в `%i` ≠ `SERVER_NAME` | P/03.2 Н3 «проверка схемы воркером», P/02.3 Н3, P/03.2 Н3 «старт()» шаги 2а, 2б, P/02.4 Н1.2, Н1.5 |
| ≠ 0 | бюджет памяти превышен — не стартовать (`MemoryBudgetRefused`); свой код норма не задаёт | P/03.4 Н3 «старт() — шаг бюджета», Н4; P/02.4 Н4 |
| 2 | после продления схема выше сборки — отсечь, отдать имя, выйти; слот не отдаётся | P/03.2 Н3 «проверка схемы воркером», Н4 |

## Сигналы и готовность

| Что | Как | Норма |
|---|---|---|
| SIGTERM | подмена и опрос — стоп; `before_stop_all`, единицы, писатели мест; последний пульс; отдать слот и место; `after_stop`; `TimeoutStopSec` ≥ 20 | P/03.4 Н3 «остановка по SIGTERM», P/02.4 Н1.1 |
| SIGKILL | ничего не пишет: судит контроллер по молчанию и замку присутствия | P/03.4 Н3 «остановка по SIGTERM», М10/8 Н1.4 |
| готовность | `READY=1` после захвата имени; `WATCHDOG=1` каждым оборотом цикла, не из подмены | P/02.4 Н1.1 `notify`, `watchdog` |
| перезапуск | `Restart=always`, `RestartSec=2`, `RestartPreventExitStatus=2` | P/02.4 Н1.1 `common` |
| запечатанная единица | не запускается, эпохи не берёт, в `status` — `why` | P/03.5 Н3 «открыть», P/03.4 Н1.1 |

## Стенд

«Стенд» — [общий README приёмки](../common/acceptance/README.md): `@start worker [<sub>]
<имя>` — имя подстановкой `{name}` (аргумент), `{sub}`; окружение от `{data}` (`PLATFORM_DIR`), `BOX_ID` стенда,
`SERVER_NAME`, `PLATFORM_STORE` сокета роли, переменная `slot.name_env`, если спека её объявила; `@sigterm`, `@sigkill`;
воркеры по заказу — директива `@grow` (исполняет ряд `workers_wanted` вместо скрипта).

## Открыто

- `SERVER_NAME` и `INSTANCE_ID` сверены с P/02.4 Н1.2.
