# P/03.5 — Кольцо и открытие: нормы

Канон главы 3.5 урока P/03 «Воркер» (ADR-0080; модуль «Платформа» — ADR-0083). [Лекция](../03-worker.md),
[инструкция](03-worker.README.md), [жизненный цикл](../lifecycle.md). Своего HTTP-контракта у урока нет (`P/03 no-openapi`):
дверей у воркера нет. Каталога приёмки у главы нет (Н5). Конверт `enc:v2`, путь AAD, грамматика `kid` и форма файла кольца —
общий [договор запечатывания](../../common/contracts/sealing.md) (векторы [`common/vectors/sealing/`](../../common/vectors/sealing/README.md));
глава его не повторяет и нормирует сторону воркера: открытие получателем, единица без ключа стоит с причиной, чем воркер
читает кольцо (разбор ревью стадии A 3–5, № 21). Запечатывание консолью, маска, кто держит ключ, ротация, режим без ключа и
отпечаток — урок 6 (глава 6.2), до переноса — [М10/7](../../../М10_Platform/spec/07-secrets-and-sealing.norms.md).

Глава перенесена из [М10/7](../../../М10_Platform/spec/07-secrets-and-sealing.norms.md) (стадия B, ADR-0083 доп. (1): без
изменения поведения): Н3 «открыть (воркер, start_unit)» с «Гонками», строка `no_key.open_without` Н1.2 и абзац о `<kid>` в её
сообщении, строка Н4 «конверт не открывается у воркера», чтение открытия воркером Н5 (S2, S19), часть п. 1 «Решает
реализация». Номера подразделов — прежние номера М10/7. Ссылка «урок N» без главы — урок М10 (`М10_Platform/`), ещё не
перенесённый; «глава 3.K» — глава этого урока. Id норм — `P/03.5-MM`; соответствие прежним id —
[`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля — [P/01.1 Н0](../../01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Полей времени у главы нет.

**Данные** ([каталог](../../common/data/catalog.tsv)):
- читает: `/etc/w2c/secrets/platform.key`, `<sub>/<spec:unit.rows>/<id>`.

Кольцо воркер находит по пути `SECRETS_KEY` (пишет установщик — [P/02.4 Н1.9](../../02-installer/spec/02.4-installer.norms.md));
из строки единицы читает конверты `*_secret`.

### Н1.2 Конверт и кольцо: сторона воркера

Воркер открывает конверт по договору запечатывания — разделы «[Конверт](../../common/contracts/sealing.md#конверт)» и
«[Путь AAD](../../common/contracts/sealing.md#путь-aad)»: ключом `kid` конверта, с единственным AAD своего места; кольцо
читает из файла `SECRETS_KEY` по разделу «[Файл кольца](../../common/contracts/sealing.md#файл-кольца)». Кто держит ключ
(`holders`) и смена кольца (`rotate`) — [М10/7 Н1.2](../../../М10_Platform/spec/07-secrets-and-sealing.norms.md) (глава 6.2).
Конверт без ключа у воркера:

```yaml
no_key:
  open_without: конверт без ключа / с чужим kid → Sealed «sealed and this process has no key» / «sealed with key <kid>,
                which this process does not hold»; единица не запускается, причина — в её статусе
```

В сообщении open_without `<kid>` заменяется именем ключа конверта, ключевые байты не выводятся.

## Н3 Проход

### открыть (воркер, start_unit)

```
до взять_эпоху (глава 3.3 Н3 «цикл», шаг 2): прочитать строку; для каждого *_secret на любой глубине: не конверт → как
есть (строка до ключа); конверт → открыть ключом kid с единственным AAD договора запечатывания строки и полного пути; старые способы не пробовать
  нет ключа (SECRETS_KEY не задан) / чужой kid / не открывается    → Sealed: эпоху не брать, единицу не запускать; элемент
                                                                     status — why "the password does not open: <причина>"
                                                                     (М10/7 Н1.4 heartbeat) (сверка python и go М10/6–11, S19, S2)
значение — только получателю (драйверу, клиенту); в памяти, пульсе и логах — конверт
```

Шаг 2 цикла — [глава 3.3](03.3-worker.norms.md) Н3 «цикл», `взять_эпоху` — [глава 3.2](03.2-worker.norms.md) Н3; AAD —
[договор запечатывания](../../common/contracts/sealing.md) «Путь AAD»; `why` элемента `status` пульса — [глава 3.4](03.4-worker.norms.md)
Н1.1 и [М10/7 Н1.4](../../../М10_Platform/spec/07-secrets-and-sealing.norms.md) `heartbeat`.

**Гонки.** Нет: чтение; кольцо сменилось между запечатыванием и открытием — `kid` конверта называет ключ: открывается им или `Sealed` с причиной.

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| конверт не открывается у воркера | единица не запущена | статус единицы с причиной | кольцо держателя |

Отказы запечатывания на входе двери единиц и нечитаемого кольца у консоли — [М10/7 Н4](../../../М10_Platform/spec/07-secrets-and-sealing.norms.md)
(глава 6.2); нечитаемый файл кольца — [договор запечатывания](../../common/contracts/sealing.md) «Файл кольца».

## Н5 Приёмка

Каталога приёмки у главы нет: воркера на стенде урока 7 нет. Функция открытия воркера проходит векторы договора своей
функцией, без стенда: [`open.tsv`](../../common/vectors/sealing/open.tsv) (конверт не на своём месте, чужой ключ — `sealed`) и
[`ring.tsv`](../../common/vectors/sealing/ring.tsv) (файл кольца) — [README векторов](../../common/vectors/sealing/README.md).

Проверяются чтением: открытие воркером, эпоха и `why` при ошибке (S2, S19) — воркера на стенде урока нет (перенесено из
Н5 [М10/7](../../../М10_Platform/spec/07-secrets-and-sealing.norms.md); сверка python и go М10/6–11).

## Чеклист готовности

Реализация соответствует главе, когда выполнена каждая норма; id нормы `P/03.5-MM` — то, на что ссылаются дельты решений,
находки и записи окон (ADR-0080 доп. 6):

- [ ] **P/03.5-01** воркер открывает конверт `enc:v2` по [договору запечатывания](../../common/contracts/sealing.md) с единственным AAD своего места (ключ строки и полный путь), старые способы не пробует; переставленный между строками и полями конверт не открывается — векторы [`open.tsv`](../../common/vectors/sealing/open.tsv) своей функцией открытия; открытие на строке единицы — чтением Н3 «открыть» и теста реализации: воркера на стенде урока 7 нет (часть М10/7-03 по `note` id-map: конверт на входе — 400 — глава 6.2; форма конверта и байты AAD — договор запечатывания)
- [ ] **P/03.5-02** открывает получатель в последний момент — до `взять_эпоху`, значение только получателю, в памяти, пульсе и логах — конверт; без ключа, с чужим `kid` или неоткрывающийся конверт — единица стоит с причиной (`Sealed`, `why` в статусе, ключевые байты не выводятся) — проверяется чтением Н3 «открыть» (S2, S19): воркера на стенде урока 7 нет (часть М10/7-05 по `note` id-map: запечатывает консоль, режим разработки без кольца и 503 нечитаемого кольца у двери единиц — глава 6.2)

## Соответствие прежним урокам

Перенесено из М10/7 (стадия B): Н3 «открыть (воркер, start_unit)» с «Гонками», строка `no_key.open_without` Н1.2 и абзац о
`<kid>` в её сообщении, строка Н4 «конверт не открывается у воркера», чтение открытия воркером Н5 (S2, S19), часть п. 1
«Решает реализация» (здесь п. 1). Id чеклиста ([id-map](../../common/id-map.tsv)): М10/7-03 → P/03.5-01 (сторона воркера),
М10/7-05 → P/03.5-02 (сторона получателя). Что в М10/7 повторяет договор запечатывания (`enc:v2`, байты AAD, грамматика
`kid`, файл кольца), не перенесено: глава ссылается на договор и его векторы (разбор ревью стадии A 3–5, № 21).
