HTTP-контракта у урока нет: дверей у воркера нет (Н2). Каталога приёмки у главы нет (Н5). Глава перенесена из
М10/5 (стадия B, ADR-0083 доп. (1): без изменения
поведения): Н2 — шесть вызовов подсистемы и абзац о вызовах упорядоченной остановки, строка Н5 «Проверяются чтением» о
`before_stop_all` и `after_stop`, п. 1 «Решает реализация»; пункты чеклиста — части М10/5-03 (вызовы цикла), -05 (вызов
под слотом), -10 (вызовы остановки) по `note` id-map. Проходы, которые зовут вызовы, — главы 3.2 («взять_эпоху»), 3.3
(«цикл()»), 3.4 (пульс, «остановка по SIGTERM»). Ссылка «урок N» без главы — урок М10 (`М10_Platform/`), ещё не
перенесённый; «глава 3.K» — глава этого урока; «P/01.K», «P/02.K» — главы уроков 1 и 2. Id норм — `P/03.1-MM`;
соответствие прежним id — [`id-map.tsv`](../../common/id-map.tsv).

## Н2 Договор библиотеки

У воркера нет собственной двери в этом уроке: он пишет и читает хранилище (P/01.1) и объекты (урок 8). Что о нём видно снаружи — пульс, слот, метка соперника, `/servers` консоли (урок 9). HTTP-контрактов своего урока нет (ADR-0082 доп. 13). Формы ответов чтения/записи — [P/01.1](../../01-store/spec/01-store.api.openapi.yaml), единиц — [урок 3](../../../М10_Platform/spec/03-units-slots-epochs-lease.api.openapi.yaml), объектов — [урок 8](../../../М10_Platform/spec/08-events-resource-requests.norms.md#н2-двери). Пульс — форма [главы 3.4](03.4-worker.norms.md) Н1.1, не HTTP-ответ воркера. Подсистеме воркер даёт шесть вызовов, форма которых — дело языка (решает реализация):

```
start_unit(id, row, epoch)   — запустить единицу под эпохой
stop_unit(id)                — остановить
status() → [status-элемент]  — доложить для пульса
reconcile_once()             — шаг сверки желаемого с текущим (глава 3.3 Н3 «цикл()», шаг 2)
before_stop_all()            — упорядоченная остановка, до stop_unit всех единиц: подсистема готовится (сбросить буферы,
                               закончить начатое); по умолчанию ничего; ошибка — строка журнала, остановка продолжается
after_stop()                 — после отдачи слота и места: подсистема закрывает своих писателей; по умолчанию ничего;
                               ошибка — строка журнала, код выхода остановки по SIGTERM не меняется
```

Оба вызова остановки зовутся только при упорядоченной остановке (SIGTERM, [глава 3.4](03.4-worker.norms.md) Н3); при крахе их нет, и по этому
контроллер отличает уход от краха (урок 4). Это вызовы воркера по правилу трёх мест (граница §1.1), не хуки платформы.

---

## Н3 Проход

Своих проходов у главы нет. Кто и когда зовёт вызовы Н2: `start_unit` — после ворот «взять_эпоху» [главы 3.2](03.2-worker.norms.md) Н3
и на перезапуске по revision ([глава 3.3](03.3-worker.norms.md) Н3 «цикл()», шаг 2); `stop_unit` — цикл, шаг аренды, отсечение и
остановка (главы 3.2–3.4); `status` — пульс ([глава 3.4](03.4-worker.norms.md) Н1.1); `reconcile_once` — цикл, шаг 2;
`before_stop_all`, `after_stop` — «остановка по SIGTERM» [главы 3.4](03.4-worker.norms.md) Н3, шаги 2 и 5.

---

## Н4 Отказы

Своих строк Н4 у главы нет: ошибка вызова остановки — строка журнала, остановка продолжается, код выхода не меняется
(Н2); отказы проходов, которые зовут вызовы, — Н4 глав 3.2–3.4.

---

## Н5 Приёмка

Каталога приёмки у главы нет: сценарии стенда не наблюдают вызовов подсистемы, только строки, которые пишут проходы глав
3.2–3.4. Проверяются чтением: вызовы `before_stop_all` и
`after_stop` — предмет: Н2 и [глава 3.4](03.4-worker.norms.md) Н3 «остановка» шаги 2 и 5 — порядок до stop_unit всех единиц и после отдачи слота и места,
только при SIGTERM, ошибка — строка журнала, остановка продолжается; воркер `testsub` их не переопределяет, свидетельство —
тест воркера подсистемы, которая переопределяет.

## Решает реализация

Реализация обязана назвать в своём описании:

1. **форму шести вызовов подсистемы** (Н2), синхронизацию принятия/отмены запуска с отсечением
   и помощник сверки (ADR-0033).

## Чеклист готовности

Реализация соответствует главе, когда выполнена каждая норма; id нормы `P/03.1-MM` — то, на что ссылаются дельты решений,
находки и записи окон (ADR-0080 доп. 6). Пункты главы — части М10/5-03, -05, -10 по `note` id-map (перенос урока 3).

- [ ] **P/03.1-01** вызовы цикла Н2 (часть 3.1 М10/5-03 по `note` id-map; цикл — [P/03.3-01](03.3-worker.norms.md)): `start_unit`, `stop_unit`, `status`, `reconcile_once` — шесть вызовов, форма которых — дело языка; `reconcile_once` — шаг 2 цикла, `status` — элементы пульса — сц. 02 [приёмки главы 3.3](../acceptance/3/README.md); форма вызовов — чтением («Решает реализация» п. 1)
- [ ] **P/03.1-02** вызов под слотом (часть 3.1 М10/5-05 по `note` id-map; ворота — [P/03.2-10](03.2-worker.norms.md)): `start_unit(id, row, epoch)` — запуск единицы под эпохой, выданной воротами «взять_эпоху», после повторной проверки ворот; перезапуск по revision — та же эпоха — сц. 02, 06 [приёмки главы 3.3](../acceptance/3/README.md); синхронизация принятия/отмены запуска с отсечением — чтением («Решает реализация» п. 1)
- [ ] **P/03.1-03** вызовы остановки Н2 (часть 3.1 М10/5-10 по `note` id-map; остановка — [P/03.4-05](03.4-worker.norms.md)): `before_stop_all` до stop_unit всех единиц, `after_stop` после отдачи слота и места, только при SIGTERM, при крахе их нет; ошибка — строка журнала, остановка продолжается, код выхода не меняется — проверяется чтением (Н5)
