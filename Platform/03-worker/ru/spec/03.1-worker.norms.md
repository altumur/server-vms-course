## N2 Договор библиотеки

У воркера нет собственной двери в этом уроке: он пишет и читает хранилище (P/01.1) и объекты (P/05). Что о нём видно снаружи — пульс, слот, метка соперника, `/servers` консоли (P/06, глава 6.5). HTTP-контрактов своего урока нет (ADR-0082 доп. 13). Формы ответов чтения/записи — [P/01.1](../../../01-store/spec/01-store.api.openapi.yaml), единиц — [P/06](../../../06-console/spec/06-console.api.openapi.yaml) (глава 6.1), объектов — [P/05](../../../05-resource/ru/spec/05-resource.norms.md#n2-двери). Пульс — форма [главы 3.4](03.4-worker.norms.md) N1.1, не HTTP-ответ воркера. Подсистеме воркер даёт шесть вызовов, форма которых — дело языка (решает реализация):

```
start_unit(id, row, epoch)   — запустить единицу под эпохой
stop_unit(id)                — остановить
status() → [status-элемент]  — доложить для пульса
reconcile_once()             — шаг сверки желаемого с текущим (глава 3.3 N3 «цикл()», шаг 2)
before_stop_all()            — упорядоченная остановка, до stop_unit всех единиц: подсистема готовится (сбросить буферы,
                               закончить начатое); по умолчанию ничего; ошибка — строка журнала, остановка продолжается
after_stop()                 — после отдачи слота и места: подсистема закрывает своих писателей; по умолчанию ничего;
                               ошибка — строка журнала, код выхода остановки по SIGTERM не меняется
```

Слово библиотеки `stalled(id)` — не вызов подсистемы, а её вопрос к библиотеке, форма — дело языка: единица застряла, отступ запуска дошёл до `RETRY_MAX`, пока счёт не обнулён ([глава 3.3](03.3-worker.norms.md) N1.2 `stalled`), то же значение, что `status[].stalled` пульса. Подсистема, которой это нужно, спрашивает из своих вызовов и своего счёта неудач не ведёт: он разошёлся бы с отступом (C03-STALLED-WORD-01, решение «Архитектора» 2026-11-01, разбор прохода VMS).

Слово библиотеки `restarting(id)` — такой же вопрос подсистемы из `stop_unit`: истина, когда этот `stop_unit` — перезапуск той же единицы по росту `revision` ([глава 3.3](03.3-worker.norms.md) N3 «цикл()», шаг 2); вне него, при снятии, переезде и остановке воркера — ложь (C03-RESTART-WORD-01, решение «Архитектора» 2026-11-01, разбор прохода VMS).

Оба вызова остановки зовутся только при упорядоченной остановке (SIGTERM, [глава 3.4](03.4-worker.norms.md) N3); при крахе их нет, и по этому
контроллер отличает уход от краха (P/04). Это вызовы воркера по правилу трёх мест (граница §1.1), не хуки платформы.

## N3 Проход

Своих проходов у главы нет. Кто и когда зовёт вызовы N2: `start_unit` — после ворот «take_unit_epoch» [главы 3.2](03.2-worker.norms.md) N3
и на перезапуске по revision ([глава 3.3](03.3-worker.norms.md) N3 «цикл()», шаг 2); `stop_unit` — цикл, шаг аренды, отсечение и
остановка (главы 3.2–3.4); `status` — пульс ([глава 3.4](03.4-worker.norms.md) N1.1); `reconcile_once` — цикл, шаг 2;
`before_stop_all`, `after_stop` — «остановка по SIGTERM» [главы 3.4](03.4-worker.norms.md) N3, шаги 2 и 5.

## N4 Отказы

Своих строк N4 у главы нет: ошибка вызова остановки — строка журнала, остановка продолжается, код выхода не меняется
(N2); отказы проходов, которые зовут вызовы, — N4 глав 3.2–3.4.

## N5 Приёмка

Каталога приёмки у главы нет: сценарии стенда не наблюдают вызовов подсистемы, только строки, которые пишут проходы глав
3.2–3.4. Проверяются чтением: вызовы `before_stop_all` и
`after_stop` — предмет: N2 и [глава 3.4](03.4-worker.norms.md) N3 «stop» шаги 2 и 5 — порядок до stop_unit всех единиц и после отдачи слота и места,
только при SIGTERM, ошибка — строка журнала, остановка продолжается; воркер `testsub` их не переопределяет, свидетельство —
тест воркера подсистемы, которая переопределяет.

## Чеклист готовности

Реализация соответствует главе, когда выполнена каждая норма; id нормы `P/03.1-MM` — то, на что ссылаются дельты решений,

- [ ] **P/03.1-01** вызовы цикла N2 (цикл — [P/03.3-01](03.3-worker.norms.md)): `start_unit`, `stop_unit`, `status`, `reconcile_once` — шесть вызовов, форма которых — дело языка; `reconcile_once` — шаг 2 цикла, `status` — элементы пульса — сц. 02 [приёмки главы 3.3](../acceptance/3/README.md); форма вызовов — чтением («Решает реализация» п. 1)
- [ ] **P/03.1-02** вызов под слотом (ворота — [P/03.2-10](03.2-worker.norms.md)): `start_unit(id, row, epoch)` — запуск единицы под эпохой, выданной воротами «take_unit_epoch», после повторной проверки ворот; перезапуск по revision — та же эпоха — сц. 02, 06 [приёмки главы 3.3](../acceptance/3/README.md); синхронизация принятия/отмены запуска с отсечением — чтением («Решает реализация» п. 1)
- [ ] **P/03.1-03** вызовы остановки N2 (остановка — [P/03.4-05](03.4-worker.norms.md)): `before_stop_all` до stop_unit всех единиц, `after_stop` после отдачи слота и места, только при SIGTERM, при крахе их нет; ошибка — строка журнала, остановка продолжается, код выхода не меняется — проверяется чтением (N5)
