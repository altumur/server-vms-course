Канон главы 3.5 урока P/03 «Воркер» (ADR-0080; модуль «Платформа» — ADR-0083). Лекция (`ru/03-worker.md`, для человека, в выгрузку не входит),
[инструкция](03-worker.README.md), [жизненный цикл](../lifecycle.md). Своего HTTP-контракта у урока нет (`P/03 no-openapi`):
дверей у воркера нет. Каталога приёмки у главы нет (N5). Конверт `enc:v2`, путь AAD, грамматика `kid` и форма файла кольца —
общий [договор запечатывания](../../../common/ru/contracts/sealing.md) (векторы [`common/vectors/sealing/`](../../../common/ru/vectors/sealing/README.md));
глава его не повторяет и нормирует сторону воркера: открытие получателем, единица без ключа стоит с причиной, чем воркер
читает кольцо (разбор ревью стадии A 3–5, № 21). Запечатывание консолью, маска, кто держит ключ, ротация, режим без ключа и
отпечаток — [глава P/06.2](../../../06-console/ru/spec/06.2-console.norms.md).

Глава перенесена из М10/7 (стадия B, ADR-0083 доп. (1): без
изменения поведения): N3 «открыть (воркер, start_unit)» с «Гонками», строка `no_key.open_without` N1.2 и абзац о `<kid>` в её
сообщении, строка N4 «конверт не открывается у воркера», чтение открытия воркером N5 (S2, S19), часть п. 1 «Решает
реализация». Номера подразделов — прежние номера М10/7. Ссылка «урок N» без главы — урок
модуля P/NN; «глава 3.K» — глава этого урока. Id норм — `P/03.5-MM`; соответствие прежним id —

## N1 Форма

**Время.** Полей времени у главы нет.

**Данные** ([каталог](../../../common/data/catalog.tsv)):
- читает: `/etc/w2c/secrets/platform.key`, `<sub>/<manifest:unit.rows>/<id>`.

Кольцо воркер находит по пути `SECRETS_KEY` (пишет установщик — [P/02.4 N1.9](../../../02-installer/ru/spec/02.4-installer.norms.md));
из строки единицы читает конверты `*_secret`.

### N1.2 Конверт и кольцо: сторона воркера

Воркер открывает конверт по договору запечатывания — разделы «[Конверт](../../../common/ru/contracts/sealing.md#конверт)» и
«[Путь AAD](../../../common/ru/contracts/sealing.md#путь-aad)»: ключом `kid` конверта, с единственным AAD своего места; кольцо
читает из файла `SECRETS_KEY` по разделу «[Файл кольца](../../../common/ru/contracts/sealing.md#файл-кольца)». Кто держит ключ
(`holders`) и смена кольца (`rotate`) — [P/06.2 N1.2](../../../06-console/ru/spec/06.2-console.norms.md).
Конверт без ключа у воркера:

```yaml
no_key:
  open_without: конверт без ключа / с чужим kid → Sealed «sealed and this process has no key» / «sealed with key <kid>,
                which this process does not hold»; единица не запускается, причина — в её статусе
```

В сообщении open_without `<kid>` заменяется именем ключа конверта, ключевые байты не выводятся.

## N3 Проход

### открыть (воркер, start_unit)

```
до взять_эпоху (глава 3.3 N3 «цикл», шаг 2): прочитать строку; для каждого *_secret на любой глубине: не конверт → как
есть (строка до ключа); конверт → открыть ключом kid с единственным AAD договора запечатывания строки и полного пути; старые способы не пробовать
  нет ключа (SECRETS_KEY не задан) / чужой kid / не открывается    → Sealed: эпоху не брать, единицу не запускать; элемент
                                                                     status — {id, phase: "sealed", why, revision}: why "the
                                                                     password does not open: <причина>" (P/06.2 N1.4 heartbeat)
                                                                     (сверка python и go М10/6–11, S19, S2); epoch и
                                                                     observed_revision нет, revision — прочитанной строки
                                                                     (глава 3.4 N1.1; догадка стадии C W03-G02, решение «Архитектора» 2026-10-23)
значение — только получателю (драйверу, клиенту); в памяти, пульсе и логах — конверт
место (глава 3.2 N3 «place: take», держать): при взятии места и при смене строки держимого места — открыть *_secret
строки таблицы мест тем же правилом и тем же AAD договора запечатывания (ключ строки таблицы и полный путь), что строку
единицы; Sealed → место не берётся (держимое — уходит с места, leave_place главы 3.2 N3 «hold»; released не пишется, C03-PLACE-SEALED-LEAVE-01), place_error.<место>: sealed в пульсе (глава 3.4 N1.1),
причина — у места, не у единицы; открытое значение — только в памяти и вызове подсистемы (ADR-0091 доп. (9) пп. 5–6, доп. (10))
```

Шаг 2 цикла — [глава 3.3](03.3-worker.norms.md) N3 «цикл», `take_epoch` — [глава 3.2](03.2-worker.norms.md) N3; AAD —
[договор запечатывания](../../../common/ru/contracts/sealing.md) «Путь AAD»; `why` элемента `status` пульса — [глава 3.4](03.4-worker.norms.md)
N1.1 и [P/06.2 N1.4](../../../06-console/ru/spec/06.2-console.norms.md) `heartbeat`.

**Гонки.** Нет: чтение; кольцо сменилось между запечатыванием и открытием — `kid` конверта называет ключ: открывается им или `Sealed` с причиной.

## N4 Отказы

Закрытый каталог главы — [forms/refusals.tsv](../../forms/refusals.tsv), строки `chapter = 3.5`. Нормативные ячейки прежних таблиц сохранены в колонках `word`, `cause`, `outcome`, `diagnostic`, `caller` в исходном порядке; `-` — ячейки нет. Машинные колонки задают поверхность и фиксированный код, если он есть. `peer` ссылается на договор чужой двери и не вводит HTTP API воркера.

## N5 Приёмка

Каталога приёмки у главы нет: воркера на стенде главы 6.2 нет. Функция открытия воркера проходит векторы договора своей

N5 М10/7; сверка python и go М10/6–11).

## Чеклист готовности

Реализация соответствует главе, когда выполнена каждая норма; id нормы `P/03.5-MM` — то, на что ссылаются дельты решений,
находки и записи окон (ADR-0080 доп. 6):

- [ ] **P/03.5-01** воркер открывает конверт `enc:v2` по [договору запечатывания](../../../common/ru/contracts/sealing.md) с единственным AAD своего места (ключ строки и полный путь), старые способы не пробует; переставленный между строками и полями конверт не открывается — векторы [`open.tsv`](../../../common/vectors/sealing/open.tsv) своей функцией открытия; открытие на строке единицы — чтением N3 «открыть» и теста реализации: воркера на стенде главы 6.2 нет (часть М10/7-03 по `note` id-map: конверт на входе — 400 — глава 6.2; форма конверта и байты AAD — договор запечатывания)
- [ ] **P/03.5-02** открывает получатель в последний момент — до `take_epoch`, значение только получателю, в памяти, пульсе и логах — конверт; без ключа, с чужим `kid` или неоткрывающийся конверт — единица стоит с причиной (`Sealed`, `why` в статусе, ключевые байты не выводятся) — проверяется чтением N3 «открыть» (S2, S19): воркера на стенде главы 6.2 нет (часть М10/7-05 по `note` id-map: запечатывает консоль, режим разработки без кольца и 503 нечитаемого кольца у двери единиц — глава 6.2)
- [ ] **P/03.5-03** секрет строки места открывается при взятии места тем же правилом и AAD, Sealed — место не берётся, причина у места — стенд не готовит исключительного места и строки места с неоткрывающимся секретом — чтением; сценарии P/04 и P/03.2 — когда учебная подсистема получит такое место (долг) (ADR-0091 доп. (9)–(10))
