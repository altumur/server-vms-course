# Данные случаев только для судьи

Этот русский текст — производный от `forms/README.cases.md`, руками не правится (ADR-0121).

Общие правила остаются в [README.md](README.md). Следующие исходные отрывки сохраняют прежние связи именованных случаев как происхождение только для судьи.

### Исходный отрывок 1

| `worker-token-cache` | Вид, текущая идентичность токена, события отказа/выдачи, признак тех же суток и фикстура проверки. Транспорт агента управляем; настоящие байты токена, ключи, отзывы и время скопированы из общих публичных случаев domain-token token-36-kind-list-audience-map и token-keep-alive. Проверка нигде не обходится. Наблюдаются запросы, слово revoked, ожидание, файлы/строки/журнал. Криптография получателя также проходит общие векторы domain-token. |

### Исходный отрывок 2

Адаптер захвата получает gen_readable по кодеку/области самого поля поколения независимо от других полей слота, до сужения. row_readable отдельно проверяет слот целиком. Подтверждённое отсутствие — отдельный случай с операндом 0. Существующий gen в 1..9007199254740991 читаем, но gen_incrementable истинен лишь ниже максимума. Вне диапазона — существующий нечитаемый gen, исходные байты сохраняются. При false машинный gen=0 — неиспользуемая заглушка. generation_exhausted остаётся для читаемого максимума у иначе допустимого кандидата; допуски NameOnAnotherBox/torn-young не обходятся. s21/s22 проверяют gen_readable=false, отсутствие записей и точный slot_gen_after; нового программного слова для unreadable не вводят, поскольку word каталога не задан.

### Исходный отрывок 3

worker-holder-takeover запускает две эпохи процессов-держателей и настоящий заблокированный callback действия. A начинает r1 в0.2; B берёт эпоху2 в1; старый callback возвращается в30.2. В11.2 фиксированное ожидание B в10.2секунды истекло, пока старый вызов ещё не вернулся. Записываются настоящая трасса незавершённых вызовов и смены держателя/эпохи: old_call_unfinished_after_wait=true, cross_holder_exclusion_proven_by_wait=false, witness=overlap_possible_marked. Адаптер выводит наблюдения из управляемой трассы IO/callback, не возвращает константы. Шов не требует отправки B в самый ранний разрешённый момент: более сильный барьер/ограждение может отложить или отвергнуть её. Отмечается, почему одно фиксированное ожидание не даёт междержательного исключения; прежний однодержательный s4 сохраняет максимум одного незавершённого вызова. Нового вида тревог/событий нет.
