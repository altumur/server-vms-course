# Инструкции ожиданий конкретных случаев только для судьи

Этот русский текст — производный от `acceptance/3/sleeps.cases.md`, руками не правится (ADR-0121).

Файл сохраняет инструкции конкретных случаев из README приёмки главы. Это данные только для судьи, не вход модели. Общий смысл ожиданий остаётся в общем протоколе стенда.

## Сны (`@sleep`, ADR-0080 доп. (17) п. 4)

Ожидание события — `@until`. Оставшиеся сны — проверка отсутствия или время перед действием; длина — наименьшая по срокам [главы 3.2](../../spec/03.2-worker.norms.md) N1.2 и главы 3.3 N1.2:

| Сц./шаг | Сон | Причина |
|---|---|---|
| 02/10 | 12 с | отсутствие: правка строки не поднимает эпоху; новую ревизию воркер увидел бы за LEASE_EVERY ≈ 8,3 с и проход POLL ~2 с |
| 06/9 | 12 с | время перед действием: воркер должен увидеть пустое назначение (шаг аренды ≈ 8,3 с и проход) до повторного создания `c6`; его пульс — объект, стенд главы его не читает |

Конец инструкций конкретных случаев только для судьи.
