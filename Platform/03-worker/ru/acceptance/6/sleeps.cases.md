# Инструкции ожиданий конкретных случаев только для судьи

Этот русский текст — производный от `acceptance/6/sleeps.cases.md`, руками не правится (ADR-0121).

Файл сохраняет инструкции конкретных случаев из README приёмки главы. Это данные только для судьи, не вход модели. Общий смысл ожиданий остаётся в общем протоколе стенда.

## Сны (`@sleep`, ADR-0080 доп. (17) п. 4)

| Сц./шаг | Сон | Причина |
|---|---|---|
| 05/7 | 20 с | отсутствие: строка просьбы не снимается сразу после `performed` — нижняя граница settle с запасом (выше, «scenarios.tsv») |
| 10/12 | 12 с | отсутствие: после потери имени версия слота, `ts` пульса и строка состояния не меняются, второй `worker.name_taken` не пишется — продление (≈ 8,3 с), пульс (10 с) и поиск имени (CONTEND_EVERY 10 с) были бы видны |
| 40/7 | 12 с | отсутствие: метки по нечитаемой строке просьбы нет и строка не снята — взгляд держателя на каждом проходе (POLL ~2 с) и жнец успели бы |
