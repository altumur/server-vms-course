# Инструкции ожиданий конкретных случаев только для судьи

Этот русский текст — производный от `acceptance/sleeps.cases.md`, руками не правится (ADR-0121).

Файл сохраняет инструкции конкретных случаев из README приёмки главы. Это данные только для судьи, не вход модели. Общий смысл ожиданий остаётся в общем протоколе стенда.

## Сны (`@sleep`, ADR-0080 доп. (17) п. 4)

Один сон: сц. `18-schema-read-wait` шаг 3, `@sleep 10` — проверка отсутствия: пока хранилище молчит ресурсу, он не выходит
(ошибка чтения `platform/schema` — ждать, не стартовать с кодом 2; выход виден шагом 5 — строки двери так и нет); за 10 с
запущенный процесс доходит до первого шага старта — чтения схемы. Второй проход аудита (Gemini) — ещё два: сц. 33 шаг 3,
`@sleep 2` — проверка отсутствия: повторный приём той же копии бакета `written` не сдвигает (R05-G04); `written` — стенные секунды,
у реализации может быть целым числом, поэтому между приёмами проходит больше секунды, иначе сдвиг не был бы виден; сц. 41 шаг 6,
`@sleep 12` — проверка отсутствия: своя строка `free-*` в полосе между отметками не снимается и не переписывается; пульс с
`pass_started` (шаг 5) говорит только о начале первого прохода. Фиксированный сон не подтверждает конец `relieve`; это раннее наблюдение. Завершение отдельно проверяет синхронный CALL s63-free-ask-band-completed. Ожидание события — `@until`: сц. 09-resource-door шаг 2 ждёт первой строки двери, шаг 3 — новой отметки двери
(`at` сменился; отметка — каждые ALIVE_EVERY, N1.4 `door_row`), сц. 08 шаг 16 — строки тревоги в индексе, сц. 16-presence-lock
шаги 3, 5, 7 — `running` в пульсе ресурса (разбор ревью стадии B 3–5, № 26); сц. 17 шаг 8, 18 шаг 5 — первой строки двери; сц. 19 шаг 3 — пульса
`w-1` в листинге; сц. 20 шаги 3, 5, 7, 9 — счёта двери после отметки (каждые ALIVE_EVERY); сц. 22 шаги 3, 5 — строк индекса; сц. 31 шаги 2, 4 — двери
`srv-b` и `srv-a`, шаг 8 — копии тела у `srv-b` после первого прохода перезапущенного `srv-a`; сц. 33 шаг 9, 37–39 шаг пульса, 40
шаги 4, 5, 41 шаг 5, 42 шаг 5 — пульса ресурса (каждые 10 с) после первого прохода; сц. 34–36 — строк индекса; сц. 43 шаг 2 — пульса
`w-1` в листинге.

Конец инструкций конкретных случаев только для судьи.
