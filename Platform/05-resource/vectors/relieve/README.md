# Векторы: просьба освободить место (`relieve`)

Владелец — урок [P/05](../../spec/05-resource.norms.md) (Н1.4 `free_ask`, Н3 «проход ресурса» `relieve`; запрос VMS freeing,
решение «Архитектора» 2026-10-23). Участники — ресурс (пишет и снимает `<sub>/requests/free-<server>-<volume>`) и воркеры
подсистемы с `requests.free` (отвечают полем пульса `freeing`, [P/03.4](../../../03-worker/spec/03.4-worker.norms.md) Н1.1).
Байты пишет «Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.
`input` — `{space, volume, sub, server, heartbeats}`: строка `platform/space` (`enabled`, `high`, `low`), том ресурса (`name`,
`used`, `total` в байтах), подсистема и сервер просьбы, пульсы воркеров (`sub`, `server`, `live` — пульс живой, `freeing` —
поле пульса или его нет); `expect` — `{action: write, free}` (записать или переписать строку с `free`), `{action: delete}`
(снять свою строку) или `{action: none}` (просьбы нет).

## `short.tsv`

Поле пульса ресурса `short` (P/05 Н1.4; догадка стадии C R05-G03, решение «Архитектора» 2026-10-23). Те же правила файла; заголовок `case<TAB>input<TAB>expect<TAB>note`.
`input` — `{space, server, volumes, subs, heartbeats}`: строка `platform/space`, сервер ресурса, тома (`name`, `used`, `total`),
подсистемы с `requests.free`, пульсы воркеров (как в `cases.tsv`); `expect` — `{short: <целое>}`: Σ по томам наибольшей `need`
(> 0) среди подсистем — у каждой подсистемы `need` тома по Н3 `relieve` (`used − total·low − Σ freeing`, вверх до байта), только
у тома выше `high`. 6 случаев: два тома и две подсистемы, том ниже `high`, всё освобождается, `space` выключен, нет подсистем,
округление вверх.

## Прогон

Сторона считает шаг `relieve` своим кодом ресурса по входу, без хранилища, и сравнивает действие с `expect` (JSON по значению).
Кто исполняет — ресурс (`05-resource`: шаг `relieve` и поле `short`, P/05 Н3 «проход ресурса», Н1.4 `free_ask`) — обе таблицы. Только читают готовое: воркеры подсистемы (`03-worker`, отвечают `freeing` на строку `free-*`, P/03.4 Н1.1) и консоль (`06-console`, ряд `w2c_resource_short_bytes` как есть, P/06.5 Н3 «/metrics — текст») (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).
