# Спека и установщик — жизненный цикл (урок P/02)

Контракт жизненного цикла установщика и его команд (ADR-0083 доп. (2) п. 1): установка и обновление, установка спеки,
вывод прав, центр сертификатов, скрипт запасных. Стадия A — поверх нынешних норм М10 и М11. Нормы здесь не
пересказываются: каждая строка ведёт к своей норме.

Нормы: [М10/11](../../М10_Platform/spec/11-the-platform-on-a-box-and-a-cluster.norms.md) (Н1.1 юниты, Н1.2 окружение,
Н1.5 запасные, Н1.6 сертификаты, Н1.7 установка, Н1.9 команды, Н4), [М10/2](../../М10_Platform/spec/02-the-spec-and-the-strict-loader.norms.md)
(Н1.5 строка спеки, Н3 «Смена спеки», Н4), [М10/6](../../М10_Platform/spec/06-rights.norms.md) (Н2 инструмент прав,
Н3 «сгенерировать», «установить»), [М11/12](../../М11_Domain/spec/12-small-members-and-one-node.norms.md) (Н1.1, Н1.8),
[М11/2](../../М11_Domain/spec/02-root-keys-and-revocation.norms.md) (Н3 «установка домена»).

## Запуск

Установщик — не служба, а команды оператора; повтор установки — обновление.

| Команда | Что | Норма |
|---|---|---|
| `install.sh` | установка и обновление: код, пользователи и группы, каталоги, спеки, окружение и файлы ролей (никогда поверх), ключ секретов, юниты, центр, файл прав, `spec put`, `enable` | М10/11 Н1.7 `install` |
| обновление сервера за сервером | `POST /drain` → `safe: true` → остановить, обновить, запустить → `DELETE /drain`; последним — подъём схемы | М10/11 Н1.7 `upgrade`, М10/10 |
| `w2cctl spec put <файл>` | установка одной спеки: загрузка, полный каталог, строка, затем метка `/rev` | М10/2 Н3 «Смена спеки» |
| `w2cctl rights -deployment <имя> [--check <файл>]` | вывод прав из `SPEC_DIR`; `--check` — по смыслу | М10/6 Н2, Н3 |
| `w2c-ca.sh init \| issue \| revoke \| crl \| own` | центр и комплекты ролей | М10/11 Н1.6 |
| `w2cctl secrets new \| seal \| rotate \| status` | кольцо ключей | М10/7 Н1.2, Н2 |
| `w2cctl mirror \| space \| retention \| epoch \| tls status \| heartbeat \| domain move` | строки оператора и проверки | М10/11 Н1.9 |
| `w2c-spares.sh` | скрипт запасных: `w2c-spares.service` (`Type=oneshot`, `Restart=no`) и `.timer` (`OnBootSec` 1–2 мин, `OnUnitActiveSec` 1 мин) | М10/11 Н1.1, Н1.5 |
| кластер из одного со встроенной спекой | процесс коробки сам пишет строку спеки и метку — правом `admin`, как установщик | М10/2 Н1.5, М11/12 Н1.1 |

## Окружение

| Переменная | Смысл | Умолчание | Норма |
|---|---|---|---|
| `SPEC_DIR` | каталог спек установщика | `/opt/w2c/specs` | М10/11 Н1.2 |
| `W2C_BOX` | корень установки | `/opt/w2c` | М10/11 Н1.2 |
| `W2C_ENV` | файл общих настроек; `roles/` — рядом | `/etc/w2c/w2c.env` | М10/11 Н1.2 |
| `PLATFORM_DIR` | корень состояния, раскладка каталогов | `/data/platform` | М10/11 Н1.2 «Канал настройки и раскладка» |
| `SECRETS_KEY` | путь кольца: вне каталога хранилища, корня объектов и корня событий | `/etc/w2c/secrets/platform.key` | М10/7 Н1.2, М10/11 Н1.2 |
| `W2C_TLS_DIR` | корень комплектов | `/etc/w2c/tls` | М10/11 Н1.2, Н1.6 |
| `HOST_MEMORY_MB`, `WORKER_MEMORY_MB`, `CAPACITY` | потолок запасных из `roles/<роль>.env` | — | М10/11 Н1.5 rules 4 |
| `LABELS` | метки узла для скрипта запасных, когда консоль их не назвала | — | М10/11 Н1.5 rules 3 |

## Флаги

Нет: команды оператора берут свои аргументы (выше), процессы платформы — только окружение (М10/11 Н1.2 «Канал
настройки»).

## Каталоги и файлы

| Путь | Что | Норма |
|---|---|---|
| `/etc/w2c` → `/data/platform/etc` | ссылка; настоящий каталог — отказ установки | М10/11 Н1.1 `dirs`, Н1.7 `refuse` |
| `/etc/w2c/w2c.env`, `/etc/w2c/roles/<роль>.env`, `<W2C_SUB_ENV>`, `/etc/w2c/configstore.env` | файлы окружения: создаются, никогда не переписываются; грамматика — разбор, не `source` | М10/11 Н1.2, Н1.7 |
| `/etc/w2c/configstore-rights.json` | файл прав, по смыслу равный выводу; иначе установка отказана | М10/6 Н3 «установить» |
| строки `platform/spec/<sub>`, `platform/spec/<sub>/rev` | строка спеки и метка | [каталог](../common/data/catalog.tsv), М10/2 Н1.5 |
| `/etc/w2c/tls/ca.pem`, `ca.next.pem`, `revoked`, `crl.pem`, `<роль>/server.pem`, `<роль>/server.key` | центр и комплекты ролей | [каталог](../common/data/catalog.tsv), М10/11 Н1.6 |
| `/etc/w2c/secrets/platform.key` | кольцо: `secrets new` создаёт, `rotate` дописывает сверху | [каталог](../common/data/catalog.tsv), М10/7 Н1.2 |
| `/run/w2c-spares/<юнит>.env` | файл запасного: одна строка `SPARE_FOR=…`, 0644, tmp + rename до `systemctl start`; каталог 0755 | [каталог](../common/data/catalog.tsv), М10/11 Н1.5 `spare_file` |
| юниты Н1.1 и юниты сокетов `configstore-*.socket` | пишет `install.sh` | М10/11 Н1.1 |

## Коды выхода

| Код | Когда | Норма |
|---|---|---|
| 0 | установка или обновление прошли; `spec put` положила или «без изменений» | М10/11 Н1.7, М10/2 Н3 |
| 2 | `spec put`: файл отказан загрузчиком, полный каталог отказан, `toolarge`, оболочка с `on…=` | М10/2 Н4 |
| ≠ 0 | установщик: отказ до изменений или после начала записи — с фазой и путём, новые службы не включаются | М10/11 Н1.7 `failure`, Н4 |
| ≠ 0 | `rights --check`: файл по смыслу не равен выводу; вывод отказан на непредставимом объявлении | М10/6 Н4 |
| ≠ 0 | скрипт запасных ничего не запустил: нет файла роли, консоль молчит, polkit отказал (не отказ процесса — лог) | М10/11 Н4 |

## Сигналы и готовность

Команды — однократные. Скрипт запасных — `Type=oneshot`, повтор задаёт таймер; ничего не останавливает (М10/11 Н1.5
rules 5).

## Стенд

«Стенд» — [README приёмки М10/01](../../Source/tests/testdata/acceptance/М10_Platform/01/README.md):
- команда загрузки одного файла спеки — `{file}` (урок 2, корпус `verdicts.tsv`);
- `spec-put {socket} {file}` — через `admin.sock`, спеки стенда по одной до первого `@start`;
- команда вывода прав — `{specs}`, `{deployment}` (`dep`), `{file}`: `{rights}` уроков 4–11 и варианты урока 6.

## Поздние главы (домен)

|---|---|---|

## Открыто

- Установщика нет в перечне ролей М10/6 Н1.1: его записи идут правом `admin` (решение по каталогу данных, п. 8).
