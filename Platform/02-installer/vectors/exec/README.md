# Векторы: командная строка `exec`

Владелец — глава [P/02.1](../../spec/02.1-installer.norms.md) загрузчика (Н1.3 `worker.exec`, определение `execLine`; ADR-0091
доп. (4)–(6)). Участники — загрузчик (отказ манифеста с путём ключа) и раннер `w2c-run.sh` ([P/02.4](../../spec/02.4-installer.norms.md)
Н1.9: `worker`, `domainworker`, `part` исполняют argv сами, без оболочки). Байты пишет «Спецификация».

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>exec<TAB>expect<TAB>note`.
`exec` — значение ключа строкой JSON; `expect` — argv JSON-массивом (разбиение по пробелу U+0020, единственное) или
`@refuse` — строка не по грамматике: загрузчик отказывает `refused:value` с путём ключа, раннер её не исполняет.

## Прогон

Сторона разбирает `exec` своим кодом загрузчика или раннера и сравнивает argv с `expect` (JSON по значению) либо отказ с `@refuse`.
