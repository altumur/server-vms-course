# Векторы: закрытые списки платформы

Владелец — глава [P/02.5](../../spec/02.5-installer.norms.md) установщика (Н1.3 `roles`, `platform_readers`; Н1.4 —
отрицания секретных читателей; разбор ревью стадии A 6–7, № 5). Участники — загрузчик [P/02.1](../../spec/02.1-installer.norms.md)
(Н1.2а: `heartbeat.strings` не называет строковых полей пульса платформы; `display.tree.columns[].field` и
`display.form[].fields[]` — поле единицы или имя из `platform_shown`; `objects.rows[]` не называет семей платформы) и
генератор прав P/02.5 Н2. Байты пишет «Спецификация»; соответствие продукта — его приёмкой по этой таблице (ADR-0080
доп. 16, ADR-0083). Перенесено из `Source/tests/testdata/platform_lists.tsv` байт в байт (стадия B, перенос урока 6,
решение «Архитектора» по В8 плана урока 6 с поправкой № 5).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` — пояснения, пустые пропускаются. Заголовка нет. Два поля: `list` — имя списка,
`word` — его элемент. Каждый список — множество: порядок строк не сравнивается.

| Список | Что в нём | Норма |
|---|---|---|
| `heartbeat_strings` | строковые поля платформы в каждом пульсе: `heartbeat.strings` манифеста ни одного не называет | P/02.1 Н1.2а `heartbeat.strings`; P/03.4 Н1.1 |
| `secret_roles` | роли, которые может назвать `secrets.readers` | P/02.5 Н1.3 `roles` |
| `secret_readers` | секретные строки платформы и их читатели, `<строка или префикс>=<роль>`; `<строка>=` — никто, кроме читателя, которого называет манифест | P/02.5 Н1.3 `platform_readers` |
| `platform_shown` | поля единицы платформы, которые манифест может назвать там, где показывает единицу | P/02.1 Н1.2а (строка ссылок 71 `display.tree.columns[].field`) |
| `object_families` | семьи объектов платформы под `objects/<sub>/`: `objects.rows[]` манифеста ни одной не называет; `*` — префикс всей семьи | P/02.1 Н1.2а `objects.rows`; P/05 Н1.1 `key` |

## Прогон

Сторона сравнивает каждый свой закрытый список с множеством слов этого списка в таблице: равенство множеств. Список,
которого таблица не называет, или слово сверх таблицы — расхождение.
Кто исполняет — по `list`, установщик (`02-installer`): `heartbeat_strings`, `platform_shown`, `object_families` — загрузчик (P/02.1 Н1.2а, строки ссылок 73 и 84); `secret_roles`, `secret_readers` — генератор прав (P/02.5 Н1.3 `roles`, `platform_readers`, Н3 шаг 4). Только читают готовое: воркер (`03-worker`, P/03.4 Н1.1 `platform_strings` — поля, которые он пишет), ресурс (`05-resource`, свой `PLATFORM_DOOR`, P/05 Н2), консоль (`06-console`, P/06.5 Н1.2 `tree.columns`) и процесс `domain` (`08-domain`, P/08.2 Н1.3 `readers`) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Чего вектор не покрывает

Отказ загрузчика на манифесте, который называет слово из списка, — случаи корпуса [приёмки P/02.1](../../acceptance/1/);
вывод прав для секретных строк — варианты [приёмки P/02.5](../../acceptance/5/) и сц. 06 [приёмки главы 6.2](../../../06-console/acceptance/2/README.md).
