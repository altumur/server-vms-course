# Векторы: скрипт воркеров по заказу

Владелец — урок М10/11 (Н1.5 «Воркеры по заказу», `rules` 2–3; ADR-0084 доп. (1) Р1, Р4); на стадии B — глава 2.4
установщика. Участник — `w2c-workers.sh` сервера. Байты пишет «Спецификация» (ADR-0083, стадия A, A6).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок. Ячейка читается байт в
байт. Поля: `case`, `input` и `expect` — текст JSON, `note`.

**Вход** — одна роль сервера: `{want: <текст значения ряда <sub>_workers_wanted{server}> | null, running: [<n>…]}`;
`null` — ряда нет; `running` — номера работающих экземпляров `n ≥ 2` (базовый `-1` не входит).
**Выход** — `{start: [<n>…], stop: [<n>…]}` по возрастанию: цель — `want − 1` экземпляров `n ≥ 2`; меньше — запустить
наименьшие свободные номера, больше — остановить наибольшие; номер — целым; ряда нет или значение не десятичное целое
1…99 — ничего. Сравнение — JSON по значению.

Не покрыто: память (rules 4 — потолок по `roles/<роль>.env`), сериализация и резерв номеров (rules 5), молчание консоли
и возраст прохода (rules 2, вторая часть) — по времени и окружению; проверка — тест скрипта и чтение.
