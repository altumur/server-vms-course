# Векторы: скрипт воркеров по заказу

Владелец — глава [P/02.4](../../spec/02.4-installer.norms.md) установщика (Н1.5 «Воркеры по заказу», `rules` 2–4;
ADR-0084 доп. (1) Р1, Р4; перенесено из М10/11, стадия B). Участник — `w2c-workers.sh` сервера. Байты пишет «Спецификация» (ADR-0083, стадия A, A6; ревью стадии A 2).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок. Ячейка читается байт в
байт. Поля: `case`, `input` и `expect` — текст JSON, `note`.

**Вход** — одна роль сервера: `{want, running, console?, reconcile_age?, memory?}`:
- `want` — текст значения ряда `<sub>_workers_wanted{server}` или `null` (ряда нет);
- `running` — номера работающих экземпляров `n ≥ 2` (базовый `-1` не входит);
- `console` — `"ok"` (последний успешный сбор `/metrics` не старше минуты) или `"silent"` (сбор не удался или старше
  минуты по монотонным часам скрипта); нет поля — `"ok"`;
- `reconcile_age` — текст значения ряда `<sub>_reconcile_last_success_age_seconds` по форме значения P/06.5 Н3 «/metrics — текст»
  (каноническая запись JCS: дробь допустима — `60.5`, `0.5`; `-1`; иная запись — `1e1`, `60.50`, `+5` — не по форме, ничего не делать);
  сравнение с 60 — по значению (C02-RECONCILE-AGE-FORM-01); нет поля — ряд в порядке;
- `memory` — значения `roles/<роль>.env` строками как записаны: `{HOST_MEMORY_MB, WORKER_MEMORY_MB, CAPACITY}`; `null` —
  файла нет; нет поля — потолок памяти не ограничивает.

**Выход** — `{start: [<n>…], stop: [<n>…]}` по возрастанию: цель — ровно номера `{2…want}`: недостающие запустить
(наименьшие первыми), работающие с номером больше `want` остановить (наибольшие первыми); номер — целым (ADR-0084 доп. (4) Р26:
номера, не счёт). Потолок памяти
`floor(HOST_MEMORY_MB / WORKER_MEMORY_MB)` — число процессов роли на сервере вместе с базовым `-1`: запускается не больше
`потолок − 1 − работающие n ≥ 2`. Ничего не запускать и не останавливать (`{start: [], stop: []}`), если: ряда нет,
значение не по форме метрики P/06.5 Н3 «/metrics — текст» (в пояснениях `cases.tsv` — прежний адрес М10/9; целое без ведущих нулей, знака и дроби — `02`, `2.0` не читаются) или вне 1…99
(rules 2); консоль молчит или `reconcile_age` больше 60 или `-1` (rules 2); файла роли нет, бюджет — не положительное
целое, `CAPACITY` — не целое > 0 или делитель — ноль (rules 4). Сравнение — JSON по значению.

Не покрыто векторами: сериализация проходов и резерв номеров (rules 5) — приёмкой стенда (`@grow`, [общий README приёмки](../../../common/acceptance/README.md); разбор ревью стадии B 3–5, № 33)
и чтением; один механизм исполнения (rules 6) — чтением.

## Кто исполняет

Кто исполняет — установщик (`02-installer`: скрипт сервера `w2c-workers.sh`, P/02.4 Н1.5 `rules` 2–4). Только читают готовое: контроллер (`04-controller`, пишет `want` строки заказа, P/04 Н1.1) и консоль (`06-console`, ряд `workers_wanted{server}`, P/06.5 Н3 «/metrics — текст»); воркер (`03-worker`) остановку только принимает (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).
