## Решает реализация

3. **внутренний API записи admin в `platform/mirror`, `platform/space`, `<s>/retention` и `<s>/alarms_retention`** (публичные argv `w2cctl mirror|space|retention` заданы `operator-commands.tsv`, глава 2.4 N1.9; ресурс и консоль их только читают — N1.4) и **как консоль удаляет `platform/doors/<s>` при выводе сервера** (`delete:` в N1.4);
