### Блок случаев 2

Данные `testsub2`: `worker.reads` и `secrets.reads` — семья `testsub/counters/` (по N3 шаг 3 префикс — ключ с `/` на конце): воркер `testsub2` читает счётчики `testsub` и их секретные строки; `testsub` не объявляет `testsub/counters/` секретной, поэтому её консоль, контроллер и воркер читают строки единиц как прежде — `secrets.reads` только добавляет `testsub2worker` (N1.4).

### Блок случаев 3

**Варианты манифестов** — `variants/` приёмки (README приёмки, «Варианты манифестов»): каталоги манифестов, в каждом `expect.tsv` —
эффективные права «роль, действие, ключ → allow | deny» после вывода прав инструментом реализации (N2) и оценки по P/01.2 N1.3 с
`never`: база без `requests` с `delete_after`, просьбы и `worker.requests`, `objects.rows` с
`marks/`, `domain.kept` имени и семьи, `secrets.readers` со словом `domainworker`. Варианты `v8`–`v11`:
`worker.writes` и `worker.deletes`, условные `asked` и `requests/free-*`, чтения ресурса (таблица `holds.table`, не `<s>/holds/*`; строки манифестов с `about`),
расширения `worker.reads` и условные чтения `domain/*` воркера, таблицы и строки допуска связной подсистемы у контроллера. Сравнение — по смыслу: порядок образцов, `comment` и группы файла не сверяются.
Вместо `expect.tsv` — `refused` (отказ генерации до файла, N4: `v13-refused-idem-read`, `v14-refused-secrets-reads-nested`, `v18-refused-secret-readers-nested`)
или `check.tsv` (`--check` на файлах прав, N3 «установить»: `v12-check-rights` — равный выводу файл `same`, код 0, и изменённые, код не 0;
команда `stand.rights-check` «Стенда», [общий README приёмки](../../../common/ru/acceptance/README.md)).
