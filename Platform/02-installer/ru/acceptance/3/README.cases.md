### Исходный отрывок 2

Больше ничего не сравнивается: ни метка `/rev`, ни текст отказа сверх имени файла. Случаи `self_*`, `other_*`,
`prefix_clash` — проверки каталога (глава 2.1 N3 `load_catalogue`: «A=B», совпадение `metrics.prefix`): одиночная загрузка этих
файлов даёт `ok`, отказ — только у установки в каталоге. `same_twice` — тот же файл дважды: «unchanged», rev 1;
`changed` — изменённый тем же именем: rev 2. Случаи `creates_*`, `uses_*`, `os_name_clash` (ADR-0091) — проверки каталога
главы 2.1 N3 для `worker.creates`, `worker.uses` и имён ОС: каждый отказной случай отличается от `creates_ok` или `uses_ok`
одной причиной; `creates_nested_prefix` ставит двух заказчиков, отказ — у второго (`cust-x`). Адресата или владельца доли в каталоге ещё нет — проверка ждёт его установки (`creates_no_target`, `uses_no_owner` — 0);
`target_after_customer_mismatch` — отказ у установки адресата после несовместимого заказчика. Случаи `kind_dup`,
`door_domain_*` (ADR-0091 доп. (14), (17), (18) п. 6) — виды токена домена: тот же вид у второй подсистемы — отказ; вид
маршрута `door.routes[].domain` объявлен другой подсистемой каталога или своей — принят; вида нет — отказ (отсрочки нет).
Случаи `files_*`, `shell_declared_*` (ADR-0094 B7): `filed` называет принятые имена — все расширения, вложенные сегменты, `api.js` и
`apis/…` рядом с запретом `api/`, пустой файл, файл в две части; `filed-missing` называет файл, которого нет, — код 2, stderr называет файл манифеста и путь;
`filed-none` — тот же `name` без перечня; `pagedecl` — `console.shell: true`, оболочки нет — код 2; `pagedecl-bare` — тот же `name` без
слова, после `@shell-put` оболочка есть — новая ревизия с объявлением. `filed-big` называет `big.js`, `filed-sum` — `sum1.js`…`sum5.js`:
файл на байт выше `FILE_MAX` и сумма на байт выше `FILES_TOTAL_MAX` (четыре файла по 8 МиБ и байт) — код 2 до записи, ревизия прежняя 1;
ровно `FILE_MAX` — принят, rev 2.
Случаи `near_*` (ADR-0091 доп. (26) п. 2) — отсрочка `near`: подсистемы `near.sub` нет — клиент принят, проверка полей
ждёт; адресат после несовместимого клиента — отказ у установки адресата.
