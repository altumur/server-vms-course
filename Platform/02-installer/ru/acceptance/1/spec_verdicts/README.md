# Свидетели вердиктов загрузчика, принадлежащие курсу

Текст производный от `acceptance/1/spec_verdicts/README.md`, руками не правится: источник — английский [`acceptance/1/spec_verdicts/README.md`](../../../../acceptance/1/spec_verdicts/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121; ADR-0124).

Пакет содержит [`spec_verdicts.tsv`](../../../../acceptance/1/spec_verdicts/spec_verdicts.tsv) и входы `<case>.subsystem.yaml` в том же каталоге: 138 случаев, 19 `ok` и 119 `refused`. Первоначальные файлы побайтно равны свидетелям Source принятого общего среза. Пакет не заменяет корпус урока из 947 случаев и 220 векторов канонического вида.

TSV — UTF-8 с разделителями LF и TAB. Шапки нет: пустые строки и строки с `#` пропускаются; каждая оставшаяся строка — ровно `case<TAB>verdict`. Каждому случаю соответствует ровно один файл рядом с таблицей, каждому входному файлу — ровно одна строка. Сохраняются первая строка данных и опубликованный порядок.

Входы YAML читаются сырыми байтами. BOM, неверный UTF-8, NUL, дубли ключей и свидетели глубины — намеренные отрицательные входы; копия не декодирует, не нормализует и не чинит их. Смыслы вердиктов прежние, нового класса отказа загрузчика и native-команды нет.

Курс владеет пакетом независимо от продукта (ADR-0083 доп. (115)). Импортированные комментарии шапки — история происхождения, а не договор синхронизации. Прежние копии `Source/tests/testdata` остаются неизменяемыми свидетелями.
