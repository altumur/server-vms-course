# P/02.4 — дополнительные швы команд и опроса для пакета

Текст производный от `acceptance/4/README.md`, руками не правится: источник — английский [`acceptance/4/README.md`](../../../acceptance/4/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Каталог передаёт [`seams.tsv`](../../../acceptance/4/seams.tsv) тестам пакета (ADR-0125 доп. (4) п. 7, доп. (5)). HTTP-стенда и публичной цели раннера для P/02.4 не добавляет. 19 шагов в 11 сценариях используют грамматику и CALL из [`forms/README.md`](../../forms/README.md).

| Сценарии | Предмет | Норма |
|---|---|---|
| `s1-put-invalid-source` | manifest put отказывает неверному кандидату кодом 2 с именем источника; исходный файл цел | P/02.3 Н3 шаг 1, Н4 |
| `s2-new-existing`, `s3-rotate-invalid` | отказ создания или проверки кольца оставляет прежний файл байт-в-байт | P/02.4 Н1.9 secrets; P/02.4-14 |
| `s4-new-exclusive` | параллельное создание O_EXCL по одному пути успешно ровно раз | P/02.4 Н1.9 secrets new |
| `s5-poll-healthy`–`s11-poll-read-equality` | чистый опрос: догон под записями, разрыв, last у ведомого, состав, двое голосующих, равенство на tick/сроке чтения | P/02.4 Н1.9 poll; P/02.4-22 |

У каждого сценария новые временные корни; входы файлов кольца — собственные строки, реальных ключей нет. RUN вызывает функцию команды; CALL `command` наблюдает 0 против ненулевого кода без выдуманного точного кода/формы вывода. Авария — не отказ. Исходные [машина](../../../forms/rollout-poll.machine.yaml) и [трассы](../../../forms/rollout-poll.traces.tsv) — канон: во входах швов только вход и внешние события со временем, без ожидаемых утверждений. Адаптер наблюдает опрос реализации, один интерпретатор курса реализацию не подтверждает.

Исходные трассы судят всю машину; семь выбранных сценариев — меньшая регрессия реализации. Они не доказывают настоящую раскатку, get/install, барьеры store/консоли, ОС/службы, TLS, отзыв, операторские окна и клиентов. Их проверки остаются в нормах/чеклисте. 946 файлов загрузчика, прежние puts и права — отдельные проверки. При подготовке швов реализация не запускалась.
