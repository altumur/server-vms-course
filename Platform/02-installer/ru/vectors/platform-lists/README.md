## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` — пояснения, пустые пропускаются. Заголовка нет. Два поля: `list` — имя списка,
`word` — его элемент. Каждый список — множество: порядок строк не сравнивается.

| Список | Что в нём | Норма |
|---|---|---|
| `heartbeat_strings` | строковые поля платформы в каждом пульсе: `heartbeat.strings` манифеста ни одного не называет | P/02.1 N1.2a `heartbeat.strings`; P/03.4 N1.1 |
| `secret_roles` | роли, которые может назвать `secrets.readers` | P/02.5 N1.3 `roles` |
| `secret_readers` | секретные строки платформы и их читатели, `<строка или префикс>=<роль>`; `<строка>=` — никто, кроме читателя, которого называет манифест | P/02.5 N1.3 `platform_readers` |
| `platform_shown` | поля единицы платформы, которые манифест может назвать там, где показывает единицу | P/02.1 N1.2a (строка ссылок 71 `display.tree.columns[].field`) |
| `object_families` | семьи объектов платформы под `objects/<sub>/`: `objects.rows[]` манифеста ни одной не называет; `*` — префикс всей семьи | P/02.1 N1.2a `objects.rows`; P/05 N1.1 `key` |

## Прогон

Сторона сравнивает каждый свой закрытый список с множеством слов этого списка в таблице: равенство множеств. Список,
которого таблица не называет, или слово сверх таблицы — расхождение.
Кто исполняет — по `list`, установщик (`02-installer`): `heartbeat_strings`, `platform_shown`, `object_families` — загрузчик (P/02.1 N1.2a, строки ссылок 73 и 84); `secret_roles`, `secret_readers` — генератор прав (P/02.5 N1.3 `roles`, `platform_readers`, N3 шаг 4). Только читают готовое: воркер (`03-worker`, P/03.4 N1.1 `platform_strings` — поля, которые он пишет), ресурс (`05-resource`, свой `PLATFORM_DOOR`, P/05 N2), консоль (`06-console`, P/06.5 N1.2 `tree.columns`) и процесс `domain` (`08-domain`, P/08.2 N1.3 `readers`) (строку исполняет роль, чья норма вызывает её функцию).


## Чего вектор не покрывает

Отказ загрузчика на манифесте, который называет слово из списка, — случаи корпуса [приёмки P/02.1](../../../acceptance/1/) (только для судьи: случаи корпуса; они проверяют P/02.1-R058);
вывод прав для секретных строк — варианты [приёмки P/02.5](../../../acceptance/5/) и сц. 06 [приёмки главы 6.2](../../../../06-console/ru/acceptance/2/README.md) (только для судьи: варианты и сценарий; они проверяют P/02.5-R087, P/02.5-R091, P/02.5-R092, P/02.5-R093, P/02.5-R094, P/02.5-R095).

## Провод векторов

Провод таблиц `cases.tsv` (только для судьи: сама таблица; она проверяет P/02.5-R005, P/02.5-R008, P/02.5-R011 и P/02.5-R038) задают строки `02-installer/platform-lists` в [единой форме](../../../../common/vectors/wire.tsv); [грамматика](../../../../common/ru/vectors/wire.md). Форма — источник шапки, выбранных входов, фикстур, нативного исхода и сравнения. Смысл алгоритма и обязанность потребителя остаются здесь.
