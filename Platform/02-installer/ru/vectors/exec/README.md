## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок `case<TAB>exec<TAB>expect<TAB>note`.
`exec` — значение ключа строкой JSON; `expect` — argv JSON-массивом (разбиение по пробелу U+0020, единственное) или
`@refuse` — строка не по грамматике: загрузчик отказывает `refused:form` с путём ключа, раннер её не исполняет.

Нативная форма команды и отображение отказа правила заданы формой провода ниже. Вход не по форме — код 2 без stdout; отказ правила на входе по форме — вычисленный исход, а не ошибка транспорта. Это не меняет отказ установки или загрузчика, названный выше.

## Прогон

Сторона разбирает `exec` своим кодом загрузчика или раннера и сравнивает argv с `expect` (JSON по значению) либо отказ с `@refuse`.
