# Манифест и установщик — жизненный цикл (урок P/02)

Контракт жизненного цикла установщика `w2cctl` и его команд: установка и обновление, установка манифеста,
вывод прав, центр сертификатов, скрипт воркеров по заказу. Нормы здесь не
пересказываются: каждая строка ведёт к своей норме.

Текст производный от `lifecycle.md`, руками не правится: источник — английский [`lifecycle.md`](../lifecycle.md), правка идёт в него, русский пересобирается переводом.

Нормы: [P/02.4](spec/02.4-installer.norms.md) (N1.1 юниты, N1.2 окружение, N1.5 воркеры по заказу, N1.6 сертификаты,
N1.7 установка, N1.9 команды и `w2cctl secrets`, N1.10 кластер из одного, N4), [P/02.3](spec/02.3-installer.norms.md)
(N1.5 строка манифеста, N3 «Смена манифеста», N4), [P/02.5](spec/02.5-installer.norms.md) (N2 инструмент прав,
N3 «сгенерировать», «установить»); поздние главы — [P/02.4](spec/02.4-installer.norms.md) N1.12 порты и юниты домена,
N3 «установка домена».

## Запуск

Установщик — не служба, а команды оператора; повтор установки — обновление.

| Команда | Что | Норма |
|---|---|---|
| `install.sh` | установка и обновление: код, пользователи и группы, каталоги, манифесты, окружение и файлы ролей (никогда поверх), ключ секретов, юниты, центр, файл прав, `manifest put`, `enable` | P/02.4 N1.7 `install` |
| обновление сервера за сервером | `POST /drain` → `safe: true` → остановить, обновить, запустить → `DELETE /drain`; последним — подъём схемы. Существующий `w2c.env` обновление не переписывает: строки `TIMEZONE` нет — действует `UTC`, иной пояс кластера оператор вписывает в файл руками на каждом сервере | P/02.4 N1.7 `upgrade`, `w2c_env`, P/06.6 N2.3, N3 «поднять_схему» |
| `w2cctl manifest put <файл>` | установка одного манифеста: загрузка, полный каталог, строка, затем метка `/rev` | P/02.3 N3 «Смена манифеста» |
| `w2cctl manifest status [-rights]` | состояние строк манифестов; с `-rights` — и файла прав | P/02.4 N1.9, P/02.5 |
| `w2c-run.sh <роль>` | раннер процессов: `configstore`, `controller <sub>`, `console`, `resource`, `domain`, `domainconsole`, `domainagent`, `worker <sub> <слот>`, `domainworker <sub>` (исполняют `worker.exec` строки манифеста, `W2C_MANIFEST_REV`), `workers`, `rights`, `part <sub> <часть>` (часть подсистемы: значения юнита и файл подсистемы, без `W2C_ROLE`); окружение — значения юнита → `roles/<W2C_ROLE>.env` → `w2c.env` → файл подсистемы (раньше прочитанное побеждает), файлы — разбором, не `source`; `W2C_ROLE` не той роли — код 2 | P/02.4 N1.2, N1.9 |
| `w2cctl rights -deployment <имя> [--check <файл>]` | вывод прав из `MANIFEST_DIR`; `--check` — по смыслу | P/02.5 N2, N3 |
| `w2c-ca.sh init \| issue \| revoke \| crl \| own` | центр и комплекты ролей | P/02.4 N1.6 |
| `w2cctl secrets new \| seal \| rotate \| status` | кольцо ключей | [договор запечатывания](../../common/ru/contracts/sealing.md), P/02.4 N1.9 |
| `w2cctl mirror \| space \| retention \| tls status \| domain move` | строки оператора и проверки | P/02.4 N1.9 |
| `w2c-workers.sh` | скрипт воркеров по заказу: `w2c-workers.service` (`Type=oneshot`, `Restart=no`, `User=w2c-workers` без групп, один на сервер) и `.timer` (`OnBootSec` 1–2 мин, `OnUnitActiveSec` 1 мин); ряды `<sub>_workers_wanted{server}` → `start`/`stop` экземпляров `<prefix>-<SERVER_NAME>-<n>`, n 2…99 | P/02.4 N1.1, N1.5 |
| кластер из одного со встроенным манифестом | процесс коробки сам пишет строку манифеста и метку — правом `admin`, как установщик | P/02.3 N1.5, P/02.4 N1.10 |

## Флаги

Флагов демона нет: P/02 — операторские команды. Опции заданы [`forms/daemon-flags.tsv`](../forms/daemon-flags.tsv), грамматика команд — [`forms/operator-commands.tsv`](../forms/operator-commands.tsv); процессы платформы настраиваются окружением (P/02.4 N1.2).

## Коды выхода

| Код | Когда | Норма |
|---|---|---|
| 0 | установка или обновление прошли; `manifest put` положила или «unchanged» | P/02.4 N1.7, P/02.3 N3 |
| 2 | `manifest put`: файл отказан загрузчиком, полный каталог отказан, `toolarge`, оболочка с `on…=`, объявленной оболочки или файла `console.files` нет | P/02.1 N4, P/02.3 N4 |
| ≠ 0 | установщик: отказ до изменений или после начала записи — с фазой и путём, новые службы не включаются | P/02.4 N1.7 `failure`, N4 |
| ≠ 0 | `rights --check`: файл по смыслу не равен выводу; вывод отказан на непредставимом объявлении | P/02.5 N4 |

Скрипт воркеров, который у роли ничего не запустил и не остановил (нет файла роли — роль пропущена, обход идёт
дальше; ряда нет или он не читается; консоль молчит; polkit отказал), пишет строку лога; код выхода для этого норма
не задаёт (P/02.4 N1.5 rules, N4).

## Сигналы и готовность

Команды — однократные. Скрипт воркеров — `Type=oneshot`, повтор задаёт таймер; останавливает только экземпляры с n ≥ 2 сверх ряда, с
наибольшего номера (P/02.4 N1.5 rules 3).

## Стенд

«Стенд» — [общий README приёмки](../../common/ru/acceptance/README.md):
- команда загрузки одного файла манифеста — `{file}` (P/02.1, корпус `verdicts.tsv`; только для судьи: таблица корпуса);
- `manifest-put {socket} {file}` — через `admin.sock`, манифесты стенда по одному до первого `@start`;
- команда вывода прав — `{manifests}`, `{deployment}` (`dep`), `{file}`: `{rights}` приёмок других уроков и варианты главы 2.5.
