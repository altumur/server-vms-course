### Case block 3

**Manifest variants** — `variants/` of the acceptance (the acceptance README, «Manifest variants»): catalogues of manifests, each with `expect.tsv` —
the effective rights «role, action, key → allow | deny» after the derivation of rights by the implementation's tool (N2) and the evaluation by P/01.2 N1.3 with
`never`: a base without `requests` with `delete_after`, requests and `worker.requests`, `objects.rows` with
`marks/`, `domain.kept` of a name and a family, `secrets.readers` with the word `domainworker`. The variants `v8`–`v11`:
`worker.writes` and `worker.deletes`, the conditional `asked` and `requests/free-*`, the reads of the resource (the table `holds.table`, not `<s>/holds/*`; the rows of manifests with `about`),
the extensions of `worker.reads` and the conditional reads `domain/*` of the worker, the tables and the admission rows of the related subsystem at the controller. The comparison is by meaning: the order of patterns, `comment` and the groups of the file are not compared.
Instead of `expect.tsv` — `refused` (a generation refusal before the file, N4: `v13-refused-idem-read`, `v14-refused-secrets-reads-nested`, `v18-refused-secret-readers-nested`)
or `check.tsv` (`--check` on rights files, N3 «install»: `v12-check-rights` — a file equal to the output `same`, code 0, and changed ones, code not 0;
the command `stand.rights-check` of «Stand», [common acceptance README](../../common/acceptance/README.md)).
