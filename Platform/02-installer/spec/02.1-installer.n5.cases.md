# Judge-only N5 case coverage

This English text is the source; the Russian translation `ru/spec/02.1-installer.n5.cases.md` is derived from it (ADR-0121).

These case descriptions and their outcomes are judge-only data. The canonical normative chapter is [`02.1-installer.norms.md`](02.1-installer.norms.md). Generic rules and explicitly retained normative examples remain there.

Set B of ADR-0092 — 43 cases `t*`, `f*`, `r*` at the end of `verdicts.tsv` under the comment «Set B ADR-0092»: the rules
of the thin check of layer 1 (flow and quotes over several lines, `|2`, `? …`, `...`, `%`, a literal TAB, an anchor, an
alias, a tag, `---` with content, the header and the leading empty lines of a block scalar; the trailing comma in a flow —
`t33`, `t33b` (ok), an empty element and a double comma — `t34`, `t34b` (`text`); `t27_escape_tab_ok`,
`t31_last_line_spaces_ok`, `t32_trailing_spaces_ok` — accepted neighbours, the bypass D16 —
[`LAYERS.md`](../../common/LAYERS.md)), scalars by the style of the node (`t23_quoted_true_string`, `r06_text_bool_ok`,
`r06b_text_bool_True`), the integer place (`f01`–`f07`: `4.0` and `1e1` are integers, the bounds ±(2^53 − 1)), the full
match of an expression (`f08`–`f10`: a trailing `\n`), other forms and relations (`f13`–`f15`, `r01`, `r02`, `r07`). The
deltas of former cases — the delta table of set B (the skill `lesson-spec`); the row of the package — `corrections-1.tsv` (historical correction record) of the chapter.
