## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок. Ячейка читается байт в
байт. Поля: `case`, `input` и `expect` — текст JSON, `note`.

**Вход** — `{prefix, want: {<сервер>: <want>}, workers: [{name, server}]}`: живые воркеры роли, имена
`<prefix>-<сервер>-<n>` (P/03.2 N1.4); `want` — цель строки заказа каждого сервера, на котором есть воркер (целое 1…99,
P/04 N1.4).
**Выход** — `{victim: <имя> | null}`: наибольший номер `n ∈ {2…want}` своего сервера, номер — целым, не по слотовому
порядку; базовый `-1` жертвой не бывает; живой номер выше want своего сервера — не жертва: его останавливает скрипт
(R28), конец сокращения его не гасит (ADR-0084 доп. (6); разбор ревью стадии B 6–7, № 42); `null` — жертвы нет.
Сравнение — JSON по значению.

Равенство номеров на разных серверах — меньшее имя сервера в байтах UTF-8 первым, как порядок кандидатов (N3
«сократить», жертва). Не покрыто: проверка «каждая единица жертвы проходит выбрать()» — шагом приёмки и чтением.

## Вход не по форме (R22)

Исполнитель вектора отвечает кодом 2 (ячейка `expect` — `@exit 2`) ровно на вход из перечня: не JSON-объект; `prefix` или
имя сервера не по грамматике (P/03.2 N1.4, P/02.4 N1.2); имя воркера не `<prefix>-<server>-<n>` своего элемента, `n` — не
целое 1…99 или с ведущим нулём; повтор имени; `want` не объект, не называет сервер воркера или его значение не целое
1…99. Целое — по точному десятичному значению записи, как `x-integer` (LAYERS §3): `1.0`, `1e0` — 1; `1.5`, булево, строка, число вне binary64 — не целое; номер `n` в имени воркера — лексема строки, без ведущего нуля (C04-VECTOR-INT-VALUE-01). Остальное — вне вектора (ADR-0084 доп. (2) R22).

## Кто исполняет

Кто исполняет — контроллер (`04-controller`: жертва сокращения, P/04 N3 «сократить», `victim`) — все строки. Скрипт сервера (`02-installer`) жертву не выбирает: останавливает номера выше готового `want` своим правилом (P/02.4 N1.5 `rules` 3, векторы `workers-script`); воркер (`03-worker`) видит готовый `retiring` (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

Ревью ADR-0127 P/04 С1: вход workers[].wanted — необязательный bool, отсутствие равно false. Кандидат сервера — только живой верхний n=want(server)>1. Защищён верхний — пропустить весь сервер; к меньшему номеру не переходить. Связка s36/s37 запускает настоящий выбор жертвы, retiring/перенос/end и прежний скрипт сервера P/02, наблюдая want и фактически выбранную остановку. При wanted(3), empty(2), want=3 цель остаётся3, остановокнет; инойсерверможетдатьсвоеговерхнегокандидата.
