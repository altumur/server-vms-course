# Инструкции ожиданий конкретных случаев только для судьи

Этот русский текст — производный от `acceptance/sleeps.cases.md`, руками не правится (ADR-0121).

Файл сохраняет инструкции конкретных случаев из README приёмки главы. Это данные только для судьи, не вход модели. Общий смысл ожиданий остаётся в общем протоколе стенда.

## Сны (`@sleep`, ADR-0080 доп. (17) п. 4)

Ожидание события — `@until`. Оставшиеся сны — проверка отсутствия или время перед действием; длина — наименьшая по срокам

| Сц./шаг | Сон | Причина |

| 13/12 | 10 с | отсутствие: `c13` не уходит с `w-1` раньше SLOT_TERM — два прохода контроллера по 5 с |
| 17/21 | 25 с | отсутствие: `want` не растёт выше 2 и пробный процесс без места не сокращается — срок `shrink_after=20` и шаг прохода контроллера 5 с (разбор ревью стадии B 3–5, № 12) |
| 18/17 | 12 с | отсутствие: строка `testsub-c3` с `made.keep` в будущем не удалена — два прохода контроллера по 5 с (удаление по `ends` — тем же проходом, что снятие, N3 шаг 8) |
