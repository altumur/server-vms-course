# Формы P/04 и швы контроллера

Текст производный от `forms/README.md`, руками не правится: источник — английский [`forms/README.md`](../../forms/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).
Формы выражают существующие нормы контроллера (ADR-0125 доп. (5)); HTTP-двери контроллера не появляется.

## Входы и отказы

[daemon-flags.tsv](../../forms/daemon-flags.tsv) имеет восемь колонок P/01 с написанием окружения/аргумента P/03: `$NAME` — окружение,
`<sub>` — аргумент подсистемы маршрута запускателя контроллера. Это настройки процесса, не новые CLI-флаги. `default` — литерал либо
`-`; `default_text` может сохранять вычисляемое умолчание, которое адаптер разрешает по `norm`, а не копирует как правило имени хоста или шаблон пути.
`number` конечен; форма не добавляет отсутствующих лексических отказов или границ. `required`/`bad` — CEL над картой точных имён `f` и `cmd`.
Парные имена проверяются до умолчаний. Пустая `bad` не отменяет проверки общих договоров. Файлы окружения разбирает запускатель, процесс получает значения.

[refusals.tsv](../../forms/refusals.tsv) имеет `chapter row name surface code kind fields headers log norm word cause outcome diagnostic caller`.
Разделитель — буквальный TAB без CSV-кавычек. Глава — `4`; четыре последние ячейки сохраняют все прежние ячейки Н4 в исходном порядке.
`start` — старт процесса, `call` — процедура контроллера, `peer` — договор двери консоли. Фиксированный код дополняет нормативный исход;
`-` не добавляет машинной проекции. `kind` — `-`: error консоли не становится HTTP Fault контроллера. Н4 ссылается на форму без второй таблицы.

## Машины

[slot-fate.tsv](../../forms/slot-fate.tsv) и [slot-release.tsv](../../forms/slot-release.tsv) имеют `n state condition action next norm`, грамматика захвата P/03:
закрытые состояния/действия, типизированные `#var`, `#const`, `#action`, условия/аргументы CEL; первая подходящая строка текущего состояния.
Части пакета названы по файлам: `slot-fate` и `slot-release`, вызываются из `core`. Нет совпадения — ожидание без эффекта. Действие `-` — YOURS по `norm`, не noop.
Судьба возвращает суждение и версию разрешения; разрешение release требует версии подтверждённого ответа CAS. Машина release получает
уже выбранную судьбу после всех более приоритетных правил; её таблица не должна самостоятельно судить свежий живой слот как gone.

Возраст входа — местное наблюдение той же версии, не `until`, ts пульса или `fates.since`. Исходы чтения и присутствие процесса берутся
из общих договоров; неизвестное чтение не является отсутствием. Повреждённое поколение не ноль. Действие CAS проверяет его, сохраняет
поля читаемой строки или пишет полную release-строку torn; слепого повтора с продлённой версией нет. blocked/error/unknown
не публикуют имени. Конкурирующее продление оставляет строку прежней; изменившуюся версию судит следующий проход. Очистка брошенного захвата,
пакеты decommission и процедуры очереди/намерения размещения остаются по исходным якорям, это не эффекты чистого выбора судьбы.

## Швы

[acceptance/seams.tsv](../../acceptance/seams.tsv) — тесты пакета отдельно от сценариев раннера процесса. Грамматика и сравнение JSON —
[README форм P/03](../../../03-worker/forms/README.md) и [README форм P/02](../../../02-installer/forms/README.md): CALL с одним значением
JSON, подмножество объекта, ровно пустые объекты/списки, новые корни сценария; без оболочки. Адрес единственной главы — `4`, без подкаталога приёмки.
Порты нормализуют тесты, не задают API реализации. Вызываются настоящие функции контроллера и записываются эффекты, готовый ответ из expect запрещён.

Адаптер дополняет допустимый синтетический фон перед вмешательством: схема/манифест, читаемая очередь/idle-намерение, единицы,
воркеры, живое владение и ёмкость. Используется манифест `testsub` с включённой возможностью размещения, если случай её называет. Всё состояние
получается запуском инициализации/предыдущего прохода той же реализации, не назначением приватных полей реализации.
Пропуск — не неответ; явный null — подтверждённое отсутствие. Непрозрачные версии — ответы управляемого клиента, числовые нормализованные
поля — декодированные значения; release_items — проводные строки хранилища. Нормальный отказ нельзя получать перехватом аварии или постороннего исключения.

| Порт CALL | Вмешательство и наблюдение |
|---|---|
| `controller-fate` | Типизированные наблюдения slot-fate. Для release — допустимый слот и ответ CAS; исполняется настоящий путь release, записываются items/версия. Конфликт не даёт разрешения; next_observation запускает свежий проход. Нет slot_writes — не было попытки; нет confirmed_slot_writes — не было подтверждённого изменения. Пять прежних свидетельств: gone/runs/unlisted без единиц, gone с единицами, конкурирующее продление. |
| `controller-admit` | Воркеры, единицы, явное чередование двух держателей очереди. Первое решение принимается до свежего взгляда второго держателя. Наблюдаются эффективная нагрузка, назначения и допуск, не два независимых выбора по одному старому снимку. |
| `controller-complete-intent` | Допустимое активное намерение и назначения; возможен обрыв после первого подтверждённого удаления и смена держателя. Возобновление со всех удалений, добавление только после их подтверждения. Неизвестная запись требует барьера своей очереди; чужой держатель останавливает все поздние записи и новые допуски. |
| `controller-key-admission` | Читается настоящий объявленный предел ключа реализации; строится допустимая именованная единица, ключ которой помещается, а ключ placement превышает предел ровно на placement_key_over_by байтов (здесь один), ASCII-заполнение id. Нельзя выдумывать меньший предел или делать оба ключа недопустимыми. Единица вместе с другим членом группы плюс независимая подходящая единица. Наблюдаются отказ намерения/размещений всей группы и продвижение независимой единицы. |
| `controller-choose` | Допустимая неразмещённая единица и кандидаты; применяются названное ограничение и предпочтение дома. Дом, не прошедший ограничение, не выигрывает ранг. |
| `controller-delete-after` | Наблюдения снятия/возврата на виртуальных монотонных часах; возврат сбрасывает счёт. Перед ответом удаления читаются свежие единица/решение. Отказ CAS не трогает состояние/журнал. Store early сохраняет not_before без барьера и журнала. Now — часы контроллера; store early — управляемый ответ допуска, не те же часы. |
| `controller-state-sweep` | Чтение сиротского состояния и единицы; null — единицы нет. Записываются guard строки единицы и CAS состояния. 412 оставляет строку без роста swept, повтор на следующем проходе. |
| `controller-snapshot` | Настоящая сериализация/публикация объекта. serialized_bytes — цель фикстуры: допустимое строковое поле с ASCII-заполнением доводит полный настоящий сериализованный шард, включая оболочку/ts, до нужного размера. Подмена счёта байтов и обход сериализации запрещены. Ошибка чтения ничего не публикует; ровно предел допускается, сверх него отказ до put; store TooLarge даёт тот же отказ. |
| `controller-table-snapshot` | Допустимая публикация таблицы, затем изменившиеся/прежние строки. Для размера — настоящая сериализация/заполнение как выше. Сверх предела таблицы — заглушка too_large, не прежний объект; прежние строки сохраняют ts без записи. |
| `controller-want` | Наблюдения want и живых номеров по монотонным моментам. Полностью поднятый заказ сбрасывает таймер полёта; позднее пропавший номер начинает новый таймер даже без смены версии want. Наблюдаются отзывы, текущая цель и in_flight_since. |
| `controller-pass` | Ошибка клиента названного независимого шага; следующие шаги продолжаются. Наблюдаются failures/ok и исполнение позднего шага. Сломанная очередь имеет своё правило и не подменяется этой независимой ошибкой. |

Свидетельства дополняют чтение и общие векторы; не закрывают гонку OS-процесса или сценарий, который не исполняют.
План — [stages.tsv](../../forms/stages.tsv); все сценарии раннера и назначенные общие таблицы остаются обязательными с выборками из README пакета.
