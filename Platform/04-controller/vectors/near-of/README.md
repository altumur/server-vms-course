# Векторы: сосед единицы по `near` (`by`, `of`, `prefer`)

Владелец — урок P/04 ([нормы](../../spec/04-controller.norms.md) Н1.3 `near`; ADR-0091 п. 10). Участник —
`<s>controller` (предпочтение при выборе воркера, Н3 «выбрать»). Байты пишет «Спецификация». Вектор проверяет только
выбор соседа; что предпочтителен воркер, держащий его, и что без держателя предпочтения нет, — Н3 «выбрать», чтением.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются; первая непропущенная — заголовок `case<TAB>input<TAB>expect<TAB>note`.

| Поле | Значение |
|---|---|
| `case` | имя строки |
| `input` | JSON-объект: `near` — ключ манифеста (`{sub, by?, of?, prefer?}`); `me` — моя строка (`id` и поля); `neighbours` — живые строки подсистемы `sub` (`id` и поля); `refs` — поле соседа → `<подсистема>/<семья>` его `ref` (для пути `prefer`); `rows` — строки целей ссылок: ключ `<подсистема>/<семья>/<id>` → поля |
| `expect` | id выбранного соседа; `""` — соседа нет |
| `note` | правило нормы |

Значения полей — текстом строки хранилища (P/06.1 Н1.2 `values_by_type`); значения `prefer` сравниваются той же
записью: `0` в `prefer` равно `"0"` строки. Отсутствующее поле ничему не равно. Значение поля `prefer` — скаляр (равенство) или список скаляров (ИЛИ по списку), как `affinity.strict` P/04 Н1.3 (C04-NEAR-PREFER-SCALAR-01).

## Прогон

Сторона строит из `input` выбор Н1.3 `near` своим кодом, без хранилища: моё значение — поле `by` (без `by` — мой `id`),
значение соседа — поле `of` (без `of` — его `id`); соседи — строки с равным значением; сначала совпавшие с `prefer`
(И по полям, ИЛИ по списку; сегмент пути через `.` — шаг по полю-ссылке соседа к строке `rows`); среди равных — по
`id` в байтах UTF-8. Результат сравнивается с `expect` байт в байт.
Кто исполняет — контроллер (`04-controller`: сосед по `near`, P/04 Н1.3, ранг предпочтения в Н3 «выбрать») — все строки. Установщик (`02-installer`) только проверяет поля `near` в каталоге (P/02.1 Н3) и соседа не выбирает; воркер (`03-worker`) даёт вход фазой `running` (P/03.4 Н1.1) (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).

## Команда стенда

`near-of` — ключ `stand` профиля `04-controller` (раздел «Раскладка по процессам» [общего README приёмки](../../../common/acceptance/README.md)):
шаблон с `{input}` — путь файла, в который раннер пишет ячейку `input` строки байт в байт; stdout — UTF-8 байты id
выбранного соседа ровно как `expect`, без перевода строки и без JSON-обёртки; соседа нет (`expect` пусто) — пустой stdout;
код 0. Вход не по форме этого README — код 2 (`@exit 2`). Иной код или лишние байты — FAIL строки.
