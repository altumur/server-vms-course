# Векторы: жертва сокращения

Владелец — урок P/04 ([нормы](../../spec/04-controller.norms.md) Н3 «сократить()», `жертва`; ADR-0084 доп. (1) Р4, доп. (6); P/03.2 Н1.4 грамматика имени). Участник —
`<s>controller`. Байты пишет «Спецификация» (ADR-0083, стадия A, A6).

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` и пустые пропускаются, первая непропущенная — заголовок. Ячейка читается байт в
байт. Поля: `case`, `input` и `expect` — текст JSON, `note`.

**Вход** — `{prefix, want: {<сервер>: <want>}, workers: [{name, server}]}`: живые воркеры роли, имена
`<prefix>-<сервер>-<n>` (P/03.2 Н1.4); `want` — цель строки заказа каждого сервера, на котором есть воркер (целое 1…99,
P/04 Н1.4).
**Выход** — `{victim: <имя> | null}`: наибольший номер `n ∈ {2…want}` своего сервера, номер — целым, не по слотовому
порядку; базовый `-1` жертвой не бывает; живой номер выше want своего сервера — не жертва: его останавливает скрипт
(Р28), конец сокращения его не гасит (ADR-0084 доп. (6); разбор ревью стадии B 6–7, № 42); `null` — жертвы нет.
Сравнение — JSON по значению.

Равенство номеров на разных серверах — меньшее имя сервера в байтах UTF-8 первым, как порядок кандидатов (Н3
«сократить», жертва). Не покрыто: проверка «каждая единица жертвы проходит выбрать()» — шагом приёмки и чтением.

## Вход не по форме (Р22)

Исполнитель вектора отвечает кодом 2 (ячейка `expect` — `@exit 2`) ровно на вход из перечня: не JSON-объект; `prefix` или
имя сервера не по грамматике (P/03.2 Н1.4, P/02.4 Н1.2); имя воркера не `<prefix>-<server>-<n>` своего элемента, `n` — не
целое 1…99 или с ведущим нулём; повтор имени; `want` не объект, не называет сервер воркера или его значение не целое
1…99. Остальное — вне вектора (ADR-0084 доп. (2) Р22).

## Кто исполняет

Кто исполняет — контроллер (`04-controller`: жертва сокращения, P/04 Н3 «сократить», `жертва`) — все строки. Скрипт сервера (`02-installer`) жертву не выбирает: останавливает номера выше готового `want` своим правилом (P/02.4 Н1.5 `rules` 3, векторы `workers-script`); воркер (`03-worker`) видит готовый `retiring` (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).
