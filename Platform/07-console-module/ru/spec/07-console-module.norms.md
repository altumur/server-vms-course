Канон модуля — нормы N1.5: опубликованные

## N1 Форма

- **Время.** Своих полей времени в строках и объектах у урока нет: модуль не пишет собственных строк и объектов по P/07-R005.

См. также: P/07-R001, P/07-R002, P/07-R004, P/07-R005, P/07-R249, P/07-R250, P/07-R251, P/07-R252, P/07-R253, P/07-R254, P/07-R255, P/07-R256, P/07-R257.

- Время в ответах дверей, которые он показывает (`until` сессии, `expires` двери из `where()`), — формы [P/06.3](../../../06-console/ru/spec/06.3-console.norms.md) и [P/06.5](../../../06-console/ru/spec/06.5-console.norms.md).

См. также: P/07-R001, P/07-R002, P/07-R003, P/07-R005, P/07-R249, P/07-R250, P/07-R251, P/07-R252, P/07-R253, P/07-R254, P/07-R255, P/07-R256, P/07-R257.

- **Данные.** Своих строк, объектов и файлов у урока нет: модуль читает и пишет только через двери из закрытого списка N1.4 — двери урока 6, в позднем слое (N1.6) ещё двери домена: `/domain/*` и вход `login_url` (`POST /api/login`) — двери консоли домена ([урок P/10](../../../10-domain-console/ru/spec/10-domain-console.norms.md); процесс `domain` — [урок P/08](../../../08-domain/spec/08-domain.api.openapi.yaml)), которые консоль кластера пересылает ([глава P/06.7](../../../06-console/ru/spec/06.7-console.norms.md); [договор пересылки](../../../common/ru/contracts/forwarding.md) «Двери домена»), и свои двери консоли кластера `/api/held`, `/domain/shared/<sub>` (глава P/06.7); формы — [контракт урока 6](../../../06-console/spec/06-console.api.openapi.yaml), в позднем слое — контракты уроков 8 и 10; владельцы строк — главы уроков 6, 8 и их каталог.

### N1.4 Что зовёт модуль — закрытый список

- **`reads`.** Разрешённые чтения модуля: /session, /manifest, `/<sub>/manifest`, /mounts, /changes, `/<rows>`, `/<sub>/<rows>`, `/<sub>/<table>` (только из servers.show), `/where/<id>`, `/<sub>/where/<id>`, /servers, `/<sub>/servers` (только профили загруженных подсистем), /unplaceable, `/<sub>/unplaceable`, /policy, /drain, /schema, /events, /metrics (только running_gauge и workers_gauge), /domain/* (договор пересылки «Двери домена»), /api/held (P/06.7-14), `/domain/shared/<sub>` (P/06.7-15), /folders (только при display.tree.folders).

См. также: P/07-R007, P/07-R008, P/07-R031, P/07-R032, P/07-R033, P/07-R202, P/07-R203, P/07-R204, P/07-R206, P/07-R271.

- **`writes`.** POST/PUT/DELETE `/<rows>[/<id>]` и `/<sub>/<rows>[/<id>]`, POST /folders, PUT/DELETE `/folders/<id>` (только при display.tree.folders), POST /marks, PUT /policy, POST/DELETE /drain, GET/PUT/DELETE `/servers/<s>/labels`, POST/DELETE `/servers/<s>/decommission`, /domain/* (договор пересылки «Двери домена»), POST/DELETE /session, /session/break-glass, login_url

См. также: P/07-R006, P/07-R008, P/07-R031, P/07-R032, P/07-R033, P/07-R202, P/07-R203, P/07-R204, P/07-R206, P/07-R271.

- **`never`.** /{sub}/requests, /api/backup (P/06.7-16), /resources, /{sub}/{table} вне show, двери держателей (door из where — только оболочке)

См. также: P/07-R006, P/07-R007, P/07-R031, P/07-R032, P/07-R033, P/07-R202, P/07-R203, P/07-R204, P/07-R206, P/07-R271.

- **`order`.** /session → /manifest → /mounts → /changes (только при монтировании) → по подсистеме `/<rows>` → /folders (если хоть одна подсистема объявила display.tree.folders) → /servers → `/<sub>/servers` (остальные профили каталога по порядку) → /unplaceable → `/domain/shared/<sub>` (P/06.7-15) → /drain → /schema → /domain (+ /domain/alarms; P/10-06) → /api/held (P/06.7-14) → /metrics;

См. также: P/07-R010, P/07-R011, P/07-R205, P/07-R271, P/07-R272, P/07-R273, P/07-R278, P/07-R279.

- **`order`.** опрос каждые poll_s;

См. также: P/07-R009, P/07-R011, P/07-R205, P/07-R271, P/07-R272, P/07-R273, P/07-R278, P/07-R279.

- **`order`.** /events?unit= выбранной — каждые 5 с

См. также: P/07-R009, P/07-R010, P/07-R205, P/07-R271, P/07-R272, P/07-R273, P/07-R278, P/07-R279.

- **`subsystems`.** opts.subsystems — имена подсистем каталога (корень и /mounts), чьи единицы модуль грузит, показывает деревом и пишет (`/<rows>`, `/<sub>/<rows>`, карточка, формы);

См. также: P/07-R013, P/07-R014, P/07-R015, P/07-R016, P/07-R017, P/07-R018, P/07-R284.

- **`subsystems`.** Если opts.subsystems отсутствует, модуль грузит, показывает и пишет единицы всех подсистем каталога.

См. также: P/07-R012, P/07-R014, P/07-R015, P/07-R016, P/07-R017, P/07-R018, P/07-R284.

- **`subsystems`.** Если opts.subsystems — список, модуль грузит, показывает и пишет единицы только названных подсистем.

См. также: P/07-R012, P/07-R013, P/07-R015, P/07-R016, P/07-R017, P/07-R018, P/07-R284.

- **`subsystems`.** Если opts.subsystems — [], модуль не грузит, не показывает и не пишет единиц подсистем.

См. также: P/07-R012, P/07-R013, P/07-R014, P/07-R016, P/07-R017, P/07-R018, P/07-R284.

- **`unplaceable`.** Модуль читает /unplaceable и `/<sub>/unplaceable` у каждой подсистемы каталога независимо от opts.subsystems; эти наблюдения — только для чтения.

См. также: P/07-R012, P/07-R013, P/07-R014, P/07-R015, P/07-R017, P/07-R018, P/07-R284.

- **`unplaceable`.** Неразмещённая единица подсистемы вне opts.subsystems видна строкой раздела (подсистема, id, причина), без карточки и действий.

См. также: P/07-R012, P/07-R013, P/07-R014, P/07-R015, P/07-R016, P/07-R018, P/07-R284.

- **`unplaceable`.** Если читать неразмещённые единицы только у показываемых страницей подсистем, неразмещённых единиц остальных подсистем не будет видно; P/07-R016 требует чтения всего каталога.
