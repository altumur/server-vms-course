## N1 Форма

- **Время.** Своих полей времени в строках и объектах у урока нет: модуль не пишет собственных строк и объектов по P/07-R005.

- Время в ответах дверей, которые он показывает (`until` сессии, `expires` двери из `where()`), — формы [P/06.3](../../../06-console/ru/spec/06.3-console.norms.md) и [P/06.5](../../../06-console/ru/spec/06.5-console.norms.md).

- **Данные.** Своих строк, объектов и файлов у урока нет: модуль читает и пишет только через двери из закрытого списка N1.4 — двери урока 6, в позднем слое (N1.6) ещё двери домена: `/domain/*` и вход `login_url` (`POST /api/login`) — двери консоли домена ([урок P/10](../../../10-domain-console/ru/spec/10-domain-console.norms.md); процесс `domain` — [урок P/08](../../../08-domain/spec/08-domain.api.openapi.yaml)), которые консоль кластера пересылает ([глава P/06.7](../../../06-console/ru/spec/06.7-console.norms.md); [договор пересылки](../../../common/ru/contracts/forwarding.md) «Двери домена»), и свои двери консоли кластера `/api/held`, `/domain/shared/<sub>` (глава P/06.7); формы — [контракт урока 6](../../../06-console/spec/06-console.api.openapi.yaml), в позднем слое — контракты уроков 8 и 10; владельцы строк — главы уроков 6, 8 и их каталог.

### N1.4 Что зовёт модуль — закрытый список

- **`reads`.** Разрешённые чтения модуля: /session, /manifest, `/<sub>/manifest`, /mounts, /changes, `/<rows>`, `/<sub>/<rows>`, `/<sub>/<table>` (только из servers.show), `/where/<id>`, `/<sub>/where/<id>`, /servers, `/<sub>/servers` (только профили загруженных подсистем), /unplaceable, `/<sub>/unplaceable`, /policy, /drain, /schema, /events, /metrics (только running_gauge и workers_gauge), /domain/* (договор пересылки «Двери домена»), /api/held (P/06.7-14), `/domain/shared/<sub>` (P/06.7-15), /folders (только при display.tree.folders).

См. также: P/07-R007, P/07-R008, P/07-R031, P/07-R070, P/07-R071, P/07-R202, P/07-R203, P/07-R204, P/07-R205, P/07-R206, P/07-R222, P/07-R336.

- **`writes`.** Собственные записи модуль делает только через двери: POST/PUT/DELETE `/<rows>[/<id>]` и `/<sub>/<rows>[/<id>]`; POST `/folders` и PUT/DELETE `/folders/<id>` только при `display.tree.folders`; POST `/marks`; PUT `/policy`; POST/DELETE `/drain`; GET/PUT/DELETE `/servers/<s>/labels`; POST/DELETE `/servers/<s>/decommission`; `/domain/*` по договору пересылки «Двери домена»; POST/DELETE `/session`; `/session/break-glass`; `login_url`.

См. также: P/07-R006, P/07-R008, P/07-R031, P/07-R070, P/07-R071, P/07-R202, P/07-R203, P/07-R204, P/07-R205, P/07-R206, P/07-R222, P/07-R336.

- **`never`.** Модуль никогда не зовёт `/{sub}/requests`, `/api/backup` (P/06.7-16), `/resources`, `/{sub}/{table}` вне `servers.show` и двери держателей; дверь из `where` модуль только передаёт оболочке.

См. также: P/07-R006, P/07-R007, P/07-R031, P/07-R070, P/07-R071, P/07-R128, P/07-R129, P/07-R130, P/07-R202, P/07-R203, P/07-R204, P/07-R205, P/07-R206, P/07-R222, P/07-R252, P/07-R336, P/07-R351.

- **`order`.** Модуль загружает данные в порядке: `/session` → `/manifest` → `/mounts` → `/changes` (только при монтировании) → по подсистеме `/<rows>` → `/folders` (если хоть одна подсистема объявила `display.tree.folders`) → `/servers` → `/<sub>/servers` (остальные профили каталога по порядку) → `/unplaceable` → `/domain/shared/<sub>` (P/06.7-15) → `/drain` → `/schema` → `/domain` (+ `/domain/alarms`; P/10-06) → `/api/held` (P/06.7-14) → `/metrics`.

См. также: P/07-R010, P/07-R011, P/07-R019, P/07-R023, P/07-R029, P/07-R030, P/07-R035, P/07-R065, P/07-R066, P/07-R067, P/07-R205, P/07-R229, P/07-R230, P/07-R338.

- **`order`.** Модуль повторяет порядок загрузки P/07-R009, кроме `/changes`, каждые `poll_s`.

См. также: P/07-R009, P/07-R011, P/07-R019, P/07-R023, P/07-R029, P/07-R030, P/07-R035, P/07-R065, P/07-R066, P/07-R067, P/07-R205, P/07-R229, P/07-R230, P/07-R338.

- **`order`.** Модуль читает `/events?unit=<selected unit>` каждые 5 с.

См. также: P/07-R009, P/07-R010, P/07-R019, P/07-R023, P/07-R029, P/07-R030, P/07-R035, P/07-R065, P/07-R066, P/07-R067, P/07-R205, P/07-R229, P/07-R230, P/07-R338.

См. также: P/07-R013, P/07-R014, P/07-R015, P/07-R016, P/07-R017, P/07-R018, P/07-R037, P/07-R229, P/07-R305, P/07-R338.

См. также: P/07-R012, P/07-R013, P/07-R015, P/07-R016, P/07-R017, P/07-R018, P/07-R037, P/07-R229, P/07-R305, P/07-R338.

См. также: P/07-R012, P/07-R013, P/07-R014, P/07-R015, P/07-R016, P/07-R017, P/07-R018, P/07-R037, P/07-R229, P/07-R338.

- **`unplaceable`.** Неразмещённая единица подсистемы вне opts.subsystems видна строкой раздела (подсистема, id, причина), без карточки и действий.

См. также: P/07-R012, P/07-R013, P/07-R014, P/07-R015, P/07-R016, P/07-R018, P/07-R037, P/07-R229, P/07-R305, P/07-R338.

См. также: P/07-R012, P/07-R013, P/07-R014, P/07-R015, P/07-R016, P/07-R017, P/07-R037, P/07-R229, P/07-R305, P/07-R338.

- **`changes`.** Для GET /changes (P/06.1 N2 «Лента изменений») модуль получает номер до первого чтения строк.

См. также: P/07-R009, P/07-R010, P/07-R011, P/07-R023, P/07-R029, P/07-R030, P/07-R035, P/07-R065, P/07-R066, P/07-R067, P/07-R205, P/07-R229, P/07-R230, P/07-R338.

- **`changes`.** После немедленного возврата или обрыва /changes модуль выдаёт новый запрос не чаще раза в секунду.

- **`changes`.** Ограничение частоты запросов P/07-R021 не сокращает держание запроса wait=15.

- **`changes`.** Сброс или сообщение о строке подсистемы страницы сразу и тихо запускает порядок загрузки P/07-R009: страница видит правку за такт, а не за poll_s.

- **`changes`.** Сообщение ленты не несёт значения, поэтому модуль перечитывает строки, а не применяет сообщение.

- **`changes`.** При обработке сообщения ленты модулю не нужно сравнивать revision.

- **`changes`.** При ответе 404 от `/changes` модуль перестаёт звать ленту и продолжает работать опросом.

- **`changes`.** При отказе /changes кроме 404 или обрыве следующая попытка ленты — через poll_s, без окна входа; это окно поднимает опрос.

- **`changes`.** Ответ /changes на запрос без after (номера ещё нет) считается сбросом.

- **`changes`.** Страница держателя P/07-R229 не зовёт ленту изменений: у консоли домена её нет.

См. также: P/07-R009, P/07-R010, P/07-R011, P/07-R019, P/07-R023, P/07-R030, P/07-R035, P/07-R065, P/07-R066, P/07-R067, P/07-R205, P/07-R215, P/07-R229, P/07-R230, P/07-R239, P/07-R338, P/07-R342, P/07-R343.
