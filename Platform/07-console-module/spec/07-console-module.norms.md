# P/07 — Модуль консоли: нормы

Канон урока. [Лекция](../07-console-module.md), [инструкция](07-console-module.README.md). Своего HTTP-контракта у урока
нет: модуль — библиотека в браузере, своей двери у него нет (Н2); двери, которые он зовёт, — [контракт урока
6](../../06-console/spec/06-console.api.openapi.yaml). Каталога приёмки у урока нет (Н5); жизненного цикла нет: процесса,
окружения и кодов выхода у библиотеки нет, публикация модуля — [глава 6.5](../../06-console/spec/06.5-console.norms.md)
(план переноса урока 7, В4). Урок перенесён из М10/9 (стадия B,
ADR-0083 доп. (1): без изменения поведения): Н1.4 и Н1.5 (номера подразделов — прежние номера М10/9), строка Н5 «модуль —
по контракту», пункты чеклиста М10/9-06, -07. Поздний слой — раздел домена, `sections: [domain]` вызова `mount`, режим
держателя — Н1.6, без своих id (план, В5). Канон модуля — нормы Н1.5 (разбор ревью стадии A 6–7, № 6): опубликованные
байты `console.js` и описание [`КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md`](../../../КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md) приводятся к нему
отдельной правкой поведения после коммита урока («Решает реализация» п. 1). Три части консоли, монтирование
`PlatformConsole.mount(root, opts)`, `opts`, `never` модуля и `may`/`may_not` оболочки — [P/06.5 Н1.1](../../06-console/spec/06.5-console.norms.md)
`module`, `shell`. Ссылка «урок N» без главы — урок модуля P/NN (М10 перенесён целиком; разбор ревью стадии B 3–5, № 34); «P/06.K» — глава урока 6;
«М11/N» — урок М11 до переноса уроков 8–10. Id норм — `P/07-MM`; соответствие прежним id — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля — [P/01.1 Н0](../../01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Полей времени в строках и объектах у урока нет: строк и объектов модуль не пишет (ниже). Время в ответах дверей,
которые он показывает (`until` сессии, `expires` двери из `where()`), — формы [P/06.3](../../06-console/spec/06.3-console.norms.md)
и [P/06.5](../../06-console/spec/06.5-console.norms.md).

**Данные.** Своих строк, объектов и файлов у урока нет: модуль читает и пишет только через двери из закрытого списка Н1.4 —
двери урока 6, в позднем слое (Н1.6) ещё двери домена М11 (`/domain/*`, `/api/held`; разбор ревью стадии B 6–7, № 30); формы — [контракт урока 6](../../06-console/spec/06-console.api.openapi.yaml), владельцы строк — главы урока 6 и их
каталог.

### Н1.4 Что зовёт модуль — закрытый список

```yaml
reads:   /session, /spec, /<sub>/spec, /mounts, /<rows>, /<sub>/<rows>, /<sub>/<table> (только из servers.show; добавлено М10/10),
         /where/<id>, /<sub>/where/<id>, /servers, /unplaceable, /<sub>/unplaceable, /policy, /drain, /schema (добавлено М10/10),
         /events, /metrics (только running_gauge и workers_gauge), /domain/* (договор пересылки «Двери домена»), /api/held (М11/8 Н1.9, форма — М11/10 Н1.4), /domain/shared/<sub> (М11/11 Н1.5)
writes:  POST/PUT/DELETE /<rows>[/<id>] и /<sub>/<rows>[/<id>], POST /marks, PUT /policy, POST/DELETE /drain, GET/PUT/DELETE /servers/<s>/labels,
         POST/DELETE /servers/<s>/decommission, /domain/* (договор пересылки «Двери домена»), POST/DELETE /session, /session/break-glass, login_url
never:   /{sub}/requests, /api/backup (М11/10), /resources, /{sub}/{table} вне show, двери держателей (door из where — только оболочке)
order:   /session → /spec → /mounts → по подсистеме /<rows> → /servers → /unplaceable → /domain/shared/<sub> (М11/11 Н1.5) → /drain → /schema
         → /domain (+ /domain/alarms; М11/11 Н1.8) → /api/held (М11) → /metrics; опрос каждые poll_s; /events?unit= выбранной — каждые 5 с
```

Слова `servers.show`, `console.running` (`running_gauge`, `workers_gauge`) и `poll_s` — [P/06.5](../../06-console/spec/06.5-console.norms.md)
Н1.1, Н1.2. Части списка, которые вводит домен (`/domain/*`, `/api/held`, `/domain/shared/<sub>`, `/domain/alarms`), —
поздний слой Н1.6.

### Н1.5 Контракт модуля с оболочкой

```yaml
version:   console.version — целое версии API оболочки (P/06.5 Н1.1 version); проверяется до использования модуля
objects:   ref: unit:<sub>/<id> | server:<s> | worker:<sub>/<w> | member:<m> | domain | person:<name> | group:<sub>/<поле>/<путь>
           | <prefix>:<…> оболочки (модуль только хранит)
api:       console.api(method, path, body) → ответ | throw {status, body, retry}
           POST с памятью повторов владельца (единица — P/06.1, просьба — P/06.4) — один ключ на логическое действие, не на одинаковые байты;
           повторы этого действия сохраняют ключ и исходное тело. Новый вызов — новый ключ. Сеть/таймаут 20 с/5xx/
           409 in flight допускают повтор только у дверей с памятью повторов (выше); задержка перед повтором — заголовок
           Retry-After ответа (секунды), без него — 2, 3, 5 с, после третьего повтора — throw (разбор ревью стадии B 6–7,
           № 27); 401 → окно входа.
           PUT и таблицы без памяти повторов автоматически не повторяются: при неизвестном исходе сначала чтение.
           Завершённый ответ закрывает действие; отказ до памяти заявки разбирается по контракту владельца, не кэшируется как успех
may:       console.may(cap, ref) → bool по grants сессии и правилу scope P/06.3 Н1.3 (* | unit:<sub>/<id> | labels:<…>; грант на
           единицу или на её about-единицу; ранг cap — view < edit < admin, договор права common/contracts/may.md шаг 7);
           via: break-glass (grants []) — true, как сервер у аварийной сессии (договор права common/contracts/may.md шаг 1,
           glass → allow); true без grants только при open: true; в закрытой или неизвестной (/session не ответила) сессии отсутствие grants — false; сервер проверяет всегда (разбор ревью стадии B 6–7, № 28)
events:    on("select", (ref, obj)) | on("refresh", {units, servers, domain}) | on("logout")
where:     where(ref) → {worker, server, door: {url, token, expires, routes} | null, reason}
           библиотека превращает отсутствующее поле door HTTP-ответа в null для оболочки; HTTP Where остаётся формой P/06.5 (контракт урока 6)
words:     display(name), spec(name), kindWord(e), eventNote(e), addEventNote; W — словарь модуля ru | en
adds:      addSection{id, label, icon, after, off, render}, addTab(kind, {id, label, render, busy}) kind ∈ unit | server |
           worker | member | domain, addTreeNodes(kind | servers | server, fn) → узлы {ref, label, icon, count, kids, badge,
           tags, dot, title, off, open, after, replaces}, addCard(prefix, render), addMenu, addDecor{icon, badge, title},
           addFieldEditor(kind, field, render(host, ref, obj, value, set)), addBlock("server", {id, covers, render}),
           addAction, addNote, addIcons, icon, unitForm(host, ref), dialog(title, fields, ok), confirm, toast, select,
           selected, refresh, logout, fullScreen, isFav, toggleFav
cards:     разметка карточки: <h1>, nav.pc-tabs, <h2> → .card, button.pc-hdbtn, span.pc-crumbs[data-crumbs], p.pc-hdsub
commands:  вид command / command.failed — слово и заметка модуля (action · исход · ответ · «кто: by»; late → «поздно»)
```

Сессия, гранты и вход, по которым судит `may`, — [P/06.3](../../06-console/spec/06.3-console.norms.md) (сторожевая,
`/session`); сервер проверяет каждый запрос независимо от `may`. Слова `display` — P/06.5 Н1.2.

  Н1.5); `writes` — `/domain/*` ([договор пересылки](../../common/contracts/forwarding.md) «Двери домена»); `order` — `/domain/shared/<sub>`, `/domain` (+ `/domain/alarms`; М11/11 Н1.8),

## Н2 Договор библиотеки

Модуль — библиотека платформы в браузере, один код у всех реализаций (ADR-0005): своего процесса, своей двери и
HTTP-контракта у урока нет (ADR-0082 доп. 13). Договор библиотеки — две нормы Н1: что модуль зовёт (Н1.4) и что он даёт
оболочке (Н1.5); поздний слой — Н1.6. Двери, которые модуль зовёт, их коды и формы — главы урока 6 и [контракт урока
6](../../06-console/spec/06-console.api.openapi.yaml); публикацию модуля байт в байт, версию `?v=` и страницу нормирует
[глава 6.5](../../06-console/spec/06.5-console.norms.md) Н1.1. Вызовы Н1.5 — оболочка, обращающаяся к библиотеке внутри своей
страницы, а не платформа, вызывающая подсистему: хуками в смысле [границы](../../../ГРАНИЦА-ПЛАТФОРМЫ-И-ПОДСИСТЕМЫ.md)
§1.1 они не являются ([ADR-0002](../../../decisions/0002-без-хуков-спека-воркер-страница.md)); байты потока и архива оболочка
берёт у держателя по `door` из `where()`, мимо консоли ([ADR-0015](../../../decisions/0015-байты-мимо-консоли-без-исключений.md)).

Описание публичной поверхности модуля (словарь `W`, разметка карточек, вызовы оболочки, облик) —
[`КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md`](../../../КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md) (не норма; план переноса урока 7, В1). Где описание или
опубликованные байты расходятся с Н1.4, Н1.5, прав урок (разбор ревью стадии A 6–7, № 6); известные расхождения — долг
«Решает реализация» п. 1.

## Н5 Приёмка

Каталога приёмки у урока нет (исключение `P/07 no-acceptance`; план переноса урока 7, В2): модуль — библиотека в браузере,
стенд HTTP-TSV её не исполняет. Публикация модуля байт в байт с опубликованными файлами и версия `?v=1` (`?v=2` — 404) —
сц. 01 [приёмки главы 6.5](../../06-console/acceptance/5/README.md) (P/06.5 Н1.1). Предметы Н1.4 и Н1.5 проверяются чтением
и jsdom-тестом владельца спецификации [`Source/tests/console`](../../../Source/tests/console) (разбор ревью стадии A 6–7,
№ 31): тест монтирует опубликованный модуль на странице в jsdom и перехватывает его запросы; модуль у реализаций один
(ADR-0005), свидетельство одно для всех (ADR-0080 доп. 16).

| Предмет | Причина | Место доказательства |
|---|---|---|

| Н1.5 `version` — целое, оболочка сверяет до использования | версию в `?v=` проверяет дверь, а сверку — страница | чтением до правки долга (п. 1): опубликованная оболочка `version` не сверяет; дверь `?v=` — сц. 01 приёмки 6.5 (разбор ревью стадии B 6–7, № 29) |

## Решает реализация

Модуль — один код у всех реализаций: реализация его не пишет и в нём не выбирает, а отдаёт опубликованные байты
(P/06.5 Н1.1 `module`). Пункт ниже — долг опубликованного модуля; закрывает его владелец спецификации (ADR-0080 доп. 16):

1. **долг: байты `console.js` и описание `КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md` приводятся к Н1.5** отдельной правкой поведения после
   коммита урока 7; долг продукта — «Сборке» (ADR-0005; разбор ревью стадии A 6–7, № 6, находки A-30, A-31): (а) `api` —
   опубликованный модуль держит ключ по методу, пути и телу у `POST` и `PUT` и повторяет `PUT` сам, описание § 5 — «один
   `Idempotency-Key` на одну отправку», § 7 п. 3 «Повторить» — тот же ключ; канон — ключ на логическое действие, `PUT` и
   таблицы без памяти повторов не повторяются, при неизвестном исходе — чтение; (б) `may` — опубликованный модуль даёт
   `true`, когда grants в сессии нет, при любом `open`; канон — `true` без grants только при `open: true`; правило показа у
   аварийной сессии (grants `[]`, слово `via` — [P/06.3](../../06-console/spec/06.3-console.norms.md)) и область `labels:` — та же
   правка; (в) неизвестная сессия: при отказе или неответе `/session` опубликованный модуль считает консоль открытой
   (`{open: true}`), и `may` даёт `true`; канон — неизвестная сессия закрыта; (г) `logout`: событие `on("logout")` модуль не
   испускает; (д) ссылка на воркер: модуль пишет `worker:<w>` без подсистемы; канон — `worker:<sub>/<w>`; (е) автоповтор
   `POST`: модуль повторяет с ключом любой `POST`, в том числе двери без памяти повторов (`POST /marks`, `/drain`,
   decommission), — таймаут `POST /marks` даёт вторую отметку; канон — повтор только у дверей с памятью повторов
   (`POST /{rows}`, `/{sub}/requests`); тесты владельца `Source/tests/console` (`module-retry`: повтор `PUT`, один ключ на
   одинаковую форму, повтор по таймауту) закрепляют нынешнее поведение и переворачиваются вместе с правкой; (ж) задержка
   повтора: модуль читает поле тела `retry_after` и зажимает его в 1–5 с, заголовок `Retry-After` не читает; канон — Н1.5
   `api`; (з) мелкие: `poll_s` берётся и из памяти браузера (при 0 опроса нет), короткий путь `/<table>` у корня вне Н1.4,
   ошибка после исчерпания повторов без `status` и `body`, чтение `server_unsaid`, которого нет в контракте урока 6;
   оболочка `console.html` не сверяет `version` до использования модуля (разбор ревью стадии B 6–7, № 26, № 27, № 28;
   находки Claude M-1, M-2, M-3, M-5). До неё предметы `api`, `may`, `version`, `where`, `objects` (`worker:`), `events`
   (`logout`) и закрытый список Н1.4 проверяются чтением (Н5; разбор ревью стадии B 6–7, № 29).
