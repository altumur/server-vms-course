## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля — [P/01.1 Н0](../../01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Полей времени в строках и объектах у урока нет: строк и объектов модуль не пишет (ниже). Время в ответах дверей,
которые он показывает (`until` сессии, `expires` двери из `where()`), — формы [P/06.3](../../06-console/spec/06.3-console.norms.md)
и [P/06.5](../../06-console/spec/06.5-console.norms.md).

**Данные.** Своих строк, объектов и файлов у урока нет: модуль читает и пишет только через двери из закрытого списка Н1.4 —
двери урока 6, в позднем слое (Н1.6) ещё двери домена: `/domain/*` и вход `login_url` (`POST /api/login`) — двери
консоли домена ([урок P/10](../../10-domain-console/spec/10-domain-console.norms.md); процесс `domain` — [урок
P/08](../../08-domain/spec/08-domain.api.openapi.yaml)), которые консоль кластера пересылает
([глава P/06.7](../../06-console/spec/06.7-console.norms.md); [договор пересылки](../../common/contracts/forwarding.md) «Двери
домена»), и свои двери консоли кластера `/api/held`, `/domain/shared/<sub>` (глава P/06.7) (разбор ревью стадии B 6–7,
№ 30; Claude M-5); формы — [контракт урока 6](../../06-console/spec/06-console.api.openapi.yaml), в позднем слое — контракты
уроков 8 и 10; владельцы строк — главы уроков 6, 8 и их каталог.

### Н1.4 Что зовёт модуль — закрытый список

```yaml
reads:   /session, /manifest, /<sub>/manifest, /mounts, /<rows>, /<sub>/<rows>, /<sub>/<table> (только из servers.show; добавлено М10/10),
         /where/<id>, /<sub>/where/<id>, /servers, /unplaceable, /<sub>/unplaceable, /policy, /drain, /schema (добавлено М10/10),
         /events, /metrics (только running_gauge и workers_gauge), /domain/* (договор пересылки «Двери домена»), /api/held (P/06.7-14), /domain/shared/<sub> (P/06.7-15)
writes:  POST/PUT/DELETE /<rows>[/<id>] и /<sub>/<rows>[/<id>], POST /marks, PUT /policy, POST/DELETE /drain, GET/PUT/DELETE /servers/<s>/labels,
         POST/DELETE /servers/<s>/decommission, /domain/* (договор пересылки «Двери домена»), POST/DELETE /session, /session/break-glass, login_url
never:   /{sub}/requests, /api/backup (P/06.7-16), /resources, /{sub}/{table} вне show, двери держателей (door из where — только оболочке)
order:   /session → /manifest → /mounts → по подсистеме /<rows> → /servers → /unplaceable → /domain/shared/<sub> (P/06.7-15) → /drain → /schema
         → /domain (+ /domain/alarms; P/10-06) → /api/held (P/06.7-14) → /metrics; опрос каждые poll_s; /events?unit= выбранной — каждые 5 с
```

Слова `servers.show`, `console.running` (`running_gauge`, `workers_gauge`) и `poll_s` — [P/06.5](../../06-console/spec/06.5-console.norms.md)
Н1.1, Н1.2. Части списка, которые вводит домен (`/domain/*`, `/api/held`, `/domain/shared/<sub>`, `/domain/alarms`,
`login_url`), — поздний слой Н1.6.

### Н1.5 Контракт модуля с оболочкой

```yaml
module:    один объект модуля — PlatformConsole {version, features, mount}; mount(root, opts) возвращает объект страницы
           (pc — имя переменной страницы в примерах, не второй объект) (ADR-0091 доп. (27) п. 3)
version:   console.version — целое версии API оболочки (P/06.5 Н1.1 version); проверяется до использования модуля;
           остаётся 1: новое ниже (features, ready, select с tab, card.closed) только добавляется, загрузка ?v=1 та же
           (ADR-0091 доп. (25) п. 1)
features:  PlatformConsole.features — список строк возможностей сверх первых вызовов версии 1: "select.tab", "card.closed",
           "api.if-match" (ADR-0091 доп. (28), (29));
           строки нет — нет возможности; страница узнаёт новое по нему, не по версии (ADR-0091 доп. (25) п. 1)
ready:     pc.ready — обещание (Promise), нового вызова нет: разрешается объектом страницы после mount и первого прочитанного
           /manifest (двери /spec нет — Н1.4); ответ 401 — обещание ждёт входа и разрешается после него; /manifest не
           прочитан (сеть, 5xx) — модуль читает его снова опросом, обещание ждёт (ADR-0091 доп. (24) п. 1, доп. (27) п. 1)
objects:   ref: unit:<sub>/<id> | server:<s> | worker:<sub>/<w> | member:<m> | domain | person:<name> | group:<sub>/<поле>/<путь>
           | <prefix>:<…> оболочки (модуль только хранит)
api:       console.api(method, path, body, opts?) → ответ | throw {status, body, retry}
           opts.ifMatch — целое ≥ 1 (revision, P/06.1 Н3) → заголовок If-Match; только у PUT и DELETE на путь строки единицы
           /<rows>/<id> (иные двери If-Match не читают и записали бы без CAS); иной метод, иной путь, поле opts, кроме ifMatch,
           ifMatch не целое ≥ 1 — отказ вызова до запроса; иных заголовков модуль не шлёт; 412 → throw {status: 412, body —
           как получено, retry: false}; прочие ошибки HTTP и правила повторов — ниже, прежние; страница без "api.if-match" в
           features запись по версии не делает (ADR-0091 доп. (28), (29))
           POST с памятью повторов владельца (единица — P/06.1, просьба — P/06.4) — один ключ на логическое действие, не на одинаковые байты;
           повторы этого действия сохраняют ключ и исходное тело. Новый вызов — новый ключ. Сеть/таймаут 20 с/5xx/
           409 in flight допускают повтор только у дверей с памятью повторов (выше); задержка перед повтором — заголовок
           Retry-After ответа (секунды), без него — 2, 3, 5 с, после третьего повтора — throw (разбор ревью стадии B 6–7,
           № 27); 401 → окно входа.
           PUT и таблицы без памяти повторов автоматически не повторяются: при неизвестном исходе сначала чтение.
           Завершённый ответ закрывает действие; отказ до памяти заявки разбирается по контракту владельца, не кэшируется как успех
may:       console.may(cap, ref) → bool по grants сессии и правилу scope P/06.3 Н1.3 (* | unit:<sub>/<id> | labels:<…>; грант на
           единицу или на её about-единицу; ранг cap — view < edit < admin, договор права common/contracts/may.md шаг 7);
           via: break-glass (grants []) — true, как сервер у аварийной сессии (договор права common/contracts/may.md шаг 1,
           glass → allow); true без grants только при open: true; в закрытой или неизвестной (/session не ответила) сессии отсутствие grants — false; сервер проверяет всегда (разбор ревью стадии B 6–7, № 28)
events:    on("select", (ref, obj)) | on("refresh", {units, servers, domain}) | on("logout") | on("card.closed", {ref})
           card.closed — карточку убрали: выбор другого объекта, снятие выбора (смена раздела, удаление), уход со страницы;
           и у карточки оболочки — ref её имя как есть (streamaccounts:local, netvols); перерисовка опроса того же выбора
           его не даёт (ADR-0091 доп. (22) п. 2, доп. (24) п. 2, доп. (25) п. 2)
where:     where(ref) → {worker, server, door: {url, token, expires, routes} | null, reason}
           библиотека превращает отсутствующее поле door HTTP-ответа в null для оболочки; HTTP Where остаётся формой P/06.5 (контракт урока 6)
words:     display(name), manifest(name), kindWord(e), eventNote(e), addEventNote; W — словарь модуля ru | en
adds:      addSection{id, label, icon, after, off, render}, addTab(kind, {id, label, render, busy}) kind ∈ unit | server |
           worker | member | domain, addTreeNodes(kind | servers | server, fn) → узлы {ref, label, icon, count, kids, badge,
           tags, dot, title, off, open, after, replaces}, addCard(prefix, render), addMenu, addDecor{icon, badge, title},
           addFieldEditor(kind, field, render(host, ref, obj, value, set)), addBlock(kind, {id, covers, render}),
           addAction, addNote, addIcons, icon, unitForm(host, ref), dialog(title, fields, ok), confirm, toast,
           select(ref, {tab?}), selected, refresh, logout, fullScreen, isFav, toggleFav
           addBlock(kind) — kind ∈ server, member, domain; addTreeNodes(kind) — kind ∈ unit (узлы под единицей), servers,
           server, member, access (то, что модуль уже даёт; ADR-0091 доп. (22) п. 1)
           select(ref, {tab}) — выбрать объект (единицу или карточку оболочки) и открыть вкладку по id, данному addTab
           ("general" — карточка модуля); такой вкладки нет — карточка открывается без смены вкладки (ADR-0091 доп. (22)
           п. 2, доп. (24) п. 2, доп. (25) п. 2)
cards:     разметка карточки: <h1>, nav.pc-tabs, <h2> → .card, button.pc-hdbtn, span.pc-crumbs[data-crumbs], p.pc-hdsub
commands:  вид command / command.failed — слово и заметка модуля (action · исход · ответ · «кто: by»; late → «поздно»); поля события
           outcome, action, by, late, error, reply пишет база воркера (P/03.6 Н3 «взгляд держателя»)
```

Сессия, гранты и вход, по которым судит `may`, — [P/06.3](../../06-console/spec/06.3-console.norms.md) (сторожевая,
`/session`); сервер проверяет каждый запрос независимо от `may`. Слова `display` — P/06.5 Н1.2.

### Н1.6 Раздел домена — поздний слой: вводят уроки 8 и 10 (без своих id)

Части Н1.4 и Н1.5, которые вводит домен, — части P/07-01 и P/07-02 без своих id (план переноса урока 7, В5; как P/02.1
Н1.2б). Текст перенесён переносом уроков 8–10 (стадия B, коммит 10; план переноса урока 8, § 5, строка P/07 Н1.6): части
о модуле из М11/8 Н1.8 `module`, М11/11 Н1.6 `declared` и описания модуля
[`КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md`](../../../КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md) § 7 (разделы `domain`, `access`, `GET /api/held`) и
§ 10a (страница держателя) (разбор ревью стадии A 6–7, № 27, № 30). Двери, которые консоль домена отдаёт странице, —
[урок P/10](../../10-domain-console/spec/10-domain-console.norms.md) (страница держателя — P/10-04); пересылка к ним, `/api/held`
и `/domain/shared/<sub>` у консоли кластера — [глава P/06.7](../../06-console/spec/06.7-console.norms.md).

```yaml
reads:     /domain/* (договор пересылки «Двери домена»; консоль кластера пересылает их консоли домена — P/06.7-02…05),
           /api/held (P/06.7-14; запись срока и пара резервной копии — P/08.8), /domain/shared/<sub> (P/06.7-15)
writes:    /domain/* (договор пересылки «Двери домена»); login_url — POST {user, password} на адрес login_url из /session:
           дверь домена POST /api/login (P/08.4 Н1.2; login_url — договор сторожевой и передачи «Сторожевая»; консоль
           кластера пересылает её домену — «Двери домена»)
order:     /domain/shared/<sub>, /domain (+ /domain/alarms — P/10-06), /api/held
never:     /api/backup (P/06.7-16)
objects:   member:<m>, domain, person:<name>
events:    поле domain у refresh; раздел access, прочитав свои двери, испускает refresh {access}
adds:      виды member, domain у addTab; addBlock — member, domain; addTreeNodes — member, access (как в Н1.5; ADR-0091
           доп. (24) п. 6, доп. (27) п. 3)
sections:  умолчание opts.sections — [units, access, journal] (P/06.5 Н1.1 opts): раздел access умолчания — поздний слой
           (ниже); [domain] — страница держателя (P/10-04)
domain:    не раздел ленты, а корень раскладки «По серверам» панели единиц: где держатель (GET /api/held), члены, ключи,
           топология, перенос («Перенести домен сюда» — диалог: файл восстановления текстом и «старый держатель украден»
           нет/да → POST /domain/move {recovery[, stolen: true]}; без файла запрос не уходит), тревоги (в карточке одна
           строка на вид и of: последняя, «×N (с …)», список членов), keys-view; карточка домена несёт срок и передачу,
           «применить заново», единицы по подсистемам, общие настройки по declared и правки для кластеров (pending и outcomes)
access:    люди, гранты, break-glass — /domain/users, /domain/grants, /domain/break-glass (договор пересылки «Двери домена»)
held:      GET /api/held — единственная дверь процессов, которую модуль читает: подписанная публичная запись держателя
           {cluster, holder, term, keys, backup: {term, rev}} на консоли кластера; backup — указатель последней копии у этого
           члена, сравнимый только парой {term, rev}; у члена модуль показывает «старая копия», когда его пара отстаёт от
           пары держателя, и «держатель её больше не обновляет», когда члена нет в backup_holders; числа — как есть
holder:    при sections: [domain] режим держателя модуль узнаёт из sections страницы: не грузит единицы, /servers и
           /unplaceable, единицы по подсистемам берёт из вида /domain; /servers, /drain, /schema, /unplaceable, /metrics,
           /events у держателя не нужны — модуль переживает их отсутствие
schema:    GET /domain/shared → {doc, delivery, declared: {<sub>: [{name, type, schema?}]}} (P/10-14): объявленные поля из
           domain.shared манифестов и их типы; у документа {name, type: json} — и его schema, по ней страница строит форму;
           правка — PUT /domain/shared {base_rev, shared: {<sub>: {<поле>: значение | null}}}
```

Откуда строки: `reads`, `writes` (`/domain/*`), `order`, `never`, `objects`, `adds`, поле `domain` у `refresh` — прежний
Н1.6 (адреса М11 → P/06.7, P/10); `login_url`, `refresh {access}` и раздел `access` умолчания `sections` — разбор ревью
стадии B 6–7, № 30 (Claude M-5); `domain`, `access`, `held` — описание § 7; `holder` — § 10a и М11/8 Н1.8 `module`;
`schema` — М11/11 Н1.6 `declared` и § 10a. Форма по `schema`: объект — по `properties` (обязательные помечены), список —
элементы по `items` с добавлением и удалением, строка, число, целое, да/нет, `enum` — свои поля; чего форма сказать не может
(объект без `properties`, объединение типов, значение с ключами вне схемы), — текст JSON на своём месте; пустые поля не
уходят, пустой документ — `null`; схему проверяет домен при `PUT` («Решает реализация» п. 2, закрыт; решение «Архитектора» 2026-10-21).
Страницу держателя (`/`, CSP, `/manifest`, `/mounts`, `/session`) отдаёт урок P/10 (P/10-04): реализации отдают байты модуля
как есть; что модуль зовёт в режиме `domain` — свойство опубликованного модуля, не реализаций (М11/8 Н1.8 `module`).

## Н2 Договор библиотеки

Модуль — библиотека платформы в браузере, один код у всех реализаций (ADR-0005): своего процесса, своей двери и
HTTP-контракта у урока нет (ADR-0082 доп. 13). Договор библиотеки — две нормы Н1: что модуль зовёт (Н1.4) и что он даёт
оболочке (Н1.5); поздний слой — Н1.6. Двери, которые модуль зовёт, их коды и формы — главы урока 6 и [контракт урока
6](../../06-console/spec/06-console.api.openapi.yaml); публикацию модуля байт в байт, версию `?v=` и страницу нормирует
[глава 6.5](../../06-console/spec/06.5-console.norms.md) Н1.1. Вызовы Н1.5 — оболочка, обращающаяся к библиотеке внутри своей
страницы, а не платформа, вызывающая подсистему: хуками в смысле [границы](../../../ГРАНИЦА-ПЛАТФОРМЫ-И-ПОДСИСТЕМЫ.md)
§1.1 они не являются ([ADR-0002](../../../decisions/0002-без-хуков-спека-воркер-страница.md)); байты потока и архива оболочка
берёт у держателя по `door` из `where()`, мимо консоли ([ADR-0015](../../../decisions/0015-байты-мимо-консоли-без-исключений.md)).

Описание публичной поверхности модуля (словарь `W`, разметка карточек, вызовы оболочки, облик) —
[`КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md`](../../../КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md) (не норма; план переноса урока 7, В1). Где описание или
опубликованные байты расходятся с Н1.4, Н1.5, прав урок (разбор ревью стадии A 6–7, № 6); расхождения «Решает реализация»
п. 1 и п. 2 сняты правками поведения (решение «Архитектора» 2026-10-21).

## Н3 Проход

Своих проходов у урока нет: порядок загрузки и опроса — Н1.4 `order`; повтор вызова — Н1.5 `api`. Проходы дверей, которые
модуль зовёт, — Н3 глав урока 6.

## Н4 Отказы

Своих строк Н4 у урока нет: отказы дверей, которые модуль зовёт, — Н4 глав урока 6 (версия модуля не та — 404 `no such
version`, [P/06.5](../../06-console/spec/06.5-console.norms.md) Н4); что модуль делает с отказом — Н1.5 `api` (401 — окно
входа; повтор — только по правилам владельца памяти повторов; неизвестный исход `PUT` и таблицы — сначала чтение).

## Н5 Приёмка

Каталога приёмки у урока нет (исключение `P/07 no-acceptance`; план переноса урока 7, В2): модуль — библиотека в браузере,
стенд HTTP-TSV её не исполняет. Публикация модуля байт в байт с опубликованными файлами и версия `?v=1` (`?v=2` — 404) —
сц. 01 [приёмки главы 6.5](../../06-console/acceptance/5/README.md) (P/06.5 Н1.1). Предметы Н1.4 и Н1.5 проверяются
jsdom-тестами владельца спецификации [`Source/tests/console`](../../../Source/tests/console) (разбор ревью стадии A 6–7,
№ 31): тест монтирует опубликованный модуль на странице в jsdom и перехватывает его запросы; модуль у реализаций один
(ADR-0005), свидетельство одно для всех (ADR-0080 доп. 16).

| Предмет | Причина | Место доказательства |
|---|---|---|
| Н1.4 `reads`, `writes`, `never` — ни одного вызова вне списка; двери держателей модуль не зовёт | TSV говорит с дверями, вызовов страницы не видит | jsdom-тест `module-calls`: каждый перехваченный запрос модуля (метод и путь) при монтировании, опросе, выборе и правках сверяется с `reads`/`writes`, пути `never` и дверь из `where()` не зовутся; режим `domain` — тот же тест (разбор ревью стадии B 6–7, № 29; решение «Архитектора» 2026-10-21) |

| Н1.5 `api` — ключ логического действия, повтор по правилам владельца, `PUT` и таблицы без автоповтора, 401 — окно входа | повтор после потерянного ответа TSV не создаёт | jsdom-тест `module-retry` (и `module-session`: «Повторить» тем же ключом): новый ключ на вызов, повтор только `POST /<rows>`, `/<sub>/<rows>` тем же ключом и телом, `Retry-After`, после третьего повтора — отказ с `status`, `body`, `retry`; `PUT`, `DELETE`, `POST /marks`, `/drain`, вывод сервера — без повтора, сначала чтение; 401 — окно входа (решение «Архитектора» 2026-10-21) |

## Решает реализация

Модуль — один код у всех реализаций: реализация его не пишет и в нём не выбирает, а отдаёт опубликованные байты
(P/06.5 Н1.1 `module`). Пункты ниже — долги опубликованного модуля; закрывает их владелец спецификации (ADR-0080 доп. 16); оба закрыты:

1. **закрыт: байты `console.js`, `console.html` и описание `КОНСОЛЬ-МОДУЛЬ-ПЛАТФОРМЫ.md` приведены к Н1.4, Н1.5**
   правкой поведения после коммита урока 7 (решение «Архитектора» 2026-10-21; разбор ревью стадии A 6–7, № 6, находки A-30, A-31;
   разбор ревью стадии B 6–7, № 26–29; находки Claude M-1, M-2, M-3, M-5). Было: ключ по методу, пути и телу и
   автоповтор `PUT` и любого `POST` (а, е), поле тела `retry_after` вместо заголовка `Retry-After` (ж), `may` без grants —
   `true` при любом `open` и у неизвестной сессии (б, в), нет события `logout` (г), ссылка `worker:<w>` без подсистемы (д),
   `poll_s` из памяти браузера, `/<table>` у корня, ошибка без `status` и `body`, чтение `server_unsaid`, оболочка без
   сверки `version` (з). Свидетельства — jsdom-тесты [`Source/tests/console`](../../../Source/tests/console) по таблице Н5. Долг
   продукта — «Сборке» (ADR-0005): его копия модуля приводится к этим байтам.
2. **закрыт: форма общего документа по `schema`** (Н1.6 `schema`) — правкой поведения владельца спецификации (ADR-0080
   доп. 16; решение «Архитектора» 2026-10-21): было — документ `{name, type: json}` текстом JSON без формы (описание § 10a). Свидетельство —
   jsdom-тест `module-shared-schema` (Н5). Долг продукта — «Сборке» (ADR-0005).
