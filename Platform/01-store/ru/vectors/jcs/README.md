# JCS (RFC 8785) — вектор

Текст производный от `vectors/jcs/README.md`, руками не правится: источник — английский [`vectors/jcs/README.md`](../../../vectors/jcs/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Владелец — урок P/01: хранилище вводит первый договор, который пишет текст JSON; норма — ADR-0072
(канон подписанного документа — RFC 8785 целиком). Читают все, кто подписывает или сравнивает текст JSON байтами: тело
просьбы и digest ([P/06.4](../../../../06-console/ru/spec/06.4-console.norms.md) N1.5), токен двери, подписи домена (уроки M11).

## `canonical_json.tsv`

Таблица вне входа модели (только для судьи: `canonical_json.tsv`); она проверяет канон ADR-0072, названный выше. Заголовка нет; три поля через TAB: `raw` — текст JSON, как он может прийти; `canonical` — его форма RFC 8785; `sha256` —
sha256 UTF-8 этой формы (hex). Реализация читает каждый вход, приводит к канону и сравнивает обе колонки. Строки с `#` —
заметки (в том числе обязательные случаи ADR-0072). Провод команды — форма ниже.

## Кто исполняет

Каждая роль, чья норма приводит JSON к канону RFC 8785 (строку исполняет роль, чья норма вызывает
её функцию): хранилище (`01-store`, владелец); установщик (`02-installer`: канонический вид манифеста,
P/02.2 N1.1); воркер (`03-worker`: `value` состояния, P/03.6); консоль кластера (`06-console`: `digest` просьбы и поля
тела, P/06.4 N1.5; claims токена двери, P/06.5 N3 и договор токена двери); процесс `domain` (`08-domain`: подписи и
документы домена, поколения, предел Entry, P/08.2, P/08.3, P/08.10); агент (`09-agent`: подписи и документы домена,
смена объекта, P/09.1). Все строки — каждой из этих ролей.

## Провод векторов

Провод вектора задают строки `01-store/jcs` в [единой форме](../../../../common/vectors/wire.tsv); [грамматика](../../../../common/ru/vectors/wire.md). Форма — источник шапки, выбранных входов, фикстур, нативного исхода и сравнения. Смысл алгоритма и обязанность потребителя остаются здесь.
