# Данные случаев только для судьи

Этот русский текст — производный от `vectors/rights-evaluator/README.cases.md`, руками не правится (ADR-0121).

Общие правила остаются в [README.md](README.md). Следующие исходные отрывки сохраняют прежние связи именованных случаев как происхождение только для судьи.

### Исходный отрывок 1

- точный образец (`acc/exact`), префикс (`acc/pre/*`: `*` только последним знаком);
- буквальные знаки: `*` не последним (`acc/a*b` — только ключ `acc/a*b`, не `acc/axb`), `!` не первым (`acc/p/!x`);
- конечная звёздочка после буквальной: у роли `star-prefix` образец `a**` для каждого действия; `a*`, `a*x` и `a**` разрешены, а `a` и `ax` запрещены (P/01.2-R008);
- `!` — отрицание пустого ключа, ничего не отнимает; `!*` — отрицание всего (роль `none`);
- отрицание побеждает независимо от места в списке: `!acc/pre/secret/*` первым, перед более широким `acc/pre/*`, отнимает
  `acc/pre/secret/k1`, а `acc/pre/secret` (без `/` — не под префиксом отрицания) остаётся разрешён (аудит покрытия P/01,
  второй проход, G07);
