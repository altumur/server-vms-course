# Оценщик прав — вектор

Текст производный от `vectors/rights-evaluator/README.md`, руками не правится: источник — английский [`vectors/rights-evaluator/README.md`](../../../vectors/rights-evaluator/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Владелец — урок P/01, глава 1.2 (на стадии A норма — P/01.2 N1.2 `pattern`, N1.3 «Оценщик»). Вход — файл прав
`rights.json`, выход — `expect.tsv`: строка `role action key expect`, `expect` — `allow` или `deny`.

**Прогон.** Раннер запускает свежее хранилище с `rights.json` как `{rights}` («Стенд» [общего README приёмки](../../../../common/ru/acceptance/README.md); разбор ревью стадии B 3–5, № 33) и на
каждую строку делает пробу сокетом роли: `read` — `GET /v1/get?key=<key>`, `write` — `POST /v1/write` `put`, `delete` —
`POST /v1/write` `delete` (без `cas`; отсутствующая строка удаляется успешно, M10/1 N3). Исход пробы:
- `deny` — `403 forbidden`;
- `allow` — только подтверждённый успех: у чтения 200 формы `Row` (в том числе `{items: null, index: ""}`), у записи и
  удаления 200 `Written`;
- 5xx, ошибка транспорта и иной ответ — неопределённый исход: проба не засчитана ни как `allow`, ни как `deny`, прогон
  не зелёный.

Проверяется смысл оценщика, а не байты файла (ревью стадии A: RA1-16, SA1-22).

**Что покрыто:**
- точный образец (`acc/exact`), префикс (`acc/pre/*`: `*` только последним знаком);
- буквальные знаки: `*` не последним (`acc/a*b` — только ключ `acc/a*b`, не `acc/axb`), `!` не первым (`acc/p/!x`);
- конечная звёздочка после буквальной: у роли `star-prefix` образец `a**` для каждого действия; `a*`, `a*x` и `a**` разрешены, а `a` и `ax` запрещены (P/01.2-R008);
- `!` — отрицание пустого ключа, ничего не отнимает; `!*` — отрицание всего (роль `none`);
- отрицание побеждает независимо от места в списке: `!acc/pre/secret/*` первым, перед более широким `acc/pre/*`, отнимает
  `acc/pre/secret/k1`, а `acc/pre/secret` (без `/` — не под префиксом отрицания) остаётся разрешён (аудит покрытия P/01,
  второй проход, G07);
- права одного действия не дают другого (`write`, `delete`): `delete` — свой список, у оценщика нет `delete = write`;
  пустой или отсутствующий `delete` — удалять нельзя (P/01.2 N1.2).

Сверка python и go M10/6–11 («`*` in the middle is literal», обе реализации); решение «Архитектора» по журналу
cammeta-go, урок 6 № 2.

## Кто исполняет

Кто исполняет — хранилище (`01-store`: оценщик P/01.2 N1.3, и у хранилища в процессе, P/01.1-22) — все строки, через дверь своих сокетов ролей. Не исполняют: агент в процессе (`09-agent`, P/09.1 N1.11 `rights`) — права его компонентов проверяет хранилище в процессе; генератор прав установщика (`02-installer`, P/02.5 N3 «сгенерировать_права» шаг 4) — своё правило покрытия образцов секретных строк, не оценщик действий; консоль (`06-console`, P/06.3) только ссылается на P/01.2 (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).
