# Инструкции проб только для судьи

Этот русский текст — производный от `probes/README.cases.md`, руками не правится (ADR-0121).

Договор наблюдений остаётся в [README.md](README.md). Следующие исходные отрывки сохраняют описание собственных запусков и программ судьи.

### Исходный отрывок 1

Это публичные проверки наблюдений [боевой приёмки](../qualification/README.md). Они судят переданные наблюдения. Они не запускают, не ищут и не квалифицируют реализацию, и реализация их не импортирует. Только стандартная библиотека Python 3.12.

### Исходный отрывок 2

`OBSERVATION_PASS` значит лишь, что переданные наблюдения прошли эту проверку. Это не родной прогон и не боевой результат: команда всегда сообщает `native_executed: 0` и `production_passed: 0`.

### Исходный отрывок 3

## Команды

Запускать из этого каталога без `PYTHONPATH`:

```sh
python3.12 -B -m store_probes --list
python3.12 -B -m store_probes
python3.12 -B -m store_probes --capture <file> --probe <name>
```

`--list` — перечень, код 0. Без записи наблюдений каждая проба называет свои недостающие привязки, код 3. `--capture` читает JSON формата `cammeta-store-probes-v1`; без `--probe` сохраняются строки всех восьми.

| Код | Значение |
|---|---|
| 0 | проверки наблюдений прошли |
| 1 | наблюдение не соответствует норме |
| 2 | ошибка средства или формы |
| 3 | нет входов |

### Исходный отрывок 4

Группы — частичные срезы [групп случаев](../qualification/README.md#группы-случаев): проба не исполняет группу целиком. `--list` печатает ссылки на нормы и требуемые привязки каждой пробы.

## Происхождение

Четыре модуля — неизменённые байты коммита раннера приёмки `05f81051b72eb758f7d2f91cbffd4006db2b6c91`. Идентификаторы коммитов и строки носителей внутри них — историческое происхождение этих проверок, а не идентичность этой выгрузки.
