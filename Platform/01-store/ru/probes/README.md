# Боевые пробы хранилища

Этот русский текст — производный от `probes/README.md`, руками не правится; для человека, в выгрузку не входит.

Это публичные проверки наблюдений [боевой приёмки](../spec/production-acceptance.md). Они судят переданные наблюдения. Они не запускают, не ищут и не квалифицируют реализацию, и реализация их не импортирует. Только стандартная библиотека Python 3.12.

`OBSERVATION_PASS` значит лишь, что переданные наблюдения прошли эту проверку. Это не родной прогон и не боевой результат: команда всегда сообщает `native_executed: 0` и `production_passed: 0`.

## Команды

Запускать из этого каталога без `PYTHONPATH`:

```sh
python3.12 -B -m store_probes --list
python3.12 -B -m store_probes
python3.12 -B -m store_probes --capture <file> --probe <name>
```

`--list` — перечень, код 0. Без записи наблюдений каждая проба называет свои недостающие привязки, код 3. `--capture` читает JSON формата `cammeta-store-probes-v1`; без `--probe` сохраняются строки всех восьми.

| Код | Значение |
|---|---|
| 0 | проверки наблюдений прошли |
| 1 | наблюдение не соответствует норме |
| 2 | ошибка средства или формы |
| 3 | нет входов |

## Пробы

Группы — частичные срезы [групп случаев](../spec/production-acceptance.md#группы-случаев): проба не исполняет группу целиком. `--list` печатает ссылки на нормы и требуемые привязки каждой пробы.

| Имя | Свойство | Группы случаев | Бюджеты |
|---|---|---|---|
| `01-connections` | Пределы соединений и отказ сверх них | нет | `BUDGET_OVERFLOW_REFUSAL` |
| `02-input-drain` | Сроки фаз ввода и сырой слив | RUN-T01, RUN-T02, RUN-T03 | `BUDGET_IDLE`, `BUDGET_HEADERS`, `BUDGET_BODY`, `BUDGET_DRAIN` |
| `03-lock-wait` | Конечное ожидание замка изменений | RUN-L02 | значение `-leader-wait` |
| `04-barrier-replay` | Сбой барьера и повтор по тому же id | RUN-F03 | нет |
| `05-data-ownership` | Исключительное владение каталогом данных | нет | нет |
| `06-cost-id` | Стоимость записи и импорта, хранение id | RUN-W01, RUN-W02, RUN-W03, RUN-W04 | `BUDGET_WRITE_P99`, `BUDGET_WRITE_GROWTH`, `BUDGET_WRITE_BYTES`, `BUDGET_IMPORT_ORDINARY`, `BUDGET_IMPORT_WORST`, `BUDGET_IMPORT_GROWTH`, `BUDGET_MEMORY_ORDINARY`, `BUDGET_MEMORY_WORST` |
| `07-framing` | Сырое кадрирование HTTP | RUN-T02, RUN-H02 | нет |
| `08-backup-rows` | Строки копии и неполный вывод | RUN-L01, RUN-H01, RUN-H02, RUN-H03 | `BUDGET_BACKUP_ORDINARY`, `BUDGET_BACKUP_WORST` |

Проверки берут значения бюджетов из переданной записи наблюдений и таблицу бюджетов не читают. Привязка утверждённых значений, запуск стенда и сбор наблюдений — дело программы приёмки; этот каталог не добавляет поля profile, порта, флага или адаптера.

## Происхождение

Четыре модуля — неизменённые байты коммита раннера приёмки `05f81051b72eb758f7d2f91cbffd4006db2b6c91`. Идентификаторы коммитов и строки носителей внутри них — историческое происхождение этих проверок, а не идентичность этой выгрузки.
