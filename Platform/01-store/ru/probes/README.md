# Боевые пробы хранилища

Этот русский текст — производный от `probes/README.md`, руками не правится; для человека, в выгрузку не входит.

Это договор наблюдений [боевой приёмки](../qualification/README.md): свойства, которые судятся над переданными наблюдениями. Проверка не запускает, не ищет и не квалифицирует реализацию, и реализация её не импортирует.

`OBSERVATION_PASS` значит лишь, что переданные наблюдения прошли эту проверку. Это не родной прогон и не боевой результат.

## Исходы

Проверка кончается одним из четырёх исходов: проверки наблюдений прошли; наблюдение не соответствует норме; ошибка средства или формы; нет входов, и проверка называет конкретные недостающие привязки.

## Пробы

Группы — частичные срезы [групп случаев](../qualification/README.md#группы-случаев): проба не исполняет группу целиком.

| Имя | Свойство | Группы случаев | Бюджеты |
|---|---|---|---|
| `01-connections` | Пределы соединений и отказ сверх них | нет | `BUDGET_OVERFLOW_REFUSAL` |
| `02-input-drain` | Сроки фаз ввода и сырой слив | RUN-T01, RUN-T02, RUN-T03 | `BUDGET_IDLE`, `BUDGET_HEADERS`, `BUDGET_BODY`, `BUDGET_DRAIN` |
| `03-lock-wait` | Конечное ожидание замка изменений | RUN-L02 | значение `-leader-wait` |
| `04-barrier-replay` | Сбой барьера и повтор по тому же id | RUN-F03 | нет |
| `05-data-ownership` | Исключительное владение каталогом данных | нет | нет |
| `06-cost-id` | Стоимость записи и импорта, хранение id | RUN-W01, RUN-W02, RUN-W03, RUN-W04 | `BUDGET_WRITE_P99`, `BUDGET_WRITE_GROWTH`, `BUDGET_WRITE_BYTES`, `BUDGET_IMPORT_ORDINARY`, `BUDGET_IMPORT_WORST`, `BUDGET_IMPORT_GROWTH`, `BUDGET_MEMORY_ORDINARY`, `BUDGET_MEMORY_WORST` |
| `07-framing` | Сырое кадрирование HTTP | RUN-T02, RUN-H02 | нет |
| `08-backup-rows` | Строки копии и неполный вывод | RUN-L01, RUN-H01, RUN-H02, RUN-H03 | `BUDGET_BACKUP_ORDINARY`, `BUDGET_BACKUP_WORST` |

Проверки берут значения бюджетов из переданной записи наблюдений и таблицу бюджетов не читают. Привязка утверждённых значений, запуск стенда и сбор наблюдений — дело программы приёмки; этот каталог не добавляет поля profile, порта, флага или адаптера.
