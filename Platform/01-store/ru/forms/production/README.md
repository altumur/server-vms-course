# Данные стенда цели P/01/production

Текст производный от `forms/production/README.md`, руками не правится: источник — английский [`forms/production/README.md`](../../../forms/production/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Это данные стенда для [боевой квалификации P/01](../../../../common/ru/acceptance/spec/acceptance.norms.md#n6-боевая-квалификация-p01): только для судьи, не вход реализации. Исходов, чисел, маршрутов и флагов они не добавляют.

## Привязки

[`bindings.tsv`](../../../forms/production/bindings.tsv) даёт для каждой записи [`production.tsv`](../../../forms/production.tsv) активации её привязок D7 по [форме payload](../../../../common/acceptance/forms/d7-payload.schema.json). У дескриптора записи по [`d7.schema.json`](../../../../common/acceptance/forms/d7.schema.json) scope `P/01/production#<id>` и по одному provider на каждую возможность её строк. Его `identity`, `invoke`, `observer_ref`, `qualification_ref` и `source_pin` стенд пишет по provider, который он собирает и квалифицирует, и по прогону. У записи без квалифицированного provider для возможности её строк дескриптора для неё нет, и запись `not_executed` с этой возможностью как причиной (N6.5).

- `RUN-W03` и `prod-id-age`: `clock` в режиме `observe`, реальное ожидание с независимым наблюдателем часов; стенд часов не сдвигает.
- `prod-clock-group`: `clock` в режиме `control` над раздельными доменами стенных часов голосующих `s1`, `s2`, `s3`. Стенд, члены которого делят одни стенные часы, дать его не может, и тогда проба `not_executed` с причиной `clock`.
- `storage` называет носитель `ext4` — оболочку [первых утверждённых бюджетов](../../qualification/README.md#первые-утверждённые-бюджеты); tmpfs этим носителем не является.

## Вход N6.2

[`input.json`](../../../forms/production/input.json) — вход N6.2 по [`production-input.schema.json`](../../../forms/production-input.schema.json) без `source_pin`. Стенд добавляет `source_pin`, коммит Source прогона, прежде чем назвать файл в вызове. Поле, которого среда ещё не дала, отсутствует, и записи, которым оно нужно, `not_executed` с его именем как причиной (N6.5); значений не выдумываем.

- `budgets` нет, пока владелец не утвердит пороги.
- `manager` нет: срок остановки настоящего менеджера известен (systemd стенда), запас разборки ещё не измерен; стенд добавит объект, когда у него будут оба.
- `volume` нет: каталог ограниченного размера на объявленной файловой системе даёт только том хоста.
