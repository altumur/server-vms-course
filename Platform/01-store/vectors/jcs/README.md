# JCS (RFC 8785) — вектор

Владелец — урок P/01 (записка модуля, «Векторы»: первый договор, который пишет текст JSON, — хранилище); норма — ADR-0072
(канон подписанного документа — RFC 8785 целиком). Читают все, кто подписывает или сравнивает текст JSON байтами: тело
просьбы и digest ([P/06.4](../../../06-console/spec/06.4-console.norms.md) Н1.5), токен двери, подписи домена (уроки М11).

Пакет перенесён из `Source/tests/testdata/canonical_json.tsv` (стадия A) вместе с векторами урока 6 (стадия B; разбор ревью
стадии B 3–5, В5); байты таблицы прежние.

## `canonical_json.tsv`

Строка: текст JSON, как он может прийти; его форма RFC 8785; sha256 UTF-8 этой формы (hex). Реализация читает каждый вход,
приводит к канону и сравнивает обе колонки. Строки с `#` — заметки (в том числе обязательные случаи ADR-0072).
