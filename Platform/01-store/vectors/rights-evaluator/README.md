# Оценщик прав — вектор

Владелец — урок P/01, глава 1.2 (на стадии A норма — М10/6 Н1.2 `pattern`, Н1.3 «Оценщик»). Вход — файл прав
`rights.json`, выход — `expect.tsv`: строка `role action key expect`, `expect` — `allow` или `deny`.

**Прогон.** Раннер запускает свежее хранилище с `rights.json` как `{rights}` («Стенд» README приёмки М10/01) и на
каждую строку делает пробу сокетом роли: `read` — `GET /v1/get?key=<key>`, `write` — `POST /v1/write` `put`. `deny` —
`403 forbidden`, `allow` — любой иной ответ. Проверяется смысл оценщика, а не байты файла.

**Что покрыто:**
- точный образец (`acc/exact`), префикс (`acc/pre/*`: `*` только последним знаком);
- буквальные знаки: `*` не последним (`acc/a*b` — только ключ `acc/a*b`, не `acc/axb`), `!` не первым (`acc/p/!x`);
- `!` — отрицание пустого ключа, ничего не отнимает; `!*` — отрицание всего (роль `none`);
- права одного действия не дают другого (`write`).

Сверка python и go М10/6–11 («`*` в середине — буквально», обе реализации); решение «Архитектора» по журналу
cammeta-go, урок 6 № 2.
