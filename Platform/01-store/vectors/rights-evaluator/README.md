# Оценщик прав — вектор

Владелец — урок P/01, глава 1.2 (на стадии A норма — P/01.2 Н1.2 `pattern`, Н1.3 «Оценщик»). Вход — файл прав
`rights.json`, выход — `expect.tsv`: строка `role action key expect`, `expect` — `allow` или `deny`.

**Прогон.** Раннер запускает свежее хранилище с `rights.json` как `{rights}` («Стенд» [общего README приёмки](../../../common/acceptance/README.md); разбор ревью стадии B 3–5, № 33) и на
каждую строку делает пробу сокетом роли: `read` — `GET /v1/get?key=<key>`, `write` — `POST /v1/write` `put`, `delete` —
`POST /v1/write` `delete` (без `cas`; отсутствующая строка удаляется успешно, М10/1 Н3). Исход пробы:
- `deny` — `403 forbidden`;
- `allow` — только подтверждённый успех: у чтения 200 формы `Row` (в том числе `{items: null, index: ""}`), у записи и
  удаления 200 `Written`;
- 5xx, ошибка транспорта и иной ответ — неопределённый исход: проба не засчитана ни как `allow`, ни как `deny`, прогон
  не зелёный.

Проверяется смысл оценщика, а не байты файла (ревью стадии A: RA1-16, SA1-22).

**Что покрыто:**
- точный образец (`acc/exact`), префикс (`acc/pre/*`: `*` только последним знаком);
- буквальные знаки: `*` не последним (`acc/a*b` — только ключ `acc/a*b`, не `acc/axb`), `!` не первым (`acc/p/!x`);
- `!` — отрицание пустого ключа, ничего не отнимает; `!*` — отрицание всего (роль `none`);
- права одного действия не дают другого (`write`, `delete`): `delete` — свой список, у оценщика нет `delete = write`;
  пустой или отсутствующий `delete` — удалять нельзя (P/01.2 Н1.2).

Сверка python и go М10/6–11 («`*` в середине — буквально», обе реализации); решение «Архитектора» по журналу
cammeta-go, урок 6 № 2.

## Кто исполняет

Кто исполняет — хранилище (`01-store`: оценщик P/01.2 Н1.3, и у хранилища в процессе, P/01.1-22) — все строки, через дверь своих сокетов ролей. Не исполняют: агент в процессе (`09-agent`, P/09.1 Н1.11 `rights`) — права его компонентов проверяет хранилище в процессе; генератор прав установщика (`02-installer`, P/02.5 Н3 «сгенерировать_права» шаг 4) — своё правило покрытия образцов секретных строк, не оценщик действий; консоль (`06-console`, P/06.3) только ссылается на P/01.2 (ACC-VECTORS-CONNECT-03: строку исполняет роль, чья норма вызывает её функцию; решение «Архитектора» 2026-10-27).
