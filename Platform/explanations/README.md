# Пояснения моделей к модулю «Платформа»

Цельные рассказы об устройстве платформы и домена, написанные моделями по урокам курса. Это не спецификация: норм в них
нет, правила живут в нормах уроков `Platform/`. В выгрузку cammeta-specs каталог не идёт.

Имя файла — `<часть модуля>-<модель>.md`: часть `cluster` — кластер (уроки P/01–P/07), `domain` — домен (уроки
P/08–P/10).

Файлы перенесены из снятых каталогов `М10_Platform/` и `М11_Domain/` (стадия B). Ссылки на уроки и пути переведены на
уроки и главы `Platform/` по `Platform/common/id-map.tsv` на 7ab0c0d59: урок, нормы которого разошлись по нескольким
главам, назван списком глав. Имена модулей «М10» и «М11» в рассказе оставлены: М10 — кластер (P/01–P/07), М11 — домен
(P/08–P/10). Содержание — на дату автора и с уроками `Platform/` не сверено.
