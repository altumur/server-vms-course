======================================================================================================
What is true now: `domain.keys: [{id, keys, prefix}]` + `display.keys: {<id>: {title, about, absent}}` (the domain card's
«Ключи»; /spec carries `domain.keys` and `domain.shared`). `domain.shared: [fields]` — the fields whose domain-wide value
the domain holds; the document is `settings.shared.<sub>.<field>` (was `settings.defaults.<field>`, flat, any field;
the folder tree was `settings.folders`). The platform resolves (`shared.resolve`; `SharedView.effective` uses it) and
serves at the cluster console's `GET /domain/shared/<sub>[?unit=<id>]`; an edit with an undeclared field is a 409.
vms: shared [folders, alarms, events_retention_days]. The `from` labels are "unit" / "unit + domain rev N" (not "camera").
