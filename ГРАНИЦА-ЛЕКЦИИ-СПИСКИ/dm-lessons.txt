## (A) М10A 09 — the dictionary (М10A_Platform/09-SubsystemSpec.md)

М10A_Platform/09-SubsystemSpec.md:907 — абзац `domain` перечисляет ключи раздела; не хватает `names` и `edit`, `kept` описан только как строки, `tokens` без слов «токен прав не несёт». Предлагаемые строки словаря (таблица, как у прочих разделов; или те же слова в абзац):

| Ключ | Что значит | Кто читает |
|---|---|---|
| `ref`, `view` | поле, которым единица названа во всём домене; поля общего вида — оба из снимка | домен (`declared.directory`, вид домена) |
| `reports`, `witness` | объекты, которые член докладывает (`<sub>/<имя>`, префикс при `/`); семья «слышали в последний раз» | домен (`declared.reported_objects`, `witnesses`) |
| `books` | строки на держателе для каждого члена `domain/<sub>/<книга>/<член>`, которые его агент уносит домой как `domain/<sub>/<книга>` | домен (агент, `carry.py`) |
| `kept` | строки, которые подсистема держит на держателе для всего домена, `domain/<sub>/<имя>`; имя с `/` на конце — **семейство** строк `domain/<sub>/<имя>/<строка>`. Уходят в копию держателя и восстанавливаются переносом (`term.exported`), агенту запрещены построчно (`rights.agent_denials`: `!domain/<sub>/<имя>/*`) | домен (`declared.kept`, `term.py`, `rights.py`) |
| `tables` | строки из `kept` (не семейства), которые дверь домена отдаёт на чтение, `GET /domain/<sub>/<таблица>` | домен (`console.py`) |
| `names: {<семейство>/: {exclusive_with: domain/users, grant: <право>}}` | строки семейства из `kept` (со `/`) — **субъекты грантов** рядом с людьми домена. Человек не заводится под именем строки, строка не пишется под именем человека (`declared.NameTaken`); грант такому субъекту не шире `grant` (`view`, `edit`, `admin` — `access.RANK`; `declared.GrantTooWide`). `exclusive_with` — закрытое множество `{domain/users}` (люди курса лежат в `identity/users/<имя>`). Проверка — на каждой записи хранилища держателя, как его открывают процессы платформы (`declared.guarded`: `IdentityStore`, `DomainPublisher.publish_grants`, `set_domain_grants`, `runtime.federation_from_env`), — у воркера подсистемы ни строки | домен (`declared.refusal`), права (`<sub>domain` читает людей и гранты) |
| `tokens.<вид>: {lifetime, claims}` | вид токена в книгах: срок, имена утверждений. Токен прав не несёт: что может его субъект — дело грантов | домен (`DeclaredIssuer`, дверь токенов) |
| `edit` | поля единицы, которые дверь домена пропускает в правку строки члена (`PUT /domain/<sub>/<rows>/<ref>`); любое другое — 400 со списком, до вопроса члену и до хранения правки для молчащего кластера. Секрет — отказ при загрузке. Не сказано — в курсе пока решает консоль члена (см. отчёт: правило ADR «без `edit` — 400» ждёт `edit` в спеках продукта) | домен (`api.ConsoleAPI.update_unit`) |
| `keys: [{id, keys, prefix}]`, `shared` | семьи ключей для страницы; поля, чьё общее на домен значение держит домен | консоль (`/spec`: `domain: {keys, shared, edit, view}`), домен (`shared.py`) |

М10A_Platform/09-SubsystemSpec.md:923 — «там, где ключи — имена (поле, таблица, вид события, вид токена, семья ключей), стоит `*`» — ещё: семейство в `domain.names` (`domain.names.*.exclusive_with`, `domain.names.*.grant`).
