## a declared table or rows named like a console route is refused at load (w2cplatform/spec.py, CONSOLE_ROUTES)

where, resources, servers, domain, policy, unplaceable, events, metrics, marks, requests, mounts, drain, schema). A spec
whose `unit.rows` or a DECLARED table (`tables: {<t>: {key, fields…}}`) is one of them does not load ("… a route the
console answers itself (`/<t>`) — no request would reach that family"). A table only named (`tables: [x]`) is served by
nobody and is not refused by this rule. New test:
