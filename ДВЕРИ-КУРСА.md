# Двери курса: опись для плана дверей (ADR-0034 → ADR-0075)

Опись «Архитектора» по коду `Source/` на main 2026-10-12 (по поручению владельца). Дверь — HTTP-маршрут, RTSP или сокет,
который один процесс курса открывает другому, браузеру или камере. Форма строки — первая строка ADR-0034. Колонки
«при mTLS» и «порядок» — предложение описи, решение — ADR-0075. Парная опись продукта — `ДВЕРИ-ПРОДУКТА.md` в корне
продукта (24 двери, «Сборка», main 8872c18).

Роли сертификатов, которые уже есть: `urn:w2c:role:configstore` (вот), `urn:w2c:role:configstore-door` (дверь без голоса);
обе единоличные, из SAN URI, иначе CN `<роль>.<сервер>` (`tls.py`). Предлагаемые ниже роли — `urn:w2c:role:<роль>` по
имени процесса: `console`, `signer`, `domainagent`, `relay`, `resource`, `recorder`, `gateway`, `worker`, `detjob`.
Люди ходят токеном подписанта, не сертификатом; камеры — токеном `stream` сейчас, сертификатом устройства-члена потом.

Порядок: **1** — удостоверения нет совсем и дверь между серверами (первыми); **2** — удостоверение есть, но условное
(открыто без ключей домена или по переменной); **3** — удостоверение есть (подпись члена, токен), mTLS сверху как
второй слой; **4** — люди и браузер, остаются на токене; **5** — в процессе, провода нет (только в продукте).

## Первыми: удостоверения нет совсем, дверь между серверами
1. Ресурс: `/v1/objects` GET/PUT/DELETE, `PUT /mirror/`, `/events*` — запись и удаление объектов между серверами, в функции 0.0.0.0.
2. Рекордер `/spans/`, `/samples/` — дозапись и резерв между серверами.
3. Пиры ingest (в продукте HTTP; в курсе в процессе) — потоки между серверами одного кластера.
4. Воркер `/playback/*` вне домена и `/devices`, `/recordings/` — видео и состояние устройств другому процессу.

Та же четвёрка у продукта (`ДВЕРИ-ПРОДУКТА.md`): ресурс 8090, пиры ingest, открытые пути рекордера, RTSP и карты ipintd.

## Условные умолчания, которые закрыть независимо от mTLS (ADR-0012: умолчание, ослабляющее отсечение, выключено)
Гейт консоли открыт без `domain/keys`; DoorKeeper открыт без `door/keys`; playback открыт вне домена; `AUTH=0` у консоли
домена и domainpart; `X-User`/`X-Operator` как есть. Правило одно: без ключей — только петля, не «все».

## Только петля по построению
Порт raft без секрета; все unix-сокеты. Остальные «петли» — умолчание переменной (консоль, ресурс, WHEP, playback,
архив, jobs, RTSP-раздача), а подписант, консоль домена, ретранслятор и domainpart по умолчанию 0.0.0.0 — для плана это
«снаружи», не «петля».
