# Урок 13 (остаток к М12) — свидетель молчания у VMS

**Модуль:** М12A — Domain (остаток о VMS; платформенное — М11/11)

## Свидетель VMS: опрос приёмника

У VMS свидетель уже есть. Камера держит долгий опрос к приёмнику (М12B, урок 3), и держит его толкатель, другой процесс, чем агент. Спека записи объявляет:

```yaml
domain:
  reports: [polled/]
  witness: {report: polled, member_field: cam}
```

и приёмник публикует — с heartbeat'ом регистратора, в котором живёт (М12B, урок 3; ADR-0065, дополнение 2026-10-08), — когда каждый член его опрашивал последний раз (`rec/polled/<приёмник>`, `vms/domainpart/ingest.py`), — под именем члена, который опрашивал: это субъект его токена потока (`cam.polled_by`), например `cam-SN0`, и у члена остаётся самый свежий опрос. Возрасты — относительно времени самого объекта, чтобы разница часов сокращалась:

```python
    def publish_polled(self, objects) -> dict:
        now, cams = self.wall(), {}
        for c in list(self.cams.values()):
            if c.polled_at is not None and c.polled_by:
                age = round(now - c.polled_at, 3)
                cams[c.polled_by] = min(age, cams.get(c.polled_by, age))    # a member's freshest poll
        key = f"{POLLED}/" + "".join(ch if ch.isalnum() or ch in "._-" else "_" for ch in self.name)
        …
        objects.put(key, json.dumps({"cluster": self.cluster, "ingest": self.name, "ts": now, "units": cams,
                                     …}).encode())
```

**Объект — на приёмник, а не на кластер.** Приёмников в кластере бывает несколько (М12B, урок 3, шаг 7), и каждый знает только тех, кто опрашивает его. Один объект на кластер переписывал бы приёмник, которого камера не опрашивает, и, записав позже, делал бы живую камеру пропавшей (AZ). Продукт кладёт то же в heartbeat каждого регистратора (`polled_ago`) — тоже по одному на приёмник.
