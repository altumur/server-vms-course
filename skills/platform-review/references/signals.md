# Признаки нарушений в коде

Для каждого правила — что искать в diff. Это подсказки для поиска, а не замена правил: полный текст и причины — в `.cursor/rules/<файл>.mdc`.

## Словарь: общие термины правил → проект

| В правилах | В проекте |
|---|---|
| узел | сервер (слово «узел» упразднено, см. `GLOSSARY.md`) |
| токен ограждения, номер срока | эпоха единицы (`e<epoch>` в пути, `NextEpoch` по CAS), срок держателя домена (`term`) |
| аренда лидера | `Lease` (`Renew`, `MayWrite` по монотонному времени) |
| хранилище с консенсусом | переменные кластера (raft), запись через CAS |
| цикл согласования | `SpecController` / контроллер: размещение по строкам спеки |
| агент на узле | ресурс сервера, воркер |
| хост плагинов | воркер, загружающий DriverPack |

## service-boundaries.mdc

- Компонент читает чужие переменные или бакеты напрямую, а не через API или события. Особо: `w2cplatform/` импортирует `vms/` или знает слово «камера».
- Синхронный вызов, без которого вызывающий мог бы ответить.
- Цикл синхронных вызовов на пути одного запроса (консоль → контроллер → консоль).
- Общий модуль тянет доменные типы чужой части.

## messaging-contracts.mdc

- Событие названо командой или CRUD (`Update*`, `Set*`, `*Updated`), а не фактом в прошедшем времени.
- В конверте нет `eventId`, `eventType`, `occurredAt`, `version`, `correlationId`, ключа партиционирования.
- Событие от устройства без пары `occurredAt` (часы устройства) и `receivedAt` (часы шлюза).
- Удалено поле или сменён тип без новой версии типа события.
- Событие несёт только `{id}`, и все потребители тут же идут за данными.
- В теле события медиа, снимок, PII или секрет вместо ссылки с проверкой прав.
- Переход состояния зависит от доставки одного события.

## resilience.mdc

- HTTP, RTSP, сокет или обращение к хранилищу без таймаута (`http.Client{}` без `Timeout`, `requests.get` без `timeout=`, `context.Background()` на сетевом вызове).
- Бесконечный цикл повторов, повторы без backoff и jitter, повторы сразу на нескольких уровнях.
- Повтор неидемпотентной операции; повтор команды устройству без чтения его фактического состояния.
- `except Exception: pass` / проглоченная `err` на пути записи или тревог.
- Нет деградации при недоступной зависимости; изменение состояния кластера по устаревшим данным вместо явного отказа.
- Потребитель сообщений неидемпотентен; у очереди нет DLQ.
- Общий пул соединений или горутин на разные зависимости.

## observability.mdc

- Лог строкой без `traceId`, `service`, `eventType`; в логе токен, ключ, пароль, персональные данные.
- Асинхронный обработчик начинает новый трейс вместо продолжения.
- Нет метрик лага, глубины очереди, DLQ для нового асинхронного потока.
- Readiness опрашивает зависимости каскадно или падает из-за мягкой зависимости.
- Для контроллера нет метрик отставания согласования и расхождения желаемого и фактического.
- Для записи нет метрик разрывов архива по камере, недоступных устройств, отставания выгрузки, подавленных событий.

## consensus-and-leadership.mdc (платформа)

- Решение о размещении по кэшу, heartbeat'у или реплике, а не по линеаризуемому чтению с CAS.
- Запись в бакет или команда исполнителю без эпохи; исполнитель не отвергает меньшую эпоху.
- Срок аренды или таймаут по `time.Now()` / `time.time()` вместо монотонных часов (`time.Since` от монотонной метки, `time.monotonic()`).
- Через raft идут данные потока (события, сегменты), а не решения.
- Нет поведения при отсутствии кворума, или при нём компонент решает локально.

## control-and-data-plane.mdc (платформа)

- Плоскость данных (воркер, рекордер, шлюз) ходит к контроллеру или консоли на каждый запрос.
- Воркер останавливается, когда контроллер недоступен, вместо работы по последнему назначению.
- Логика «по событию перехода» вместо сравнения желаемого и фактического.
- Проход контроллера неидемпотентен: прерванный на середине даёт другой результат.
- Подписка на изменения без позиции возобновления или без явной ошибки при слишком старой позиции.
- Изменение формата переменных, heartbeat'а или путей без учёта версионного скоса Go (продукт `vmssubsystem`) ↔ Python (курс) и старых воркеров. Go-порта в курсе больше нет: скос сверяй с продуктом.

## sharding-and-backpressure.mdc (платформа)

- Неограниченная очередь, канал или список в памяти.
- Отбрасывание при переполнении для тревог или аудита вместо дисковой очереди и алерта.
- Перебалансировка по таймауту без явной остановки старого владельца.
- Нет квоты на арендатора; одинаковый ответ на отказ по квоте и по перегрузке.

## data-consistency.mdc (прикладные части)

- «Записал и отправил» двумя вызовами без outbox.
- Last-write-wins там, где потеря записи небезопасна; нет версии для оптимистичной блокировки.

## devices-and-media.mdc (сбор с устройств)

- Логика знает протокол или модель устройства, а не профиль возможностей.
- Медиа идёт через шину событий или через компонент, способный его задержать.
- Команда PTZ относительным сдвигом; повтор команды без чтения позиции.
- Переподключение без экспоненциальной задержки и jitter.
- Одна метка времени вместо двух; архив или поиск без явной шкалы времени.
- Раскладка тянет полный поток для всех камер.

## events-and-alarms.mdc (сбор с устройств)

- Одна очередь и одна политика для тревог, состояния и телеметрии.
- Тревога обрабатывается в порядке поступления, а не по классу.
- Дедупликация не по «устройство + тип + окно»; подавление теряет число повторов и границы окна.
- Событие, требующее реакции оператора, без состояния и срока эскалации.

## recording-and-retention.mdc (сбор с устройств)

- Путь записи ждёт сеть, центр, консоль или проверку прав у домена.
- Поведение при заполнении диска выбрано кодом по умолчанию, а не явной настройкой из ADR.
- Удаление по сроку или по кругу задевает материал, помеченный как доказательство.
- Удаление по политике не пишется в журнал; у фрагментов нет контрольных сумм.
- Доступ к живому видео, архиву или экспорту не логируется.

## plugins-extensibility.mdc

- Сторонний драйвер в процессе воркера или рекордера; нет лимитов памяти и времени вызова.
- Запись или тревоги не работают без плагина.
- Хост ждёт плагин без бюджета времени.
- Данные от плагина не проверяются на границе (размер, кодировка, частота).
- Ошибки и метрики без имени и версии плагина.
- Ломающее изменение SDK без новой мажорной версии.

## Документы: adr-format.mdc, doc-language.mdc, mermaid-diagrams.mdc

- Нет обязательных разделов MADR, `Confirmation` или хотя бы одного `Bad, because`; разделы переведены или переименованы.
- Класс системы не указан первой строкой `Context and Problem Statement`.
- Выдуманные числа, версии, имена вместо `[TODO: уточнить ...]`.
- Канцелярит («осуществляется», «в рамках», «данный», «функционал», «оптимизация»), пассивный залог, решение без причины.
- Диаграмма содержит сущности, которых нет в тексте; событие нарисовано `->>` вместо `-)`; для цикла согласования или медиапотока — sequence вместо диаграммы состояний или пути потока.
