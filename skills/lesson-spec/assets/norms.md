## Н0 Словарь слов

Нормативные слова — по [общему канону Н0]({{N0_LINK}}).

Пометки этого текста. «(только для судьи: …)» (в источнике — «(judge-only: …)») называет файл, его строку или случай,
которых нет в выгрузке модели (M); требование, которое он проверяет, названо в M по id в том же месте. `сц. NN` —
сценарий NN приёмки главы — только для судьи. Требование, абзац которого начинается меткой «**Охват: боевой.**»
(в источнике — «**Scope: production.**»; у пункта чеклиста — сразу после id), относится только к боевой квалификации
([боевая приёмка]({{PRODUCTION_LINK}})): функциональные ворота её не устанавливают; недостающий вход, бюджет или
привязка там — `blocked`/`NotExecuted`. Требование без метки обязательно для любой реализации, даже если его
