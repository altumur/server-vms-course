### Семьи данных (построены из источника)

Форма строк и объектов, которыми глава владеет по [каталогу](../../common/data/catalog.tsv), — из схем семей на [диалекте](../../common/DIALECT.md) (ADR-0088). Экземпляр строки — `{key, row}`, объекта — `{key, object}`; ключ — грамматика колонки `key` каталога. Поля `row` — значения `items` после [кодека](../../common/data/codec.tsv): писатель пишет строго, читатель читает терпимо (DIALECT § 8). Ключ вне таблицы — отказ `key`, иной отказ — `value`. Нечитаемо — строка не раскодировалась или не прошла схему в режиме читателя; исход — по таблице исходов семьи (DIALECT § 9): путь — префикс пути отказа (пустой — строка целиком), при нескольких путях отказа действует исход с наименьшим приоритетом.

#### `platform/spec/<sub>` — строка

Схема — [`spec-row.form.yaml`](../data/spec-row.form.yaml), исходы — [`spec-row.outcomes.tsv`](../data/spec-row.outcomes.tsv); версия формы 1; норма — P/02.3 Н1.5.

| Ключ | Тип и границы | Обязательность | Урок | Смысл |
|---|---|---|---|---|
| `yaml` | строка | обязателен |  | байты файла спеки как есть; загружаются по главе 2.1 (Н3 «загрузить») |
| `sha256` | строка; целиком `[0-9a-f]{64}` | обязателен |  | дайджест байтов yaml; читатель сравнивает запись как есть |
| `rev` | строка; целиком `[1-9][0-9]*` | обязателен |  | десятичное целое ≥ 1 — ревизия правила; первая установка — 1, затем +1 записью с cas по строке |
| `shell` | строка | необязателен |  | страница подсистемы (урок 9 Н1.1) или ""; отсутствие поля и "" — одно и то же «страницы нет» |

Исходы нечитаемой строки:

| Путь отказа | Исход | Приоритет | Единица | Норма |
|---|---|---|---|---|
| строка целиком | старт процесса: не старт, код 2, без перезапуска; spec put: отказ, ничего не пишет, код ≠ 0 | 1 | строка | P/02.3 Н3 «Старт процесса», Н1.5 rules, Н4 |
| `/yaml` | старт: загрузка отказана — не старт, код 2; spec put: отказ, ничего не пишет | 1 | строка | P/02.3 Н3 «Старт процесса» шаг 3, Н1.5 rules |
| `/sha256` | старт: «sha256 не совпадает» — не старт, код 2 | 1 | строка | P/02.3 Н1.5 sha256, Н3 «Старт процесса» шаг 2 |
| `/rev` | spec put: отказ, ничего не пишет; старт: не старт, код 2 | 1 | строка | P/02.3 Н1.5 rules, Н4 |

#### `platform/spec/<sub>/rev` — строка

Схема — [`spec-rev.form.yaml`](../data/spec-rev.form.yaml), исходы — [`spec-rev.outcomes.tsv`](../data/spec-rev.outcomes.tsv); версия формы 1; норма — P/02.3 Н1.5.

| Ключ | Тип и границы | Обязательность | Урок | Смысл |
|---|---|---|---|---|
| `rev` | строка; целиком `[1-9][0-9]*` | обязателен |  | то же число, что rev строки; пишется после строки, никогда не понижается |
| `sha256` | строка; целиком `[0-9a-f]{64}` | обязателен |  | тот же дайджест, что у строки |

Исходы нечитаемой строки:

| Путь отказа | Исход | Приоритет | Единица | Норма |
|---|---|---|---|---|
| строка целиком | старт процесса: не старт, код 2; spec put: отказ, ничего не пишет; работающий процесс: метка не по форме — тот же исход, что на старте: остановка с диагностикой (refused, имя строки), код 2, рестарт отказывает до исправления spec put; неподтверждённое чтение (хранилище не ответило) — не смена, процесс продолжает | 1 | строка | P/02.3 Н3 «Старт процесса», «Смена спеки», Н1.5 rules, Н4; решение «Архитектора» по пробелу Go P/02 № 1 |
| `/rev` | как строка целиком | 1 | строка | P/02.3 Н1.5 rules |
