## 7. Вопросы плана — решения «Архитектора» (2026-10-27)

1. **Имена и места.** Каждый стандартный файл самодостаточен: копии нужных `$defs` из общего — внутри схемы, без `$ref`
   между файлами. Файлы лежат рядом с нынешним файлом диалекта того же базового имени: `<семья>.schema.json` в `data/`
   урока-владельца; манифест — `02.1-installer.schema.json`, `02.1-installer.relations.json` (CEL) и
   `02.1-installer.layers.tsv` в `spec/` урока 02. `common.form.yaml` — источник генератора до перехода, после —
   `common.schema.json` справочно (пп. 1.1, 2.1, 5).
2. **`diagnostics.tsv`** — остаётся подсказкой: раннер строго сверяет только вердикт и код выхода, строки диагностики —
   в отчёт без провала (ADR-0092 п. 5; пп. 2.3.4, 3.1).
3. **`family-read`** — весь набор, один пакет `Platform/common/vectors/family-read`, таблица на урока-владельца семьи
   (01–06 сейчас, 08–10 добавятся); «кто исполняет» — роли, пишущие и читающие семью по каталогу (п. 2.5).
4. **Эталона слоёв на Go в навыке нет**: курс не несёт кода реализаций; реализации пишут слои сами и проверяются
   `family-read` и корпусом; урок D18 — строкой в README пакета (пп. 2.5, 4.1).
5. **`requests.schema`** манифеста — вне В7 (ADR-0087 доп. (9) п. 7): остаётся проверкой своего подмножества.
