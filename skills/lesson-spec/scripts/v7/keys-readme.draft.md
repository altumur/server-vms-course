# Черновик таблицы плейсхолдеров ключа каталога (V7-FAMILY-KEY-PLACEHOLDER-01) — для «Спецификации»

Временный выбор генератора c-go: литералы — точно, плейсхолдер — непустой компонент, корень и путь — несколько
компонентов. Грамматики уточняет «Спецификация» (`<sub>` — имя подсистемы P/02.1, `<id>` — id единицы P/06.1, …) в
`Platform/common/data/README.md`; до того тесты навыка кладут этот черновик в копию дерева. Форма — `v7.spec.placeholder_table`:
первая таблица с заголовком ниже; грамматика — переносимое выражение `^(?:…)$` на подстроку ключа, которую занимает
плейсхолдер (`|` в ячейке — `\|`); пример — по грамматике, из него строится столбец `key` пакета `family-read`.
