# Ревью ServerVMS: восьмой проход

2 октября 2026 · ревью по правилам `.cursor/rules` через скил `platform-review` · прошлое: [`РЕВЬЮ-SERVERVMS-7.md`](./РЕВЬЮ-SERVERVMS-7.md)

Прогон идёт частями, по мере того как автор сливает группы исправлений седьмого ревью:
- **часть 1** — двери и права на команды устройству на `da3a07d` (слияние `59bcf58`);
- **часть 2** — сетевой том;
- дальше — карта и толкатель, такт держателя и длинный опрос, битые строки и ответ автора `РЕВЬЮ-SERVERVMS-7-ОТВЕТ.md`.

Аутентификация дверей между процессами отложена до mTLS по решению владельца.

## Часть 1. Двери и права — итог

Из 10 проверенных находок седьмого ревью исправлено 6, частично 4. Новых находок 7: blocker нет, 3 major, 4 minor.

Главное:
- **Права на реле и пресеты обходятся.** Права теперь требуются на все камеры устройства, но «устройство» — это строка адреса как есть. Тот же видеорегистратор под другим написанием (регистр, порт по умолчанию, DNS-имя вместо IP, точка в конце имени) считается другим устройством. Через это снова открыта закрытая в шестом ревью находка про `source` на канал чужой камеры.
- **Предел консоли держится.** Для `/cameras` теперь нужно 8 атакующих адресов, для входа — 16; число совпадает с уроком. Но полосу мониторов в М11 может занять любой адрес из `10.0.0.0/8`.
- **Память держателя ограничена 64 МиБ** (было 503 МБ). Но этот бюджет может занять один зритель с `view` на одну камеру, и тогда воспроизведение всех остальных получает 503.

**Тесты на `da3a07d`** с `obsd` сборки (патчи 01–07):
- vmsserver — 825 прошли, 0 упали, 1 пропущен;
- М11 — 49 из 49;
- М12 — 235 из 235. Тест двери консоли домена на macOS проходит 6 раз из 6.

## Часть 1. Что сделано хорошо

- **`Bounds.take` делает «многих» записанным числом.** Замер совпал с уроком: 8 адресов — граница для `/cameras`, 16 — для входа. Указанный монитор отвечает при любом числе атакующих (53 из 53 при 24 адресах).
- **`ByteBudget` с учётом фактического куска.** Память держателя ограничена ~64 МиБ при любой нагрузке (146 МБ против 503).
- **Бакет ресурса через `Paced`.** 64 нечитающих читателя — +10 МБ, медленный пир получает бакет целиком.
- **Права после тела, по всем камерам устройства.** `scenario_cams` проверяет старую и новую строку, удаление тоже проверяется. Добавленная позже камера на том же NVR закрывает правку сценария тем, у кого нет прав на неё.
- **`/backfill`.** Одна строка на человека под CAS, `bool` отсечён явно, нижняя граница — и по хранению, и по покрытию.
