# P/07.1 — Синтетический демон: нормы (фикстура сверки)

## Н1 Форма

### Н1.3 Демон

Секрет демона — переменная `THING_TOKEN`.

**Флаги демона** — закрытый набор.

| Флаг | Тип | Умолчание | Смысл |
|---|---|---|---|
| `-dir` | путь | нет: обязателен, без него отказ старта, код 2 | каталог данных |
| `-limit` | целое > 0 | `32` | предел элементов |
| `-wait` | срок | `3s` | ожидание партнёров |
| `-root` | путь каталога | `/var/lib/thing` | корень состояния |
| `-gone` | без значения | выключен | флаг, которого сборка не знает |

## Н4 Отказы

| Причина | Код | `kind` и поля | Что делает вызывающий |
|---|---|---|---|
| ключ пустой | 400 | `badkey` | ничего |
| прав нет | 403 | `{kind: forbidden, error: "<роль> may not read <ключ>"}` | ничего |
| строка тяжелее потолка | 413 | `toolarge`, `limit`, `key`, `size` | ничего |
| версия не та | 409 | `conflict` | перечитать |
| демон: нет `-dir` | не стартует, код 2 | лог | править юнит |
