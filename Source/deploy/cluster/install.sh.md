# install.sh — make a machine a server of the cluster

**Role in the module.** Lesson 3. One script, on every server, from a checkout of the course: `deploy/cluster/install.sh [--spares]` as root on Linux, `deploy/cluster/install.sh --box <dir> [--spares]` as the box's user on macOS. It replaces what Nomad did as the installer of processes (`nomad job run …`): the code, the users, the store's rights and the units, the same on every server. What it does, in order:

1. **The code**: `Source/` — the one code root, М10's and М11's — copied to `/opt/w2c/Source` as a whole tree swapped in (`.new` → place, the previous kept as `.old`); `w2c-run.sh` to `/opt/w2c/bin/` (rm, then copy — never over a running script).
2. **The rights, checked**: `w2c-run.sh rights --check deploy/cluster/configstore-rights.json` — a file that is not what the spec generates now is refused, not installed.
3. **Configuration on the data partition** (the owner's decision): `/etc/w2c → /data/platform/etc` (w2c.env, `configstore-rights.json`, `tls/`, `secrets/platform.key`) and `/etc/vms → /data/vms/etc` (vms.env), as symlinks (`link_etc`). A real directory already at `/etc/…` is MOVED into `/data` first — nothing deleted; a file already there is kept, the moved one beside it as `<name>.from-etc`. A link that points elsewhere is left and said. Units and code say `/etc/w2c/…` and `/etc/vms/…`, never the target.
4. The rights file installed; the two env files from `systemd/*.env.example` when absent (never overwritten); warnings when this server has no TLS bundle (`w2c-ca.sh issue <server> configstore`, made on the operator's machine) or no `platform.key`.
5. **Linux**: `w2c-cluster.sysusers` and `.tmpfiles`; М10's `install-obsd.sh`, which installs and enables М10's obsd unit, and `vms-obsd.service` as an ALIAS of it (a symlink — the recorder's `After=vms-obsd.service` is that one unit, never a second daemon on the same socket); the units into `/etc/systemd/system`, enabled and started, `configstore` first — a subsystem's controller an instance of the platform's template (`w2c-controller@vms`, `w2c-controller@rec`: the file `w2c-controller@.service`, ADR 0023). `--spares`: the spares' templates (`SPARE_UNITS`: `vms-vmsworker-spare@`, `vms-recworker-spare@` — installed, never enabled; the twelfth review, blocker 6), the polkit rule `systemd/w2c-spares.rules` into `/etc/polkit-1/rules.d/50-w2c-spares.rules` (the spares' user may `start` those templates' instances and nothing else; the product's cross-check, 4 Oct), `w2c-spares.sh` into `/usr/local/bin` and М10's `w2c-spares*.{service,timer}` (run as `w2c-spares`), the recorders' and the camera workers' timers enabled.
6. **macOS — the box is a directory** (the thirteenth review, major 15, the decision aligned with the product): there is no /data on a Mac (the root volume is read-only, and the script failed at `mkdir /data`), so `--box <dir>` is REQUIRED — no default, refused without it — and it runs as the user who runs the box, not root. Everything goes under the box: the code (`<dir>/Source`, `<dir>/bin/w2c-run.sh`), the rights file `<dir>/configstore-rights.json` (checked the same way), `<dir>/w2c.env` and `<dir>/vms.env` written from the examples with the box's places in them (`/data/platform` → `<dir>/state`, `/etc/w2c` → `<dir>`, and the recorder's own volume `ARCHIVE_VOLUME=file://<dir>/state/vms/obsd/volume`), `<dir>/secrets/` and `<dir>/tls/` (0700; a bundle there handed to the user, `w2c-ca.sh own`), and `<dir>/state/` (the store's journal and sockets, the objects, the events archive, the logs, the spares' plists). A box whose longest socket path would not fit a unix socket (104 bytes) is refused before anything is written. The plists say `__BOX__`, replaced by the directory, `@HOST@` by this host's short name and `@BOXID@` by this Mac's IOPlatformUUID; they go to `~/Library/LaunchAgents` and are bootstrapped into the user's domain (`gui/<uid>`). `com.w2c.spares.plist` and `<dir>/bin/w2c-spares.sh` only with `--spares`. /data, /etc/w2c, /etc/vms and their links are Linux's; no `synthetic.conf`; the archive's engine is not installed here (the recorder reaches it at `<dir>/state/run/vms-obsd/obsd.sock`).
7. **The TLS bundle, the store's** (the thirteenth review, major 14): on Linux, after `configstore` is made, `w2c-ca.sh own /etc/w2c/tls configstore` — the files that user's, the keys and `raft.secret` 0600, the certificates 0644, the directory 0750 to its group. The bundle copied in as root, keys 0600, was a `PermissionError` for a daemon running as `configstore`, and the store came up on no server; group read would not do for the secret, which `tls.raft_secret` refuses when anybody but its owner may read it. A bundle copied in later is put right by running the script again.

## Notes
- It makes no certificates and starts no group: the first server's `w2c.env` has no `CONFIGSTORE_JOIN` (`-bootstrap`, a group of one), every other's names a member — lesson 2. A box's rows come over once with `configstore import --from file:///data/platform/config` (WP1).
- `tests/cluster/test_units.py::test_install_installs_the_units_there_are`: the units it lists are the units there are.
- `tests/cluster/test_units.py::test_on_a_mac_the_box_is_a_directory_named_to_the_installer_and_everything_goes_under_it` runs it on the macOS path with `launchctl` and `ioreg` shimmed: refused without `--box` and with a box too long, then everything under the box and the plists in the test's `~/Library/LaunchAgents`, bootstrapped into `gui/<uid>`.
- `Source/tests/test_deploy_units.py::test_a_bundle_copied_to_a_server_is_given_to_the_daemons_user_who_can_then_read_it`.
