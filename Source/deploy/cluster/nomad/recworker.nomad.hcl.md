# recworker.nomad.hcl — the appendix: the recorder as a Nomad service job

**Role in the module.** The appendix «форма поставки». The recorder as `vms-recworker.service` runs it — `w2c-run.sh recorder` as `vms`, `OBSD_SOCKET=/run/vms-obsd/obsd.sock` (the node's `vms-obsd.service`, host infrastructure like the configstore, not a job; `tests/cluster/test_recorder_job.py` holds the socket to М10's unit), `BOX_ID=${node.unique.id}` (`Source/tests/test_rec_volume.py` checks it) — placed only where a volume can be (`meta.archive`), the name from the allocation's index, `lost_after = "45s"`. The cluster's key is the node's file (`/etc/w2c/secrets/platform.key`), not a Nomad template — readable by `vms` through `w2c-secrets` (`vms-nomad.sysusers`). No `RESOURCE_ROOT`: its events go where the node's resource keeps them (`w2c.env`, `/data/platform/events`).
