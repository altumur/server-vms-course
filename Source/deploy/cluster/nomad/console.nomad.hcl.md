# console.nomad.hcl — the appendix: the console as a Nomad system job

**Role in the module.** The appendix «форма поставки». One console on every node, as `w2c-console.service` (a platform process, ADR 0014) — `w2c-run.sh console` as `w2c` (a platform process, ADR 0023), through the node's configstore. THE INSTALLATION IS A VARIABLE (`w2c_home`, default `/opt/w2c`), and М12 is why: a cluster in a domain runs the console from the domain's installation (`-var w2c_home=/opt/w2c-domain`), whose code can check a token; this module's, in a cluster whose store holds a key set, answers 503 to everything — the gate failing shut. `CONSOLE_MONITORS` lists the addresses that scrape (the node's loopback and address, and `monitors`), never a network. М12's tests read this file (`test_cluster_console_gate.py`, `test_lesson3_readview_api_gateway.py`).
