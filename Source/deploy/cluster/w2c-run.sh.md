# w2c-run.sh — what every unit of a cluster server runs

**Role in the module.** Lesson 3. The product's runner (`ExecStart=/opt/w2c/bin/w2c-run.sh <program>`), the course's form of it. Every systemd unit, every launchd plist, every spare `w2c-spares.sh` starts (from its role's template, `vms-<role>-spare@.service`) and a person at a shell run the same line, and get the same environment and the same code.

## What it does
1. **The environment from two files** — `/etc/w2c/w2c.env` (the platform's: `SERVER_NAME`, `LABELS`, `PLATFORM_DIR`, `OBJECTS`, `RESOURCE_URL`, the store's `CONFIGSTORE_*`, the spares' settings) then `/etc/vms/vms.env` (the subsystem's) — the product's split. A name is set only when it is not set already: what the UNIT said wins (its `PLATFORM_STORE`, its `WORKER_NAME`), and the platform's file wins over the subsystem's. That is why the units list no `EnvironmentFile=`: systemd lets a file override `Environment=`. A line is `NAME=value`, a name of letters, digits and `_`; `#` and blank lines are skipped, anything else is skipped too; a value is exported as it stands and never run (`load`).
2. `PYTHONPATH=/opt/w2c/Source` — the one code root (`W2C_HOME` names another installation — the appendix's console job uses it for a domain's). `SPEC_DIR=/opt/w2c/Source/vms` unless the unit says another — the specs the platform knows the subsystems by (`w2cplatform/catalog.py`: which objects are rows, how an address carries a login; the recordings' controller runs from it).
3. `configstore` → `python3 -m w2cplatform.configstore -id $SERVER_NAME -dir /data/platform/configstore -raft $CONFIGSTORE_RAFT -api $CONFIGSTORE_API -sockets /run/configstore -rights /etc/w2c/configstore-rights.json -tls /etc/w2c/tls -tuning lan` and `-bootstrap` when `CONFIGSTORE_JOIN` is empty, `-join $CONFIGSTORE_JOIN` otherwise — both count only the first time (a daemon taken into a group starts from its journal), so systemd restarting it with the same flags just brings it back. `CONFIGSTORE_SOCKETS` (the box's on macOS, 7 below), `CONFIGSTORE_DIR`, `CONFIGSTORE_RIGHTS`, `W2C_TLS`, `CONFIGSTORE_TUNING` override the defaults.
4. `worker|recorder|controller|reccontroller|console|resource|rights` → `python3 -m cluster <verb>`; `spares <role>…` → `w2c-spares.sh` with the two files read (a box on macOS: its plist runs this); anything else exits 2.
5. **A spare's set, one line** (the product's cross-check, 4 Oct). When the unit names a file (`SPARE_FILE`, the spare templates' `/run/w2c-spares/%n.env`, written by `w2c-spares.sh` under its own user), its FIRST line is read, and it must be `SPARE_FOR=<set>` — what the script writes (the thirteenth review, minor: the first such line anywhere in the file was taken) — and nothing else: every other line of the file, `LD_PRELOAD` or `PYTHONPATH`, never reaches the process. Checked against the labels' alphabet (`spec.LABEL_WORD`, comma-joined; empty is the empty set; the letters spelled out, not a locale's range). Another first line, no file, or a set outside the alphabet: exit 2, nothing run — and the worker spare's template does not restart on 2 (`RestartPreventExitStatus=2`). `SPARE_FOR` and `SPARE_FILE` are never taken from the two shared files (`load`).

6. **`umask 0007`** before anything (the thirteenth review, major 13): a unit says `UMask=0007`, but Nomad's `raw_exec` hands on the agent's 0022 — the events archive's buckets came out 2755 `vms:w2c-events`, the resource (`w2c`) could not delete them, and its retention stopped. The store's member alone gets `umask 0077` (the product's r28-ops2): its raft journal and snapshots are its own, 0600 — the unit's `UMask=0077` and the plist's `Umask` 63, which the 0007 would undo.
7. **A box on macOS** (`W2C_BOX`, the same review, major 15): the two files are `$W2C_BOX/w2c.env` and `$W2C_BOX/vms.env`, the code is under `$W2C_BOX`, and the store's member gets `$W2C_BOX/state/configstore`, `$W2C_BOX/state/run/configstore`, `$W2C_BOX/configstore-rights.json`, `$W2C_BOX/tls` — what it says itself still wins.

## Notes
- `tests/cluster/test_units.py::test_the_runner_reads_the_two_files_under_what_the_unit_said` runs it with a stub `python3`: the unit's socket wins, the files fill the rest, a `$(…)` in a value stays a value, and the daemon's flags come out as above.
- `tests/cluster/test_units.py::test_a_spares_runner_takes_only_its_set_from_its_file_and_refuses_one_outside_the_alphabet`: a hostile file's other lines ignored, bad sets, a file that does not open with the set, a missing line or file refused, the shared files unable to make a spare.
- `tests/cluster/test_units.py::test_the_runner_writes_as_its_group_however_it_was_started_and_finds_a_box_by_its_directory`: started under 0022 it execs under 0007; with `W2C_BOX` alone the box's files, code and the store's places.
