# w2c-console.service — the platform's console: the page and the API, on every server

**Role in the module.** Lesson 5. `w2c-run.sh console` (`python3 -m w2cplatform.cluster console`, a platform process: ADR 0014) as `vms`, joining `w2c-console`: the operator's rows and nothing else (the rights file); and the box's layout's groups (WP-E) — `w2c-events` (an operator's marks), `w2c-store`, `w2c-secrets` — with `UMask=0007`, `ProtectSystem=strict` writing only the events archive and the objects. `CONSOLE_UNIX` in `/run/w2c-console` (`RuntimeDirectory`, 0700) — the box's own door. The cluster's key as a systemd credential (`LoadCredential=platform.key:/etc/w2c/secrets/platform.key`, `SECRETS_KEY=%d/platform.key`): only this process sees it; three units load it — the console seals, the holder and the recorder open (`tests/cluster/test_policies.py`). `MemoryMax=256M`, the budget the console's blob limits were measured against. Its settings beyond its own lines come from `/etc/w2c/w2c.env` and `/etc/vms/vms.env`, read by `w2c-run.sh` UNDER what the unit says (no `EnvironmentFile=`: systemd would let a file override `Environment=`). `Restart=always`, `RestartSec=2`: a crash is systemd's to restart under the same name, on this server.

## Notes
- `tests/cluster/test_units.py`: each unit names its role's socket (`PLATFORM_STORE=configstore:///run/configstore/<role>.sock`), joins the group the rights file gives that role, runs `w2c-run.sh <verb>`, comes after `configstore.service`, as `w2c` (the resource) or `vms` (every other, the platform's console too).
