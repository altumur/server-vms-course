# __init__.py — the platform's domain: the layer above a set of clusters

**Role in the module.** The package docstring is the module's thesis: the smallest layer that can sit above a set of clusters, be switched off, and be the top of the product. Exactly three things a cluster cannot know — lookup across clusters, which cluster gets a unit, whether an answer is complete — plus the discipline of a layer that may be down: a signer that is the top of its own trust, identity that never reaches a worker, grants that expire per cluster, a server that joins with nobody typing a secret, and a read model that says how old it is.

**What it knows of the subsystems.** Their specs and nothing else (the boundary's «no hooks»): the `domain:` section of each `<sub>.subsystem.yaml` (`spec.DomainSection`, read through `declared.py`) says which units are in the directory and by which field, which objects a member reports, which rows a member carries home (books) and which the holder keeps and backs up, which tables the door serves, which kinds of token the signer issues. What a subsystem does on the domain — its books' content, its passes, its pages — is its own worker's and page's.
