# __init__.py — `w2cplatform.cluster`: what a cluster adds to the platform (М11_Cluster)

**Role in the module.** The package docstring is the module map for М11 — a cluster with no orchestrator (the owner's decision of 3 October): every server runs the same units, the platform's `configstore` daemon (a member of one raft group over the servers), its resource, console and controllers, and a subsystem's workers. It is part of the platform: it knows the subsystems by their specs and imports no subsystem (the boundary's step 7 moved it here from a top-level `cluster` package that re-exported the subsystem's classes). What it adds: the entry points by role (`__main__.py`), the rights file generated from the catalogue (`rights.py`), the contract's name and the in-memory fake (`variables.py`), the objects on every server (`objectstore.py`, `s3.py`), the directory (`directory.py`). It registers no store scheme: `configstore://` is the platform's own (`w2cplatform/configstorevars.py`).
