# Проверки нынешнего модуля консоли

Задача P07.19 продолжает принятый вариант Б P07.18: прямое свидетельство относится
к нынешнему канону, а пункт 1 «Implementation decides» не закрыт целиком.
Исходный срез этой правки — `391dab0af930be105516ba93f3d602f59896690b`.
Расхождение загрузчиков уже существовало на этом срезе; его происхождение разобрано
в принятом коммите P07.18 `c91832dbac457ce1c1c723781213f85d2d2a9f4a`.

## Запуск и вход

Из этого каталога:

```sh
npm install --ignore-scripts --no-audit --no-fund --package-lock=false
node canonical-current.test.js
sh run.sh
```

`run.sh` автоматически включает новый `canonical-current.test.js` по маске
`*.test.js`. Для восьми выбранных фикстур отдельный дочерний процесс получает
`PC_MODULE_SOURCE=canonical`. `module-source.js` читает только
`Platform/07-console-module/module/console.js` и печатает абсолютный путь и SHA-256
прочитанных байтов. Родитель сверяет их с нынешним файлом, требует успешный выход,
отчёт проверок, отсутствие FAILED, ошибок браузера и диагностики в stderr.
Смена канона не требует переписывать закреплённый хеш: проверяется файл того дерева,
в котором запущены тесты. Отсутствующий канон вызывает ошибку, отката к Source нет.

Обычный отдельный запуск выбранных `module-*.test.js` без переменной сохраняет
вход `Source/w2cplatform/console.js`. Поэтому прохождение прежнего запуска само по
себе не засчитывается за исполнение канона. Неизвестное значение переменной — ошибка.

Каждая выбранная фикстура вставляет прочитанный JS без переписывания в минимальную
страницу с `mount` и учебными подсистемами. HTTP заменён поддельным API. Это исполнение
нынешней библиотеки в jsdom, а не проверка настоящего HTTP, браузерной навигации или
страницы `console.html`. Замороженная оболочка из `boot.js` не загружается: фикстуры
всегда задают свой `CONSOLE_FILE`. Ни VMS, ни J-P07-01 в этот новый запуск не входят.

## Сохранённые долги и связанные места

R260 целиком этим набором не закрыт: safe-integer границы, сохранность элементов
списков, все scoped worker identities, обе пагинации и выключенные разделы требуют
своих полных проверок. Pending 0/1/null и outcomes остаются отдельной областью
`holder-page`/J-P07-01. Навигация `module-return` остаётся инструментированной
проверкой другого входа. R264/R266 требуют настоящего HTTP-сценария публикации,
а R277, R279–R280 и остальные части R278/R286 этим набором не закрыты.

`v1showsHidden`, R268, R283–R285, R292–R301 и пункты готовности P/07-07/P/07-08
сохраняют прежние открытые долги. Зелёный суммарный счёт не закрывает ни один из них.
Для предмета пункта 5 «Implementation decides» появляется прямое свидетельство
только о перечисленных случаях `module-changes` на каноне.

| Связанное место по lesson-spec | Результат |
|---|---|
| Подготовка и изоляция проверок | Изменено: явный источник, отдельные процессы, фикстуры каталога для CAS, нынешний порядок профилей |
| Перенос свидетельства между копиями | Изменено: канон проверяется отдельно; прежний Source-вход сохранён |
| Нормы, перевод, инструкция, история P/07 | Согласовано с принятым вариантом Б P07.18; нового поведения и закрытия долгов нет, тексты не меняются |
| Канон JS/CSS/HTML, замороженный модуль, J-P07-01, VMS | Не меняются: задача только о проверках курса |
| Выгрузка, HTTP-профиль и публикация реализации | Не относится: jsdom-проверки курса не являются входом генерационной линии и не исполняют её сервер |

Класс ошибки — неверный источник исполняемых байтов. Просмотрены загрузчики восьми
выбранных тестов, `boot.js`, `run.sh`, нынешний JS и строки N5/R258–R301.
Область других уроков не меняется. Механический `check_spec --scope platform`
проверяет структуру курса отдельно; его PASS не заменяет результат jsdom.

В проверке P07.19 канонический набор прошёл 8/8. Полный `run.sh` дал 45/46:
неизменённый `shell-short` сообщает `FAILED: backendLink, otherVersionSaid`.
Он исполняет канон оболочки VMS с заглушкой библиотеки; его входы равны исходной
базе, результат воспроизведён отдельно. Этот отказ не объявлен закрытым. Граница
требования задачи «тесты зелёные» при запрете брать VMS уточняется у автора задачи.
