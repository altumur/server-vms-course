#
#   <step> | <file>:<line> | <what> | <fingerprint>
#
# what         a word of the product's dictionary (test_boundary.PRODUCT_WORDS), `import <package>` (a subsystem's
#              package imported by a module of the platform or by a test of it — `via <module>` when through
#              another module of the code root), or `run <why>` (a piece of the platform that does not come up on
#              tests/testdata/testsub.subsystem.yaml alone; its file is `run:<piece>`).
# fingerprint  sha1 of the line's text, stripped, first eight hex digits ("-" for a run).

# step is the step of the plan (§5) that removes the line: 2 cam → unit; 3 the pages; 4 the strings, roles, fields
# and names wired in → the spec, obsd.py → vms/; 5 the common host from the spec catalogue and the platform's tests
# on testsub; 6 the hooks → spec/worker/page; 7 the platform's work done in a subsystem (here: the domain's access
# by name); 8 the motivation of a mechanism by video, in a comment of a module the memo's tables do not name. A
# comment's step is its file's owner in the memo's tables (console.html 3; obsd.py, secrets.py, configstore.py,

# step 2 wherever the platform says it, and so is the whole of eventdatabase.py's word `camera`.

# The test compares the COUNT of each (file, what) and fails on more (new) and on less (no longer true). Lines that
# moved or were edited keep their debt; `W2C_BOUNDARY_SHRINK=1 python3 tests/run.py` (or
# `python3 -m tests.test_boundary --shrink`) rewrites this file from what is found — lower counts only, each line
# keeping its step. It never adds a line.
