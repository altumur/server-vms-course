## Решено при написании М10/1 (структурные — «Архитектор», остальное — сессия)

Свидетели расходились; норма выбрана так:

1. **Версия на проводе — строка** десятичных цифр, `""` — отсутствие (Go); Python отдавал число в `get`/`list`/`conflict`/`guard` и принимал число в `cas`. Непрозрачная версия — строка.
2. **`cas` на проводе** — отсутствует/`null`, `""`, десятичная строка; иное — `400 badrequest` (Go). Python принимал число, `0` как `""` и «слово до 32 знаков» (`TORN`), отвечая 409; слово `TORN` — внутреннее дело файлового хранилища, на провод не выходит.
3. **Отказ стража** — `{kind: "guard", error, key, index}` в общей форме `Fault` (Go); ADR-0074 доп. 1 писал `{"error": "guard", …}` сокращённо, Python так и отвечал. Форма отказов одна.
4. **Страж раньше CAS** (Python). Go во всех трёх хранилищах проверял CAS первым; разница видна только когда нарушены оба. Выбран страж: его отказ значит «остановись», отказ CAS — «повтори».
5. **Повтор по `id` — та же запись целиком** (op, key, items, cas, guard; Python). Go сравнивал только op и key: иные items под тем же id получали ответ первого применения.
6. **`items` у `put` обязателен и только строки** → иначе `400 badrequest` (Go по типу; Python приводил значения `str()` и требовал объект). Строгость — безопасное умолчание (ADR-0012).
7. **`again: true`** в ответе на повтор (Go); Python поля не отдавал.
8. **`id`** — 1–64 строчных шестнадцатеричных знака (Go); Python принимал буквы, цифры, `-`, `_`.
9. **Предел ключа у двери — 1024 байта** (Go); у Python — 246 байт по имени файла; файловой реализации разрешён меньший предел, названный в описании.
10. **Память повторов**: не меньше двух минут и пока применено меньше 50 000 записей с id (Go: 2 мин / 65 536; Python: 50 000 без срока).

Расхождения по сторонам: Go — пп. 4, 5 (находки «Сборке» через «Архитектора»); Python — пп. 1, 2, 3, 6, 7, 8 (команда курса догоняет по приёмке М10/1, задача `inbox/2026-10-13-задача-adr-0080-после-adr-0074.md`).

## Решено при написании М10/2

Обе реализации читают один текст одинаково (таблица вердиктов зелёная на обеих до переноса); расхождений между свидетелями по 138 прежним случаям нет. Нормы сверх свидетелей и расхождения:

1. **Грамматика имени** `^[a-z][a-z0-9_-]{0,31}$` (та же, что у имён домена в загрузчике): оба загрузчика принимали `probe/two` и `Probe` — новые случаи `name_with_slash`, `name_uppercase`; расхождение обеих сторон (Go — «Сборке», Python — команде).
2. **Шесть новых случаев** без расхождений: `name_missing`, `name_reserved_platform`, `capacity_default_absent`, `empty_document`, `snapshot_said_nothing`, `default_and_inherit` — оба отказывают (проверено на обоих загрузчиках 2026-10-14).
3. **Строка спеки в хранилище, старт и смена** (ADR-0068, Н1.5, Н3): есть только у Go (`specstore.go`: `{yaml, shell, sha256, rev}`, метка `/rev`, выход при смене, `w2cctl spec put/status`); Python читает каталог файлов `SPEC_DIR`, строки `platform/spec/<sub>` и метки нет, смена спеки — перезапуск руками, отказ загрузки при старте — traceback (код 1). Расхождение Python — команде; нормы М10/2-12…14, 16; `shell` в строке — ключ страницы (урок 9), МОЖЕТ отсутствовать.
4. **Отказ при старте** — ненулевой код и строка лога с источником и путём; Go — выход 2 с логом, Python — необработанный traceback: форма — «решает реализация» п. 4, «не стартовать и не служить частично» — норма.
5. **`tie_break`** — закрытый перечень из одного слова на обеих сторонах; перечни размещения — урок 4.
6. **Приёмка загрузчика переносится** из `Source/tests/testdata/spec_verdicts*` в `acceptance/М10_Platform/02/` (решение записки: форма таблицы по двери). Прежние копии снимают: команда — `tests/test_spec_verdicts.py` и каталог, «Сборка» — `spec_verdicts_test.go` и `testdata/` после синка. До этого две копии живут один шаг; новые случаи — только в приёмке.

## Решено при написании М10/3

Свидетели расходились; норма выбрана так:

1. **Список с запятой в элементе** — принимается, хранится массивом JSON (Go); Python отказывал `400`. Ограничение шло от формы хранения, а не от предметной области.
2. **`required`** — задано и не `""`; `0`, `false`, `[]` — значения (Go); Python отказывал по `not value`.
3. **Типы значений у двери — строго** (ADR-0074 поправка C7 (2) для двери домена, та же дверь единиц): `"7"` и `1.5` у `int` — `400 not_number`; обе стороны приводили (Go `Refuse` вместо `RefuseValues`, Python `int(v)`). Расхождение обеих сторон.
4. **Грамматика имени** — объединение: `/`, `\`, `|`, `"`, `,`, `.`/`..`, пустое, Cc, Zl/Zp, цифры вне ASCII; Go не отказывал Zl/Zp и не-ASCII цифрам, Python — `\`. Обе стороны.
5. **Числовой id и повтор создания**: строка под зарезервированным номером уже есть — тот же create, `201` та же строка (Go); Python отвечал `409 taken over`. Номер, выданный отказанной попытке, не возвращается (обе).
6. **Слот: `server` при каждом захвате и продлении** (ADR-0045, Python); у Go строка слота без `server` (сервер берётся из пульса). Расхождение Go.
7. **Истёкший, но не отданный слот не берут** (ADR-0048, Python); Go брал истёкший без единиц самовольно. Расхождение Go.
8. **Порванная строка слота**: `until` дальше `now + 45 + допуск` — порвана (Go); Python так не судит — расхождение Python, проверяется чтением.
9. **Удаление `revision` не меняет; `GET /<rows>/<id>` нет** — обе стороны, закреплено.
10. **Форма заявки `idem`** — решает реализация (у сторон разные элементы), нормировано поведение.

Расхождения по сторонам: Go — пп. 3, 4, 6, 7 («Сборке»); Python — пп. 1, 2, 3, 4, 5, 8 (команде по приёмке М10/3). Не покрыто дверью `testsub`: числовые id, `fixed` над надгробием, `unique` — нужна вторая спека у раннера (открыто).

## Решено при написании М10/4

Свидетели расходились; норма выбрана так:

1. **`spec_rev` на строке размещения, страж правила, `spec_behind`** (ADR-0068, Go); в Python нет вовсе — расхождение Python (крупное, вместе с хранением спеки в строке из М10/2).
2. **Вес единицы** (ADR-0078, Go): нагрузка = Σ весов; в Python нет — расхождение Python (задача-зеркало уже стоит).
3. **Строка двери ресурса `platform/doors/<s> {url, since, at}`** с `at` каждые 15 с и состояние ресурса `unreachable` (ADR-0045, Python); у Go `{url, since}`, трёх состояний и исхода `wait` как «сервер неизвестен» нет — расхождение Go (исходы `unsure`/`wait` по ADR-0048).
4. **`names_given` привязан к версии строки слота** (Python, урок 1: версия и есть привязка); Go сверяет кортеж `{holder, until, gen, released}` — расхождение Go.
5. **Нехватка в отчёте — `short[]`** `{labels, units, workers, groups?, offered, withheld?}` (Go); Python — пять карт `units_short`/`workers_needed`/… — расхождение Python. Обязательные поля отчёта — Н1.2, остальное решает реализация.
6. **Вывод сервера: `gone: true`** подтверждает вывод никогда не слышанного (Go); Python выводил с предупреждением — расхождение Python. Слово отказа — `server answers` (Python); Go — `answers` — расхождение Go.
7. **Перебалансировка** — по запросу реализации, двери нет (ADR-0047) — обе стороны.
8. **Порядок прохода** — общий у обеих, закреплён; удаление неразмещённых — после дома, до предложений.
9. **Поправка 2026-10-14 (находка «Сборки» при окне «судьба слота»)**: `wait` — «ресурс жив, но о воркере ничего» (нет полей присутствия или воркер не перечислен, ADR-0048), а «сервер неизвестен вовсе» — два молчания → `move` (ADR-0045); в первой редакции Н3 было наоборот. Python судит «сервер неизвестен → wait» — расхождение Python.

Расхождения по сторонам: Go — пп. 3, 4, 6 («Сборке»); Python — пп. 1, 2, 5, 6 (команде). У Go нет теста на `spread_by` (находка «Сборке», не норма).

## Решено при написании М10/5

Свидетели расходились; норма выбрана так:

## Решено при написании М10/6

Свидетели расходились; норма выбрана так:

1. **Права чтения — положительные списки из спеки** (Python; ADR-0014 «чтение по роли», М11/05 «воркер читает свою долю»); Go даёт каждой роли `*` минус секретные префиксы. Расхождение Go — крупное (генератор, права чтения воркеров и контроллеров).
2. **Ресурс пишет только `platform/doors/*` и `<s>/requests/free-*`** (Python); Go — `*` минус `domain/*`, `platform/spec/*`. Расхождение Go; что ещё пишет ресурс (`mirror`, `space`) — назовёт урок 11 дельтой к Н1.4.
3. **Демон хранилища не в группах подсистем** — ролевые сокеты в setgid-каталогах владельца `w2c` (ADR-0030); обе реализации добавляют демона в каждую группу роли. Расхождение обеих (развёртывание; окно вместе с уроком 11).
4. **Роль сертификата = личность в хранилище** (`<sub>controller`, не `controller`; ADR-0075 «роль в сертификате равна роли процесса»); юниты Go ставят `W2C_ROLE=controller`. Расхождение Go. Имена ролей в тексте ADR-0075 (`vmsworker`, `controller`) — устаревшие, норма — `<sub>worker`/`<sub>controller`.
5. **Грамматика имени роли** `^[a-z][a-z0-9_-]{0,63}$` (Python); Go — только буквы и цифры. Расхождение Go (мелкое).
6. **Сертификат роли для дверей процессов** (ADR-0075 окно 1) — у Go комплект `roletls` есть, у Python только демоны. Расхождение Python — по окнам ADR-0075, не раньше.

## Решено при написании М10/7

Свидетели расходились; норма выбрана так:

2. **Секрет — только по суффиксу `_secret`**, строки платформы тоже (Python: `issuing_key_secret`, `seed_secret`, `pwhash_secret`); Go держит реестр `SecretRows` с полями без суффикса (`issuing_key`, `seed`, `pwhash`, `doc`). Расхождение Go (имена полей строк домена — закрывается с М12A). `door/signer {kid, seed}` — у обеих поле без суффикса: норма `seed_secret`, расхождение обеих.
3. **`w2cctl secrets rotate`** (ADR-0024, Go); Python — без `rotate`. Расхождение Python.
4. **Нечитаемое кольцо при заданном `SECRETS_KEY` — отказ записи** (Go); Python не различает «не задано» и «не читается». Расхождение Python.
5. **Маска на входе — множество знаков** объединено (Go шире: `∗⁎✱∙·⋅◦○⚫`); `a***b` — пароль у обеих.

Расхождения по сторонам: Go — п. 2 («Сборке»); Python — пп. 1, 3, 4 (команде, крупное — 1); обе — `door/signer.seed_secret`.

9. **Префикс против ключа у читателей секретов (2026-10-14, опись продукта):** Н1.3 уточнена — ключ с `/` на конце префикс, без — точный; продукт считал всё префиксами, и `domain/backup` закрывал `domain/backups/*`. Читатель `<s>/keys/` — по Н1.4 урока 6 (`<s>domain` читает свой префикс), решить в окне 7 по описи.

## Решено при написании М10/9

5. **`/healthz` → `{ok: true}`** (Python); Go — 404 — расхождение Go.
6. **`display.actions` снят** (ADR-0003: загрузчики проверяют, модуль и оболочки не читают) — обе стороны и спеки; **`display.held`** модуль читает, а загрузчики не знают — модуль чинится: слово единиц (команда — `console.js` в её дереве, продукт берёт синком).

## Проба мутаций (ADR-0080 доп. 6 п. 4)

Продукт, `windows/mutation-trial/` (main 3c4bb0fc): в досягаемости раннера двери выжили 63 из 161 (39 %), из них 14 должна была ловить приёмка — добавлены сценарии 19–22 (предел ключа, формы стража, права вне префикса, край тела); остальные 49 — вторые проверки автомата и вне урока. Решение 2026-10-14: одно окно хранилища Python по норме (baseline, версии-строки, V12, второй исполнитель через API без двери); в README приёмки добавлено правило — связываемое `$имя` значение ДОЛЖЕН быть строкой JSON (раннер продукта — «Сборке»).
