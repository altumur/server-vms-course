# V/11.16 — Шкала и события: нормы

Канон главы 16 урока V/11 «Бэкенд конфигуратора» (ADR-0080; модуль VMS — ADR-0090; прежняя глава V/11.16 урока «Страница VMS» — ADR-0118). Лекция (`ru/11-backend.md`, для человека, в выгрузку не входит),
[инструкция](11-backend.README.md), контракт — [`consolem.openapi.json`](../../consolem.openapi.json). Платформа — выгрузка
`cammeta-specs` `7a875c75` (пин VMS; глава написана на `8fc3aa2`; `where` без `door` — `d3f8e05`).

Текст производный от `spec/11.16-backend.norms.md`, руками не правится: источник — английский [`spec/11.16-backend.norms.md`](../../spec/11.16-backend.norms.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Шкала камеры — все её записи, в этом кластере и в других, со всех дверей регистраторов, которые что-то о них держат, и её события. Шкалу собирает `backend` (ADR-0112 доп. (13) п. 5, V/11.4 Н1.22), форма рисует страницы `GET /devices/{id}/timeline` и зовёт журнал. Глава нормирует правила: как держать дверь, как собирать шкалу, как называть недоступное, как ставить события и отметки. Проигрывание — глава 17.

Id норм — `V/11.16-MM`; соответствие прежним урокам — [`id-map.tsv`](../../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../../Platform/01-store/ru/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Секунды Unix; спаны двери — миллисекунды (`start_ms`, `end_ms`, V/02.5 Н1.5).

### Н1.1 Дверь держателя

Правила двери исполняет `backend` (V/11.1 Н1.2а, запись другого кластера — через консоль цели, V/11.4 Н1.22); браузер зовёт только адреса, которые вернул контракт: кусок, WHEP.

- Адрес и токен — `GET /<sub>/where/<id>` консоли ([P/06.5](../../../../Platform/06-console/ru/spec/06.5-console.norms.md) Н3) → `door:
  {url, token, expires, routes}`; дверь места — `GET /rec/where/<таблица>/<место>?unit=<запись>` (`unit` — id записи, без
  префикса подсистемы; иное — 400); запись другого кластера — через консоль этого: `/domain/at/<кластер>/rec/where/…`
  ([P/06.7](../../../../Platform/06-console/ru/spec/06.7-console.norms.md)); адрес куска браузер зовёт сам: источник этой консоли — в
  `CONSOLE_ORIGINS` кластера двери (договор файла окружения; V/09.2 Н1.2).
- Вызывающий держит дверь по адресу вопроса и берёт новую, когда до `expires` осталось меньше 20 с; запас — по часам браузера,
  расхождение часов закрывает 403 и один `where`.
- Токен — `Authorization: Bearer` для запросов, `?t=` для элемента видео (договор токена двери).
- Отказ токена — 403 `forbidden` (договор токена двери; V/02.5 Н1.5, V/03.3 Н1.1): вызывающий спрашивает `where` заново **один раз**
  и повторяет. 401 у двери — `no_role` (маршрут по роли), не токен: не повторяется. Элемент видео кода ответа не видит —
  его отказ ведёт по главе 17 Н1.1 (один повтор куска с новым `where`).
- Ответ другого кластера словами, и о записи, и о месте: 403 — «там вас не знают», 502 — «его консоль не видна по сети», 404 с
  `error` `no such member` или `no console known` (P/06.7 Н4) — «член отсюда не известен», 503 — «список членов здесь не
  читается»; его архив не показан, не утрачен. Иной 404 — ответ члена: как своей двери.

### Н1.2 Шкала

**Форма:** `GET /devices/{id}/timeline?from&to&limit&cursor`, страница до 500, при открытии закладки и по кнопке окна, таймера нет; «Показать дальше» — `nextCursor`. Спан рисуется со словами `backupOnly`, `source`, `epoch`, `fenced`; `unavailable` названо строкой. Поздний ответ прежней камеры или окна не рисуется. Сборку ниже исполняет `backend`.

Окна — час, 6 часов, сутки, всё. Источники:

1. записи камеры этого кластера (`rec/recordings` с её `cam`) и записи других кластеров по книге основных
   (раздел `ref`, V/11.4 Н1.22, элементы её `ref` с ролью `primary` или `backup` и `running`; V/02.9 Н1.6). Запись в домене — пара (кластер, id): id уникален только в кластере. «Не свои» — по члену: `member` ≠
   имени
   своего кластера (`cluster` ответа `GET /api/held`, P/06.7 Н1.12; не прочитано — свои узнаются по id записей этого
   кластера); чужие уникальны по (`member`, `recording`). Случай: своя запись `7` и запись `7` члена `m2` — обе на
   шкале;
2. для каждой — дверь записи: `GET <door>/timeline/<запись>?from&to` (V/02.5 Н1.5);
3. затем двери мест: каждое место таблицы мест `rec` (`places.table` манифеста) — `GET
   /rec/where/<таблица>/<место>?unit=<запись>` и `/timeline` там; у записи другого кластера — только её дом: `home`
   элемента книги (V/02.9 Н1.6), обход — `/domain/at/<член>/rec/where/<таблица>/<home>?unit=<запись>`; элемента без
   `home`
   обхода места нет; кластер отказал словами Н1.1 — дом не спрашивается: ответ будет тот же; иначе (404 члена, 200 без
   `door`, сбой двери) дверь записи не ответила, а `home` есть — место всё равно спрашивается.

Слияние — без близнецов по (кластер, запись, `start`, `end`, эпоха, источник), дверь самой записи — первой. Спаны записи на
резервном томе (и записи другого кластера с ролью резервной) уступают основной (`yields`): остаток — «только в резервном».
Спаны архива устройства (`yields`, источник `device`) — часть ответа двери записи без `stream` (V/02.5 Н1.5): архив камеры,
играет, в «только в резервном» не входит.

**«Закрепить»** — на минутах «только в резервном» и на минутах устройства. Форма склеивает их из спанов и шлёт `POST /devices/{id}/archive-fetch` на интервал (V/11.4 Н1.25); `backend`: `POST /rec/requests {unit: <запись основной>, from,
to}` (V/02.8 Н1.4; `unit` — id записи) на каждый интервал каждой основной. Основная — запись своего кластера той же камеры и
того же `stream`, что запись спана, с домом не на резервном томе и без `replica_from` (V/02.6 Н1.4); своей нет — кнопки нет. Интервал — минуты,
склеенные при зазоре до 3 с, границы наружу до целых секунд (ключ `{from:int}-{to:int}`). Часть просьб отказана — сказаны и
число поданных, и слова отказа; поздний отказ регистратора приходит в журнал `archive.backfill.refused`.

**Недоступное названо:** дверь не ответила или ответила не 200; поля тела `/timeline` (V/02.5 Н1.5): `unreachable`
(регистраторы), `unavailable` (тома записи без живого держателя, `<том>@<сервер>`); место 404 с `X-Unreachable` — «недоступно: архив не утрачен, лента может быть неполной»; `where` записи или места ответил
без `door` и не 404 — 200 по памяти (`lapse`: местоположение известно, допуска нет, P/06.5 Н3), 503 или не ответил —
запись или место названы недоступными. Место 404 без `X-Unreachable` («нет такого места») — молчание.

### Н1.3 События на шкале

**Форма:** `GET /journal?deviceId&from&to&limit=200[&source]` (V/11.3), перевод ниже; подписи, фильтр по подсистеме и переход к моменту — здесь.

- `GET /events?from&to&unit=cam/<id>&by=occurred&late=<с>` консоли ([P/06.4 Н1.3](../../../../Platform/06-console/ru/spec/06.4-console.norms.md)):
  окно — по времени события: `t` строки — часы писателя, находка по старому архиву записана сейчас, а `occurred` — о минутах
  окна. `late` — возраст конца окна (`now − to`, целое вверх), не меньше умолчания 3600: строка, записанная позже `to + late`,
  запросу не видна (договор слияния журнала событий `by`, C05-QUERY-LATE-01).
  События камеры и всех единиц «про» неё, слитые; поля ответа — по P/06.4 (`events`, `state`, `truncated`, `withheld`),
  иных `backend` не ждёт. `withheld` — единицы, чьи события права не смогли рассудить: метки единицы или группа не прочитаны (P/06.4): молчанием не роняются —
  недоступное названо, шкала и лента живого показывают строку «скрыто правами: события N единиц» (`N` — число единиц
  `withheld`; дополнение Kimi к разбору ревью V/08, вопрос 2).
- У события одно время — `occurred`, если поле есть (по наличию поля, не по значению), иначе `t`: засечка, края окна
  «всё», переход и список. Записанное позже на 2 с и больше подписано «записано в …»; отсечённая эпоха (`fenced`)
  выделена; `state` ≠ `live` и обрезка окна (`truncated`) сказаны; поля сверх полей журнала (`line` договора журнала событий
  и поля ответа P/06.4) — `ключ=значение`; фильтр по подсистеме. Случай: событие с `t` = сейчас и `occurred` три часа назад в окне «всё».
- Список — до 200 последних **по этому времени** (убывание, при равном — `id` по байтам UTF-8, как `cut` договора
  [слияния журнала событий](../../../../Platform/common/ru/contracts/events-merge.md)), а не по порядку ответа: классы в
  ответе
  идут группами (сначала `alarm`, затем `observation`). Случай: 201 строка `observation` — видна самая новая.
- **Отметка:** `POST /devices/{id}/bookmarks {note, occurred?}`, чтение `GET /devices/{id}/bookmarks?from[&to]` (V/11.4 Н1.24; форма шлёт `from` окна), поток `kind: bookmark`; засечки на шкале — по `occurred`. Отметка о прошлом лежит в бакете своего `t`, поэтому чтение идёт с `late` по тому же правилу: `now − to`, не меньше 3600.

## Н2 Двери

Своей двери у главы нет. Форма: `timeline`, `archive-fetch`, `bookmarks`, `/journal` контракта. `backend`: `/where`, `/events`, `/marks`, `/rec/requests`, `/domain/rec/books/primaries/*/<раздел>`, `/domain/at/…` — консоли (P/06); `/timeline` — дверь архива регистратора ([OpenAPI V/02](../../../02-rec/spec/02-rec.api.openapi.yaml)).

## Н3 Проход

```
форма: окно → timeline страницами → journal, bookmarks
backend: окно → записи камеры (свои + книга основных) → /timeline у двери каждой записи → у дверей мест (?unit=<запись>)
→ слияние без близнецов, своя дверь первой → уступка резервной, «только в резервном» → недоступное названо
→ события камеры (/events by=occurred, late от возраста окна), засечки по occurred
```

**Гонки.** Том сменил держателя между `where` и `/timeline` — дверь отвечает 403, один `where`: новая дверь, нет её — место
названо недоступным; 503 закрытого тома — названо сразу; следующее окно спросит снова. Токен истёк между вопросами — 403, один повтор `where`. Ушли с камеры (или сменили окно), пока шкала
строилась, — поздний ответ прежней форма не рисует (работа привязана к выбору, глава 17 Н1.2 п. 5).

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| отказ токена | `where` заново, один повтор | — | — |
| дверь записи или места молчит | названо недоступным | подпись шкалы | — |
| `where` без `door` не 404 (`lapse`, 503) | названо недоступным | подпись шкалы | — (следующее окно спросит снова) |
| тома записи без держателя | `unavailable` тела `/timeline` — названы | подпись шкалы | поднять регистратор |
| другой кластер отказал | словами по коду | подпись шкалы | — |
| события не читаются | «события недоступны: `<код>`» | подпись | — |
| часть событий скрыта правами (`withheld`) | «скрыто правами: события N единиц» | строка шкалы и ленты | грант на единицы |

Слова отказа — `Problem` контракта, `message` — только ошибке сети. Одно правило у всех отказов формы (главы 16–19).
