# Векторы: растр зоны детектора

Владелец — урок V/11 ([нормы главы 3](../../spec/11.3-backend.norms.md) N1.3 «`zone`»; ADR-0112 доп. (1) п. 3). Закрепляют `ZONE_MASK` = 256 и правило точки. Числа выведены по норме, реализацией не проверены. Прогон — с драйвером `backend`.

Текст производный от `vectors/zone-mask/README.md`, руками не правится: источник — английский [`vectors/zone-mask/README.md`](../../../vectors/zone-mask/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

## `cases.tsv`

UTF-8, LF, поля через TAB, первая строка — заголовок:

- `case` — имя случая;
- `shape`, `points` — поля `DetectorZone`;
- `count` — точек со значением 255;
- `sha256` — hex SHA-256 тела PGM: `P5\n256 256\n255\n` и 65 536 байтов растра, строки сверху вниз, в строке слева направо;
- `note` — пояснение.

Центр точки `(x, y)` — `((x + ½) / 256, (y + ½) / 256)`. Границы фигур в векторах через центры точек не проходят: проверено точным рациональным счётом, центров на рёбрах ноль, точка на границе нормой не судится. Вершины поэтому не круглые: диагонали круглых вершин идут по центрам.
