# Векторы: дайджест тела повтора createExport

Текст производный от `vectors/export-repeat-digest/README.md`, руками не правится: источник — английский [`vectors/export-repeat-digest/README.md`](../../../vectors/export-repeat-digest/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Владелец — V/11.20 Н1.2, правило дайджеста тела в [нормах главы](../../spec/11.20-backend.norms.md); хранимое поле — `body` таблицы `backend/repeats` из [V/11.4 Н1.4](../../spec/11.4-backend.norms.md). Пакет не меняет другие операции. Он изолирует вычисление дайджеста, а не приёмку HTTP-запроса или запись. Каждый пароль таблицы — синтетические тестовые данные.

## `cases.tsv`

UTF-8, LF, шесть полей через TAB; первая строка — заголовок. Ячейка читается побайтно между TAB; экранирование JSON принадлежит JSON и не разворачивается читателем таблицы.

- `case` — уникальное имя случая;
- `raw` — текст тела JSON для разбора;
- `canonical` — точный текст JCS после удаления только `password` и `supervisor.password`, без конечного LF;
- `sha256` — SHA-256 строчными hex от байтов UTF-8 поля `canonical`;
- `relation` — `-`, `same:<case>` или `different:<case>`, дополнительное сравнение двух дайджестов;
- `note` — причина случая.

## Обязательные сравнения

Случаев 16. Смена только паролей и отсутствие необязательного корневого пароля сохраняют дайджест. Порядок ключей объекта, пробелы, запись Unicode через экранирование и равнозначная числовая запись тоже его сохраняют. Сохраняемые имена, логин супервизора, значение камеры, порядок массива, граница периода и комментарий остаются во входе хеша. Если обоих исключаемых путей нет, канонизируется всё разобранное тело как есть; отсутствующий объект супервизора не создаётся.

Канон — RFC 8785 целиком, как в существующем [пакете P/01 JCS](../../../../../Platform/01-store/ru/vectors/jcs/README.md). Эти случаи не заменяют общие случаи соответствия сериализатора из того пакета.

## Исполнение и пределы

Драйвер векторов backend подаёт `raw` своему вычислению дайджеста тела createExport и сравнивает `canonical` и `sha256`, затем проверяет `relation`. Новые CLI, HTTP-операция или сигнатура функции этим не задаются. Совпавший вектор не доказывает права, надзор, исполнение выгрузки, гонки памяти повторов или её истечение. Автор проверил ожидаемые байты и хеши как данные; реализация backend или кластер не запускались.
