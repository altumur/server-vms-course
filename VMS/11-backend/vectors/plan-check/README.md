# Векторы инструментов и проверки плана — V/11.10, V/11.11

Векторы главы 10 (инструменты чтения, ответ админу) и главы 11 (план, сверка слов, вопрос и отказ) урока V/10. Их
исполняет драйвер `backend` (V/11.7 Н5) с данными харнеса [`harness/`](../../harness/) и заглушкой консоли по
файлу консоли ниже. Модели в векторах нет: вызовы инструментов даны готовыми.

## Файлы

| Файл | Что |
|---|---|
| `stand3.console.json` | консоль стенда 3 пилота: засев и манифесты обзора пакета передачи в форме дверей консоли урока (V/11.10 Н1.2) |
| `vms.console.json` | консоль VMS: манифесты канона `cam` и `rec` проекцией `ManifestView`, несколько камер, поток, записи; у админа `admin` на `*` |
| `text.json` | сверка слов V/11.11 Н1.2 — функция, аргументы, ожидание; `said` — выражения `rights`, `not_found`, `all` над `norm`, с русскими словами у границ (ADR-0093 доп. (28), (29)) |
| `cases.json` | ходы: тексты хода, секреты, вызовы инструментов по порядку и ожидаемый результат каждого |

## Консоль (`<имя>.console.json`)

Охват, корень и манифесты `backend` берёт по V/11.10 Н0, Н1.2: охват — подсистемы консоли
(или `subs` случая), корень — `mounts.root`, манифест — `manifests[<sub>]`; «в охвате ли» — есть ли подсистема в
консоли.

```yaml
mounts:     {root, mounts: {<sub>: ManifestView}} — корень и подсистемы консоли
manifests:  {<sub>: ManifestView} — копии модуля
rows:       {<sub>: [элемент configured]} — GET /<rows> у корня, GET /<sub>/<rows> у прочей: {rows: [], configured: …}
tables:     {<sub>: {<table>: [строка]}} — GET /<table> у корня, GET /<sub>/<table>: {<table>: […]}
session:    сессия модуля — для may() заглушки (страница её не читает)
schema:     ответ GET /schema
```

Иной путь — 404 `{error: "no_route"}`. `may(cap, ref, sub)` заглушки — правило модуля (P/07 Н1.5): аварийная сессия
(`via: break-glass`) и открытый режим — да; иначе грант ранга не ниже `cap` с областью `*`, `unit:<sub>/<id>` единицы или
её `about`-единицы, `labels:<…>` — все метки есть у `about`-единицы, если она есть, иначе у самой единицы (правило
`covers` модуля). Право записи — `may("admin", …)`
(V/11.10 Н1.2).

Отличия от стенда пилота: гранты `edit` подняты до `admin` (дверь записи строки единицы требует `admin`, ADR-0093 доп. (4)
п. 4); подписи полей и слова операторов пилота лежат в `display` манифестов (`fields`, `field_help`), а не накладкой;
не заданное поле без умолчания — `null`.

## Ход (`cases.json`)

```yaml
id:        имя случая
console:   имя консоли — файл <имя>.console.json
rule:      правило нормы, которое случай держит (или «переигровка основы пилота: <набор> <просьба> (<вид>)»)
violates:  есть — случай «нарушено, но проходит»: проверка его пропускает, причина словами (пробел замера, README урока)
source:    lesson — случай урока; pilot <набор> <просьба> — вызовы прогона основы пилота
texts:     тексты хода (V/11.9 Н0): просьба, затем ответы админа
secrets:   номера секретов, введённых в ходе (V/11.12 Н1.3); нет — секретов нет
session:   поля, которые заменяют session консоли (гранты, аварийная сессия)
fail:      {<путь>: <статус>} — эти чтения консоли отвечают статусом с {error: "unavailable", detail: "test"}
subs:      охват — подсистемы страницы, если не все подсистемы консоли
bulk:      {<sub>: N} — строки подсистемы дополнены до N копиями первой строки: id bulk-1, bulk-2, …, поле имени (если id
           манифеста не numeric) — тот же id, revision 1 (граница LIST_MAX, V/11.10 Н1.2)
calls:     [{name, args, content}] — вызовы по порядку в одном ходе; content — ожидаемый content результата (V/11.10 Н1.3)
```

Ход — один на случай: учёт найденного за ход (`find_units` → проверка `refuse`) и «раз за ход» (проверка «не найдено»)
идут по вызовам случая. Сравнение `content` — байт в байт. Цикл хода (подсказки, «сначала данные», `not executed`,
предел) — не здесь: векторы `turn` (V/11.9 Н5).

## Откуда ожидания

- **Переигровка основы пилота** (`source: pilot …`): все вызовы инструментов шести наборов стенда 3 прогона основы
  (v4.0 + `tool_choice: required`), кроме подсказки цикла «сначала данные». Перевод формы урока: слот секрета пилота —
  метка `{"secret": 1}`, пароль убран из текста просьбы (он — в поле формы). Вердикт совпадает с вердиктом пилота
  в 174 вызовах из 175; расходится L07 — `named: ["Spruce"]` при просьбе «Remove the label floor2 from all counters»:
  правило `named` (ADR-0093 доп. (4) п. 5) отвергает план, который пилот принимал (README урока, «Правки после замера»).
- **Случаи урока** (`source: lesson`): каждое правило V/11.10 Н1.5 и V/11.11 Н1.3–Н1.5 — хотя бы раз «нарушено» и «не
  нарушено»; формы «нет прав» по одной; классы «нарушено, но проходит» — с `violates`. Случаи `vms-*` — русские просьбы
  по манифестам VMS с подписями `display` и словами операторов `words.json`: «Выключи» называет «Включена», подмена поля
  отвергается; `vms-passes-days` — «дней» называет и `retention_days`, и `min_depth_days` (`violates`).
- Каждый `op` V/11.10 Н1.5 вызывается в аргументах корпуса (генератор векторов это проверяет); `gte` и `lt` — на
  меньшем, равном и большем значении.
- `content` построен снятым ядром страницы и сверен с нормой построчно; правка нормы или харнеса меняет векторы тем же
  коммитом.
