# Векторы переводчика нейтрального плана — V/11.13

Переводчик нейтрального плана в тело контракта (глава 13 Н1.4) и его отказы. Модели нет: план дан готовым. Ожидания выведены записью нормы, независимой от кода пилота `neutral/plan.py`; реализацией не проверены.

## Файлы

| Файл | Что |
|---|---|
| `cases.json` | `world` — камеры, дети, папки, расписания, режимы, роли, правила, как у [`rules-words`](../rules-words/README.md); `cases` — `{id, note, plan, body, errors}`: `plan` — нейтральный `edits`, `body` — `AssistRuleEdit` по порядку, `errors` — слова отказа перевода |

- `body` — только то, что переводчик выводит из плана: умолчаний `Rule` и `logOnly` нового правила здесь нет, их ставят перевод и запись (Н1.4, Н1.7).
- Id контракта — знаками `<вид>:<id мира>`: `device:<камера>`, `child:<ключ>`, `folder:`, `rule:`, `role:`, `schedule:`, `mode:`. Настоящий id — UUID по V/11.3 Н1.6, вектор его не судит.
- `errors` не пусты — `body` `null`: план не переведён, слои не судят.

**Предел:** круг строка → тело → нейтральная → тело → строка эти векторы не проходят: перевод тела в строку V/07 (V/11.3 Н1.3) здесь не судится. Двух устройств одного имени в мире нет: отказ `several devices are named` вектора не имеет.
