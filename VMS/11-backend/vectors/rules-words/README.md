# Векторы сверки слов правил — V/11.13

Сверка со словами просьбы (глава 13 Н1.6) и запреты (Н1.5) на случаях замера. Модели нет: строка плана дана готовой. Ожидания выведены записью правил главы над `harness/rules/words.json`, независимой от кода пилота; реализацией не проверены. Случаи с `known_gap` закрепляют предел: план неверен, а сверка его принимает.

## Файлы

| Файл | Что |
|---|---|
| `cases.json` | `world` — камеры (у строки `eventsrc` ещё `words`, V/01.1 Н1.1г), дети (реле без `name` — без имени), единицы `units` (строки `cam/device_units`: `key`, `camera`, `n`, `type`, `title?`), папки, расписания, режимы, правила, серверы, роли; `cases` — `{id, note, request, row | edits, errors, known_gap?}`: `row` — строка нового правила, `edits` — план целиком |

`errors` — слова ошибок: запреты Н1.5 раньше сверки, сверка — по порядку строк таблицы Н1.6, ошибка плана — с приставкой `edits[i]`; пусто — слои пройдены.

Строка плана — перевод нейтрального плана (Н1.4): слои судят строку, поэтому случаи даны строкой. `ask`, `escalate` составляются с ADR-0093 доп. (9): случаи `ask-*`, `escalate-*`; путь уровня — `<путь шага>.levels[k]`.

Слова ADR-0093 доп. (19)–(31): случаи `wait-still*` (п. 1 доп. (19)), `pass-*`, `open-*`, `on-numbered`, `ru-*` (реле прохода и номер, «открой», знак номера, русские основы с границей; `pass-lock-name` — имя вырезано до слов состояния, `pass-steps-order` — порядок конца «на N секунд»), `runrule-*` (запуск правила), `disarm-*`, `arm-*`, `armed-false-ru` (снятие только при «охран»), `relay-off-ru`, `record-ru-pisat`, `disable-*` (выключение камеры, «switch … off» со словами между), `vanish-*` («пропад»), `unit-*` (триггер `unit`, слово события с границами), `text-*` (триггер `text`). Текст сверяется в нижнем регистре, границы слова — по `tokens` (V/11.13 Н1.6).
