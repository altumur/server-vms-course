# V/11.1 — Единица, манифест, дверь: нормы

Канон главы 1 урока V/11 «Бэкенд конфигуратора» (ADR-0080; модуль VMS — ADR-0090; подсистема — ADR-0094 A1–A7).
[Лекция](../11-backend.md), [инструкция](11-backend.README.md), манифест [`backend.subsystem.yaml`](../backend.subsystem.yaml).
Платформа — выгрузка `cammeta-specs` `2110dbf` (пин VMS); нормы платформы B (ADR-0094 B1–B6) — после Go GREEN 01–10
(ADR-0094 «Порядок» п. 1): где глава на них опирается, место помечено «норма платформы B — после Go GREEN 01–10».

Подсистема `backend` отдаёт WebUI конфигуратора consolem (продукт) его собственный REST API — контракт
[`consolem.openapi.json`](../consolem.openapi.json) на закреплённом коммите (глава 2). Перевод — на сервере: воркер
`backend` получает запрос человека передачей консоли и зовёт двери консоли обратно по билету этого запроса. Своих прав,
своего входа и своих данных у воркера нет — права и правду решает консоль. Глава нормирует единицу, размещение,
манифест, передачу и то, как консоль отдаёт WebUI. Перевод видов — главы 3–4; билет и поток — глава 5.

Id норм — `V/11.1-MM`; соответствие — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

- **Контракт** — `api/openapi.json` consolem на закреплённом коммите; его копия — [`consolem.openapi.json`](../consolem.openapi.json).
- **WebUI** — набор байтов интерфейса consolem, который отдаёт консоль (Н1.4); в курс он не входит.
- **Передача** — `door.pass` консоли (P/06.5 Н1.8); **второй вид** — передача с билетом (ADR-0094 B1).
- **Билет** — 128 случайных бит, которые консоль выдаёт на один открытый запрос человека (B1; глава 5).

## Н1 Форма

**Время.** Сроки главы — секунды монотонных часов процесса.

**Данные** (общие семьи [каталога платформы](../../../Platform/common/data/catalog.tsv)): строка `backend/instances/<name>`
(P/06.1), пульс `backend/heartbeats/<воркер>`, снимок `backend/snapshot/*` (P/04 Н1.3а); своих семей сверх них у главы
нет. Строк других подсистем воркер сам не читает (`worker` манифеста без `reads`, `writes`, `requests`, `creates`): всё,
что нужно переводу, он читает и пишет дверями консоли по билету запроса (Н1.3).

### Н1.1 Поля и права

`unit: {rows: instances, id: name}` — строка `backend/instances/<name>`, `name` — имя сервера, который она обслуживает.
`about` у строки нет.

| Поле | Форма | Смысл | Кто читает |
|---|---|---|---|
| `name` | `string`, обязательно | имя сервера (`SERVER_NAME` ресурса, P/05), чья консоль отдаёт WebUI | размещение (Н1.2) |
| `enabled` | `bool`, умолчание `true` | `false` — держатель не отвечает на передачу: консоль отвечает 503 «no worker of backend with a door is heard» (P/06.5 Н1.8) | держатель |

- Строку заводит оператор на каждом сервере, чья консоль отдаёт WebUI (Н1.4); строки нет — на этом сервере WebUI не
  работает (`/backend/…` — 503 передачи).
- Права на строку — обычные права единиц (P/06.3): заводит и выключает `admin` кластера.

### Н1.2 Размещение: один на сервер, свой сервер

- **Один на сервер**, как модель `assist` (V/10.1 Н1.2): `placement.capacity` — 1, без `grows`; держатель несёт одну строку.
- **Свой сервер:** строка `backend/instances/<name>` стоит только на сервере `<name>`. Пока транспорт передачи — сокет
  роли воркера на сервере консоли (ADR-0094 B1, «транспорт»), воркер на другом сервере консоли недоступен. Строгое
  размещение по полю — `placement.home: {field: name, strict: true}`: единица только на сервере из поля, иначе
  неразмещена с причиной (ADR-0094 доп. (2) п. 1, B8; норма платформы B — после Go GREEN 01–10, P/04, P/02.1). До нормы B8
  манифест несёт `home: name` — предпочтение P/04 Н1.3, а строгая форма записана комментарием. Входа на набор меток нет: при
  сокете роли он смысла не имеет (ADR-0094 A2).
- После окна mTLS «консоль → воркер» (ADR-0075) — пересмотр к размещению по меткам рядом с `live` (ADR-0094 A2, решение
  владельца 2).

### Н1.3 Воркер без своих прав и состояния

- Удостоверения человека воркер не получает и не хранит: консоль передаёт запрос **без** `Authorization` человека, с
  билетом (ADR-0094 B1; норма платформы B — после Go GREEN 01–10). До нормы B1 передача `backend` не включается: вид
  передачи «с удостоверением» (нынешний `door.pass`) для `backend` не допускается (ADR-0093 доп. (1), ADR-0094 «Decision
  Drivers»).
- Обратный вызов — только по билету и только на двери **закрытого перечня**, который объявляет манифест (Н1.5).
- Своего состояния сверх памяти повторов группового `idempotencyKey` нет (глава 4; до нормы платформы B3).
- Своего входа нет: передача без сессии человека отвечает тем, что ответила сторожевая консоли (401 — WebUI идёт на вход
  консоли; ADR-0094 A4).

### Н1.4 WebUI: своя оболочка и статические файлы подсистемы (B7)

- WebUI consolem `backend` **не** отдаёт: его отдаёт консоль (ADR-0094 A3, доп. (1), доп. (2) п. 5).
- **Входная страница** — своя оболочка VMS [`backend.shell.html`](../backend.shell.html): канон наш, как оболочки прочих
  подсистем (`<sub>.shell.html` рядом с манифестом, ADR-0090 доп. (6) п. 8), под CSP консоли (P/06.5 Н1.1 `page`:
  `script-src 'self'` и хэши встроенных скриптов, атрибутов `on…=` нет). `index.html` продукта не используется: в нём
  приложение — встроенный скрипт и обработчики в атрибутах, под CSP консоли такая страница не отдаётся (P/06.5 Н1.1
  `shell`). Вынести приложение WebUI в файлы без обработчиков в атрибутах — запрос продукту (владелец); до ответа оболочка
  несёт рамку страницы, стили, шрифт и словарь, приложения в ней нет. Как консоль отдаёт оболочку смонтированной
  подсистемы `backend` (сейчас — только оболочку корня, P/06.5 Н1.1 `root`) — открытый вопрос урока (README).
- **Статические файлы** — механизм B7 (ADR-0094 доп. (1); норма платформы B — после Go GREEN 01–10, P/06.5, грамматика
  P/02.1): файлы рядом с манифестом по списку манифеста, адрес консоли `/backend/<файл>`, байт в байт, типы js, css, json и
  шрифты (html — нет), `script-src 'self'`; та же кука, сторожевая, Origin и `may`. До нормы B7 список — комментарием
  манифеста. Файлы — набор WebUI consolem на коммите `9dc16881cebf66286e2af1bfd7bd3224d676d483` без `index.html`: пять
  файлов — `assets/i18n-en.js`, `assets/one-psim/bridge.css`, `assets/one-psim/native.css`,
  `assets/one-psim/one-psim.css`, `assets/one-psim/fonts/InterVariable.woff2`, у каждого SHA-256. SHA-256 набора — SHA-256
  строк `<sha256 файла>␣␣<путь>\n`, упорядоченных по пути байтами (форма вывода `sha256sum`):
  `71b362ac879c7fabf83847040cb2c48ede3de0d467064ac0de3362333aaad94b`; построчно — [README урока](../README.md).
- Байты в курс не входят: это код продукта (репозиторий `github.com/ndm234234/consolem`). Пакет развёртывания кладёт их с
  закреплённого коммита рядом с манифестом `backend` и сверяет SHA-256 каждого файла (V/09.3, как `obsd` — собран из
  закреплённого коммита).

### Н1.5 Передача и перечень обратного вызова

- **Маршруты передачи** — первые сегменты путей контракта (глава 2): `door.pass` манифеста — `me`, `reference`,
  `domains`, `servers`, `devices`, `folders`, `archives`, `volumes`, `operations`, `rules`, `access`, `settings`,
  `licenses`, `journal`, `stream`, `test`, `objects`. Браузер зовёт их по адресу консоли `/backend/<путь контракта>`
  (смонтированная подсистема, P/06.5 Н1.1).
- **Ответ передачи** — только `application/json` или `text/event-stream`; консоль добавляет `X-Content-Type-Options:
  nosniff` и `Content-Security-Policy: sandbox`; иной тип — 502 консоли (ADR-0094 A3; норма платформы B — после Go GREEN
  01–10).
- **Второй вид передачи** (ADR-0094 B1; норма платформы B — после Go GREEN 01–10). Манифест объявляет — до нормы
  комментарием, ключи загрузчик сейчас не знает:
  - **поток:** маршрут `stream` — без предела 5 с и буфера 4 МиБ; билет потока годится только на чтения и `/changes`;
  - **предел ожидания по маршруту:** составная запись (`objects`, `devices`) — дольше `PASS_WAIT`, потолок — норма B1;
  - **закрытый перечень обратного вызова:** строки и таблицы `cam` (`cameras`, `devices`), `rec` (`recordings`,
    `volumes`), `det` (`units`), `auto` (`scenarios`); общие настройки этих подсистем — `<sub>/policy` и снимки настроек
    `cam`, `rec`, `det`, `auto` (ADR-0094 доп. (2) п. 6); лента `/changes` (B2); чтения `GET /manifest`, `/servers`,
    `/events`, `/session` (только «кто я»). **Не** входят: платформенные настройки (`/schema`, `/drain`, метки серверов),
    `/where`, записи `/session`, гранты, люди, ключи, break-glass, `/operations`.

## Н2 Двери

Своей двери, кроме передачи консоли, у подсистемы нет: `door.routes` пуст. Дверь API — контракт (глава 2) за передачей
консоли.

## Н3 Проход

```
держатель строки backend/instances/<name> на сервере <name> (P/03)
  enabled false → на передачу не отвечать (консоль — 503)
передача консоли /backend/<путь> (второй вид: билет)
  путь контракта → перевод (главы 3–4) обратными вызовами по билету из перечня Н1.5
  пути нет в контракте или «нет у нас» → 404 NO_ROUTE (глава 2)
  ответ — JSON или SSE; иное — 502 консоли
```

## Н4 Отказы

| Причина | Исход | Кто видит | Что делает вызывающий |
|---|---|---|---|
| строки `backend/instances/<сервер>` нет или `enabled: false` | 503 передачи консоли | WebUI | завести, включить строку |
| сессии человека нет | 401 сторожевой консоли | WebUI | вход консоли |
| ответ передачи не JSON и не SSE | 502 консоли | WebUI | — |
| обратный вызов вне перечня, после закрытия запроса, с чужого транспорта | 401 консоли (B1) | воркер, журнал консоли | — |

## Н5 Приёмка

Каталога приёмки у урока нет (`V/11 no-acceptance`): приёмка — тесты API consolem (`tests/api-*.js` на закреплённом
коммите) против стенда в профиле возможностей и `?selftest` их интерфейса (ADR-0094 Confirmation; глава 6).
