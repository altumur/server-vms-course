# V/11 Бэкенд конфигуратора — инструкция для реализации

Что реализация подсистемы `backend` делает и как проверить результат. Канон — нормы глав `11.K-backend.norms.md`; эта
инструкция их не дополняет. Платформа — выгрузка `cammeta-specs` `7a875c75` (пин VMS; приращение прав поверх норм B, ADR-0090 доп. (17); пометка «норма платформы B» — где глава на них опирается).

## Входы и их приоритет

- Канон — нормы глав `11.K-backend.norms.md` (Н1–Н5 каждой главы; адреса `V/11.K Н…`).
- Канон манифеста — [`backend.subsystem.yaml`](../backend.subsystem.yaml): байты как есть; блоки второго вида передачи
  (B1), статических файлов (B7) — комментарии до норм платформы.
- Канон оболочки — [`backend.shell.html`](../backend.shell.html): байты как есть; реализация её не генерирует.
- Контракт двери — [`consolem.openapi.json`](../consolem.openapi.json) (закреплённый коммит, SHA-256 рядом), не правится.
- Сопоставление видов — данные [`data/mapping.tsv`](../data/mapping.tsv).
- Харнес ассистента — данные [`harness/`](../harness/), каталог [`data/rule-catalog.json`](../data/rule-catalog.json): байты как есть.
- Приёмка — тесты API consolem на закреплённом коммите в профиле возможностей (глава 6) и свой набор [`acceptance/`](../acceptance/).
- [Лекция](../11-backend.md) объясняет причины; платформа — нормы выгрузки пина VMS по адресам `P/…`.

Противоречие записать с местом и контрпримером (раздел «При расхождении»); произвольный отказ не заменяет
отсутствующую норму. Устройство кода остаётся реализации в рамках канона.

Пакет подсистемы несёт исполняемый `/usr/lib/backend/worker` и кладёт рядом с манифестом семь файлов набора WebUI —
сборку consolem с закреплённого коммита (V/09.3); их отдаёт консоль статическими файлами подсистемы и сверяет SHA-256
каждого при отдаче (B7); оболочка `backend.shell.html` — канон урока: `index.html` той же сборки.

## Порядок

Сначала платформа с нормами B, затем `backend`: передача второго вида (билет) — условие включения
`backend`, нынешний `door.pass` с `Authorization` человека для него не допускается (V/11.1 Н1.3).

## Готово, когда

Манифест грузится строгим загрузчиком без правок; тесты API consolem в профиле возможностей проходят на платформе с
нормами B; операции «`NO_ROUTE`» отвечают 404 без обращений к консоли; пункты чеклистов, отмеченные «чтением»,
подтверждены описанием реализации (раздел «Решает реализация» каждой главы).

## При расхождении

Порядок источников: нормы главы → контракт consolem и таблица сопоставления → тесты продукта → лекция; платформа — нормы
выгрузки пина VMS. Норма молчит или противоречит себе — вопрос «Спецификации VMS» с местом, контрпримером и
предложением; контракт — вопрос «Консоли», форк наш (ADR-0112); норма платформы — через «Архитектора».
