# V/11 Бэкенд конфигуратора

Статус: **перевод начат** (2026-10-29, «Спецификация VMS»; план принят «Архитектором»): главы V/11.1–V/11.6 — нормы.
Основание — ADR-0094 (A1–A7, доп. (1), (2); B1–B8 — нормы платформы после Go GREEN 01–10).
Платформа — выгрузка `cammeta-specs` `2110dbf` (пин VMS). Манифест — [`backend.subsystem.yaml`](backend.subsystem.yaml)
(канон; ADR-0090 доп. (6) п. 8). Источники — сессия «Консоль»
(сравнение с consolem, набросок адаптера; справка, не канон).

## Что такое урок V/11

Подсистема `backend`. Продукт утвердил интерфейс конфигуратора consolem — WebUI и его контракт с сервером, REST API
`api/openapi.json`. `backend` отдаёт WebUI этот API, переводя каждый вызов в двери консоли платформы. Перевод — на
сервере, но у воркера нет ни своих прав, ни удостоверения человека: консоль передаёт ему запрос с **билетом** на этот
один запрос, и воркер зовёт двери консоли обратно по билету, только из закрытого перечня (ADR-0094 B1). WebUI отдаёт сама
консоль: своя оболочка VMS `backend.shell.html` и файлы набора продукта (стили, шрифт, словарь).

## Приёмка

Каталога приёмки у урока нет (`V/11 no-acceptance`): приёмка — тесты API consolem (`tests/api-*.js` на закреплённом
коммите) против стенда в профиле возможностей и `?selftest` (ADR-0094 Confirmation; глава 6). Профиль — список урока
(V/11.6 Н1.2), до ответа продукта об объявлении возможностей:

| Файл тестов продукта | В профиле | Почему |
|---|---|---|
| `api-read.js` | частично | чтение разделов, 404 неизвестного, `/test/*`; чтения `NO_ROUTE`-разделов (папки, права, лицензии, настройки) — вне |
| `api-hardware.js` | частично | `PATCH` устройства, 428/412/422, пароль только на запись; групповые операции (`/operations`) — вне |
| `api-domains.js` | вне | домены, серверы и папки создаются и правятся не у нас (`NO_ROUTE`) |
| `api-storage.js` | частично | хранилища и тома; занятый диск, форматирование, проверка подключения — вне |
| `api-devices.js` | частично | добавление, групповое изменение, удаление с дочерними; определение модели, поиск в сети, детектор шагом операции — вне |
| `api-bulk.js` | целиком | групповое удаление, правка выборки |
| `api-rules.js` | целиком | правило целиком с версией |
| `api-access.js` | вне | права — ADR-0094 C |

Случаи «частично» — по операциям таблицы V/11.2 Н1.2; список сверяется при новой версии контракта.

## Открытые вопросы

1. **Оболочка смонтированной подсистемы** (V/11.1 Н1.4): консоль отдаёт только оболочку корня (`CONSOLE_ROOT`, P/06.5 Н1.1);
   `backend.shell.html` при корне `cam` не отдаётся — расширение B7 («оболочка смонтированной подсистемы на `/<sub>/`»)
   или иной способ — слово «Архитектора».
2. **Приложение WebUI файлом** (V/11.1 Н1.4): вынести встроенный скрипт и обработчики в атрибутах `index.html` в файлы
   набора — запрос продукту (владелец); до ответа оболочка без приложения.
3. **Индекс надгробия удалённой части** (V/11.4 Н1.1): как консоль отдаёт индекс хранилища надгробия (B4: `ETag` строки;
   у удалённой — ?) — слово «Архитектора» к норме B4.
4. **Эталонный набор стенда** (V/11.6 Н1.3): набор продукта у нас невыразим целиком; свой набор — данными урока после
   стенда B.
5. **Версия сборной камеры** — вопрос продукту (ADR-0094 Consequences); до ответа — наибольший индекс (ADR-0094 доп. (2)
   п. 4).
6. **Объявление возможностей и профиль тестов** — запрос продукту (владелец; ADR-0094 «Порядок» п. 4).
