# V/11 Бэкенд конфигуратора

Статус: **переведён** (2026-10-30, «Спецификация VMS»; план принят «Архитектором»): главы V/11.1–V/11.7 — нормы; стенд —
после норм платформы B. Основание — ADR-0094 (A1–A7, доп. (1)–(9); B1–B7, B9 — нормы платформы после Go GREEN 01–10).
Платформа — выгрузка `cammeta-specs` `d3f8e05` (пин VMS). Манифест — [`backend.subsystem.yaml`](backend.subsystem.yaml)
(канон; ADR-0090 доп. (6) п. 8). Источники — сессия «Консоль»
(сравнение с consolem, набросок адаптера; справка, не канон).

## Что такое урок V/11

Подсистема `backend`. Продукт утвердил интерфейс конфигуратора consolem — WebUI и его контракт с сервером, REST API
`api/openapi.json`. `backend` отдаёт WebUI этот API, переводя каждый вызов в двери консоли платформы. Перевод — на
сервере, но у воркера нет ни своих прав, ни удостоверения человека: консоль передаёт ему запрос с **билетом** на этот
один запрос, и воркер зовёт двери консоли обратно по билету, только из закрытого перечня (ADR-0094 B1). WebUI отдаёт сама
консоль: оболочка `backend.shell.html` и файлы набора продукта (стили, шрифт, словарь); API — под `/backend/api/`.

## Приёмка

Каталога приёмки у урока нет (`V/11 no-acceptance`): приёмка — тесты API consolem (`tests/api-*.js` на закреплённом
коммите) против стенда в профиле возможностей; `?selftest` — проверка сборки продуктом под нашим CSP (ADR-0094
Confirmation; глава 6 Н1.4). Профиль — список урока
(V/11.6 Н1.2), до ответа продукта об объявлении возможностей:

| Файл тестов продукта | В профиле | Почему |
|---|---|---|
| `api-read.js` | частично | чтение разделов, 404 неизвестного, `/test/reset`, `/test/clock`, объявление возможностей; чтения `NO_ROUTE`-разделов (папки, правила и срабатывания, права, лицензии, настройки), `/test/events` и ожидание `test.reset` — вне |
| `api-hardware.js` | частично | `PATCH` устройства, 428/412/422, пароль только на запись; групповые операции (`/operations`) — вне |
| `api-domains.js` | вне | домены, серверы и папки создаются и правятся не у нас (`NO_ROUTE`) |
| `api-storage.js` | частично | хранилища и тома; занятый диск, форматирование, проверка подключения — вне |
| `api-devices.js` | частично | добавление, групповое изменение, удаление с дочерними; определение модели, поиск в сети, детектор шагом операции — вне |
| `api-bulk.js` | целиком | групповое удаление, правка выборки |
| `api-rules.js` | вне | «Автоматизация» не объявляется (ADR-0094 доп. (7)): правила, расписания, режимы, окна обслуживания |
| `api-access.js` | вне | права — ADR-0094 C |

Случаи «частично» — по операциям таблицы V/11.2 Н1.2; список сверяется при новой версии контракта.

## Открытые вопросы

1. **Эталонный набор стенда** (V/11.6 Н1.3) — свой, данными урока **после стенда B** (ADR-0094 доп. (3) п. 10 (4)).
2. **«Автоматизация»** (V/11.2 Н1.2, V/11.3) — отображение нового `Rule` на сценарии `auto` — отдельным решением (вторая
   очередь C, ADR-0094 доп. (7)); до него `recordMode` `motion` и `sched` не объявляются (V/11.3 Н1.3; разбор ревью V/11,
   вопрос 2).
3. **Код инфраструктурного 5xx** (V/11.2 Н1.3): в `ProblemCode` закреплённого контракта нет кода для 502, 503, 504
   (консоль, хранилище или память повторов недоступны) — запрос продукту через «Консоль» (разбор ревью V/11, вопрос 5).
4. **Версия, которая может вернуться** (V/11.4 Н1.1): потоки камеры и записи тома входят в версию живыми строками —
   их надгробий по камере или тому не найти; создание и снятие такой строки мимо `backend` возвращает прежнюю склейку
   при той же видимой записи. Строгое «не возвращается» продукта здесь не держится.
5. **Срок памяти повторов** (V/11.4 Н1.4): `delete_after` у таблиц в грамматике P/02.1 нет — норма платформы B; до неё
   строки `backend/repeats` живут без срока.
