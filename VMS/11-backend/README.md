# V/11 Бэкенд конфигуратора

Статус: **перевод начат** (2026-10-29, «Спецификация VMS»; план принят «Архитектором»). Основание — ADR-0094 (A1–A7; B —
нормы платформы после Go GREEN 01–10). Платформа — выгрузка `cammeta-specs` `2110dbf` (пин VMS). Манифест —
[`backend.subsystem.yaml`](backend.subsystem.yaml) (канон; ADR-0090 доп. (6) п. 8). Источники — сессия «Консоль»
(сравнение с consolem, набросок адаптера; справка, не канон).

## Что такое урок V/11

Подсистема `backend`. Продукт утвердил интерфейс конфигуратора consolem — WebUI и его контракт с сервером, REST API
`api/openapi.json`. `backend` отдаёт WebUI этот API, переводя каждый вызов в двери консоли платформы. Перевод — на
сервере, но у воркера нет ни своих прав, ни удостоверения человека: консоль передаёт ему запрос с **билетом** на этот
один запрос, и воркер зовёт двери консоли обратно по билету, только из закрытого перечня (ADR-0094 B1). WebUI отдаёт сама
консоль — закреплённым набором байтов продукта.

  `github.com/ndm234234/consolem` на коммите `9dc16881cebf66286e2af1bfd7bd3224d676d483`, байты как в репозитории;
  SHA-256 — [`consolem.openapi.json.sha256`](consolem.openapi.json.sha256) (`397a4e0f…ce50`).

## Приёмка

Каталога приёмки у урока нет (`V/11 no-acceptance`): приёмка — тесты API consolem (`tests/api-*.js` на закреплённом
коммите) против стенда в профиле возможностей и `?selftest` их интерфейса (ADR-0094 Confirmation; глава 6).

## Открытые вопросы

1. **Строгое размещение на свой сервер** (V/11.1 Н1.2): у P/04 есть предпочтение `home`, фильтра «только сервер, названный
   полем» без таблицы мест нет. Обойтись `home` до окна mTLS или просить фильтр — слово «Архитектора».
2. **`/test/*` вне стенда:** ADR-0094 A5 называет `404 NO_ROUTE`, контракт на закреплённом коммите — `404 TEST_SUPPORT_OFF`
   («служебные операции тестового стенда выключены»). Урок следует контракту (решение владельца 6: контракт не правим) —
   подтверждение «Архитектора».
3. **`recordMode` `motion`, `sched`, `replica`** (V/11.3 Н1.3): сопоставление с записью по событию и расписанию V/02 —
   глава 4, вопрос продукту о смысле.
4. **Версия сборной камеры** (`version` — одно целое, у нас — несколько строк) — вопрос продукту (ADR-0094 Consequences).
5. **`index.html` и B7:** тип html в перечне типов статических файлов B7 (js, css, json, шрифты) не назван — входную
   страницу WebUI консоль отдаёт типом html B7 или оболочкой подсистемы; слово «Архитектора».
6. **`/settings`** вне перечня обратного вызова B1 — `NO_ROUTE`; если WebUI без них не работает — расширение перечня
   решением «Архитектора».
