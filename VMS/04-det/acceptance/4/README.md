# Приёмка V/04.4 — детектор на стенде

Норма главы — [`04.4-det.norms.md`](../../spec/04.4-det.norms.md) Н5 (и главы 2, 3). Стенд и словарь — [общий README

## Подготовка

Хранилище, консоль кластера, контроллеры `cam` и `det`, ресурс `srv-a`; установлены манифесты `VMS/01-cam/cam.subsystem.yaml`,
`VMS/04-det/det.subsystem.yaml`, `VMS/07-auto/auto.subsystem.yaml`; консоль — `CONSOLE_ROOT=det` (дверь `/units`, `/events`),
`cam` смонтирован (`console2` — префикс `/cam`). Держатель камеры и воркер детекции — на `srv-a` (`@start worker`); метки
серверов не заданы — детекторы сценария без меток (`labels: []`). Камера — файл стенда `door.mp4`. Сценарий — на чистом
экземпляре.
