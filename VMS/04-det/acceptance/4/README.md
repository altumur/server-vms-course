# Приёмка V/04.4 — детектор на стенде

Норма главы — [`04.4-det.norms.md`](../../spec/04.4-det.norms.md) Н5 (и главы 2, 3). Стенд и словарь — [общий README
приёмки VMS](../../../common/acceptance/README.md) поверх общего README платформы (выгрузка `d3f8e05`, пин VMS).

## Подготовка

Хранилище, консоль кластера, контроллеры `cam` и `det`, ресурс `srv-a`; установлены манифесты `VMS/01-cam/cam.subsystem.yaml`,
`VMS/04-det/det.subsystem.yaml`, `VMS/07-auto/auto.subsystem.yaml`; консоль — `CONSOLE_ROOT=det` (дверь `/units`, `/events`),
`cam` смонтирован (`console2` — префикс `/cam`). Держатель камеры и воркер детекции — на `srv-a` (`@start worker`); метки
серверов не заданы — детекторы сценария без меток (`labels: []`). Камера — файл стенда `door.mp4`. Файл подсистемы `cam`
задан стендом через `W2C_SUB_ENV` (общий README приёмки VMS): `MEDIA_DIR` с `door.mp4`, `SHM_DIR` — каталог стенда (доля
кадров, V/01.2 Н1.3), поэтому детектор на сервере держателя идёт через долю (`via: shm`). Сценарий — на чистом экземпляре.

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-detect` | V/04.2-02, V/04.2-03, V/04.3-01, V/04.3-02, V/04.4-01 | учебная модель `tick` — `running` через долю; её строки — тревоги (`alarms: [tick]`) с `of` камеры в `/events`: две старейшие (`keep=oldest&limit=2`, договор `events-merge`) — `pass` 3 и 6 (журнал растёт, ожидание держит длину); детектор несуществующей камеры — `waiting` с причиной; неизвестный вид — `unsupported` |
