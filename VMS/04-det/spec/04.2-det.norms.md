# V/04.2 — Источник и модель: нормы

Канон главы 2 урока V/04 «Живая детекция» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../04-det.md),
[инструкция](04-det.README.md), манифест [`det.subsystem.yaml`](../det.subsystem.yaml). Платформа — выгрузка
`cammeta-specs` `84a28c6`.

Детектор работает, когда у воркера есть модель его вида и есть поток его камеры. Глава нормирует, откуда воркер берёт
поток, что такое модель для курса (реестр видов и учебная модель `tick`), фазы детектора и перезапуск по смене строки.
Раздача держателя — [V/01.2](../../01-cam/spec/01.2-cam.norms.md) Н1.3; приёмник — [V/02.9](../../02-rec/spec/02.9-rec.norms.md)
Н1.3; события модели — глава 3.

Id норм — `V/04.2-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Сроки — монотонные часы процесса.

**Данные** (общие семьи [каталога платформы](../../../Platform/common/data/catalog.tsv)): читает — строки `det/units/*`
своего назначения, тела масок `det/blobs/*`, строки камер `cam/cameras/*` (основа роли — строки `about`), пульсы держателей
`cam/heartbeats/*` и регистраторов `rec/heartbeats/*` (`worker.reads`: чужие пульсы основа роли не даёт,
[P/02.5 Н1.4](../../../Platform/02-installer/spec/02.5-installer.norms.md)); долю `cam.shm` (`worker.uses`); пишет — эпоху
`det/epoch/<name>` (P/03.2 Н1.5), пульс.

### Н1.1 Источник

Каждый проход воркер ищет источник каждого детектора назначения — по пульсам, раз за проход на все детекторы:

| Камера | Источник (`via`) |
|---|---|
| держатель на **своём** сервере: элемент `status[]` камеры в пульсе `cam/heartbeats/*` с `phase: running` и `live_shm`, поле пульса `server` = свой `SERVER_NAME`, пульс услышан за `LOST_AFTER` = 45 с | доля `cam.shm` — `live_shm` (`shm`); не открылась — RTSP петли `live_url` (`rtsp`), V/01.2 Н1.3 |
| держатель на **другом** сервере кластера; камера другого кластера (`cam: ref:<ref>`) | приёмник своего кластера: обращение «подписка» листом роли `detworker` (V/02.9 Н2; адрес — поле `ingest` пульса регистратора, услышанного за `PEER_LOST_AFTER` = 30 с: своего сервера, иначе первый по имени слота) — `ingest` |
| камера без потока (`kind: io`, адресов раздачи нет) | нет — `waiting`, `reason` `camera <cam> has no stream` |
| строки камеры нет; держатель не `running` нигде; приёмника в кластере нет | нет — `waiting`, `reason` `no camera <cam>`, `camera <cam> is held by nobody`, `camera <cam> is not running`, `no ingest in this cluster` |

RTSP чужого сервера — не источник (петля, ADR-0075 окно 2). Подписка на приёмнике — живой край, желание живёт, пока
детектор подписан, и ещё `LINGER` = 10 с (V/02.9 Н1.3). Источник открывается при запуске модели, один на детектор.

**Сверка** каждый проход: сменились источник (держатель переехал, другой адрес) или эпоха держателя, или источник мёртв
(8 с без кадра) — источник открывается заново по таблице выше; модель не перезапускается. Хранилище молчит — держится
последний прочитанный источник.

### Н1.2 Модель

- **Реестр видов** — свойство воркера: вид (`kind` строки) → модель. Модель получает кадры источника и настройки строки
  (`params`, тело маски) и отдаёт события `(kind события, поля)` (глава 3); кадров, тензоров и устройств наружу не отдаёт.
  Какие модели GPU есть у воркера — решает реализация.
- **Учебная модель `tick`** ДОЛЖНА быть у каждого воркера курса: работает на любом потоке без GPU; на каждом третьем
  проходе после своего запуска (третьем, шестом, …) отдаёт одно событие вида `tick` с полем `pass` — номер прохода с запуска.
  Кадры ей не нужны, источник — нужен: без источника `tick` молчит, как любая модель. Это приёмка детектора без GPU (глава 4).
- Тело маски (`mask`, V/04.1) воркер читает объектом `det/blobs/<digest>` при запуске модели; не читается — `failed`.

### Н1.3 Фазы

Эпоху детектора воркер берёт при взятии единицы ([P/03.3](../../../Platform/03-worker/spec/03.3-worker.norms.md) запуск
единицы; P/03.2 Н1.5) — до модели и источника: один писатель событий `det/<name>/…`. Эпоха не взята — единица не взята,
элемента в пульсе нет (форма P/03.4 Н1.1), повтор следующим проходом. Строки нет или надгробие — пропустить молча (гонка
назначения, P/03.3).

| `phase` | Когда | Что делает воркер |
|---|---|---|
| `running` | модель запущена, источник открыт | прогоняет модель, пишет события (глава 3) |
| `pending` | `enabled: false` | модель остановлена, источник закрыт; детектор виден |
| `waiting` | источника нет (Н1.1) | модель остановлена; `reason` — слова Н1.1 |
| `unsupported` | вида нет в реестре воркера | модели и источника нет; `reason` `no model <kind> on this worker`; модель, доставленная на воркер, оживляет детектор следующим проходом |
| `failed` | запуск модели или её прогон не удались (исключение, тело маски не читается) | модель остановлена; `reason`; повтор по отступу рантайма (P/03.3, `stalled` платформы); прочие детекторы идут — изоляция единицы |

Неизвестный вид — фаза, а не ошибка и не отказ создания: консоль не знает моделей воркеров. Слова подсистемы — в `reason`,
`why` — поле платформы.

### Н1.4 Перезапуск по строке

Ревизия строки выросла (`params`, `mask`, `kind`, `labels`) — модель останавливается и запускается заново
(P/03.3 Н3 шаг 2: рост `revision` — останов и запуск единицы); `enabled: false` — `pending` (Н1.3).

## Н2 Двери

Своей двери у главы нет: источник — доля `cam.shm`, RTSP держателя (V/01.2) или приёмник регистратора (V/02.9 Н2
«подписка»).

## Н3 Проход

```
пульсы cam/heartbeats/*, rec/heartbeats/* — по разу
для каждого детектора назначения (эпоха взята при взятии единицы):
  enabled: false → pending; вида нет → unsupported; источника нет → waiting (reason)
  модель не запущена → тело маски, источник (shm | rtsp | ingest), модель → running; не вышло → failed
  сверка источника: сменился или мёртв → открыть заново
  running → прогон модели, события — глава 3
ушедшие из назначения → модель и источник остановлены (рантайм P/03.3)
```

**Гонки.** Держатель переехал между проходами — модель до сверки получает кадры прежнего источника или их нет (8 с — мёртв).
Две модели одного детектора на двух воркерах (подмена) — у второго эпоха выше; первый видит потерю аренды (P/03.2) и
останавливается (`unconfirmed_max` — умолчание `off`).

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| камеры нет, держатель не `running`, камера без потока | `waiting`, `reason` | пульс | — |
| приёмника в кластере нет | `waiting` `no ingest in this cluster` | пульс | поставить регистратор |
| доля не открылась | RTSP петли | — | — |
| вида нет на воркере | `unsupported` | пульс | доставить модель или метки |
| модель упала, маска не читается | `failed`, `reason`, отступ | пульс, журнал воркера | — |
| эпоха не взята | элемента нет, повтор | журнал воркера | — |

## Н5 Приёмка

Фазы `waiting`, `running`, `unsupported` на стенде с учебной моделью — [приёмка 4](../acceptance/4/README.md) (глава 4); источник
`ingest` и `rtsp`, `failed` — чтением и тестом реализации.

---

## Решает реализация

Реализация обязана назвать в своём описании: **реестр моделей** воркера (какие виды кроме `tick`), **декодер** потока и как
модели подаются кадры.

## Соответствие прежним урокам

Из М10B/14 — шаг 2 (модель за двумя методами, реестр видов, модель без кадров наружу, учебная модель по расписанию), шаг 3
(проход: строки нет, `enabled`, неизвестный вид — `unsupported`, источника нет — `waiting`, эпоха до модели, остановка
ушедших). Отличия от свидетеля: источник — доля своего сервера, иначе приёмник своего кластера (у свидетеля — RTSP
держателя откуда угодно; ADR-0075 окно 2, решение плана 1); сверка источника и перезапуск по `revision` — нормой (у
свидетеля перезапуска нет); учебная модель — вид `tick` с событием `tick` (у свидетеля — подставная модель, отдающая вид
строки); `failed` — только под взятой эпохой, эпоха не взята — элемента нет (решение плана 5); слова — `reason`. Id
([id-map](../../common/id-map.tsv)): М10B/14 ш.3 → V/04.2-01; М10B/14 ш.2 → V/04.2-02; М10B/14 ш.3 → V/04.2-03, V/04.2-04.
