## Н1 Form

**Data** (the shared families of the [platform catalogue](../../../../Platform/common/data/catalog.tsv)): the heartbeat `det/heartbeats/<воркер>`.

### Н1.1 Heartbeat

The form is [P/03.4 Н1.1](../../../../Platform/03-worker/spec/03.4-worker.norms.md); the platform puts `server`, `instance`, `labels`,
`capacity`, `headroom` (capacity − Σ of the weights of the assignment), `conflicts` and the rest of its own. `det` MUST add:

| Field | Value | Meaning |
|---|---|---|
| `events_written` | an integer, a counter | the event rows written by the worker since start; it grows — the models work; it stands still while `running` — the models see nothing |
| `events_refused` | an integer, a counter | the rows that were not written: a write error or the lease is not confirmed (`may_write` is false; chapter 3 Н1.1) |

The names of the subsystem's top-level fields MUST NOT coincide with the platform's fields and with `platform_strings` (P/03.4 Н1.1): `events` there is a platform
string, therefore the detector's counter is `events_written`. `events` of an element of `status[]` is a subsystem field, it does not touch
the platform's names.

**The detector's element of `status[]`** (beyond the platform's fields; the epoch is taken — chapter 2 Н1.3): `phase` — `running` | `pending` |
`waiting` | `unsupported` | `failed` (chapter 2 Н1.3); `reason` — the subsystem's words (chapter 2 Н1.1, Н1.3), with `waiting`,
`unsupported`, `failed`; `events` — the rows of this detector written since the model started (a window summary is a row, the absorbed ones are not
counted), with `running`; `via` — `shm` | `rtsp` | `ingest` (with `running`, chapter 2 Н1.1). The detector has neither `url` nor device
fields: it delivers nothing.

### Н1.2 The series and `console.running`

`metrics: [{name: units_running, from: status.phase, agg: count, equals: running, live: true}]`, `console.running:
units_running` ([P/06.5](../../../../Platform/06-console/spec/06.5-console.norms.md) Н3 «/metrics»): the series `det_units_running` is
the detectors with a running model.

### Н1.3 Stop

The loop, the leases, the heartbeat and SIGTERM are the runtime ([P/03.3](../../../../Platform/03-worker/spec/03.3-worker.norms.md), P/03.4 Н3): each
model is stopped, the source is closed; the suppression windows are closed by P/03.6 Н1.2 `stop` (chapter 3 Н1.3); the last
heartbeat, the slot is returned. The stop timeout is the default of `worker.stop_timeout`. The detector has no state: the next
worker starts the model anew.
