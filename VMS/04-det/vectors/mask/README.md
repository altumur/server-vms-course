# Векторы: маска детектора — грамматика PGM и масштаб к кадру

Владелец — урок V/04 ([нормы главы 1](../../spec/04.1-det.norms.md) Н1.1 «Маска и размер кадра»). Участники — `detworker`
(маска детектора, V/04.2 Н1.2) и `detjobworker` (маска задачи скана, V/05.3 Н1.3): правило одно. Байты пишет «Спецификация
VMS» (решение «Архитектора» по второму кругу ревью «потоки камеры», п. 13). Прогон — после первой генерации стадии C,
прошедшей приёмку платформы (ADR-0090 доп. (8), (9)).

Кто исполняет — реализации подсистем `det` и `detjob`, каждая своей командой пакета (ниже); правило одно, пакет один:
`VMS/04-det/mask` (путь пакета в выгрузке без `vectors/`), отдельного пакета у V/05 нет — урок V/05 ссылается на этот.

## `cases.tsv`

UTF-8, LF, поля через TAB; строки с `#` — пояснения, пустые пропускаются. Пять полей:

- `case` — имя случая: `g-…` — грамматика тела, `s-…` — масштаб;
- `body` — байты тела маски: части через `+`, часть — шестнадцатеричная запись байтов или `<hex>*<n>` (байты `<hex>`,
  повторённые `n` раз);
- `frame` — размер кадра `<W>x<H>`; пусто — только разбор тела;
- `expect` — `refused` (тело не по грамматике: маска не читается, V/04.2 `failed`) или `ok <w>x<h>` (размер маски), а при
  непустом `frame` — `ok <w>x<h> <строки>`: маска, отображённая на кадр, — строки кадра сверху вниз через `/`, каждая —
  шестнадцатеричная запись `W` байтов;
- `why` — пояснение, не сравнивается.

## Команда пакета

Единая команда пакета векторов — по общему README приёмки платформы («Единая команда пакета векторов»): профиль реализации
`det` и профиль реализации `detjob` объявляют каждый `vectors` → `VMS/04-det/mask`: своя команда с `{input}` (её описание
называет команду, раздел «Решает реализация» инструкции урока). Вход — файл JSON `{format, package, table, case, variant,
cells, files}`: `cells` — `body` и `frame` строкой ячейки как в таблице (`body` — запись частей выше, байты из неё собирает
команда; `frame` — `<W>x<H>` или `""` — только разбор тела), `files` — пустой; ожиданий и `why` во входе нет.

Нативный исход — stdout команды: `{"result": "refused"}` или `{"result": "ok", "size": "<w>x<h>", "frame": [<строки кадра
hex>] | null}` (`null` — при пустом `frame` входа); код 0 — вычислено, 2 — вход не по форме (у строк пакета не ждётся: код 2 —
расхождение строки). Сравнение — по полям: у `refused` — ровно `result`; у `ok` — `result`, `size`, `frame`; лишнее поле —
расхождение; строки кадра — по байтам (регистр hex не важен). Строки пакета исполняет каждый из двух владельцев; нет записи
`vectors` у одного из них — цель `blocked`.
