## Что такое урок V/04

Подсистема `det`: детектор — единица «одна модель на одной камере» («пересечение линии на камере 7», `7-linecross`).
Воркеры детекции на серверах с GPU читают поток камеры, прогоняют модель и пишут события в журнал своего сервера с `of`
камеры: событие не подсистема — у него нет единицы работы, его место решено писателем. Ёмкость — в потоках, которые сервер
декодирует и прогоняет. Общее — размещение, рантайм воркера, журнал событий, классы, подавление, слияние событий для
страницы — нормы платформы по ссылке (P/…).

## Формы и двери

- **Строки и объекты:** `det/units/<name>`, тело маски `det/blobs/sha256-<hex>` (P/06.1 N1.5), пульс `det/heartbeats/<worker>`,
  события — журнал ресурса своего сервера `det/<unit>/e<epoch>/`, тревоги — `det.alarms/<unit>/e<epoch>/` (P/05 N1.2).
- **Двери:** своей HTTP-двери у `det` нет — строки дверью консоли (P/06.1), события — `/events` консоли (P/06.4); OpenAPI
  урока нет — строка реестра `V/04 no-openapi` (запросом с главой V/04.1).
- **Семьи данных:** поля строк событий детектора — [`data/det-events`](../data/) (учебная `tick` — `pass`; место — корень строки
  семьи событий платформы, деревья `det` и `det.alarms`; читают консоль и сценарии `auto`), строка — в каталоге VMS
  [`../common/data/catalog.tsv`](../../common/data/catalog.tsv); поля прочих моделей — реестр воркера, семьёй не судятся.
