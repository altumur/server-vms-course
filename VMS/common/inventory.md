# Опись слоя VMS: главы М10B, М12A, М12B → уроки `VMS/` и платформа

Первая задача «Спецификации VMS» (ADR-0090 доп. (4)); проверяет «Архитектор». Платформа — выгрузка `cammeta-specs`
`c9447b3` (курс `5d752c661`); адреса `P/NN.K Нx.y` проверены поиском по ней, `Platform/` курса не читался. Опись не
нормирует: она называет владельца каждой главы и шага, решение по каждому имени с «vms», путь работы `vmsjobs`, ключи
раздела `domain:`, пробелы платформы и расхождения уроков с её нормами. Перевод урока берёт отсюда свои строки; новое,
найденное при переводе, вносится сюда той же правкой.

Обозначения: `V/NN` — урок `VMS/NN-<имя>`; `P/…` — норма платформы по ссылке (в `VMS/` не переносится);
`P/? —` — платформенное, нормы в выгрузке нет (кандидат в запрос, § 6); «снять» — не переносится (причина в строке).
Правила доп. (4) — «п. N»; прочие основания — по ADR. Код реализации (пакеты, модули, классы, тесты, Quadlet свидетеля)
нормой не становится (ADR-0080) — такие строки собраны одной строкой в главе, а не по шагам.
