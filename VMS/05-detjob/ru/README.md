## Что такое урок V/05

Подсистема `detjob`: задача — одна модель на одном интервале одной записи («найти этот номер на камере 7 вчера с 10 до 11»).
Первая единица VMS, чья работа **кончается**. Воркер задачи читает видео из дверей архива регистраторов (V/02.5), прогоняет
модель того же реестра, что у детектора (V/04.2), пишет события в своё дерево с `of` камеры и кладёт итог в состояние
единицы; законченную задачу платформа не размещает, заказ через трое суток удаляет. Свой бюджет: ретро-поиск не тратит потоки
живой детекции. Заказчики — оператор, регистратор (скан дозаписанных минут, V/02.8 N1.5), сценарий (V/07).

## Формы и двери

- **Строки и объекты:** `detjob/jobs/<name>`, состояние `detjob/state/result/<job>`, `detjob/state/cursor/<job>` (P/03.6 N1.7),
  просьбы `rec/requests/<rid>` (подача), пульс `detjob/heartbeats/<worker>`, события — журнал ресурса своего сервера
  `detjob/<job>/e<epoch>/`, тревоги — `detjob.alarms/…`.
- **Двери:** своей HTTP-двери у `detjob` нет — строки дверью консоли (P/06.1), чтение — двери архива регистраторов (V/02.5)
  и перечень двери держателя (V/01.5) по сертификату роли `detjobworker`; OpenAPI урока нет — строка реестра
  `V/05 no-openapi` (запросом с главой V/05.1).
- **Семьи данных:** поля строк событий задачи — [`data/detjob-events`](../data/) (учебная `tick` — `pass`, `scan.partial` —
  `partial`, `waited`; место — корень строки семьи событий платформы, деревья `detjob` и `detjob.alarms`; читают консоль и
  сценарии `auto`), строки — в каталоге VMS [`../common/data/catalog.tsv`](../../common/data/catalog.tsv). Строки, состояние
  и пульс выражает манифест: пульс задачи другие процессы не читают.
