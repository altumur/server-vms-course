# VMS

Модуль уроков-спецификаций видеоподсистемы, нарезанный по подсистемам: один урок — одна подсистема со своим
манифестом (ADR-0090 доп. (2)). Каталог урока — `NN-<name>`, номер урока — адрес владельца (`V/NN`), карта —
[`common/lessons.tsv`](../common/lessons.tsv). Общее для всех уроков — [`common/`](../common/ru/README.md). Раскладка урока —
как у `Platform/` (ADR-0124): английский источник на каноническом пути — `README.md`, нормы `spec/`, формы `forms/`, данные `data/`, векторы `vectors/`, приёмка `acceptance/<K>/`; для человека, в выгрузку не входит, — `ru/`: лекция `ru/NN-<name>.md` и переводы английского текста тем же путём. Семьи
данных VMS — JSON Schema 2020-12 со слоями `Platform/common/LAYERS.md`, как у платформы (ADR-0092).

Текст производный от `README.md`, руками не правится: источник — английский [`README.md`](../README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Платформу уроки VMS читают только из выгрузки `cammeta-specs` на закреплённом коммите (ADR-0090 п. 2); правку
платформы просят файлом во входящих (п. 4). Пишет модуль «Спецификация VMS» по белому списку ADR-0090 доп. (1).

Манифесты и оболочка подсистем — **канон здесь**: `NN-<name>/<sub>.subsystem.yaml`, `<sub>.shell.html` (ADR-0090
доп. (6) п. 8). Урок V/10 `assist` — новый, свидетеля у него нет: подсистема и урок вписаны в
перечни ADR-0090 доп. (2), (3), (5) решением ADR-0093 доп. (2) п. 1.
