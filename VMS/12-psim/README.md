# V/12 Плагины psim

Статус: **нормы глав V/12.1–V/12.4** (2026-11-03, «Спецификация VMS»; план принят «Архитектором»); векторы генератора — после
ключа загрузчика `display.tables` (ADR-0115 доп. (11)), приёмка стенда — [`acceptance/4`](acceptance/4/README.md). Основание — ADR-0071 (плагины psim
через адаптер), ADR-0115 с доп. (1)–(15). Платформа — выгрузка `cammeta-specs` `7a875c75`; ключи загрузчика ADR-0115 — P/02.1
курса. psim-sdk `c3d9ebb` — только для чтения. Канонического манифеста у урока нет: манифест подсистемы строит генератор
из манифеста плагина.

## Что такое урок V/12

Плагин psim — чужой исполняемый файл с манифестом `plugin.json`: виды объектов с параметрами, события, команды, страницы.
У нас каждый плагин — подсистема `psim-<id>`. Генератор строит её манифест из манифеста плагина, воркер-адаптер запускает
процесс плагина и играет для него платформу psim, шаг установки ставит манифест и пересобирает манифест `backend`, чтобы
консоль VMS увидела новые виды. Страница настроек объекта плагина строится сама — по описанию вида (V/11); своя страница
плагина открывается рядом, его дверью. Сам плагин не меняется.

## Главы

| Глава | Что нормирует | Статус | Платформа и уроки |
|---|---|---|---|
| V/12.1 | Раскладка `plugin.json` → манифест подсистемы: имя `psim-<id>`, единица `units/plugin` (параметры, `enabled`, `readonly` в `unit.state`), вид — таблица с `id`, `plugin`, `parent`, `<т>_seen` для `readonly`, поле из параметра, подписи `{key, text}` и `display.langs`, `display.tables`, события `<т>.<id>` и класс по `severity`, команды просьбой, маршруты `PROXY`, владельцы `source` | нормы | P/02.1; ADR-0115 |
| V/12.2 | Генератор: функция каталога плагина и списка установленных, схема psim `c3d9ebb`, манифест и фрагмент `calls` с частями `enabled` и `objects`, владельцы `source`, отказ одной строкой | нормы | P/02.1; V/11.1 |
| V/12.3 | Адаптер: процесс как у хоста psim (`stdin`, учётка в памяти, готовность, остановка), сервер `Platform` на петле, `Configure`, `ChangeUnit`, команды и события, чужой плагин по `source`, дверь страницы — вход по `?t=`, кука сеанса, `static` | нормы | P/03, P/03.4 Н1.7, P/06.4 Н1.5, P/06.5 |
| V/12.4 | Шаг `psim`: установка, начальные значения (пустое не по схеме, секрет только вводом), включение и выключение, сборщик манифеста `backend` из канона и фрагментов каталога, пересборка зависимых | нормы | P/02.3; V/11.1 |

Соседи: `backend` — описание вида и `/units` для `origin: plugin` (V/11), его манифест собирает шаг этого урока; развёртывание —
пакеты адаптера и плагина (V/09).

## Формы и двери

- **Строки:** `psim-<id>/units/plugin`, таблицы видов `psim-<id>/<т>`, `psim-<id>/<т>_seen`, кольца событий `psim-<id>/<т>_events` (ADR-0115 доп. (13)), состояние
  `psim-<id>/state/<имя>/plugin`, просьбы `psim-<id>/requests/<rid>`, журнал событий единицы `plugin`.
- **Двери:** дверь процесса адаптера — [`spec/12-psim.api.openapi.yaml`](spec/12-psim.api.openapi.yaml); сервер `Platform` — gRPC
  на петле, наружу не выходит.
- **Семьи данных:** своих строк в каталоге VMS нет — таблицы задаёт манифест плагина.
