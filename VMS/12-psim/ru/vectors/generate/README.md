# Векторы генератора V/12.2

Вход — каталог плагина (`plugin.json`, `langs/*.json`) и список установленных; выход — манифест подсистемы и фрагмент `calls`
(V/12.2 Н1.2) или строка отказа (Н1.3). Сравнение манифеста — после загрузки строгим загрузчиком P/02.1, не текстом.

Текст производный от `vectors/generate/README.md`, руками не правится: источник — английский [`vectors/generate/README.md`](../../../vectors/generate/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Случаи:

- `security_controller` и `camera` psim-sdk `c3d9ebb` как есть, порядок установки `camera` → `security_controller` и обратный
  (владелец `CAM`, V/12.2 Н1.2 п. 3);
- синтетические манифесты на каждую строку Н4 глав V/12.1 и V/12.2, на `readonly`, `hidden`, `secret`, массивы, `enum_values`
  у чисел и переводы: у образцов psim этих слов нет.

**Статус:** векторы пишутся после ключа загрузчика `display.tables` (ADR-0115 доп. (11), доля «Спецификации»): без него
манифест подсистемы строгий загрузчик не примет.
