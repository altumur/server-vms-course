# V/08.9 — File door: norms

This English text is the source; the Russian translation `ru/spec/08.9-exp.norms.md` (for people, not in the export) is derived from it by translation and is not edited by hand (ADR-0121).

The canon of chapter 9 of lesson V/08 Export (until 2026-11-03 — chapter V/13.4, ADR-0118 addendum (1)) (ADR-0117 § 6, addendum (2) items 1, 5, addendum (3) «M», addendum (4) items 1, 2, addendum (6) item 4; the word
of Architect 2026-11-03: `Range` 206 and `attachment` are a rule of the `exp` door, not common to doors). Lecture (`ru/08-exp.md`, for people, not in the export),
[instructions](08-exp.README.md), the door — [`08-exp.api.openapi.yaml`](08-exp.api.openapi.yaml). The platform is the export
`cammeta-specs` `7a875c75`.

The file is served by the part's holder through its own door, bypassing the console and `backend` (ADR-0015): the window takes the link immediately before
the download, and the link carries the door token. The chapter sets norms for the route `files` for a person, the route `parts` for the leading part and
the download log.

Norm ids are `V/08.9-MM`.

## N0 Vocabulary

Normative keywords follow the [course canon](../../../Platform/common/NORMATIVE-TERMS.md). The lesson's words — chapter 6 N0.

- **Download** — all requests for one file with one token.

## N1 Form

**Data.** Those of chapter 6: the part's `result.files`, the files on its volume.

### N1.1 Link

- The link is the address of the door of the part's holder and the platform token `where`: `GET /exp/where/<part>` of the console (P/06.5 N3 «`/where/<id>`»);
  it is called by `backend` for `POST /exports/{id}/files/{fileId}/link` (V/11). `EXPORT_LINK_TTL` is the lifetime of this token, 120 s (addendum
  (3) «M»). The address: `https://<door>/files/<part>/<file id>?t=<token>`.
- The token check is the door token contract at the holder (P/03.4 N3 door token at the holder): the token's `unit` MUST be this part.

### N1.2 Route `files`

- `GET` and `HEAD /files/<part>/<file id>`; another method — 405, another path — 404 `no such path`.
- **Admittance.** The token is valid, this worker holds the part, the token's `user` is the part's `by` (only the author, addendum (2) item 5; addendum (6) item 4):
  otherwise 403 `{"error": "forbidden"}` or `{"error": "not the author"}`. The right is checked both when the link is issued (V/11) and here.
- **No file** — no `id` in `result.files`: 404 `no such file`; the part is `expired` or the expiry has passed — 410 `{"error": "expired"}` (`result.expires` has passed).
- **Answer.** `200`, the body is the bytes of the file, `Content-Type` by extension (`video/x-matroska`, `video/mp4`, `video/x-msvideo`,
  `image/jpeg`, `application/pdf`, `application/zip`), `Content-Length`, `Content-Disposition: attachment; filename="<name
  ASCII>"; filename*=UTF-8''<name>`, `Accept-Ranges: bytes`, `ETag` — `"<sha256>"`.
- **`Range`** — one range `bytes=<a>-<b>`, `bytes=<a>-`, `bytes=-<n>`: `206` with `Content-Range: bytes a-b/size`; a range outside the
  file — `416` with `Content-Range: bytes */size`; several ranges — `200` whole (a decision of VMS Specification: the window downloads
  by one range). `If-Range` with another `ETag` — `200` whole.
- **Log.** `export.issued` — the first request with a token the door has not yet seen for this part (by the SHA-256 of the token);
  `export.read` — the first request for a file in a download: `Range` requests of the same download MUST NOT multiply rows (addendum (3) «M»; chapter 6
  N1.6). Refusals are rows of the process door log.

### N1.3 Route `parts`

`GET /parts/<part>/<file id>` is a process route, `{name: parts, role: [expworker]}` of the manifest, the words of the class `role` of the role certificate
contract, there is no token: the leading part takes the files of the other parts of the order for «in one file» (chapter 7 N1.5; addendum (3) «M»).
It MUST serve the file only if the `export` of the requested part equals the `export` of the part `?for=<leading part>`, and the holder of `for` is the calling worker:
the door reconciles the worker name from the role leaf with the decision `exp/placement/<for>` (M3 of the norms review); otherwise 403 `{"error": "not the same
export"}`. The address of the door of the holder of another part the leading part takes from that holder's heartbeat `exp/heartbeats/*` (the field `url`) by the decision
`exp/placement/<part name>`; both are `worker.reads` of the manifest. `Range` — as N1.2; there is no `export.read` log.

### N1.4 Holder

The door is the worker's process door (P/03.4 N1.7): connection limits, the address `SERVER_NAME`, CORS — by the role certificate contract.
If the holder has moved, former links lead to the former address: 403 or a broken connection; the window takes the link anew, and the new door answers
410 `expired` if the files are lost (chapter 8 N1.4).

## N3 Pass

```
files: path → method → token (unit — the part) → do I hold the part → by == user → file in result.files → expiry → Range → answer; log issued, read
parts: path → role leaf expworker → for — my own part of the same export → file → answer
```

**Races.** The expiry passes midway through a download — the started answer finishes, the next request gets 410. A deletion (chapter 8) midway — the same.

---

## N4 Refusals

| Cause | Outcome | Who sees it and how | What the caller does |
|---|---|---|---|
| the token is wrong, expired, not for this part | 403 `forbidden` | window | the link anew |
| not the author | 403 `not the author` | window | — |
| no file | 404 `no such file` | window | — |
| the expiry has passed, the files are lost | 410 `expired` | window — `EXPORT_EXPIRED` (V/11) | a new order |
| a `Range` range outside the file | 416 | window | download anew |
| resuming a download at the same address later than `EXPORT_LINK_TTL` | 403 `forbidden` | browser | a new link from the window and `Range` from the break point — a limit: the browser's download manager will not renew the link by itself (M4 of the norms review) |
| `parts`: the role is not `expworker`, a part of another order | 401 `no_role`, 403 `wrong_role`, 403 `not the same export` | worker `exp` | — |

## N5 Acceptance

[Acceptance 6](../acceptance/6/README.md): the link expires after 120 s; a repeated issue writes `export.issued`; a download with
`Range` — 206; not the author — 403; after `done` and a restart of the holder — the download goes on (addendum (2) item 1).
