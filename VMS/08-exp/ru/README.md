## Что такое урок V/08

Подсистема `exp`: оператор выгружает отрезки архива или один кадр — живой или из архива — в файлы со сроком. Единица — часть:
одна камера, одна запись, её отрезки и файлы. Часть стоит рядом с записью, режет видео, которое читает дверями регистратора,
держит файлы на своём томе и отдаёт их автору своей дверью по ссылке с токеном. Байты не идут ни через консоль, ни через
`backend` (ADR-0015).

## Формы и двери

- **Строки:** `exp/parts/<name>`, состояние `exp/state/cursor/<name>`, `exp/state/result/<name>`, просьбы `exp/requests/<rid>`,
  журнал событий части с `of: cam/<cam>`; заводит `live/streams/<cam>`.
- **Двери:** дверь процесса воркера — [`spec/08-exp.api.openapi.yaml`](../spec/08-exp.api.openapi.yaml): `files` по токену, `parts`
  по роли `expworker`.
- **Семьи данных:** своих строк в каталоге VMS у урока нет; читатель пульсов `rec` и `live` — `expworker` (исходы в данных
  уроков 02, 03).
