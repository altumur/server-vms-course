# V/08 Выгрузка — инструкция для реализации

Что строит реализация подсистемы `exp` и как проверить результат. Канон — нормы глав `08.K-exp.norms.md`; эта инструкция их
не дополняет. Платформа — выгрузка `cammeta-specs` `7a875c75`.

Текст производный от en, руками не правится: источник — английский [`en/08-exp.README.en.md`](en/08-exp.README.en.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

## Входы и их приоритет

- Канон — нормы глав `08.K-exp.norms.md` (Н1–Н5 каждой главы; адреса `V/08.K Н…`).
- Канон манифеста — [`exp.subsystem.yaml`](../exp.subsystem.yaml): байты как есть.
- Дверь — [`08-exp.api.openapi.yaml`](08-exp.api.openapi.yaml).
- Соседи: двери архива V/02.5, маршрут кадра V/03.3 Н1.5, чтение интервала V/05.2, `backend` V/11.
- [Лекция](../08-exp.md) объясняет причины.

## Что создать — результат по главам

| Глава | Что есть у реализации | Проверка |
|---|---|---|
| V/08.6 | воркер `exp` держит части по размещению, том части `files` долей `exp.files`, `cursor` не реже 5 с, `result`, журнал камеры `export.*` | приёмка |
| V/08.7 | чтение отрезков дверями `rec` по правилу V/05.2, звук, дыры — `partial`, живой кадр шлюза, кадр архива, перепаковка и перекодирование, нарезка, ZIP AES-256 и пароль PDF, «в один файл» ведущей частью | приёмка |
| V/08.8 | просьбы `cancel`, `delete`, срок `result.expires` от конца части, удаление файлов и строки держателем | приёмка |
| V/08.9 | дверь `files` (токен, автор, `attachment`, `Range`, журнал), `parts` по роли | приёмка |

## Порядок

Сначала платформа и уроки 02, 03 с ролью `expworker`, затем `exp`, затем `backend` с `/exports` (V/11).

## Ловушки

| Норма | Возможная ошибка | Как сохранить поведение |
|---|---|---|
| V/08.6 Н1.1 | держать заказ отдельной строкой или в одной ведущей части | общие поля — в каждой части; заказ — ведущая |
| V/08.6 Н1.2 | снимать часть по `ends` или `retire_when` | снимает держатель удалением строки в `result.expires` |
| V/08.6 Н1.6 | писать пароль в журнал | только признак `password: true` |
| V/08.7 Н1.1 | ждать дозаписи дыры | файл с дырой, `partial` |
| V/08.7 Н1.2 | брать кадр у держателя камеры или из последнего блока записи | только шлюз `live`, `/frame` |
| V/08.8 Н1.4 | хранить файлы дольше `result.expires` или считать срок от создания | удалить файлы и строку, `export.deleted` |
| V/08.9 Н1.2 | пускать к байтам по праву журнала | только `by` части |
| V/08.9 Н1.2 | писать `export.read` на каждый `Range` | одна строка на скачивание |

## Готово, когда

Приёмка урока проходит на стенде; манифест грузится строгим загрузчиком без правок.

## При расхождении

Порядок источников: нормы главы → манифест → лекция. Норма молчит или противоречит себе — вопрос «Спецификации VMS» с местом,
контрпримером и предложением.
