# V/08 Страница VMS — инструкция для реализации

Форму форка не генерируют: реализация отдаёт её байты, а `backend` исполняет сторону V/11. Инструкция говорит, что должно быть видно и как проверить результат. Канон — нормы глав `08.K-page.norms.md` и контракт `VMS/11-backend/consolem.openapi.json`; эта инструкция их не дополняет. Платформа — выгрузка `cammeta-specs` `0f8d47f7` (пин VMS).

## Входы и их приоритет

- Канон — нормы глав `08.K-page.norms.md` (Н1–Н5 каждой главы; адреса `V/08.K Н…`).
- Страница-свидетель — [`cam.shell.html`](../../01-cam/cam.shell.html): байты как есть, пока не снята (глава 1 Н1.1).
- [Лекция](../08-page.md) объясняет причины; платформа — нормы выгрузки пина VMS по адресам `P/…` (их правит не VMS).

Противоречие записать с местом и контрпримером (раздел «При расхождении»); произвольный отказ не заменяет
отсутствующую норму. Устройство кода остаётся реализации в рамках канона.

## Ловушки

| Норма | Возможная ошибка | Как сохранить поведение |
|---|---|---|
| V/08.1 | генерировать страницу или её часть | страница — канон байт в байт, реализаций нет |
| V/08.3 Н1.2 | повторять оффер WHEP дольше `grace` раздачи | первый оффер и до 20 повторов, пока до конца `grace` не меньше `ICE_WAIT` |
| V/08.3 Н1.1 | повторять отказ куска видео без нового `where` | один повтор через 5 с с новым `where` |
| V/08.2 Н1.2 | читать недоступное из заголовков `/timeline` | поля тела `unreachable`, `unavailable` |

## Готово, когда

Страница реализаций не имеет: её байты — канон. Готово, когда check_spec урока проходит, jsdom-тесты курса над
страницей (`Source/tests/console`, `shell-*`) зелёные, а правило каждой главы, не покрытое тестом, отмечено чтением в чеклисте главы.
Для реализации «готово» — отдача байт; тесты судят канон и в выгрузку не входят.

## При расхождении

Порядок источников: нормы главы → OpenAPI → приёмка и векторы → лекция; платформа — нормы выгрузки пина VMS.
Норма молчит или противоречит себе — вопрос «Спецификации VMS» с местом, контрпримером и предложением; норма
платформы — через «Архитектора». Дефект приёмки (ожидание против нормы) — тот же маршрут; закрытое решение
вносится в канон, а не остаётся в этой инструкции.
