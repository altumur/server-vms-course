# V/08 Страница VMS — инструкция для реализации

Что реализация страницы VMS делает и как проверить результат. Канон — нормы глав `08.K-page.norms.md` и страница
`VMS/01-cam/cam.shell.html`; эта инструкция их не дополняет. Платформа — выгрузка `cammeta-specs` `d3f8e05` (пин VMS).

## Входы и их приоритет

- Канон — нормы глав `08.K-page.norms.md` (Н1–Н5 каждой главы; адреса `V/08.K Н…`).
- Канон страницы — [`cam.shell.html`](../../01-cam/cam.shell.html): байты как есть.
- [Лекция](../08-page.md) объясняет причины; платформа — нормы выгрузки пина VMS по адресам `P/…` (их правит не VMS).

Противоречие записать с местом и контрпримером (раздел «При расхождении»); произвольный отказ не заменяет
отсутствующую норму. Устройство кода остаётся реализации в рамках канона.

## Что создать — результат по главам

| Глава | Что есть у реализации | Проверка |
|---|---|---|
| V/08.1 | страница отдаётся полем `shell` корня `cam`, без обработчиков в атрибутах; сверяет `version` модуля; добавляет свои части вызовами модуля; камера — адрес, заметки, события словами | чтением; jsdom-тесты |
| V/08.2 | дверь держателя (`where`, `?unit=<запись>`, запас 20 с, 403 — один повтор), шкала из дверей записей и мест (слияние, уступка, «Закрепить», недоступное названо), события по `occurred`, отметка | чтением; jsdom-тесты |
| V/08.3 | куски по 60 с (каждый момент один раз, отказ — повтор через 5 с с новым `where`), живое: раздача, оффер с H.265, повторы 404/500/503 по 1,5 с (первый оффер и 8 повторов), отбой, переподключение с разбросом | чтением; jsdom-тесты |
| V/08.4 | записи камеры (состояние словом, правка полем, `when` у `backup`/`edge`, выбор тома, имя новой), удержания (постановка с `recordings`, слова пульса `of: keeps`, «Проверить»), тома (место, `volume_missing`, объявление строкой целиком, `incidents` — `admits: false`, уменьшение с подтверждением) | чтением; jsdom-тесты |
| V/08.5 | сценарии (форма = схема `then` с `params`, отказы двери и двух полей до записи, слова `reason`/`unfit`/`unchecked`, сработки за сутки), домен (только назначение `PUT {cluster, origin, copies}`; строку записи заводит кластер), учётки (пароль один раз) | чтением; jsdom-тесты |

Страница — данные спецификации: реализация отдаёт её байты как есть (ADR-0090 доп. (6) п. 8).

## Ловушки

| Норма | Возможная ошибка | Как сохранить поведение |
|---|---|---|
| V/08.1 | генерировать страницу или её часть | страница — канон байт в байт, реализаций нет |
| V/08.3 Н1.2 | повторять оффер WHEP дольше `grace` раздачи | первый оффер и до 8 повторов, пока до конца `grace` не меньше `ICE_WAIT` |
| V/08.3 Н1.1 | повторять отказ куска видео без нового `where` | один повтор через 5 с с новым `where` |
| V/08.2 Н1.2 | читать недоступное из заголовков `/timeline` | поля тела `unreachable`, `unavailable` |

## Готово, когда

Страница реализаций не имеет: её байты — канон. Готово, когда check_spec урока проходит, jsdom-тесты курса над
страницей (`Source/tests/console`, `shell-*`) зелёные, а правило каждой главы, не покрытое тестом, отмечено чтением в чеклисте главы.

## При расхождении

Порядок источников: нормы главы → OpenAPI → приёмка и векторы → лекция; платформа — нормы выгрузки пина VMS.
Норма молчит или противоречит себе — вопрос «Спецификации VMS» с местом, контрпримером и предложением; норма
платформы — через «Архитектора». Дефект приёмки (ожидание против нормы) — тот же маршрут; закрытое решение
вносится в канон, а не остаётся в этой инструкции.
