# V/08.3 — Проигрывание и живое: нормы

Канон главы 3 урока V/08 «Страница VMS» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../08-page.md),
[инструкция](08-page.README.md), страница — [`cam.shell.html`](../../01-cam/cam.shell.html). Платформа — выгрузка
`cammeta-specs` `fd5913ba` (пин VMS; глава написана на `8fc3aa2`; раздача потока — `41d3ec8`; поток на двери шлюза —
`b41527f`).

Записанное страница проигрывает кусками с дверей регистраторов, живое — по WebRTC у двери шлюза. Глава нормирует куски и
правило «каждый момент — один раз», повтор отданного дверью отказа, порядок живого: раздача, оффер, повторы, отбой и
переподключение. Двери — V/02.5 Н1.6 (кусок), V/03.1–V/03.5 (шлюз).

Id норм — `V/08.3-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Секунды Unix; кусок — `PIECE` = 60 с.

### Н1.1 Куски

- Проигрывание — кусками по 60 с: `GET <door>/segment/<запись>/e<эпоха>/<fromMs>-<toMs>[.<источник>].mp4?t=<токен>` у двери,
  назвавшей спан (V/02.5 Н1.6; дверь отдаёт кусок потоком без длины и не больше часа за раз); кусок играет элемент видео
  страницы, следующий — по окончании.
- **Каждый момент — один раз:** спаны перекрываются (две эпохи, два тома, копия удержания); очередь строится от конца уже
  поставленного, а не от начала следующего спана; отсечённый спан (`fenced`) играет, если выбран сам (щелчок по спану)
  или
  если момент не покрыт неотсечённым (как V/02 вопрос 3: отсечённое проигрывает автоматическому выбору; его кадры —
  дубль,
  не порча). Переход по времени (событие, отметка) берёт неотсечённый спан над моментом, нет такого — отсечённый.
  Случай:
  e1 (`fenced`) и e2 на `[100, 200)`, переход к 150 — e2.
- С выбранного момента — куски, кончающиеся после него, первый — со сдвигом до момента.
- Подпись — интервал, эпоха, из резервного ли архива, дозаписано ли.
- Кусок не отдан: элемент видео не видит ни кода, ни заголовков (`busy` — 503 на 5 с, V/02.5 Н1.6, — и отказ токена
  неразличимы). Подпись и один повтор того же куска через 5 с **с новой дверью** (`where` заново: и новый токен); не
  вышло —
  очередь идёт дальше. Цена — один вопрос консоли на неудавшийся кусок.
- Шов между кусками раз в минуту — принятая цена (без склейки в браузере).

### Н1.2 Живое

1. **Раздача:** `POST /live/streams {cam, labels?}` через модуль (V/03.1); метки — явный выбор зрителя на вкладке
   «Видео»:
   «из локальной сети» (умолчание, `labels` не шлётся) или «извне» (`labels: ["public-address"]`, шлюз с публичным
   адресом,
   V/03.1 Н1.2); выбор не хранится (без хранилища браузера, как глава 5 Н1.3). 409 `exists` — норма (раздачу камеры уже
   смотрят): страница читает метки раздачи из строки `GET /live/streams`; созданы для другой сети — подпись «раздачу
   создали для другой сети», при праве `admin` на камеру — предложение «переразместить» (`PUT /live/streams/<cam> {labels}`:
   переразмещение рвёт сессии, V/03 вопрос 5).
2. **Оффер:** WebRTC только на приём, видео и звук (V/03.4 Н1.5), кодек H.265 — с переносом статических номеров нагрузки в 96–127 (V/03.4 Н1.2);
   `POST <door>/whep/<cam>[?stream=<id> | ?width=<ш>&height=<в>]` (дверь — `GET /live/where/<cam>`, глава 2 Н1.1) — `application/sdp`;
   `stream` — выбранный поток (вкладка «Видео» потока); у камеры — размер окна видео в пикселях экрана (`clientWidth`,
   `clientHeight` × `devicePixelRatio`, округление), поток выбирает шлюз (V/03.3 Н1.2); окно не размечено, размер 0 — параметров нет,
   основной. Размер берётся один раз на попытку показа: новое окно идущую сессию не меняет. 404 `not yet` — повтор (подписку потока заводит проход шлюза, V/03.3 Н1.2); 404 `stream refused` — слова
   `detail` зрителю, без повтора.
3. **Повторы:** 404 (`not yet` — подписки ещё нет), 503 (`full`, `busy`), 500 (`answer failed`; V/03.3 Н4), `where` без двери и
   сбой сети (до первого прохода шлюза двери нет, V/03.3 Н1.1) — снова через 1,5 с, в том же счёте:
   первый оффер
   и не больше 20 повторов, всего 21 оффер (V/03.1 Н1.1; поток в `idle` поднимается до 22 с, V/01.2 Н1.2в; оффер после 403 входит в 21), и только пока до конца `grace` строки раздачи (V/03.1, от её
   создания или чтения страницей) остаётся не меньше `ICE_WAIT`; исчерпаны — `where` один раз: 404 (раздачи нет) — п. 1 заново,
   один раз (409 — раздачу создал другой), иначе — «шлюз не взял поток». `Retry-After` шлюза странице
   не виден (`cors` договора сертификата роли: `Expose-Headers` без него) — пауза постоянная; окно повторов — 20 × 1,5
   с =
   30 с плюс `ICE_WAIT` каждого оффера, в пределах `grace` 60 с; при малом `grace`
   повторов меньше (решение «Архитектора» 2026-10-29). 403
   — `where` заново один раз (глава 2); `where` — 404 — п. 1 заново, один раз;
   иной ответ кроме 201 — словами отказа.
4. **Успех** — 201: ответ SDP, сессия — `Location` (`/whep/session/<sid>?gateway=<шлюз>`); подпись — через какой шлюз. Ответ не
   принят браузером — слова, отбой, соединение закрыто.
5. **Отбой** — `DELETE <door><Location>` свежим токеном при остановке, уходе с камеры (`select`, `card.closed`), выходе из сессии
   и закрытии страницы (V/03.3 Н1.3); вкладка той же камеры — не уход. При закрытии — `keepalive` с токеном из памяти; не дошло —
   сессию снимает шлюз (V/03.5).
   Работа, начатая для прежнего выбора, после ухода с него не публикуется: поздний 201 оффера — сразу отбой `DELETE
   <Location>` и закрытие соединения; поздний ответ шкалы прежней камеры не рисуется; таймер повтора куска снимается. Способ
   (поколение выбора, отмена) — канона, не норма.
6. **Переподключение:** соединение потеряно (`failed`, `closed`; `disconnected` — через 5 с) — живое заново с п. 1 (раздачу могли
   удалить, V/03.1 Н3) после паузы 1 с (5 с у `disconnected`) плюс случайные до 3 с: зрители одной камеры не приходят разом
   (V/03.2 Н1.3); предел — п. 3.
7. **Лента событий** при живом: каждые 3 с `/events` камеры с момента начала (−30 с), последние 30. Во вкладке потока —
   `unit=cam/<камера>` потока, как шкала: общее — у потока с его камеры (глава 1 Н1.5); оффер — поток. Показанное
   узнаётся по `id` строки (договор журнала событий: `id` уникален, дубли копий убирают по нему), не по `server`,
   `bucket`,
   `t`, `kind`. Случай: два `lpr` одного `t` с разными `id` — оба. Порядок и подпись строки — время события: `occurred`,
   нет поля — `t` (одно время во всех местах страницы, как шкала, глава 2 Н1.3); окно опроса сдвигается по `t` с запасом
   `JOURNAL_SETTLE` = 5 с, дубли — по `id`: выборка `/events` идёт по `t`.
8. **Звук:** дорожка того же потока браузера, играет элемент видео. Браузер отказал в автозапуске со звуком — элемент без звука (`muted`), зритель включает его сам кнопками элемента. Кусок записи со звуком
   (V/02.5 Н1.6) играет тот же элемент.
9. **Разговор** (V/03.3 Н1.2а): кнопка «Говорить» на вкладке «Видео» камеры — первый по `number` живой невыключенный `spk`, чей хозяин — эта камера (V/01.4 Н1.4а), и на карточке `spk`, с правом `edit` на хозяина.
   Порядок: микрофон браузера; `POST /cam/requests {unit: <хозяин>, action: talk, port: <number>}` (первая подача — 202, повтор с `answered` `refused` — слова, без офферов); `POST /live/streams {cam: <хозяин>}` (409 `exists` — норма); оффер только на отправку,
   `POST <door>/talk/<хозяин>/<number>` (дверь — `GET /live/where/<хозяин>`). 404 `not yet`, 500, 503 — снова через 1,5 с, всего 9 офферов, после 500 — и просьба снова: шлюз положил трубку; 409 `busy` — «динамик занят»; иной ответ — слова отказа.
   201 — кнопка «Закончить разговор», отбой — п. 5; поздний 201 после ухода — сразу отбой. Уход с объекта, выход и закрытие страницы кончают разговор: микрофон открытым не остаётся.
10. **Титры** (ADR-0102 доп. (9) п. 6). Источник один, журнал: строки вида `text` (V/01.2 Н1.5) строк `eventsrc`, чей `camera` — эта камера (V/01.1 Н1.1г). В кадр не вжигаются (V/03.4 Н1.3): страница
    рисует их поверх видео, текстом, не разметкой. Живое: каждые 3 с `GET /events?unit=cam/<строка>&kind=text`, окно и дубли — как п. 7, строка показывается через `overlay_delay_ms` после прочтения, держится `overlay_duration_sec`, `0` и нет поля — до следующей.
    Архив (куски, Н1.1): те же строки за время куска, по `occurred`, нет поля — `t`, плюс `overlay_delay_ms`; показ по времени кадра. Строки прочитанных кусков остаются на время показа камеры: титр не обрывается на границе куска; перед куском, куда перешли, строки не читаются, титр появится со следующей: это предел. Живое снимает титры архива. `word` строки — цвета `color`, `bg` элемента `words` с тем же `msg`; нет такого — без цвета.
    Строка без `lines` или не по форме — титра нет, журнал её показывает как есть. Нет права `view` на строку `eventsrc` — строк нет, титров нет. `words`, `overlay_*` не прочитаны — без цвета, без задержки, до следующей: титр важнее оформления. Задержка титра — такт опроса и `JOURNAL_SETTLE`; её цена — на замере (ADR-0102 доп. (9) п. 6).

Пока идёт живое, разговор, согласование или проигрывание, вкладка «Видео» занята (`busy` вкладки модуля).

## Н3 Проход

```
проигрывание: спан → куски по 60 с от конца поставленного → /segment?t= → по окончании следующий; отказ — 5 с, один повтор с новым where
разговор: микрофон → POST /cam/requests {action: talk} → /live/streams → /talk/<хозяин>/<number>: 404/500/503 — 1,5 с × 8 повторов; 409 busy — слова; 201 — сессия
живое: POST /live/streams {cam, labels?} (409 — метки строки) → оффер → /whep/<cam>?stream=: 404 not yet/500/503 — 1,5 с × 20 повторов;
404 stream refused — слова; 403 — where; 201 — сессия
обрыв — пауза + случайное → живое заново; стоп — DELETE <Location>
```

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| кусок не отдан | повтор через 5 с с новым `where`, затем дальше | подпись | — |
| шлюз не взял поток после 20 повторов | «шлюз не взял поток» | подпись | позже |
| раздача создана для другой сети | «раздачу создали для другой сети»; с `edit` — «переразместить» | подпись, диалог | переразместить или ждать конца `grace` |
| 409 `exists`, чтение отказало (метки неизвестны) | «метки раздачи не прочитаны», живое не начинается; поля `labels` нет — меток нет, локальная сеть | подпись | повторить |
| 409 `exists`, чтение успешно, строки нет | один новый `POST` (V/03.1 Н3); снова 409 — «метки раздачи не прочитаны» | подпись | повторить |
| WHEP отказал (не 201, не повторяемый) | слова отказа | подпись | — |
| браузер без WebRTC | слова | подпись | — |
| разговор: микрофон не дан, динамик занят, шлюз не взял разговор | слова | сообщение страницы | позже |


Слова отказа вызова модуля — по главе 2 Н4 (из тела ответа, `message` — только ошибке сети).
