# V/08.5 — Сценарии, домен, учётки: нормы

Канон главы 5 урока V/08 «Страница VMS» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../08-page.md),
[инструкция](08-page.README.md), страница — [`cam.shell.html`](../../01-cam/cam.shell.html). Платформа — выгрузка
`cammeta-specs` `8fc3aa2`.

Раздел «Сценарии» — единицы `auto`; домен глазами VMS — камеры и записи членов, назначения записи; «Учётки потоков» —
учётки шлюза. Глава нормирует форму сценария и её отказы, слова вычислителя, что страница пишет в домен и чего не пишет,
и показ пароля учётки.

Id норм — `V/08.5-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Секунды Unix; `within`, `valid_for` — секунды.

### Н1.1 Сценарии

- Список — `/auto/scenarios` (`configured` и `rows`): сценарий есть, пока есть его строка; слово — выключен, `running` —
  следит, `refused` — отказан, `unreadable` — не читается, иначе — размещается.
- **Форма = схема:** «если» — 1–4 триггера `{sub, kind[, unit][, match]}` (V/07.1 Н1.1 `when`); «то» — 1–4 действия, каждое —
  одна из пяти форм `then` манифеста `auto` с её обязательными полями (`cam output`: `unit`, `port`[, `state`, `pulse_ms`];
  `cam preset`: `unit`, `n`; `rec record`: `cam`, `minutes`[, `archive`]; `det detect`: `cam`, `kind`, `minutes`[, `params`];
  `det scan`: `cam`, `kind`[, `before`, `after`, `rec`, `params`]); `params` — объект JSON. Действия `det` — только когда
  консоль монтирует `det`. Виды триггера подсказывают слова `display.kinds`; иной вид вписывается.
- **Отказы формы — отказы двери** (V/07.1 Н4): имя, пустые или больше четырёх `when`/`then`, незаполненное обязательное поле,
  `within` вне 0…3600, `rate_per_minute` вне 1…600 (0 — умолчание), `valid_for` вне 5…600 (0 — умолчание), — **и отказ двух
  полей вычислителя** (V/07.3 Н1.1): два триггера и больше без `within`, один триггер с `within`. Страница не пишет то, что
  откажут, и говорит это до записи.
- Запись — `POST /auto/scenarios {name, …}` или `PUT /auto/scenarios/<имя>` (поля `enabled`, `when`, `then`, `within`,
  `rate_per_minute`, `valid_for`); удаление — `DELETE` с подтверждением («поданные заявки не отменяются»).
- **Слова вычислителя** — из элемента `status[]`: `refused` с `reason` — «вычислитель отказал: …»; `unfit` — «не годится: …»;
  `unchecked` — «не проверено» (V/07.3 Н1.2).
- **Сработки за сутки** — `/events?subsystem=auto&unit=auto/<имя>` (V/07.4 Н1.6): события `fired`, последние 10 — время,
  число поданного (`actions`), `late` — «срок прошёл, не подано».

### Н1.2 Домен

- Вид держателя — `/domain` (через модуль, `refresh`): камеры и записи членов в дереве под членом, их карточки; камера
  одного члена-камеры стоит вместо члена, её записи — под ней.
- **Назначение записи** (V/02.9 Н1.1; [P/08.6 Н1.1](../../../Platform/08-domain/spec/08.6-domain.norms.md)) — страница пишет
  только его: `PUT /domain/placement/rec/<ref> {cluster, origin, copies}`; `origin` — кластер камеры; основная — `cluster`;
  резерв — добавить кластер в `copies` (без `cluster`, без повторов, по возрастанию); резерв без основной — отказ словами.
- **Строк записи страница через домен не создаёт и не удаляет:** дверь правки домена берёт только `domain.edit`
  (`enabled`, `retention_days`; P/08.6 Н1.3), а строку `rec/recordings` (`cam: ref:<ref>`, `ref`; у резерва — дом на резервном
  томе, `when: offline`) заводит оператор кластера записи — страница называет её ему. Перенос основной: прежняя запись
  встаёт и хранит архив до срока, её строку убирает оператор её кластера — страница это говорит.
- Таблица «Назначения записи» — `GET /domain/placement` (`records` с префиксом `rec/`): камера, основной, резервы.

### Н1.3 Учётки потоков

- Узел «Учётки потоков» в разделе прав; двери — `/live/accounts` (V/03.6 Н1.2) через консоль: список, создать (`POST
  {name}`), новый пароль (`POST …/password`), включить и отключить (`PUT {disabled}`), удалить (`DELETE`, с подтверждением —
  «её гранты снимаются»). Писать — только при `admin`; сервер проверяет сам.
- **Пароль — один раз:** из ответа `{account: {name, disabled, at, by}, password}`; живёт только в значении поля вывода —
  не в разметке, не в хранилище браузера, не в списке; забывается кнопкой, выбором другого объекта и уходом карточки.
  Ответ без пароля — «шлюз не вернул пароль; запросите новый».

## Н3 Проход

```
сценарий: черновик → отказы двери и двух полей до записи → POST/PUT → перечитать → слова status[] → сработки за сутки
домен: GET назначения → PUT {cluster, origin, copies} → назвать строку записи кластеру; прежнюю не трогать
учётка: POST → пароль в поле вывода один раз → забыть
```

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| форма сценария не по схеме или два поля | слова до записи | форма | поправить |
| дверь отказала | «Отказано: <слова>» | всплывающее | поправить |
| вычислитель отказал, не годится | слова `reason`, `unfit` | карточка сценария | поправить сценарий или камеру |
| резерв без основной | «сначала назначьте основную» | всплывающее | назначить основную |
| назначение не читается | «назначение недоступно» | всплывающее | позже |
| шлюз не вернул пароль | слова | карточка учёток | новый пароль |
