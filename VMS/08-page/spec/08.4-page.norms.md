# V/08.4 — Архив, удержания, тома: нормы

Канон главы 4 урока V/08 «Страница VMS» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../08-page.md),
[инструкция](08-page.README.md), страница — [`cam.shell.html`](../../01-cam/cam.shell.html). Платформа — выгрузка
`cammeta-specs` `d3f8e05` (пин VMS; глава написана на `8fc3aa2`; поток записи — `41d3ec8`; имя записи без тома —
`b41527f`).

Вкладка «Архив» камеры — её записи и удержания; тома — в дереве под серверами и на своих карточках. Всё это строки и
единицы `rec`, которые страница пишет дверями консоли; слова о состоянии — из пульса регистраторов. Глава нормирует, что
страница показывает, что пишет и каким телом. Смысл полей — V/02.1, виды томов — V/02.6, удержания — V/02.7.

Id норм — `V/08.4-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н1 Форма

**Чтение.** `/rec/recordings` (`configured` и `rows`, [P/06.1](../../../Platform/06-console/spec/06.1-console.norms.md)), таблица мест
`rec` — `/rec/<places.table>` (с `held_by`), `/rec/keeps`, `/rec/servers` (слова пульса — поля `servers.status` манифеста,
[P/06.5](../../../Platform/06-console/spec/06.5-console.norms.md)); после каждой записи — перечитать.

### Н1.1 Записи камеры

- Запись — строка `rec/recordings/<id>` с полем `cam` камеры; у камеры их может быть несколько (V/02.1 Н1.1).
- **Состояние одним словом** — по строке и элементу `status[]`: выключена (`enabled: false`); не размещена (элемента нет);
  регистратор молчит (`stale`); `running` — пишет; `pending` — запускается; `standby` — ждёт: основная идёт; `waiting` — ждёт;
  `failed` — ошибка; иное — словом фазы. Причина — `reason` элемента (слова подсистемы; V/02.4 Н1.8).
- **Правка — действие:** включить и выключить, том (`home`), срок хранения (целое ≥ 1), `when` — `PUT /rec/recordings/<id>`
  одним полем; удалить — `DELETE` с подтверждением («записанное остаётся в томе до срока»). Пусто в `home` — «любой
  свободный том».
- **Резервная запись** — с домом на томе `backup` или `edge` (V/02.1 `when`, V/02.6): только у неё выбор `when` (`always` \|
  `offline`); на шкале её спаны уступают основной (глава 2 Н1.2).
- **Выбор тома** записи камеры — тома включённые, принимающие записи (без `admits: false` — `incidents`), карта камеры
  (`edge`) — только своей камеры: правило выбора страницы; дверь записи на томе без `cam` не отказывает (`must_match` у
  `home` снят, V/02.1 Н1.1), страж — регистратор карты (V/02.6 Н1.7).
- **Новая запись** — `POST /rec/recordings {name, cam[, stream], retention_days[, home]}`; камера и поток выбираются вместе
  (камеры — строки с пустым `main`; поток пуст — основной; подсказка — самый крупный по `size`, V/01.1 Н1.1а). Имя записи —
  первое свободное по порядку: id камеры; `<cam>-<том>`, если том выбран; `<cam>-s<поток>`, если тома нет, а поток выбран
  (`s` — чтобы не совпасть с именем тома из цифр); занято и оно или выбирать нечего — отказ словами, без записи. Камеру, которую выбранный сервер (том) уже пишет, страница
  не предлагает. Карта чужой камеры — отказ словами до записи.

### Н1.2 Удержания

- Удержание — строка `rec/keeps/{cam}-{from:int}-{to:int}` (V/02.1 Н1.2, канон `rec` `keeps.key`; V/02.7 Н1.1); тело —
  целые
  секунды (окно диалога — минуты): `POST /rec/keeps {cam, from, to[, note][,
  recordings]}`; `recordings` — записи камеры на момент постановки (удалённая позже копируется); по умолчанию — показанное на
  шкале окно, иначе последний час; конец позже начала.
- Снять — `DELETE /rec/keeps/<ключ>` с подтверждением («отрезок снова подчиняется сроку хранения»). Строка с `released_at` —
  «отпущено — больше не держит».
- **Состояние** — слова пульса, только поля, названные манифестом `rec` в `servers.status` с `of: keeps`: `keeps {<ключ>:
  {state, …}}`, `incidents_lost`, `incidents_at_risk` (V/02.7 Н1.5). Регистратор записи говорит `here` (с `leaves_in_s`),
  `pushing`, `pushed`, `at risk` и `garbled` (с `why`), `lost` (с `lost_seconds`); держатель `incidents` — `kept`, `empty` —
  «в отрезке нет кадров — запечатывать нечего». Не названо — не сказано.
- Тома `incidents` с держателем нет — предупреждение «удержанное держится, только пока его хранит архив записи».
- **«Проверить»** — только если `rec` открывает маршрут `keeps` на двери (`door.routes`): для каждой записи удержания (иначе
  — записей камеры) дверь места `incidents` (`/rec/where/<таблица>/<том>?unit=<запись>`, глава 2 Н1.1) и `POST
  /keeps/<ключ>/verify?recording=<запись>` (V/02.7 Н1.4); ответ одним словом на запись: `ok` — цело, `broken: …` —
  повреждено, `unknown: …` — не с чем сравнить, `result: empty` — «нет кадров» (не отказ); отказ двери — словами.

### Н1.3 Тома

- Том — строка таблицы мест `rec`; **место**, пока его держит регистратор (`held_by`): «обслуживается: <воркер>», «никто не
  обслуживает», «выключен».
- Дерево: под сервером — его тома (кроме `network`); «Сетевые архивы» — `network`. Карточка тома — объявление и записи,
  выбравшие его; блок сервера «Архивы сервера» (`covers: rec/volumes`).
- **Пропал каталог** — `volume_missing` пульса регистраторов сервера: названо, ссылкой на том.
- **Объявить** — `POST /rec/<таблица>` строкой **целиком** (P/06.1: полная замена полей): тело собирается из всех полей
  строки по схеме таблицы мест манифеста `rec` (`tables.<таблица>.fields`) — без вычисленных (`held_by`, ревизия,
  штампы) —
  и на них накладываются правки окна; что окно не показывает, берётся из строки как есть — общим правилом, а не перечнем
  (`admits: false` обычного тома сохраняется); `cam` — только у `edge`; `incidents` — всегда с `admits: false` (схема
  таблицы, V/02.1 Н1.2); `shrink_confirmed` — по правилу ниже; секрет пуст — прежний (P/06.2), сменился адрес — вписать
  заново. Случай: `local` с `admits: false` — переобъявление его не снимает.
- **Уменьшение квоты** — только со вторым словом оператора: меньшая квота или квота, уменьшение которой держатель называет
  неподтверждённым (`shrink_pending` пульса, V/02.6 Н1.2), — подтверждение «самое старое будет стёрто» и
  `shrink_confirmed` = новой квоте; ждущее уменьшение — на карточке тома.
- **Отозвать** — `DELETE /rec/<таблица>/<имя>` с подтверждением: «записанное не удаляется; записи, выбравшие том, уедут».

## Н2 Двери

Своей двери у главы нет: `/rec/recordings`, `/rec/<таблица>`, `/rec/keeps`, `/rec/servers`, `/rec/where/…` — консоли (P/06);
`/keeps/<ключ>/verify` — дверь архива держателя `incidents` ([OpenAPI V/02](../../02-rec/spec/02-rec.api.openapi.yaml)).

## Н3 Проход

```
вкладка «Архив»: записи, тома, удержания, пульс → состояние словом → правка полем (PUT) → перечитать
удержание: POST строки (recordings на сейчас) → слова пульса of: keeps → «Проверить» у двери incidents
том: объявить строкой целиком (несказанное — из строки; incidents — admits: false) → меньшая квота — подтверждение
```

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| дверь консоли отказала | «Отказано: <слова>» | всплывающее | поправить |
| имя новой записи занято | «запись уже есть», без записи | всплывающее | выбрать том |
| карта чужой камеры | отказ страницы словами до записи (не двери) | всплывающее | другой том |
| `incidents` никто не держит | «проверять негде» | всплывающее | поднять регистратор |
| сверка не подтвердила | «Не подтверждено: …» по записям | всплывающее | — |
| `rec` не смонтирован | карточка «подсистема записи не подключена» | вкладка, блок | — |


Слова отказа вызова модуля — по главе 2 Н4 (из тела ответа, `message` — только ошибке сети).
