# V/08.2 — Двери держателей и шкала: нормы

Канон главы 2 урока V/08 «Страница VMS» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../08-page.md),
[инструкция](08-page.README.md), страница — [`cam.shell.html`](../../01-cam/cam.shell.html). Платформа — выгрузка
`cammeta-specs` `8fc3aa2` (`where` без `door` — `d3f8e05`).

Шкала камеры — все её записи, в этом кластере и в других, со всех дверей регистраторов, которые что-то о них держат, и её
события. Страница сама ходит к дверям держателей с токеном двери консоли. Глава нормирует, как страница получает и держит
дверь, как строит шкалу, как называет недоступное и как ставит события. Проигрывание — глава 3.

Id норм — `V/08.2-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Секунды Unix; спаны двери — миллисекунды (`start_ms`, `end_ms`, V/02.5 Н1.5).

### Н1.1 Дверь держателя

- Адрес и токен — `GET /<sub>/where/<id>` консоли ([P/06.5](../../../Platform/06-console/spec/06.5-console.norms.md) Н3) → `door:
  {url, token, expires, routes}`; дверь места — `GET /rec/where/<таблица>/<место>?unit=<запись>` (`unit` — id записи, без
  префикса подсистемы; иное — 400); запись другого кластера — через консоль этого: `/domain/at/<кластер>/rec/where/…`
  ([P/06.7](../../../Platform/06-console/spec/06.7-console.norms.md)).
- Страница держит дверь по адресу вопроса и берёт новую, когда до `expires` осталось меньше 20 с.
- Токен — `Authorization: Bearer` для запросов, `?t=` для элемента видео (договор токена двери).
- Отказ токена — 403 `forbidden` (договор токена двери; V/02.5 Н1.5, V/03.3 Н1.1): страница спрашивает `where` заново **один раз**
  и повторяет. 401 у двери — `no_role` (маршрут по роли), не токен: не повторяется.
- Ответ другого кластера словами: 403 — «там вас не знают», 502 — «его консоль не видна по сети», 404 — «член отсюда не
  известен», 503 — «список членов здесь не читается»; его архив не показан, не утрачен.

### Н1.2 Шкала

Окна — час, 6 часов, сутки, всё. Источники:

1. записи камеры этого кластера (`rec/recordings` с её `cam`) и записи других кластеров по книге основных
   (`/domain/rec/books/primaries`, элементы её `ref` с ролью и `running`, член не в `missing`, не свои; V/02.9 Н1.6);
2. для каждой — дверь записи: `GET <door>/timeline/<запись>?from&to` (V/02.5 Н1.5);
3. затем двери мест: каждое место таблицы мест `rec` (`places.table` манифеста, не имя в странице) — `GET
   /rec/where/<таблица>/<место>?unit=<запись>` и `/timeline` там; у записи другого кластера — только её дом.

Слияние — без близнецов по (кластер, запись, `start`, `end`, эпоха, источник), дверь самой записи — первой. Спаны записи на
резервном томе (и записи другого кластера с ролью резервной) уступают основной (`yields`): остаток — «только в резервном»;
есть основная — «Закрепить»: `POST /rec/requests {unit: <запись основной>, from, to}` (V/02.8 Н1.4; `unit` — id записи) на каждый
интервал. Спаны архива устройства (`yields`, источник `device`) — часть ответа двери записи (V/02.5 Н1.5).

**Недоступное названо:** дверь не ответила или ответила не 200; `X-Unreachable` (регистраторы); `X-Unavailable` (тома записи без
живого держателя, `<том>@<сервер>`); место 404 с `X-Unreachable` — «недоступно: архив не утрачен, лента может быть неполной»; `where` записи или места ответил
без `door` и не 404 — 200 по памяти (`lapse`: местоположение известно, допуска нет, P/06.5 Н3), 503 или не ответил —
запись или место названы недоступными. Место 404 без `X-Unreachable` («нет такого места») — молчание.

### Н1.3 События на шкале

- `GET /events?from&to&unit=cam/<id>` консоли ([P/06.4 Н1.3](../../../Platform/06-console/spec/06.4-console.norms.md)): события
  камеры и всех единиц «про» неё, слитые; поля ответа — по P/06.4 (`events`, `state`, `truncated`), иных страница не ждёт.
- Засечка — где событие **произошло** (`occurred`, иначе `t`); записанное позже на 2 с и больше подписано «записано в …»;
  отсечённая эпоха (`fenced`) выделена; `state` ≠ `live` и обрезка окна (`truncated`) сказаны; поля сверх полей журнала —
  `ключ=значение`; список — до 200 последних, фильтр по подсистеме.
- Отметка оператора — `POST /marks {unit: cam/<id>, note}` (P/06.4 Н1.2); шкала перечитывается.

## Н2 Двери

Своей двери у главы нет: `/where`, `/events`, `/marks`, `/rec/requests`, `/domain/rec/books/primaries`, `/domain/at/…` — консоли (P/06);
`/timeline` — дверь архива регистратора ([OpenAPI V/02](../../02-rec/spec/02-rec.api.openapi.yaml)).

## Н3 Проход

```
окно → записи камеры (свои + книга основных) → /timeline у двери каждой записи → у дверей мест (?unit=<запись>)
→ слияние без близнецов, своя дверь первой → уступка резервной, «только в резервном» → недоступное названо
→ события камеры (/events), засечки по occurred
```

**Гонки.** Том сменил держателя между `where` и `/timeline` — дверь отвечает 503, место названо недоступным; следующее
окно спросит снова. Токен истёк между вопросами — 403, один повтор `where`.

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| отказ токена | `where` заново, один повтор | — | — |
| дверь записи или места молчит | названо недоступным | подпись шкалы | — |
| `where` без `door` не 404 (`lapse`, 503) | названо недоступным | подпись шкалы | — (следующее окно спросит снова) |
| тома записи без держателя | `X-Unavailable` — названы | подпись шкалы | поднять регистратор |
| другой кластер отказал | словами по коду | подпись шкалы | — |
| события не читаются | «события недоступны: <код>» | подпись | — |
