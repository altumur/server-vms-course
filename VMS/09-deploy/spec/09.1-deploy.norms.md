# V/09.1 — Что ставится и в каком порядке: нормы

Канон главы 1 урока V/09 «Развёртывание VMS» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../09-deploy.md),
[инструкция](09-deploy.README.md). Платформа — выгрузка `cammeta-specs` `cf4a3ce` (урок V/09 — `1997368`; порядок — по норме `near`).

Механизм установки — пользователи, группы, юниты, каталоги, порядок и отказы — платформы
([P/02.4](../../../Platform/02-installer/spec/02.4-installer.norms.md) Н1.1, Н1.7; установочный источник —
[P/02.3](../../../Platform/02-installer/spec/02.3-installer.norms.md)). Глава нормирует, что VMS даёт установщику, с какой
основой имён ставится, в каком порядке встают её манифесты и что оператор делает после установки.

Id норм — `V/09.1-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

### Н1.1 Установочный источник

В `MANIFEST_DIR` (P/02.3 «Установочный источник») — манифесты семи подсистем, байты канона:

| Подсистема | Манифест | Исполняемое |
|---|---|---|
| `cam` | [`cam.subsystem.yaml`](../../01-cam/cam.subsystem.yaml) и страница [`cam.shell.html`](../../01-cam/cam.shell.html) (поле `shell` корня, V/08.1) | `/usr/lib/cam/worker` |
| `rec` | [`rec.subsystem.yaml`](../../02-rec/rec.subsystem.yaml) | `/usr/lib/rec/worker`; часть `obsd` — `/usr/local/bin/obsd` (V/02.2) |
| `live` | [`live.subsystem.yaml`](../../03-live/live.subsystem.yaml) | `/usr/lib/live/worker` |
| `det` | [`det.subsystem.yaml`](../../04-det/det.subsystem.yaml) | `/usr/lib/det/worker` |
| `detjob` | [`detjob.subsystem.yaml`](../../05-detjob/detjob.subsystem.yaml) | `/usr/lib/detjob/worker` |
| `detedge` | [`detedge.subsystem.yaml`](../../06-detedge/detedge.subsystem.yaml) | `/usr/lib/detedge/worker` |
| `auto` | [`auto.subsystem.yaml`](../../07-auto/auto.subsystem.yaml) | `/usr/lib/auto/worker` |

- Исполняемые — пути `worker.exec` и `parts.obsd.exec` манифестов; кладёт их пакет (глава 3).
- **Ключ вендора** (V/01.7): `/etc/cam/vendor.pem` — файл каталога настроек `cam` (`/data/platform/etc/subsystems/cam`, 0640
  `root:vms-cam`, P/02.4 Н1.1); кладёт пакет, оператор не правит; ключа нет — подпись лицензии не сходится (`invalid`, при прежнем
  решении — `degraded`; V/01.7 Н3).

### Н1.2 Основа имён ОС

- VMS ставится с `W2C_DEPLOYMENT=vms` (P/02.4 Н1.2): пользователи и группы `vms-<sub>`, юниты, каталоги долей
  `/run/vms-cam-shm`, `/run/vms-rec-obsd`.
- Причина: часть `rec` слушает `--socket /run/vms-rec-obsd/obsd.sock` (`parts.obsd.exec`), каталог доли — `/run/<dep>-rec-obsd`
  (P/02.4 Н1.1), умолчание `OBSD_CLIENT_GROUP` — `vms-rec-obsd` (V/02.2). Иная основа — сокет части и группа клиента не совпадут
  с долей: регистратор не подключится к движку. Понадобится иная основа — запросом (путь доли в `exec` части), не правкой
  манифеста под установку.

### Н1.3 Порядок `manifest put`

По P/02.4 Н1.7 `order` — адресат раньше клиента; среди готовых — по имени, байтами. Рёбра VMS:

| Клиент | Адресат | Почему |
|---|---|---|
| `rec` | `cam` | `worker.requests: [cam]` (V/02.9 Н1.2); `door.routes ingest.domain` — виды `stream`, `poll`, `ask` из `domain.tokens` `cam` (V/01.6) |
| `detjob` | `rec` | `worker.requests: [rec]` (V/05.4) |
| `detedge` | `rec` | `worker.requests: [rec]` (V/06.4) |
| `auto` | `cam` | `worker.requests: [cam]` (V/07.4) |

`placement.near` порядка не задаёт (P/02.4 Н1.7 `order`; ADR-0091 доп. (26)): `cam` рядом с `rec`, `det` и `detedge` рядом с `cam`,
`detjob` рядом с `rec`; подсистемы `near.sub` в каталоге ещё нет — сродство ждёт (строка вывода установщика, `near_waiting` в
отчёте прохода контроллера, P/04), проверка `near.of`, `near.prefer` откладывается до её появления (P/02.1). `worker.creates` (`auto`, `rec`) и `worker.uses` порядка не задают.
Порядок первой установки: **`cam`, `auto`, `det`, `live`, `rec`, `detedge`, `detjob`**.


### Н1.4 После установки

1. **Тома части `obsd`** (`parts.obsd.volumes`) — оператор монтирует диск в `/data/platform/subsystems/rec/obsd/volumes/<n>`,
   владелец — пользователь части `vms-rec-obsd`; установщик не создаёт и не монтирует; чужой владелец — отказ старта части,
   код 2 (P/02.4 Н1.1). Число томов — свойство сервера.
2. **Том сервера** — строка `rec/volumes/<имя>` (V/02.1 Н1.2): `kind: local`, `server: <сервер>`, `url:
   file:///data/platform/subsystems/rec/obsd/volumes/<n>`, `quota_bytes` — размер кольца (V/02.6 Н1.2), — дверью таблиц консоли
   (`POST /rec/volumes`, право `admin`, P/06.1 Н1.6) или страницей (V/08.4). Переменной тома нет: места — только строки
   `volumes` (V/02.4). Без строки записи не размещаются — видно сразу (`/unplaceable`, P/04).
3. Сертификаты серверов — рука оператора (P/02.4 Н1.7 `not`); здоровье — глава 4.

### Н1.5 Обновление

Сервер за сервером (P/02.4 Н1.7 `upgrade`); смена манифеста — `manifest put` по P/02.3. Ключи установочного источника
(`parts`, `worker.stop_timeout`, `shares`, `worker.uses`) действуют только после переустановки на серверах (P/02.3). Часть
`obsd` встаёт с сервером раньше воркеров; регистратор ждёт сброса писателя `OBSD_WRITER_GRACE_S` (V/02.2).

## Н2 Двери

Своей двери у главы нет: `POST /rec/volumes` — дверь таблиц консоли (P/06.1 Н1.6).

## Н3 Проход

```
источник (7 манифестов, страница, исполняемые, ключ вендора) → install.sh с W2C_DEPLOYMENT=vms
→ manifest put: cam, auto, det, live, rec, detedge, detjob (одним проходом; near — не ребро)
→ оператор: смонтировать тома части obsd, объявить rec/volumes/<имя> → здоровье (глава 4)
```

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| том части чужого владельца | отказ старта части, код 2 | журнал части | `chown` тома пользователю части |
| строки `rec/volumes` нет | записи не размещаются | `/unplaceable` | объявить том сервера |
| основа имён не `vms` | регистратор не подключается к движку | статус записи, журнал | `W2C_DEPLOYMENT=vms` |
| ключа вендора нет | лицензия `invalid` (`degraded`) | `domain/cam/licence`, пульс | переустановить пакет |
