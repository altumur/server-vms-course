# Приёмка V/03.1 — раздача — единица по спросу

Норма главы — [`03.1-live.norms.md`](../../spec/03.1-live.norms.md) Н5. Стенд и словарь — [общий README приёмки
VMS](../../../common/acceptance/README.md) поверх общего README платформы (выгрузка `f6f3895`).

## Подготовка

Хранилище и консоль кластера; установлены манифесты `VMS/01-cam/cam.subsystem.yaml` и `VMS/03-live/live.subsystem.yaml`;
консоль — `CONSOLE_ROOT=live` (дверь `/streams`), `cam` смонтирован (`console2` — префикс `/cam`). Контроллер, воркеры,
ресурс и домен не запущены. Запросы — с петли без домена (одна личность с полными правами). Сценарий — на чистом
экземпляре.

Сценарий `02-two-viewers` — на стенде домена VMS ([общий README приёмки VMS](../../../common/acceptance/README.md), «Стенд
домена VMS»): `@domain m1`, на `m1` — те же манифесты, `member m1 console` — корень `live`, `member m1 console2` — `/cam`;
люди и гранты — двери `holder` и директива `@person` общего README платформы. Ann видит только камеру `$a`, Bob — только
`$b`. Что раздачу с именем не по правилу (`{name: "$b.$bs", cam: "$a"}`) шлюз удаляет на первом проходе, — чтением
(V/03.5 Н1.1): шлюза на стенде нет.

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-create` | V/03.1-01, V/03.1-02 | раздача камеры с умолчанием `grace` 30; второй зритель — 409 `exists`; `cam` не меняется — 400; раздача камеры без строки — создаётся; раздача прочего потока — имя `<cam>.<stream>`; без `name` — 400; поток другой камеры и id самой камеры — 409 `must_match`; `stream` не меняется — 400 |
| `02-two-viewers` | V/03.1-01, V/03.1-02 | стенд домена, два человека с `view` каждый на свою камеру: поток чужой камеры под своей — 409 `must_match`, чужая камера — 403; раздача потока камеры Bob создаётся им, раздача камеры Ann ему — 403 |
