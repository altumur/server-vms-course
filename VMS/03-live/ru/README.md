## Что такое урок V/03

Подсистема `live` — шлюз живого видео. Единица — раздача камеры зрителям («камеру 7 смотрят через шлюз g-2»): одна на
камеру, её создаёт первый зритель (`POST /live/streams`, право `view` на камеру) и удаляет шлюз через отсрочку после
ухода последнего. Воркеры — шлюзы `liveworker`: без состояния, число — по спросу, ёмкость — в зрителях. Шлюз держит одну
подписку на поток камеры при любом числе зрителей и отдаёт её браузерам по WebRTC (WHEP: оффер и ответ одним обменом, без
trickle), без перекодирования; устройствам (видеостена, чужая VMS) — по RTSP с учётками кластера. Байты идут шлюз ↔
браузер мимо консоли (решение владельца 1, ADR-0015): консоль выдаёт адрес двери и токен (`GET /live/where/<cam>`).
Общее — размещение, рантайм воркера, двери консоли, токен двери, книги домена — нормы платформы по ссылке (P/…).

## Формы и двери

- **Строки и объекты:** `live/streams/<cam>` (единица), таблица `live/accounts/<name>` (`password_secret`), вклад
  `live/stream-accounts/<slot>`, копия книги `domain/live/stream-accounts`; пульс `live/heartbeats/<worker>`; журнал
  шлюза (`live.view*`, `live.rtsp.*`).
- **Семьи данных** (класс семей VMS, решение «Архитектора» А): строка раздачи, таблица `accounts` и вклад
  `live/stream-accounts/<slot>` выражает манифест (P/02.1) — своих семей у них нет. Своё содержимое в открытых местах семей
  платформы — [`data/`](../data/): `value`
  элемента книги учёток `stream-accounts-entry` (место `/*/entries/*/value`; пароль — только конверт кольца) — форма, слои,
  исходы по читателям; строки — в каталоге VMS [`../common/data/catalog.tsv`](../../common/data/catalog.tsv) (колонка
  `place`); векторы строит построитель family-read, вручную не пишутся. Слова пульса шлюза — семья
  `live/heartbeats/<name>` ([`data/live-heartbeat-words.schema.json`](../data/live-heartbeat-words.schema.json); читают `camworker`, `expworker`); `capacity` судит контроллер платформы (договор пула), `headroom` показывает консоль рядами `worker_headroom` и
  `headroom` (P/06.5 N3; контроллер его не читает, P/04 N1.3).
- **Двери:** дверь шлюза `whep` (страница, токен двери консоли) и `/live/accounts` через `door.pass` — OpenAPI урока
  `spec/03-live.api.openapi.yaml`; дверь RTSP шлюза — RTSP с Digest (не HTTP), глава 6.
