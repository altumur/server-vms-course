# Векторы: функция момента — расписание, солнце, режим объекта

Владелец — урок V/07 ([нормы главы 6](../../spec/07.6-auto.norms.md) N1.2–N1.5, N1.7). Числа посчитаны образцовым движком
автоматизации из набора consolem `785824c` (`api/rule-engine.js`) и перепроверены независимым пересчётом по тексту нормы;
строка `at` ручного режима — правило нормы (N1.5), у движка её нет. Прогон — после первой генерации стадии C, прошедшей приёмку
платформы (ADR-0090 доп. (8), (9)).

Текст производный от `vectors/moment/README.md`, руками не правится: источник — английский [`vectors/moment/README.md`](../../../vectors/moment/README.md), правка идёт в него, русский пересобирается переводом (ADR-0121).

Кто исполняет — реализация `auto`, своей командой пакета; пакет `VMS/07-auto/moment` (путь в выгрузке без `vectors/`).

## Файлы

| Файл | Что |
|---|---|
| `world.json` | вход всех случаев: `schedules`, `day_groups`, `modes` — строки таблиц (V/07.6 N1.1); `unreadable: true` у группы — строка не читается |
| `cases.tsv` | случаи: UTF-8, LF, поля через TAB, первая строка — заголовок |

## `cases.tsv`

- `case` — имя случая; приставка — чеклист главы: `w-` неделя, `n-` через полночь, `d-` границы суток, `b-` встроенные, `g-` группы дней, `t-` даты, `c-` цикл, `v-` срок, `z-` пояс, `s-` переходы часов, `a-` солнце, `m-` режим, `u-` нечитаемая группа, `e-` поля строки нет;
- `func` — `in_effect`, `object_mode` или `sun`;
- `arg` — `in_effect`: `title` расписания из `world.json`; `object_mode`: строка `mode_current` JSON `{mode, until, at}` (время — секунды, `at` 0 — не ограничивает) или `-` — строки нет; `sun`: JSON `{date, lat, lon, utc_offset_hours, event}`, `event` — `rise`, `set`;
- `tz` — пояс момента, `sun` — `-`;
- `t` — момент RFC 3339 UTC, `sun` — `-`;
- `expect` — `in_effect`: `true`, `false`, `unknown` (приставка `u-`); `object_mode`: `name` режима; `sun`: минута суток или слово `day`, `night`;
- `why` — пояснение, не сравнивается.

## Команда пакета

По общему README приёмки платформы («Единая команда пакета векторов»): профиль реализации `auto` объявляет `vectors` →
`VMS/07-auto/moment`: своя команда с `{input}`. Вход — файл JSON `{format, package, table, case, variant, cells, files}`: `cells` —
`func`, `arg`, `tz`, `t` строкой ячейки, `files` — `world.json`. Выход — значение колонки `expect` строкой.
