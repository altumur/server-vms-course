# V/07.1 — Сценарий — единица и язык: нормы

Канон главы 1 урока V/07 «Сценарии» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../07-auto.md),
[инструкция](07-auto.README.md), манифест [`auto.subsystem.yaml`](../auto.subsystem.yaml). Платформа — выгрузка
`cammeta-specs` `d3f8e05`.

Сценарий — «когда это случилось (и то, в пределах окна), сделать вот это». Глава нормирует строку сценария, его язык —
триггеры и действия фиксированной формы, права, размещение и снимок. Что вычислитель делает со сценарием — главы 2–4;
сценарии между камерами разных членов — глава 5.

Id норм — `V/07.1-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** `within`, `valid_for` — секунды.

**Данные** (общие семьи [каталога платформы](../../../Platform/common/data/catalog.tsv)): строка `auto/scenarios/<name>` (P/06.1),
снимок `auto/snapshot/*`; своих семей сверх них у главы нет.

### Н1.1 Поля

`unit: {rows: scenarios, id: name}`. Сценарий — единица, вычислитель — её держатель: «ровно один вычислитель на сценарий»
даёт эпоха с арендой (P/03.2), а не забота кода.

| Поле | Форма | Смысл |
|---|---|---|
| `name` | `string`, обязательно | имя оператора: `door-on-badge` |
| `when` | `json`, обязательно, схема Н1.2 | 1–4 триггера |
| `within` | `int`, 0…3600, умолчание `0` | окно между триггерами, секунды |
| `then` | `json`, обязательно, схема Н1.3 | 1–4 действия |
| `rate_per_minute` | `int`, `0` или 1…600, умолчание `6` (`0` — умолчание) | потолок сработок сценария в минуту (глава 4) |
| `valid_for` | `int`, `0` или 10…600, умолчание `30` (`0` — умолчание; нижняя граница — `SETTLE` 5 с плюс дорога: строка читается не раньше `t + SETTLE`) | сколько поданное действие остаётся годным от момента события (глава 4) |
| `enabled` | `bool`, умолчание `true` | |
| `labels` | `list` | метки сервера вычислителя |

### Н1.2 Триггер

`when` — массив 1…4 объектов `{sub, kind, unit?, match?}`, лишних ключей нет: `sub` — подсистема события, `kind` — вид
события, `unit` — единица (строка или число; нет — любая; id единицы подсистемы `sub`, число — своей десятичной записью, сравнение —
ссылкой `<sub>/<unit>`, глава 2 Н1.3), `match` — объект «поле события → значение», сравнение строгое (`"1"` ≠ `1`): форму
поля события задаёт урок его писателя (`io.input` — `port` целое JSON с 1, `value` — слово устройства, V/01.2 Н1.5), сценарий
пишет `match` тем же типом (`"port": 1`). Фиксированный язык, а не выражения: форма проверяется у двери для любого писателя (P/06.1 Н1.2, схема поля
`json`), смысл — вычислителем (глава 3).

### Н1.3 Действие

`then` — массив 1…4 объектов ровно одной из пяти форм (лишних ключей нет; каталог действий = эта схема):

| `sub`, `action` | Обязательно | Можно | Исполняет |
|---|---|---|---|
| `cam`, `output` | `unit`, `port` | `state`, `pulse_ms` | держатель камеры — просьба (V/01.4) |
| `cam`, `preset` | `unit`, `n` | — | держатель камеры — просьба (V/01.4) |
| `rec`, `record` | `cam`, `minutes` | `archive` (том) | заказ записи на время (глава 4; V/02.1) |
| `det`, `detect` | `cam`, `kind`, `minutes` | `params` (строка, как у владельца — V/04.1) | заказ детектора на время (глава 4; V/04.1) |
| `det`, `scan` | `cam`, `kind` | `before`, `after`, `rec`, `params` (строка — V/05.1) | заказ задачи по интервалу (глава 4; V/05.1) |

Формы полей действий не шире схемы и правил владельца строки или просьбы: `unit` — строка или целое, в тело просьбы идёт
десятичной записью; `port`, `n`, `pulse_ms` — целое JSON ≥ 1 для `port`, `n` (нумерация с 1, V/01.4 Н1.1), ≥ 0 для
`pulse_ms`; `state` — как у `cam` (слово до 32 знаков или целое); `minutes` — `number` 1…1440, `before`, `after` — `number`
0…3600 (строк нет). `before` = `after` = 0 — пустое окно скана: связь двух полей, отказ вычислителя (глава 3 Н1.1).

Каталог говорит, что сценарию **можно просить**, а не что умеет устройство: что умеет камера, проверяет вычислитель (глава 3)
и держатель при исполнении.

### Н1.4 Права

`rights: {cluster_rows: true, names: [{field: when, unit: unit, sub: sub}, {field: then, unit: unit, sub: sub}, {field: then, unit:
cam, of: cam}]}` ([договор сторожевой и передачи](../../../Platform/common/contracts/gate-and-pass.md) «Права по телу»): запись
сценария — дело всего кластера (метки говорят, где работает вычислитель, а не чей сценарий); единицы, которые сценарий
называет — каждого триггера и действия, — требуют прав и на них: сценарий не командует камерой, на которую у автора нет
права.

### Н1.5 Размещение, аренда, снимок

| Ключ | Значение | Смысл |
|---|---|---|
| `capacity` | `{from: capacity, default: 50, unit_mb: 1, base_mb: 21}` | сценариев на вычислитель (окно и вопрос к журналу на каждый); память — замер ADR-0070 |
| `headroom` | `{from: headroom}` | запас — платформа |
| `constraint` | `labels-subset` | |
| `requires` | `resource` | вычислитель читает события, а события живут на ресурсах |
| `servers` | `shared` | два вычислителя на одном сервере допустимы |
| `tie_break` | `most-free-capacity` | |
| `grows` | `true` | не хватает вычислителей — заказ ещё одного на сервере (ADR-0084) |
| `rebalance` | `{dead_band: 0.10}` | |

`near` нет: что сценарий смотрит, сказано внутри `when` (JSON), правило размещения JSON не читает. `lease: {unconfirmed_max:
off}` (P/03.2 Н1.6): действие под неподтверждённой арендой — второе открытие двери, не дубль. Снимок — `snapshot: [name,
enabled]` (P/04 Н1.3а): домену — что сценарий есть и включён ли, не его триггеры и действия.

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| `when` или `then` не по схеме (пусто, больше 4, лишний ключ, не та форма действия) | 400 (схема поля, P/06.1 Н1.2) | ответ | — |
| `within` вне 0…3600, `rate_per_minute`, `valid_for` вне границ (`valid_for` 1…9) | 400 | ответ | — |
| `minutes` вне 1…1440 или строкой; `before`, `after` вне 0…3600 или строкой; `port`, `n` не целое ≥ 1 | 400 (схема поля) | ответ | — |
| нет права на единицу, которую сценарий называет | 403 | ответ | — |
| нет гранта на кластер | 403 (`cluster_rows`) | ответ | — |

## Н5 Приёмка

[Приёмка 1](../acceptance/1/README.md): сценарий с умолчаниями; каждая из пяти форм действия; по каждой форме — без
обязательного и с лишним ключом; отказы схемы `when`, `then` и границ полей (`within`, `rate_per_minute`, `valid_for`,
`minutes`, `port`). Права — чтением (стенд без домена — одна личность с полными правами); отказ двух полей и сверка — глава 3,
чтением и тестом реализации.
