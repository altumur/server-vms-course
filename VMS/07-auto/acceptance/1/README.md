Хранилище и консоль кластера; установлены манифесты VMS `cam`, `rec`, `det`, `detjob`, `auto` (заказчики и адресаты
заказов `auto`); консоль — `CONSOLE_ROOT=auto` (дверь `/scenarios`). Контроллер, воркеры, ресурс и домен не запущены.
Запросы — с петли без домена (одна личность с полными правами). Сценарий — на чистом экземпляре.
