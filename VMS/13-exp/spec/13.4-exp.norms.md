# V/13.4 — Дверь файла: нормы

Канон главы 4 урока V/13 «Выгрузка» (ADR-0117 § 6, доп. (2) пп. 1, 5, доп. (3) М, доп. (4) пп. 1, 2, доп. (6) п. 4; слово
«Архитектора» 2026-11-03: `Range` 206 и `attachment` — правило двери `exp`, не общее для дверей). [Лекция](../13-exp.md),
[инструкция](13-exp.README.md), дверь — [`13-exp.api.openapi.yaml`](13-exp.api.openapi.yaml). Платформа — выгрузка
`cammeta-specs` `7a875c75`.

Файл отдаёт держатель части своей дверью, мимо консоли и `backend` (ADR-0015): ссылку окно берёт непосредственно перед
скачиванием, в ней — токен двери. Глава нормирует маршрут `files` для человека, маршрут `parts` для ведущей части и
журнал скачиваний.

Id норм — `V/13.4-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Слова урока — глава 1 Н0.

- **Скачивание** — все запросы одного файла с одним токеном.

## Н1 Форма

**Данные.** Главы 1: `result.files` части, файлы на её томе.

### Н1.1 Ссылка

- Ссылка — адрес двери держателя части и токен `where` платформы: `GET /exp/where/<part>` консоли (P/06.5 Н3 «`/where/<id>`»),
  его зовёт `backend` для `POST /exports/{id}/files/{fileId}/link` (V/11). `EXPORT_LINK_TTL` — срок этого токена, 120 с (доп.
  (3) М). Адрес: `https://<дверь>/files/<part>/<file id>?t=<токен>`.
- Проверка токена — договор токена двери у держателя (P/03.4 Н3 «токен двери у держателя»): `unit` токена — эта часть.

### Н1.2 Маршрут `files`

- `GET` и `HEAD /files/<part>/<file id>`; иной метод — 405, иной путь — 404 `no such path`.
- **Допуск.** Токен верен, часть держит этот воркер, `user` токена — `by` части (только автор, доп. (2) п. 5; доп. (6) п. 4):
  иначе 403 `{"error": "forbidden"}` или `{"error": "not the author"}`. Право проверено и при выдаче ссылки (V/11), и здесь.
- **Файла нет** — нет `id` в `result.files`: 404 `no such file`; часть `expired` или срок вышел — 410 `{"error": "expired"}` (`result.expires` прошёл).
- **Ответ.** `200`, тело — байты файла, `Content-Type` по расширению (`video/x-matroska`, `video/mp4`, `video/x-msvideo`,
  `image/jpeg`, `application/pdf`, `application/zip`), `Content-Length`, `Content-Disposition: attachment; filename="<имя
  ASCII>"; filename*=UTF-8''<имя>`, `Accept-Ranges: bytes`, `ETag` — `"<sha256>"`.
- **`Range`** — один отрезок `bytes=<a>-<b>`, `bytes=<a>-`, `bytes=-<n>`: `206` с `Content-Range: bytes a-b/size`; отрезок вне
  файла — `416` с `Content-Range: bytes */size`; несколько отрезков — `200` целиком (решение «Спецификации VMS»: окно качает
  одним отрезком). `If-Range` с иным `ETag` — `200` целиком.
- **Журнал.** `export.issued` — первый запрос с токеном, которого дверь у этой части ещё не видела (по SHA-256 токена);
  `export.read` — первый запрос файла в скачивании: запросы `Range` того же скачивания строк не множат (доп. (3) М; глава 1
  Н1.6). Отказы — строки журнала двери процесса.

### Н1.3 Маршрут `parts`

`GET /parts/<part>/<file id>` — процессный, `{name: parts, role: [expworker]}` манифеста, слова класса `role` договора
сертификата роли, токена нет: ведущая часть берёт файлы прочих частей заказа для «в один файл» (глава 2 Н1.5; доп. (3) М).
Отдаёт файл, только если `export` запрошенной части равен `export` части `?for=<ведущая>`, а держатель `for` — вызывающий воркер:
дверь сверяет имя воркера из листа роли с решением `exp/placement/<for>` (М3 ревью норм); иначе 403 `{"error": "not the same
export"}`. Адрес двери держателя прочей части ведущая берёт из его пульса `exp/heartbeats/*` (поле `url`) по решению
`exp/placement/<часть>`; оба — `worker.reads` манифеста. `Range` — как Н1.2; журнала `export.read` нет.

### Н1.4 Держатель

Дверь — дверь процесса воркера (P/03.4 Н1.7): пределы соединений, адрес `SERVER_NAME`, CORS — по договору сертификата роли.
Держатель переехал — прежние ссылки ведут на прежний адрес: 403 или обрыв; окно берёт ссылку заново, новая дверь отвечает
410 `expired`, если файлы потеряны (глава 3 Н1.4).

## Н2 Двери

Дверь части — [`13-exp.api.openapi.yaml`](13-exp.api.openapi.yaml): `GET`, `HEAD /files/{part}/{file}` по токену, `GET
/parts/{part}/{file}` по роли `expworker`.

---

## Н3 Проход

```
files: путь → метод → токен (unit — часть) → держу ли часть → by == user → файл в result.files → срок → Range → ответ; журнал issued, read
parts: путь → лист роли expworker → for — своя часть того же export → файл → ответ
```

**Гонки.** Срок вышел посреди скачивания — начатый ответ доигрывает, следующий запрос — 410. Удаление (глава 3) посреди — так же.

---

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| токен не тот, истёк, не на эту часть | 403 `forbidden` | окно | ссылку заново |
| не автор | 403 `not the author` | окно | — |
| нет файла | 404 `no such file` | окно | — |
| срок вышел, файлы потеряны | 410 `expired` | окно — `EXPORT_EXPIRED` (V/11) | новый заказ |
| отрезок `Range` вне файла | 416 | окно | качать заново |
| докачка тем же адресом позже `EXPORT_LINK_TTL` | 403 `forbidden` | браузер | новая ссылка из окна и `Range` с места обрыва — предел: менеджер загрузок браузера сам ссылку не обновит (М4 ревью норм) |
| `parts`: роль не `expworker`, часть чужого заказа | 401 `no_role`, 403 `wrong_role`, 403 `not the same export` | воркер `exp` | — |

## Н5 Приёмка

стенд урока (ветка приёмки V/13): ссылка истекает через 120 с; повторная выдача пишет `export.issued`; скачивание с
`Range` — 206; не автор — 403; после `done` и перезапуска держателя — скачивание идёт (доп. (2) п. 1).

Буфер отдачи, отдача файла с тома (sendfile).
