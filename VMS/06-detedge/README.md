# V/06 Детекция по архиву устройства

Статус: **переведён** — главы V/06.1–V/06.4 (2026-10-23; ревью — разбор 2026-10-29); план ниже — история перевода (решения 1–10
приняты «Архитектором» 2026-10-23; переход — ADR-0090 доп. (11)). Источники — опись [`../common/inventory.md`](../common/inventory.md) § 1, § 2 (М10B/23).
Платформа — выгрузка `cammeta-specs` `d3f8e05` (пин VMS). Манифест — [`detedge.subsystem.yaml`](detedge.subsystem.yaml) (канон; ADR-0090
доп. (6) п. 8).

## Что такое урок V/06

Подсистема `detedge`: **обход** — одна модель смотрит архив **устройства** одной камеры (карту,
NVR) — всегда, без конца. Видео не копируется: тридцать суток лежат на NVR без своей аналитики, места на сервере нет, а
детекции нужны; наружу выходят только события и, по желанию, минуты вокруг находок (просьбой дозаписи регистратору).
Семья детекторов: `det` — живой поток (V/04), `detjob` — интервал нашего архива (V/05), `detedge` — архив устройства. Свой
бюджет: предел ставит не GPU, а сессии воспроизведения устройства, которые делят оператор и регистратор.

## Формы и двери

- **Строки и объекты:** `detedge/watches/<name>`, курсор `detedge/state/cursor/<watch>` (P/03.6 Н1.7), просьбы
  `rec/requests/<rid>` (подача), пульс `detedge/heartbeats/<воркер>`, события — журнал ресурса своего сервера
  `detedge/<watch>/e<эпоха>/`, тревоги — `detedge.alarms/…`.
- **Двери:** своей HTTP-двери нет — строки дверью консоли (P/06.1), чтение — двери держателя `/recordings`, `/playback`
  (V/01.5, лист роли `detedgeworker`); OpenAPI урока нет — строка реестра `V/06 no-openapi` (запросом с главой V/06.1).
- **Семьи данных:** поля строк событий обхода — [`data/detedge-events`](data/) (`tick` — `pass`; `detedge.overrun`,
  `detedge.rewound` — `from`, `to`; место — корень строки семьи событий платформы, деревья `detedge` и `detedge.alarms`;
  читают консоль и сценарии `auto`), строка — в каталоге VMS [`../common/data/catalog.tsv`](../common/data/catalog.tsv).

## Решения для плана (приняты «Архитектором» 2026-10-23)

1. **Имя подсистемы `detedge` первым коммитом V/06.1** (ADR-0090 доп. (2), доп. (4) п. 7 — «по слову «Архитектора» при
   переводе урока 06»; доп. (7) п. 4 — файл и `name` одним коммитом): `detedge.subsystem.yaml`, `name: detedge`, слот
   `{prefix: e, name_env: DETEDGE_NAME}` (`d` занят), `exec: /usr/lib/detedge/worker`, `rows: watches`,
   ряд `detedge_watches_running`, роль `detedgeworker` (V/01.5 Н2), `lessons.tsv`; словарь границы —
   «Архитектору»; продукт — строкой долга «Сборке». `Source/vms/*` не трогается.
2. **С `detjob` — ссылками, не копией:** реестр, `tick` в медийном времени, маска — V/04.2, V/05.3 Н1.3; правила строки
   события — V/05.3 Н1.4 (кроме дерева, класса); перечень устройства с `None` ≠ `[]` и форма просьбы — V/05.4 Н1.4. Своё у
   V/06: курсор-край вместо множества `done`, нет итога и снятия, источник — дверь держателя, окно и `SETTLE`, правило рубежа.
3. **Обход уступает:** любой 503 двери держателя — `waiting` до следующего прохода, без повтора в проходе; не больше одной
   сессии воспроизведения на устройство у воркера; последняя сессия — оператору или регистратору: запас держит дверь
   держателя (`PLAYBACK_SPARE` = 1 для `detedgeworker`, V/01.5 Н1.5, — разбор ревью V/06, вопрос 3), проверка `/devices`
   (`playbacks ≥ max_playbacks − 1` — не читать) — предварительная; `max_playbacks` = 1 — обход устройство не читает; число
   сессий называет устройство (V/01.5 Н1.4), не урок; за проход — не больше `STRETCHES_PER_PASS` = 4 чтений по `READ_SECONDS`
   = 60 с медиа (`PLAYBACK_PIECE` — порция двери внутри ответа), чтение и модель — не на потоке цикла рантайма: бюджет
   ограничивает время до записи курсора и долю устройства.
4. **Дозапись — только `keep: hits`:** обход дыр не заказывает и задач не заводит; отрезки вокруг находок — просьбой в
   запись, названную полем `rec` (`ref: rec/recordings`, `must_match: {cam: cam}`, обязательно при `keep: hits`; у камеры
   бывает несколько записей — «первая по камере» свидетеля неоднозначна); куски короче секунды и до «видно с» записи не
   подаются (иначе отказ V/02.8 Н1.4); `by: detedge/<watch>`.
5. **`per_person` (опись № 17) к подаче воркером не относится — по слову нормы:** учёт `asked` — людей (P/06.4 Н1.5, дверь
   консоли), подача воркером идёт мимо двери (P/03.6 Н1.5); запрос не нужен.
6. **`events.older_epochs: earlier-run`**: после переезда строки прежней эпохи — единственная запись тех минут (повтор —
   работа после последнего курсора, без предела в секундах видео), не отсечённый писатель; подавления нет (медиа быстрее реального времени).
7. **`alarms`, умолчание `[]`**: находки по старому архиву — наблюдения; тревогу оператор ставит видом явно.
8. **Стёртое кольцом устройства:** рубеж < `coverage.from` — прыжок на `coverage.from`, счёт `overrun_seconds` в элементе
   пульса и одна строка события `detedge.overrun` (`from`, `to`) — у свидетеля рубеж молча полз через стёртое.
9. **Курсор пишется при первом взятии** (`start: now` → `max(oldest, newest − SETTLE)`, `earliest` → `coverage.from`; та же
   формула — у сброса рубежа впереди архива, `detedge.rewound`): у свидетеля обход с
   умолчанием `now` не начинал смотреть никогда — рубеж не записывался, каждый проход начинал с `newest`.
10. **Фаза `caught_up`** — рубеж у края (`newest − SETTLE`), читать нечего — здоровое состояние; `running` — только при
    чтении; ряд `watches_running` считает читающих (у догнавшего кластера — 0, отставание — `lag`).

## Запросы урока

Строка реестра `V/06 no-openapi` (своей двери у `detedge` нет) — запросом с главой V/06.1. Механизмов платформы сверх
выгруженных урок не просит.

## Отличия от свидетеля, которые урок записывает

Имя подсистемы — по ADR-0090 доп. (2), (11); рубеж — курсор состояния единицы, не файл ресурса (переживает переезд,
ADR-0091 п. 3); сохранение находок — подача воркером, не поле пульса `hits` и исполнитель заданий; запись — полем `rec`;
`older_epochs: earlier-run`; `alarms`; стёртое кольцом — счёт и событие; курсор при первом взятии (дефект `start: now`);
бюджет прохода кусками; чтение не больше одной сессии и с запасом сессии оператору; эпоха — при взятии единицы.

## Правки манифеста при переводе

Имя подсистемы (решение 1); поля `alarms`, `rec`; `start`, `keep` — перечнями (`enum`); `unit.state.cursor`; `events.older_epochs:
earlier-run`; `worker: {exec, reads: [cam/heartbeats/, rec/recordings/], requests: [rec]}` (`det/blobs/` снят: маска обхода —
своё поле, разбор ревью V/06, Н-1); `pre`, `post`, `join` — `schema: {minimum: 0, maximum: 600}`; ряд `filings_total`;
комментарии — без «пишет консоль», `frontier.json`, «две сессии» константой. V/01.5 Н2 — снять оговорку. Продукт — строкой
долга «Сборке».
