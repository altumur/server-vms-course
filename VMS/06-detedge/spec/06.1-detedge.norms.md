# V/06.1 — Обход — единица без конца: нормы

Канон главы 1 урока V/06 «Детекция по архиву устройства» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../06-detedge.md),
[инструкция](06-detedge.README.md), манифест [`detedge.subsystem.yaml`](../detedge.subsystem.yaml). Платформа — выгрузка
`cammeta-specs` `d3f8e05` (пин VMS; архив устройства — у камеры, `41d3ec8`).

Обход — одна модель смотрит архив устройства одной камеры, всегда. Глава нормирует имя подсистемы после перехода, строку
обхода, кто её заводит, размещение и снимок. Чтение — глава 2; рубеж и события — глава 3; сохранение находок и пульс —
глава 4.

Id норм — `V/06.1-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Данные** (общие семьи [каталога платформы](../../../Platform/common/data/catalog.tsv)): строка `detedge/watches/<name>` (P/06.1),
курсор `detedge/state/cursor/<watch>` (P/03.6 Н1.7), снимок `detedge/snapshot/*`; своих семей сверх них у главы нет.

### Н1.1 Имя

Подсистема `detedge` (ADR-0090 доп. (2), доп. (11)): манифест `detedge.subsystem.yaml`, `name: detedge`,
ключи `detedge/…`, слот `{prefix: e, name_env: DETEDGE_NAME}`, программа `/usr/lib/detedge/worker`, роль `detedgeworker`
(V/01.5 Н2), ряды `detedge_*`. Семья детекторов: `det` — живой поток (V/04), `detjob` — интервал нашего архива (V/05),
`detedge` — архив устройства.

### Н1.2 Поля

`unit: {rows: watches, id: name}`; `about: {sub: cam, field: cam}` — события, гранты и метки обхода — камеры.

| Поле | Форма | Смысл |
|---|---|---|
| `name` | `string`, обязательно | имя пары; соглашение — `<cam>-<kind>` |
| `cam` | `string`, обязательно, `fixed` | чей архив устройства смотреть: id камеры (основного потока; архив устройства — у камеры, V/01.5 Н1.1а); своего поля `stream` у обхода нет |
| `kind` | `string`, обязательно | вид модели — реестр детекторов (V/04.2 Н1.2), в том числе учебная `tick` |
| `params` | `string` | настройки модели, непрозрачны; предел — общий предел строки (413 `toolarge`, P/06.1 Н1.4) |
| `mask` | `blob` | маска телом (P/06.1 Н1.5) |
| `alarms` | `list`, умолчание `[]` | какие виды событий — тревоги; находки в старом архиве — наблюдения, тревогу оператор ставит явно |
| `start` | `now` \| `earliest`, умолчание `now` | откуда обход начинает в первый раз: край архива устройства или его начало (тридцать суток бэклога — решение, не умолчание) |
| `keep` | `none` \| `hits`, умолчание `none` | сохранять ли минуты вокруг находок в запись (глава 4) |
| `rec` | `string`, `ref: rec/recordings`, `must_match: {cam: cam}` | запись этой камеры, куда идут сохранённые минуты; при `keep: hits` нужна (без неё — `keep` не действует, `reason` в пульсе, глава 4) |
| `pre`, `post` | `float`, умолчание `5`, `schema: {minimum: 0, maximum: 600}` | секунд до и после находки; не шире окна прохода (`SECONDS_PER_PASS`, глава 2 Н1.2) |
| `join` | `float`, умолчание `30`, `schema: {minimum: 0, maximum: 600}` | находки ближе — один отрезок |
| `enabled` | `bool`, умолчание `true` | |
| `labels` | `list`, умолчание `["gpu"]` | метки сервера воркера |

Проверка строки, `fixed`, `ref`, `must_match`, перечни — [договор проверки строки](../../../Platform/common/contracts/row-check.md).

### Н1.3 Кто заводит

Только оператор — дверью единиц консоли (`POST /detedge/watches`, P/06.1). Заказов (`worker.creates`) у обхода нет: обход —
решение оператора, не реакция на событие. Работа не кончается: итога, `retire_when` и `ends` нет; обход снимают выключением
(`enabled: false`) или удалением строки.

### Н1.4 Размещение

| Ключ | Значение | Смысл |
|---|---|---|
| `capacity` | `{from: capacity, default: 2}` | обходов на воркер — свой бюджет: обход не тратит потоки живой детекции |
| `headroom` | `{from: headroom}` | запас — платформа (P/03.4 Н1.1) |
| `constraint` | `labels-subset` | |
| `requires` | `resource` | события — в ресурс своего сервера |
| `near` | `{sub: cam, by: cam}` | предпочтение: рядом с держателем камеры — архив идёт по петле, не по сети; `by: cam` — по полю, а не по имени обхода ([P/04 Н1.3](../../../Platform/04-controller/spec/04-controller.norms.md)) |
| `tie_break` | `most-free-capacity` | |

`home`, `grows`, `retire_when`, `ends` нет. Снимок — `snapshot: [name, cam, kind, enabled]` (P/04 Н1.3а): домену — «камеру 7
обходят».

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| нет `cam` или `kind` | 400 | ответ | — |
| `cam` меняется | 400 «cam is fixed …» | ответ | новый обход |
| `start` или `keep` не из перечня | 400 | ответ | — |
| `pre`, `post`, `join` вне `[0, 600]` | 400 по схеме | ответ | — |
| `rec` — запись другой камеры | 409 `must_match` | ответ | запись этой камеры |
