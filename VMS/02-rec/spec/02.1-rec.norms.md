# V/02.1 — Запись — единица: нормы

Канон главы 1 урока V/02 «Запись» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../02-rec.md),
[инструкция](02-rec.README.md), [приёмка](../acceptance/1/README.md), манифест [`rec.subsystem.yaml`](../rec.subsystem.yaml).
Платформа — выгрузка `cammeta-specs` `e747d1f`; ссылки `P/…` ведут в её `Platform/`.

Глава нормирует, что подсистема `rec` объявляет о записи: поля и их смысл, связь записи с камерой и томом, формы таблиц
`volumes` и `keeps`, значения размещения, срок записи, снимок и права людей. Как платформа исполняет каждое объявление —
нормы платформы по ссылке. Регистратор — глава 4; движок `obsd` — глава 2; виды томов — глава 6; удержания и метки —
глава 7; дозапись — глава 8; домен — глава 9.

Id норм — `V/02.1-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** `until` — секунды Unix (число); `min_depth_days`, `retention_days` — сутки.

**Данные** (общие семьи `<sub>/…` [каталога платформы](../../../Platform/common/data/catalog.tsv); своих ключей сверх них у главы
нет): пишет оператор — `rec/recordings/<id>`, таблицы `rec/volumes/<имя>`, `rec/keeps/<ключ>` ([P/06.1](../../../Platform/06-console/spec/06.1-console.norms.md)
Н1.1–Н1.3, Н1.6); заказчик `auto` — строку записи по сценарию (`worker.creates`, P/03.6 Н1.6; урок V/07); места
`rec/holds/<том>` — регистратор (P/03.2, глава 4).

### Н1.1 Запись

Единица `rec` — запись одной камеры в одно место: строка `rec/recordings/<id>`, `unit.id: name` — id — имя записи,
которое выбирает оператор (`7`, `7-cloud`); `about: {sub: cam, field: cam}` — события, гранты и метки записи — камеры.

| Поле | Объявление | Смысл | Кто читает |
|---|---|---|---|
| `name` | `string`, обязательно | имя записи: ключ, эпоха, потоки в томе (глава 3) | регистратор |
| `cam` | `string`, обязательно, `fixed` | чью камеру записывает: id камеры `cam` (V/01.1); не меняется | регистратор (источник, глава 4), `about` |
| `retention_days` | `int`, `30`, `≥ 1` | как далеко назад дверь записи показывает видео — потолок; что в томе есть, решает кольцо (глава 5) | дверь архива |
| `enabled` | `bool`, `true` | регистратор пишет только включённую | регистратор |
| `labels` | `list` | где может работать: регистратор, чей сервер несёт эти метки | размещение (`constraint`) |
| `home` | `string`, `ref: rec/volumes`, `must_match: {cam: cam}` | том, в котором лежит архив записи; том с полем `cam` (карта камеры, глава 6) — только для своей камеры | размещение (`home`, `affinity`) |
| `until` | `float`, `0` | конец записи; `0` — без конца (все ручные записи); запись по сценарию кончается сама (Н1.3) | контроллер (`ends`) |
| `min_depth_days` | `float`, `0` | пол глубины архива: меньше — тревога `archive.shallow` (глава 5) | регистратор |
| `when` | `always` \| `offline`, `always` | резервная запись (дом на томе `backup` или `edge`): всегда или только пока основная должна писать и не пишет (глава 6) | регистратор |

**Несколько записей одной камеры.** Запись — отдельная сущность: у камеры их может быть несколько (основная и резервная,
локальный и сетевой том; запись `7` и `7-cloud`). Развести копии по разным серверам — `placement.spread_by: cam`
(фильтр P/04 Н1.3); в поставляемом манифесте его нет: сетевому тому нужны обе записи на одной машине. Установка, которая
покупает выживание сервера, добавляет его себе. Имя первой записи камеры, которое предлагает страница (`<cam>`,
`<cam>-<том>`), — урок V/08.

### Н1.2 Таблицы

**`volumes`** — куда писать: строка `rec/volumes/<имя>`, пишет оператор (P/06.1 Н1.6); смысл видов и что каждый
меняет — глава 6.

| Поле | Объявление | Смысл |
|---|---|---|
| `name` | `string`, ключ | имя тома |
| `kind` | `local` \| `network` \| `backup` \| `edge` \| `incidents`, `local` | вид (глава 6) |
| `url` | `url`, обязательно; `credentials: {login: access_key, secret: access_secret}`, `secret_in` | где том: параметры, а не адрес с ключом (глава 3) |
| `server` | `string` | чей диск (`local`, `edge`, `backup`, `incidents`); у `network` — нет (его берёт любой) |
| `quota_bytes` | `int`, обязательно, `≥ 1` | размер кольца тома (глава 6) |
| `access_key` | `string` | ключ доступа бакета — какой ключ, не ключ; показывается |
| `access_secret` | `string`, `bound_to: [url]` | секрет бакета (P/06.2) |
| `enabled` | `bool`, `true` | объявлен ли том к записи (места — только `enabled`, Н1.3) |
| `shrink_confirmed` | `int`, `0` | подтверждение уменьшения квоты (глава 6) |
| `cam` | `string` | у `edge` — карта какой камеры; у прочих видов поля нет |
| `admits` | `bool`, `true` | принимает ли записи; у `incidents` — `false` |

Схема таблицы: `local` — обязателен `server`; `network` — без `server`; `incidents` — `admits: false`; `edge` — обязательны
`server` и `cam`, `url` — `file://` или путь, без `access_*`; `cam` — только у `edge`. Журнал таблицы —
`archive.volume.declared`, `archive.volume.withdrawn`.

**`keeps`** — метки «сохранить»: строка `rec/keeps/{cam}-{from:int}-{to:int}`, поля `cam`, `from`, `to` (секунды, > 0),
`note` (≤ 500), `recordings`, `released_at`; `stamp: [by, at, made_at]`; журнал `archive.keep.made`, `archive.keep.lifted`.
Смысл, удержания и копии — глава 7.

### Н1.3 Размещение и срок

Ключи и их смысл — [P/04 Н1.3](../../../Platform/04-controller/spec/04-controller.norms.md); `rec` объявляет:

| Ключ | Значение | Почему |
|---|---|---|
| `capacity` | `{from: capacity, default: 50, unit_mb: 38, base_mb: 51}` | камер на регистратор — его слово из пульса (диски и сеть) |
| `constraint` | `labels-subset` | — |
| `requires` | `resource` | единственная подсистема, которой надо быть там, где архив |
| `places` | `{table: volumes, where: {enabled: true}, server_field: server, lease: strict}` | том — место: его держит один регистратор (P/03.2 Н1.3, глава 4) |
| `place_by` | `volume` | `distinct` и `home` считаются по диску, не по коробке |
| `servers` | `distinct` | один регистратор на том несёт записи (остальные на коробке без места) |
| `home` | `home` | поле строки, называющее том её архива; дом держится |
| `affinity` | `{field: home, table: volumes, server_field: server, strict: {kind: [backup, edge], enabled: true}}` | запись на резервном томе или карте — только на сервере этого тома (глава 6) |
| `grows` | `true` | воркеры по заказу: том, который никто не держит, — нехватка (P/04 Н3 «нехватка(), заказать()» для `servers: distinct` с местом из пульса); запасных нет (ADR-0084) |
| `ends` | `{field: until, never: 0}` | конец записи (ADR-0091 п. 2) |
| `tie_break`, `rebalance` | `most-free-capacity`, `{dead_band: 0.10}` | — |

**Срок записи** (`ends`): запись с `until` ≠ 0 и не позже часов контроллера снимается с размещения; строку заказа
(запись по сценарию, `made`) контроллер удаляет физически, когда его часы строго позже `made.keep`; ручную запись с
прошедшим сроком — снимает и не удаляет (`expired_kept`), её удаляет оператор (P/04 Н1.3, P/03.6 Н1.6).

### Н1.4 Снимок и права

`snapshot: [name, cam, retention_days, enabled, until, labels, home, when]` — форма P/04 Н1.3а; `when` — домен находит
резервную `offline` записи камеры другого кластера (глава 9). Права людей ([P/06.3 Н1.5](../../../Platform/06-console/spec/06.3-console.norms.md)):
`unit_of: {keeps: cam}` — метка принадлежит камере; `routes: {edit: [keeps]}` — ставить метку хватает `edit`;
`reach: {cluster: [home]}` — перенос записи на другой том — дело кластера (ADR-0057).

## Н3 Проход

### Запись строки записи (дверь P/06.1)

```
тело → поля Н1.1; name, cam — обязательны
cam при правке иным значением → 400 «cam is fixed»
home: тома нет → 409 conflict (ref); у тома есть cam ≠ cam записи → 409 conflict, fault: must_match
retention_days < 1, when вне enum → 400
id с префиксом «auto-» → 400 (имена заказчика auto, P/06.1 Н1.3 made_prefix)
права: reach.cluster — грант на кластер при смене home
```

**Гонки.** Том удалили после записи строки — ссылка цели не требует (ADR-0057): запись хранит прежний `home`, размещение
её не ставит (места нет), строка остаётся.

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| нет `name` или `cam` | 400 «a rec unit needs a …» (P/06.1 Н4) | ответ | — |
| `cam` меняется | 400 «cam is fixed …» | ответ | новая запись |
| `home` — нет тома / чужая карта | 409 `conflict`, `fault: must_match` (P/06.1 Н4) | ответ | другой том |
| `retention_days` < 1, `when` вне списка | 400 | ответ | — |
| id `auto-…` | 400 «names starting with "auto-" are made by auto» | ответ | другое имя |
