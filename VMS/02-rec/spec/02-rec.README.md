# V/02 Запись — инструкция для реализации

Что реализация подсистемы `rec` делает и как проверить результат. Канон — нормы глав `02.K-rec.norms.md`; эта
инструкция их не дополняет. Платформа — выгрузка `cammeta-specs` `e0b19be`.

## Результат по главам

| Глава | Что есть у реализации | Проверка |
|---|---|---|
| V/02.1 | манифест `VMS/02-rec/rec.subsystem.yaml` грузится строгим загрузчиком без правок; дверь единиц и таблиц консоли исполняет объявления записи | [приёмка 1](../acceptance/1/README.md) |
| V/02.2 | клиент движка по [договору `obsd`](02-rec.obsd.contract.md) и обязанностям Н1.5; движок ObjectStorage с патчами 01–07; часть `obsd` ставит установщик платформы по манифесту | чтением; приёмки глав 3–5 на живом `obsd` |
| V/02.3 | потоки в томе по Н1.1, отказы тома Н1.4, открытие тома Н1.5, кадр в писатель Н1.6, перемонтирование | чтением; приёмки глав 4–5 |
| V/02.4 | регистратор `recworker`: источник, конвейер записи, места-тома, отказы, уход с тома, остановка (`worker.stop_timeout` 40), сторож писателя, пульс; команда запуска для «Стенда» — в описании реализации | [приёмка 4](../acceptance/4/README.md) |
| V/02.5 | дверь архива по [OpenAPI](02-rec.api.openapi.yaml): видимость и потолок, правило эпохи, муксер fMP4, адрес, журнал, допуск | [приёмка 5](../acceptance/5/README.md) |
| V/02.6 | виды томов, квота-кольцо, секрет тома, резервная `offline` с предзаписью, копия из резервной, карта камеры (регистратор камеры-кластера), `incidents` | чтением |
| V/02.7 | метки: копия в `incidents`, печать и сверка (функция дайджеста — в описании реализации), пропажа, сторона записи, ответ `freeing` | чтением |
| V/02.8 | дозапись (план, бюджет, окно, выкачка, посадка), просьба с профилем `fetched`, заказ скана `worker.creates` к `detjob` | чтением |
| V/02.9 | запись в каталоге домена (`ref`, назначение), источник чужой камеры, приёмник (допуск токеном, опрос, `have`, время кадра, тройник; транспорт — в описании реализации), заявка диапазона, соседи, книги `primaries`, `polls`, резерв по книге, передатчик и звезда, свидетель `rec/polled` | чтением |

Манифест — данные спецификации: реализация читает его байты как есть (ADR-0090 доп. (6) п. 8).

## Порядок

Сначала платформа (генерация стадии C, прошедшая приёмку платформы), затем `cam` (V/01), затем `rec` — приёмка VMS идёт
только на такой платформе (ADR-0090 доп. (8), (9)).
