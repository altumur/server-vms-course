# V/02 Запись — инструкция для реализации

Что реализация подсистемы `rec` делает и как проверить результат. Канон — нормы глав `02.K-rec.norms.md`; эта
инструкция их не дополняет. Платформа — выгрузка `cammeta-specs` `e0b19be`.

## Входы и их приоритет

- Канон — нормы глав `02.K-rec.norms.md` (Н1–Н5 каждой главы; адреса `V/02.K Н…`).
- Канон манифеста — [`rec.subsystem.yaml`](../rec.subsystem.yaml): байты как есть.
- [Контракт](02-rec.api.openapi.yaml) выражает формы HTTP-входов канона.
- Приёмка — [глава 1](../acceptance/1/README.md), [глава 4](../acceptance/4/README.md), [глава 5](../acceptance/5/README.md); стенд и словарь — [общий README приёмки VMS](../../common/acceptance/README.md); новых требований приёмка не вводит.
- [Лекция](../02-rec.md) объясняет причины; платформа — нормы выгрузки пина VMS по адресам `P/…` (их правит не VMS).

Противоречие записать с местом и контрпримером (раздел «При расхождении»); произвольный отказ не заменяет
отсутствующую норму. Устройство кода остаётся реализации в рамках канона.

## Порядок

Сначала платформа (генерация стадии C, прошедшая приёмку платформы), затем `cam` (V/01), затем `rec` — приёмка VMS идёт
только на такой платформе (ADR-0090 доп. (8), (9)).

## Ловушки

| Норма | Возможная ошибка | Как сохранить поведение |
|---|---|---|
| V/02.4 Н1.5 | считать отдельный срок у слива, `FINISH_MEDIA` и `WRITER_CLOSE` | один срок — «конец закрытия»; не закрылся — `WRITER_ABANDON` |
| V/02.5 Н1.3 | отдавать отсечённую эпоху наравне со старшей | автоматический выбор — по ключу `(epoch, live)`, отсечённая проигрывает; явный `stream` — его кадры |
| V/02.5 Н1.2 | сообщать недоступное заголовками ответа `/timeline` | недоступное — в теле `{spans, unreachable, unavailable}` |
| V/02.2 Н1.1, Н1.3 | запускать движок `obsd` напрямую и ждать, что он прочтёт файл подсистемы | часть — обёртка VMS: читает файл по `W2C_SUB_ENV` и передаёт движку ключи `OBSD_*` окружением |
| V/02.9 Н2 | считать местный стык одного сервера договором | между серверами и кластерами — шесть путей `/ingest/*`; местный стык — выбор реализации |
| V/02.1 Н1.1 | отказывать записи на томе без поля `cam` | у `home` нет `must_match`; страж — регистратор карты |

## Готово, когда

Манифест грузится строгим загрузчиком без правок; приёмка глав 1, 4, 5 проходит на платформе, прошедшей свою приёмку;
пункты чеклистов, отмеченные «чтением», подтверждены описанием реализации (раздел «Решает реализация» каждой главы).
Проверка схемы, загрузчика и стенда друг друга не подменяют.

## При расхождении

Порядок источников: нормы главы → OpenAPI → приёмка и векторы → лекция; платформа — нормы выгрузки пина VMS.
Норма молчит или противоречит себе — вопрос «Спецификации VMS» с местом, контрпримером и предложением; норма
платформы — через «Архитектора». Дефект приёмки (ожидание против нормы) — тот же маршрут; закрытое решение
вносится в канон, а не остаётся в этой инструкции.
