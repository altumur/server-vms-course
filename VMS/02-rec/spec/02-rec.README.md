# V/02 Запись — инструкция для реализации

Что реализация подсистемы `rec` делает и как проверить результат. Канон — нормы глав `02.K-rec.norms.md`; эта
инструкция их не дополняет. Платформа — выгрузка `cammeta-specs` `5a39bd5`.

## Порядок

Сначала платформа (генерация стадии C, прошедшая приёмку платформы), затем `cam` (V/01), затем `rec` — приёмка VMS идёт
только на такой платформе (ADR-0090 доп. (8), (9)).
