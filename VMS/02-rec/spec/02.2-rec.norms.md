# V/02.2 — Движок `obsd` — часть `rec`: нормы

Канон главы 2 урока V/02 «Запись» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../02-rec.md),
[инструкция](02-rec.README.md), [договор `obsd`](02-rec.obsd.contract.md), манифест [`rec.subsystem.yaml`](../rec.subsystem.yaml).
Платформа — выгрузка `cammeta-specs` `e0b19be`.

Видео лежит в томах движка архива `obsd` (ObjectStorage): это служба хоста, а не библиотека в процессе регистратора и не
контейнер, — один демон на сервер, чтобы «один писатель на том» значило что-то: все регистраторы сервера спрашивают один
демон. Для платформы движок — **часть** подсистемы `rec` со своей службой и пользователем (ADR-0091 п. 5); видео
платформа не знает. Протокол сокета и свойства движка — [договор `obsd`](02-rec.obsd.contract.md) (главы V/02.3–V/02.5
ссылаются на него, не повторяют); глава нормирует, что `rec` объявляет и требует от части: служба, доля сокета,
окружение, сроки, версия движка, обязанности клиента.

Id норм — `V/02.2-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Время архива — договор `obsd` «Время и запись SMPL».

**Данные.** Строк хранилища у главы нет: тома — файлы и бакеты движка; состояние части —
`/data/platform/subsystems/rec/obsd` ([P/02.4 Н1.1](../../../Platform/02-installer/spec/02.4-installer.norms.md) `dirs`).

### Н1.1 Часть `obsd`

`parts: {obsd: {exec: "/usr/lib/rec/obsd-part", volumes: true, stop_timeout: 60}}` — обёртка VMS, движок — `/usr/local/bin/obsd`
([P/02.1](../../../Platform/02-installer/spec/02.1-installer.norms.md) `parts`; юнит части, пользователь, каталоги, раннер
`w2c-run.sh part rec obsd` — P/02.4 Н1.1, Н1.9; путь сокета — `OBSD_SOCKET` файла подсистемы, Н1.3, не аргумент `exec`; движок файла подсистемы не читает — свои ключи
берёт из окружения (сокет — `OBSD_SOCKET` или аргумент `--socket`, без них — свой путь `/run/vms/obsd.sock`), а юнит части
окружения из файла не даёт (P/02.4 Н1.1: только `W2C_SUB_ENV`, `EnvironmentFile=` не используется); поэтому `exec` части —
обёртка VMS: читает файл подсистемы по `W2C_SUB_ENV` (договор файла окружения) и запускает движок с ключами `OBSD_*`
файла в окружении, сокет — всегда, с умолчанием Н1.3):

- служба `vms-rec-obsd.service`, пользователь и группа `vms-rec-obsd`; часть стартует сама до воркеров `rec`; юнит
  регистратора — `After=` части без `Wants`: перезапуск регистратора движок не трогает, пропажа движка регистратор не
  останавливает (регистратор переживает её сам — глава 4);
- состояние — `/data/platform/subsystems/rec/obsd` (`0700`); тома — точки монтирования
  `/data/platform/subsystems/rec/obsd/volumes/<n>` пользователя части (`volumes: true`; монтирует оператор, установщик
  проверяет владельца при старте);
- `stop_timeout: 60`: по SIGTERM движок закрывает всех писателей параллельно, каждый до 30 с, и выходит не позже 45 с с
  кодом 3, назвав застрявших (договор «Остановка демона»).

### Н1.2 Доля сокета

`shares: {obsd: {kind: socket, part: obsd}}` — доля части: каталог `/run/vms-rec-obsd` `2750 vms-rec-obsd:vms-rec-obsd`,
сокет `obsd.sock` `0660` — умолчание `OBSD_SOCKET` (Н1.3) `/run/vms-rec-obsd/obsd.sock` (P/02.4 Н1.1 `dirs`;
ADR-0091 доп. (2) п. 4, доп. (3) п. 3 — каталог в `ReadWritePaths` части); регистратор объявляет `worker.uses: [rec.obsd]` и получает группу части. Путь сокета короче `sun_path` (договор
«Транспорт»). Демон допускает пир чужого uid только из `OBSD_CLIENT_GROUP` = `vms-rec-obsd`.

### Н1.3 Файл подсистемы

Файл подсистемы `/etc/rec/rec.env` (`W2C_SUB_ENV`, P/02.4 Н1.2) — один на часть и регистраторов сервера: раннер части
читает значения юнита и только его, регистратор — его вместе с файлами платформы ([договор файла
окружения](../../../Platform/common/contracts/env-file.md): файла нет — умолчания; строка не по грамматике договора или
файл не читается — отказ запуска, код 2). Все ключи `rec` — эта таблица; главы ссылаются сюда. Значение не по грамматике
ключа — отказ запуска того, кто его читает, код 2, строка журнала называет ключ (значение — без секретов: их здесь нет).

| Ключ | Кто читает | Грамматика | Умолчание | Почему, где норма |
|---|---|---|---|---|
| `OBSD_SOCKET` | обёртка `exec` части (движку — окружением), регистратор | абсолютный путь короче `sun_path` (договор «Транспорт») | `/run/vms-rec-obsd/obsd.sock` | сокет доли Н1.2; стенд задаёт свой каталог экземпляра (общий README приёмки VMS) |
| `OBSD_WRITER_GRACE_S` | часть | целое ≥ 1 | `90` | отсрочка писателя того же `owner` (договор «Отсрочка») больше срока места P/03.2 Н1.2 (45 + `HOLD_SKEW` = 50): перезапущенный регистратор подхватывает свой том (`reattached`) раньше, чем место уйдёт |
| `OBSD_CLIENT_GROUP` | часть | имя группы | `vms-rec-obsd` | Н1.2 |
| `OBSD_LOG_LEVEL` | часть | `off` \| `error` \| `warning` \| `info` \| `debug` | `warning` | — |
| `SEQUENCE_FLUSH_MS` | регистратор | целое ≥ 0; 0 — умолчание движка | `10000` | период резки последовательности, глава 3 Н1.5 |
| `BLOCK_FLUSH_S` | регистратор | целое ≥ 0; 0 — умолчание движка | `5` | период сброса блока, глава 3 Н1.5 |
| `ARCHIVE_HOST` | регистратор | необязателен; задан — адрес по правилу двери: `SERVER_NAME` с комплектом роли, `127.0.0.1` без него | — (по правилу) | адрес двери архива, глава 5 Н1.7; иной или `0.0.0.0` — отказ старта, код 2 |
| `ARCHIVE_PORT` | регистратор | целое 0–65535; 0 — порт ОС | `0` | порт двери архива, глава 5 Н1.7 |
| `BACKFILL_BUDGET` | регистратор | целое ≥ 0; 0 — только просьбы | `1` | диапазонов дозаписи за проход, глава 8 Н1.2 |
| `BACKFILL_WINDOW` | регистратор | `^(\d\|1\d\|2[0-3])-(\d\|1\d\|2[0-3])$` — часы начала и конца по местному часу сервера, с переходом через полночь (`22-6`) | нет — любой час | окно дозаписи, глава 8 Н1.2 |

Прочие переменные движка (`OBSD_SESSION_LINGER_MS` 3000, `OBSD_MAX_FRAME`, `OBSD_RESIZE_STEP_MB` 1024, потоки) — умолчания
движка; файл подсистемы их не задаёт.

### Н1.4 Версия движка

ObjectStorage — дерево `2bbee4a` (2026-10-02) с патчами 01–07 (`standalone-build/patches/`): 01 — сборка на macOS; 02, 03 —
тесты; 04 — пробуждение по таймеру сброса блока (без него блок закрывается через минуту, а не через
`blockFlushPeriodSec`); 05 — чтения индекса порциями (таймлайн за ≥ 6 дней); 06 — armv7 (поля заголовков по значению);
07 — ограда замка тома и `WRITER_ABANDON` (`37e2d0e`). Без 07 демон не годится: курс его не поддерживает — регистратор
проверяет `WRITER_ABANDON` при подключении (`UNKNOWN_OP` — нет ограды). Сборка — `standalone-build/build.sh` в
`/usr/local/bin/obsd`; что кладёт её в образ — урок V/09.

### Н1.5 Обязанности клиента

Регистратор — клиент движка (глава 4); от клиента `rec` требует:
- `client` в `HELLO` — роль процесса (`recworker`), не имя продукта;
- `owner` писателя — `rec:<том>`: тот же у перезапущенного регистратора того же места (отсрочка подхватывает том);
  уникальность даёт место платформы (P/03.2), не движок;
- срок вызова — `OBSD_TIMEOUT` = 10 с; вызовы движка — не на потоке аренд (P/03.2 Н1.6): долгий вызов не задерживает
  продление места; дольше срока вызова ждут только `FINISH_MEDIA` и `WRITER_CLOSE` при закрытии писателя — до «конца
  закрытия» главы 4 Н1.5 (`WRITER_CLOSE` — не дольше 30 с договора);
- обрыв после отправки неидемпотентного запроса — не повторять вслепую (договор «Повтор»); неотвеченный
  `VOLUME_MOUNT_RW` — возможный писатель без хэндла: сессию отпустить без `BYE`, монтировать заново тем же `owner`
  (глава 3 Н3);
- параметры тома — `params`, не `uri`: ключ бакета не попадает в адрес и журнал (V/02.1 Н1.2, P/06.2).

## Н3 Проход

Своего прохода у главы нет: часть живёт по своему юниту (P/02.4 Н1.1), протокол — договор, клиент — главы 3, 4.

**Гонки.** Два регистратора одного сервера на одном томе — второй `VOLUME_MOUNT_RW` — `ALREADY_LOCKED` (один писатель на
хосте); на разных серверах — ограда патча 07 по замку тома и место платформы (P/03.2) — глава 3.

## Н4 Отказы

| Причина | Исход | Кто и как видит | Что делает вызывающий |
|---|---|---|---|
| путь сокета длиннее `sun_path` | демон не стартует | журнал юнита части | короче путь |
| `OBSD_CLIENT_GROUP` — неизвестная группа | демон не стартует | журнал | группа части |
| пир не в группе | соединение отвергнуто | регистратор — `away` (глава 3) | `worker.uses: [rec.obsd]` |
| демон без патча 07 | `WRITER_ABANDON` — `UNKNOWN_OP` | регистратор: том не берётся, журнал | движок с патчами 01–07 |

## Решает реализация

## Соответствие прежним урокам

Из М10B/06 «ObjectStorage» — шаги 1–14 (процесс, кадр, сессия, обрыв и молчание, время архива и SMPL, том, писатель,

([id-map](../../common/id-map.tsv)): М10B/06 ш.1, М10B/17 ш.5 → V/02.2-01; М10B/17 ш.5 (группа, сокет) → V/02.2-02; М10B/06
