# V/02.5 — Видимость, срок, таймлайн и дверь архива: нормы

Канон главы 5 урока V/02 «Запись» (ADR-0080; модуль VMS — ADR-0090). [Лекция](../02-rec.md),
[HTTP-контракт](02-rec.api.openapi.yaml), [инструкция](02-rec.README.md), [приёмка](../acceptance/5/README.md),
[договор `obsd`](02-rec.obsd.contract.md). Платформа — выгрузка `cammeta-specs` `6e51975`.

Глава нормирует, что из тома видно и кому: видимость записанного, срок хранения как потолок, таймлайн записи с правилом
«один момент — одна эпоха», дверь архива регистратора — процессам (`/spans`, `/samples`) и странице (`/timeline`,
`/segment`, `/keeps`), куски fMP4, адрес двери и глубину архива. Протокол движка — договор `obsd`; потоки в томе —
[глава 3](02.3-rec.norms.md); страница — урок V/08 (что она зовёт — здесь).

Id норм — `V/02.5-MM`; соответствие прежним урокам — [`id-map.tsv`](../../common/id-map.tsv).

## Н0 Словарь слов

Нормативные слова — по [канону курса](../../../НОРМАТИВНЫЕ-СЛОВА.md). Правила модуля «Платформа» — [P/01.1 Н0](../../../Platform/01-store/spec/01.1-store.norms.md#н0-словарь-слов).

## Н1 Форма

**Время.** Наружу — секунды Unix (`/spans`, `/samples`: `from`, `to`, `start`, `end`) и миллисекунды Unix (`/timeline`:
`start_ms`, `end_ms`; путь `/segment`); `from`, `to` — конечные числа (`nan`, `inf` — отказ).

**Данные** (общие семьи [каталога платформы](../../../Platform/common/data/catalog.tsv)): читает — `rec/recordings/<id>`
(срок, пол глубины), таблицу `rec/keeps/*` (удержания видны за потолком), `rec/epoch/<id>` (отсечение), пульсы `rec/*` и
`cam/*`; пишет — строки событий `archive.shallow` (бакет записи), строки журнала `archive.read` (Н1.8).

### Н1.1 Видимость

- **Записано ≠ видно:** дверь отвечает только о видимом (договор «Видимость»: закрытые блоки к моменту монтирования
  читателя); каждый вопрос — свежий читатель; только что записанное появится позже. Когда записанное нужно увидеть
  сейчас (копия удержания, глава 7), регистратор закрывает блок (`seal`: закрыть и снова открыть писателя).
- Регистратор планирует по видимому: дыры — только до конца видимого покрытия; скопированное, но ещё невидимое — не дыра.

### Н1.2 Срок — потолок

- `retention_days` записи — как далеко назад дверь показывает видео: видно с `now − retention_days × 86400`; что в томе
  лежит, решает кольцо (договор «Кольцо»), по возрасту ничего не удаляется.
- Потолок применяется к **ответу**, не к вопросу: каждый спан и каждый кадр режется по видимому множеству — `[видно с,
  ∞)` ∪ интервалы удержаний этой записи (`keeps`, глава 7): удержанное видно и за потолком.
- Том `incidents` (глава 6) показывает всё (потолка нет).
- Строка записи читается на каждый вопрос: нет строки или надгробие — 30 сут; хранилище молчит — последняя прочитанная
  строка (30 сут — только если не читал ни разу); значение не конечное неотрицательное число — видно с `now` (прятать
  безопасно), счёт `ceilings_garbled` в пульсе. Удержания не прочитались — потолок стоит.
- Потолок не обещает глубины: пол `min_depth_days` — наблюдение (Н1.9).

### Н1.3 Таймлайн и «один момент — одна эпоха»

- Таймлайн записи — все её потоки в томе (`<запись>/e<n>`, `…/backfill`, `…/e0`, глава 3), из индекса (договор
  `READER_TIMELINE`; запрос за много суток регистратор МОЖЕТ резать окнами), отсортированные по `(start, epoch)`;
  касающиеся куски (шов ≤ 2 с) склеиваются в покрытие.
- **Отсечённая эпоха** (`epoch` < эпохи записи в хранилище, `rec/epoch/<id>`; копия `e0` не отсекается) показывается и
  помечается `fenced: true`; при чтении кадров — не берётся (правило ниже).
- **Один момент — одна эпоха** (`authoritative`): границы — `from`, `to` и все начала и концы спанов между ними; каждый
  элементарный промежуток отдаётся старшему из покрывающих по ключу `(epoch, live)`: при равной эпохе живой поток
  побеждает дозаписанный; копия `e0` проигрывает любой настоящей эпохе; соседние промежутки одного спана склеиваются.

### Н1.4 Дверь архива: маршруты процессам

Контракт — [OpenAPI](02-rec.api.openapi.yaml). Допуск — Н2.

| Маршрут | Ответ 200 |
|---|---|
| `GET /spans/<запись>?from&to` | `{unit, spans: [{start, end, epoch, source: live \| backfill, bytes, fenced}], current_epoch, held_since, now}` — видимое (Н1.1, Н1.2); `current_epoch` — эпоха записи у этого регистратора; `held_since` — стенные часы регистратора при взятии эпохи (`null` — тома нет, том `incidents`, запись не своя); `now` — часы двери: читатель переводит `held_since` на свои часы |
| `GET /samples/<запись>?from&to[&stream=<epoch>[/backfill]]` | записи SMPL подряд (договор «Время и запись SMPL»), `application/octet-stream`; без `stream` — по правилу Н1.3 (каждый отрезок — от эпохи-владельца, с подводкой от ключевого кадра не позже начала отрезка); с `stream` — кадры только этого потока; HTTP/1.1 — chunked, без `Content-Length`; пусто — 200 без тела; отказ после первого байта — обрыв без последнего куска |

`from` по умолчанию 0, `to` — часы двери + 86400. Тома нет — 503 `{"error": "no volume open here"}` («сейчас нельзя», не
«записи нет»).

### Н1.5 Дверь архива: маршруты странице

`door: {routes: [timeline, segment, keeps]}` манифеста — выдача двери и токена — [P/06.5 Н3](../../../Platform/06-console/spec/06.5-console.norms.md)
`/where/<id>`, `/where/<table>/<place>`; проверка токена — [P/03.4 Н3](../../../Platform/03-worker/spec/03.4-worker.norms.md)
«токен двери у держателя», договор токена двери (отказ — 403 `{"error": "forbidden"}`; страница на 403 перезапрашивает
`/where` один раз).

| Маршрут | Ответ 200 |
|---|---|
| `GET /timeline/<запись>?from&to` | список `[{start_ms, end_ms, epoch, source?, fenced?, yields?}]` по `(start_ms, epoch)`: потоки записи со всех живых дверей регистраторов (их `/spans`, срок вопроса 5 с, тело ≤ 16 МиБ) и спаны архива устройства (`{epoch: 0, source: device, yields: true}` из `coverage` держателя камеры, V/01.5 Н1.1); заголовки `X-Unreachable` (регистраторы, чья дверь не ответила или ответила неполно), `X-Unavailable` (`<том>@<сервер>` томов этой записи без живого держателя) |
| `GET /segment/<запись>/e<эпоха>/<fromMs>-<toMs>[.backfill \| .device].mp4` | кусок fMP4 (Н1.6): `.mp4` — живой поток эпохи (`e0` — копия удержания), `.backfill.mp4` — её дозапись, `.device.mp4` (только `e0`) — архив устройства; HTTP/1.1 — chunked; `X-Unreachable`, если дверь отпала до первого байта |
| `POST /keeps/<метка>/verify?recording=<id>` | сверка копии удержания — глава 7 |

Живая дверь — регистратор, чей пульс менялся за 45 с по часам читателя (`fresh_for`, P/03.4 Н1.1).

### Н1.6 Кусок fMP4

Сборка: `/spans` у живых дверей → спаны эпохи и источника куска → Н1.3 над ними → кадры у двери-владельца `/samples`
с `stream` кусками по 60 с (срок 30 с) → слияние по времени, каждый момент один раз (кадр раньше конца предыдущего —
пропуск) → до первого ключевого кадра — пропуск → файл. На проводе:

- `ftyp` (`iso5`, minor 512, совместимые `iso5 iso6 mp41 avc1`); `moov`: `mvhd` (timescale 1000, длительность 0), один
  `trak` (`track_id` 1, `hdlr` `vide`, `stsd` → `avc1` → `avcC`), пустые `stts`, `stsc`, `stsz`, `stco`, `mvex/trex`;
- `avcC` — профиль из SPS потока (не из строки камеры): `[1, sps[1], sps[2], sps[3], 0xFF, 0xE0 | nSPS]`, SPS и PPS с длиной
  u16; ширина и высота — из `sub` записи SMPL; нет SPS или PPS — 415 `not playable`;
- сэмпл — AVCC (каждый NAL с длиной u32 BE; NAL 7, 8, 9, 12 выброшены); длительность — `max(1, end − begin)` мс;
- фрагмент на каждом ключевом кадре: `moof` (`mfhd` seq; `traf`: `tfhd` с `default-base-is-moof`, `tfdt` v1 u64 мс,
  `trun` с флагами `0x000701` — смещение данных от первого байта `moof`) + `mdat`; флаги сэмпла: ключевой — `2<<24`, иной —
  `(1<<24) | (1<<16)`;
- шкала куска начинается с 0 (позицию в сутках знает страница); тот же интервал — тот же файл байт в байт.

`.device.mp4`: регистратор читает `/playback/<камера>?from&to` у держателя камеры (V/01.5; сертификат роли `recworker`) и
отдаёт байты как пришли; держателя или покрытия нет — 404 `no device archive`; длиннее 3600 с — 400 `range too long`.

Пределы куска: длиннее 3600 с — 400 `bad range`; одновременно — 2 куска на дверь, 1 на человека (`user` токена); сверх —
503 `busy` с `Retry-After: 5`; пределы соединения — P/03.4 Н1.7 `door_limits`.

### Н1.7 Адрес двери

`ARCHIVE_HOST`:`ARCHIVE_PORT` файла подсистемы `/etc/rec/rec.env`: без `ARCHIVE_HOST` — петля `127.0.0.1`; `0.0.0.0` или
`::` — отказ старта, код 2; `ARCHIVE_PORT` не задан или 0 — порт ОС. Адрес в пульсе (`url`, P/03.4 Н1.1):
`<схема>://<хост>:<порт>` — хост `127.0.0.1` на петле, иначе `SERVER_NAME` (совпадает с SAN сертификата роли); схема —
`https` с комплектом роли `recworker`, `http` только на петле (P/02.4 Н1.6). То же правило — у `live_url` и `playback_url`
держателя камеры (V/01.2 Н1.3, V/01.5 Н1.2). Имена серверов — предпосылка развёртывания (DNS или хосты оператора), установщик предупреждает ([ADR-0091 доп. (7)](../../../decisions/0091-механизмы-платформы-по-запросам-vms.md)).

### Н1.8 Журнал выдачи

Каждая выдача страничного маршрута — строка `archive.read` в журнале `audit/recworker/e1` (договор журнала событий): `user`
(токен), `media` (`rec/<запись>/e<эпоха>[/backfill|/device]/<from>-<to>`), `addr`, `status`, `bytes`, `target`, `of` (`rec/<запись>`),
`sha256` (только у целого файла), `unreachable`, `broken`; часть файла меньше 1 МиБ — не чаще строки в минуту на пару (кто,
`media`). Журнал двери — `audit/<роль>/e1` с общими полями, виды называет урок-владелец; CORS двери — консоль кластера и
домена, `GET`/`HEAD`/`OPTIONS`, заголовок `Authorization`, без куки ([ADR-0091 доп. (7)](../../../decisions/0091-механизмы-платформы-по-запросам-vms.md)).

### Н1.9 Глубина

Раз в минуту (не при потерянном движке): `depth_days` записи = `(now − начало покрытия) / 86400` (дыры не вычитаются,
потолок не влияет), в статус записи; тревога `archive.shallow` (класс `alarm`, бакет записи под её эпохой, поля `cam`,
`depth_days`, `min_depth_days`) — пол задан, кольцо замкнулось (`firstBlockId > 0`), глубина меньше пола, эпоха записи —
у этого регистратора; повтор — раз в сутки; снятие условия очищает отметку.

## Н2 Двери

Дверь архива регистратора — [OpenAPI](02-rec.api.openapi.yaml); один слушатель (Н1.7). С комплектом роли `recworker` —
TLS; сертификат клиента запрашивается необязательно и проверяется в рукопожатии; процессные маршруты (`/spans`,
`/samples`) требуют предъявленную роль `recworker` или `detjobworker` (иначе 403); страничные (`/timeline`, `/segment`,
`/keeps`) — токен двери (Н1.5; единица токена — запись из пути или `?recording=`, лежащая в держимом томе). Без комплекта —
петля, процессные маршруты — любой процесс сервера. Это класс `mixed` решения [ADR-0091 доп. (7)](../../../decisions/0091-механизмы-платформы-по-запросам-vms.md) (на ревью; норма — после выгрузки):
у каждого маршрута `door.routes` — допуск `role: […]` или `token`; манифест `rec` получает эту форму при переходе на
выгрузку с нормой.
Иной метод — 405, иной путь — 404. Своей страницы `/metrics` у двери нет (V/02.4 Н1.8). Кластер из одного до первой
публикации — 503 `not_ready` (P/02.4 Н1.10).

## Н3 Проход

Своего прохода у двери нет: каждый вопрос — свежий читатель тома (Н1.1), строка записи и удержания — на каждый вопрос
(Н1.2). Глубина — раз в минуту проходом регистратора (Н1.9).

**Гонки.** Запись переехала к другому регистратору между `/timeline` и `/segment` — кусок собирается со всех живых дверей
по их `/spans`; дверь, отпавшая до первого байта, — `X-Unreachable`; после — обрыв, страница спрашивает снова. Два вопроса
во время записи — каждый видит закрытое к моменту своего монтирования.

## Н4 Отказы

| Причина | Код | `error` |
|---|---|---|
| тома нет | 503 | `no volume open here` (процессам) |
| `from`/`to` не конечные числа, `t1 ≤ t0`, кусок длиннее 3600 с | 400 | `bad range` |
| в интервале нет записанного | 404 | `nothing recorded` |
| устройства или покрытия нет (`.device.mp4`) | 404 | `no device archive` |
| путь не по форме | 404 | `no such path` / `no such segment` |
| SPS или PPS нет | 415 | `not playable` |
| пределы куска | 503, `Retry-After: 5` | `busy` |
| пределы двери (P/03.4 Н1.7) | 503, `Retry-After: 1` | `busy` |
| токен не годен | 403 | `forbidden` |
| роль клиента не допущена | 403 | `forbidden` |
| иной метод | 405 | — |

## Соответствие прежним урокам

Из М10B/08 — видимость, срок, таймлайн, дверь архива; из М10B/20 — сторона `rec` (`/spans`, `held_since`, правило эпохи);
из М10B/24 — fMP4 и маршрут `/segment`; из М10B/15 шаги 7–9 — своё чтение, `source: device`, `.device.mp4`; из М10B/28 шаги
3–4 — где том и где дверь, таймлайн по двум томам; из М10B/18 шаги 3–4 — глубина. Отличия от свидетеля: допуск процессам —
сертификат роли (ADR-0075 окно 2), странице — токен двери платформы (403 `forbidden`, а не 401 со словом; claims договора);
`/samples` получает выбор потока (`stream`) — кусок одной эпохи и в томе с несколькими эпохами; копия удержания `e0`
проигрывается `/segment/<запись>/e0/…mp4` (у свидетеля — 404); `ARCHIVE_URL` с адресом снят — хост `SERVER_NAME`,
`0.0.0.0` — отказ старта; журнал — `audit/recworker`, `media` с эпохой и источником; `nan`/`inf` в `from`/`to` — отказ;
`X-Unavailable` — только тома этой записи; своей `/metrics` нет; пределы двери — P/03.4 Н1.7. Id
([id-map](../../common/id-map.tsv)): М10B/08 ш.1–2 → V/02.5-01; М10B/08 ш.3–4 → V/02.5-02; М10B/08 ш.5–6, М10B/20 ш.2–3 →
V/02.5-03; М10B/08 ш.7, М10B/20 ш.1 → V/02.5-04; М10B/08 ш.7, М10B/24 ш.8, М10B/15 ш.8 → V/02.5-05; М10B/24 ш.1–8 → V/02.5-06;
М10B/28 ш.3 → V/02.5-07; М10B/24 ш.8 (журнал) → V/02.5-08; М10B/18 ш.3–4 → V/02.5-09; М10B/28 ш.3 (допуск) → V/02.5-10.
