# V/02 Запись

Статус: **план перевода** (2026-10-23, «Спецификация VMS»; годен — «Архитектор» 2026-10-23); нормы — по главам ниже. Источники — опись
[`../common/inventory.md`](../common/inventory.md) § 1, § 2. Платформа — выгрузка `cammeta-specs` `6e51975`. Манифест —
[`rec.subsystem.yaml`](rec.subsystem.yaml) (канон; ADR-0090 доп. (6) п. 8).

## Что такое урок V/02

Подсистема `rec`: запись камеры как единица, её держатель — регистратор `recworker`, который берёт поток у держателя
камеры (V/01) и пишет его в том движка архива; движок `obsd` — часть подсистемы со своей службой; виды томов, удержания и
метки, дозапись из архива устройства, дверь архива для страницы и процессов, запись на домене (приёмник толкаемого потока,
книги, цепочка). Всё общее — места и захваты, рантайм воркера, просьбы, удержания событий, двери консоли, домен — нормы
платформы по ссылке (P/…). Самый большой урок VMS.

## Формы и двери

- **Строки и объекты** (общие семьи платформы; каталог VMS — только своё сверх них): `rec/recordings/<id>`, таблицы
  `rec/volumes/*`, `rec/keeps/*`, места `rec/holds/<том>`, объекты `rec/used/*`, `rec/sealed/*`, `rec/taken/*`,
  `rec/ingest/clock/*`, `rec/ingest/up/*` (`objects`), просьбы `rec/requests/*`, вклады в книги `rec/primaries/*`,
  `rec/upstream/*`, `rec/polls/*`, отчёт `rec/polled/<приёмник>`.
- **Двери:** дверь архива регистратора (`/spans`, `/samples` — процессы, класс `role`; `/timeline`, `/segment`, `/keeps` —
  страница, токен двери) — OpenAPI урока `spec/02-rec.api.openapi.yaml`; дверь приёмника (опрос, толчок, `/ask`) — глава 9;
  протокол `obsd` — сокет части (не HTTP), глава 2.

## Решения, принятые для плана (опись § 7 и проверки)

- `rec` объявляет `grows: true` (P/04 Н3 «нехватка(), заказать()» для `servers: distinct` с местом из пульса) — регистратор
  под том без держателя поднимает заказ воркеров, запасных нет (ADR-0084).
- Подмена продлевает место (P/03.4 Н3), отпускание места посреди работы — по ADR-0091 п. 9; `may_stand_in_hold` и отсчёт
  `FOR` свидетеля не переносятся.
- Том не открылся — `place_by: ""` в пульсе (ADR-0091 п. 9), удержание отпускается по P/03.2.
- `worker.stop_timeout: 40`; бюджет закрытия мест после SIGTERM — около 31 с (40 − `RENEW_EVERY`), закрытие писателей
  (≈ 22 с) в него укладывается (слово «Архитектора» 2026-10-23).
- Порядок остановки — P/03.4 Н3 SIGTERM (писатели мест → пульс → место → слот).
- Профиль дозаписи — `requests.outcome: fetched` (P/06.4 Н3 «жнец»): старую заявку закрывает регистратор (`fetched` с
  отказом), а не `ttl`.
- Своя `/metrics` регистратора не переносится: ряды — `metrics:` манифеста из пульса.
- `requests.elsewhere: [record]` снимается: запись по сценарию заводит `auto` (`worker.creates`, V/07); `until` →
  `placement.ends: {field: until, never: 0}`.
- Доля части `obsd` — `shares: {obsd: {kind: socket, part: obsd}}`, свой регистратор — `worker.uses: [rec.obsd]`;
  доля `cam.shm` — `worker.uses: [cam.shm]` (ADR-0091 п. 5, доп. (2) п. 4).
- Дверь архива для процессов — класс `role` сертификата роли (ADR-0075 окно 2), для страницы — токен двери консоли
  (`door.routes`).

## Запросы урока (опись § 6)

Подаются при переводе своей главы: № 7 (`access_secret` строки таблицы мест открывает воркер) — V/02.6; № 8 (`url` пульса
не «все интерфейсы») — V/02.5; № 11 (форма `freeing` в пульсе) — V/02.7; № 14 (журнал двери держателя: `archive.read`,
`archive.keep.verified`) — V/02.5, V/02.7. Открытые вопросы описи к V/02: права `_held_by_the_book` (`cam/placement`,
`cam/slots` — нет в `worker.reads`), `domain/rec/primaries` в `rec.worker.reads`, метрики потерь приёмника, правило «общая
сеть — забирать» без `domainpart`, версия движка `obsd` для приёмки (ObjectStorage, патчи 01–07) — решаются в главах.

## Отличия от свидетеля, которые урок записывает

Порядок остановки по P/03.4; `place_by: ""` при неоткрытом томе; подмена продлевает место; `grows` вместо запасного;
`/data/vms/obsd/volume` → `/data/platform/subsystems/rec/obsd/volumes/<n>`; `vms-obsd` → `vms-rec-obsd`; сокет — доля
части; `TimeoutStopSec` 40 — `worker.stop_timeout` с бюджетом ≈ 31 с; профиль дозаписи `fetched`; `elsewhere: [record]`
снят; HMAC-ключ двери держателя не используется — дверь архива процессам по сертификату роли.

## Правки манифеста при переводе

`placement.ends`, `grows: true`, `parts.obsd {exec, volumes: true, stop_timeout}`, `shares.obsd {kind: socket, part:
obsd}`, `worker.uses: [cam.shm, rec.obsd]`, `worker.stop_timeout: 40`, `worker.creates` к `detjob` (V/02.8),
`requests.outcome: fetched`; снять `requests.elsewhere`; комментарии с кодом свидетеля и «петлёй консоли» — ссылками на
нормы. Продукт — строкой долга «Сборке» по главе.
