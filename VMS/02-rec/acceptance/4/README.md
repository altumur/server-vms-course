# Приёмка V/02.4 — регистратор

Норма главы — [`02.4-rec.norms.md`](../../spec/02.4-rec.norms.md) Н5. Стенд и директивы — [общий README приёмки
VMS](../../../common/acceptance/README.md) (выгрузка `60307209`).

## Подготовка

Стенд VMS с манифестами `cam` и `rec`: консоль — `CONSOLE_ROOT=rec` (дверь `console` — `/recordings`, `/volumes`),
`cam` смонтирован (`console2` — `/cam/…`); контроллеры `cam` и `rec`, ресурс `srv-a`. Часть `obsd` запущена на `srv-a`
(движок V/02.2 Н1.4: ObjectStorage с патчами 01–07); точка `{data}/subsystems/rec/obsd/volumes/1` — каталог
пользователя части. Держатель камеры и регистратор — `@start worker` командой «Стенда» реализаций `cam` и `rec`. Медиа —
`door.mp4` (общий README VMS). Каждый сценарий — на чистом экземпляре.

| Шаги `01-record` | Норма | Что наблюдает |
|---|---|---|
| 1–6 | V/02.4-01, -03, -08 | запись камеры на том своего сервера идёт: `running`, источник — разделяемая память (держатель на том же сервере) |
| 7 | V/02.4-03, -08 | регистратор держит том `disk-a` (место), сторож писателя — `ok` |
| 8–9 | V/02.4-08 | выключенная запись — `pending` |

Сценарий `02-audio` — `@manual`: живого драйвера со звуком на стенде нет (ADR-0102 доп. (9) п. 9).

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `03-backup-always` | V/02.6-10 | запись на томе `backup` без `when` — `waiting` со словом; `when: offline` — `standby` |
| `04-replica` | V/02.6-11 | `replica` из архива: фаза, полей живого потока нет; цикл — `waiting` у обеих, снят — обе идут; нет источника; источник на `backup`; `@manual` — копия за 900 с, кольцо, смена источника, метка: стенду не дождаться и не обогнать кольцо |
| `05-replica-device` | V/02.6-11, V/02.8-05 | `@manual`: архива устройства у стенда нет |
| `06-edge` | V/02.6-12, V/01.6-08 | одна строка тома `edge`: держатель каждой камеры заказывает `cam-<cam>-<том>`, `home`, `when` — умолчание `offline`; снятую оператором — снова; `@manual` — две камеры на карте, вытеснение, бюджет, страж, `when` тома, конец строки, срок 7200 с, умолчание `when` кластера из одного, заявка регистратору карты, `role`: карты у стенда нет |
| `07-segment-lost` | V/02.3-08 | `@manual`: событие потери, поля, схлопывание: стенду не заставить движок потерять последовательность |

Сценарии `03`, `04`, `05`, `06` — на своих экземплярах. В `04-replica` два тома: второй регистратор стенд запускает сам, заказа (`grows`) на стенде нет; том `bk-a` держателя не имеет, его вид читается из строки.

Отказы тома, уход с тома, остановка в бюджете, сторож при застревании, кольцо резерва — чтением (Н5 норм).
