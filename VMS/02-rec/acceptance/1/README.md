# Приёмка V/02.1 — запись — единица

Норма главы — [`02.1-rec.norms.md`](../../spec/02.1-rec.norms.md) Н5. Стенд и словарь — [общий README приёмки
VMS](../../../common/acceptance/README.md) поверх общего README платформы (выгрузка `e0b19be`).

## Подготовка

Хранилище и консоль кластера; установлены манифесты `VMS/01-cam/cam.subsystem.yaml` и `VMS/02-rec/rec.subsystem.yaml`;
консоль — `CONSOLE_ROOT=rec` (двери `/recordings`, `/volumes`, `/keeps`), `cam` смонтирован (`console2` — `/cam/…`). Контроллер, воркеры, ресурс и
домен не запущены. Запросы — с петли без домена (одна личность с полными правами). Сценарии — последовательно на одном
экземпляре с пустыми данными `rec/` и `cam/` после установки; сценарии 02, 03 опираются на том `disk-a` сценария 01.

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-create` | V/02.1-01 | том `local` и запись с умолчаниями; без `cam` — 400; `retention_days` 0 — 400 |
| `02-fixed` | V/02.1-01 | `cam` не меняется — 400 «cam is fixed»; имя `auto-…` — имена заказчика `auto` |
| `03-home` | V/02.1-02 | дом на карте другой камеры — принят двери (её не пишет регистратор карты, V/02.6 Н1.7 — чтением); своей — принято; тома нет — принято (размещение не ставит) |
| `04-volumes` | V/02.1-03 | схема таблицы по видам: `network` с `server`, `incidents` без `admits: false`, `cam` у не-`edge` — 400 |
| `05-stream` | V/02.1-01 | поток записи `stream`: поток своей камеры — принят; поток другой камеры и id самой камеры — 409 `must_match`; смена на пустой (основной) — принята |
