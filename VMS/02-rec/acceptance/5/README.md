# Приёмка V/02.5 — дверь архива

Норма главы — [`02.5-rec.norms.md`](../../spec/02.5-rec.norms.md) Н5. Стенд — как у [приёмки 4](../4/README.md); дверь
архива регистратора — на петле без комплекта (`archive <воркер>` [общего README приёмки VMS](../../../common/acceptance/README.md)).

| Шаги `01-door` | Норма | Что наблюдает |
|---|---|---|
| 1–6 | V/02.5-07 | регистратор держит том и объявляет адрес двери на петле (`url` — `http://127.0.0.1:…`) |
| 7 | V/02.5-10 | без комплекта процессный маршрут (`/spans`, допуск `role`) закрыт — 401 `no_role` |
| 8 | V/02.5-04 | иной путь — 404 `no such path` |
| 9–10 | V/02.5-10 | разбор Н2: путь со слешем в конце — не маршрут (404 `no such path`); иной метод на маршруте — 405 `method not allowed` (путь → метод раньше допуска) |
| 11 | V/02.5-05, -10 | страничный маршрут (допуск `token`) на петле открыт, без токена — 403 `forbidden` |

Процессные маршруты (`/spans`, `/samples`) — TLS-стенд с комплектами ролей; страничные маршруты с токеном, кусок fMP4, потолок,
отсечённые эпохи, журнал — чтением (Н5 норм).
