## Подготовка

Хранилище и консоль кластера; установлены манифесты `VMS/01-cam/cam.subsystem.yaml`, `VMS/02-rec/rec.subsystem.yaml` и `VMS/07-auto/auto.subsystem.yaml`;
консоль — `CONSOLE_ROOT=rec` (двери `/recordings`, `/volumes`, `/keeps`), `cam` смонтирован (`console2` — `/cam/…`). Контроллер, воркеры, ресурс и
домен не запущены. Запросы — с петли без домена (одна личность с полными правами). Сценарии — последовательно на одном
экземпляре с пустыми данными `rec/` и `cam/` после установки; сценарии 02, 03 опираются на том `disk-a` сценария 01.

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-create` | V/02.1-01 | том `local` и запись с умолчаниями; без `cam` — 400; `retention_days` 0 — 400 |
| `02-fixed` | V/02.1-01 | `cam` не меняется — 400 «cam is fixed»; имена `auto-…`, `cam-…` — заказчиков `auto`, `cam` |
| `03-home` | V/02.1-02 | дом на карте — принят двери (запись камеры чужого сервера не пишет регистратор карты, V/02.6 N1.7 — чтением); тома нет — принято (дома нет, P/04 N1.3) |
| `04-volumes` | V/02.1-03 | схема таблицы по видам: `network` с `server`, `incidents` без `admits: false`, `when` у не-`edge`, `edge` без `server`, с полем `cam`, `when` вне списка — 400; `when` у `edge`, без него поля нет |
| `05-stream` | V/02.1-01 | поток записи `stream`: поток своей камеры — принят; поток другой камеры и id самой камеры — 409 `must_match`; смена на пустой (основной) — принята |
| `06-audio` | V/02.1-01 | микрофон записи `audio`: умолчание 0 — первый `mic` камеры, правится, меньше 0 — 400 |
| `07-replica` | V/02.1-08 | дверь не судит `replica_from` и `when` у `backup`: цикл и `always` на резервном томе приняты, истина у регистратора (приёмка 4) |
