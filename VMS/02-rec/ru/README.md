## Что такое урок V/02

Подсистема `rec`: запись камеры как единица, её держатель — регистратор `recworker`, который берёт поток у держателя
камеры (V/01) и пишет его в том движка архива; движок `obsd` — часть подсистемы со своей службой; виды томов, удержания и
метки, дозапись из архива устройства, дверь архива для страницы и процессов, запись на домене (приёмник толкаемого потока,
книги, цепочка). Всё общее — места и захваты, рантайм воркера, просьбы, удержания событий, двери консоли, домен — нормы
платформы по ссылке (P/…). Самый большой урок VMS.

## Формы и двери

- **Строки и объекты** (общие семьи платформы; каталог VMS — только своё сверх них): `rec/recordings/<id>`, таблицы
  `rec/volumes/*`, `rec/keeps/*`, места `rec/holds/<volume>`, объекты `rec/used/*`, `rec/sealed/*`, `rec/taken/*`,
  `rec/ingest/clock/*`, `rec/ingest/up/*` (`objects`), долг заказа `rec/state/scan/*`, просьбы `rec/requests/*`, вклады в книги `rec/primaries/*`,
  `rec/upstream/*`, `rec/polls/*`, отчёт `rec/polled/<receiver>`.
- **Семьи данных** — своё содержимое в открытых местах семей платформы, которое читают другие процессы и манифест не
  выражает, — [`data/`](../data/): слова пульса `rec-heartbeat-words` (`ingest`, `url`, `volume`, `stream.lagging`, `written_through`
  элемента записи; место — корень пульса, пустой указатель), `value` элементов книг `primaries-entry`, `ingest-entry`, `polls-entry`,
  `upstream-entry` (место `/*/entries/*/value`; `#copy` — копия у члена, `#member` — строка члена у держателя домена; у `primaries`, `ingest` только `#member`: книги всем, ключи одни) —
  форма, слои, исходы по читателям; строки — в каталоге VMS [`../common/data/catalog.tsv`](../../common/data/catalog.tsv)
  (колонка `place`). Объекты `rec/ingest/*`, `rec/sealed/*`, `rec/used/*`, `rec/taken/*` (`objects` манифеста) и вклады
  `rec/<book>/<slot>` — форма манифеста, семьёй VMS не судятся; свидетель `rec/polled/<slot>` читает консоль домена по
  объявлению `witness` (P/10 N1.8). Векторы — построитель `family-read` (`VMS/common/vectors/family-read/02.tsv`).
- **Двери:** дверь архива регистратора (`/spans`, `/samples` — процессы, класс `mixed`; `/timeline`, `/segment`, `/keeps` —
  страница, токен двери) — OpenAPI урока `spec/02-rec.api.openapi.yaml`; дверь приёмника (опрос, толчок, `/ask`) — глава 9;
  протокол `obsd` — сокет части (не HTTP), глава 2.
