## Что такое урок V/01

Подсистема `cam`: камера (или иное устройство: `kind: io`) как единица; её держатель — воркер `camworker`, который
открывает устройство одним соединением, раздаёт поток подписчикам (`rec`, `live`, `det`) и отвечает на команды и
вопросы к устройству; архив самого устройства (карта, NVR) и его двери; вклад камеры в домен. Всё общее — рантайм
воркера, слот, эпоха, аренда, просьбы, события, двери консоли, домен — нормы платформы по ссылке (P/…), урок их не
повторяет. Отдельного HTTP-контракта консоли у `cam` нет (двери единиц — P/06.1); своя дверь есть у держателя (глава
5) — `spec/01-cam.api.openapi.yaml`.

## Формы и двери (Н1, Н2 по главам)

- **Строки и объекты** (каталог `../common/data/catalog.tsv` получает строки урока): `cam/cameras/<id>`, `cam/next_id`
  (P/06.1), `cam/devices/<хост>` (таблица воркера), `cam/sources/<…>` (вклад в книгу, P/03.7), `cam/requests/*` (P/06.4),
  `cam/retention`, `cam/alarms_retention` (P/05 Н1.3), `door/signer` (секрет, P/06.2), бакеты событий `cam/<id>/e<эпоха>`
  (P/05 Н1.2) — владелец каждого ключа по P/06.1 Н1.1; пульс и снимок — формы платформы с полями `cam` (главы 2, 5).
- **Двери:** консоль — P/06.1, P/06.4 (у `cam` своих маршрутов консоли нет); держатель — `/playback`, `/devices`,
  `/recordings` (глава 5, OpenAPI); RTSP раздачи — не HTTP, форма адреса в пульсе (глава 2).
- **Семьи данных** `data/*.form.yaml` — строка камеры, строка `devices`, тело просьбы `cam`, вклад в книгу `sources`,
  слова пульса `cam` — по образцу `Platform/*/data/`.

## Отличия от свидетеля, которые урок записывает (опись § 7)

Потолок снимка 64 МиБ (P/04 Н1.3а), а не 64 КиБ — довод о `folders` пересматривается; ворота старта по P/03.3 Н3 шаг 2
(секрет до эпохи, `may_act` перед стартом); `stalled` по P/03.3 Н1.2; неоткрытое устройство — `refused` (P/03.6);
`DELETE /devices/<хост>` у консоли — 403 (таблица воркера); метрики `vms_*` → `cam_*`; `POST /vms/requests` →
`/cam/requests`; дерево событий `cam/<id>/…`; `/run/vms` → доля `cam.shm` (`/run/vms-cam-shm`).

## Правки манифеста при переводе

Комментарии, называющие код свидетеля (классы и файлы старой реализации, `cam/<w>/heartbeat`, «Lesson 6»),
заменяются ссылками на нормы урока и платформы; `shares: {shm: {kind: dir}}`; `worker.reads` — по главе 6; ключи и
значения меняются только там, где этого требует норма, с записью в главе; продукт — строкой долга «Сборке».
