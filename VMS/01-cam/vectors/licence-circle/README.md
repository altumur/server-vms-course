# Векторы: круг счёта лицензии

Владелец — урок V/01 ([нормы главы 7](../../spec/01.7-cam.norms.md) Н1.2, Н3 «Счёт»; ADR-0113 доп. (11) п. 5). Числа выведены по тексту нормы, реализацией не проверены. Прогон — после первой генерации стадии C.

## Файлы

| Файл | Что |
|---|---|
| `cases.tsv` | один круг на строку: `case`, `input`, `expect`, `note` |

## Поля

- `input` — `units` (`null` — документа нет), `doc`, `state`, `row` — строка `domain/cam/licence-count` на входе (`null` — строки нет), `head` — `parts` головы, `budget` — разделов на проход, нет — все, `sections` — на раздел `refs` камер набора, `licensed` прежних решений, в упрощении один член на раздел, `never` — ref строки члена `never`, `unreadable` — решение не читается, `units` — записи вида для итога, нет — все `running`.
- `expect` — `read` — прочитанные разделы, `decisions` — `licensed` прочитанных разделов, `row` — строка на конце прохода, `part` только у незакрытого круга, `summary` — суммы итога состояний, только на конце круга.
