## Что такое урок V/01

Подсистема `cam`: камера (или иное устройство: `type` — `ipsrv`, `eventsrc`, `acfa`) как единица; её держатель — воркер `camworker`, который
открывает устройство одним соединением, раздаёт поток подписчикам (`rec`, `live`, `det`) и отвечает на команды и
вопросы к устройству; архив самого устройства (карта, NVR) и его двери; вклад камеры в домен. Всё общее — рантайм
воркера, слот, эпоха, аренда, просьбы, события, двери консоли, домен — нормы платформы по ссылке (P/…), урок их не
повторяет. Отдельного HTTP-контракта консоли у `cam` нет (двери единиц — P/06.1); своя дверь есть у держателя (глава
5) — `spec/01-cam.api.openapi.yaml`.

## Формы и двери (N1, N2 по главам)

- **Строки и объекты** (каталог `../common/data/catalog.tsv` получает строки урока): `cam/cameras/<id>`, `cam/next_id`
  (P/06.1), `cam/devices/<host>`, `cam/children/<id>`, `cam/rule_state/<id>` (таблицы воркера), `cam/child_settings/<id>` (таблица консоли), `cam/sources/<…>` (вклад в книгу, P/03.7), `cam/requests/*` (P/06.4),
  `cam/retention`, `cam/alarms_retention` (P/05 N1.3), бакеты событий `cam/<id>/e<epoch>` (P/05 N1.2), книга решений
  лицензии `domain/cam/licence/<member>` и её копия у члена (глава 7) — владелец каждого ключа по P/06.1 N1.1; пульс и снимок — формы платформы с полями `cam` (главы 2, 5).
- **Двери:** консоль — P/06.1, P/06.4 (у `cam` своих маршрутов консоли нет); держатель — `/playback`, `/devices`,
  `/recordings` (глава 5, OpenAPI); RTSP раздачи — не HTTP, форма адреса в пульсе (глава 2).
- **Семьи данных** `data/*.schema.json` (JSON Schema 2020-12) с `*.layers.tsv` и `*.outcomes.tsv` — слова пульса `cam`, поля строк
  событий `cam-events`, элемент книги `sources`, решение лицензии — по образцу `Platform/*/data/` (слои —
  `Platform/common/LAYERS.md`, ADR-0092).
  Строка камеры, строки `devices`, `children`, `child_settings`, `device_units`, `unit_next`, `rule_state`, `searches`, `found`, `probes`, `probe_replies` и тело просьбы выражает манифест (P/02.1) — своих семей у них нет. Своё содержимое в
  открытых местах семей платформы — [`data/`](../data/): слова пульса `cam-heartbeat-words` (место — корень пульса, пустой указатель),
  `value` элемента книги `sources-entry` и решение `licence-decision` (место `/*/entries/*/value`) — форма, слои, исходы по
  читателям; строки — в каталоге VMS [`../common/data/catalog.tsv`](../../common/data/catalog.tsv) (колонка `place`; решение
  «Архитектора» А); поля строк событий `cam-events` (`io.input` — `port`, `value`; `source-stats` — `dropped`, `depth`; `text` — `lines`, `group`, `camera`, `word`; `unit` — `unit`, `event`, `phase`;
  место — корень строки семьи событий платформы, деревья `cam` и `cam.alarms`). Вклад `cam/sources/<slot>` — форма манифеста (P/03.7), семьёй VMS не судится. Векторы семей строит
  построитель `family-read` (`VMS/common/vectors/family-read/01.tsv`), вручную их нет.
