# Приёмка V/01.4 — команды и вопросы к устройству

Норма главы — [`01.4-cam.norms.md`](../../spec/01.4-cam.norms.md) Н5. Стенд и словарь — как у [приёмки 2](../2/README.md)
(общий README приёмки платформы, выгрузка `148f9ae9`).
Прогон — после первой генерации стадии C, прошедшей приёмку платформы (ADR-0090 доп. (8), (9)).

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-no-device` шаги 1–4, 6 | V/01.4-01, -02 | команда камере-файлу (устройства нет): просьба подана при живом держателе в пределах срока 30 с — подача `202 queued` или `200 answered` (кто успел; P/06.4 Н3 «подать просьбу» шаг 5); держатель исполняет просьбу — метка `refused` «`camera has no device`» и событие `command.failed` камеры (V/01.4 Н1.5) |
| `01-no-device` шаги 5, 6 | V/01.4-02 | две ошибки сразу — камера без устройства и `output` без `port`: по порядку Н3 «камера без устройства» раньше аргументов — метка `refused` «`camera has no device`», не «output needs a port»; событий `command.failed` — два |
| `01-no-device` шаг 7 | V/01.4-01 | аргумент длиннее 32 знаков — 400 у двери (схема раздела `requests:`) |

| `02-owner` | V/01.4-05, -08 | `@manual`: хозяин блока, индекс, `videos`, `can` списками, снятие настройки нынешней строкой, повтор перечня |
| `03-norm` | V/01.4-08 | `@manual`: `value` от `norm`, выключенный вход, хозяин `unlicensed` |
| `04-sound` | V/01.2, V/01.4 звук | `@manual`: точки звука, 404, разговор: `talk`, `busy`, снятие занятости: `Drivers/Virtual` по нынешнему DriverPack годен только после `ipintd` (ADR-0102 доп. (9) пп. 8, 9) |
| `04-units` | V/01.4-09 | `@manual`: дерево единиц, `units_down`, событие и действие `unit` |
| `05-builtin` | V/01.4-11 | `@manual`: встроенный детектор, отказы, работа без потока: аналитики в подставном драйвере нет |
| `05-ptz` | V/01.4-12 | `@manual`: аренда, стоп вне очереди, стоп при взятии эпохи, предел 105 с: телеметрии в подставном драйвере нет |
| `06-rule-state` | V/01.4-13, V/01.1-15 | слова правила на камере-файле: строки до слова нет, `arm`, `disarm` без новой `revision`, `disable` с `pending`, `reason` «rule: off», отказ прочих просьб, правка камеры слово не снимает, срок в прошлом включает, оператор строку не пишет; `@manual` — выход срока, новый держатель, порченая строка |

`performed` с ответом, вопросы к медленному устройству, строка устройства, совпадение `identity`, `can`, дети устройства — чтением: нужен
двойник устройства с выходами и пресетами, у стенда его нет (V/01.4 Н5). Шаги `@manual` ждут модель подставного драйвера с несколькими видео
и блоками с каналом, с `-1`, без поля: у `Drivers/Virtual` её нет.
