# Приёмка V/01.2 — держатель камеры

Норма главы — [`01.2-cam.norms.md`](../../spec/01.2-cam.norms.md) Н5. Словарь директив, дверей и ожиданий — общий
[README приёмки платформы](../../../../Platform/common/acceptance/README.md#словарь-директив-и-дверей) (выгрузка `148f9ae9`);
формат `scenarios.tsv` — тот же. Прогон — после первой генерации стадии C, прошедшей приёмку платформы (ADR-0090 доп. (8),
(9)); до него сценарии — текст нормы.

## Подготовка

Стенд по разделу «Стенд» общего README: хранилище, консоль кластера (`CONSOLE_ROOT=cam`, дверь `console` — `/cameras`),
контроллер `cam`, ресурс сервера `srv-a`; установлены манифесты `VMS/01-cam/cam.subsystem.yaml` и `VMS/02-rec/rec.subsystem.yaml` (`console2` — `/rec/…`: строка записи — потребитель потока, регистратора нет). Реализация
подсистемы `cam` — её держатель запускается директивой `@start worker cam <имя> on srv-a` командой «Стенда» реализации
(раздел «Решает реализация» инструкции урока). Файл подсистемы `/etc/cam/cam.env` задан стендом (общий README приёмки
VMS, «Файл подсистемы на стенде»; путь — в `W2C_SUB_ENV`): `MEDIA_DIR={data}/subsystems/cam/media` — каталог стенда с
`door.mp4` (H.264, ≥ 10 с; источник `driverpack://file/door.mp4`, глава 3), `SHM_DIR` — каталог доли кадров стенда
(`{shm}`, «Доля кадров на стенде»); `RTSP_PORT` не задан — RTSP на петле, порт выбирает ОС. Один сценарий
`01-hold` на одном экземпляре: создаёт камеру `$c1`, правит её по шагам и заводит строку `$c2`. Повторный и параллельный прогон — свои экземпляры.

## Сценарии

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-hold` шаги 1–3 | V/01.2-13 | включённая камера `always` без потребителя — `idle`, адресов нет |
| `01-hold` шаги 4–5 | V/01.2-01, -03, -04, -13 | строка записи — потребитель: `running`, `live_url` на петле, `live_shm` в каталоге доли стенда (`shm://{shm}/…`) |
| `01-hold` шаги 6–9 | V/01.2-01, -04 | выключенная — `pending`, адресов нет; включённая снова — `running` |
| `01-hold` шаги 10–11 | V/01.2-01, -04 | `live: on-demand` — `held`, адресов раздачи нет |
| `01-hold` шаги 12–13 | V/01.2-01, -04 | строка `type: ipsrv` — фаза `held`, без адресов раздачи (`live` не читается) |
| `01-hold` шаги 14–17 | V/01.2-10 | `resolution` не совпал с `size` при `running` — `warning`, поток идёт; поле снято — предупреждения нет |
| `01-hold` шаги 18–19 | V/01.2-13 | потребитель снят — через `IDLE_AFTER` и перечень строк `idle`, адресов нет, `size` остался |
| `02-settings` | V/01.2-10 | `@manual`, живой драйвер: передача `resolution`, `fps`, отказ на одну настройку в адресе и в поле |
| `04-events` | V/01.2-11 | `@manual`: источник текста, `text`, `word`, занятый порт, `lost` |

Остальное главы — чтением (Н5 норм): одно соединение на подписчиков и потеря кадров медленной ветвью, 8 с молчания и
`silent`, `busy` второго написания, пароль вне командной строки, бюджет. Раздачу со стороны подписчика наблюдают приёмки
V/02 (регистратор) и V/03 (шлюз).
