# Приёмка V/01.8 — поиск устройств

Норма главы — [`01.8-cam.norms.md`](../../spec/01.8-cam.norms.md) Н5. Стенд и словарь — как у [приёмки 1](../1/README.md): воркеров нет, манифест `cam`, формы таблиц.
Прогон — после первой генерации стадии C, прошедшей приёмку платформы (ADR-0090 доп. (8), (9)).

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-tables` | V/01.8-01 | строка поиска и вопрос пишутся дверью таблиц, поле не по форме — 400; `found`, `probe_replies` оператор не пишет: 403 «written by its worker» |
| `02-live` | V/01.8-02, -03 | `@manual`: живой поиск и вопрос о модели на драйвере |

Шаги `@manual` ждут живого драйвера и сети с камерами: подставной драйвер `Drivers/Virtual` поиска такой модели не даёт, широковещательный ответ стенд не создаёт (ADR-0102 доп. (4) п. 8, доп. (6) п. 11).
Чтением: базовый воркер, вызовы вне цикла. Двойник держателя и сторона `backend` — приёмка V/11.
