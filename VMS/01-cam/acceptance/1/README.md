# Приёмка V/01.1 — камера — единица

Норма главы — [`01.1-cam.norms.md`](../../spec/01.1-cam.norms.md) Н5. Стенд, словарь директив и ожиданий — общий
[README приёмки платформы](../../../../Platform/common/acceptance/README.md#словарь-директив-и-дверей) (выгрузка
`6c13e996`); формат `scenarios.tsv` — тот же (`scenario`, `step`, `request`, `expect`; ожидание — подмножество).
Прогон — после первой генерации стадии C, прошедшей приёмку платформы (ADR-0090 доп. (8), (9)); до него сценарии —
текст нормы.

## Подготовка

Хранилище и консоль кластера одной реализации по разделу «Стенд» общего README; установлен один манифест —
`VMS/01-cam/cam.subsystem.yaml` (P/02.1), консоль — `CONSOLE_ROOT=cam`, двери — `/cameras`, `/devices`, `/children`, `/child_settings`. Кольцо ключей
задано (`SECRETS_KEY`, P/06.2 Н1.2): `cred_secret` запечатывается. Контроллер, воркеры, ресурс и домен не запущены.
Запросы — с петли без домена (P/06.3 Н1.3 `open`): одна личность с полными правами. Все сценарии — последовательно на
одном экземпляре с пустыми данными `cam/` после установки; связывание `$имя` — в пределах сценария. Повторный и
параллельный прогон — свои экземпляры. Для каждого `POST` создания раннер выдаёт свежий `Idempotency-Key`. Сценарии делят
данные: адрес (`source`) каждой созданной камеры — свой во всей приёмке, иначе следующий сценарий получит 409 `unique`;
`01-create` — первый на пустых данных, его камеры — номера 1 и 2 (P/06.1 Н1.3: первый номер — 1).

## Сценарии

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-create` | V/01.1-01 | поля и умолчания Н1.1, `name` без имени — `cam<id>` полностью (`cam1`, второе создание — `cam2`); правка другого поля имя не пересчитывает; пароля нет — поле пусто |
| `02-numeric` | V/01.1-01 | `id` в `POST` — отказ с именем поля; `live` вне `enum` — отказ без `fault` (P/06.1 Н4) |
| `03-one-channel` | V/01.1-02 | то же каноническое написание (регистр схемы) — 409 `unique`; другой канал — можно; без порта по умолчанию — другой канон (порт не снимается, договор проверки строки), дверь принимает — тот же ли канал, решает держатель (глава 2 Н1.2, `busy`) |
| `04-credentials` | V/01.1-03 | логин и пароль в адресе (userinfo, `secret_in`, `driverpack://` в пути) — 400 `bad_url` с именами полей; в своих полях — принято, пароль замаскирован |
| `05-bound` | V/01.1-03 | смена `source` без пароля — 400 `bound_to`; с паролем — принято |
| `06-schemes` | V/01.1-03 | схема не из `schemes` — 400; `ipint` с `#` в пути — принято |
| `07-devices` | V/01.1-04 | таблицу `devices` оператор не пишет: `POST` — 403 «written by its worker», `PUT` — 405; `DELETE` несуществующей строки — 404 (удаление существующей — 200 с cas, P/06.1 Н1.6; строки на стенде без устройства нет) |
| `08-streams` | V/01.1-09 | поток камеры: `main` на камеру, `profile` по умолчанию `main`, правка `main` — 400 `fixed`, `profile` правится; `resolution`, `fps` правятся у потока, не по форме — 400; незнакомое поле — 400 |
| `09-delete-camera` | V/01.1-09 | удаление камеры потоков не трогает: поток живёт с `main` на удалённую камеру и правится; новый поток на неё — 201 (`ref` цели не требует); держатель такой поток не держит (`reason` «main: missing», глава 2) — чтением; поток удаляется сам |
| `10-type` | V/01.1-11 | `type` вне `enum` (`thermal`) — отказ; четыре вида приняты; правка — 400 `fixed`; поток на строке не `camera` и поток не `camera` на камере — 409 `must_match`; поток `camera` на камере — принят |
| `11-order` | V/01.1-01, -02 | две ошибки сразу по порядку P/06.1 Н3: создание с полем не по схеме и адресом, который уже держит камера сценария 03, — 400 формы (без `fault`), не 409 `unique`; правка несуществующей камеры телом не по схеме — 400, не 404; данных сценарий не создаёт |
| `12-children` | V/01.1-10 | `children` оператор не пишет: `POST` — 403 «written by its worker», `PUT` — 405; настройка ребёнка: ключ из `camera`, `type`, `number` виден чтением строки, `enabled` и `norm` без умолчания, правка `POST` поверх — имя пережило правку; без `type`, `type` вне перечня, `number` 0 — 400; поля `kind` нет; строки детей на стенде без устройства нет — чтением (V/01.4-08); `mic`, `spk` приняты, `norm` вне перечня — 400 |
| `13-fields` | V/01.1-11 | `lat`, `lon`, `azimuth`, `short`, `mac`: приняты, `0` — значение, `null` снимает поле, не число — 400 |
| `14-eventsrc` | V/01.1-13 | поля строки `eventsrc`: `camera`, `words`, `overlay_*`, метка `server:*`; `words` без `msg`, `overlay_delay_ms` < 0 — 400 |
| `15-units` | V/01.1-14 | таблицы `device_units`, `unit_next`: ключ, `enabled` по умолчанию, вложенность `parent`, отказы формы, снятие |

Права людей (`rights.reach`, V/01.1-07) этим стендом не наблюдаются: гранты `view`/`edit`/`admin` — стенд домена
(P/06.3, P/08.4); проверяются чтением до сценария стенда домена урока.
