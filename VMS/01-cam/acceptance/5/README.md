# Приёмка V/01.5 — архив устройства и его дверь

Норма главы — [`01.5-cam.norms.md`](../../spec/01.5-cam.norms.md) Н5. Стенд, директивы и дверь `holder` — [общий README
приёмки VMS](../../../common/acceptance/README.md) поверх общего README платформы (выгрузка `6d8ab4b`). Комплектов
сертификатов нет. Прогон — после первой генерации стадии C, прошедшей
приёмку платформы (ADR-0090 доп. (8), (9)).

| Шаги `01-door` | Норма | Что наблюдает |
|---|---|---|
| 1–3 | V/01.5-01 | камера без архива устройства — в пульсе нет `coverage`, `playback_url`, `index_url` |

Без комплекта сертификатов дверь держателя не слушает (все её маршруты — допуск по роли, V/01.5 Н1.2, Н2): маршруты
`/devices`, `/recordings`, `/playback` проверяются на TLS-стенде с комплектами ролей.
Байты, куски, бюджеты, застревание, сессии устройства, `501 no index`, класс `role` — чтением (Н5 норм).
