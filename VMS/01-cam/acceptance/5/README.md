# Приёмка V/01.5 — архив устройства и его дверь

Норма главы — [`01.5-cam.norms.md`](../../spec/01.5-cam.norms.md) Н5. Стенд, директивы и дверь `holder` — [общий README
приёмки VMS](../../../common/acceptance/README.md) поверх общего README платформы (выгрузка `e0b19be`). Комплектов
сертификатов нет. Прогон — после первой генерации стадии C, прошедшей
приёмку платформы (ADR-0090 доп. (8), (9)).

| Шаги `01-door` | Норма | Что наблюдает |
|---|---|---|
| 1–3 | V/01.5-01 | камера без архива устройства — в пульсе нет `coverage`, `playback_url`, `index_url` |
| 4 | V/01.5-02 | без комплекта маршруты держателя (допуск по роли) закрыты — 401 `no_role` |
| 5–7 | V/01.5-06 | порядок проверок Н2 без комплекта: путь со слешем в конце и неизвестный путь — 404 `no such path`, иной метод на маршруте — 405 (путь и метод — раньше допуска) |

Маршруты `/devices`, `/recordings`, `/playback` с ответами — TLS-стенд с комплектами ролей.
Байты, куски, бюджеты, застревание, сессии устройства, `501 no index`, исходы класса `role` (рукопожатие, 401, 403),
разбор `from`/`to` — чтением (Н5 норм).
