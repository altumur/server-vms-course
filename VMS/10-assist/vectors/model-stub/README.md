# Файлы ответов заглушки модели — приёмка 2

Владелец — урок V/10 ([нормы главы 2](../../spec/10.2-assist.norms.md) Н5 «Заглушка модели»). Читает программа раннера
`model-stub`: стенд приёмки 2 называет файл сценария в `MODEL_COMMAND` (`{model_stub} <этот каталог>/<сценарий>.tsv`,
[README приёмки 2](../../acceptance/2/README.md)). Файл — не ожидание: он задаёт, что «модель» ответит; ожидания — в
`scenarios.tsv` приёмки.

Форма файла — UTF-8, LF, поля через TAB, строки с `#` — пояснения:
- первая строка — `load <секунды>`: столько секунд от запуска `GET /health` отвечает 503, затем 200;
- дальше строка на каждый запрос `POST /v1/chat/completions` по порядку: `<после>` (секунды или `hang`), `<статус>`,
  `<тело ответа JSON>`; `hang` — ответа нет, пока держатель не оборвёт соединение; строк не хватило — 500.

| Файл | Сценарий | Что отвечает |
|---|---|---|
| `01-step.tsv` | `01-step` | грузится 15 с; первый шаг — `готово`; второй — `hang`; третий — 500 |
| `02-limits.tsv` | `02-limits` | два шага — `hang` |
| `03-owner.tsv` | `03-owner` | один шаг — `для ann` |
