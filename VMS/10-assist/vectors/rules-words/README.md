# Векторы сверки слов правил — V/10.7

Сверка со словами просьбы (глава 7 Н1.6) и запреты (Н1.5) на случаях замера. Модели нет: строка плана дана готовой. Ожидания выведены записью правил главы над `harness/rules/words.json`, независимой от кода пилота; реализацией не проверены. Случаи с `known_gap` закрепляют предел: план неверен, а сверка его принимает.

## Файлы

| Файл | Что |
|---|---|
| `cases.json` | `world` — камеры, дети, папки, расписания, режимы, правила; `cases` — `{id, note, request, row, errors, known_gap?}` |

`errors` — слова ошибок по порядку строк таблицы Н1.6, пусто — слой пройден.
