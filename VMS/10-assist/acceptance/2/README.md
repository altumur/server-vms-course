# Приёмка V/10.2 — дверь модели

Норма главы — [`10.2-assist.norms.md`](../../spec/10.2-assist.norms.md) Н5 (и процесс модели, пульс — [`10.1-assist.norms.md`](../../spec/10.1-assist.norms.md)
Н1.3, Н1.4). Стенд и словарь — [общий README приёмки VMS](../../../common/acceptance/README.md) поверх общего README
платформы (выгрузка `35582ba`).

## Подготовка

Стенд VMS с манифестом `assist`: консоль — `CONSOLE_ROOT=assist` (дверь `console` — `/models`, `/where/<name>`), контроллер
`assist`, ресурс сервера `srv-a`. Держатель модели запускается директивой `@start worker assist m-srv-a-1 on srv-a
labels=assist-a` командой «Стенда» реализации (раздел «Решает реализация» инструкции урока): у сервера метка `assist-a`.

**Заглушка модели.** Файл подсистемы `/etc/assist/assist.env` стенд задаёт на сценарий: `MODEL_COMMAND={model_stub}
{spec}/VMS/10-assist/vectors/model-stub/<сценарий>.tsv` — `{model_stub}` — программа раннера `model-stub` по протоколу V/10.2 Н5,
`{spec}` — корень спецификации. Файл ответов сценария — [`vectors/model-stub/<сценарий>.tsv`](../../vectors/model-stub/README.md): первая строка — `load <секунды>`, дальше строка на запрос
к модели по порядку (`<после>` TAB `<статус>` TAB `<тело>`; `hang` — ответа нет до обрыва). Весов и сервера модели на
стенде нет.

Сценарий `03-owner` — на стенде домена VMS (общий README приёмки VMS, «Стенд домена VMS»): `@domain m1`, на `m1` — тот же
стенд; `member m1 console` — корень `assist`; люди и гранты — двери `holder` и директива `@person`. Ann и Bob — оба с
`view` на строку модели `m1`.

Каждый сценарий — на чистом экземпляре.

| Сценарий | Норма | Что наблюдает |
|---|---|---|
| `01-step` | V/10.1-03, V/10.1-04, V/10.2-01, V/10.2-03, V/10.2-04, V/10.2-06, V/10.2-08 | фаза `loading` (заглушка грузится 15 с) — шаг 503 `loading` с `retry_after`; `running`; без токена — 403; пустые `messages` — 400 `bad step`; шаг 202 → долгий опрос → `done` с сообщением и `usage`; повторное чтение завершённого — тот же исход; шаг, на котором заглушка «думает вечно», — `running`, отбой 200 `cancelled`, затем 404; ответ модели 500 — `failed` `model failed`; чужой экземпляр в id шага — 410 `gone`; `enabled: false` — `stopped` `disabled`, шаг — 503 `model unavailable` |
| `02-limits` | V/10.2-03, V/10.2-04, V/10.1-04 | два незавершённых шага владельца — третий 429 `too many steps`; второй ждёт в очереди (`ahead: 0`), отбой снимает его; первый, которого владелец не спрашивает, через `ABANDON` — `cancelled` `abandoned`, счёт `steps.abandoned` в пульсе |
| `03-owner` | V/10.2-02 | шаг Ann с ответом; Bob с тем же грантом на модель читает и отбивает шаг Ann по id — 404 `no such step`; Ann новым токеном снова читает свой шаг — 200 |

Чтением (Н5 норм): `STEP_MAX`, `QUEUE_MAX`, `KEEP_UNREAD` (сроки дольше сценария), `context exceeded`, перезапуск процесса
модели, `model did not load`, `model keeps failing`, 410 после смены держателя, деление кеша (общий префикс; данные — тот же `user` и `turn`), журнал `assist.step`
без текстов, погашение процесса модели до отдачи слота, сокет 0700.
