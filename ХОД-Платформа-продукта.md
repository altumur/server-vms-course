## Что знать о частях платформы

- **`consolehost`** (`cmd/console`): консоль из каталога спек — `SPEC_DIR`, `CONSOLE_ROOT` (подсистема на `/`),
  остальные спеки под своими именами; одна ручка хранилища (личность `console`, грант консоли каждой спеки), один
  журнал, один индекс, один гейт. На старте запечатывает строки секретов спек, которые пишет сама. Двери переезда
  домена (`/api/held`, `/api/backup…`, `/api/prepare`, `/api/take`, `/domain/move`) — у `ConsoleDoor.Moves`, к
  подписанту по `SIGNER_URL` (ADR-0066); без него — 404 со словами. Ёмкость консоль не читает (ADR-0030 п. 6).
  `consolehost.Build` годится и для тестового хоста (`vmscam`, `vmsdev` строятся им).
- **`controllerhost`** (`cmd/controller <sub>`): контроллер одной спеки, такт 5 с, без порта и состояния; личность
  `<sub>controller`, грант `ACLController` (с `delete:<sub>/<rows>/*` только при `placement.unplaced.delete_after`),
  группа сокета `w2c-<sub>controller`. Ёмкость — слово воркера в биении, иначе `placement.capacity.default`;
  `CAPACITY` платформа не читает. Журнал — `EVENTS`; `WATCHDOG=1` systemd на каждом такте.
- **`p.PassRead`** (`w2cplatform/passread.go`): одно чтение хранилища на проход для любого процесса — `Table`
  (через `RowCache` петли), `Indexed` (только при индексах хранилища, иначе nil и `Get` по одной), `Get`, `Put`/`Drop`
  (CAS на прочитанном индексе, записанное видно следующим шагам), `Saw` (строка от другого писателя, без индекса),
  `Heartbeats`/`HolderOf` (раз за проход, с слухом процесса), `Memo`. У `p.Worker`: `OpenPass()` (вложенные шаги
  делят проход, он кончается с внешним) и `Pass()` (открытый или разовый); кэш строк — у воркера. На нём проход консоли
  VMS (`ConsolePass`) и вид рекордера (`storeView` в `Memo`). Счётчики чтений тестов `passreads_test`,
  `recpassreads_test` — страж: рост чтений там красный.
- **Права:** `configstore-rights.json` делает платформа — `SPEC_DIR=vms go run ./cmd/w2cctl rights -deployment vms -o
  vms/deploy/configstore-rights.json`; тест «файл = спеки» в `vms/deploy`.
- **Установщик:** `deploy/install.sh` и `deploy/systemd/install.sh` не знают подсистем — всё сверх платформы из
  `--units <dir>` (`*.env.example`, `install-hook.sh` печатает юниты по порядку, `spares/*.spare`, plist/юниты).
