# Нормативные слова курса

Канон курса (решение «Архитектора» по второй редакции записки «Платформа», 2026-10-18; ADR-0083). Нормативные разделы
всех уроков курса пользуются только этими словами; повествование — нет. Уроки ссылаются на этот файл из своего Н0;
правила модуля — устойчивость выдачи, время в строке — живут в P/01.1 Н0 и действуют в своей области.

| Слово | Значение | Нарушение |
|---|---|---|
| **ДОЛЖЕН / НЕ ДОЛЖЕН** | требование; без него реализация не соответствует уроку | несоответствие, приёмка красная |
| **СЛЕДУЕТ / НЕ СЛЕДУЕТ** | рекомендация; отступление допустимо, называется в описании реализации с причиной | не нарушение, если названо |
| **МОЖЕТ** | выбор реализации; любой из названных вариантов соответствует | — |
| **решает реализация** | норма не задана нарочно; реализация обязана назвать свой выбор в описании реализации | выбор не назван |

Непомеченное словами ДОЛЖЕН/СЛЕДУЕТ/МОЖЕТ предложение нормативного раздела читается как ДОЛЖЕН.
