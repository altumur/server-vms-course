# Normative words of the course

This English text is the source; the Russian translation `ru/НОРМАТИВНЫЕ-СЛОВА.md` (for people, not in the export) is derived from it by translation and is not edited by hand (ADR-0121; ADR-0124 addendum (1) item 4).

The canon of the course (the Architect's decision on the second edition of the note «Платформа», 2026-10-18; ADR-0083). The normative sections
of all lessons of the course use only these words; the narrative does not. The lessons refer to this file from their Н0;
the rules of the module — stability of output, time in a row — live in P/01.1 Н0 and apply in their own area.

| Word | Meaning | Violation |
|---|---|---|
| **MUST / MUST NOT** («ДОЛЖЕН / НЕ ДОЛЖЕН») | a requirement; without it the implementation does not conform to the lesson | non-conformance, the acceptance is red |
| **SHOULD / SHOULD NOT** («СЛЕДУЕТ / НЕ СЛЕДУЕТ») | a recommendation; a deviation is allowed and is named in the implementation description with its reason | not a violation if named |
| **MAY** («МОЖЕТ») | a choice of the implementation; any of the named options conforms | — |
| **Implementation decides** («решает реализация») | the norm is not set on purpose; the implementation is to name its choice in the implementation description | the choice is not named |

A sentence of a normative section not marked with the words MUST/SHOULD/MAY reads as MUST.
