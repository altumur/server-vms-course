
- `path "secrets/vms" { capabilities = ["read"] }` — the cluster's key, read by this job's template. Granted to the console, the worker and the recorder (it opens a network volume's secret, the review's fourth pass) and to no other job: the key is not in the store it protects, and not in every process's reach.
- `path "vms/devices/*" { capabilities = ["write", "read", "list"] }` — what a device the worker holds turned out to be (`describe_devices`, М10B Lesson 25): its events, relays, presets, and its own word for which device it is (`identity`). `WORKER_ACL` in `vms/config.py` adds it to the platform's grant; `tests/test_policies.py` checks this file against `WORKER_ACL` and `WORKER_OBJECTS`, and the stand's `WORKER_GRANTS` (`tests/stand.py`) is the same list since the eighth review — it lacked this line and `objects/vms/commands/*`.
- `platform/schema` — read: the store's schema, checked first (`check_schema`; М10's eighth review).
- `platform/decommission/*` — read: a process on a decommissioned server is given no slot (`Worker._claim_slot`, a named refusal; М10A Lesson 7, step 7).
- `domain/keys`, `domain/member` — read only: what the playback door's gate reads on every request (`playback_refusal`; `w2cplatform/access.py`, `Gate.gated`, `TRUST_KEYS`, `MEMBER_MARK`). Missing before М10's eighth review: on a real Nomad the door got a 403 and failed shut. Until the ninth review the file granted every row that marks a member — `domain/root`, `domain/grants`, `domain/grants/*`, `domain/revoked`, `domain/break_glass` — and the holder could read the emergency password's hash and the grants; the door verifies no token and reads only whether the cluster is in a domain. `tests/test_policies.py` checks that the policy reads no more of `domain/*` than the code does.
