
- `path "secrets/vms" { capabilities = ["read"] }` — the cluster's key, read by this job's template. Granted to the console, the worker and the recorder (it opens a network volume's secret, the review's fourth pass) and to no other job: the key is not in the store it protects, and not in every process's reach.
- `domain/keys`, `domain/member`, `domain/root`, `domain/grants`, `domain/grants/*`, `domain/revoked`, `domain/break_glass` — read only (`list` only on `domain/grants/*`). What the console's gate reads on every request: the key set, and while there is none, the rows that say this cluster is a member all the same (`w2cplatform/access.py`, `TRUST_KEYS`, `DOMAIN_MARKS`); a domain's image reads the grants by cluster too. No policy let anybody read `domain/*` before М10's eighth review, and the stand enforces no read ACL, so it was not seen: on a real Nomad the gate got a 403 and failed shut. The domain's agent writes these rows; the console never does.
- `platform/*` read covers `platform/schema`, which the console checks first (`check_schema`).
