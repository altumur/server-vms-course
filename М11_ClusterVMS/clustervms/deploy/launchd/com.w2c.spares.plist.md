# com.w2c.spares.plist — the spares script every minute, on a macOS server

**Role in the module.** Lesson 4. The twin of `w2c-spares[-<role>].timer`: `__BOX__/bin/w2c-run.sh spares recworker vmsworker` every 60 s (`StartInterval`) — the runner reads the box's two files (the console's address, the ceilings, this server's name and labels) and runs `w2c-spares.sh`. The script reads the console's numbers and starts the spares this server can serve — each the role's own plist (`~/Library/LaunchAgents/com.w2c.vms.<role>.plist`) copied without its name as `com.w2c.vms.<role>.spare-<n>` under `__BOX__/state/run/w2c-spares`, `SPARE_FOR` and its own ports set, its log beside its role's, and `launchctl bootstrap gui/<uid>`ped — the user's domain, not `system` (the thirteenth review, major 15), so a spare runs as its role does (the twelfth review, blocker 6); it never stops one. Installed only by `install.sh --box <dir> --spares`.
