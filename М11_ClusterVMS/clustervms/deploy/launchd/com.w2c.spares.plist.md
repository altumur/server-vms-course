# com.w2c.spares.plist — the spares script every minute, on a macOS server

**Role in the module.** Lesson 4. The twin of `w2c-spares[-<role>].timer`: `w2c-spares.sh recworker vmsworker` every 60 s (`StartInterval`). The script reads the console's numbers and starts the spares this server can serve — each the role's own plist (`/Library/LaunchDaemons/com.w2c.vms.<role>.plist`) copied without its name as `com.w2c.vms.<role>.spare-<n>` under `/var/run/w2c-spares`, `SPARE_FOR` and its own ports set, and `launchctl bootstrap`ped, so a spare runs as its role does (the twelfth review, blocker 6); it never stops one. Installed only by `install.sh --spares`.
