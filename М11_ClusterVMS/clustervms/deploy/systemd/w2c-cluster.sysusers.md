# w2c-cluster.sysusers — the users and groups of a cluster server

**Role in the module.** Lessons 3 and 5. The platform's user and its clients' groups are the BOX's, by the same numbers (`vmsserver/deploy/w2c.sysusers`, WP-E): `w2c` 2100 runs the resource and owns the events archive; `w2c-events` 2102 (the archive's writers), `w2c-store` 2103 (the objects), `w2c-secrets` 2104 (the key ring). `install.sh` runs the box's `install-obsd.sh`, which applies the box's file after this one and refuses a `w2c` numbered otherwise. `configstore` 2105 runs the store's member and owns its journal alone; the daemon chowns every socket to its role's group, so `configstore` is a member of each group the rights file names — `w2c-resource`, `w2c-domainagent`, `w2c-member`, `vms-console`, `vms-vmscontroller`, `vms-reccontroller`, `vms-vmsworker`, `vms-recworker`. `vms` runs the subsystem's processes, its home `/data/vms`. A unit joins its own role's group and the layout's it uses (`SupplementaryGroups=`). `vms-obsd` is М10's (`obsd.sysusers`, gid 2101).
